---
title: การอัปเดตแพลตฟอร์ม
---

การติดตั้ง Spwig ของคุณถูกสร้างขึ้นจากชุดขององค์ประกอบ — ธีม, วิดเจ็ต, การผสาน, องค์ประกอบสร้างหน้า, และการเชื่อมต่อกับผู้ให้บริการ — แต่ละส่วนมีเวอร์ชันของตัวเองที่สามารถอัปเดตได้อย่างอิสระ รีจิสตรีองค์ประกอบให้คุณมีมุมมองแบบรวมศูนย์เกี่ยวกับทุกสิ่งที่ติดตั้งไว้ แสดงรายการองค์ประกอบที่มีการอัปเดตรออยู่ และอนุญาตให้คุณติดตั้งหรือย้อนกลับการอัปเดตได้ตลอดเวลา

![ภาพรวมรีจิสตรีองค์ประกอบ](/static/core/admin/img/help/platform-updates/component-registry-overview.webp)

## การทำความเข้าใจรีจิสตรีองค์ประกอบ

ไปที่ **แดชบอร์ดระบบ > การอัปเดตอนค์ประกอบ** เพื่อดูองค์ประกอบทั้งหมดที่ติดตั้งไว้ในร้านค้าของคุณ แต่ละแถวแสดง:

- **ชื่อ** — ชื่อแสดงขององค์ประกอบ
- **ประเภท** — ประเภทขององค์ประกอบ (ธีม, วิดเจ็ต, การผสาน, ฯลฯ)
- **เวอร์ชันปัจจุบัน** — เวอร์ชันที่กำลังทำงานอยู่ในร้านค้าของคุณ
- **สถานะการอัปเดต** — ว่ามีการอัปเดตพร้อมใช้งานหรือไม่
- **ช่องทาง** — ช่องทางการอัปเดตที่องค์ประกอบติดตาม
- **อัปเดตอัตโนมัติ** — ว่าการอัปเดตจะติดตั้งโดยอัตโนมัติหรือไม่
- **ล็อก** — ว่าองค์ประกอบถูกแช่แข็งไว้ที่เวอร์ชันปัจจุบันหรือไม่

แดชบอร์ดด้านบนของหน้าแสดงจำนวนสรุป: จำนวนองค์ประกอบทั้งหมดที่ติดตั้งไว้, จำนวนที่มีการอัปเดตพร้อมใช้งาน, และจำนวนที่อัปเดตแล้ว

### ประเภทขององค์ประกอบ

| ประเภท | หมายถึงอะไร |
|------|------------|
| ธีม | ดีไซน์ภาพรวมของร้านค้า |
| วิดเจ็ต | บล็อกสร้างหน้าที่สามารถใช้ซ้ำได้ |
| องค์ประกอบสร้างหน้า | องค์ประกอบเฉพาะสำหรับสร้างหน้า |
| เครื่องมือสร้างหน้า | เครื่องมือและฟังก์ชันสำหรับตัวแก้ไข |
| แม่แบบหัว/ท้าย | รูปแบบหัวและท้าย |
| ผู้ให้บริการการจัดส่ง | การผสานกับผู้ให้บริการจัดส่ง (FedEx, UPS, ฯลฯ) |
| ผู้ให้บริการอีเมล | บริการส่งอีเมล |
| ผู้ให้บริการชำระเงิน | การผสานกับระบบชำระเงิน |
| ผู้ให้บริการอัตราแลกเปลี่ยน | แหล่งข้อมูลอัตราแลกเปลี่ยนสกุลเงิน |
| ผู้ให้บริการแปล | บริการแปลโดยใช้ AI |
| ชุดภาษา | ไฟล์แปลอินเทอร์เฟซ |

## ช่องทางการอัปเดต

องค์ประกอบทุกตัวติดตามช่องทางการอัปเดตที่ควบคุมการปล่อยที่มันจะได้รับ

คุณสามารถกำหนดแต่ละส่วนประกอบให้อยู่ในช่องทางที่แตกต่างกันได้ ตามระดับความเสี่ยงที่คุณรับได้

| ช่องทาง | คำอธิบาย | เหมาะสำหรับ |
|---------|-------------|----------|
| **Stable** | การปล่อยที่พร้อมใช้งานในระบบผลิต ได้รับการทดสอบอย่างละเอียด | ส่วนประกอบทั้งหมดในร้านค้าที่เปิดให้บริการ |
| **Beta** | การสร้างก่อนการปล่อยเพื่อทดสอบคุณสมบัติใหม่ก่อนที่จะเป็นเวอร์ชัน Stable | ส่วนประกอบที่ไม่สำคัญที่คุณต้องการลองใช้ |
| **Development** | คุณสมบัติล่าสุด อาจไม่มั่นคง | แค่ทดสอบในสภาพแวดล้อมการทดสอบ |
| **Security** | แพตช์ด้านความปลอดภัยสำคัญเท่านั้น ถูกส่งด้วยความสำคัญสูงสุด | ส่วนประกอบที่ความมั่นคงเป็นสิ่งสำคัญที่สุด |

เพื่อเปลี่ยนช่องทางของส่วนประกอบ ให้คลิกที่ชื่อของมันเพื่อเปิดมุมมองรายละเอียด แล้วเลือกค่าใหม่ในช่อง **Update Channel** และบันทึก
d
## การตรวจสอบการอัปเดต

Spwig จะตรวจสอบการอัปเดตโดยอัตโนมัติที่ช่วงเวลาที่กำหนดไว้ในการตั้งค่าเซิร์ฟเวอร์อัปเดตของคุณ (ค่าเริ่มต้น: ทุก 24 ชั่วโมง) เพื่อตรวจสอบทันที:

1. ไปที่ **System Dashboard > Component Updates**
2. คลิกปุ่ม **Check for Updates** ที่ด้านบนของหน้าจอ
3. ระบบจะติดต่อเซิร์ฟเวอร์อัปเดตของ Spwig และอัปเดตสถานะการอัปเดตสำหรับส่วนประกอบทั้งหมด
4. ส่วนประกอบที่มีการอัปเดตสามารถใช้งานได้ จะมีการเน้นแสดง และจำนวน **Updates Available** จะอัปเดต
d
คุณยังสามารถเรียกใช้การตรวจสอบการอัปเดตสำหรับส่วนประกอบแต่ละตัวโดยใช้การกระทำ **Check for Updates** จากเมนูการกระทำของรายการ
d

### สิ่งที่เกิดขึ้นระหว่างการอัปเดต

กระบวนการอัปเดตจะดำเนินการผ่านขั้นตอนต่อไปนี้:

1. **Checking** — ยืนยันว่ามีการอัปเดตพร้อมใช้งานและใบอนุญาตของคุณมีความถูกต้อง
2. **Downloading** — ดาวน์โหลดแพ็กเกจจากเซิร์ฟเวอร์อัปเดตของ Spwig
3. **Verifying** — ตรวจสอบความสมบูรณ์ของแพ็กเกจโดยใช้ checksum SHA-256
4. **Extracting** — แตกไฟล์ใหม่ออกมา
5. **Deploying** — เปิดใช้งานเวอร์ชันใหม่
6. **Health check** — ตรวจสอบว่าส่วนประกอบทำงานได้หลังจากการอัปเดต

หากขั้นตอนใดล้มเหลว ระบบจะพยายามกู้คืนเวอร์ชันก่อนหน้าโดยอัตโนมัติ

## การอัปเดตระดับแพลตฟอร์ม

นอกจากส่วนประกอบแต่ละตัวแล้ว Spwig ยังสามารถรับการอัปเดตระดับแพลตฟอร์มที่อัปเดตเครื่องมือหลักของร้านค้าเอง การอัปเดตเหล่านี้ผ่านกระบวนการที่ละเอียดมากขึ้น รวมถึงการย้ายฐานข้อมูลและช่วงเวลาบำรุงรักษาสั้นๆ

ไปที่ **System Dashboard > Platform Updates** เพื่อดูและจัดการการอัปเดตระดับแพลตฟอร์มแยกจากส่วนประกอบแต่ละตัว

### ตรวจสอบสิ่งใหม่ก่อนติดตั้ง

คลิก **Check for Updates** เพื่อดูว่ามีเวอร์ชันแพลตฟอร์มใหม่พร้อมใช้งานหรือไม่ เมื่อพบเวอร์ชันใหม่ บัตร **Update Available** จะแสดงการเปลี่ยนเวอร์ชัน (เช่น `v1.7.0 → v1.7.1`) ขนาดแพ็กเกจ (**Package Size**) เวลาประมาณ (**Est. Time**) และช่องทางอัปเดต (**Channel**) — พร้อมกับตัวอย่าง **What's New** เพื่อให้คุณเห็นสิ่งที่เปลี่ยนไปก่อนตัดสินใจติดตั้ง:

- บรรทัดสรุปสั้นๆ ที่อธิบายการปล่อยเวอร์ชัน
- รายการข้อเปลี่ยนแปลงหลักในเวอร์ชันนั้น (ไม่เกิน 5 ข้อ โดยมีหมายเหตุหากมีมากกว่านั้น)

หากการอัปเดตเปลี่ยนโครงสร้างฐานข้อมูลของคุณ จะมีข้อความ **Requires database migration** พร้อมเวลาประมาณที่แสดง

การอัปเดตด้านความปลอดภัยจะแสดงป้าย **Security update** แนะนำให้ติดตั้งทันที

อ่านข้อมูลการอัปเดตใหม่ล่าสุดก่อนติดตั้ง — นี่คือวิธีที่เร็วที่สุดในการตรวจสอบว่าการปล่อยนี้ต้องการความสนใจเพิ่มเติมหรือไม่ เช่น ขั้นตอนที่ระบุไว้หลังจากอัปเกรดเสร็จสิ้น

ประวัติการอัปเดตแพลตฟอร์มสามารถมองเห็นได้ต่ำกว่านี้ในหน้า แต่ละรายการแสดงการเปลี่ยนเวอร์ชัน (เช่น `v1.3.2 → v1.3.3`) สถานะ และระยะเวลาของการอัปเดต

การอัปเดตด้านความปลอดภัยจะถูกทำเครื่องหมายแยกต่างหาก และหาก **Auto Install Security Updates** ถูกเปิดใช้งานในการตั้งค่าเซิร์ฟเวอร์อัปเดตของคุณ การอัปเดตจะติดตั้งโดยอัตโนมัติโดยไม่ต้องการการดำเนินการด้วยมือ

## การดูประวัติเวอร์ชัน

เพื่อดูเวอร์ชันที่ติดตั้งไว้ก่อนหน้านี้ทั้งหมดของส่วนประกอบ:

1. คลิกที่ชื่อส่วนประกอบเพื่อเปิดมุมมองรายละเอียด
2. ค้นหาส่วน **Component Versions** ที่ด้านล่างของหน้า
3. แต่ละรายการเวอร์ชันแสดงหมายเลขเวอร์ชัน วันที่ติดตั้ง วิธีการติดตั้ง และสถานะสุขภาพ

ระบบจะเก็บเวอร์ชันที่ติดตั้งล่าสุด 3 เวอร์ชันไว้เพื่อใช้ในการย้อนกลับ เวอร์ชันที่เกินกว่านั้นจะถูกลบโดยอัตโนมัติ

## การย้อนกลับส่วนประกอบ

หากการอัปเดตทำให้เกิดปัญหา คุณสามารถย้อนกลับไปยังเวอร์ชันก่อนหน้า:

1. เปิดมุมมองรายละเอียดของส่วนประกอบ
2. ค้นหาส่วน **Rollback**
3. เลือกเวอร์ชันที่คุณต้องการกู้คืน
4. คลิก **Roll Back to this Version**

เวอร์ชันที่มีเครื่องหมาย **Rollback Available** เท่านั้นที่สามารถกู้คืนได้ เข้าสู่บันทึกการย้อนกลับจะบันทึกผู้ที่เริ่มต้นการย้อนกลับและเวลาที่ทำ

## การล็อกส่วนประกอบ

การล็อกส่วนประกอบจะป้องกันไม่ให้การอัปเดตใด ๆ ถูกติดตั้ง รวมถึงการอัปเดตอัตโนมัติ ซึ่งมีประโยชน์เมื่อคุณมีการปรับแต่งหรือการผสานที่พึ่งพาเวอร์ชันเฉพาะ

1. เปิดมุมมองรายละเอียดของส่วนประกอบ
2. ตรวจสอบกล่อง **Locked** ในส่วน **Lock & Freeze**
3. ใส่เหตุผลใน **Lock Reason** เพื่อให้ทีมของคุณเข้าใจว่าทำไมจึงถูกล็อก
4. บันทึกบันทึก

ส่วนประกอบที่ถูกล็อกจะแสดงด้วยตัวบ่งชี้ล็อกในรายการลงทะเบียน เพื่อปลดล็อก ให้ยกเลิกการเลือก **Locked** และบันทึก

## การอ่านบันทึกการอัปเดต

บันทึกการอัปเดตบันทึกการดำเนินการทุกครั้งที่ติดตั้ง อัปเดต ย้อนกลับ และตรวจสอบสุขภาพ:

1. เปิดดูรายละเอียดของส่วนประกอบ
2. **บันทึกการอัปเดต** จะแสดงอยู่ในบรรทัดล่างของหน้า
3. แต่ละรายการแสดง: การดำเนินการที่ทำ เวลาเริ่มต้นและสิ้นสุด รุ่นเก่าและรุ่นใหม่ ว่าเป็นการอัปเดตอัตโนมัติหรือมือ รวมถึงข้อความข้อผิดพลาดหากการดำเนินการล้มเหลว

รายการบันทึกที่มีสถานะ **ล้มเหลว** จะรวมข้อความข้อผิดพลาดทั้งหมดเพื่อช่วยในการแก้ไขปัญหา

## การเปิดใช้งานการอัปเดตอัตโนมัติ

คุณสามารถอนุญาตให้ Spwig ติดตั้งการอัปเดตอัตโนมัติเมื่อมีการอัปเดตใหม่:

1. เปิดดูรายละเอียดของส่วนประกอบ
2. ตรวจสอบ **การอัปเดตอัตโนมัติ** ในส่วน **รุ่นและสถานะการอัปเดต**
3. บันทึกข้อมูล

เมื่อเปิดใช้งานการอัปเดตอัตโนมัติ ระบบจะติดตั้งการอัปเดตในรอบการตรวจสอบที่กำหนดไว้ในอนาคต ข้อความอัปเดตด้านความปลอดภัยจะติดตามการตั้งค่า **การติดตั้งอัตโนมัติของข้อความอัปเดตด้านความปลอดภัย** ทั่วโลก ไม่ว่าจะตั้งค่าส่วนประกอบแต่ละตัวอย่างไร

## เคล็ดลับ

- ควรอัปเดตผ่านช่องทาง **Stable** สำหรับธีมและผู้ให้บริการชำระเงิน — ส่วนประกอบเหล่านี้เป็นส่วนที่มีการใช้งานโดยลูกค้ามากที่สุด และความเสถียรจึงมีความสำคัญที่สุด
- ควรล็อกส่วนประกอบก่อนทำการแก้ไขเฉพาะก่อน แล้วบันทึกเหตุผลอย่างชัดเจน เพื่อให้สมาชิกทีมในอนาคตทราบว่าไม่ควรอัปเดตส่วนประกอบนี้
- ก่อนติดตั้งการเพิ่มรุ่นหลัก ตรวจสอบ **หมายเหตุการปล่อย** บนรายการรุ่นของส่วนประกอบ — การเปลี่ยนแปลงที่ทำลายระบบจะระบุไว้ที่นั่น
- ก่อนติดตั้งการอัปเดตแพลตฟอร์ม โปรดอ่าน **What's New** ที่แสดงในหน้า **Platform Updates** — เพื่อดูหมายเหตุการปล่อยทั้งหมด รวมถึงขั้นตอนเพิ่มเติมที่คุณอาจต้องทำ โปรดไปยังหน้า **System Upgrade**
- หลังจากอัปเดต ให้เข้าไปยังส่วนที่ได้รับผลกระทบของร้านค้าของคุณเพื่อยืนยันว่าทุกอย่างดูและทำงานตามที่คาดไว้ก่อนประกาศว่าการอัปเดตเสร็จสิ้น
- หากเปิดใช้งานการอัปเดตอัตโนมัติในส่วนประกอบ ให้ตรวจสอบ **บันทึกการอัปเดต** อย่างสม่ำเสมอเพื่อให้มั่นใจว่าการอัปเดตอัตโนมัติเสร็จสมบูรณ์
