---
title: 平台更新
---

您的 Spwig 安裝是由一系列組件組成 — 主題、小組件、整合、頁面構建器元素和供應商連接 — 每個組件都有自己的版本，可以獨立更新。組件倉庫為您提供一個集中視圖，顯示所有已安裝的內容，顯示哪些組件有待更新，並讓您隨時安裝或回滾更新。

![組件倉庫概覽](/static/core/admin/img/help/platform-updates/component-registry-overview.webp)

## 理解組件倉庫

導航至 **系統儀表板 > 組件更新**，查看商店中安裝的每個組件。每一行顯示：

- **名稱** — 組件的顯示名稱
- **類型** — 組件的類型（主題、小組件、整合等）
- **當前版本** — 目前在您的商店中運行的版本
- **更新狀態** — 是否有可用更新
- **頻道** — 組件遵循的更新頻道
- **自動更新** — 是否自動安裝更新
- **鎖定** — 組件是否固定在當前版本

頁面頂部的儀表板顯示總結數量：已安裝的總組件數、有多少個有可用更新，以及有多少個已更新。

### 組件類型

| 類型 | 是什麼 |
|------|------------|
| 主題 | 您商店的視覺設計 |
| 小組件 | 可重複使用的頁面構建器區塊 |
| 頁面構建器元素 | 頁面構建器的自定義元素 |
| 頁面構建器工具 | 編輯器工具和實用程式 |
| 頁首/頁尾模板 | 頁首和頁尾的佈局 |
| 運輸供應商 | 載運商整合（FedEx、UPS 等） |
| 電子郵件供應商 | 電子郵件傳遞服務 |
| 支付供應商 | 支付網關整合 |
| 汇率供應商 | 貨幣匯率數據來源 |
| 翻譯供應商 | AI 翻譯服務 |
| 語言包 | 介面翻譯文件 |

## 更新頻道

每個組件都遵循一個更新頻道，該頻道控制它接收哪些發行版本。

你可以根據自己能接受的風險程度，將每個組件分配到不同的頻道。

| 頻道 | 說明 | 最適合用於 |
|---------|-------------|----------|
| **穩定版** | 已準備好用於生產環境，經過充分測試的版本 | 所有在線商店上的組件 |
| **測試版** | 在正式發佈前用於測試新功能的預發佈版本 | 你想要預覽的非關鍵組件 |
| **開發版** | 最新功能，可能不穩定 | 僅限測試環境使用 |
| **安全版** | 僅包含關鍵的安全修補程式，優先級最高 | 穩定性至關重要的組件 |

要更改組件的頻道，請點擊其名稱以打開詳細視圖，然後在 **更新頻道** 欄位中選擇新值並保存。

## 檢查更新

Spwig 會根據你在更新伺服器設定中配置的間隔自動檢查更新（預設：每 24 小時）。若要立即檢查：

1. 進入 **系統儀表板 > 組件更新**
2. 點擊頁面上方的 **檢查更新** 按鈕
3. 系統會聯繫 Spwig 更新伺服器，並刷新所有組件的更新狀態
4. 有可用更新的組件會被標記出來，並更新 **有可用更新** 的數量

你也可以透過列表的動作選單中使用 **檢查更新** 的動作，來觸發單個組件的更新檢查。

## 安裝更新

### 更新單個組件

1. 進入 **系統儀表板 > 組件更新**
2. 找到你想要更新的組件 — 有可用更新的組件會在其版本旁顯示更新指示符
3. 點擊該組件行的 **安裝更新** 按鈕
4. 當提示時確認更新
5. 更新會下載、驗證並安裝 — 進度指示器會顯示每個階段
6. 一旦完成，該組件的 **當前版本** 會更新為新的版本號

### 更新多個組件

1.

選擇你想要更新的組件旁的複選框
2.



從 **Action** 下拉選單中選擇 **Install updates**
3.

點擊 **Go** 以繼續
4.

更新會按照依賴順序進行 — 其他組件所依賴的組件會先更新

### 更新過程中會發生什麼

更新流程會經過以下階段：

1. **Checking** — 確認更新可用且您的許可證有效
2. **Downloading** — 從 Spwig 更新伺服器下載套件
3. **Verifying** — 將套件完整性與 SHA-256 校驗和進行比對
4. **Extracting** — 解壓新文件
5. **Deploying** — 啟用新版本
6. **Health check** — 更新後驗證組件是否正常運作

如果任何階段失敗，系統會自動嘗試恢復到之前的版本。

## 平台級更新

除了個別組件外，Spwig 還可以接收平台級更新，這些更新會更新核心商店引擎本身。這些更新會經過更嚴謹的流程，包括資料庫遷移和短暫的維護時間。

導航至 **System Dashboard > Platform Updates**，以獨立於個別組件的方式查看和管理平台級更新。

### 在安裝前查看新功能

點擊 **Check for Updates** 以查看是否有新的平台版本可用。當發現新版本時，**Update Available** 卡會顯示版本變更（例如 `v1.7.0 → v1.7.1`）、**Package Size**、**Est. Time** 和更新的 **Channel** — 以及 **What's New** 預覽，讓您在決定安裝前查看有哪些變更：

- 一則簡短的摘要行描述該版本的發布
- 一個列出該版本主要變更的項目清單（最多五項，如有更多會附註說明）

如果更新會更改您的資料庫結構，會顯示 **Requires database migration** 通知並附上預估時間。

安全更新會顯示 **Security update** 標籖，建議您立即安裝。

在安裝之前，請先閱讀 What's New 預覽 — 這是最快速的方式，用來查看發行版本是否需要額外的注意事項，例如升級完成後需要執行的步驟。

平台更新歷史記錄可在此頁面下方查看。每個條目會顯示版本過渡（例如 `v1.3.2 → v1.3.3`）、狀態以及更新過程的持續時間。

安全更新會單獨標記，如果在更新伺服器配置中啟用了 **Auto Install Security Updates**，則會自動安裝，無需手動操作。

## 查看版本歷史

要查看組件的所有先前安裝版本：

1. 點擊組件名稱以打開其詳細視圖
2. 向下滾動到頁面底部的 **Component Versions** 區域
3. 每個版本條目會顯示版本號、安裝時間、安裝方法及其健康狀態

系統會保留最後三個已安裝的版本以供回滾。超過這個數量的版本會自動刪除。

## 回滾組件

如果更新導致問題，您可以回滾到之前的版本：

1. 打開組件的詳細視圖
2. 向下滾動到 **Rollback** 區域
3. 選擇您要恢復的版本
4. 點擊 **Roll Back to this Version**

只有標記為 **Rollback Available** 的版本才能恢復。回滾日誌條目會記錄誰啟動了回滾以及時間。

## 锁定組件

鎖定組件可防止任何更新被安裝，包括自動更新。當您在特定版本上有自定義或整合時，這很有用。

1. 打開組件的詳細視圖
2. 在 **Lock & Freeze** 區域中勾選 **Locked** 方框
3. 在 **Lock Reason** 中輸入原因，讓您的團隊了解為什麼它被凍結
4. 儲存記錄

被鎖定的組件會在註冊表列表中顯示鎖定指示符。要解除鎖定，取消勾選 **Locked** 並儲存。

## 阅讀更新日誌

更新日誌會記錄每一次安裝、更新、回滾和健康檢查操作：

1. 開啟組件的詳細視圖
2. **更新日誌**會在頁面底部以內聯方式顯示
3. 每個條目會顯示：採取的動作、開始和結束時間、舊版和新版、是否為自動或手動，以及如果操作失敗時的任何錯誤訊息

狀態為 **Failed** 的日誌條目會包含完整的錯誤訊息，以協助進行問題排除。

## 啟用自動更新

您可以允許 Spwig 在更新可用時自動安裝更新：

1. 開啟組件的詳細視圖
2. 在 **版本與更新狀態** 區域中勾選 **自動更新**
3. 儲存記錄

啟用自動更新後，系統會在下一次預定的檢查週期中安裝更新。安全更新會遵循全域的 **自動安裝安全更新** 設定，與個別組件設定無關。

## 小提示

- 為了主題和支付提供商，始終在 **Stable** 通道上進行更新 — 這些是最面向客戶的組件，穩定性最重要
- 在對組件進行自訂修改之前，先將其鎖定，並清楚記錄原因，以便未來團隊成員知道不要更新它
- 在安裝主要版本升級之前，請查看組件版本條目中的 **發佈說明** — 重大變更會在那裡標記
- 在安裝平台更新之前，請閱讀 **Platform Updates** 頁面上的 **What's New** 預覽 — 若要查看完整的發佈說明，包括您可能需要採取的額外步驟，請繼續前往 **System Upgrade** 頁面
- 更新後，請瀏覽您商店中受影響的區域，確認一切看起來和運作正常，再宣告更新完成
- 如果組件啟用了自動更新，請定期監控 **更新日誌**，以確保自動更新能夠成功完成
