고객 디스플레이는 판매 중 고객에게 보여지는 두 번째 화면입니다. 거래를 처리하는 동안 고객은 각 항목이 스캔될 때마다 항목, 누적 합계, 가격 및 세금 분할, 그리고 판매가 진행되지 않을 때는 프로모션 콘텐츠의 회전 슬라이드 쇼를 보게 됩니다.

이 가이드는 고객 디스플레이를 설정하는 하드웨어 및 페어링 측면을 다룹니다: 터미널에서 기능을 활성화하고, 별도의 장치를 디스플레이 화면으로 페어링하고, 일반적인 설정 시나리오를 처리합니다. 대기 시간 동안 표시되는 프로모션 슬라이드에 대한 정보는 [고객 디스플레이 프로모션 슬라이드](customer-display-promo-slides)를 참조하십시오.

## 고객 디스플레이가 표시하는 내용

판매가 진행 중일 때 고객 디스플레이는 다음과 같이 표시합니다:

- 항목이 추가되거나 제거될 때마다 수량 및 가격
- 장바구니 소계, 적용된 할인, 세금 분할
- 결제가 필요한 총 금액 및 결제 중인 금액과 거스름돈

터미널이 대기 상태일 때(활성 거래 없음), 디스플레이는 프로모션 슬라이드 쇼로 전환됩니다. 이 슬라이드 쇼의 콘텐츠는 별도로 제어할 수 있습니다 — [고객 디스플레이 프로모션 슬라이드](customer-display-promo-slides)를 참조하십시오.

## 일반적인 하드웨어 설정

고객 대면 화면을 설정하는 실용적인 방법은 세 가지입니다:

- **스탠드에 고정된 별도의 태블릿 또는 모니터** — 카운터 판매에 가장 일반적인 설정입니다.

스탠드에 세워진 작은 태블릿은 고객을 향해 배치되고, 주 터미널은 당신을 향해 배치됩니다.

두 장치를 짧은 유효기간의 코드(아래에서 설명됨)를 사용하여 쌍으로 만듭니다.
- **확장된 데스크탑 모드의 두 번째 모니터** — 주 터미널이 노트북 또는 데스크탑인 경우, 두 번째 모니터를 연결하고 데스크탑을 확장한 후, 화면 창을 두 번째 모니터로 끌어다 놓고 최대화합니다.

두 화면은 동일한 장치에서 실행되며, 쌍을 이루는 코드가 필요하지 않습니다.
- **전용 가로대 디스플레이** — 가로대에 장착된 하드웨어 디스플레이 유닛으로, 일반적으로 카운터 터미널과 USB로 연결되거나 카운터에 배치됩니다.

가로대 장치의 브라우저에서 `/pos/display/`를 열고, 주 터미널에서 받은 코드를 사용하여 쌍을 이룹니다.

## 터미널에서 고객 디스플레이 기능 활성화

고객 디스플레이 기능은 터미널의 하드웨어 구성에 따라 터미널별로 활성화됩니다.

1. **POS > 터미널**로 이동하고 구성하려는 터미널을 열거나, 새 터미널을 추가하려면 **+ POS 터미널 추가**를 클릭합니다.
2. **장치** 탭을 클릭합니다.
3. **하드웨어 구성** 카드로 스크롤합니다. JSON 필드를 보게 됩니다.
4. JSON 객체에 `"customer_display": true`를 추가합니다. 예시:

```json
{
  "customer_display": true
}
```

필드에 이미 다른 하드웨어 설정(프린터 또는 스캐너 구성 등)이 포함되어 있는 경우, `"customer_display": true`를 함께 추가합니다:

```json
{
  "printer": {"type": "network", "url": "http://192.168.1.100:9100"},
  "scanner": "keyboard_wedge",
  "customer_display": true
}
```

5. **저장**을 클릭합니다.

![고객 디스플레이 기능이 활성화된 터미널 하드웨어 구성](/static/core/admin/img/help/pos-customer-display-setup/terminal-capabilities-toggle.webp)

활성화된 후, 해당 터미널의 POS 앱은 세션 시작 시 고객 디스플레이 뷰를 두 번째 브라우저 창 또는 탭에서 열게 됩니다.

## 별도 장치를 디스플레이로 쌍을 이루기

고객 화면용으로 별도의 물리적 장치(태블릿, 전화, 두 번째 컴퓨터)를 사용하는 경우, 주 터미널에서 생성된 짧은 유효기간의 6자리 코드를 사용하여 해당 장치와 쌍을 이룹니다.

### 단계 1: 주 터미널에서 쌍을 이루는 코드 생성

# 단계 1: 새로운 디스플레이 페어링 코드 요청

메인 터미널에서 POS 앱을 열고 터미널 인터페이스의 디스플레이 설정 또는 페어링 섹션으로 이동합니다.

새로운 디스플레이 페어링 코드를 요청합니다.

코드는 6자리 숫자이며 **5분** 동안 유효합니다.

새로운 코드를 생성하면 이 터미널에 대한 이전에 사용되지 않은 코드는 자동으로 취소됩니다.

### 단계 2: 고객 기기에서 디스플레이 URL 열기

고객 기기에서 웹 브라우저를 열고 다음 주소로 이동합니다:

```
https://your-store-domain.com/pos/display/
```

로그인은 필요하지 않습니다 — 디스플레이 페이지는 공개적으로 접근할 수 있도록 의도되었습니다. 이는 디스플레이 기기에서 직원 자격 증명이 필요하지 않으며, 페어링 코드가 디스플레이와 올바른 터미널 사이의 연결을 제공하기 때문입니다.

![고객 디스플레이 기본 화면](/static/core/admin/img/help/pos-customer-display-setup/customer-display-view.webp)

### 단계 3: 페어링 코드 입력

고객 기기에서 메인 터미널에서 받은 6자리 코드를 입력합니다. 디스플레이가 해당 터미널과 페어링되어 고객의 실시간 장바구니 데이터를 표시하기 시작합니다.

코드가 사용되면 즉시 무효화되어 재사용할 수 없습니다.

## 페어링 코드 재생성

페어링 코드가 입력하기 전에 만료되었거나, 디스플레이 기기를 다시 페어링해야 하는 경우(예: 디스플레이 기기가 교체되거나 재설정된 경우) 메인 터미널의 POS 앱에서 새로운 코드를 생성합니다.

새로운 코드를 생성하면 해당 터미널에 대한 기존의 사용되지 않은 코드가 자동으로 취소됩니다. 새 코드는 5분 동안 유효합니다.

코드를 재생성하려면 관리자에서 변경할 필요가 없습니다 — 이 작업은 POS 앱 내에서 완전히 수행됩니다.

## 단일 기기에서 다중 모니터 설정

메인 터미널이 노트북 또는 두 개의 모니터가 있는 데스크탑인 경우:

1.

두 번째 모니터를 연결하고 운영 체제의 디스플레이 설정에서 **확장된 데스크탑** 모드로 설정합니다(미러링이 아님).
2.

기본 화면에서 일반적으로 POS 앱을 엽니다.
3.

POS 앱은 고객 디스플레이를 두 번째 창으로 열게 됩니다.

그 창을 두 번째 모니터로 끌어다 놓습니다.
4.

모든 마크다운 포맷, 이미지 경로, 코드 블록 및 기술 용어를 유지합니다.

두 번째 모니터에서 최대화하거나 전체 화면으로 전환합니다.

두 창이 동일한 장치에서 실행되며 직접 통신하므로 페어링 코드가 필요하지 않습니다.

## 대기 상태 행동

활성 판매가 없는 경우 고객 디스플레이에는 프로모션 이미지의 회전 슬라이드가 표시됩니다. 이 슬라이드는 **POS > 프로모션 슬라이드**에서 별도로 생성 및 관리합니다.

슬라이드를 생성하는 방법, 특정 매장에 타겟팅하는 방법, 계절별 콘텐츠를 관리하는 방법에 대한 자세한 내용은 [고객 디스플레이 프로모션 슬라이드](customer-display-promo-slides)를 참조하십시오.

슬라이드가 구성되지 않은 경우 디스플레이에는 귀하의 매장 이름이 포함된 간단한 환영 화면이 표시됩니다.

## 문제 해결

**디스플레이가 검은 화면이 되거나 업데이트가 중단되었습니다**

디스플레이는 주 단말과 실시간으로 통신합니다. 연결이 끊어지면 디스플레이가 검은 화면이 되거나 오래된 데이터를 표시할 수 있습니다. 고객 장치의 브라우저를 새로 고치세요. 이 방법이 효과가 없으면 새로운 페어링 코드를 생성하고 다시 페어링하세요.

**디스플레이가 잘못된 단말의 장바구니를 표시하고 있습니다**

각 디스플레이는 특정 단말에 페어링됩니다. 여러 단말이 있는 경우 해당 단말에서 페어링 코드를 생성했고 디스플레이에 입력했는지 확인하세요. 불일치를 수정하려면 올바른 단말에서 새로운 코드를 생성하고 디스플레이 장치를 다시 페어링하세요.

**페어링 코드가 입력하기 전에 만료되었습니다**

코드는 5분 동안 유효합니다. POS 앱에서 새로운 코드를 생성하고 디스플레이 장치에 즉시 입력하세요. 페어링 과정 중 두 장치가 서로 가까운 곳에 있도록 유지하세요.

**페어링 코드를 입력했지만 디스플레이가 연결되지 않았습니다**

고객 장치가 귀하의 매장 도메인에 도달할 수 있는지 확인하세요(네트워크 액세스가 필요합니다). 또한 단말의 하드웨어 구성에서 `"customer_display": true`가 설정되어 있고 단말이 저장되었는지 확인하세요.

**디스플레이 URL이 오류를 반환합니다**

귀하의 매장 도메인에서 `/pos/display/`로 이동했는지 확인하세요. 관리자 URL이 아닌지 확인하세요.

표시 뷰는 로그인을 요구하지 않습니다 — 로그인하라는 메시지가 표시되면 URL을 다시 확인하세요.

## 팁

- **페어링 세션을 짧게 유지하세요** — 고객 기기와 브라우저가 `/pos/display/`에 열려 있는 상태에서 페어링 코드를 생성하세요. 5분의 시간이 있지만, 1분 이내에 완료하면 타임아웃을 피할 수 있습니다.
- **시작하기 전에 테스트하세요** — 표시가 연결된 상태에서 테스트 판매를 완료하여 첫 번째 실제 거래 전에 고객이 올바른 항목과 총액을 볼 수 있는지 확인하세요.
- **표시 URL을 북마크하세요** — 고객 기기의 브라우저를 시작 시에 자동으로 `/pos/display/`를 열도록 설정하여 항상 준비 상태를 유지하세요.
- **간단함을 위해 확장된 데스크탑 사용** — 터미널에 여유 있는 HDMI 포트와 모니터가 있다면, 확장된 데스크탑 방식은 지속적인 페어링이 필요 없으며 만료되지 않습니다.
- **시작하기 전에 프로모션 슬라이드 추가** — 고객이 아무것도 보지 못하는 빈 환영 화면만 보이는 유휴 표시는 기회를 놓치는 것입니다. 최소한 몇 가지 프로모션 슬라이드를 설정하여 거래가 진행되지 않을 때도 표시가 유용하도록 하세요. [고객 표시 프로모션 슬라이드](customer-display-promo-slides)를 참조하세요.
- **표시 기기를 보호하세요** — 표시 URL은 설계상 공개적으로 접근할 수 있지만, 활성 터미널과 페어링되어 있을 때만 실시간 장바구니 데이터를 표시합니다. 그래도 고객 기기에서 고객이 다른 곳으로 이동하지 못하도록 하기 위해 키오스크 브라우저 모드를 고려하세요.
