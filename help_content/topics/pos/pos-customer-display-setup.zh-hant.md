客戶顯示器是在交易過程中面向客戶的第二個螢幕。當您在處理交易時，客戶可以看到每個掃描的項目、累計總額、價格和稅額明細，以及在沒有交易進行時，輪播您促銷內容的幻燈片。

本指南涵蓋設定客戶顯示器的硬體和配對方面：在終端機上啟用此功能、將獨立設備配對為顯示螢幕，以及處理常見的設定場景。如需閒置期間顯示的促銷幻燈片資訊，請參閱[客戶顯示器促銷幻燈片](customer-display-promo-slides)。

## 客戶顯示器顯示的內容

當交易進行中時，客戶顯示器會顯示：

- 每個新增或移除的項目，包含數量和價格
- 購物車小計、應用的折扣以及稅額明細
- 應付總額，以及在付款時的支付金額和找零

當終端機閒置（無活動交易）時，顯示器會切換到促銷幻燈片。您可以獨立控制這些幻燈片的內容——請參閱[客戶顯示器促銷幻燈片](customer-display-promo-slides)。

## 常見的硬體設定

有三種實際方法可以設定面向客戶的螢幕：

- **獨立的平板電腦或監視器（放在支架上）** — 用於櫃檯銷售的最常見設定。

一個小平板放在支架上面對客戶，而您的主要終端機則面對您自己。

您使用一个短暂有效的代码（如下所述）将两个设备配对。
- **扩展桌面模式下的第二个显示器** — 如果您的主终端是笔记本电脑或台式机，请连接第二个显示器，将桌面扩展到该显示器上，然后将显示窗口拖到第二个显示器并最大化。

两个屏幕都在同一台设备上运行；不需要配对代码。
- **专用立柱显示器** — 一种安装在立柱上的硬件显示器单元，通常通过 USB 连接到收银终端，或放置在收银台上。

在立柱设备的浏览器中打开 `/pos/display/`，并使用主终端上的代码进行配对。

## 在终端上启用客户显示器

客户显示器功能是通过终端的硬件配置在每个终端上启用的。

1. 导航到 **POS > 终端**，并打开您要配置的终端（或点击 **+ 添加 POS 终端** 以添加新终端）。
2. 点击 **设备** 选项卡。
3. 滚动到 **硬件配置** 卡。您将看到一个 JSON 字段。
4. 将 `"customer_display": true` 添加到 JSON 对象中。例如：

```json
{
  "customer_display": true
}
```

如果该字段已经包含其他硬件设置（如打印机或扫描仪配置），请将 `"customer_display": true` 与它们一起添加：

```json
{
  "printer": {"type": "network", "url": "http://192.168.1.100:9100"},
  "scanner": "keyboard_wedge",
  "customer_display": true
}
```

5. 点击 **保存**。

![启用 customer_display 的终端硬件配置](/static/core/admin/img/help/pos-customer-display-setup/terminal-capabilities-toggle.webp)

启用后，该终端上的 POS 应用程序在会话开始时将在第二个浏览器窗口或标签页中打开客户显示器视图。

## 将独立设备配对为显示器

如果您使用独立的物理设备作为客户屏幕（平板电脑、手机或第二台计算机），您将使用一个短暂有效的 6 位代码将其与终端配对。

### 第 1 步：在主终端上生成配对代码


# 第 3 部分：顯示器配對設定

在主終端機上啟動 POS 應用程式，並前往終端機介面的顯示設定或配對部分。

請求新的顯示配對碼。

該碼是 6 位數字，且在 **5 分鐘** 內有效。

當您生成新碼時，此終端機的任何先前未使用的碼都會自動取消。

### 第 2 步：在客戶設備上開啟顯示 URL

在客戶面對的設備上，開啟網頁瀏覽器並前往：

```
https://your-store-domain.com/pos/display/
```

不需要登入 — 顯示頁面是公開可訪問的。這是故意設計的：顯示設備不需要員工憑證，配對碼提供了顯示器與正確終端機之間的連結。

![客戶顯示器閒置視圖](/static/core/admin/img/help/pos-customer-display-setup/customer-display-view.webp)

### 第 3 步：輸入配對碼

在客戶設備上，輸入來自主終端機的 6 位數碼。顯示器將配對到該終端機，並開始顯示即時購物車資料。

一旦碼被使用，它會立即失效且無法重複使用。

## 重新生成配對碼

如果配對碼在您能夠輸入之前過期，或者您需要重新配對顯示設備（例如，顯示設備被更換或重置），請從主終端機上的 POS 應用程式生成新碼。

生成新碼會自動取消該終端機的任何現有未使用碼。新碼在 5 分鐘內有效。

您不需要在管理介面中更改任何內容來重新生成碼 — 這完全是在 POS 應用程式內完成的。

## 在單一設備上的多顯示器設定

如果您的主終端機是筆記型電腦或桌面電腦，並配有兩個顯示器：

1. 

  將第二個顯示器連接起來，並在作業系統的顯示設定中將其設定為 **擴展桌面** 模式（而非鏡像）。
2. 

  如常在主螢幕上開啟 POS 應用程式。
3. 

  POS 應用程式會在第二個視窗中開啟客戶顯示器。

  將該視窗拖動到第二個顯示器上。
4. 

  保留所有 markdown 格式、圖片路徑、程式碼區塊和技術術語。

在第二台顯示器上最大化或進入全屏模式。

不需要配對碼，因為兩個視窗都運行在同一台設備上，並直接進行通訊。

## 空閒行為

當沒有進行銷售時，客戶顯示器會顯示促銷圖片的輪播幻燈片。您可以在 **POS > 優惠幻燈片** 中另行創建和管理這些幻燈片。

如需了解如何創建幻燈片、針對特定商店進行目標設定以及管理季節性內容，請參閱 [客戶顯示器優惠幻燈片](customer-display-promo-slides)。

如果未配置任何幻燈片，顯示器將顯示一個簡單的歡迎畫面，並顯示您的商店名稱。

## 故障排除

**顯示器變為空白或停止更新**

顯示器會與主終端機實時通訊。如果連接中斷，顯示器可能會變為空白或顯示過時的數據。請在客戶設備上刷新瀏覽器。如果這沒有幫助，請生成新的配對碼並重新配對。

**顯示器顯示錯誤的終端機購物車**

每個顯示器都與特定的終端機配對。如果您有多個終端機，請確保您是在正確的終端機上生成配對碼，並在顯示器上輸入該碼。要解決不匹配的問題，請在正確的終端機上生成新碼，並重新配對顯示器設備。

**配對碼在我能輸入之前就過期了**

配對碼的有效期為 5 分鐘。請從 POS 應用程式生成新的配對碼，並及時在顯示器設備上輸入。在配對過程中，請確保兩台設備靠近。

**已輸入配對碼但顯示器未連接**

請確認客戶設備可以連接到您的商店域名（需要網絡訪問）。同時請確認終端機的硬體配置中設置了 `"customer_display": true`，並已保存終端機。

**顯示器 URL 返回錯誤**

請確保您導航到商店域名的 `/pos/display/`，而不是管理員 URL。

顯示視圖不需要登入 — 如果您被要求登入，請再次檢查 URL。

## 小技巧

- **保持配對會話簡短** — 在生成配對碼之前，請確保客戶設備已準備好，並在瀏覽器中打開 `/pos/display/`。您有 5 分鐘的時間，但若能在 1 分鐘內完成，可避免超時。
- **在啟用前進行測試** — 在首次實際交易前，連接顯示器完成一次測試交易，以確認客戶能看到正確的商品和總金額。
- **將顯示 URL 加入書籤** — 設置客戶設備的瀏覽器在啟動時自動打開 `/pos/display/`，這樣它始終處於準備狀態。
- **使用擴展桌面以簡化操作** — 如果您的終端機有額外的 HDMI 接口和顯示器可用，擴展桌面的方式不需要持續配對，且從不過期。
- **在啟用前添加促銷幻燈片** — 僅顯示空白歡迎畫面的閒置顯示器是浪費機會。請至少設置幾張促銷幻燈片，這樣即使沒有交易進行中，顯示器也能發揮作用。請參閱 [客戶顯示器促銷幻燈片](customer-display-promo-slides)。
- **保護顯示設備** — 顯示 URL 的設計是公開可訪問的，但它只在與活動終端機配對時顯示即時購物車資料。儘管如此，請考慮在客戶設備上使用 kiosk 瀏覽器模式，以防止客戶導航到其他地方。
