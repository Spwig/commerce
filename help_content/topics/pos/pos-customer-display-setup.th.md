หน้าจอแสดงผลลูกค้าคือหน้าจอที่สองที่หันหน้าไปทางลูกค้าขณะทำการขาย เมื่อคุณกำลังดำเนินการชำระเงิน ลูกค้าจะเห็นรายการสินค้าที่ถูกสแกน ยอดรวมที่กำลังดำเนินการ ราคาและรายละเอียดภาษี และเมื่อไม่มีการขายใดๆ กำลังดำเนินการอยู่ หน้าจอจะแสดงสไลด์โชว์โปรโมชันของคุณอย่างต่อเนื่อง

คู่มือนี้ครอบคลุมด้านฮาร์ดแวร์และการจับคู่ในการตั้งค่าหน้าจอแสดงผลลูกค้าของคุณ: การเปิดใช้งานฟีเจอร์บนเทอร์มินัล การจับคู่อุปกรณ์แยกต่างหากเป็นหน้าจอแสดงผล และการจัดการสถานการณ์การตั้งค่าทั่วไป สำหรับข้อมูลเกี่ยวกับสไลด์โชว์โปรโมชันที่แสดงในช่วงเวลาที่ไม่มีการขาย โปรดดู [Customer Display Promo Slides](customer-display-promo-slides)

## สิ่งที่หน้าจอแสดงผลลูกค้าแสดง

เมื่อมีการขายที่ดำเนินการอยู่ หน้าจอแสดงผลลูกค้าจะแสดง:

- รายการสินค้าที่ถูกเพิ่มหรือลบ พร้อมจำนวนและราคา
- ยอดรวมตะกร้าสินค้า คูปองส่วนลดที่ใช้ และรายละเอียดภาษี
- ยอดเงินที่ต้องชำระ และในระหว่างการชำระเงิน จำนวนเงินที่จ่ายและเงินทอน

เมื่อเทอร์มินัลอยู่ในสถานะว่าง (ไม่มีการทำธุรกรรมที่ดำเนินการอยู่) หน้าจอจะเปลี่ยนไปเป็นสไลด์โชว์โปรโมชัน คุณสามารถควบคุมเนื้อหาของสไลด์โชว์นี้ได้แยกต่างหาก — ดู [Customer Display Promo Slides](customer-display-promo-slides)

## ตั้งค่าฮาร์ดแวร์ที่พบบ่อย

มีวิธีการตั้งค่าหน้าจอแสดงผลสำหรับลูกค้า 3 วิธีที่ใช้กันอย่างแพร่หลาย:

- **แท็บเล็ตหรือหน้าจอแยกต่างหากที่ตั้งอยู่บนขาตั้ง** — วิธีตั้งค่าที่พบบ่อยที่สุดสำหรับการขายที่เคาน์เตอร์

แท็บเล็ตขนาดเล็กที่วางอยู่บนขาตั้งหันหน้าไปทางลูกค้า ในขณะที่เทอร์มินัลหลักของคุณหันหน้าไปทางคุณ

คุณจับคู่อุปกรณ์ทั้งสองโดยใช้รหัสที่มีอายุสั้น (อธิบายไว้ด้านล่าง)
- **หน้าจอเสริมในโหมดเดสก์ท็อปขยาย** — หากอุปกรณ์หลักของคุณเป็นแล็ปท็อปหรือเดสก์ท็อป ให้เชื่อมต่อหน้าจอเพิ่มเติม ขยายเดสก์ท็อปไปยังหน้าจอที่สอง จากนั้นลากหน้าต่างแสดงผลไปยังหน้าจอที่สองและขยายให้เต็มหน้าจอ

ทั้งสองหน้าจอทำงานบนอุปกรณ์เดียวกัน ไม่จำเป็นต้องใช้รหัสจับคู่
- **หน้าจอที่ติดตั้งบนเสา** — หน่วยแสดงผลฮาร์ดแวร์ที่ติดตั้งบนเสา โดยทั่วไปจะเชื่อมต่อกับอุปกรณ์ที่เคาน์เตอร์ผ่าน USB หรือวางไว้ที่เคาน์เตอร์

เปิดหน้าเว็บเบราว์เซอร์ของอุปกรณ์เสาที่ `/pos/display/` และจับคู่มันโดยใช้รหัสจากอุปกรณ์หลัก

## การเปิดใช้งานหน้าจอสำหรับลูกค้าบนอุปกรณ์ปลายทาง

คุณสมบัติหน้าจอสำหรับลูกค้าจะถูกเปิดใช้งานต่ออุปกรณ์ปลายทางผ่านการตั้งค่าฮาร์ดแวร์ของอุปกรณ์ปลายทาง

1. ไปที่ **POS > Terminals** และเปิดอุปกรณ์ปลายทางที่คุณต้องการตั้งค่า (หรือคลิก **+ Add POS Terminal** สำหรับอุปกรณ์ใหม่)
2. คลิกแท็บ **Device**
3. ค้นหาไปยัง **Hardware Configuration** คุณจะเห็นฟิลด์ JSON
4. เพิ่ม `"customer_display": true` ลงในวัตถุ JSON ตัวอย่างเช่น:

```json
{
  "customer_display": true
}
```

หากฟิลด์นั้นมีการตั้งค่าฮาร์ดแวร์อื่นอยู่แล้ว (เช่น การตั้งค่าเครื่องพิมพ์หรือสแกนเนอร์) ให้เพิ่ม `"customer_display": true` ไปพร้อมกับการตั้งค่าเหล่านั้น:

```json
{
  "printer": {"type": "network", "url": "http://192.168.1.100:9100"},
  "scanner": "keyboard_wedge",
  "customer_display": true
}
```

5. คลิก **Save**

![การตั้งค่าฮาร์ดแวร์ของอุปกรณ์ปลายทางที่เปิดใช้งาน customer_display](/static/core/admin/img/help/pos-customer-display-setup/terminal-capabilities-toggle.webp)

เมื่อเปิดใช้งานแล้ว แอป POS บนอุปกรณ์ปลายทางนั้นจะเปิดหน้าจอสำหรับลูกค้าในหน้าต่างหรือแท็บเบราว์เซอร์ที่สองเมื่อเริ่มเซสชัน

## การจับคู่อุปกรณ์แยกต่างหากเป็นหน้าจอ

หากคุณใช้อุปกรณ์ทางกายภาพแยกต่างหากสำหรับหน้าจอของลูกค้า (แท็บเล็ต โทรศัพท์ หรือคอมพิวเตอร์เครื่องที่สอง) คุณจะจับคู่มันกับอุปกรณ์ปลายทางโดยใช้รหัส 6 หลักที่มีอายุสั้น

### ขั้นตอนที่ 1: สร้างรหัสจับคู่บนอุปกรณ์หลัก

เปิดแอป POS บนเทอร์มินัลหลักของคุณ และไปที่ส่วนตั้งค่าการแสดงผลหรือส่วนการจับคู่ของอินเทอร์เฟซเทอร์มินัล

ขอรหัสจับคู่การแสดงผลใหม่

รหัสเป็นตัวเลข 6 หลัก และมีอายุใช้งาน **5 นาที**

เมื่อคุณสร้างรหัสใหม่ รหัสที่ยังไม่ได้ใช้ก่อนหน้านี้สำหรับเทอร์มินัลนี้จะถูกยกเลิกอัตโนมัติ

### ขั้นตอนที่ 2: เปิด URL ของหน้าจอแสดงผลบนอุปกรณ์ของลูกค้า

บนอุปกรณ์ที่ใช้แสดงผลสำหรับลูกค้า ให้เปิดเบราว์เซอร์และไปที่:

```
https://your-store-domain.com/pos/display/
```

ไม่จำเป็นต้องเข้าสู่ระบบ — หน้าแสดงผลสามารถเข้าถึงได้โดยทั่วไป: หน้าแสดงผลไม่จำเป็นต้องใช้ข้อมูลประจำตัวของพนักงาน และรหัสจับคู่จะเป็นตัวเชื่อมระหว่างหน้าจอแสดงผลกับเทอร์มินัลที่ถูกต้อง

![มุมมองหน้าจอแสดงผลของลูกค้า](/static/core/admin/img/help/pos-customer-display-setup/customer-display-view.webp)

### ขั้นตอนที่ 3: ใส่รหัสจับคู่

บนอุปกรณ์ของลูกค้า ให้ใส่รหัส 6 หลักจากเทอร์มินัลหลัก หน้าจอแสดงผลจะจับคู่กับเทอร์มินัลนั้นและเริ่มแสดงข้อมูลตะกร้าสินค้าแบบเรียลไทม์

เมื่อใช้รหัสแล้ว รหัสจะถูกทำให้ใช้งานไม่ได้ทันที และไม่สามารถใช้ซ้ำได้

## การสร้างรหัสจับคู่ใหม่

หากรหัสจับคู่หมดอายุก่อนที่คุณจะสามารถใส่ได้ หรือหากคุณต้องการจับคู่อุปกรณ์แสดงผลใหม่ (เช่น หากอุปกรณ์แสดงผลถูกเปลี่ยนหรือรีเซ็ต) ให้สร้างรหัสใหม่จากแอป POS บนเทอร์มินัลหลัก

การสร้างรหัสใหม่จะยกเลิกรหัสที่ยังไม่ได้ใช้ที่มีอยู่ก่อนหน้านี้สำหรับเทอร์มินัลนั้น รหัสใหม่มีอายุ 5 นาที

คุณไม่จำเป็นต้องเปลี่ยนอะไรในแดชบอร์ดผู้ดูแลระบบเพื่อสร้างรหัสใหม่ — การดำเนินการนี้ทำได้ทั้งหมดภายในแอป POS เท่านั้น

## การตั้งค่าหลายหน้าจอบนอุปกรณ์เดียว

หากเทอร์มินัลหลักของคุณเป็นแล็ปท็อปหรือคอมพิวเตอร์เดสก์ท็อปที่มีหน้าจอสองจอ:

1.

เชื่อมต่อหน้าจอที่สอง และตั้งค่าเป็นโหมด **extended desktop** ในตัวจัดการการแสดงผลของระบบปฏิบัติการ (ไม่ใช่โหมด mirror)
2.

เปิดแอป POS บนหน้าจอหลักตามปกติ
3.

แอป POS จะเปิดหน้าจอแสดงผลลูกค้าในหน้าต่างที่สอง

ลากหน้าต่างนั้นไปยังหน้าจอที่สอง
4.



最大化或进入第二显示器全屏模式。

การแสดงผลไม่จำเป็นต้องเข้าสู่ระบบ — หากคุณถูกขอให้เข้าสู่ระบบ กรุณาตรวจสอบ URL อีกครั้ง

## เคล็ดลับ

- **รักษาเซสชันการจับคู่ให้สั้น** — ให้อุปกรณ์ของลูกค้าพร้อมใช้งาน และเปิดเบราว์เซอร์ไปที่ `/pos/display/` ก่อนสร้างรหัสการจับคู่ คุณมีเวลา 5 นาที แต่การดำเนินการภายใน 1 นาทีจะช่วยหลีกเลี่ยงการหมดเวลา
- **ทดสอบก่อนเปิดใช้งาน** — ทำรายการขายทดสอบโดยใช้การแสดงผลที่เชื่อมต่อเพื่อตรวจสอบว่าลูกค้าจะเห็นรายการและยอดรวมที่ถูกต้องก่อนการทำรายการจริงครั้งแรกของคุณ
- **บันทึก URL แสดงผล** — ตั้งค่าเบราว์เซอร์ของอุปกรณ์ลูกค้าให้เปิด `/pos/display/` ที่การเริ่มต้น เพื่อให้พร้อมใช้งานเสมอ
- **ใช้โหมดเดสก์ท็อปขยายเพื่อความสะดวก** — หากเทอร์มินัลของคุณมีพอร์ต HDMI ว่างและมีหน้าจอเพิ่มเติม วิธีการใช้โหมดเดสก์ท็อปขยายจะไม่ต้องการการจับคู่ต่อเนื่องและไม่มีการหมดอายุ
- **เพิ่มสไลด์โปรโมชันก่อนเปิดใช้งาน** — การแสดงผลที่แสดงเพียงหน้าจอต้อนรับว่างเปล่าเป็นโอกาสที่สูญเสียไป จัดตั้งสไลด์โปรโมชันอย่างน้อย 2-3 หน้าเพื่อให้การแสดงผลมีประโยชน์แม้ในกรณีที่ไม่มีการขายใดๆ อยู่ในขณะนั้น ดู [Customer Display Promo Slides](customer-display-promo-slides)
- **ป้องกันอุปกรณ์แสดงผล** — URL แสดงผลถูกออกแบบมาให้เข้าถึงได้จากสาธารณะ แต่มันจะแสดงข้อมูลตะกร้าที่กำลังดำเนินการก็ต่อเมื่อจับคู่กับเทอร์มินัลที่ใช้งานอยู่เท่านั้น อย่างไรก็ตาม ควรพิจารณาใช้โหมดเบราว์เซอร์แบบเคสิโอ (kiosk) บนอุปกรณ์ลูกค้าเพื่อป้องกันไม่ให้ลูกค้าเข้าถึงส่วนอื่นๆ
