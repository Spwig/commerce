顧客ディスプレイは、売買中に顧客に向ける2番目の画面です。取引を処理している間、顧客はスキャンされた各商品、累計金額、価格と税金の明細を表示します。取引が進行していないときは、プロモーションコンテンツのスライドショーが回転表示されます。

このガイドでは、顧客ディスプレイのハードウェアとペアリングの設定について説明します。端末で機能を有効にする、別々のデバイスをディスプレイ画面としてペアリングする、一般的な設定シナリオの処理方法について説明します。アイドル期間中に表示されるプロモーションスライドに関する情報については、[顧客ディスプレイプロモーションスライド](customer-display-promo-slides)を参照してください。

## 顧客ディスプレイが表示する内容

取引がアクティブな場合、顧客ディスプレイは以下を表示します：

- 商品が追加または削除されるたびに、数量と価格を表示
- カートの小計、適用された割引、および税金の明細
- 支払うべき合計金額、支払い中の支払額とおつり

端末がアイドル状態（アクティブな取引がない）のときは、ディスプレイはプロモーションスライドショーに切り替わります。そのスライドショーのコンテンツは別途管理します — [顧客ディスプレイプロモーションスライド](customer-display-promo-slides)を参照してください。

## 一般的なハードウェア設定

顧客向けの画面を設定する実用的な方法は3つあります：

- **スタンドに設置された別々のタブレットまたはモニター** — カウンター販売で最も一般的な設定です。

スタンドに設置された小さなタブレットが顧客に向かい、メインの端末はあなたに向いています。

2台のデバイスをペアリングするには、以下で説明する短い有効期限付きコードを使用します。
- **拡張デスクトップモードでの2番目のモニター** — メイン端末がノートPCまたはデスクトップの場合、2番目のモニターを接続し、デスクトップを拡張してから、表示ウィンドウを2番目のモニターにドラッグし、最大化してください。

両方の画面は同じデバイスで動作しています。ペアリングコードは必要ありません。
- **専用のポールディスプレイ** — ポールに取り付けられたハードウェアディスプレイユニットで、通常はカウンター端末とUSBで接続されたり、カウンター上に配置されています。

ポールデバイスのブラウザで `/pos/display/` を開き、メイン端末のコードを使用してペアリングしてください。

## ターミナルで顧客ディスプレイを有効にする

顧客ディスプレイ機能は、ターミナルごとにターミナルのハードウェア構成を通じて有効になります。

1. **POS > Terminals** に移動し、設定したいターミナルを開きます（または新しいターミナルを追加する場合は **+ Add POS Terminal** をクリックします）。
2. **Device** タブをクリックします。
3. **Hardware Configuration** カードまでスクロールします。JSONフィールドが表示されます。
4. JSONオブジェクトに `"customer_display": true` を追加します。例:

```json
{
  "customer_display": true
}
```

すでに他のハードウェア設定（プリンターやスキャナの設定など）が含まれている場合、`"customer_display": true` をそれらと一緒に追加します:

```json
{
  "printer": {"type": "network", "url": "http://192.168.1.100:9100"},
  "scanner": "keyboard_wedge",
  "customer_display": true
}
```

5. **Save** をクリックします。

![顧客ディスプレイを有効にしたターミナルのハードウェア構成](/static/core/admin/img/help/pos-customer-display-setup/terminal-capabilities-toggle.webp)

有効にした後、そのターミナルのPOSアプリはセッションが開始されたときに、2番目のブラウザウィンドウまたはタブで顧客ディスプレイビューを開きます。

## 別のデバイスをディスプレイとしてペアリングする

顧客画面用に別々の物理デバイス（タブレット、スマートフォン、または2番目のコンピュータ）を使用している場合、ターミナルに短い有効期限付き6桁のコードを使用してペアリングします。

### ステップ1: メインターミナルでペアリングコードを生成する


# ステップ 1: メイン端末で表示ペアリングコードを生成する

メイン端末でPOSアプリを開き、端末インターフェースの表示設定またはペアリングセクションにアクセスしてください。

新しい表示ペアリングコードをリクエストしてください。

コードは6桁の数字であり、**5分**間有効です。

新しいコードを生成すると、この端末の以前に使用されていないコードは自動的にキャンセルされます。

### ステップ 2: 顧客端末で表示URLを開く

顧客向けの端末で、ウェブブラウザを開き、以下にアクセスしてください：

```
https://your-store-domain.com/pos/display/
```

ログインは必要ありません — 表示ページは公開アクセス可能です。これは意図的な設計です：表示デバイスはスタッフの資格情報を必要とせず、ペアリングコードが表示と正しい端末の間のリンクを提供します。

![顧客表示アイドルビュー](/static/core/admin/img/help/pos-customer-display-setup/customer-display-view.webp)

### ステップ 3: ペアリングコードを入力する

顧客端末で、メイン端末から取得した6桁のコードを入力してください。表示はその端末にペアリングされ、リアルタイムのカートデータを表示し始めます。

コードが使用されると、すぐに無効となり、再利用することはできません。

## ペアリングコードの再生成

ペアリングコードが入力する前に期限切れになった場合、または表示デバイスを再ペアリングする必要がある場合（たとえば、表示デバイスが交換またはリセットされた場合など）は、メイン端末のPOSアプリから新しいコードを生成してください。

新しいコードを生成すると、その端末の既存の未使用コードは自動的にキャンセルされます。新しいコードは5分間有効です。

コードを再生成するには、管理者画面で変更を加える必要はありません — これはPOSアプリ内で完全に処理されます。

## 単一のデバイスでのマルチモニタ設定

メイン端末がノートPCまたは2つのモニタを持つデスクトップの場合：

1.

2番目のモニタを接続し、オペレーティングシステムのディスプレイ設定で**拡張デスクトップ**モード（ミラーリングモードではない）に設定してください。
2.

通常通り、プライマリ画面でPOSアプリを開きます。
3.

POSアプリは、顧客表示を別のウィンドウで開きます。

そのウィンドウを2番目のモニタにドラッグしてください。
4.



セカンドモニターで最大化またはフルスクリーン表示します。

ペアリングコードは必要ありません。両方のウィンドウが同じデバイス上で動作し、直接通信しているためです。

## アイドル時の動作

アクティブな販売がない場合、顧客ディスプレイはプロモーション画像の回転スライドショーを表示します。これらのスライドは **POS > Promo Slides** で別途作成および管理します。

スライドの作成方法、特定の店舗へのターゲティング、季節コンテンツの管理については、[Customer Display Promo Slides](customer-display-promo-slides) を参照してください。

スライドが設定されていない場合、ディスプレイはあなたの店舗名を表示するシンプルなウェルカム画面を表示します。

## トラブルシューティング

**ディスプレイが真っ黒になった、または更新が止まった**

ディスプレイはメイン端末とリアルタイムで通信しています。接続が中断された場合、ディスプレイが真っ黒になるか、古いデータを表示する可能性があります。顧客のデバイスでブラウザを再読み込みしてください。それでも改善しない場合は、新しいペアリングコードを生成し、再ペアリングしてください。

**ディスプレイが間違った端末のカートを表示している**

各ディスプレイは特定の端末にペアリングされています。複数の端末がある場合は、正しい端末でペアリングコードを生成し、ディスプレイにそれを入力したことを確認してください。不一致を修正するには、正しい端末で新しいコードを生成し、ディスプレイデバイスを再ペアリングしてください。

**ペアリングコードの有効期限が切れた**

コードは5分間有効です。POSアプリから新しいコードを生成し、ディスプレイデバイスに入力してください。ペアリングプロセス中は、2つのデバイスを近くに置いてください。

**ペアリングコードを入力したが、ディスプレイが接続されなかった**

顧客のデバイスが店舗のドメインにアクセスできるかを確認してください（ネットワークアクセスが必要です）。また、端末のハードウェア設定で `"customer_display": true` が設定されていることを確認し、端末が保存されていることを確認してください。

**ディスプレイのURLがエラーを返す**

店舗のドメインで `/pos/display/` にアクセスしていることを確認してください。管理用URLではなく、このURLであることを確認してください。

ディスプレイビューはログイン不要です — ログインを求められたら、URLが正しいか再度確認してください。

## Tips

- **ペアリングセッションは短く保つ** — ペアリングコードを生成する前に、顧客の端末が準備できており、ブラウザで `/pos/display/` が開いていることを確認してください。5分ありますが、1分以内に完了させることでタイムアウトを避けることができます。
- **開店前にテストする** — ディスプレイを接続してテスト販売を行い、最初の実際の取引が始まる前に、顧客が正しい商品と合計金額を表示していることを確認してください。
- **ディスプレイURLをブックマークする** — 顧客の端末のブラウザを起動時に常に `/pos/display/` を開くように設定し、常に準備を整えましょう。
- **拡張デスクトップを使用してシンプルに** — 終端に余分なHDMIポートとモニターが利用できる場合は、拡張デスクトップアプローチは継続的なペアリングを必要とせず、期限切れの心配もありません。
- **開店前にプロモーションスライドを追加する** — ただ空白のウェルカム画面しか表示されないアイドル状態のディスプレイは、機会を逃していることになります。取引が進行中でない場合でもディスプレイが役立つように、少なくとも数枚のプロモーションスライドを設定してください。[Customer Display Promo Slides](customer-display-promo-slides) を参照してください。
- **ディスプレイデバイスをセキュリティで保護する** — ディスプレイURLは設計上、公開アクセス可能ですが、アクティブな端末とペアリングされている場合にのみ、ライブカートデータを表示します。それでも、顧客デバイスでキオスクブラウザモードを使用して、顧客が他の場所に移動できないようにするのも考慮してください。
