title: POS 직원 로그인 및 생체 인식 로그인
---

POS 계산대에서 고객을 서비스하는 모든 사람은 적절한 권한을 가진 직원 계정이 필요합니다. 이 주제는 해당 계정을 생성하는 방법, 직원을 터미널에 할당하는 방법, 그리고 그들이 비밀번호를 입력하지 않고 지문, 얼굴 인식, 하드웨어 패스워드로 계산대를 잠금 해제할 수 있도록 생체 인식 로그인을 설정하는 방법을 설명합니다.

PIN 코드, 할인 한도 및 터미널 잠금 설정은 [POS 직원 할인 및 터미널 보안](pos-staff-discounts)을 참조하세요.

## 직원이 POS 터미널을 사용하기 위해 필요한 사항

POS 터미널에 로그인하려면 다음과 같은 것이 필요합니다:

1. **직원 계정** — **직원 상태** 플래그가 활성화된 Spwig 사용자.
2. **POS 액세스를 포함한 역할** — 역할은 직원이 관리자 내에서 할 수 있는 작업을 제어합니다. POS 권한이 포함된 역할이 필요합니다.
3. **터미널 할당** — 터미널은 해당 직원을 할당된 직원으로 표시해야 하거나, 매장 위치 수준에서 할당되어야 합니다.

## POS 자격을 갖춘 직원 계정 생성

**직원 및 계정 > 직원**으로 이동하세요 (또는 `/admin/accounts/staffmember/`로 이동하세요).

1. **+ 직원 추가**를 클릭합니다.
2. 직원의 **이름**, **성**, **이메일 주소**를 입력합니다.
3. 임시 비밀번호를 설정하고 직원에게 첫 로그인 시 변경하도록 요청합니다.
4. **직원 상태**가 선택되어 있는지 확인합니다 — 이 옵션은 그들이 관리자 및 POS 애플리케이션에 로그인할 수 있도록 허용합니다.
5. **저장**을 클릭합니다.

> **참고:** 일반적인 현금원이나 감독자에게 **슈퍼유저 상태**를 선택하지 마세요. 슈퍼유저 상태는 모든 권한 검사를 우회하며, 매장 소유자에게만 예약되어야 합니다.

### POS 액세스를 포함한 역할 할당

직원 계정 자체에는 권한이 없습니다 — 역할이 구체적인 기능을 부여합니다. 계정을 생성한 후 직원의 기록을 열고 **역할** 섹션으로 이동하여 POS 액세스를 포함한 역할을 할당합니다.

역할이 어떻게 작동하는지 및 포함해야 하는 권한에 대한 전체 설명은 [직원 역할](staff-roles)을 참조하세요.

heading

생체 인식 로그인

paragraph

생체 인식 로그인은 계산원이 비밀번호를 입력하는 대신 지문 센서를 터치하거나 얼굴 카메라를 바라보거나 하드웨어 키를 탭할 수 있도록 합니다. 바쁜 계산대에서는 근무 시간당 몇 초를 절약하고, 피크 시간에 실수를 피할 수 있습니다.

Spwig은 생체 인식 로그인을 위해 **WebAuthn** 브라우저 표준을 사용합니다.

"WebAuthn credential"은 장치에 바인딩된 키 쌍입니다: 개인 키는 장치의 보안 하드웨어에 저장되며 외부로 나가지 않습니다.

POS 애플리케이션은 브라우저를 통해 해당 하드웨어와 통신합니다.

### 생체 인증을 지원하는 장치 및 브라우저

WebAuthn은 호환 가능한 하드웨어가 있는 장치에서 Chrome, Edge, Firefox, Safari 등 모든 현대 브라우저에서 지원됩니다. 잘 작동하는 일반적인 설정:

| 장치 | 인증자 |
|--------|---------------|
| iPad (Touch ID) | Safari 또는 Chrome을 통한 지문 |
| Android 태블릿 | Chrome을 통한 지문 또는 얼굴 |
| Windows 태블릿 또는 PC | Windows Hello (지문, 얼굴 또는 PIN) |
| 모든 장치 + 보안 키 | USB, NFC 또는 블루투스 FIDO2 키 (예: YubiKey) |
| iPhone (Face ID) | Safari를 통한 얼굴 |

POS 애플리케이션은 브라우저가 해당 장치에서 현재 사용자의 인증 자격 증명이 등록되었음을 확인한 경우에만 생체 인증 로그인 옵션을 표시합니다.

### 등록 과정

등록은 관리자 대신 POS 단말기에서 이루어집니다. 직원은 먼저 일반 비밀번호 로그인을 완료한 후 POS 애플리케이션 내에서 생체 인증 로그인을 설정하려 선택해야 합니다. 브라우저는 장치의 생체 센서를 사용하여 그들의 신원을 확인하도록 요청하거나 iOS/macOS/Windows에서 계정에 저장된 패스키를 사용하도록 요청합니다. 확인되면 자격 증명이 저장되고 해당 장치에서 향후 근무 시 생체 인증 로그인이 가능해집니다.

한 직원은 여러 장치에 등록할 수 있습니다 - 예를 들어 개인 태블릿과 공유 계산대 - 그리고 각 장치는 자체의 자격 증명을 유지합니다.

> **참고:** 등록 요청 메시지의 정확한 문구("생체 인증 등록", "지문 로그인 설정" 등)는 POS 애플리케이션에서 제공하며 브라우저 및 장치에 따라 달라질 수 있습니다.

### 생체 인증으로 로그인

등록 후 로그인 화면에 계산원의 이름 옆에 생체 인증 로그인 버튼(지문 아이콘 또는 유사한 아이콘)이 표시됩니다. 계산원은 다음과 같이 수행합니다:

1.

터미널의 로그인 화면에서 이름을 탭합니다.
2.

**지문으로 로그인** (또는 동등한 옵션)을 탭합니다.
3.

센서를 만든다거나 카메라를 바라보면 됩니다.
4.

터미널이 즉시 잠금 해제됩니다.

생체 인증이 실패할 경우(지문 인식 실패, 얼굴이 가려짐), 현금원은 비밀번호를 입력하는 방식으로 전환합니다.

### 자격 증명 취소

기기 유실, 도난, 직원이 퇴직한 경우, 해당 직원의 생체 인증 자격 증명을 즉시 제거해야 합니다.

1. **직원 및 계정 > 직원 목록**으로 이동합니다.
2. 직원의 기록을 엽니다.
3. **POS 설정** 섹션으로 스크롤합니다.
4. **생체 인증 잠금 해제** 행에서 **모두 제거**를 클릭합니다.
5. 작업을 확인합니다.

이 작업은 해당 직원이 모든 기기에서 등록한 WebAuthn 자격 증명을 제거합니다. 다음 번에 그들이 어떤 터미널에서 생체 인증 로그인을 시도할 때는 대신 비밀번호로 로그인해야 합니다.

> **중요:** 여기서 자격 증명을 제거해도 직원이 비밀번호로 로그인하는 것을 방지하지 않습니다. 완전히 접근 권한을 취소하려면 직원 계정을 비활성화하거나 터미널에 할당된 직원 목록에서 제거해야 합니다.

## 보안 참고 사항

- **자격 증명은 하드웨어에 결합되어 있습니다.** 개인 키는 장치의 보안 요소에서 벗어나지 않습니다.

태블릿이 도난당하더라도 공격자는 생체 인증 키를 추출할 수 없습니다. 브라우저가 키를 해제하기 전에 먼저 장치 자체의 잠금 화면을 우회해야 하기 때문입니다.
- **장치를 잃어도 비밀번호가 유출되지 않습니다.** WebAuthn은 해당 장치의 비밀번호를 대체하며, 직원의 비밀번호는 별도로 영향을 받지 않습니다.
- **직원이 퇴사할 때 즉시 취소하세요.** 직원을 해고할 때 동일한 세션에서 생체 인증 자격 증명을 제거하고 직원 계정을 비활성화하세요.
- **생체 인증 정보 자체는 전송되지 않습니다.** 지문 또는 얼굴 스캔은 장치 하드웨어에 의해 완전히 처리됩니다.

Spwig은 서명된 도전 응답만 받고, 생체 정보는 받지 않습니다.

## 문제 해결

### "지문으로 로그인" 버튼이 표시되지 않음

생체 인증 옵션은 다음 경우에만 나타납니다:
- 직원이 이 특정 장치에 자격 증명을 등록했을 때.
- 브라우저가 WebAuthn을 지원할 때 (모든 현대 브라우저가 지원합니다 — 오래된 버전을 사용 중이라면 업데이트하세요).

버튼이 표시되지 않는 경우, 직원이 이 장치에 등록하지 않았을 수 있습니다. 직원은 비밀번호로 로그인한 후 POS 애플리케이션을 통해 생체 인증 로그인을 설정해야 합니다.

### 등록 실패

일반적인 원인:
- **브라우저 권한 거부.** 브라우저가 인증기의 접근을 요청했고 직원이 거부했습니다. 다시 시도하고 권한 요청 시 **허용**을 누르도록 해야 합니다.
- **호환 가능한 인증기가 없음.** 장치에 지문 센서, 얼굴 카메라 또는 보안 키가 부착되어 있지 않습니다. 장치 하드웨어를 확인하세요.
- **중복된 자격 증명.** 직원이 이미 이 장치에 등록했을 수 있습니다. 재등록 시 기존 자격 증명은 중복을 피하기 위해 제외됩니다.

### 한 장치에서는 생체 인증이 작동하지만 다른 장치에서는 작동하지 않음

각 장치는 자체의 자격 증명을 저장합니다. iPad에서 등록하면 두 번째 iPad에서 자동으로 작동하지 않습니다. 직원은 사용할 모든 장치에서 별도로 등록 절차를 완료해야 합니다.

### 장치 간 패스키(Passkey)


일부 운영체제(iOS 16+, macOS Ventura+, Microsoft 계정이 있는 Windows 11)는 iCloud Keychain 또는 Windows Hello를 통해 기기 간 패스키를 동기화할 수 있습니다.

직원이 동기화된 패스키를 사용하여 등록한 경우, 여러 기기에서 자동으로 작동할 수 있습니다.

동작은 운영체제와 브라우저에 따라 달라지며, Spwig에 따라 달라지지 않습니다.

## 팁

- 직원이 근무 시간에 도착하기 전에 공유 계산대에서 생체 인식 로그인을 설정하세요. 고객이 대기하지 않는 상태에서 2분간의 등록 과정이 훨씬 매끄럽습니다.
- 계산원에게 제한된 POS 권한을 가진 역할을 할당하고, 감독자에게 별도의 관리자 역할을 할당하세요. 그들의 계정은 매장 소유자 계정과 구분해 두세요.
- 직원이 기기를 변경할 때(새로운 태블릿, 새로운 전화기), 먼저 새 기기에서 등록을 수행한 후 기기 사용이 중단된 경우 관리자에서 이전 자격 증명을 취소하세요.
- 직원 이동이 빈번한 매장의 경우, 각 터미널에서 정기적으로 **할당된 직원** 목록을 확인하고 해당 위치에서 더 이상 근무하지 않는 직원을 제거하세요.
- 하드웨어 보안 키(YubiKey 또는 유사한 키)를 사용하는 경우, 관리자 설정을 변경하지 않고도 하나의 키를 여러 터미널에 등록할 수 있습니다. 단순히 키를 연결하고 각 터미널에서 등록 절차를 완료하면 됩니다.
