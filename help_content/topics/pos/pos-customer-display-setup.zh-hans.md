客户显示屏是在销售过程中面向客户的第二个屏幕。在您处理交易时，客户可以看到每个被扫描的商品、累计金额、价格和税费明细，以及在没有进行销售时，显示您促销内容的轮播幻灯片。

本指南涵盖设置客户显示屏的硬件和配对方面：在终端上启用该功能、将单独的设备配对为显示屏，并处理常见的设置场景。有关空闲期间显示的促销幻灯片的信息，请参阅[客户显示屏促销幻灯片](customer-display-promo-slides)。

## 客户显示屏显示的内容

当销售进行时，客户显示屏显示以下内容：

- 每个添加或移除的商品，包括数量和价格
- 购物车小计、已应用的折扣和税费明细
- 应付总额，以及在付款过程中显示的支付金额和找零

当终端处于空闲状态（无活动交易）时，显示屏会切换到促销幻灯片。您可以单独控制该幻灯片的内容 — 请参阅[客户显示屏促销幻灯片](customer-display-promo-slides)。

## 常见的硬件设置

有三种实际方法可以设置面向客户的屏幕：

- **支架上的独立平板电脑或显示器** — 用于柜台销售的最常见设置。

一个小型平板电脑放在支架上面向客户，而您的主终端则面向您自己。

你使用一个短暂有效的代码（如下所述）将两个设备配对。
- **扩展桌面模式下的第二个显示器** — 如果你的主终端是笔记本电脑或台式机，请连接第二个显示器，将桌面扩展到该显示器上，然后将显示窗口拖到第二个显示器并最大化。

两个屏幕运行在同一个设备上；不需要配对代码。
- **专用立柱显示器** — 一个安装在立柱上的硬件显示器单元，通常通过USB连接到收银终端，或放置在收银台上。

在立柱设备的浏览器中打开 `/pos/display/`，并使用主终端上的代码进行配对。

## 在终端上启用客户显示器

客户显示器功能通过终端的硬件配置在每个终端上启用。

1. 导航到 **POS > 终端**，并打开你要配置的终端（或点击 **+ 添加POS终端** 以添加新的终端）。
2. 点击 **设备** 选项卡。
3. 滚动到 **硬件配置** 卡。你将看到一个JSON字段。
4. 将 `"customer_display": true` 添加到JSON对象中。例如：

```json
{
  "customer_display": true
}
```

如果该字段已经包含其他硬件设置（如打印机或扫描仪配置），请将 `"customer_display": true` 与它们一起添加：

```json
{
  "printer": {"type": "network", "url": "http://192.168.1.100:9100"},
  "scanner": "keyboard_wedge",
  "customer_display": true
}
```

5. 点击 **保存**。

![启用 customer_display 的终端硬件配置](/static/core/admin/img/help/pos-customer-display-setup/terminal-capabilities-toggle.webp)

启用后，该终端上的POS应用在会话开始时将在第二个浏览器窗口或标签页中打开客户显示器视图。

## 将独立设备配对为显示器

如果你使用独立的物理设备作为客户屏幕（平板电脑、手机或第二台计算机），你将使用一个短暂有效的6位代码将其与终端配对。

### 第1步：在主终端上生成配对代码

# 第3部分：在客户设备上打开显示URL

在客户设备上，打开网络浏览器并前往：

```
https://your-store-domain.com/pos/display/
```

无需登录——显示页面是公开可访问的。这是有意为之：显示设备不需要员工凭据，配对代码提供了显示与正确终端之间的链接。

![客户显示空闲视图](/static/core/admin/img/help/pos-customer-display-setup/customer-display-view.webp)

## 第3步：输入配对代码

在客户设备上，输入主终端上的6位代码。显示将配对到该终端，并开始显示实时购物车数据。

一旦代码被使用，它将立即失效且无法再次使用。

## 重新生成配对代码

如果配对代码在您输入之前过期，或者您需要重新配对显示设备（例如，如果显示设备被更换或重置），请从主终端上的POS应用中生成新代码。

生成新代码会自动取消该终端的任何现有未使用代码。新代码在5分钟内有效。

您无需在管理后台中进行任何更改即可重新生成代码——这完全在POS应用内完成。

## 在单个设备上设置多显示器

如果您的主终端是笔记本电脑或带有两个显示器的台式机：

1. 

  连接第二个显示器，并在操作系统显示设置中将其设置为**扩展桌面**模式（而不是镜像）。
2. 

  按照常规方式在主屏幕上打开POS应用。
3. 

  POS应用将在第二个窗口中打开客户显示。

  将该窗口拖动到第二个显示器上。
4. 

  保留所有Markdown格式、图片路径、代码块和技术术语。

在第二台显示器上最大化或全屏显示。

不需要配对码，因为两个窗口都在同一台设备上运行，并且可以直接通信。

## 空闲行为

当没有正在进行的销售时，客户显示屏会显示促销图片的轮播幻灯片。您可以在 **POS > 促销幻灯片** 下单独创建和管理这些幻灯片。

有关创建幻灯片、针对特定商店进行定位以及管理季节性内容的详细信息，请参阅 [客户显示屏促销幻灯片](customer-display-promo-slides)。

如果没有配置幻灯片，显示屏将显示一个简单的欢迎屏幕，并显示您的商店名称。

## 故障排除

**显示屏变黑或停止更新**

显示屏与主终端实时通信。如果连接中断，显示屏可能会变黑或显示过时的数据。在客户设备上刷新浏览器。如果这没有帮助，请生成新的配对码并重新配对。

**显示屏显示了错误终端的购物车**

每个显示屏都与特定的终端配对。如果您有多个终端，请确保在正确的终端上生成配对码，并在显示屏上输入。要修复不匹配，请在正确的终端上生成新码，并重新配对显示屏设备。

**配对码在输入之前已过期**

配对码有效期为5分钟。从POS应用中生成新的配对码，并尽快在显示屏设备上输入。配对过程中请将两台设备靠近。

**已输入配对码但显示屏未连接**

检查客户设备是否可以访问您的商店域名（需要网络访问权限）。同时确认终端的硬件配置中已设置 `"customer_display": true`，并且已保存终端。

**显示屏URL返回错误**

确保您访问的是商店域名下的 `/pos/display/`，而不是管理员URL。

显示视图不需要登录 —— 如果您被要求登录，请再次检查 URL 是否正确。

## 小贴士

- **保持配对会话简短** —— 在生成配对代码之前，确保客户设备已准备好，并且浏览器已打开到 `/pos/display/`。您有 5 分钟的时间，但若能在 1 分钟内完成配对，可避免超时。
- **在开启前进行测试** —— 在首次真实交易前，连接显示设备完成一次测试销售，以确保客户能看到正确的商品和总计金额。
- **将显示 URL 添加到收藏夹** —— 设置客户设备的浏览器在启动时自动打开 `/pos/display/`，以确保始终处于就绪状态。
- **使用扩展桌面以简化操作** —— 如果您的终端有备用的 HDMI 接口和显示器可用，扩展桌面的方法无需持续配对，且永远不会过期。
- **在开启前添加促销幻灯片** —— 仅显示空白欢迎屏幕的空闲显示是一种浪费。设置至少几张促销幻灯片，即使没有正在进行的交易，显示也能派上用场。请参阅 [客户显示促销幻灯片](customer-display-promo-slides)。
- **确保显示设备的安全性** —— 显示 URL 按设计是公开可访问的，但只有在与活动终端配对时才会显示实时购物车数据。尽管如此，仍建议在客户设备上使用 kiosk 浏览器模式，以防止客户浏览其他页面。
