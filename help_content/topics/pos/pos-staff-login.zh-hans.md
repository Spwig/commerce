---
title: POS员工登录与生物识别签到
---

每个在POS收银机上服务顾客的人都需要一个具有适当权限的员工账户。本主题将解释如何创建该账户，将员工分配到终端，并设置生物识别签到，以便他们可以通过指纹、面部扫描或硬件密钥解锁收银机，而无需每次输入密码。

如需了解PIN码、折扣限制和终端锁定设置，请参阅[POS员工折扣与终端安全](pos-staff-discounts)。

## 员工使用POS终端所需内容

要登录POS终端，一个人需要：

1. 一个**员工账户** — 一个启用了**员工状态**标志的Spwig用户。
2. 一个**包含POS访问权限的角色** — 角色控制员工在管理后台中可以执行的操作。需要具有POS权限的角色才能访问收银机。
3. **分配到终端** — 终端必须将他们列为已分配的员工，或者他们必须在商店位置级别上被分配。

## 创建有资格使用POS的员工账户

导航到 **员工与账户 > 员工**（或前往 `/admin/accounts/staffmember/`）。

1. 点击 **+ 添加员工**。
2. 填写员工的 **名字**、**姓氏** 和 **电子邮件地址**。
3. 设置一个临时密码，并要求员工在首次登录时更改它。
4. 确保 **员工状态** 已勾选 — 这是允许他们登录管理后台和POS应用程序的设置。
5. 点击 **保存**。

> **注意：** 不要为普通收银员或主管勾选 **超级用户状态**。超级用户状态会绕过所有权限检查，应仅保留给商店所有者。

### 分配包含POS访问权限的角色

员工账户本身没有权限 — 角色授予特定功能。创建账户后，打开员工记录并进入 **角色** 部分。分配一个包含POS访问权限的角色。

如需了解角色的工作原理以及应包含哪些权限，请参阅[员工角色](staff-roles)。

heading

生物识别登录

paragraph

生物识别登录允许收银员通过触摸指纹传感器、注视面部摄像头或点击硬件密钥来登录，而不是输入密码。在繁忙的收银台，这可以为每个班次节省几秒钟，并避免高峰时段的错误。

Spwig 使用 **WebAuthn** 浏览器标准进行生物识别登录。

"WebAuthn 凭证" 是一个与设备绑定的密钥对：私钥存储在设备的安全硬件中，且不会离开设备。

POS 应用程序通过浏览器与该硬件进行通信。

### 支持生物识别登录的设备和浏览器

WebAuthn 受所有现代浏览器 —— Chrome、Edge、Firefox 和 Safari —— 支持，前提是设备具有兼容的硬件。以下是一些常见的有效配置：

| 设备 | 认证器 |
|--------|---------------|
| iPad (Touch ID) | 通过 Safari 或 Chrome 进行指纹识别 |
| Android 平板 | 通过 Chrome 进行指纹或面部识别 |
| Windows 平板或 PC | Windows Hello（指纹、面部或 PIN） |
| 任何设备 + 安全密钥 | USB、NFC 或蓝牙 FIDO2 密钥（例如 YubiKey） |
| iPhone (Face ID) | 通过 Safari 进行面部识别 |

只有当浏览器确认该设备上已为当前用户注册了凭证时，POS 应用程序才会显示生物识别登录选项。

### 注册流程

注册是在 POS 终端进行的，而不是在管理后台。员工必须首先完成正常的密码登录，然后在 POS 应用程序中选择设置生物识别登录。浏览器随后会提示他们使用设备的生物识别传感器（或保存在 iOS/macOS/Windows 账户中的密码）来验证身份。确认后，凭证将被存储，并且该设备上将可用生物识别登录功能。

一名员工可以在多个设备上注册 —— 例如，个人平板和共享收银机 —— 每个设备都会存储自己的凭证。

> **注意：** 注册提示的确切措辞（如 "注册生物识别"、"设置指纹登录" 等）来自 POS 应用程序，可能因浏览器和设备而异。

### 使用生物识别登录

注册后，登录屏幕上将显示一个生物识别登录按钮（指纹图标或其他类似图标）。收银员：

1.

在终端的登录屏幕上轻点他们的姓名。
2.

轻点 **使用指纹登录**（或等效选项）。
3.

触摸传感器或注视摄像头。
4.

终端会立即解锁。

如果生物识别验证失败（指纹未被识别、面部被遮挡），收银员将回退到输入密码。

### 撤销凭证

如果设备丢失、被盗或员工离职，您应立即移除他们的生物识别凭证。

1. 导航至 **员工与账户 > 员工**。
2. 打开员工的记录。
3. 滚动到 **POS 设置** 部分。
4. 在 **生物识别解锁** 行中，点击 **全部移除**。
5. 确认操作。

这将移除该员工在所有设备上注册的所有 WebAuthn 凭证。下次他们尝试在任何终端上使用生物识别登录时，将需要使用密码登录。

> **重要提示：** 在此处移除凭证不会阻止员工使用密码登录。要完全撤销访问权限，请同时停用他们的员工账户或从终端分配的员工列表中移除他们。

## 安全提示

- **凭证与硬件绑定。** 私钥永远不会离开设备的安全元件。

如果平板电脑被盗，攻击者无法提取生物识别密钥——他们仍需要绕过设备本身的锁屏，浏览器才会释放密钥。
- **丢失设备不会泄露密码。** WebAuthn 替代了该设备的密码；员工的密码是独立的，不会受到影响。
- **员工离职时应立即撤销。** 在为员工办理离职手续时，应在同一会话中移除生物识别凭证并停用员工账户。
- **生物识别信息本身不会被传输。** 指纹或面部扫描完全由设备硬件处理。

Spwig 仅接收已签名的挑战响应，而不是任何生物识别数据。

## 故障排除

### "使用指纹登录"按钮未显示

生物识别选项仅在以下情况下出现：
- 员工已在该特定设备上注册了凭证。
- 浏览器支持 WebAuthn（所有现代浏览器都支持——如果使用的是旧版本，请进行更新）。

如果按钮未显示，说明员工尚未在该设备上注册。他们应使用密码登录，并通过 POS 应用程序设置生物识别登录。

### 注册失败

常见原因：
- **浏览器权限被拒绝。** 浏览器请求访问认证器的权限，但员工拒绝了。员工需要再次尝试，并在提示时点击 **允许**。
- **未找到兼容的认证器。** 设备上没有指纹传感器、面部摄像头或安全密钥。请检查设备硬件。
- **重复的凭证。** 员工可能已在该设备上注册过。在重新注册时，现有凭证会被排除，以避免重复。

### 生物识别在一个设备上有效，但在另一个设备上无效

每个设备存储自己的凭证。在 iPad 上注册不会自动在第二个 iPad 上生效。员工必须在他们将使用的每个设备上分别完成注册。

### 跨设备的密钥


# 操作系统支持

某些操作系统（iOS 16+、macOS Ventura+、使用 Microsoft 账户的 Windows 11）可以通过 iCloud Keychain 或 Windows Hello 在设备之间同步 passkey。

如果员工使用的是同步的 passkey 注册，它可能会在多个设备上自动生效。

行为取决于操作系统和浏览器，而不是 Spwig。

## 小贴士

- 在员工到岗前，在共享收银机上设置生物识别登录 —— 在没有顾客等待的情况下，两分钟的注册过程会更加顺畅。
- 为收银员分配具有有限 POS 权限的角色，并为主管分配单独的管理员角色。确保他们的账户与商店所有者账户分开。
- 当员工更换设备（新平板、新手机）时，先让他们在新设备上注册，如果旧设备不再使用，请从管理员界面撤销旧凭证。
- 对于员工流动率较高的门店，请定期检查每个终端的 **Assigned staff** 列表，并移除不再在该地点工作的员工。
- 如果您使用硬件安全密钥（如 YubiKey 或类似设备），一个密钥可以在多个终端上注册，无需对管理员进行任何更改 —— 只需将密钥插入终端并完成每个终端的注册即可。
