---
title: Акции на доставку
---

Правила доставки применяют условные корректировки стоимости методов доставки на основе содержимого корзины, атрибутов клиента и зон доставки — автоматически предлагают бесплатную доставку при заказе свыше 50 долларов, добавляют надбавки за отдаленные районы или предоставляют скидки на доставку для клиентов VIP-статуса. Правила используют выполнение на основе приоритета (высший приоритет сначала) с необязательными флагами остановки для предотвращения дальнейшей обработки. Каждое правило оценивает несколько условий (сумма корзины, вес, зоны, товары, группы клиентов) и выполняет одну из 6 типов корректировки, когда все условия совпадают.

Используйте акции на доставку, когда вам нужны динамические стоимости доставки, которые меняются в зависимости от контекста заказа, а не только статические ставки из методов доставки.

## Типы акций на доставку

Правила доставки применяют 6 типов корректировки стоимости:

### Процентная скидка

**Что это делает**: Уменьшает стоимость доставки на определенный процент (например, 25% скидка).

**Формула**: `новая_стоимость = базовая_стоимость × (1 - процент/100)`

**Пример**:
```
Базовая стоимость: $20
Скидка: 25%
Результат: $15
```

**Сценарии использования**:
- Скидка для клиентов VIP-статуса (20% скидка на все доставки)
- Сезонные акции (15% скидка на доставку в декабре)
- Скидка на大宗 заказы (10% скидка на доставку при заказе 5 и более товаров)

---

### Фиксированная скидка

**Что это делает**: Вычитает фиксированную сумму из стоимости доставки.

**Формула**: `новая_стоимость = базовая_стоимость - сумма` (минимум $0)

**Пример**:
```
Базовая стоимость: $15
Скидка: $5
Результат: $10
```

**Сценарии использования**:
- Бонус для новых клиентов ($5 скидка на доставку первого заказа)
- Вознаграждение за регистрацию в рассылке ($3 скидка на доставку)
- Преимущество программы лояльности ($10 скидка на доставку в месяц)

---

### Замена стоимости

**Что это делает**: Заменяет стоимость доставки на конкретную сумму.

**Формула**: `новая_стоимость = фиксированная_сумма`

**Пример**:
```
Базовая стоимость: $25
Установить на: $9.99
Результат: $9.99
```

**Сценарии использования**:
- Акция скидки (плоская стоимость доставки $5 для всех заказов сегодня)
- Специфичная доставка по категориям (книги всегда доставляются за $3.99)
- Акции по времени (ограничение стоимости доставки до $9.99 на этой неделе)

---

### Бесплатная доставка

**Что это делает**: Устанавливает стоимость доставки в $0.

**Формула**: `новая_стоимость = $0`

**Пример**:
```
Базовая стоимость: $18
Правило применяется
Результат: $0
```

**Сценарии использования**:
- Бесплатная доставка при заказе свыше $50
- Бесплатная доставка для определенных товаров (рекламных товаров)
- Бесплатная доставка для клиентов VIP-статуса
- Бесплатная доставка на заказы с 3 и более товарами

---

### Надбавка (фиксированная)

**Что это делает**: Добавляет фиксированную сумму к стоимости доставки.

**Формула**: `новая_стоимость = базовая_стоимость + сумма`

**Пример**:
```
Базовая стоимость: $12
Надбавка: $5
Результат: $17
```

**Сценарии использования**:
- Плата за доставку в отдаленные районы
- Плата за обработку крупногабаритных товаров
- Надбавка за доставку в субботу
- Плата за упаковку хрупких товаров

---

### Надбавка (процентная)

**Что это делает**: Увеличивает стоимость доставки на определенный процент.

**Формула**: `новая_стоимость = базовая_стоимость × (1 + процент/100)`

**Пример**:
```
Базовая стоимость: $20
Надбавка: 15%
Результат: $23
```

**Сценарии использования**:
- Надбавка в пиковые сезоны (20% в праздничные дни)
- Премиум за экспресс-доставку (50% надбавка)
- Надбавка за топливо (переменная на основе текущих ставок)

## Условия акции

Акции оценивают **все условия должны быть выполнены**, чтобы правило применялось:

### Временная действительность

- **Дата начала**: Правило активно только после этой даты
- **Дата окончания**: Правило активно только до этой даты
- **Сценарии использования**: Сезонные акции, ограниченные предложения

**Пример**: Бесплатная доставка только в выходные Black Friday
```
Дата начала: 2026-11-27 00:00
Дата окончания: 2026-11-30 23:59
```

---

### Диапазон суммы корзины

- **Минимальная сумма корзины**: Общая сумма корзины должна быть ≥ сумма
- **Максимальная сумма корзины**: Общая сумма корзины должна быть ≤ сумма
- **Сценарии использования**: Пороги бесплатной доставки, поэтапные скидки

**Пример**: Бесплатная доставка для заказов от $50 до $200
```
Минимум: $50
Максимум: $200
```

---

### Диапазон веса корзины

- **Минимальный вес**: Общий вес корзины должен быть ≥ сумма
- **Максимальный вес**: Общий вес корзины должен быть ≤ сумма
- **Сценарии использования**: Скидки на легкие посылки, надбавки за тяжелые товары

**Пример**: Надбавка в $5 для заказов свыше 20 кг
```
Минимальный вес: 20 кг
Максимальный вес: null (без ограничения)
```

---

### Диапазон количества товаров


- **Минимальное количество товаров**: В корзине должно быть ≥ количество товаров
- **Максимальное количество товаров**: В корзине должно быть ≤ количество товаров
- **Сценарий использования**: Скидки на大宗 заказы, сборы за одиночные товары

**Пример**: Бесплатная доставка при 5+ товарах
```
Min Items: 5
Max Items: null
```

---

### Зона доставки

- **Зоны**: Правило применяется только если адрес клиента совпадает с хотя бы одной из выбранных зон
- **Пустой выбор**: Правило применяется ко ВСЕМ зонам
- **Сценарий использования**: Дополнительные сборы или скидки, специфичные для зоны

**Пример**: Бесплатная доставка только для зоны Domestic
```
Zones: ["Domestic USA"]
```

---

### Способ доставки

- **Способы**: Правило применяется только к определенным способам доставки
- **Пустой выбор**: Правило применяется ко ВСЕМ способам
- **Сценарий использования**: Промоакции, специфичные для способа доставки

**Пример**: Скидка 25% на доставку Express
```
Methods: ["Express Delivery"]
```

---

### Требования к продуктам

**Требуется товар**: В корзине должно быть как минимум один из этих товаров

**Требуется категория**: В корзине должно быть как минимум один товар из этих категорий

**Сценарий использования**: Бесплатная доставка для конкретных товаров, промо-комплекты

**Пример**: Бесплатная доставка, если в корзине есть товар "Promotion Item A"
```
Requires Products: [Product ID 123]
```

---

### Исключения товаров

**Исключить товары**: Правило не применяется, если в корзине есть любой из этих товаров

**Исключить категории**: Правило не применяется, если в корзине есть товары из этих категорий

**Сценарий использования**: Исключить тяжелые/oversized товары из бесплатной доставки

**Пример**: Бесплатная доставка, кроме категории мебели
```
Excludes Categories: [Furniture]
```

---

### Группа клиентов

- **Группы клиентов**: Правило применяется только для клиентов, находящихся в выбранных группах (VIP, оптовая продажа и т.д.)
- **Пустой выбор**: Правило применяется ко ВСЕМ группам клиентов
- **Сценарий использования**: Преимущества для VIP, скидки для оптовых покупателей

**Пример**: Скидка 15% на доставку для клиентов VIP
```
Customer Groups: ["VIP"]
```

---

### Первый клиент

- **Первый клиент**: Переключатель для ограничения правила только для клиентов без предыдущих заказов
- **Сценарий использования**: Предложение для новых клиентов

**Пример**: Скидка $5 на доставку для первого заказа
```
First Time Customer: Yes
```

## Приоритет промоакции и выполнение

Промоакции выполняются в **порядке приоритета** (высшее число = более раннее выполнение):

### Механика приоритета

**Пример выполнения**:
```
Promotion A (Priority 100): Free shipping if cart > $50
Promotion B (Priority 50): 10% discount on all shipping
Promotion C (Priority 1): $2 surcharge for remote zones

Cart: $60, Remote zone
Base shipping cost: $15

Step 1: Promotion A evaluates (Priority 100)
  Cart > $50? YES
  Apply: Set cost to $0
  Cost now: $0

Step 2: Promotion B evaluates (Priority 50)
  Apply 10% discount to $0
  Cost now: $0 (still free)

Step 3: Promotion C evaluates (Priority 1)
  Add $2 surcharge to $0
  Cost now: $2

Final cost: $2
```

**Флаг остановки дальнейших промоакций**:

Если у Промоакции A есть `stop_further_promotions = True`:
```
Promotion A (Priority 100, stop_further_promotions=True): Free shipping if cart > $50
Promotion B (Priority 50): 10% discount
Promotion C (Priority 1): $2 surcharge

Cart: $60
Base: $15

Step 1: Promotion A applies, sets cost to $0
        stop_further_promotions = True → STOP

Final cost: $0 (Rules B and C never execute)
```

## Создание промоакций доставки

**Пошаговая рабочая процедура**:

1. **Перейдите к правилам**
   - Настройки > Доставка > Промоакции доставки
   - Нажмите "Добавить промоакцию доставки"

2. **Базовая настройка**
   - **Название**: Внутренний идентификатор (например, "Бесплатная доставка при заказе более $50")
   - **Описание**: Необязательные примечания (не отображаются клиентам)
   - **Активный**: Переключатель для включения/отключения
   - **Приоритет**: Установите порядок выполнения (100 для высокого приоритета, 1 для низкого)

3. **Выберите тип промоакции**
   - Выберите тип корректировки (скидка %, скидка фиксированная, установить стоимость, бесплатная, дополнительная плата %, дополнительная плата фиксированная)
   - Введите сумму или процент

4. **Установить флаг остановки** (Необязательно)
   - Отметьте "Остановить дальнейшие акции", если это правило должно предотвращать выполнение акций более низкого приоритета
   - Используйте для окончательных/абсолютных правил (например, бесплатная доставка не должна иметь дополнительных сборов после)

5. **Определить условия** (Необязательно - оставьте пустым для "всегда применять")
   - Действительность по времени: даты начала/окончания
   - Значение корзины: минимум/максимум
   - Вес корзины: минимум/максимум
   - Количество товаров: минимум/максимум
   - Зоны: выберите применимые зоны
   - Методы: выберите применимые методы
   - Товары: обязательные или исключаемые
   - Покупатель: группы или только для новых клиентов

6. **Сохранить правило**
   - Нажмите Сохранить
   - Правило становится активным сразу (если переключатель активности установлен в Да)

## Стратегии комбинирования акций

### Стратегия 1: Накопление скидок

**Разрешить накопление нескольких скидок**:
```
Акция A (Приоритет 100): 10% скидка для VIP → stop_further_promotions=Нет
Акция B (Приоритет 50): 15% скидка на заказы >$100 → stop_further_promotions=Нет

VIP-клиент с заказом $120:
Базовая стоимость: $15
После акции A: $13.50 (10% скидка)
После акции B: $11.48 (15% скидка с $13.50)
```

### Стратегия 2: Исключительные правила

**Применяется только одно правило** (самое высокое приоритет):
```
Акция A (Приоритет 100): Бесплатная доставка >$50 → stop_further_promotions=Да
Акция B (Приоритет 50): 20% скидка на все доставки → stop_further_promotions=Да

Корзина > $50:
Применяется акция A → Бесплатная доставка → ОСТАНОВИТЬ
Акция B никогда не применяется
```

### Стратегия 3: Условные дополнительные сборы


**Сначала скидки, потом надбавки**:
```
Promotion A (Priority 100): Free shipping >$75
Promotion B (Priority 75): 15% VIP discount
Promotion C (Priority 50): 10% general discount
Promotion D (Priority 25): $5 remote area surcharge
Promotion E (Priority 1): 10% fuel surcharge

Order: $80, Remote zone, VIP customer
Base: $20
A: $80 > $75 → Free ($0)
B: VIP → 15% off $0 = $0
C: 10% off $0 = $0
D: Remote +$5 = $5
E: Fuel +10% of $5 = $5.50

Final: $5.50 (not free due to surcharges)
```

**Чтобы избежать этого, используйте stop_further_promotions=Yes**:
```
Promotion A (Priority 100, stop=Yes): Free shipping >$75

Same order:
A: $80 > $75 → Free ($0) → STOP
Final: $0 (truly free)
```

## Testing Shipping Promotions

**Before going live**:

1. **Create Test Carts**
   - Cart A: $25 (below threshold)
   - Cart B: $55 (above threshold)
   - Cart C: $200 + Remote zone
   - Cart D: VIP customer

2. **Test Each Rule**
   - Proceed to checkout
   - Verify correct shipping cost displayed
   - Check rule execution order

3. **Test Priority Resolution**
   - Multiple matching rules
   - Verify highest priority executes first
   - Check stop_further_promotions behavior

4. **Test Edge Cases**
   - Cart value exactly at threshold
   - Multiple conditions matching
   - Conflicting rules

## Troubleshooting

**Issue 1: Promotion not applying**

**Causes**:
- Rule is inactive
- One or more conditions not met
- Higher priority rule set stop_further_promotions=Yes
- Time validity outside current date

**Solution**: Review all conditions, check priority, verify active status.

---

**Issue 2: Unexpected discount amount**

**Causes**:
- Multiple promotions stacking
- Percentage applied to already-discounted cost
- Rule priority incorrect

**Solution**: Check priority order, review stop_further_promotions flags, trace execution manually.

---

**Issue 3: Free shipping not working**

**Causes**:
- Lower priority surcharge rule adding cost after free shipping promotion
- Cart doesn't meet min value threshold
- Excluded products in cart

**Solution**: Use stop_further_promotions=Yes on free shipping promotion, verify conditions, check exclusions.

## Tips

- **Use high priority for free shipping** - Priority 100 ensures it executes before other adjustments
- **Set stop_further_promotions for absolute rules** - Free shipping should stop further processing
- **Test rule combinations** - Multiple promotions can interact unexpectedly
- **Use descriptive names** - "VIP 20% Discount (Priority 75)" better than "Promotion 3"
- **Document complex logic** - Add notes in description field
- **Start with simple promotions** - Add complexity gradually
- **Monitor rule performance** - Check if rules are being used or causing confusion
- **Avoid excessive promotions** - Too many promotions slow checkout, use 5-10 max
- **Use zones for geography** - Better than multiple similar rules per country
- **Combine with methods** - Rules + Methods work together for sophisticated pricing
