Spwig POS 시스템은 현대적인 판매점 단말기를 사용하여 가게를 완전한 유통 솔루션으로 변환합니다. 이 시스템은 커뮤니티, 프로, 엔터프라이즈 모든 에디션에 포함되어 있으며, 추가 비용 없이 무제한의 위치에 무제한의 단말기를 사용할 수 있습니다. 각 단말기는 오프라인에서 작동하고 자동으로 동기화되며 재고, 고객 데이터 및 결제 처리와 완벽하게 통합된 프로그레시브 웹 앱(PWA)입니다. 관리 대시보드에서 모든 것을 관리할 수 있습니다 - 단말기 설정, 시프트 정산, 영수증 커스터마이징, 하드웨어 통합.

물리적 유통 위치, 팝업 스토어, 전시회 또는 온라인보다 대면 구매가 이루어지는 모든 환경에서 POS 시스템을 사용할 수 있습니다.

![POS 대시보드](/static/core/admin/img/help/pos-system-overview/dashboard.webp)

## Spwig POS란 무엇인가요?

Spwig POS는 온라인과 물리적 위치 모두에서 판매하는 상인을 위한 완전히 통합된 판매점 시스템입니다. 제3자 POS 시스템과 달리 복잡한 통합이 필요하지 않으며, Spwig POS는 플랫폼에 직접 구축되어 모든 판매 채널에서 완벽한 데이터 동기화를 보장합니다.

**주요 특징**:
- **무제한 단말기** - 추가 비용 없이 필요한 만큼 단말기를 배포할 수 있음
- **오프라인 우선 아키텍처** - 인터넷 연결이 끊어졌을 때도 판매 처리를 계속할 수 있음
- **프로그레시브 웹 앱** - 앱 스토어 설치 없이 모든 기기(태블릿, 컴퓨터, 전용 단말기)에서 브라우저를 통해 접근 가능
- **실시간 재고 동기화** - 재고 예약(15분 TTL)은 채널 간 과다 판매를 방지함
- **분할 결제 지원** - 거래당 여러 결제 방식(현금 + 카드 + 기프트 카드)을 수락 가능
- **하드웨어 통합** - ESC/POS 열 프린터, 바코드 스캐너, 현금 캐비닛, 고객 디스플레이
- **시프트 관리** - 개시/종료 계수와 차이 추적을 통한 현금 정산
- **다중 위치 지원** - 프랜차이즈 및 지역 관리를 위한 설정 상속이 가능한 가상 스토어 그룹

## 에디션

POS는 Spwig 1.5.8부터 모든 Spwig 에디션 — 커뮤니티, 프로, 엔터프라이즈 —에 포함되어 있습니다.

별도의 POS 라이선스도 없고, 활성화 단계도 없으며, 단말기당 요금도 없습니다.

**모든 에디션에 포함된 사항**:
- 무제한 단말기 등록
- 무제한 직원 할당
- 모든 POS 기능 (교대, 현금 관리, 영수증 커스터마이징, 고객 디스플레이)
- 결제 제공업체 통합 (Stripe Terminal 및 기타 지원되는 제공업체)
- 하드웨어 통합 지원

Spwig 호스팅된 가맹점 운영 또는 프로/엔터프라이즈 라이선스를 지불하는 사용자는 선택적 Spwig 호스팅된 서비스 (GeoIP, 지오코더, 푸시 알림)에 대한 더 높은 제한을 받고, 우선 지원을 받습니다. 하지만 POS 기능 세트 자체는 모든 에디션에서 동일합니다.

## 시스템 아키텍처

**프론트엔드** - React 18 프로그레시브 웹 앱:
- 오프라인 우선, Service Worker 캐싱 (인터넷 없이도 작동)
- 빠른 로딩을 위한 Vite 빌드 시스템
- CSS 모듈 + 디자인 토큰 (가맹점 테마와 일관됨)
- 로컬 데이터 지속성을 위한 IndexedDB
- 10개 지원 언어 (영어, 중국어 간체/번체, 프랑스어, 독일어, 스페인어, 포르투갈어, 일본어, 러시아어, 아랍어)

**백엔드** - 백엔드 통합:
- 13개 POS 모델 (POSTerminal, POSShift, CashMovement, ReceiptTemplate, PromoSlide 등)
- 단말기 운영을 위한 43개 이상의 REST API 엔드포인트
- TTL 관리와 함께하는 재고 예약 시스템
- 백그라운드 동기화를 위한 Celery 작업
- 결제 제공업체를 위한 암호화된 자격 증명 저장

**보안**:
- 단말기 쌍방향 연결을 위한 8자리 코드 (서버 측에서 생성, 사용 후 만료)
- 직원 할당은 어떤 사용자가 어떤 단말기를 접근할 수 있는지 제어
- 관리자 긴급 상황을 위한 원격 잠금/잠금 해제 기능
- 결제 제공업체 자격 증명 암호화
- 생체 인식 잠금 지원을 포함한 세션 기반 인증 (브라우저에 따라 다름)

## 시작하기 워크플로

첫 번째 POS 단말기를 배포하려면 다음 4단계를 따르세요.

POS를 시작하는 완전한 단계별 확인 목록(직원 설정, 결제 제공업체, 첫 번째 판매 실행 포함)은 [POS 시작하기](getting-started-with-pos)를 참조하세요.

**단계 1: 창고 생성**
- **카탈로그 > 창고**로 이동
- 판매점 위치를 나타내는 창고를 생성
- 주소 및 연락처 정보를 구성
- 이 창고는 POS 판매의 물리적 재고를 추적합니다

**단계 2: 단말기 등록**
- **POS > 단말기**로 이동
- **+ 단말기 추가**를 클릭
- 단말기 이름 설정(예: "메인 계산대", "체크아웃 1")
- 단계 2에서 선택한 창고를 할당
- 하드웨어 설정 구성(프린터, 스캐너, 현금 캐비닛)
- 저장하여 8자리 짝 맞춤 코드 생성

**단계 3: 직원 할당**
- 단말기 설정에서 **할당된 사용자**로 스크롤
- 이 단말기를 사용할 수 있는 직원을 선택
- 할당된 사용자만 단말기에 로그인할 수 있습니다
- 사용자는 직원 역할에 적절한 POS 권한을 가져야 합니다

**단계 4: 장치 짝 맞춤**
- 단말기 장치(태블릿/컴퓨터)에서 `/pos/` URL로 이동
- 단계 3에서 얻은 8자리 짝 맞춤 코드 입력
- 단말기에서 설정을 다운로드하고 초기 데이터를 동기화
- 할당된 직원 자격 증명으로 로그인
- 단말기는 판매를 위해 준비되었습니다

짝 맞춤 후 단말기는 5분마다 자동으로 동기화됩니다(설정 가능). 인터넷이 없을 때도 오프라인 모드로 계속 작동할 수 있으며, 연결이 복원되면 판매가 자동으로 동기화됩니다.

## 핵심 POS 기능

**판매 처리**:
- 이름, SKU 또는 바코드로 제품 검색
- 분할 결제(주문당 여러 결제 방식)
- 일시 저장된 장바구니(완료되지 않은 거래 저장)
- 사유 추적을 통한 환불 및 취소
- 할인 적용(쿠폰, 기프트 카드, 프로모션)
- 고객 조회 및 충성도 포인트 사용

**현금 관리**:
- 시프트 시작 시 초기 현금 수량으로 이동
- 예상 대비 실제 현금 조정을 통한 시프트 종료
- 현금 이동 (유동성 추가, 사유를 포함한 소액 현금 인출)
- 현금 판매 기반 자동 예상 현금 계산
- 차이 추적 및 보고

**하드웨어 통합**:
- ESC/POS 열식 영수증 프린터 (네트워크 또는 직렬)
- USB 바코드 스캐너
- 프린터 펄스를 통한 현금 캐비닛 트리거
- 고객 대면 디스플레이 (대기 시 프로모션 회전)
- Stripe Terminal 카드 리더 (S700, WisePOS E, P400)

**오프라인 기능**:
- Service Worker가 모든 터미널 자산을 캐시합니다
- IndexedDB가 최근 주문을 저장합니다 (설정 가능: 7-30일, 200-1000개 주문)
- 15분 TTL을 가진 재고 예약으로 과매출 방지
- 연결이 복원될 때 동기화를 위한 주문 대기열
- 자동 재연결 감지

## POS 관리자 페이지

이 관리자 페이지에 접속하여 POS 배포의 모든 측면을 관리할 수 있습니다:

**POS 대시보드** (`/admin/pos/`)
- 시스템 개요 및 빠른 통계
- 최근 터미널 활동
- 활성 시프트 요약
- 호스팅 서비스 사용 타일 (GeoIP, 지오코더, 푸시 — [Spwig 호스팅 서비스](hosted-services) 참조)

**터미널 관리** (`/admin/pos_app/posterminal/`)
- 터미널 등록 및 구성
- 직원 및 창고 할당
- 온라인/오프라인 상태 모니터링 (하트비트 추적)
- 원격으로 터미널 잠금 해제
- [더 알아보기: POS 터미널 관리](managing-pos-terminals)

**시프트 관리** (`/admin/pos_app/posshift/`)
- 모든 시프트 보기 (활성, 종료, 역사적)
- 현금 조정 보고서 검토
- 현금 이동 및 차이 추적
- 시프트 활동 감사
- [더 알아보기: POS 시프트 및 현금 관리](pos-shifts-cash-management)

**가맹점 그룹** (`/admin/pos_app/storegroup/`)
- 위치/지역별 터미널 분류
- 그룹 수준 설정 구성 (통화, 언어, 시간대)
- 설정 상속 계층 구현
- [더 알아보기: POS 가맹점 그룹](pos-store-groups)

**영수증 템플릿** (`/admin/pos_app/receipttemplate/`)
- 인쇄된 영수증을 커스터마이징 (종이 너비, 로고, 헤더/푸터)
- 규제 필드 구성 (세금 ID, 사업 등록)
- 프로모션을 위한 QR 코드 추가
- 특정 매장 또는 그룹에 템플릿 범위 지정
- [더 알아보기: 영수증 템플릿 커스터마이징](receipt-template-customization)

**프로모션 슬라이드** (`/admin/pos_app/promoslide/`)
- 고객 디스플레이 캐러셀 콘텐츠 생성
- 특정 매장 또는 그룹에 슬라이드 대상 지정
- 계절 프로모션 일정 설정
- [더 알아보기: 고객 디스플레이 프로모션 슬라이드](customer-display-promo-slides)

**결제 제공업체** (`/admin/pos_app/posterminalprovider/`)
- Stripe 터미널 통합 구성
- 결제 제공업체 자격 증명 관리
- 연결 상태 모니터링
- [더 알아보기: 결제 터미널 제공업체](payment-terminal-providers)

**카드 리더** (`/admin/pos_app/posterminalreader/`)
- 물리적 카드 리더 등록
- 리더를 터미널에 할당
- 스플래시 화면 커스터마이징 (고객 대면 디스플레이 브랜딩)
- 리더 상태 모니터링 (온라인/오프라인/바쁨)
- [더 알아보기: 카드 리더 관리](card-reader-management)

## 다중 위치 배포

여러 유통 위치를 가진 상인을 위해 Spwig POS는 계층적 설정 상속을 지원합니다:

**설정 계층** (가장 높은 우선순위에서 가장 낮은 순서):
1. 터미널별 설정 (모든 설정을 재정의)
2. 매장별 설정 (그룹 및 사이트를 재정의)
3. 그룹 설정 (사이트 기본값을 재정의)
4. 사이트 기본값 (모든 설정의 대체)

그룹 수준에서 공유 설정을 구성하고 필요에 따라 특정 매장 또는 터미널에 재정의할 수 있습니다. 상세한 설정 가이드는 [POS 매장 그룹](pos-store-groups)을 참조하세요.

## 팁

모든 마크다운 포맷, 이미지 경로, 코드 블록 및 기술 용어를 보존하세요.

- **한 대의 터미널부터 시작하세요** - 여러 터미널에 배포하기 전에 단일 터미널로 POS 설정 및 워크플로우를 테스트하세요
- **페어링 전에 창고를 할당하세요** - 터미널은 창고가 할당되지 않으면 판매를 처리할 수 없습니다
- **수신 영수증 템플릿을 조기에 구성하세요** - 세금 번호 등 준수 필드는 지역에 따라 다릅니다; 실제 운영 전에 설정하세요
- **오프라인 모드를 테스트하세요** - 인터넷을 끊고 판매가 계속되는지 확인하세요; 다시 연결할 때 동기화가 제대로 되는지 확인하세요
- **다중 위치를 위한 가맹점 그룹 사용** - 가맹점 또는 지역별 배포에 대한 구성 관리를 간소화합니다
- **하트비트 상태를 모니터링하세요** - 터미널은 5분마다 서버에 펄스를 보내며, 오프라인 터미널은 관리 대시보드에 표시됩니다
- **성능을 위한 동기화 제한 설정** - 느린 연결을 가진 터미널은 더 낮은 sync_days/sync_limit 설정을 적용하는 데 이점이 있습니다
- **하드웨어 구성 백업** - 프린터 IP, 스캐너 설정, 현금 인출기 구성 등을 재해 복구를 위해 문서화하세요
