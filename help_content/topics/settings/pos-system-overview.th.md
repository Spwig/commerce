ระบบ POS ของ Spwig ช่วยเปลี่ยนร้านค้าของคุณให้เป็นโซลูชันค้าปลีกแบบครบวงจรด้วยเครื่องจ่ายเงินแบบสมัยใหม่ (point-of-sale terminals) ระบบ POS นี้มีในทุกเวอร์ชัน — Community, Pro, และ Enterprise — โดยไม่มีค่าใช้จ่ายเพิ่มเติมสำหรับเครื่องจ่ายเงินไม่จำกัดจำนวนในสถานที่ไม่จำกัดจำนวน เครื่องจ่ายเงินแต่ละเครื่องเป็น Progressive Web App (PWA) ที่ทำงานได้โดยไม่ต้องเชื่อมต่ออินเทอร์เน็ต ซิงค์อัตโนมัติ และผสานรวมกับสต็อกสินค้า ข้อมูลลูกค้า และระบบประมวลผลการชำระเงินได้อย่างราบรื่น จัดการทุกสิ่งผ่านแดชบอร์ดผู้ดูแลระบบ — การตั้งค่าเครื่องจ่ายเงิน การตรวจสอบยอดขายในกะงาน การปรับแต่งใบเสร็จ และการผสานรวมฮาร์ดแวร์

ใช้ระบบ POS เมื่อคุณมีสถานที่ค้าปลีกแบบร่างกาย (physical retail locations) ร้านค้าชั่วคราว (pop-up shops) งานแสดงสินค้า (trade shows) หรือสภาพแวดล้อมใด ๆ ที่ลูกค้าซื้อสินค้าโดยตรงแทนที่จะซื้อออนไลน์

## Spwig POS คืออะไร?

Spwig POS เป็นระบบจ่ายเงินแบบครบวงจร (point-of-sale system) ที่ออกแบบมาสำหรับผู้ขายที่ขายสินค้าทั้งออนไลน์และในสถานที่จริง ต่างจากระบบ POS ของบุคคลที่สามที่ต้องการการผสานรวมที่ซับซ้อน Spwig POS ถูกสร้างขึ้นโดยตรงในแพลตฟอร์มของคุณ ทำให้ข้อมูลสอดคล้องกันอย่างสมบูรณ์ในทุกช่องทางการขาย

**คุณลักษณะหลัก**:
- **เครื่องจ่ายเงินไม่จำกัดจำนวน** - ติดตั้งเครื่องจ่ายเงินได้ตามที่ต้องการโดยไม่มีค่าใช้จ่ายเพิ่มเติม
- **สถาปัตยกรรมแบบ Offline-First** - ยังสามารถประมวลผลการขายได้แม้ไม่มีการเชื่อมต่ออินเทอร์เน็ต
- **Progressive Web App** - ไม่ต้องติดตั้งผ่านร้านค้าแอป (app store); สามารถเข้าถึงได้ผ่านเบราว์เซอร์บนอุปกรณ์ใด ๆ (แท็บเล็ต คอมพิวเตอร์ เครื่องจ่ายเงินเฉพาะ) 
- **การซิงค์สต็อกจริง** - การจองสต็อก (15 นาที TTL) ป้องกันการขายเกินจำนวนที่มีในช่องทางต่าง ๆ
- **การสนับสนุนการชำระเงินแบบแยก** - ยอมรับวิธีการชำระเงินหลายแบบในแต่ละธุรกรรม (เงินสด + บัตร + บัตรของขวัญ)
- **การผสานรวมฮาร์ดแวร์** - พิมพ์รีล (ESC/POS thermal printers) สแกนบาร์โค้ด ลิ้นชักเงิน หน้าจอแสดงข้อมูลลูกค้า
- **การจัดการกะงาน** - ตรวจสอบยอดเงินสดโดยใช้การนับเงินเริ่มต้น/สิ้นสุดและติดตามความคลาดเคลื่อน
- **พร้อมสำหรับหลายสถานที่** - กลุ่มร้านค้าที่มีการสืบทอดการตั้งค่าสำหรับการจัดการแฟรนไชส์และภูมิภาค

POS ถูกรวมไว้ในทุก edition ของ Spwig — Community, Pro, และ Enterprise — เริ่มต้นจาก Spwig 1.5.8

ไม่มี license POS แยกต่างหาก ไม่มีขั้นตอนการเปิดใช้งาน และไม่มีค่าธรรมเนียมต่อเทอร์มินัล

**สิ่งที่รวมอยู่ในทุก edition**:
- การลงทะเบียนเทอร์มินัลไม่จำกัด
- การมอบหมายพนักงานไม่จำกัด
- ฟีเจอร์ POS ทั้งหมด (ชั่วโมงทำงาน, การจัดการเงินสด, การปรับแต่งใบเสร็จ, หน้าจอแสดงผลลูกค้า)
- การผสานผู้ให้บริการชำระเงิน (Stripe Terminal และผู้ให้บริการที่ได้รับการสนับสนุนอื่น ๆ)
- การสนับสนุนการผสานฮาร์ดแวร์

ผู้ค้าที่ใช้ร้านค้าที่โฮสต์โดย Spwig หรือจ่ายค่า license Pro/Enterprise จะได้รับขีดจำกัดที่สูงขึ้นสำหรับบริการที่โฮสต์โดย Spwig ที่เป็นตัวเลือก (GeoIP, geocoder, การแจ้งเตือน) และการสนับสนุนแบบมีลำดับความสำคัญ แต่ชุดฟีเจอร์ POS เองนั้นเหมือนกันในทุก edition

## สถาปัตยกรรมระบบ

**Frontend** - React 18 Progressive Web App:
- ทำงานได้โดยไม่ต้องใช้อินเทอร์เน็ตด้วย Service Worker caching (offline-first)
- ระบบสร้าง Vite สำหรับการโหลดที่รวดเร็ว
- CSS Modules + design tokens (สอดคล้องกับธีมร้านค้าของคุณ)
- IndexedDB สำหรับการเก็บข้อมูลในท้องถิ่น
- 10 ภาษาที่รองรับ (อังกฤษ, จีนแบบง่าย/แบบดั้งเดิม, ฝรั่งเศส, เยอรมัน, สเปน, โปรตุเกส, ญี่ปุ่น, รัสเซีย, อารบิก)

**Backend** - การผสาน Backend:
- 13 โมเดล POS (POSTerminal, POSShift, CashMovement, ReceiptTemplate, PromoSlide, ฯลฯ)
- 43+ จุดปลายทาง REST API สำหรับการดำเนินการเทอร์มินัล
- ระบบสำรองสต็อกพร้อมการจัดการ TTL
- งาน Celery สำหรับการซิงค์ข้อมูลในพื้นหลัง
- การจัดเก็บข้อมูลการรับรองที่เข้ารหัสสำหรับผู้ให้บริการชำระเงิน

**ความปลอดภัย**:
- การจับคู่เทอร์มินัลผ่านรหัส 8 ตัวอักษร (สร้างขึ้นโดยเซิร์ฟเวอร์ หมดอายุหลังการใช้งาน)
- การควบคุมการมอบหมายพนักงานที่กำหนดว่าผู้ใช้ใดสามารถเข้าถึงเทอร์มินัลใดได้
- ความสามารถในการล็อก/ปลดล็อกจากระยะไกลสำหรับกรณีฉุกเฉินของผู้ดูแลระบบ
- การจัดเก็บข้อมูลการรับรองผู้ให้บริการชำระเงินที่เข้ารหัส
- การตรวจสอบสิทธิ์แบบเซสชันพร้อมการสนับสนุนการปลดล็อกด้วยการตรวจสอบชีวภาพ (ขึ้นอยู่กับเบราว์เซอร์)

## ขั้นตอนการเริ่มต้น

ปฏิบัติตามขั้นตอน 4 ขั้นตอนต่อไปนี้เพื่อติดตั้งเทอร์มินัล POS แรกของคุณ

สำหรับรายการตรวจสอบขั้นตอนทั้งหมด รวมถึงการตั้งค่าพนักงาน ผู้ให้บริการชำระเงิน และการดำเนินการขายครั้งแรก โปรดดู [Getting Started with POS](getting-started-with-pos)

**ขั้นตอนที่ 1: สร้างคลังสินค้า**
- ไปที่ **Catalog > Warehouses**
- สร้างคลังสินค้าที่แสดงถึงสถานที่ขายปลีกของคุณ
- ตั้งค่าที่อยู่และข้อมูลการติดต่อ
- คลังสินค้านี้จะติดตามสต็อกสินค้าสำหรับการขายผ่าน POS

**ขั้นตอนที่ 2: ลงทะเบียนเครื่องขาย**
- ไปที่ **POS > Terminals**
- คลิก **+ Add Terminal**
- ตั้งชื่อเครื่องขาย (เช่น "Main Register", "Checkout 1")
- เลือกคลังสินค้าจากขั้นตอนที่ 2
- ตั้งค่าการตั้งค่าฮาร์ดแวร์ (เครื่องพิมพ์ เครื่องสแกน ลิ้นชักเก็บเงิน)
- บันทึกเพื่อสร้างรหัสคู่ที่มี 8 ตัวอักษร

**ขั้นตอนที่ 3: มอบสิทธิ์ให้พนักงาน**
- ในการตั้งค่าเครื่องขาย ให้เลื่อนไปที่ **Assigned Users**
- เลือกพนักงานที่ได้รับอนุญาตให้ใช้เครื่องขายนี้
- เพียงผู้ใช้ที่ได้รับการมอบสิทธิ์เท่านั้นที่สามารถเข้าสู่ระบบเครื่องขายได้
- ผู้ใช้ต้องมีสิทธิ์ POS ที่เหมาะสมในบทบาทพนักงานของตนเอง

**ขั้นตอนที่ 4: คู่กับอุปกรณ์**
- บนอุปกรณ์เครื่องขายของคุณ (แท็บเล็ต/คอมพิวเตอร์) ให้ไปที่ URL `/pos/`
- ใส่รหัสคู่ที่มี 8 ตัวอักษรจากขั้นตอนที่ 3
- เครื่องขายจะดาวน์โหลดการตั้งค่าและซิงค์ข้อมูลเริ่มต้น
- เข้าสู่ระบบด้วยข้อมูลผู้ใช้ที่ได้รับการมอบสิทธิ์
- เครื่องขายพร้อมสำหรับการขายแล้ว

หลังจากคู่กับอุปกรณ์ เครื่องขายจะซิงค์อัตโนมัติทุก 5 นาที (ปรับแต่งได้) โหมดออฟไลน์ช่วยให้ดำเนินการต่อได้เมื่อไม่มีการเชื่อมต่ออินเทอร์เน็ต—การขายจะซิงค์อัตโนมัติเมื่อการเชื่อมต่อกลับมา

## ฟีเจอร์หลักของ POS

**การประมวลผลการขาย**:
- ค้นหาสินค้าตามชื่อ SKU หรือบาร์โค้ด
- แบ่งการชำระเงิน (หลายวิธีการชำระเงินต่อคำสั่งซื้อ)
- รถเข็นที่ถูกเก็บไว้ (บันทึกการซื้อที่ไม่สมบูรณ์)
- การคืนเงินและยกเลิกพร้อมการติดตามเหตุผล
- การใช้ส่วนลด (คูปอง บัตรของขวัญ การส่งเสริมการขาย)
- ค้นหาลูกค้าและแลกคะแนนสะสม

**การจัดการเงินสด**:
- บันทึกการเปิดกะด้วยการนับเงินสดเริ่มต้น
- บันทึกการปิดกะด้วยการตรวจสอบความสอดคล้องระหว่างคาดการณ์กับจริง
- การเคลื่อนไหวของเงินสด (การเพิ่มเงินสำรอง, การถอนเงินเล็กน้อยพร้อมเหตุผล)
- การคำนวณเงินสดที่คาดการณ์โดยอัตโนมัติจากยอดขายเงินสด
- การติดตามและรายงานความคลาดเคลื่อน

**การผสานรวมฮาร์ดแวร์**:
- พิมพ์ใบเสร็จแบบเทอร์มัล ESC/POS (เครือข่ายหรือซีเรียล)
- ตัวสแกนบาร์โค้ดผ่าน USB
- การเปิดลิ้นชักเงินสดผ่านการกระตุ้นจากพิมพ์เตือน
- หน้าจอสำหรับลูกค้า (สไลด์แสดงโปรโมชันเมื่อว่าง)
- ตัวอ่านบัตร Stripe Terminal (S700, WisePOS E, P400)

**ความสามารถในการทำงานแบบออฟไลน์**:
- Service Worker แคชทรัพยากรทั้งหมดของเทอร์มินัล
- IndexedDB เก็บคำสั่งซื้อล่าสุด (ปรับแต่งได้: 7-30 วัน, 200-1000 คำสั่งซื้อ)
- การจองสต็อกพร้อม TTL 15 นาทีป้องกันการขายเกินจำนวน
- คิวคำสั่งซื้อสำหรับการซิงค์เมื่อการเชื่อมต่อกลับมา
- การตรวจจับการเชื่อมต่ออัตโนมัติ

## หน้าผู้ดูแลระบบ POS

เข้าถึงหน้าผู้ดูแลระบบเหล่านี้เพื่อจัดการทุกด้านของการติดตั้ง POS ของคุณ:

**แดชบอร์ด POS** (`/admin/pos/`)
- ภาพรวมระบบและสถิติเร็วๆ
- กิจกรรมเทอร์มินัลล่าสุด
- สรุปกะที่กำลังดำเนินอยู่
- บล็อกการใช้งานบริการที่โฮสต์ (GeoIP, geocoder, push — ดู [Spwig Hosted Services](hosted-services))

**การจัดการเทอร์มินัล** (`/admin/pos_app/posterminal/`)
- ลงทะเบียนและตั้งค่าเทอร์มินัล
- มอบหมายพนักงานและคลังสินค้า
- ตรวจสอบสถานะออนไลน์/ออฟไลน์ (การติดตามการเต้นหัวใจ)
- ปลดล็อกเทอร์มินัลจากระยะไกล
- [เรียนรู้เพิ่มเติม: การจัดการเทอร์มินัล POS](managing-pos-terminals)

**การจัดการกะ** (`/admin/pos_app/posshift/`)
- ดูทุกกะ (กำลังเปิด, ปิด, ประวัติ)
- ตรวจสอบรายงานการตรวจสอบความสอดคล้องของเงินสด
- ติดตามการเคลื่อนไหวของเงินสดและความคลาดเคลื่อน
- ตรวจสอบกิจกรรมของกะ
- [เรียนรู้เพิ่มเติม: กะและจัดการเงินสด POS](pos-shifts-cash-management)

**กลุ่มร้านค้า** (`/admin/pos_app/storegroup/`)
- จัดกลุ่มเทอร์มินัลตามสถานที่/ภูมิภาค
- ตั้งค่าระดับกลุ่ม (สกุลเงิน, ภาษา, เวลาท้องถิ่น)
- ดำเนินการลำดับชั้นการสืบทอดการตั้งค่า
- [เรียนรู้เพิ่มเติม: กลุ่มร้านค้า POS](pos-store-groups)

**เทมเพลตใบเสร็จ** (`/admin/pos_app/receipttemplate/`)
- ปรับแต่งใบเสร็จที่พิมพ์ (ความกว้างของกระดาษ, โลโก้, หัว/ท้ายหน้า)
- ตั้งค่าฟิลด์ที่เกี่ยวข้องกับการปฏิบัติตามกฎหมาย (หมายเลขภาษี, ใบจดทะเบียนธุรกิจ)
- เพิ่มรหัส QR สำหรับโปรโมชัน
- จำกัดขอบเขตของเทมเพลตให้เฉพาะร้านค้าหรือกลุ่ม
- [เรียนรู้เพิ่มเติม: การปรับแต่งเทมเพลตใบเสร็จ](receipt-template-customization)

**สไลด์โปรโมชัน** (`/admin/pos_app/promoslide/`)
- สร้างเนื้อหาสไลด์แสดงผลสำหรับลูกค้า
- กำหนดเป้าหมายสไลด์ให้เฉพาะร้านค้าหรือกลุ่ม
- กำหนดเวลาสำหรับโปรโมชันตามฤดูกาล
- [เรียนรู้เพิ่มเติม: สไลด์โปรโมชันแสดงผลลูกค้า](customer-display-promo-slides)

## การติดตั้งหลายสถานที่

สำหรับผู้ค้าที่มีหลายสาขา ระบบ Spwig POS สนับสนุนการสืบทอดการตั้งค่าแบบลำดับชั้น:

**ลำดับชั้นการตั้งค่า** (จากความสำคัญสูงสุดถึงต่ำสุด):
1. การตั้งค่าเฉพาะอุปกรณ์ปลายทาง (ทับซ้อนทุกอย่าง)
2. การตั้งค่าเฉพาะร้านค้า (ทับซ้อนกลุ่มและไซต์)
3. การตั้งค่ากลุ่ม (ทับซ้อนค่าเริ่มต้นของไซต์)
4. ค่าเริ่มต้นของไซต์ (ค่าเริ่มต้นสำหรับทุกอย่าง)

ตั้งค่าการตั้งค่าที่ใช้ร่วมกันในระดับกลุ่ม (เช่น สกุลเงินตามภูมิภาค, ภาษา) และทับซ้อนสำหรับร้านค้าหรืออุปกรณ์ปลายทางเฉพาะตามที่จำเป็น ดู [กลุ่มร้านค้า POS](pos-store-groups) สำหรับคำแนะนำการตั้งค่าที่ละเอียด

## เคล็ดลับ

รักษาการจัดรูปแบบมาร์กดาวน์ ค่าเส้นทางรูปภาพ บล็อกโค้ด และคำศัพท์ทางเทคนิคไว้ทั้งหมด

- **เริ่มต้นด้วยเทอร์มินัลหนึ่งเครื่อง** - ทดสอบการตั้งค่าและกระบวนการทำงานของ POS กับเทอร์มินัลเดียวก่อนที่จะนำไปใช้ทั่วทั้งองค์กร
- **กำหนดคลังสินค้าก่อนจับคู่** - เทอร์มินัลไม่สามารถประมวลผลการขายได้หากไม่มีการกำหนดคลังสินค้า
- **ตั้งค่าเทมเพลตใบเสร็จล่วงหน้า** - ฟิลด์การปฏิบัติตามกฎหมาย (หมายเลขประจำตัวผู้เสียภาษี) แตกต่างกันไปตามภูมิภาค; จัดตั้งก่อนเปิดให้บริการ
- **ทดสอบโหมดออฟไลน์** - ตัดการเชื่อมต่ออินเทอร์เน็ตและตรวจสอบว่าการขายยังคงดำเนินต่อไป; ยืนยันการซิงค์เมื่อเชื่อมต่ออีกครั้ง
- **ใช้กลุ่มร้านค้าสำหรับร้านค้าหลายแห่ง** - ช่วยให้การจัดการการตั้งค่าเป็นไปอย่างง่ายสำหรับการติดตั้งแบบแฟรนไชส์หรือภูมิภาค
- **ตรวจสอบสถานะการส่งสัญญาณ (heartbeat)** - เทอร์มินัลจะส่งสัญญาณไปยังเซิร์ฟเวอร์ทุก 5 นาที; เทอร์มินัลที่ออฟไลน์จะปรากฏในแดชบอร์ดผู้ดูแลระบบ
- **ตั้งค่าขีดจำกัดการซิงค์เพื่อเพิ่มประสิทธิภาพ** - เทอร์มินัลที่มีการเชื่อมต่อช้าจะได้ประโยชน์จากการตั้งค่า sync_days/sync_limit ที่ต่ำกว่า
- **สำรองการตั้งค่าฮาร์ดแวร์** - จัดทำเอกสารหมายเลข IP ของเครื่องพิมพ์, การตั้งค่าสแกนเนอร์, การตั้งค่าลิ้นชักเงินสดสำหรับการกู้คืนข้อมูลในกรณีฉุกเฉิน
