---
title: 配送ルール
---

配送ルールは、カートの内容、カスタマーの属性、配達エリアに基づいて、配送方法のコスト調整を条件付きで適用します。50ドル以上の注文で無料配送を自動的に提供したり、遠隔地域に対して追加料金を課したり、VIP顧客向けに配送料金を割引いためます。ルールは優先順位に基づいた実行（高い優先順位から）を使用し、以降の処理を中止するオプションのフラグを備えています。各ルールは、カートの価値、重量、ゾーン、製品、カスタマーグループなどの複数の条件を評価し、すべての条件が一致した場合に6種類の調整タイプのいずれかを実行します。

注文の文脈に応じて変化する動的な配送料金が必要な場合にのみ、配送ルールを使用してください。配送方法からの静的な料金のみではなく、注文の文脈に応じて変化する料金が必要な場合に使用してください。

## デリバリー・ルールの種類

デリバリー・ルールは6種類のコスト調整を適用します。

### パーセンテージ割引

**何をしますか**: 送料をパーセンテージで引き下げます（例: 25％オフ）。

**式**: `new_cost = base_cost × (1 - percent/100)`

**例**:
```
ベース料金: $20
割引: 25％
結果: $15
```

**利用例**:
- ビジネスカスタマー割引（すべての送料20％オフ）
- シーズナルプロモーション（12月の送料15％オフ）
- ボリューム注文割引（5点以上の注文で送料10％オフ）

---

### 固定割引

**何をしますか**: 送料から固定額を差し引きます。

**式**: `new_cost = base_cost - amount`（最小で$0）

**例**:
```
ベース料金: $15
割引: $5
結果: $10
```

**利用例**:
- 初めてのカスタマーへのボーナス（初回注文の送料$5オフ）
- ニュースレター登録報酬（送料$3オフ）
- ロイヤルティプログラムの特典（月1回の送料$10オフ）

---

### 固定料金

**何をしますか**: 送料を特定の金額に上書きします。

**式**: `new_cost = fixed_amount`

**例**:
```
ベース料金: $25
設定: $9.99
結果: $9.99
```

**利用例**:
- フラッシュセール（本日の注文すべてで送料$5固定）
- カテゴリ固有の送料（本は常に送料$3.99）
- 時間ベースのプロモーション（今週の送料は$9.99まで）

---

### 無料配送

**何をしますか**: 送料を$0に設定します。

**式**: `new_cost = $0`

**例**:
```
基本料金: $18
ルールが適用される
結果: $0
```

**利用ケース**:
- $50以上で送料無料
- 特定の製品で送料無料（プロモーション商品）
- VIP顧客向け送料無料
- 3点以上の注文で送料無料


### 施設料（固定額）

**機能**: 送料に固定額を追加します。

**式**: `新しい料金 = 送料ベース + 金額`

**例**:
```
基本料金: $12
施設料: $5
結果: $17
```

**利用ケース**:
- 未開拓地域への配達手数料
- 大型品取扱い
- 土曜日配達施設料
- 脆弱品包装手数料


### 施設料（パーセンテージ）

**機能**: 送料をパーセンテージで増加させます。

**式**: `新しい料金 = 送料ベース × (1 + パーセンテージ/100)`

**例**:
```
基本料金: $20
施設料: 15%
結果: $23
```

**利用ケース**:
- ピークシーズン施設料（休日の20%）
- エクスプレス配達プレミアム（50%の施設料）
- ファイナル施設料（現在のレートに応じて変化）


## ルールの条件

ルールは**すべての条件が満たされている必要があります**。

### 期間の有効性

- **開始日**: この日付以降のみルールが有効
- **終了日**: この日付までにのみルールが有効
- **利用ケース**: シーズナルプロモーション、限定オファー

**例**: ブラックフRIdayの週末のみ送料無料
```
開始: 2026-11-27 00:00
終了: 2026-11-30 23:59
```


### カートの価値範囲

- **最小カート価値**: カート小計は ≥ 金額
- **最大カート価値**: カート小計は ≤ 金額
- **利用ケース**: 送料無料のしきい値、段階的な割引

**例**: $50-$200の注文で送料無料
```
最小: $50
最大: $200
```


### カートの重量範囲

- **最小重量**: カートの総重量は ≥ 金額
- **最大重量**: カートの総重量は ≤ 金額
- **利用ケース**: 軽量配送割引、重い商品への施設料

**例**: 20kgを超える注文には$5の施設料
```
最小重量: 20kg
最大重量: null（無制限）
```


### 商品数範囲

- **Min Item Count**: カートに ≥ 数量 の商品が含まれている必要があります
- **Max Item Count**: カートに ≤ 数量 の商品が含まれている必要があります
- **Use Case**: バッチ注文割引、単品商品の手数料

**Example**: 5個以上の商品で送料無料
```
Min Items: 5
Max Items: null
```


### 送料対象地域
- **Zones**: 顧客の住所が少なくとも1つの選択済みゾーンに一致する場合にのみルールが適用されます
- **空の選択**: ルールはすべてのゾーンに適用されます
- **Use Case**: ゾーン固有の追加料金または割引

**Example**: ディスカウントなしで国内ゾーンのみ
```
Zones: ["Domestic USA"]
```


### 送料方法
- **Methods**: ルールは特定の配送方法にのみ適用されます
- **空の選択**: ルールはすべての方法に適用されます
- **Use Case**: 方法固有のプロモーション

**Example**: エクスプレス配送で25％オフ
```
Methods: ["Express Delivery"]
```


### 製品要件
**Requires Products**: カートにこれらの製品の少なくとも1つが含まれている必要があります

**Requires Categories**: カートにこれらのカテゴリの製品が少なくとも1つ含まれている必要があります

**Use Case**: 製品固有の送料無料、プロモーションボックス

**Example**: カートに「Promotion Item A」が含まれている場合に送料無料
```
Requires Products: [製品ID 123]
```


### 製品除外
**Excludes Products**: カートにこれらの製品のいずれかが含まれている場合、ルールは適用されません

**Excludes Categories**: カートにこれらのカテゴリの製品が含まれている場合、ルールは適用されません

**Use Case**: 送料無料から大型品・過大サイズ品を除外する

**Example**: フurnitureカテゴリを除き送料無料
```
Excludes Categories: [家具]
```


### カスタマーグループ
- **Customer Groups**: これらのグループ（VIP、卸など）に所属するカスタマーのみにルールが適用されます
- **空の選択**: ルールはすべてのカスタマーグループに適用されます
- **Use Case**: VIPの特典、卸売割引

**Example**: VIP会員向けに15％の送料割引
```
Customer Groups: ["VIP"]
```

- **初めてのカスタマー**: 以前の注文がないカスタマーにルールを制限するトグル
- **ユースケース**: 新規カスタマー向けウェルカムオファー

**例**: 初回注文で送料5ドルオフ

## ルールの優先順位と実行

ルールは**優先順位順に実行**されます（数値が高いほど実行が早くなります）:

### 優先順位のメカニクス

**実行例**:
```
ルールA (優先順位100): カートが50ドル以上なら送料無料
ルールB (優先順位50): すべての送料に対して10%の割引
ルールC (優先順位1): 未利用地域には2ドルの追加料金

カート: 60ドル、未利用地域
送料ベース: 15ドル

ステップ1: ルールAを評価 (優先順位100)
  カートが50ドル以上? はい
  実行: 料金を0ドルに設定
  料金現在: 0ドル

ステップ2: ルールBを評価 (優先順位50)
  0ドルに10%の割引を適用
  料金現在: 0ドル（まだ無料）

ステップ3: ルールCを評価 (優先順位1)
  0ドルに2ドルの追加料金を追加
  料金現在: 2ドル

最終的な料金: 2ドル
```

**以降のルールを停止するフラグ**:

ルールAに`stop_further_rules = True`がある場合:
```
ルールA (優先順位100, stop_further_rules=True): カートが50ドル以上なら送料無料
ルールB (優先順位50): 送料すべてに10%の割引
ルールC (優先順位1): 未利用地域に2ドルの追加料金

カート: 60ドル
ベース: 15ドル

ステップ1: ルールAが適用され、料金が0ドルに設定される
        stop_further_rules = True → 実行を停止

最終的な料金: 0ドル（ルールBとCは実行されない）
```

## シッピングルールの作成

**ステップバイステップのワークフロー**:

1. **ルールに移動する**
   - 設定 > シッピング > シッピングルール
   - 「シッピングルールの追加」をクリック

2. **基本的な設定**
   - **名前**: 内部識別子 (例: 「50ドル以上で送料無料」)
   - **説明**: オプションのノート (カスタマーには表示されません)
   - **有効**: 有効/無効にするトグル
   - **優先順位**: 実行順序を設定 (高優先度は100、低優先度は1)

3. **ルールタイプの選択**
   - 調整タイプ (パーセンテージ割引、固定割引、コスト設定、無料、パーセンテージ追加料金、固定追加料金) を選択
   - 金額またはパーセンテージを入力


4. **ストップフラグの設定** (オプション)
  - このルールが優先度の低いルールの実行を防止する必要がある場合は、"以降のルールを停止"にチェックを付けてください
  - 例: 無料配送は、その後に追加料金がかかるべきではありません

5. **条件の定義** (オプション - いつでも適用する場合は空のままにしてください)
  - 有効期間: 開始日/終了日
  - カートの価値: 最低値/最高値
  - カートの重量: 最低値/最高値
  - 商品数: 最低値/最高値
  - ゾーン: 適用可能なゾーンを選択
  - 方法: 適用可能な方法を選択
  - 製品: 必要または除外
  - 顧客: グループまたは初回のみ

6. **ルールの保存**
  - 保存ボタンをクリック
  - ルールは即座に有効になります (有効トグルがYesの場合)


## 一般的な配送ルールのシナリオ

### シナリオ1: $50以上の無料配送

**目的**: カートの小計が$50以上の場合、無料配送を提供します。

**構成**:
```
名前: $50以上の無料配送
タイプ: 無料配送
優先度: 100
条件:
  最低カート価値: $50
以降のルールを停止: はい
```


### シナリオ2: リモートエリアへの追加料金

**目的**: リモートゾーンへの配送に$10の追加料金を追加します。

**構成**:
```
名前: リモートエリアへの追加料金
タイプ: 追加料金 (固定)
金額: $10
優先度: 50
条件:
  ゾーン: ["リモートエリア"]
以降のルールを停止: いいえ
```


### シナリオ3: VIPカスタマーの20%オフ

**目的**: VIPカスタマーはすべての配送で20%オフになります。

**構成**:
```
名前: VIP配送割引
タイプ: 割引 (パーセンテージ)
パーセンテージ: 20
優先度: 75
条件:
  顧客グループ: ["VIP"]
以降のルールを停止: いいえ
```


### シナリオ4: ハローフラットレート

**目的**: 12月中のすべての配送は$9.99に上限が設けられます。

**構成**:
```
名前: 12月フラットレートプロモーション
タイプ: 定額料金
金額: $9.99
優先度: 100
条件:
  開始日: 2026-12-01
  終了日: 2026-12-31
以降のルールを停止: はい
```


### シナリオ5: 重い商品への追加料金

```
名前: 大量注文手数料
種類: 手数料 (固定)
金額: $15
優先度: 50
条件:
  最小重量: 25kg
他のルールを停止する: いいえ
``` 


### シナリオ6: 初回注文で送料無料

**目的**: 新規顧客は初回注文で送料無料になります。

**設定**:

```
名前: 初回注文送料無料
種類: 送料無料

  初めての利用者: はい
``` 

## ルールの組み合わせ戦略

### 戦略1: 割引の積み重ね

**複数の割引を積み重ね可能**:
```
ルールA (優先度100): VIP向け10%オフ → stop_further_rules=いいえ
ルールB (優先度50): $100以上の注文で15%オフ → stop_further_rules=いいえ

VIPカスタマーの$120注文:
ベース: $15
ルールA適用後: $13.50 (10%オフ)
ルールB適用後: $11.48 ($13.50の15%オフ)
```

### 戦略2: 限定ルール

**1つのルールのみ適用** (優先度が最も高いもの):
```
ルールA (優先度100): $50以上で送料無料 → stop_further_rules=はい
ルールB (優先度50): すべての配送で20%オフ → stop_further_rules=はい

$50以上のカート:
ルールAが適用される → 送料無料 → 実行を停止
ルールBは実行されない
```

### 戦略3: 条件付き手数料

マークダウンフォーマット、画像パス、コードブロック、技術用語を保持してください。

**割引は最初に、追加料金は最後に**:
```
ルール A (優先度 100): $75以上で送料無料
ルール B (優先度 75): ビジネスVIP割引15%
ルール C (優先度 50): 一般割引10%
ルール D (優先度 25): $5のリモート地域追加料金
ルール E (優先度 1): 燃料追加料金10%

注文: $80、リモートゾーン、VIPカスタマー
ベース: $20
A: $80 > $75 → 送料無料 ($0)
B: VIP → $0の15%オフ = $0
C: $0の10%オフ = $0
D: リモート +$5 = $5
E: 燃料 +$5の10% = $5.50

最終: $5.50 (追加料金のため、送料無料にはならない)
```

**これを防ぐには、stop_further_rules=Yesを使用してください**:
```
ルール A (優先度 100, stop=Yes): $75以上で送料無料

同じ注文:
A: $80 > $75 → 送料無料 ($0) → STOP
最終: $0 (本物の送料無料)
```

## 送料ルールのテスト

**本番環境に移行する前に**:

1. **テストカートの作成**
   - カート A: $25 (しきい値未満)
   - カート B: $55 (しきい値以上)
   - カート C: $200 + リモートゾーン
   - カート D: VIPカスタマー

2. **各ルールのテスト**
   - 注文手続きに進む
   - 送料が正しく表示されているか確認する
   - ルールの実行順序を確認する

3. **優先度の解決のテスト**
   - 複数のルールが一致する
   - 最も優先度の高いルールが最初に実行されるか確認する
   - stop_further_rulesの振る舞いを確認する

4. **エッジケースのテスト**
   - カートの金額が正確にしきい値に達している
   - 複数の条件が一致する
   - 互いに矛盾するルール

## よくあるトラブルシューティング

**問題1: ルールが適用されない**

**原因**:
- ルールが非アクティブ
- 1つ以上の条件が満たされていない
- 他のルールがstop_further_rules=Yesに設定されている
- 有効期間が現在の日付と一致していない

**解決策**: すべての条件を再確認し、優先度を確認し、アクティブ状態を確認してください。

---

**問題2: 予期しない割引額**

**原因**:
- 複数のルールが重なっている
- 割引がすでに適用された金額にパーセンテージが適用されている
- ルールの優先度が間違っている

**解決策**: 優先度の順序を確認し、stop_further_rulesフラグを確認し、実行フローを手作業で追跡してください。

---

**問題3: 送料無料が動作しない**

**原因**:
- 低い優先度の追加料金ルールが無料配送ルールの後にコストを追加している
- カートが最小価格基準を満たしていない
- カートに除外されている製品が含まれている

**ソリューション**: 無料配送ルールでstop_further_rules=Yesを使用し、条件を確認し、除外をチェックしてください。


## トipp

- **無料配送用に高い優先度を設定する** - 他の調整よりも先に実行されるよう、優先度100を設定してください
- **絶対的なルールに対してstop_further_rulesを設定する** - 無料配送は以降の処理を停止する必要があります
- **ルールの組み合わせをテストする** - 複数のルールが予期せぬ方法で相互作用することがあります
- **説明的な名前を使用する** - 「VIP 20%オフ（優先度75）」は「ルール3」より良いです
- **複雑なロジックをドキュメント化する** - 説明フィールドにノートを追加してください
- **単純なルールから始める** - 複雑さを段階的に追加してください
- **ルールのパフォーマンスをモニタリングする** - ルールが使用されているか、混乱を引き起こしていないかを確認してください
- **過度なルールを避ける** - 10個までにとどめてください
- **地理用にゾーンを使用する** - 国ごとに類似したルールを複数設定するよりも優れています
- **方法と組み合わせる** - ルールと方法を組み合わせることで、洗練された価格設定が可能です
- **明確な時間枠を設定する** - プロモーションには常に終了日を含めてください
- **エッジケースをテストする** - ちょうど50ドル、ちょうど5点など
