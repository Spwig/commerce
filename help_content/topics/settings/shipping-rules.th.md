title: กฎการจัดส่ง
---

กฎการจัดส่งใช้การปรับค่าใช้จ่ายแบบมีเงื่อนไขสำหรับวิธีการจัดส่งตามเนื้อหาของตะกร้าสินค้า คุณสมบัติของลูกค้า และพื้นที่จัดส่ง ทำให้สามารถเสนอการจัดส่งแบบฟรีเมื่อมียอดสั่งซื้อเกิน 50 ดอลลาร์ หรือเพิ่มค่าธรรมเนียมสำหรับพื้นที่ที่ห่างไกล หรือลดค่าใช้จ่ายการจัดส่งสำหรับลูกค้า VIP ได้ กฎการจัดส่งใช้การประมวลผลแบบมีลำดับความสำคัญ (ลำดับสูงสุดก่อน) โดยมีตัวชี้หยุดเพื่อป้องกันไม่ให้ประมวลผลต่อ กฎแต่ละอันจะประเมินเงื่อนไขหลายอย่าง (มูลค่าตะกร้า น้ำหนัก พื้นที่ สินค้า กลุ่มลูกค้า) และดำเนินการปรับแต่ง 6 ประเภทเมื่อเงื่อนไขทั้งหมดตรงกัน

ใช้กฎการจัดส่งเมื่อคุณต้องการค่าใช้จ่ายการจัดส่งแบบไดนามิกที่เปลี่ยนแปลงตามบริบทของคำสั่งซื้อ ไม่ใช่แค่อัตราค่าจัดส่งจากวิธีการจัดส่งเท่านั้น

## ประเภทของกฎการจัดส่ง

กฎการจัดส่งใช้การปรับแต่งค่าใช้จ่าย 6 ประเภท:

### การลดราคาเปอร์เซ็นต์

**สิ่งที่มันทำ**: ลดค่าใช้จ่ายการจัดส่งตามเปอร์เซ็นต์ (เช่น ลด 25%)

**สูตร**: `new_cost = base_cost × (1 - percent/100)`

**ตัวอย่าง**:
```
ค่าฐาน: 20 ดอลลาร์
ส่วนลด: 25%
ผลลัพธ์: 15 ดอลลาร์
```

**กรณีใช้งาน**:
- ส่วนลดลูกค้า VIP (ลด 20% ค่าจัดส่งทั้งหมด)
- การโปรโมชั่นตามฤดูกาล (ลด 15% ค่าจัดส่งในเดือนธันวาคม)
- ส่วนลดการสั่งซื้อจำนวนมาก (ลด 10% ค่าจัดส่งสำหรับสินค้า 5 ชิ้นขึ้นไป)

---

### การลดราคาแบบคงที่

**สิ่งที่มันทำ**: ลบจำนวนคงที่ออกจากค่าใช้จ่ายการจัดส่ง

**สูตร**: `new_cost = base_cost - amount` (ขั้นต่ำ 0 ดอลลาร์)

**ตัวอย่าง**:
```
ค่าฐาน: 15 ดอลลาร์
ส่วนลด: 5 ดอลลาร์
ผลลัพธ์: 10 ดอลลาร์
```

**กรณีใช้งาน**:
- ของขวัญลูกค้าใหม่ (ลด 5 ดอลลาร์สำหรับการสั่งซื้อครั้งแรก)
- รางวัลจากการสมัครรับจดหมายข่าว (ลด 3 ดอลลาร์ค่าจัดส่ง)
- สิทธิประโยชน์ของโปรแกรมความภักดี (ลด 10 ดอลลาร์ค่าจัดส่งต่อเดือน)

---

### ค่าใช้จ่ายแบบกำหนด

**สิ่งที่มันทำ**: กำหนดค่าใช้จ่ายการจัดส่งให้เป็นจำนวนเฉพาะ

**สูตร**: `new_cost = fixed_amount`

**ตัวอย่าง**:
```
ค่าฐาน: 25 ดอลลาร์
ตั้งค่าเป็น: 9.99 ดอลลาร์
ผลลัพธ์: 9.99 ดอลลาร์
```

**กรณีใช้งาน**:
- การขายแบบลดราคาชั่วคราว (ค่าจัดส่งคงที่ 5 ดอลลาร์สำหรับทุกคำสั่งซื้อในวันนี้)
- ค่าจัดส่งเฉพาะหมวดหมู่ (หนังสือทุกเล่มมีค่าจัดส่ง 3.99 ดอลลาร์)
- การโปรโมชั่นตามเวลา (ค่าจัดส่งถูกจำกัดที่ 9.99 ดอลลาร์ในสัปดาห์นี้)

---

### การจัดส่งแบบฟรี

**สิ่งที่มันทำ**: กำหนดค่าใช้จ่ายการจัดส่งให้เป็น 0 ดอลลาร์

**สูตร**: `new_cost = $0`

**ตัวอย่าง**:
```
ค่าฐาน: $18
กฎใช้ได้
ผลลัพธ์: $0
```

**กรณีใช้งาน**:
- ค่าจัดส่งฟรีสำหรับการสั่งซื้อเกิน $50
- ค่าจัดส่งฟรีสำหรับสินค้าเฉพาะ (สินค้าโปรโมชัน)
- ค่าจัดส่งฟรีสำหรับลูกค้า VIP
- ค่าจัดส่งฟรีสำหรับออเดอร์ที่มีสินค้า 3 ชิ้นขึ้นไป


### ค่าธรรมเนียมเพิ่ม (จำนวนคงที่)

**สิ่งที่ทำ**: เพิ่มจำนวนเงินคงที่ให้กับค่าจัดส่ง

**สูตร**: `new_cost = base_cost + amount`

**ตัวอย่าง**:
```
ค่าฐาน: $12
ค่าธรรมเนียมเพิ่ม: $5
ผลลัพธ์: $17
```

**กรณีใช้งาน**:
- ค่าธรรมเนียมพื้นที่ห่างไกล
- ค่าจัดการสินค้าขนาดใหญ่
- ค่าธรรมเนียมการจัดส่งวันเสาร์
- ค่าธรรมเนียมการบรรจุสินค้าที่เปราะบาง


### ค่าธรรมเนียมเพิ่ม (ร้อยละ)

**สิ่งที่ทำ**: เพิ่มค่าจัดส่งตามร้อยละ

**สูตร**: `new_cost = base_cost × (1 + percent/100)`

**ตัวอย่าง**:
```
ค่าฐาน: $20
ค่าธรรมเนียมเพิ่ม: 15%
ผลลัพธ์: $23
```

**กรณีใช้งาน**:
- ค่าธรรมเนียมช่วงฤดูกาล (20% ในช่วงวันหยุด)
- ค่าธรรมเนียมการจัดส่งด่วน (เพิ่ม 50%)
- ค่าธรรมเนียมค่าน้ำมัน (ขึ้นอยู่กับอัตราปัจจุบัน)


## ข้อกำหนดของกฎ

กฎจะต้องผ่าน **เงื่อนไขทั้งหมด** ที่กำหนดไว้เพื่อให้ใช้ได้:

### ช่วงเวลาที่ใช้ได้

- **วันเริ่มต้น**: กฎจะใช้ได้หลังจากวันนี้เท่านั้น
- **วันสิ้นสุด**: กฎจะใช้ได้ก่อนวันนี้เท่านั้น
- **กรณีใช้งาน**: การโปรโมชันตามฤดูกาล, ข้อเสนอพิเศษชั่วคราว

**ตัวอย่าง**: ค่าจัดส่งฟรีในช่วงวันหยุดวันศุกร์ที่ 5 ของเดือนพฤศจิกายน
```
เริ่ม: 2026-11-27 00:00
สิ้นสุด: 2026-11-30 23:59
```


### ช่วงมูลค่าตะกร้า

- **มูลค่าตะกร้าขั้นต่ำ**: มูลค่ารวมของตะกร้าต้อง ≥ จำนวนเงิน
- **มูลค่าตะกร้าสูงสุด**: มูลค่ารวมของตะกร้าต้อง ≤ จำนวนเงิน
- **กรณีใช้งาน**: ขั้นต่ำของการจัดส่งฟรี, ส่วนลดแบบหลายระดับ

**ตัวอย่าง**: ค่าจัดส่งฟรีสำหรับออเดอร์ $50-$200
```
ขั้นต่ำ: $50
ขั้นสูงสุด: $200
```


### ช่วงน้ำหนักตะกร้า

- **น้ำหนักตะกร้าขั้นต่ำ**: น้ำหนักรวมของตะกร้าต้อง ≥ จำนวนเงิน
- **น้ำหนักตะกร้าสูงสุด**: น้ำหนักรวมของตะกร้าต้อง ≤ จำนวนเงิน
- **กรณีใช้งาน**: ส่วนลดการจัดส่งสินค้าที่มีน้ำหนักเบา, ค่าธรรมเนียมสินค้าที่มีน้ำหนักมาก

**ตัวอย่าง**: ค่าธรรมเนียม $5 สำหรับออเดอร์ที่มีน้ำหนักเกิน 20kg
```
น้ำหนักขั้นต่ำ: 20kg
น้ำหนักสูงสุด: null (ไม่จำกัด)
```


### ช่วงจำนวนสินค้า


- **จำนวนสินค้าขั้นต่ำ**: ต้องมีจำนวนสินค้า ≥ จำนวนที่กำหนด
- **จำนวนสินค้าสูงสุด**: ต้องมีจำนวนสินค้า ≤ จำนวนที่กำหนด
- **กรณีใช้งาน**: ส่วนลดการสั่งซื้อจำนวนมาก, ค่าธรรมเนียมสินค้าเพียงชิ้นเดียว

**ตัวอย่าง**: ค่าจัดส่งฟรีสำหรับสินค้า 5 ชิ้นขึ้นไป
```
Min Items: 5
Max Items: null
```

### โซนการจัดส่ง
- **โซน**: กฎนี้ใช้ได้ก็ต่อเมื่อที่อยู่ของลูกค้าตรงกับโซนที่เลือกอย่างน้อยหนึ่งโซน
- **การเลือกที่ว่างเปล่า**: กฎนี้ใช้ได้กับทุกโซน
- **กรณีใช้งาน**: การเพิ่มค่าธรรมเนียมหรือส่วนลดเฉพาะโซน

**ตัวอย่าง**: ค่าจัดส่งฟรีสำหรับโซนภายในประเทศเท่านั้น
```
Zones: ["Domestic USA"]
```

### วิธีการจัดส่ง
- **วิธีการ**: กฎนี้ใช้ได้กับวิธีการจัดส่งเฉพาะ
- **การเลือกที่ว่างเปล่า**: กฎนี้ใช้ได้กับทุกวิธีการ
- **กรณีใช้งาน**: การโปรโมตเฉพาะวิธีการ

**ตัวอย่าง**: ลด 25% สำหรับการจัดส่งแบบด่วน
```
Methods: ["Express Delivery"]
```

### ข้อกำหนดของสินค้า
**ต้องการสินค้า**: ต้องมีสินค้าอย่างน้อยหนึ่งตัวจากสินค้าเหล่านี้

**ต้องการหมวดหมู่**: ต้องมีสินค้าอย่างน้อยหนึ่งตัวจากหมวดหมู่เหล่านี้

**กรณีใช้งาน**: ค่าจัดส่งฟรีเฉพาะสินค้า, ชุดโปรโมชันเฉพาะสินค้า

**ตัวอย่าง**: ค่าจัดส่งฟรีเมื่อตระกร้ามี "สินค้าโปรโมชัน A"
```
Requires Products: [Product ID 123]
```

### การยกเว้นสินค้า
**ยกเว้นสินค้า**: กฎนี้ไม่ใช้ได้หากตระกร้ามีสินค้าใด ๆ จากสินค้าเหล่านี้

**ยกเว้นหมวดหมู่**: กฎนี้ไม่ใช้ได้หากตระกร้ามีสินค้าใด ๆ จากหมวดหมู่เหล่านี้

**กรณีใช้งาน**: ยกเว้นสินค้าที่มีน้ำหนักมากหรือขนาดใหญ่จากค่าจัดส่งฟรี

**ตัวอย่าง**: ค่าจัดส่งฟรียกเว้นหมวดหมู่เฟอร์นิเจอร์
```
Excludes Categories: [Furniture]
```

### กลุ่มลูกค้า
- **กลุ่มลูกค้า**: กฎนี้ใช้ได้กับลูกค้าในกลุ่มที่เลือก (VIP, ขายส่ง เป็นต้น)
- **การเลือกที่ว่างเปล่า**: กฎนี้ใช้ได้กับทุกกลุ่มลูกค้า
- **กรณีใช้งาน**: สิทธิพิเศษของ VIP, ส่วนลดขายส่ง

**ตัวอย่าง**: ส่วนลดค่าจัดส่ง 15% สำหรับลูกค้า VIP
```
Customer Groups: ["VIP"]
```

### ลูกค้าครั้งแรก
 Preserve all markdown formatting, image paths, code blocks, and technical terms.

- **ลูกค้าครั้งแรก**: เปิด/ปิด เพื่อจำกัดกฎให้กับลูกค้าที่ยังไม่มีคำสั่งซื้อที่ผ่านมา
- **กรณีใช้งาน**: ข้อเสนอสำหรับลูกค้าใหม่ที่เพิ่งเริ่มต้นใช้งาน

**ตัวอย่าง**: ลดค่าจัดส่ง 5 ดอลลาร์สำหรับคำสั่งซื้อครั้งแรก
```
ลูกค้าครั้งแรก: ใช่
```


## ลำดับความสำคัญของกฎและการดำเนินการ

กฎจะทำงานในลำดับ **ความสำคัญ** (ค่าที่มากขึ้น = การทำงานก่อน):

### กลไกการจัดลำดับความสำคัญ

**ตัวอย่างการดำเนินการ**:
```
กฎ A (ลำดับความสำคัญ 100): ค่าจัดส่งฟรีหากตระกร้าสินค้ามากกว่า 50 ดอลลาร์
กฎ B (ลำดับความสำคัญ 50): ลด 10% สำหรับค่าจัดส่งทั้งหมด
กฎ C (ลำดับความสำคัญ 1): เพิ่มค่าธรรมเนียม 2 ดอลลาร์สำหรับพื้นที่ห่างไกล

ตระกร้า: 60 ดอลลาร์, พื้นที่ห่างไกล
ค่าจัดส่งพื้นฐาน: 15 ดอลลาร์

ขั้นตอนที่ 1: ตรวจสอบกฎ A (ลำดับความสำคัญ 100)
 ตระกร้ามากกว่า 50 ดอลลาร์หรือไม่? ใช่
 ใช้: ตั้งค่าให้เป็น 0 ดอลลาร์
 ค่าปัจจุบัน: 0 ดอลลาร์

ขั้นตอนที่ 2: ตรวจสอบกฎ B (ลำดับความสำคัญ 50)
 ลด 10% สำหรับ 0 ดอลลาร์
 ค่าปัจจุบัน: 0 ดอลลาร์ (ยังคงฟรี)

ขั้นตอนที่ 3: ตรวจสอบกฎ C (ลำดับความสำคัญ 1)
 เพิ่มค่าธรรมเนียม 2 ดอลลาร์สำหรับ 0 ดอลลาร์
 ค่าปัจจุบัน: 2 ดอลลาร์

ค่าสุดท้าย: 2 ดอลลาร์
```

**ธงหยุดกฎอื่นๆ**:

หากกฎ A มีค่า `stop_further_rules = True`:
```
กฎ A (ลำดับความสำคัญ 100, stop_further_rules=True): ค่าจัดส่งฟรีหากตระกร้ามากกว่า 50 ดอลลาร์
กฎ B (ลำดับความสำคัญ 50): ลด 10% สำหรับค่าจัดส่ง
กฎ C (ลำดับความสำคัญ 1): เพิ่มค่าธรรมเนียม 2 ดอลลาร์

ตระกร้า: 60 ดอลลาร์
ค่าพื้นฐาน: 15 ดอลลาร์

ขั้นตอนที่ 1: กฎ A ใช้ได้ ตั้งค่าให้เป็น 0 ดอลลาร์
        stop_further_rules = True → หยุด

ค่าสุดท้าย: 0 ดอลลาร์ (กฎ B และ C ไม่ได้ทำงานเลย)
```


## การสร้างกฎค่าจัดส่ง

**กระบวนการทำงานแบบขั้นตอน**:

1. **ไปยังกฎ**: 
   - การตั้งค่า > ค่าจัดส่ง > กฎค่าจัดส่ง
   - คลิก "เพิ่มกฎค่าจัดส่ง"

2. **การตั้งค่าพื้นฐาน**
   - **ชื่อ**: รหัสภายใน (เช่น "ค่าจัดส่งฟรีเมื่อซื้อเกิน 50 ดอลลาร์")
   - **คำอธิบาย**: หมายเหตุเพิ่มเติม (ไม่แสดงให้ลูกค้าเห็น)
   - **เปิดใช้งาน**: เปิด/ปิด การใช้งาน
   - **ลำดับความสำคัญ**: ตั้งลำดับการดำเนินการ (100 สำหรับลำดับความสำคัญสูง, 1 สำหรับลำดับความสำคัญต่ำ)

3. **เลือกประเภทกฎ**: 
   - เลือกประเภทการปรับ (ร้อยละลดราคา, จำนวนลดราคา, ตั้งค่าราคา, ฟรี, ร้อยละเพิ่มค่าธรรมเนียม, จำนวนเพิ่มค่าธรรมเนียม)
   - ใส่จำนวนหรือร้อยละ

4. **ตั้งค่าป้ายหยุด** (ตัวเลือก)

### กลยุทธ์ 3: ค่าธรรมเนียมที่ขึ้นอยู่กับเงื่อนไข

รักษารูปแบบ Markdown เดิม รูปภาพ ชื่อไฟล์ บล็อกโค้ด และคำศัพท์ทางเทคนิค

## การแก้ไขปัญหา

**ปัญหา 1: กฎไม่ถูกใช้งาน**

**สาเหตุ**:

- ช่วงเวลาไม่อยู่ในวันที่ถูกต้อง

**วิธีแก้ไข**: ตรวจสอบเงื่อนไขทั้งหมด ตรวจสอบลำดับความสำคัญ และตรวจสอบสถานะการเปิดใช้งาน

**ปัญหา 2: จำนวนส่วนลดไม่คาดคิด**

**สาเหตุ**:

- เปอร์เซ็นต์ถูกนำไปใช้กับราคาที่ลดแล้ว

**วิธีแก้ไข**: ตรวจสอบลำดับความสำคัญ ตรวจสอบค่า flag stop_further_rules และตรวจสอบการดำเนินการด้วยตนเอง

**ปัญหา 3: การจัดส่งฟรีไม่ทำงาน**

- สินค้าที่ถูกยกเว้นอยู่ในตะกร้า

**วิธีแก้ไข**: ใช้ stop_further_rules=Yes บนกฎการจัดส่งฟรี ตรวจสอบเงื่อนไข และตรวจสอบการยกเว้น
