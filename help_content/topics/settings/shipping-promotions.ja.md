---
title: 配送プロモーション
---

配送ルールは、カートの内容、顧客の属性、配達地域に基づいて配送方法のコスト調整を条件付きで適用します。$50以上で無料配送を自動的に提供したり、遠隔地域に追加料金を課与したり、VIP顧客向けに配送を割引したりできます。ルールは優先順位に基づいて実行され（高い優先順位から）、さらなる処理を防ぐためにオプションで停止フラグを使用できます。各ルールは複数の条件（カート価格、重量、地域、商品、顧客グループ）を評価し、すべての条件が一致した場合に6種類の調整のいずれかを実行します。

注文の文脈に基づいて動的な配送コストが必要な場合に配送プロモーションを使用してください。配送方法から静的なレートだけではなく、動的なコストを設定できます。

## 配送プロモーションの種類

配送ルールは6種類のコスト調整を適用します。

### パーセンテージ割引

**機能**: 配送コストをパーセンテージで減らします（例: 25％割引）。

**式**: `new_cost = base_cost × (1 - percent/100)`

**例**:
```
基本コスト: $20
割引: 25％
結果: $15
```

**使用例**:
- VIP顧客割引（すべての配送に20％割引）
- 季節限定プロモーション（12月の配送に15％割引）
- 複数注文割引（5つ以上の商品に10％割引）

---

### 固定割引

**機能**: 配送コストから固定金額を引きます。

**式**: `new_cost = base_cost - amount`（最小$0）

**例**:
```
基本コスト: $15
割引: $5
結果: $10
```

**使用例**:
- 初回顧客ボーナス（初回注文の配送に$5割引）
- ニュースレター登録報酬（配送に$3割引）
- ロイヤルティプログラムの特典（毎月配送に$10割引）

---

### コストの上書き

**機能**: 配送コストを特定の金額に設定します。

**式**: `new_cost = fixed_amount`

**例**:
```
基本コスト: $25
設定: $9.99
結果: $9.99
```

**使用例**:
- フラッシュセール（今日はすべての注文に$5の固定配送）
- カテゴリ別配送（本は常に$3.99の配送）
- 時間ベースのプロモーション（今週は配送を$9.99に上限）

---

### 無料配送

**機能**: 配送コストを$0に設定します。

**式**: `new_cost = $0`


**例**:
```
基本料金: $18
ルール適用
結果: $0
```

**使用例**:
- $50以上で送料無料
- 特定の商品に対する送料無料（プロモーション商品）
- VIP顧客向け送料無料
- 3つ以上の商品を含む注文

---

### 補加料（固定）

**機能**:
送料に固定金額を追加します。

**式**:
`new_cost = base_cost + amount`

**例**:
```
基本料金: $12
補加料: $5
結果: $17
```

**使用例**:
- 遠隔地配達料
- 大型商品の取り扱い料
- 土曜日配達の補加料
- 破損防止包装料

---

### 補加料（百分比）

**機能**:
送料を百分比で増加させます。

**式**:
`new_cost = base_cost × (1 + percent/100)`

**例**:
```
基本料金: $20
補加料: 15%
結果: $23
```

**使用例**:
- 高峰期補加料（休日前は20%）
- 速達配達のプレミアム料（50%補加料）
- 燃料補加料（現在の料金に基づく変動）

---

## プロモーション条件

プロモーションは、**すべての条件が満たされる**必要があります。

### 有効期間

- **開始日**: この日以降にルールが有効になります
- **終了日**: この日以前にルールが有効になります
- **使用例**: 季節限定プロモーション、限定時間オファー

**例**: ブラックフライデー週末のみ送料無料
```
開始: 2026-11-27 00:00
終了: 2026-11-30 23:59
```

---

### カート金額範囲

- **最小カート金額**: カートの小計が金額以上でなければなりません
- **最大カート金額**: カートの小計が金額以下でなければなりません
- **使用例**: 送料無料のしきい値、段階的な割引

**例**: 注文が$50〜$200の場合は送料無料
```
最小: $50
最大: $200
```

---

### カート重量範囲

- **最小重量**: カートの総重量が金額以上でなければなりません
- **最大重量**: カートの総重量が金額以下でなければなりません
- **使用例**: 軽量配送割引、重い商品の補加料

**例**: 20kgを超える注文に$5の補加料
```
最小重量: 20kg
最大重量: null（無制限）
```

---

### 商品数範囲


- **最小商品数**: カートに商品数が ≥ 数量である必要があります
- **最大商品数**: カートに商品数が ≤ 数量である必要があります
- **使用例**: 複数商品割引、単品料金

**例**: 5つ以上の商品で送料無料
```
Min Items: 5
Max Items: null
```

---

### 配送地域

- **地域**: 規則は、顧客の住所が選択された地域の少なくとも1つに一致する場合にのみ適用されます
- **空の選択**: 規則はすべての地域に適用されます
- **使用例**: 地域ごとの追加料金または割引

**例**: 国内地域のみで送料無料
```
Zones: ["Domestic USA"]
```

---

### 配送方法

- **方法**: 規則は特定の配送方法にのみ適用されます
- **空の選択**: 規則はすべての方法に適用されます
- **使用例**: 配送方法ごとのプロモーション

**例**: エクスプレス配送25％割引
```
Methods: ["Express Delivery"]
```

---

### 商品要件

**必要な商品**: カートにこれらの商品の少なくとも1つを含む必要があります

**必要なカテゴリ**: カートにこれらのカテゴリの商品の少なくとも1つを含む必要があります

**使用例**: 特定商品の無料配送、プロモーションバンドル

**例**: カートに「プロモーション商品A」が含まれている場合に無料配送
```
Requires Products: [Product ID 123]
```

---

### 商品除外

**除外商品**: カートにこれらの商品のいずれかを含んでいる場合、規則は適用されません

**除外カテゴリ**: カートにこれらのカテゴリの商品のいずれかを含んでいる場合、規則は適用されません

**使用例**: 重い/大型商品を無料配送から除外

**例**: 家具カテゴリを除いて無料配送
```
Excludes Categories: [Furniture]
```

---

### 顧客グループ

- **顧客グループ**: 規則は選択されたグループ（VIP、卸売など）の顧客にのみ適用されます
- **空の選択**: 規則はすべての顧客グループに適用されます
- **使用例**: VIPの特典、卸売割引

**例**: VIP会員向け15％の送料割引
```
Customer Groups: ["VIP"]
```

---

### 初回顧客


- **初回顧客**: チェックボックスで、過去の注文がない顧客にのみこのルールを適用する
- **使用例**: 新規顧客向けのウェルカムキャンペーン

**例**: 初回注文で送料5ドル割引
```
First Time Customer: Yes
```

---

## プロモーションの優先順位と実行

プロモーションは**優先順位の順序**で実行されます（数値が高いほど先に実行されます）:

### 優先順位のメカニズム

**実行例**:
```
プロモーションA（優先順位100）: カートが50ドル以上の場合無料配送
プロモーションB（優先順位50）: 全ての送料に10％割引
プロモーションC（優先順位1）: 遠隔地域に2ドルの追加料金

カート: 60ドル、遠隔地域
基本送料: 15ドル

ステップ1: プロモーションAを評価（優先順位100）
  カートが50ドル以上？ YES
  適用: コストを0ドルに設定
  コストは現在: 0ドル

ステップ2: プロモーションBを評価（優先順位50）
  0ドルに対して10％割引を適用
  コストは現在: 0ドル（依然として無料）

ステップ3: プロモーションCを評価（優先順位1）
  0ドルに2ドルの追加料金を加算
  コストは現在: 2ドル

最終コスト: 2ドル
```

**他のプロモーションの実行を停止するフラグ**:

プロモーションAが `stop_further_promotions = True` の場合:
```
プロモーションA（優先順位100、stop_further_promotions=True）: カートが50ドル以上の場合無料配送
プロモーションB（優先順位50）: 10％割引
プロモーションC（優先順位1）: 2ドルの追加料金

カート: 60ドル
基本: 15ドル

ステップ1: プロモーションAが適用され、コストを0ドルに設定
        stop_further_promotions = True → 停止

最終コスト: 0ドル（ルールBおよびCは実行されない）
```

## 配送プロモーションの作成

**ステップバイステップワークフロー**:

1. **ルールに移動**
   - 設定 > 配送 > 配送プロモーション
   - 「配送プロモーションを追加」をクリック

2. **基本設定**
   - **名前**: 内部識別子（例: 「50ドル以上で無料配送」）
   - **説明**: 必須でないノート（顧客には表示されません）
   - **有効**: 有効/無効切り替え
   - **優先順位**: 実行順序を設定（100で高優先、1で低優先）

3. **プロモーションタイプの選択**
   - 調整タイプを選択（割引％、固定割引、コスト設定、無料、追加料金％、固定追加料金）
   - 金額または％を入力


4. **停止フラグの設定** (オプション)
   - このルールが下位のプロモーションの実行を防ぐ場合、"さらに進むプロモーションを停止"にチェックを入れます
   - 最終的/絶対的なルールに使用します (例: 無料配送はその後の追加料金が加算されないようになります)

5. **条件の定義** (オプション - 空欄にすると"常に適用"になります)
   - 有効期間: 開始/終了日
   - カート価格: 最小/最大
   - カート重量: 最小/最大
   - アイテム数: 最小/最大
   - ゾーン: 適用可能なゾーンを選択
   - 配送方法: 適用可能な方法を選択
   - 商品: 必要または除外
   - 顧客: グループまたは初回のみ

6. **ルールの保存**
   - 保存をクリック
   - ルールは即座に有効になります (アクティブトグルが"はい"の場合)

## プロモーション組み合わせ戦略

### 戦略 1: 折引の重ね合わせ

**複数の折引を重ね合わせる**:
```
プロモーション A (優先度 100): VIP向け10%割引 → stop_further_promotions=No
プロモーション B (優先度 50): $100以上の注文に15%割引 → stop_further_promotions=No

VIP顧客で$120の注文:
基本: $15
プロモーション A後: $13.50 (10%割引)
プロモーション B後: $11.48 (15%割引 $13.50)
```

### 戦略 2: 排他的なルール

**1つのルールのみが適用される** (最高優先度):
```
プロモーション A (優先度 100): $50以上で無料配送 → stop_further_promotions=Yes
プロモーション B (優先度 50): 全ての配送に20%割引 → stop_further_promotions=Yes
```

カート > $50:
プロモーションAが適用されます → 無料配送 → STOP
プロモーションBは実行されない
```

### 策略3: 条件付き追加料金

**割引を先に、追加料金を最後に**:
```
プロモーションA (優先度100): $75以上で無料配送
プロモーションB (優先度75): VIP顧客15％割引
プロモーションC (優先度50): 一般顧客10％割引
プロモーションD (優先度25): 遠隔地域追加料金$5
プロモーションE (優先度1): 燃料追加料金10％

注文: $80, 遠隔地域, VIP顧客
ベース: $20
A: $80 > $75 → 無料 ($0)
B: VIP → $0の15％割引 = $0
C: $0の10％割引 = $0
D: 遠隔地域 +$5 = $5
E: 燃料 +$5の10％ = $5.50

最終: $5.50 (追加料金のため無料ではない)
```

**これを防ぐには stop_further_promotions=Yes を使用**:
```
プロモーションA (優先度100, stop=Yes): $75以上で無料配送

同じ注文:
A: $80 > $75 → 無料 ($0) → STOP
最終: $0 (本当に無料)
```

## 配送プロモーションのテスト

**本番環境に公開する前**:

1. **テストカートの作成**
   - カートA: $25 (しきい値未満)
   - カートB: $55 (しきい値以上)
   - カートC: $200 + 遠隔地域
   - カートD: VIP顧客

2. **各ルールのテスト**
   - 支払い手続きへ進む
   - 正しい配送費用が表示されているか確認
   - ルールの実行順序を確認

3. **優先度の解決テスト**
   - 複数の一致するルール
   - 最も高い優先度が最初に実行されるか確認
   - stop_further_promotions の動作を確認

4. **エッジケースのテスト**
   - 注文金額がしきい値にちょうど一致
   - 複数の条件が一致
   - 矛盾したルール

## トラブルシューティング

**問題1: プロモーションが適用されない**

**原因**:
- ルールが非アクティブ
- 1つ以上の条件が満たされていない
- 高い優先度のルールで stop_further_promotions=Yes が設定されている
- 有効期限が現在の日付の外側

**解決策**: すべての条件を確認し、優先度を確認し、アクティブ状態を確認してください。

---

**問題2: 予期しない割引額**

**原因**:
- 複数のプロモーションが重複して適用
- パーセンテージが既に割引された費用に適用
- ルールの優先度が誤っている

**解決策**: 優先度順序を確認し、stop_further_promotions フラグを確認し、手動で実行順序をトレースしてください。

---

**問題 3: 無料配送が動作しない**

**原因**:
- 無料配送プロモーションの後に実行される優先度が低いサージチャージルールによりコストが追加されている
- カートの金額が最小値のしきい値に達していない
- カートに除外された商品が含まれている

**解決策**: 無料配送プロモーションで stop_further_promotions=Yes を使用し、条件を確認し、除外事項をチェックする。

---

## ヒント

- **無料配送には高い優先度を設定する** - 優先度 100 は他の調整よりも先に実行される
- **絶対ルールで stop_further_promotions を設定する** - 無料配送は他の処理を停止するべきである
- **ルールの組み合わせをテストする** - 複数のプロモーションが予期せぬように相互作用する可能性がある
- **説明的な名前を使用する** - "VIP 20% Discount (Priority 75)" は "Promotion 3" よりも良い
- **複雑な論理を記録する** - 説明フィールドにノートを追加する
- **シンプルなプロモーションから始める** - 複雑さを段階的に追加する
- **ルールのパフォーマンスを監視する** - ルールが使用されているか、混乱を引き起こしているかを確認する
- **過剰なプロモーションを避ける** - プロモーションが多すぎるとチェックアウトが遅くなる。最大で 5〜10 個を使用する
- **地理用にゾーンを使用する** - 国ごとに複数の類似ルールよりもゾーンを使用する方が良い
- **メソッドと組み合わせる** - ルール + メソッドは複雑な価格設定に協力する
- **明確な時間枠を設定する** - プロモーションには常に終了日を含める
