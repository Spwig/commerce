title: POSシステム概要
---

Spwig POSシステムは、現代的なレジ端末を備えた完全な小売ソリューションに店舗を変貌させます。これはすべてのエディション（コミュニティ、プロ、エンタープライズ）に含まれており、追加料金なしで無制限の場所にわたる無制限の端末を使用できます。各端末は、オフラインで動作し、自動同期し、在庫、顧客データ、支払い処理とシームレスに統合されるプログレッシブ・ウェブ・アプリ（PWA）です。管理はadminダッシュボードからすべて行えます—端末の設定、シフトの調整、レシートのカスタマイズ、ハードウェアの統合。

物理的な小売店舗、ポップアップショップ、展示会、またはオンラインではなく現地で購入する環境がある場合にPOSシステムを使用してください。

![POSダッシュボード](/static/core/admin/img/help/pos-system-overview/dashboard.webp)

## Spwig POSとは？

Spwig POSは、オンラインと物理的な場所の両方で商品を販売する商人向けに設計された完全に統合されたレジシステムです。第三者のPOSシステムとは異なり、複雑な統合を必要としません。Spwig POSは、あなたのプラットフォームに直接構築されており、すべての販売チャネルにわたる完璧なデータ同期を保証します。

**主な特徴**:
- **無制限の端末** - 追加料金なしで必要に応じて端末を任意の数だけ展開できます
- **オフライン優先アーキテクチャ** - インターネット接続が失われた場合でも販売処理を継続できます
- **プログレッシブ・ウェブ・アプリ** - アプリストアのインストールは不要です。任意のデバイス（タブレット、コンピュータ、専用端末）のブラウザからアクセスできます
- **リアルタイム在庫同期** - 在庫予約（15分TTL）により、チャネル間の過剰販売を防止します
- **分割支払いサポート** - 1つの取引で複数の支払い方法（現金＋カード＋ギフトカード）を受け入れます
- **ハードウェア統合** - ESC/POS熱量プリンタ、バーコードスキャナ、レジキャッシュボックス、顧客ディスプレイ
- **シフト管理** - 開店/閉店時の現金の確認と差額の追跡
- **マルチロケーション対応** - フランチャイズや地域管理用の設定を継承するストアグループ

## エディション

POSは、Spwig 1.5.8から、Community、Pro、EnterpriseのすべてのSpwigエディションに含まれています。

個別のPOSライセンスはなく、アクティベーション手順もなく、端末ごとの料金もありません。

**すべてのエディションに含まれるもの**:
- 無制限の端末登録
- 無制限のスタッフ割り当て
- すべてのPOS機能（シフト、現金管理、レシートのカスタマイズ、顧客ディスプレイ）
- 支払いプロバイダーの統合（Stripe Terminalおよび他のサポートされているプロバイダー）
- ハードウェア統合のサポート

Spwigホストされたストアを実行している店舗や、Pro/Enterpriseライセンスを支払っている店舗は、オプションのSpwigホストされたサービス（GeoIP、ジオコーダー、プッシュ通知）の上限が高くなり、優先サポートが提供されますが、POS機能自体はすべてのエディションで同じです。

## システムアーキテクチャ

**フロントエンド** - React 18プログレッシブウェブアプリ:
- オフラインファーストで、Service Workerによるキャッシュ（インターネット接続なしでも動作）
- ファストロード用のViteビルドシステム
- CSS Modules + デザイントークン（ストアテーマと一致）
- ローカルデータ永続化用のIndexedDB
- 10のサポートされている言語（英語、中国語簡体字/繁体字、フランス語、ドイツ語、スペイン語、ポルトガル語、日本語、ロシア語、アラビア語）

**バックエンド** - バックエンド統合:
- 13のPOSモデル（POSTerminal、POSShift、CashMovement、ReceiptTemplate、PromoSlideなど）
- 端末操作用の43以上のREST APIエンドポイント
- TTL管理付き在庫予約システム
- 背景同期用のCeleryタスク
- 支払いプロバイダー用の暗号化された資格情報ストレージ

**セキュリティ**:
- 端末ペアリングは8文字のコードで（サーバー側で生成され、使用後に期限切れ）
- スタッフ割り当ては、どのユーザーがどの端末にアクセスできるかを制御
- 管理者緊急時のリモートロック/アンロック機能
- 暗号化された支払いプロバイダー資格情報
- バイオメトリックアンロックサポート付きセッションベースの認証（ブラウザ依存）

## 初回POS端末の展開ワークフロー

最初のPOS端末を展開するために、以下の4つのステップに従ってください。

POSを開始するための完全なステップバイステップのチェックリスト（スタッフの設定、支払いプロバイダー、最初の販売の実行を含む）については、[POSでの開始](getting-started-with-pos)を参照してください。

**ステップ1: 倉庫の作成**
- **カタログ > 倉庫**に移動
- あなたの小売店舗を表す倉庫を作成
- 住所と連絡先情報を設定
- この倉庫はPOS販売の物理在庫を追跡します

**ステップ2: 端末の登録**
- **POS > 端末**に移動
- **+ 端末の追加**をクリック
- 端末名を設定（例: "メインレジ", "チェックアウト1"）
- ステップ2で設定した倉庫を割り当て
- ハードウェア設定を構成（プリンタ、スキャナ、現金引き出しなど）
- 保存して8桁のペアリングコードを生成

**ステップ3: スタッフの割り当て**
- 端末設定で、**割り当てられたユーザー**にスクロール
- この端末を使用を許可されたスタッフを選択
- 割り当てられたユーザーのみが端末にログインできます
- ユーザーはスタッフロールに適切なPOS権限を持っている必要があります

**ステップ4: デバイスのペアリング**
- あなたの端末デバイス（タブレット/コンピュータ）で、`/pos/` URLにアクセス
- ステップ3から取得した8桁のペアリングコードを入力
- 端末が設定をダウンロードし、初期データを同期
- 割り当てられたスタッフの資格情報を使用してログイン
- 端末は販売準備が整いました

ペアリング後、端末は5分ごとに自動的に同期されます（設定可能です）。インターネット接続が不可の場合は、オフラインモードで継続して操作が可能で、接続が復帰すると販売が自動的に同期されます。

## コアPOS機能

**販売処理**:
- 名前、SKU、またはバーコードで商品を検索
- 複数の支払い方法（1注文あたり）
- 保留中のカート（未完了の取引を保存）
- 理由の追跡付きの返金とキャンセル
- チケットの適用（クーポン、ギフトカード、プロモーション）
- 顧客の検索とロイヤルティポイントの利用

**現金管理**:
- シフト開始時に初期現金を数える
- シフト終了時に予想と実際の金額を照合する
- 現金の動き（浮動金の追加、小切手の引き出しと理由）
- 現金売上の基づく自動予想現金計算
- 紛失の追跡と報告

**ハードウェア統合**:
- ESC/POS熱伝票プリンタ（ネットワークまたはシリアル）
- USBバーコードスキャナ
- プリンタパルスによるキャッシュドロワートリガー
- 顧客向けディスプレイ（アイドル時にプロモーションカルーセル）
- Stripe Terminalカードリーダー（S700, WisePOS E, P400）

**オフライン機能**:
- Service Workerがすべての端末アセットをキャッシュ
- IndexedDBが最近の注文を保存（設定可能：7〜30日、200〜1000注文）
- 15分のTTLを持つ在庫予約で過剰販売を防止
- 接続が復帰したときに同期するための注文キュー
- 自動再接続検出

## POS管理画面

これらの管理画面にアクセスして、POSデプロイメントのすべての側面を管理してください:

**POSダッシュボード** (`/admin/pos/`)
- システム概要とクイック統計
- 最近の端末アクティビティ
- アクティブなシフトの概要
- ホストされたサービスの使用状況タイル（GeoIP、ジオコーダー、プッシュ — [Spwigホストされたサービス](hosted-services)を参照）

**端末管理** (`/admin/pos_app/posterminal/`)
- 端末を登録して構成
- スタッフと倉庫を割り当て
- オンライン/オフライン状態を監視（ハートビート追跡）
- リモートで端末をアンロック
- [詳しくはこちら: POS端末の管理](managing-pos-terminals)

**シフト管理** (`/admin/pos_app/posshift/`)
- すべてのシフトを表示（オープン、クローズド、履歴）
- 現金照合レポートを確認
- 現金の動きと不一致を追跡
- シフトアクティビティを監査
- [詳しくはこちら: POSシフトと現金管理](pos-shifts-cash-management)

**ストアグループ** (`/admin/pos_app/storegroup/`)
- 位置/地域ごとに端末を整理
- グループレベルの設定を構成（通貨、言語、タイムゾーン）
- 設定の継承階層を実装
- [詳しくはこちら: POSストアグループ](pos-store-groups)

**レシートテンプレート** (`/admin/pos_app/receipttemplate/`)
- 印刷用レシートをカスタマイズ（紙の幅、ロゴ、ヘッダー/フッター）
- 合法性フィールドを構成（税ID、事業許可）
- プロモーション用のQRコードを追加
- テンプレートを特定の店舗またはグループに限定
- [詳しくはこちら: レシートテンプレートのカスタマイズ](receipt-template-customization)

**プロモーションスライド** (`/admin/pos_app/promoslide/`)
- 顧客向けディスプレイのスライドコンテンツを作成
- スライドを特定の店舗またはグループにターゲット
- 季節限定プロモーションをスケジュール
- [詳しくはこちら: 顧客ディスプレイ用プロモーションスライド](customer-display-promo-slides)

**支払いプロバイダ** (`/admin/pos_app/posterminalprovider/`)
- Stripe Terminalの統合を構成
- 支払いプロバイダの資格情報を管理
- 接続状態を監視
- [詳しくはこちら: 支払い端末プロバイダ](payment-terminal-providers)

**カードリーダー** (`/admin/pos_app/posterminalreader/`)
- 物理的なカードリーダーを登録
- リーダーを端末に割り当て
- スプラッシュ画面をカスタマイズ（顧客向けディスプレイのブランド）
- リーダーの状態を監視（オンライン/オフライン/ビジー）
- [詳しくはこちら: カードリーダー管理](card-reader-management)

## マルチロケーション展開

複数の小売店舗を持つ事業主向けに、Spwig POSは階層的な設定の継承をサポートしています:

**設定階層**（優先度が高い順）:
1. 端末固有の設定（すべてを上書き）
2. 店舗固有の設定（グループおよびサイトを上書き）
3. グループ設定（サイトのデフォルトを上書き）
4. サイトデフォルト（すべての設定のフォールバック）

グループレベルで共有設定を構成し（例: 地域通貨、言語）、必要に応じて特定の店舗または端末で上書きしてください。詳細な構成ガイドについては、[POS店舗グループ](pos-store-groups)を参照してください。

## ヒント

すべてのマークダウンフォーマット、画像パス、コードブロック、および技術用語を保持してください。

- **1つの端末から開始する** - フレート全体への展開前に、1つの端末でPOSのセットアップとワークフローをテストする
- **ペアリング前に倉庫を割り当てる** - 倉庫の割り当てがないと端末は販売を処理できない
- **レシートテンプレートを早期に設定する** - 税IDなどのコンプライアンスフィールドは地域によって異なり、本番運用開始前に設定する必要がある
- **オフラインモードをテストする** - インターネットを切断し、販売が継続することを確認し、再接続時に同期が確認されるかを確認する
- **マルチロケーション用にストアグループを使用する** - フランチャイズまたは地域展開の構成管理を簡素化する
- **ハートビート状態を監視する** - 端末は5分ごとにサーバーにパングして、オフラインの端末は管理ダッシュボードに表示される
- **パフォーマンス用に同期制限を設定する** - 接続速度が遅い端末は、sync_days/sync_limitの設定を低くすることで恩恵を受ける
- **ハードウェア構成をバックアップする** - プリンタのIPアドレス、スキャナの設定、現金引き出しへの構成を災害復旧用に記録する
