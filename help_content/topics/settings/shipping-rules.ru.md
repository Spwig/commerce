title: Правила доставки
---

Правила доставки применяют условные корректировки стоимости доставки на основе содержимого корзины, атрибутов клиента и зон доставки — автоматически предлагать бесплатную доставку при сумме заказа свыше 50 долларов, добавлять доплаты за удаленные районы или снижать стоимость доставки для VIP-клиентов. Правила используют приоритетное выполнение (сначала высокий приоритет) с необязательными флагами остановки для предотвращения дальнейшей обработки. Каждое правило оценивает несколько условий (стоимость корзины, вес, зоны, товары, группы клиентов) и выполняет один из 6 типов корректировок, когда все условия совпадают.

Используйте правила доставки, когда вам нужны динамические тарифы на доставку, которые меняются в зависимости от контекста заказа, а не только статические ставки из методов доставки.

## Типы правил доставки

Правила доставки применяют 6 типов корректировок стоимости:

### Процентная скидка

**Что это делает**: Уменьшает стоимость доставки на процент (например, 25% скидки).

**Формула**: `new_cost = base_cost × (1 - percent/100)`

**Пример**:
```
Базовая стоимость: $20
Скидка: 25%
Результат: $15
```

**Сценарии использования**:
- Скидка для VIP-клиентов (20% скидки на все доставки)
- Сезонные акции (15% скидки на доставку в декабре)
- Скидка на крупные заказы (10% скидки на доставку для 5+ товаров)

---

### Фиксированная скидка

**Что это делает**: Вычитает фиксированную сумму из стоимости доставки.

**Формула**: `new_cost = base_cost - amount` (минимум $0)

**Пример**:
```
Базовая стоимость: $15
Скидка: $5
Результат: $10
```

**Сценарии использования**:
- Бонус для новых клиентов ($5 скидки на доставку первого заказа)
- Награда за регистрацию на рассылку ($3 скидки на доставку)
- Преимущество программы лояльности ($10 скидки на доставку в месяц)

---

### Установленная стоимость

**Что это делает**: Заменяет стоимость доставки на конкретную сумму.

**Формула**: `new_cost = fixed_amount`

**Пример**:
```
Базовая стоимость: $25
Установить на: $9.99
Результат: $9.99
```

**Сценарии использования**:
- Быстрая распродажа (фиксированная стоимость доставки $5 для всех заказов в этот день)
- Специфичная стоимость доставки по категориям (всегда $3.99 доставка для книг)
- Временные акции (доставка ограничена $9.99 на эту неделю)

---

### Бесплатная доставка

**Что это делает**: Устанавливает стоимость доставки равной $0.

**Формула**: `new_cost = $0`

**Пример**:
```
Базовая стоимость: $18
Правило применяется
Результат: $0
```

**Сценарии использования**:
- Бесплатная доставка при сумме заказа свыше 50 долларов
- Бесплатная доставка для определенных товаров (рекламные товары)
- Бесплатная доставка для VIP-клиентов
- Бесплатная доставка для заказов с 3+ товарами

---

### Доплата (фиксированная)

**Что это делает**: Добавляет фиксированную сумму к стоимости доставки.

**Формула**: `new_cost = base_cost + amount`

**Пример**:
```
Базовая стоимость: $12
Доплата: $5
Результат: $17
```

**Сценарии использования**:
- Доплата за доставку в отдаленные районы
- Обработка крупногабаритных товаров
- Доплата за субботнюю доставку
- Пакетирование хрупких товаров

---

### Доплата (процентная)

**Что это делает**: Увеличивает стоимость доставки на процент.

**Формула**: `new_cost = base_cost × (1 + percent/100)`

**Пример**:
```
Базовая стоимость: $20
Доплата: 15%
Результат: $23
```

**Сценарии использования**:
- Доплата за сезон (20% в праздничный период)
- Доплата за экспресс-доставку (50% надбавка)
- Доплата за топливо (переменная в зависимости от текущих тарифов)

## Условия правил

Правила оценивают **ВСЕ условия должны быть выполнены**, чтобы правило применялось:

### Временная действительность

- **Дата начала**: Правило активно только после этой даты
- **Дата окончания**: Правило активно только до этой даты
- **Сценарий использования**: Сезонные акции, ограниченные предложения

**Пример**: Бесплатная доставка в выходные праздника Хэллоуина только
```
Начало: 2026-11-27 00:00
Окончание: 2026-11-30 23:59
```

---

### Диапазон стоимости корзины

- **Минимальная стоимость корзины**: Сумма корзины должна быть ≥ сумма
- **Максимальная стоимость корзины**: Сумма корзины должна быть ≤ сумма
- **Сценарий использования**: Пороги бесплатной доставки, многоуровневые скидки

**Пример**: Бесплатная доставка для заказов от $50 до $200
```
Мин: $50
Макс: $200
```

---

### Диапазон веса корзины

- **Минимальный вес**: Общий вес корзины должен быть ≥ сумма
- **Максимальный вес**: Общий вес корзины должен быть ≤ сумма
- **Сценарий использования**: Скидки на легкие посылки, доплаты за тяжелые товары

**Пример**: Доплата $5 за заказы свыше 20 кг
```
Минимальный вес: 20 кг
Максимальный вес: null (неограниченно)
```

---

### Диапазон количества товаров


- **Минимальное количество товаров**: Корзина должна содержать ≥ количество товаров
- **Максимальное количество товаров**: Корзина должна содержать ≤ количество товаров
- **Случай использования**: Скидки на оптовые заказы, сборы за один товар

**Пример**: Бесплатная доставка для 5+ товаров
```
Мин. товаров: 5
Макс. товаров: null
```


### Зона доставки

- **Зоны**: Правило применяется только в том случае, если адрес клиента совпадает с хотя бы одной выбранной зоной
- **Пустой выбор**: Правило применяется ко всем зонам
- **Случай использования**: Доплаты или скидки по зонам

**Пример**: Бесплатная доставка только для зоны "Внутренние США"
```
Зоны: ["Внутренние США"]
```


### Способ доставки

- **Методы**: Правило применяется только к определенным способам доставки
- **Пустой выбор**: Правило применяется ко всем методам
- **Случай использования**: Промо-акции по методам

**Пример**: 25% скидки на экспресс-доставку
```
Методы: ["Экспресс-доставка"]
```


### Требования к товарам

**Требуемые товары**: В корзине должно быть хотя бы один из этих товаров

**Требуемые категории**: В корзине должно быть хотя бы одно изделие из этих категорий

**Случай использования**: Бесплатная доставка по товарам, подарочные наборы

**Пример**: Бесплатная доставка, когда корзина содержит "Товар со скидкой A"
```
Требуемые товары: [Идентификатор товара 123]
```


### Исключения по товарам

**Исключаемые товары**: Правило не применяется, если корзина содержит любой из этих товаров

**Исключаемые категории**: Правило не применяется, если корзина содержит изделия из этих категорий

**Случай использования**: Исключение тяжелых/крупногабаритных товаров из бесплатной доставки

**Пример**: Бесплатная доставка, за исключением категории "Мебель"
```
Исключаемые категории: ["Мебель"]
```


### Группы клиентов

- **Группы клиентов**: Правило применяется только к клиентам, входящим в выбранные группы (VIP, оптовые покупатели и т.д.)
- **Пустой выбор**: Правило применяется ко всем группам клиентов
- **Случай использования**: Преимущества для VIP, оптовые скидки

**Пример**: 15% скидки по доставке для членов VIP
```
Группы клиентов: ["VIP"]
```


### Первый заказ клиента

- **Клиент впервые**: Переключатель для ограничения правилами клиентов, у которых еще не было предыдущих заказов
- **Случай использования**: Предложения для новых клиентов

**Пример**: $5 скидки по доставке для первого заказа
```
Клиент впервые: Да
```


## Приоритет правил и выполнение

Правила выполняются в **порядке приоритета** (большее число = раньше выполнение):

### Механика приоритета

**Пример выполнения**:
```
Правило A (Приоритет 100): Бесплатная доставка, если сумма корзины > $50
Правило B (Приоритет 50): 10% скидки на все доставки
Правило C (Приоритет 1): $2 доплата за удаленные зоны

Корзина: $60, Удаленная зона
Базовая стоимость доставки: $15

Шаг 1: Оценивается правило A (Приоритет 100)
  Сумма корзины > $50? ДА
  Применить: Установить стоимость на $0
  Стоимость теперь: $0

Шаг 2: Оценивается правило B (Приоритет 50)
  Применить 10% скидки к $0
  Стоимость теперь: $0 (по-прежнему бесплатная)

Шаг 3: Оценивается правило C (Приоритет 1)
  Добавить $2 доплаты к $0
  Стоимость теперь: $2

Итоговая стоимость: $2
```

**Флаг "Остановить дальнейшие правила":

Если у правила A установлено `stop_further_rules = True`:
```
Правило A (Приоритет 100, stop_further_rules=True): Бесплатная доставка, если сумма корзины > $50
Правило B (Приоритет 50): 10% скидки на все доставки
Правило C (Приоритет 1): $2 доплаты за удаленные зоны

Корзина: $60
Базовая стоимость: $15

Шаг 1: Применяется правило A, устанавливает стоимость на $0
        stop_further_rules = True → ОСТАНОВИТЬ

Итоговая стоимость: $0 (Правила B и C никогда не выполняются)
```


## Создание правил доставки

**Пошаговый процесс**:

1. **Перейдите в Правила**
   - Настройки > Доставка > Правила доставки
   - Нажмите "Добавить правило доставки"

2. **Базовая настройка**
   - **Название**: Внутренний идентификатор (например, "Бесплатная доставка при сумме > $50")
   - **Описание**: Опциональные примечания (не отображаются клиентам)
   - **Активно**: Переключатель для включения/отключения
   - **Приоритет**: Установите порядок выполнения (100 для высокого приоритета, 1 для низкого)

3. **Выберите тип правила**
   - Выберите тип корректировки (процент скидки, фиксированная скидка, установить стоимость, бесплатная, процент доплаты, фиксированная доплата)
   - Введите сумму или процент

4. **Установите флаг остановки** (Опционально)
   - Отметьте "Остановить дальнейшие правила", если это правило должно запретить выполнение правил с более низким приоритетом
   - Используйте для финальных/абсолютных правил (например, бесплатная доставка не должна иметь доплат после скидок)

5. **Определите условия** (опционально - оставьте пустым для «всегда применяется»)
  - Временная действительность: Даты начала/окончания
  - Сумма корзины: Минимум/максимум
  - Вес корзины: Минимум/максимум
  - Количество товаров: Минимум/максимум
  - Зоны: Выберите подходящие зоны
  - Методы: Выберите подходящие методы
  - Товары: Необходимые или исключенные
  - Клиенты: Группы или только новые

6. **Сохранить правило**
  - Нажмите Сохранить
  - Правило становится активным немедленно (если переключатель активен - Да)

## Стратегии комбинации правил

### Стратегия 1: Накопление скидок

**Разрешить накопление нескольких скидок**:
```
Правило A (Приоритет 100): 10% скидки для VIP → stop_further_rules=Нет
Правило B (Приоритет 50): 15% скидки на заказы >$100 → stop_further_rules=Нет

VIP-клиент с заказом на $120:
Базовая сумма: $15
После правила A: $13.50 (10% скидки)
После правила B: $11.48 (15% скидки от $13.50)
```


### Стратегия 2: Исключающие правила

**Действует только одно правило** (наивысший приоритет):
```
Правило A (Приоритет 100): Бесплатная доставка >$50 → stop_further_rules=Да
Правило B (Приоритет 50): 20% скидки на все доставки → stop_further_rules=Да

Корзина > $50:
Правило A применяется → Бесплатная доставка → ОСТАНОВИТЬ
Правило B никогда не выполняется
```


### Стратегия 3: Условные доплаты

**Скидки сначала, доплаты потом**:
```
Правило A (Приоритет 100): Бесплатная доставка >$75
Правило B (Приоритет 75): 15% скидки для VIP
Правило C (Приоритет 50): 10% общая скидка
Правило D (Приоритет 25): $5 доплата за отдаленные зоны
Правило E (Приоритет 1): 10% топливная доплата

Заказ: $80, отдаленная зона, VIP-клиент
Базовая сумма: $20
A: $80 > $75 → Бесплатно ($0)
B: VIP → 15% скидки от $0 = $0
C: 10% скидки от $0 = $0
D: Отдаленная зона +$5 = $5
E: Топливо +10% от $5 = $5.50
```


Preserve all markdown formatting, image paths, code blocks, and technical terms.

Итого: 5,50 $ (не бесплатно из-за дополнительных сборов)
```

**Чтобы этого избежать, используйте stop_further_rules=Да**:
```
Правило A (Приоритет 100, stop=Да): Бесплатная доставка > 75 $

Тот же заказ:
A: 80 $ > 75 $ → Бесплатно ($0) → ОСТАНОВИТЬСЯ
Итого: 0 $ (на самом деле бесплатно)
```

## Тестирование правил доставки

**Перед запуском в эксплуатацию**:

1. **Создайте тестовые корзины**
   - Корзина A: 25 $ (ниже порогового значения)
   - Корзина B: 55 $ (выше порогового значения)
   - Корзина C: 200 $ + Далекая зона
   - Корзина D: VIP-клиент

2. **Проверьте каждое правило**
   - Перейдите к оформлению заказа
   - Убедитесь, что отображается правильная стоимость доставки
   - Проверьте порядок выполнения правил

3. **Проверьте разрешение приоритетов**
   - Несколько соответствующих правил
   - Убедитесь, что выполняется правило с наивысшим приоритетом
   - Проверьте поведение stop_further_rules

4. **Проверьте крайние случаи**
   - Сумма корзины точно на уровне порога
   - Несколько условий, соответствующих правилу
   - Противоречивые правила

## Устранение неполадок

**Проблема 1: Правило не применяется**

**Причины**:
- Правило неактивно
- Одно или несколько условий не выполнены
- Правило с более высоким приоритетом установлено stop_further_rules=Да
- Время действия вне текущей даты

**Решение**: Проверьте все условия, проверьте приоритет, убедитесь, что статус активен.

---

**Проблема 2: Неожиданная сумма скидки**

**Причины**:
- Несколько правил накладываются друг на друга
- Процент применяется к уже со скидкой стоимости
- Неправильный приоритет правила

**Решение**: Проверьте порядок приоритетов, проверьте флаги stop_further_rules, пройдите путь выполнения вручную.

---

**Проблема 3: Бесплатная доставка не работает**

**Причины**:
- Правило с меньшим приоритетом добавляет стоимость после правила бесплатной доставки
- Корзина не соответствует минимальному порогу
- В корзине находятся исключенные товары

**Решение**: Используйте stop_further_rules=Да для правила бесплатной доставки, проверьте условия, проверьте исключения.

## Советы

- **Используйте высокий приоритет для бесплатной доставки** - Приоритет 100 гарантирует, что он выполнится перед другими корректировками
- **Установите stop_further_rules для абсолютных правил** - Бесплатная доставка должна остановить дальнейшую обработку
- **Проверьте комбинации правил** - Несколько правил могут неожиданно взаимодействовать
- **Используйте описательные названия** - «VIP-скидка 20% (Приоритет 75)» лучше, чем «Правило 3»
- **Документируйте сложную логику** - Добавьте примечания в поле описания
- **Начните с простых правил** - Добавляйте сложность постепенно
- **Мониторьте эффективность правил** - Проверьте, используются ли правила или вызывают ли они путаницу
- **Избегайте избыточного количества правил** - Слишком много правил замедляет оформление заказа, используйте максимум 5-10
- **Используйте зоны для географии** - Лучше, чем несколько похожих правил на страну
- **Объединяйте с методами** - Правила + Методы работают вместе для сложных цен
- **Установите четкие временные окна** - Всегда включайте даты окончания для акций
- **Проверьте крайние случаи** - Точная сумма 50 $, ровно 5 предметов и т.д.
