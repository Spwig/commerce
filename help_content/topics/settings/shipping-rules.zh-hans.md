---
title: 配送规则
---

配送规则根据购物车内容、客户属性和配送区域对配送方式应用条件成本调整——在订单金额超过50美元时自动提供免费配送，对偏远地区收取附加费，或对VIP客户减免配送费用。规则使用基于优先级的执行（优先级高的先执行），并带有可选的停止标志以防止进一步处理。每个规则评估多个条件（购物车价值、重量、区域、产品、客户组）并在所有条件匹配时执行6种调整类型之一。

在需要根据订单上下文动态调整配送费用时使用配送规则，而不是仅从配送方式获取静态费率。

## 配送规则类型

配送规则应用6种成本调整类型：

### 百分比折扣

**它做什么**: 以百分比减少配送费用（例如，25% 折扣）。

**公式**: `new_cost = base_cost × (1 - percent/100)`

**示例**:
```
基础费用: $20
折扣: 25%
结果: $15
```

**使用案例**:
- VIP客户折扣（所有配送20% off）
- 节日促销（12月配送15% off）
- 批量订单折扣（5+件商品配送10% off）

---

### 固定折扣

**它做什么**: 从配送费用中减去固定金额。

**公式**: `new_cost = base_cost - amount`（最低 $0）

**示例**:
```
基础费用: $15
折扣: $5
结果: $10
```

**使用案例**:
- 首次客户奖励（首次订单配送$5 off）
- 通讯订阅奖励（配送$3 off）
- 忠诚计划福利（每月配送$10 off）

---

### 设置费用

**它做什么**: 将配送费用覆盖为特定金额。

**公式**: `new_cost = fixed_amount`

**示例**:
```
基础费用: $25
设置为: $9.99
结果: $9.99
```

**使用案例**:
- 闪购（所有订单今天flat $5配送）
- 类别特定配送（书籍始终$3.99配送）
- 时间基于促销（本周配送上限$9.99）

---

### 免费配送

**它做什么**: 将配送费用设为$0。

**公式**: `new_cost = $0`

**示例**:
```
基础费用: $18
规则适用
结果: $0
```

**使用案例**:
- 订单满$50免运费
- 特定商品免运费（促销商品）
- VIP客户免运费
- 订单包含3件以上商品免运费


### 加收费用（固定金额）

**作用**: 将固定金额添加到运费中。

**公式**: `new_cost = base_cost + amount`

**示例**:
```
基础费用: $12
加收费用: $5
结果: $17
```

**使用案例**:
- 远程地区配送费
- 超大件处理费
- 周六配送附加费
- 易碎品包装费


### 加收费用（百分比）

**作用**: 按照百分比增加运费。

**公式**: `new_cost = base_cost × (1 + percent/100)`

**示例**:
```
基础费用: $20
加收费用: 15%
结果: $23
```

**使用案例**:
- 高峰季节附加费（节假日20%）
- 快速配送溢价（50%附加费）
- 燃料附加费（根据当前费率变动）


## 规则条件

规则评估 **所有条件必须满足** 才能应用规则:

### 时间有效性

- **开始日期**: 该日期之后规则才生效
- **结束日期**: 该日期之前规则才生效
- **使用案例**: 季节性促销，限时优惠

**示例**: 仅限黑色星期五周末免运费
```
开始: 2026-11-27 00:00
结束: 2026-11-30 23:59
```


### 购物车金额范围

- **最小购物车金额**: 购物车小计 ≥ 金额
- **最大购物车金额**: 购物车小计 ≤ 金额
- **使用案例**: 免运费门槛，分层折扣

**示例**: 订单金额$50-$200免运费
```
最小: $50
最大: $200
```


### 购物车重量范围

- **最小重量**: 购物车总重量 ≥ 金额
- **最大重量**: 购物车总重量 ≤ 金额
- **使用案例**: 轻量级运输折扣，重物附加费

**示例**: 超过20kg订单收取$5附加费
```
最小重量: 20kg
最大重量: null（无限）
```


### 商品数量范围

- **最小商品数量**: 购物车必须有 ≥ 数量的商品
- **最大商品数量**: 购物车必须有 ≤ 数量的商品
- **使用场景**: 批量订单折扣，单件商品费用

**示例**: 5件以上商品免运费
```
最小商品数量: 5
最大商品数量: null
```

### 运输区域

- **区域**: 仅当客户地址匹配至少一个所选区域时适用该规则
- **未选择任何选项**: 该规则适用于所有区域
- **使用场景**: 区域特定的附加费或折扣

**示例**: 仅限国内区域的免运费
```
区域: ["国内美国"]
```

### 运输方式

- **运输方式**: 仅适用于特定运输方式
- **未选择任何选项**: 该规则适用于所有方式
- **使用场景**: 方式特定的促销

**示例**: 快递运输85折
```
运输方式: ["快递配送"]
```

### 商品要求

**需要商品**: 购物车必须包含至少一个这些商品

**需要分类**: 购物车必须包含至少一个这些分类中的商品

**使用场景**: 商品特定的免运费，促销套装

**示例**: 购物车包含"促销商品A"时免运费
```
需要商品: [商品ID 123]
```

### 商品排除

**排除商品**: 如果购物车包含任何这些商品，该规则不适用

**排除分类**: 如果购物车包含这些分类中的任何商品，该规则不适用

**使用场景**: 排除重型/大件商品的免运费

**示例**: 除家具分类外其他商品免运费
```
排除分类: ["家具"]
```

### 客户组

- **客户组**: 仅适用于所选组的客户（VIP，批发等）
- **未选择任何选项**: 该规则适用于所有客户组
- **使用场景**: VIP福利，批发折扣

**示例**: VIP会员享受15%运输折扣
```
客户组: ["VIP"]
```

### 首次购买客户

- **First Time Customer**: Toggle to restrict rule to customers with no previous orders
- **Use Case**: New customer welcome offers

**Example**: $5 off shipping for first order
```
First Time Customer: Yes
```


## Rule Priority & Execution

Rules execute in **priority order** (higher number = earlier execution):

### Priority Mechanics

**Example Execution**:
```
Rule A (Priority 100): Free shipping if cart > $50
Rule B (Priority 50): 10% discount on all shipping
Rule C (Priority 1): $2 surcharge for remote zones

Cart: $60, Remote zone
Base shipping cost: $15

Step 1: Rule A evaluates (Priority 100)
  Cart > $50? YES
  Apply: Set cost to $0
  Cost now: $0

Step 2: Rule B evaluates (Priority 50)
  Apply 10% discount to $0
  Cost now: $0 (still free)

Step 3: Rule C evaluates (Priority 1)
  Add $2 surcharge to $0
  Cost now: $2

Final cost: $2
```

**Stop Further Rules Flag**:

If Rule A has `stop_further_rules = True`:
```
Rule A (Priority 100, stop_further_rules=True): Free shipping if cart > $50
Rule B (Priority 50): 10% discount
Rule C (Priority 1): $2 surcharge

Cart: $60
Base: $15

Step 1: Rule A applies, sets cost to $0
        stop_further_rules = True → STOP

Final cost: $0 (Rules B and C never execute)
```


## Creating Shipping Rules

**Step-by-Step Workflow**:

1. **Navigate to Rules**
   - Settings > Shipping > Shipping Rules
   - Click "Add Shipping Rule"

2. **Basic Configuration**
   - **Name**: Internal identifier (e.g., "Free Shipping Over $50")
   - **Description**: Optional notes (not shown to customers)
   - **Active**: Toggle to enable/disable
   - **Priority**: Set execution order (100 for high priority, 1 for low)

3. **Choose Rule Type**
   - Select adjustment type (discount %, discount fixed, set cost, free, surcharge %, surcharge fixed)
   - Enter amount or percentage

4. **设置停止标志**（可选）
  - 如果此规则应阻止低优先级规则的执行，请勾选“阻止后续规则”
  - 用于最终/绝对规则（例如，免费配送不应在之后添加附加费）

5. **定义条件**（可选 - 留空表示“始终应用”）
  - 时间有效性：开始/结束日期
  - 购物车价值：最小/最大值
  - 购物车重量：最小/最大值
  - 商品数量：最小/最大值
  - 区域：选择适用的区域
  - 运输方式：选择适用的方式
  - 商品：必需或排除的商品
  - 客户端：群组或仅首次购买

6. **保存规则**
  - 点击保存
  - 规则立即生效（如果启用切换为是）


## 常见的运输规则场景

### 场景 1：满 50 美元免运费

**目标**：当购物车小计 ≥ 50 美元时提供免运费。

**配置**：
```
名称: 满 50 美元免运费
类型: 免运费
优先级: 100
条件:
  最低购物车价值: 50 美元
阻止后续规则: 是
```


### 场景 2：偏远地区附加费

**目标**：对偏远地区配送收取 10 美元附加费。

**配置**：
```
名称: 偏远地区附加费
类型: 附加费（固定）
金额: 10 美元
优先级: 50
条件:
  区域: ["偏远地区"]
阻止后续规则: 否
```


### 场景 3：VIP 客户 20% 折扣

**目标**：VIP 客户可享受所有运输的 20% 折扣。

**配置**：
```
名称: VIP 运输折扣
类型: 折扣（百分比）
百分比: 20
优先级: 75
条件:
  客户端群组: ["VIP"]
阻止后续规则: 否
```


### 场景 4：假日固定费率

**目标**：在 12 月期间所有运输费用上限为 9.99 美元。

**配置**：
```
名称: 十二月固定费率促销
类型: 设置费用
金额: 9.99 美元
优先级: 100
条件:
  开始日期: 2026-12-01
  结束日期: 2026-12-31
阻止后续规则: 是
```


### 场景 5：重物附加费

**目标**：对超过 25 公斤的订单收取 15 美元费用。

**配置**:
```
名称: 大订单附加费
类型: 附加费 (固定金额)
金额: $15
优先级: 50
条件:
  最小重量: 25kg
停止后续规则: 否
```

```
  首次购买者: 是
```

**目标**: 包含促销类目商品的订单可享受免运费。

**配置**:
```
名称: 促销类目免运费
类型: 免运费

  需要类目: ["促销"]

```

```
  需要类目: ["家具"]
  最低购物车价值: $50
停止后续规则: 否
```

## 规则组合策略

### 策略 1: 折扣叠加

**允许多个折扣叠加**:
```
规则 A (优先级 100): VIP 享 10% 折扣 → stop_further_rules=No
规则 B (优先级 50): 订单超过 $100 享 15% 折扣 → stop_further_rules=No

VIP 客户订单 $120:
基础: $15
应用规则 A 后: $13.50 (10% 折扣)
应用规则 B 后: $11.48 (15% 折扣 $13.50)
```

### 策略 2: 互斥规则

**仅应用一个规则** (优先级最高):
```
规则 A (优先级 100): 订单超过 $50 免运费 → stop_further_rules=Yes
规则 B (优先级 50): 所有订单享 20% 运费折扣 → stop_further_rules=Yes

购物车超过 $50:
规则 A 应用 → 免运费 → 停止
规则 B 不会执行
```

### 策略 3: 条件附加费

保留所有 markdown 格式, 图片路径, 代码块, 技术术语。

**先折扣后附加费**:
```
规则 A（优先级 100）：订单满 75 美元免运费
规则 B（优先级 75）：15% 会员折扣
规则 C（优先级 50）：10% 一般折扣
规则 D（优先级 25）：5 美元偏远地区附加费
规则 E（优先级 1）：10% 燃料附加费

订单：80 美元，偏远地区，会员客户
基础：20 美元
A：80 美元 > 75 美元 → 免费（0 美元）
B：会员 → 15% 折扣 0 美元 = 0 美元
C：10% 折扣 0 美元 = 0 美元
D：偏远地区 +5 美元 = 5 美元
E：燃料 +5 美元 的 10% = 5.50 美元

最终：5.50 美元（由于附加费未免费）
```

**为防止此情况，请使用 stop_further_rules=Yes**:
```
规则 A（优先级 100，stop=Yes）：订单满 75 美元免运费

相同订单：
A：80 美元 > 75 美元 → 免费（0 美元） → 停止
最终：0 美元（真正免费）
```


## 测试运费规则

**上线前**：

1. **创建测试购物车**
   - 购物车 A：25 美元（低于门槛）
   - 购物车 B：55 美元（高于门槛）
   - 购物车 C：200 美元 + 偏远地区
   - 购物车 D：会员客户

2. **测试每个规则**
   - 进入结账页面
   - 验证显示的运费是否正确
   - 检查规则执行顺序

3. **测试优先级解决**
   - 多个匹配规则
   - 验证最高优先级的规则先执行
   - 检查 stop_further_rules 的行为

4. **测试边缘情况**
   - 购物车金额正好达到门槛
   - 多个条件匹配
   - 冲突的规则


## 故障排除

**问题 1：规则未应用**

**原因**：
- 规则未激活
- 一个或多个条件未满足
- 优先级较高的规则设置了 stop_further_rules=Yes
- 有效时间不在当前日期范围内

**解决方案**：检查所有条件，检查优先级，验证激活状态。


**问题 2：意外的折扣金额**

**原因**：
- 多个规则叠加
- 百分比应用在已打折的金额上
- 规则优先级不正确

**解决方案**：检查优先级顺序，检查 stop_further_rules 标志，手动跟踪执行过程。


**问题 3：免运费未生效**

**原因**：
- 优先级较低的附加费规则在免运费规则之后添加费用
- 购物车未达到最低金额门槛
- 购物车中包含排除商品

**解决方案**: 在免运费规则中使用 stop_further_rules=Yes，验证条件，检查排除项。

## 提示

- **为免运费规则设置高优先级** - 优先级 100 确保它在其他调整之前执行
- **为绝对规则设置 stop_further_rules** - 免运费应停止进一步处理
- **测试规则组合** - 多个规则可能会意外地相互作用
- **使用描述性名称** - "VIP 20% 折扣 (优先级 75)" 比 "规则 3" 更好
- **记录复杂逻辑** - 在描述字段中添加注释
- **从简单规则开始** - 逐步增加复杂度
- **监控规则性能** - 检查规则是否被使用或是否造成混淆
- **避免过多规则** - 规则过多会减慢结账流程，最多使用 5-10 个
- **使用区域进行地理设置** - 比为每个国家设置多个类似规则更好
- **与支付方式结合使用** - 规则 + 支付方式一起使用可实现复杂的定价
- **设置明确的时间窗口** - 始终包含促销的结束日期
- **测试边缘情况** - 如正好 50 美元，正好 5 件商品等
