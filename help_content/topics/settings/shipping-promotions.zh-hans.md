---
title: 运费促销
---

运费规则根据购物车内容、客户属性和配送区域对运费方法应用条件性费用调整——自动提供满50美元免运费、对偏远地区加收附加费或为VIP客户提供运费折扣。规则基于优先级执行（优先级高的先执行），并可选停止标志以防止进一步处理。每条规则评估多个条件（购物车金额、重量、区域、产品、客户组），并在所有条件匹配时执行6种调整类型中的一种。

在需要基于订单上下文动态调整运费（而不仅仅是静态的运费方法费率）时使用运费促销。

## 运费促销类型

运费规则应用6种类型的费用调整：

### 百分比折扣

**作用**：按百分比减少运费（例如，减少25%）。

**公式**：`new_cost = base_cost × (1 - percent/100)`

**示例**：
```
基础费用：20美元
折扣：25%
结果：15美元
```

**使用场景**：
- VIP客户折扣（所有运费享受20%折扣）
- 节日促销（12月运费享受15%折扣）
- 批量订单折扣（5件以上商品运费享受10%折扣）

---

### 固定折扣

**作用**：从运费中减去固定金额。

**公式**：`new_cost = base_cost - amount`（最低0美元）

**示例**：
```
基础费用：15美元
折扣：5美元
结果：10美元
```

**使用场景**：
- 首次客户优惠（首次订单运费减5美元）
- 邮件订阅奖励（运费减3美元）
- 忠诚度计划福利（每月运费减10美元）

---

### 覆盖费用

**作用**：将运费设置为特定金额。

**公式**：`new_cost = fixed_amount`

**示例**：
```
基础费用：25美元
设置为：9.99美元
结果：9.99美元
```

**使用场景**：
- 限时促销（今天所有订单运费固定为5美元）
- 类别特定运费（书籍运费始终为3.99美元）
- 时间相关促销（本周运费上限为9.99美元）

---

### 免运费

**作用**：将运费设置为0美元。

**公式**：`new_cost = $0`

**示例**:
```
基础费用: $18
适用规则
结果: $0
```

**使用场景**:
- 消费满 $50 免运费
- 特定产品免运费（促销商品）
- VIP 客户免运费
- 购物车中有 3 件或以上商品免运费

---

### 附加费用（固定）

**作用**：在运费基础上增加固定金额。

**公式**：`new_cost = base_cost + amount`

**示例**:
```
基础费用: $12
附加费用: $5
结果: $17
```

**使用场景**:
- 远程地区配送费
- 超大件商品处理费
- 周六配送附加费
- 易碎品包装费

---

### 附加费用（百分比）

**作用**：按百分比增加运费。

**公式**：`new_cost = base_cost × (1 + percent/100)`

**示例**:
```
基础费用: $20
附加费用: 15%
结果: $23
```

**使用场景**:
- 高峰期附加费（节假日期间 20%）
- 快递服务溢价（附加费 50%）
- 燃油附加费（根据当前费率变化）

---

## 促销条件

促销规则要求 **所有条件都必须满足** 才能适用:

### 时间有效性

- **开始日期**：规则在此日期之后生效
- **结束日期**：规则在此日期之前有效
- **使用场景**：季节性促销，限时优惠

**示例**：仅限黑色星期五周末免运费
```
开始: 2026-11-27 00:00
结束: 2026-11-30 23:59
```

---

### 购物车金额范围

- **最低购物车金额**：购物车小计必须 ≥ 金额
- **最高购物车金额**：购物车小计必须 ≤ 金额
- **使用场景**：免运费门槛，阶梯折扣

**示例**：订单金额 $50-$200 免运费
```
最低: $50
最高: $200
```

---

### 购物车重量范围

- **最低重量**：购物车总重量必须 ≥ 金额
- **最高重量**：购物车总重量必须 ≤ 金额
- **使用场景**：轻量货物折扣，重物附加费

**示例**：订单重量超过 20kg 加收 $5
```
最低重量: 20kg
最高重量: null（无限制）
```

---

### 商品数量范围


- **最小商品数量**: 购物车中必须包含 ≥ 指定数量的商品
- **最大商品数量**: 购物车中必须包含 ≤ 指定数量的商品
- **使用场景**: 批量订单折扣，单件商品费用

**示例**: 5件及以上商品免运费
```
Min Items: 5
Max Items: null
```

---

### 配送区域

- **区域**: 仅当客户地址匹配至少一个选定区域时，规则才适用
- **未选择**: 规则适用于所有区域
- **使用场景**: 针对特定区域的附加费用或折扣

**示例**: 仅适用于国内区域免运费
```
Zones: ["Domestic USA"]
```

---

### 配送方式

- **方式**: 仅适用于特定的配送方式
- **未选择**: 适用于所有配送方式
- **使用场景**: 针对特定配送方式的促销

**示例**: Express Shipping 享受 25% 折扣
```
Methods: ["Express Delivery"]
```

---

### 商品要求

**要求的商品**: 购物车中必须包含这些商品中的至少一个

**要求的类别**: 购物车中必须包含这些类别中的至少一个商品

**使用场景**: 针对特定商品的免运费，促销捆绑

**示例**: 购物车包含 "Promotion Item A" 时免运费
```
Requires Products: [Product ID 123]
```

---

### 商品排除

**排除的商品**: 如果购物车中包含这些商品中的任何一个，规则不适用

**排除的类别**: 如果购物车中包含这些类别中的任何商品，规则不适用

**使用场景**: 排除重型/超大商品免运费

**示例**: 除家具类别外免运费
```
Excludes Categories: [Furniture]
```

---

### 客户群体

- **客户群体**: 仅适用于选定客户群体（VIP、批发等）的客户
- **未选择**: 适用于所有客户群体
- **使用场景**: VIP 优惠，批发折扣

**示例**: VIP 会员享受 15% 配送折扣
```
Customer Groups: ["VIP"]
```

---

### 首次客户


- **新客户**: 开关以限制规则仅适用于无历史订单的客户
- **使用场景**: 新客户欢迎优惠

**示例**: 首单运费减 $5
```
First Time Customer: Yes
```

---

## 促销优先级与执行

促销按 **优先级顺序** 执行（数字越高，执行越早）：

### 优先级机制

**执行示例**：
```
促销 A（优先级 100）：购物车金额大于 $50 免运费
促销 B（优先级 50）：所有运费打 10% 折
促销 C（优先级 1）：偏远地区加 $2 费用

购物车：$60，偏远地区
基础运费成本：$15

步骤 1：评估促销 A（优先级 100）
  购物车金额大于 $50？是
  应用：将成本设为 $0
  当前成本：$0

步骤 2：评估促销 B（优先级 50）
  对 $0 应用 10% 折扣
  当前成本：$0（仍然免费）

步骤 3：评估促销 C（优先级 1）
  对 $0 加 $2 费用
  当前成本：$2

最终成本：$2
```

**停止后续促销标志**：

如果促销 A 设置了 `stop_further_promotions = True`：
```
促销 A（优先级 100，stop_further_promotions=True）：购物车金额大于 $50 免运费
促销 B（优先级 50）：10% 折扣
促销 C（优先级 1）：偏远地区加 $2 费用

购物车：$60
基础：$15

步骤 1：应用促销 A，将成本设为 $0
        stop_further_promotions = True → 停止

最终成本：$0（规则 B 和 C 从未执行）
```

## 创建运费促销

**逐步操作流程**：

1. **导航到规则**
   - 设置 > 运费 > 运费促销
   - 点击“添加运费促销”

2. **基本配置**
   - **名称**：内部标识符（例如，“购物车金额大于 $50 免运费”）
   - **描述**：可选备注（不显示给客户）
   - **启用**：开关以启用/禁用
   - **优先级**：设置执行顺序（100 为高优先级，1 为低）

3. **选择促销类型**
   - 选择调整类型（折扣百分比、固定折扣、设置成本、免费、附加费用百分比、固定附加费用）
   - 输入金额或百分比

4. **设置停止标志**（可选）
   - 如果此规则应阻止较低优先级的促销执行，请勾选“停止进一步促销”
   - 用于最终/绝对规则（例如，免费送货不应在之后添加附加费用）

5. **定义条件**（可选 - 留空表示“始终适用”）
   - 时间有效性：开始/结束日期
   - 购物车价值：最小/最大
   - 购物车重量：最小/最大
   - 商品数量：最小/最大
   - 区域：选择适用区域
   - 方法：选择适用方法
   - 商品：必需或排除
   - 客户：客户组或仅首次购买客户

6. **保存规则**
   - 点击保存
   - 规则立即生效（如果活动开关设置为“是”）

## 常见运费促销场景

### 场景 1：购物车金额超过 50 美元免费送货

**目标**：当购物车小计 ≥ 50 美元时提供免费送货。

**配置**：
```
名称：Free Shipping Over $50
类型：Free Shipping
优先级：100
条件：
  Min Cart Value: $50
Stop Further Promotions: Yes
```

---

### 场景 2：偏远地区附加费

**目标**：对偏远地区送货收取 10 美元附加费。

**配置**：
```
名称：Remote Area Surcharge
类型：Surcharge (Fixed)
金额：$10
优先级：50
条件：
  Zones: ["Remote Areas"]
Stop Further Promotions: No
```

---

### 场景 3：VIP 客户 20% 折扣

**目标**：VIP 客户可享受所有运费 20% 的折扣。

**配置**：
```
名称：VIP Shipping Discount
类型：Discount (Percentage)
百分比：20
优先级：75
条件：
  Customer Groups: ["VIP"]
Stop Further Promotions: No
```

---

### 场景 4：节假日固定运费

**目标**：12 月期间所有运费上限为 9.99 美元。

**配置**：
```
名称：December Flat Rate Promo
类型：Override Cost
金额：$9.99
优先级：100
条件：
  Start Date: 2026-12-01
  End Date: 2026-12-31
Stop Further Promotions: Yes
```

---

### 场景 5：重物附加费

**目标**：对超过 25kg 的订单收取 15 美元费用。

**配置**:
```
Name: Heavy Order Surcharge
Type: Surcharge (Fixed)
Amount: $15
Priority: 50
Conditions:
  Min Weight: 25kg
Stop Further Promotions: No
```

---

### 场景 6: 首次订单免运费

**目标**: 新客户首次订单享受免运费。

**配置**:
```
Name: First Order Free Shipping
Type: Free Shipping
Priority: 100
Conditions:
  First Time Customer: Yes
Stop Further Promotions: Yes
```

---

### 场景 7: 分类特定免运费

**目标**: 包含促销分类商品的订单享受免运费。

**配置**:
```
Name: Promo Category Free Shipping
Type: Free Shipping
Priority: 90
Conditions:
  Requires Categories: ["Promotions"]
Stop Further Promotions: Yes
```

---

**目标**: 订单满 $50 免运费，但购物车包含家具除外。

**解决方案**: 两个规则

**促销 1**:

  Min Cart Value: $50

```

**促销 2**:
```

  Requires Categories: ["Furniture"]

Stop Further Promotions: No
```

## 促销组合策略

### 策略 1: 折扣叠加

**允许多个折扣叠加**:
```
Promotion A (Priority 100): VIP 10% 折扣 → stop_further_promotions=No
Promotion B (Priority 50): 订单金额 >$100 15% 折扣 → stop_further_promotions=No

VIP 客户订单金额 $120:
Base: $15
After Promotion A: $13.50 (10% 折扣)
After Promotion B: $11.48 (15% 折扣 $13.50)
```

### 策略 2: 独占规则

**仅适用一个规则** (最高优先级):
```
Promotion A (Priority 100): 订单金额 >$50 免运费 → stop_further_promotions=Yes
Promotion B (Priority 50): 所有运费 20% 折扣 → stop_further_promotions=Yes
```

购物车 > $50:
促销 A 适用 → 免运费 → 停止
促销 B 从不执行
```

### 策略 3: 条件附加费

**先折扣，后附加费**：
```
促销 A (优先级 100): 购物车 >$75 免运费
促销 B (优先级 75): 15% VIP 折扣
促销 C (优先级 50): 10% 通用折扣
促销 D (优先级 25): $5 远程地区附加费
促销 E (优先级 1): 10% 燃油附加费

订单: $80, 远程地区, VIP 客户
基础: $20
A: $80 > $75 → 免运费 ($0)
B: VIP → 15% 折扣 $0 = $0
C: 10% 折扣 $0 = $0
D: 远程 +$5 = $5
E: 燃油 +10% 的 $5 = $5.50

最终: $5.50 (由于附加费，未真正免运费)
```

**为防止此情况，请使用 stop_further_promotions=Yes**：
```
促销 A (优先级 100, stop=Yes): 购物车 >$75 免运费

相同订单：
A: $80 > $75 → 免运费 ($0) → 停止
最终: $0 (真正免运费)
```

## 测试运费促销

**上线前**：

1. **创建测试购物车**
   - 购物车 A: $25 (低于门槛)
   - 购物车 B: $55 (高于门槛)
   - 购物车 C: $200 + 远程地区
   - 购物车 D: VIP 客户

2. **测试每条规则**
   - 前往结账
   - 验证显示的运费是否正确
   - 检查规则执行顺序

3. **测试优先级解决**
   - 多条匹配规则
   - 验证优先级最高的先执行
   - 检查 stop_further_promotions 的行为

4. **测试边缘情况**
   - 购物车金额正好达到门槛
   - 多个条件匹配
   - 冲突的规则

## 故障排除

**问题 1: 促销未应用**

**原因**：
- 规则未激活
- 一个或多个条件未满足
- 更高优先级规则设置了 stop_further_promotions=Yes
- 时间有效性不在当前日期内

**解决方案**：检查所有条件，查看优先级，验证激活状态。

---

**问题 2: 折扣金额异常**

**原因**：
- 多个促销叠加
- 百分比应用于已折扣的金额
- 规则优先级错误

**解决方案**：检查优先级顺序，查看 stop_further_promotions 标志，手动跟踪执行过程。

**问题 3：免费送货功能不起作用**

**原因**:
- 优先级较低的附加费用规则在免费送货促销之后增加费用
- 购物车未达到最低金额门槛
- 购物车包含被排除的产品

**解决方案**: 在免费送货促销中使用 stop_further_promotions=Yes，验证条件，检查排除项。

## 小贴士

- **为免费送货设置高优先级** - 优先级 100 可确保其在其他调整之前执行
- **为绝对规则设置 stop_further_promotions** - 免费送货应停止后续处理
- **测试规则组合** - 多个促销可能会产生意外的交互
- **使用描述性名称** - "VIP 20% 折扣（优先级 75）" 比 "促销 3" 更好
- **记录复杂逻辑** - 在描述字段中添加注释
- **从简单促销开始** - 逐步增加复杂度
- **监控规则性能** - 检查规则是否被使用或导致混淆
- **避免过多促销** - 太多促销会减慢结账流程，建议使用 5-10 个
- **使用区域划分地理区域** - 比按国家设置多个相似规则更好
- **与方法结合使用** - 规则 + 方法可协同工作以实现复杂的定价
- **设置明确的时间窗口** - 促销时始终包含结束日期
- **测试边缘情况** - 恰好 $50，恰好 5 件商品等
