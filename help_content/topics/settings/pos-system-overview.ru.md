Система POS Spwig превращает ваш магазин в полное ретейлерское решение с современными терминалами продаж. Она включена во все версии — Community, Pro и Enterprise — с неограниченным количеством терминалов в неограниченном количестве локаций без дополнительных затрат. Каждый терминал представляет собой прогрессивное веб-приложение (PWA), которое работает офлайн, автоматически синхронизируется и интегрируется с вашим ассортиментом, данными о клиентах и обработкой платежей. Управляйте всем из панели администратора — настройка терминалов, сверка смен, настройка чеков и интеграция с оборудованием.

Используйте систему POS, когда у вас есть физические розничные локации, временные магазины, выставки и любая среда, где клиенты совершают покупки лично, а не онлайн.

## Что такое Spwig POS?

Spwig POS — это полностью интегрированная система продаж, предназначенная для продавцов, которые продают как онлайн, так и в физических локациях. В отличие от сторонних систем POS, требующих сложных интеграций, Spwig POS встроена напрямую в вашу платформу, обеспечивая идеальную синхронизацию данных по всем каналам продаж.

**Основные характеристики**:
- **Неограниченное количество терминалов** - Развертывайте столько терминалов, сколько необходимо, без дополнительных затрат
- **Архитектура с приоритетом офлайн-режима** - Продолжает обрабатывать продажи даже при потере соединения с интернетом
- **Прогрессивное веб-приложение** - Нет необходимости устанавливать в магазине приложений; доступ через браузер на любом устройстве (планшеты, компьютеры, специализированные терминалы)
- **Синхронизация реального запаса** - Резервирование запасов (TTL 15 минут) предотвращает перепродажу по каналам
- **Поддержка разделения платежей** - Принимайте несколько методов оплаты за одну транзакцию (наличные + карта + подарочная карта)
- **Интеграция с оборудованием** - Термопечати ESC/POS, сканеры штрих-кодов, кассовые ящики, дисплеи для клиентов
- **Управление сменами** - Сверка наличных с начальными/конечными подсчетами и отслеживанием расхождений
- **Готов к работе с несколькими локациями** - Группы магазинов с наследованием настроек для управления франшизами и региональными операциями

## Версии

POS включена во все версии Spwig — Community, Pro и Enterprise — начиная с Spwig 1.5.8. Нет отдельной лицензии на POS, нет этапа активации и нет платы за терминал.

**Что входит во все версии**:
- Неограниченная регистрация терминалов
- Неограниченное назначение сотрудников
- Все функции POS (смены, управление наличными, настройка чеков, дисплеи для клиентов)
- Интеграции с поставщиками платежей (Stripe Terminal и другие поддерживаемые провайдеры)
- Поддержка интеграции с оборудованием

Торговцы, использующие магазины, хостируемые Spwig, или платящие за лицензию Pro/Enterprise, получают более высокие лимиты на опциональных услугах, хостируемых Spwig (GeoIP, геокодер, уведомления), и приоритетную поддержку, но набор функций POS одинаков во всех версиях.

## Архитектура системы

**Frontend** - React 18 Progressive Web App:
- Офлайн-приоритет с кэшированием через Service Worker (работает без интернета)
- Система сборки Vite для быстрой загрузки
- CSS Modules + токены дизайна (соответствуют теме вашего магазина)
- IndexedDB для локального хранения данных
- 10 поддерживаемых языков (английский, китайский упрощенный/традиционный, французский, немецкий, испанский, португальский, японский, русский, арабский)

**Backend** - Интеграция с бэкендом:
- 13 моделей POS (POSTerminal, POSShift, CashMovement, ReceiptTemplate, PromoSlide и т.д.)
- 43+ конечных точек REST API для операций с терминалами
- Система резервирования запасов с управлением TTL
- Задачи Celery для фоновой синхронизации
- Зашифрованное хранение учетных данных для поставщиков платежей

**Безопасность**:
- Сопоставление терминалов через коды из 8 символов (созданы на сервере, истекают после использования)
- Контроль назначения сотрудников, определяющий, какие пользователи могут получить доступ к каким терминалам
- Возможность удаленного блокировки/разблокировки для экстренных случаев администратора
- Зашифрованные учетные данные поставщиков платежей
- Аутентификация на основе сессии с поддержкой биометрической разблокировки (зависит от браузера)

## Рабочий процесс начала работы

Следуйте этим 4 шагам, чтобы развернуть ваш первый терминал POS.

Для получения полного пошагового списка действий, включая настройку персонала, провайдеров оплаты и запуск первой продажи, см. [Getting Started with POS](getting-started-with-pos).

**Шаг 1: Создать склад**
- Перейдите в **Каталог > Склады**
- Создайте склад, представляющий ваше розничное место
- Настройте адрес и контактную информацию
- Этот склад будет отслеживать физический запас для продаж в POS

**Шаг 2: Зарегистрировать терминал**
- Перейдите в **POS > Терминалы**
- Нажмите **+ Добавить терминал**
- Укажите имя терминала (например, «Основной кассовый аппарат», «Оплата 1»)
- Назначьте склад из шага 2
- Настройте параметры оборудования (принтер, сканер, денежный ящик)
- Сохраните, чтобы сгенерировать 8-символьный код сопоставления

**Шаг 3: Назначить сотрудников**
- В настройках терминала прокрутите вниз до **Назначенные пользователи**
- Выберите сотрудников, имеющих право использовать этот терминал
- Только назначенные пользователи могут войти в терминал
- Пользователи должны иметь соответствующие разрешения POS в своей роли сотрудника

**Шаг 4: Сопоставить устройство**
- На вашем устройстве терминала (планшет/компьютер) перейдите по URL `/pos/`
- Введите 8-символьный код сопоставления из шага 3
- Терминал загружает конфигурацию и синхронизирует начальные данные
- Войдите с учетными данными назначенного сотрудника
- Терминал готов к продажам

После сопоставления терминалы автоматически синхронизируются каждые 5 минут (настраиваемо). Режим оффлайн позволяет продолжать работу, когда интернет недоступен — продажи автоматически синхронизируются, когда соединение восстановится.

## Основные функции POS

**Обработка продаж**:
- Поиск товаров по названию, SKU или штрих-коду
- Разделение оплаты (несколько методов оплаты на заказ)
- Сохраненные корзины (сохранение незавершенных транзакций)
- Возвраты и аннулирования с отслеживанием причин
- Применение скидок (купоны, подарочные карты, акции)
- Поиск клиентов и использование баллов лояльности

**Управление наличными**:
- Открытие смены с начальным подсчетом наличных
- Закрытие смены с проверкой ожидаемого и фактического баланса
- Движение наличных (дополнение кассы, выдача наличных с указанием причин)
- Автоматический расчет ожидаемого наличного баланса на основе наличных продаж
- Отслеживание и отчеты о расхождениях

**Интеграция с оборудованием**:
- Термопечати ESC/POS (сетевые или последовательные)
- Сканеры штрих-кодов по USB
- Триггер денежного ящика через импульс принтера
- Дисплеи для клиентов (рекламный карусель в режиме ожидания)
- Считывающие устройства карт Stripe Terminal (S700, WisePOS E, P400)

**Возможности оффлайн**:
- Service Worker кэширует все активы терминала
- IndexedDB хранит последние заказы (настраиваемо: 7–30 дней, 200–1000 заказов)
- Зарезервированные товары с TTL 15 минут предотвращают перепродажу
- Очередь продаж для синхронизации при восстановлении соединения
- Автоматическое обнаружение повторного подключения

## Админ-страницы POS

Доступ к этим административным страницам позволит вам управлять всеми аспектами вашего развертывания POS:

**Панель управления POS** (`/admin/pos/`)
- Обзор системы и быстрые статистики
- Недавняя активность терминалов
- Обзор активных смен
- Плитки использования хостинг-сервисов (GeoIP, геокодер, push — см. [Spwig Hosted Services](hosted-services))

**Управление терминалами** (`/admin/pos_app/posterminal/`)
- Регистрация и настройка терминалов
- Назначение сотрудников и складов
- Отслеживание статуса онлайн/оффлайн (отслеживание пульса)
- Дистанционное разблокирование терминалов
- [Узнайте больше: Управление терминалами POS](managing-pos-terminals)

**Управление сменами** (`/admin/pos_app/posshift/`)
- Просмотр всех смен (открытые, закрытые, исторические)
- Просмотр отчетов по проверке наличных
- Отслеживание движений наличных и расхождений
- Аудит активности смен
- [Узнайте больше: Смены POS и управление наличными](pos-shifts-cash-management)

**Группы магазинов** (`/admin/pos_app/storegroup/`)
- Организация терминалов по локации/региону
- Настройка параметров на уровне группы (валюта, язык, часовой пояс)
- Реализация иерархии наследования параметров
- [Узнайте больше: Группы магазинов POS](pos-store-groups)

**Шаблоны чеков** (`/admin/pos_app/receipttemplate/`)
- Настройте печатные чеки (ширина бумаги, логотип, заголовок/подвал)
- Настройте поля соответствия (идентификатор налога, регистрация бизнеса)
- Добавьте QR-коды для акций
- Ограничьте шаблоны определенными магазинами или группами
- [Узнайте больше: Настройка шаблонов чеков](receipt-template-customization)

**Промо-слайды** (`/admin/pos_app/promoslide/`)
- Создавайте контент карусели для отображения клиентам
- Настройте слайды для определенных магазинов или групп
- Запланируйте сезонные акции
- [Узнайте больше: Промо-слайды для клиентского отображения](customer-display-promo-slides)

**Платежные провайдеры** (`/admin/pos_app/posterminalprovider/`)
- Настройте интеграцию с Stripe Terminal
- Управляйте учетными записями провайдеров платежей
- Отслеживайте статус подключения
- [Узнайте больше: Провайдеры терминалов оплаты](payment-terminal-providers)

**Читалки карт** (`/admin/pos_app/posterminalreader/`)
- Регистрируйте физические читалки карт
- Назначайте читалки терминалам
- Настройте экраны приветствия (брендинг отображения для клиентов)
- Отслеживайте статус читалки (онлайн/оффлайн/занято)
- [Узнайте больше: Управление читалками карт](card-reader-management)

## Развертывание для нескольких локаций

Для торговцев с несколькими розничными локациями Spwig POS поддерживает иерархическое наследование настроек:

**Иерархия настроек** (от высшего приоритета к низшему):
1. Настройки, специфичные для терминала (переопределяют все)
2. Настройки, специфичные для магазина (переопределяют группу и сайт)
3. Настройки группы (переопределяют настройки по умолчанию сайта)
4. Настройки по умолчанию сайта (используются по умолчанию для всех)

Настройте общие параметры на уровне группы (например, региональная валюта, язык) и при необходимости переопределяйте их для конкретных магазинов или терминалов. Детальные инструкции по настройке см. в [POS Группы магазинов](pos-store-groups).

## Советы

- **Начните с одного терминала** - протестируйте настройку POS и рабочий процесс с одним терминалом перед масштабированием на всю флоту
- **Назначьте склад до паринга** - терминалы не могут обрабатывать продажи без назначения склада
- **Настройте шаблоны чеков заранее** - поля соответствия (идентификаторы налогов) различаются в зависимости от региона; настройте их до запуска
- **Проверьте режим оффлайн** - отключите интернет и убедитесь, что продажи продолжаются; подтвердите синхронизацию при повторном подключении
- **Используйте группы магазинов для нескольких локаций** - упрощает управление настройками для франшиз или региональных развертываний
- **Отслеживайте статус пульса** - терминалы отправляют пинг серверу каждые 5 минут; терминалы, находящиеся в оффлайн-режиме, отображаются в админ-панели
- **Настройте лимиты синхронизации для производительности** - терминалы с медленным подключением выигрывают от более низких настроек sync_days/sync_limit
- **Создайте резервную копию настройки оборудования** - документируйте IP-адреса принтеров, настройки сканеров, конфигурацию денежного ящика для восстановления после катастрофы
