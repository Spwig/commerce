---
title: โปรโมชันการจัดส่ง
---

กฎการจัดส่งจะปรับค่าใช้จ่ายตามเงื่อนไขที่กำหนด โดยพิจารณาจากวิธีการจัดส่ง รายการสินค้าในตะกร้า คุณสมบัติของลูกค้า และโซนการจัดส่ง — ให้การจัดส่งฟรีเมื่อสั่งซื้อสินค้ามูลค่าเกิน $50 เพิ่มค่าธรรมเนียมสำหรับพื้นที่ห่างไกล หรือลดค่าใช้จ่ายการจัดส่งสำหรับลูกค้า VIP กฎจะถูกประมวลผลตามลำดับความสำคัญ (เริ่มจากความสำคัญสูงสุด) และสามารถตั้งค่าปิดการประมวลผลเพิ่มเติมได้ กฎแต่ละข้อจะประเมินเงื่อนไขหลายประการ (มูลค่าตะกร้า น้ำหนัก โซน ผลิตภัณฑ์ กลุ่มลูกค้า) และดำเนินการปรับค่าใช้จ่ายหนึ่งใน 6 ประเภทเมื่อเงื่อนไขทั้งหมดตรงกัน

ใช้โปรโมชันการจัดส่งเมื่อคุณต้องการค่าใช้จ่ายการจัดส่งที่เปลี่ยนแปลงตามบริบทของคำสั่งซื้อ ไม่ใช่เพียงอัตราค่าจัดส่งแบบคงที่จากวิธีการจัดส่งเท่านั้น

## ประเภทของโปรโมชันการจัดส่ง

กฎการจัดส่งสามารถปรับค่าใช้จ่ายได้ 6 ประเภท:

### ส่วนลดเปอร์เซ็นต์

**สิ่งที่มันทำ**: ลดค่าใช้จ่ายการจัดส่งตามเปอร์เซ็นต์ (เช่น ลด 25%)

**สูตร**: `new_cost = base_cost × (1 - percent/100)`

**ตัวอย่าง**:
```
Base cost: $20
Discount: 25%
Result: $15
```

**กรณีการใช้งาน**:
- ส่วนลดสำหรับลูกค้า VIP (ลดค่าใช้จ่ายการจัดส่ง 20% สำหรับทุกการสั่งซื้อ)
- โปรโมชันตามฤดูกาล (ลดค่าใช้จ่ายการจัดส่ง 15% ในเดือนธันวาคม)
- ส่วนลดสำหรับการสั่งซื้อจำนวนมาก (ลดค่าใช้จ่ายการจัดส่ง 10% สำหรับการสั่งซื้อ 5 ชิ้นขึ้นไป)

---

### ส่วนลดคงที่

**สิ่งที่มันทำ**: หักจำนวนคงที่ออกจากค่าใช้จ่ายการจัดส่ง

**สูตร**: `new_cost = base_cost - amount` (ค่าต่ำสุด $0)

**ตัวอย่าง**:
```
Base cost: $15
Discount: $5
Result: $10
```

**กรณีการใช้งาน**:
- ส่วนลดสำหรับลูกค้าใหม่ (ลดค่าใช้จ่ายการจัดส่ง $5 สำหรับการสั่งซื้อแรก)
- ส่วนลดสำหรับการสมัครสมาชิกอีเมล (ลดค่าใช้จ่ายการจัดส่ง $3)
- ประโยชน์จากโปรแกรมสะสมแต้ม (ลดค่าใช้จ่ายการจัดส่ง $10 ต่อเดือน)

---

### กำหนดค่าใช้จ่ายใหม่

**สิ่งที่มันทำ**: กำหนดค่าใช้จ่ายการจัดส่งเป็นจำนวนเฉพาะ

**สูตร**: `new_cost = fixed_amount`

**ตัวอย่าง**:
```
Base cost: $25
Set to: $9.99
Result: $9.99
```

**กรณีการใช้งาน**:
- การขายแบบแฟลช (ค่าใช้จ่ายการจัดส่งคงที่ที่ $5 สำหรับทุกการสั่งซื้อในวันนี้)
- ค่าใช้จ่ายการจัดส่งเฉพาะหมวดหมู่ (หนังสือมีค่าใช้จ่ายการจัดส่งคงที่ที่ $3.99 เสมอ)
- โปรโมชันตามเวลา (ค่าใช้จ่ายการจัดส่งถูกจำกัดไว้ที่ $9.99 ในสัปดาห์นี้)

---

### การจัดส่งฟรี

**สิ่งที่มันทำ**: ตั้งค่าใช้จ่ายการจัดส่งเป็น $0

**สูตร**: `new_cost = $0`


**ตัวอย่าง**:
```
Base cost: $18
Rule applies
Result: $0
```

**กรณีการใช้งาน**:
- การจัดส่งฟรีสำหรับการสั่งซื้อที่มีมูลค่าเกิน $50
- การจัดส่งฟรีสำหรับสินค้าบางประเภท (สินค้าโปรโมชัน)
- การจัดส่งฟรีสำหรับลูกค้า VIP
- การจัดส่งฟรีสำหรับการสั่งซื้อที่มีสินค้า 3 ชิ้นขึ้นไป

---

### ค่าเพิ่ม (คงที่)

**มีผลอย่างไร**: เพิ่มจำนวนคงที่เข้าไปในค่าจัดส่ง

**สูตร**: `new_cost = base_cost + amount`

**ตัวอย่าง**:
```
Base cost: $12
Surcharge: $5
Result: $17
```

**กรณีการใช้งาน**:
- ค่าจัดส่งสำหรับพื้นที่ห่างไกล
- ค่าจัดส่งสำหรับสินค้าขนาดใหญ่
- ค่าเพิ่มสำหรับการจัดส่งวันเสาร์
- ค่าจัดส่งสำหรับการบรรจุสินค้าที่เปราะบาง

---

### ค่าเพิ่ม (เปอร์เซ็นต์)

**มีผลอย่างไร**: เพิ่มค่าจัดส่งตามเปอร์เซ็นต์

**สูตร**: `new_cost = base_cost × (1 + percent/100)`

**ตัวอย่าง**:
```
Base cost: $20
Surcharge: 15%
Result: $23
```

**กรณีการใช้งาน**:
- ค่าเพิ่มช่วงฤดูกาล (20% ในช่วงเทศกาล)
- ค่าเพิ่มสำหรับการจัดส่งแบบเร่งด่วน (ค่าเพิ่ม 50%)
- ค่าเพิ่มเชื้อเพลิง (เปลี่ยนแปลงตามอัตราค่าใช้จ่ายปัจจุบัน)

## ข้อกำหนดโปรโมชัน

โปรโมชันจะประเมิน **ทุกเงื่อนไขต้องผ่าน** เพื่อให้กฎนั้นใช้ได้:

### ช่วงเวลาที่ใช้ได้

- **วันเริ่มต้น**: กฎจะใช้ได้หลังจากวันนี้เท่านั้น
- **วันสิ้นสุด**: กฎจะใช้ได้ก่อนวันนี้เท่านั้น
- **กรณีการใช้งาน**: โปรโมชันตามฤดูกาล, ข้อเสนอจำกัดเวลา

**ตัวอย่าง**: การจัดส่งฟรีเฉพาะช่วงวัน Black Friday
```
Start: 2026-11-27 00:00
End: 2026-11-30 23:59
```

---

### ช่วงมูลค่าตะกร้าสินค้า

- **มูลค่าตะกร้าขั้นต่ำ**: มูลค่าตะกร้ารวมต้อง ≥ จำนวน
- **มูลค่าตะกร้าขั้นสูงสุด**: มูลค่าตะกร้ารวมต้อง ≤ จำนวน
- **กรณีการใช้งาน**: ข้อกำหนดการจัดส่งฟรี, ส่วนลดตามระดับ

**ตัวอย่าง**: การจัดส่งฟรีสำหรับการสั่งซื้อที่มีมูลค่า $50-$200
```
Min: $50
Max: $200
```

---

### ช่วงน้ำหนักตะกร้าสินค้า

- **น้ำหนักขั้นต่ำ**: น้ำหนักรวมตะกร้าสินค้าต้อง ≥ จำนวน
- **น้ำหนักขั้นสูงสุด**: น้ำหนักรวมตะกร้าสินค้าต้อง ≤ จำนวน
- **กรณีการใช้งาน**: ส่วนลดสำหรับสินค้าที่มีน้ำหนักเบา, ค่าเพิ่มสำหรับสินค้าที่มีน้ำหนักมาก

**ตัวอย่าง**: ค่าเพิ่ม $5 สำหรับการสั่งซื้อที่มีน้ำหนักเกิน 20kg
```
Min Weight: 20kg
Max Weight: null (ไม่จำกัด)
```

---

### ช่วงจำนวนสินค้า


- **Min Item Count**: ตะกร้าสินค้าต้องมี ≥ จำนวนสินค้า
- **Max Item Count**: ตะกร้าสินค้าต้องมี ≤ จำนวนสินค้า
- **Use Case**: ส่วนลดสำหรับสั่งซื้อจำนวนมาก, ค่าธรรมเนียมสำหรับสินค้าเดี่ยว

**Example**: จัดส่งฟรีสำหรับสินค้า 5 ชิ้นขึ้นไป
```
Min Items: 5
Max Items: null
```

---

### Shipping Zone

- **Zones**: กฎนี้จะใช้ได้ก็ต่อเมื่อที่อยู่ของลูกค้าตรงกับโซนที่เลือกอย่างน้อยหนึ่งโซน
- **Empty selection**: กฎนี้จะใช้กับทุกโซน
- **Use Case**: ค่าธรรมเนียมหรือส่วนลดเฉพาะโซน

**Example**: จัดส่งฟรีสำหรับโซน Domestic เท่านั้น
```
Zones: ["Domestic USA"]
```

---

### Shipping Method

- **Methods**: กฎนี้จะใช้ได้ก็ต่อเมื่อเป็นวิธีการจัดส่งที่ระบุไว้เท่านั้น
- **Empty selection**: กฎนี้จะใช้กับวิธีการจัดส่งทั้งหมด
- **Use Case**: ส่วนลดเฉพาะวิธีการจัดส่ง

**Example**: ส่วนลด 25% สำหรับการจัดส่งแบบ Express
```
Methods: ["Express Delivery"]
```

---

### Product Requirements

**Requires Products**: ตะกร้าสินค้าต้องมีสินค้าอย่างน้อยหนึ่งชิ้นจากสินค้าเหล่านี้

**Requires Categories**: ตะกร้าสินค้าต้องมีสินค้าอย่างน้อยหนึ่งชิ้นจากหมวดหมู่เหล่านี้

**Use Case**: การจัดส่งฟรีเฉพาะสินค้า, ชุดสินค้าโปรโมชัน

**Example**: จัดส่งฟรีเมื่อตะกร้ามีสินค้า "Promotion Item A"
```
Requires Products: [Product ID 123]
```

---

### Product Exclusions

**Excludes Products**: กฎนี้จะไม่ใช้ได้หากตะกร้ามีสินค้าใดสินค้าหนึ่งจากสินค้าเหล่านี้

**Excludes Categories**: กฎนี้จะไม่ใช้ได้หากตะกร้ามีสินค้าใดสินค้าหนึ่งจากหมวดหมู่เหล่านี้

**Use Case**: ยกเว้นสินค้าที่มีน้ำหนักมากหรือขนาดใหญ่จากการจัดส่งฟรี

**Example**: จัดส่งฟรียกเว้นหมวดหมู่เฟอร์นิเจอร์
```
Excludes Categories: [Furniture]
```

---

### Customer Group

- **Customer Groups**: กฎนี้จะใช้ได้ก็ต่อเมื่อลูกค้าอยู่ในกลุ่มที่เลือก (VIP, Wholesale, ฯลฯ)
- **Empty selection**: กฎนี้จะใช้กับกลุ่มลูกค้าทั้งหมด
- **Use Case**: สิทธิพิเศษสำหรับลูกค้า VIP, ส่วนลดสำหรับลูกค้ารายใหญ่

**Example**: ส่วนลดค่าจัดส่ง 15% สำหรับลูกค้า VIP
```
Customer Groups: ["VIP"]
```

---

### First-Time Customer

- **ลูกค้าใหม่**: ปรับใช้เพื่อจำกัดกฎให้ลูกค้าที่ไม่มีคำสั่งซื้อเดิม
- **กรณีการใช้งาน**: ข้อเสนอต้อนรับลูกค้าใหม่

**ตัวอย่าง**: ส่วนลด $5 สำหรับคำสั่งซื้อแรก
```
First Time Customer: Yes
```

## ลำดับความสำคัญและการดำเนินการของโปรโมชัน

โปรโมชันดำเนินการตาม **ลำดับความสำคัญ** (จำนวนที่สูง = ดำเนินการก่อน):

### กลไกลำดับความสำคัญ

**ตัวอย่างการดำเนินการ**:
```
Promotion A (Priority 100): Free shipping if cart > $50
Promotion B (Priority 50): 10% discount on all shipping
Promotion C (Priority 1): $2 surcharge for remote zones

Cart: $60, Remote zone
Base shipping cost: $15

Step 1: Promotion A evaluates (Priority 100)
  Cart > $50? YES
  Apply: Set cost to $0
  Cost now: $0

Step 2: Promotion B evaluates (Priority 50)
  Apply 10% discount to $0
  Cost now: $0 (still free)

Step 3: Promotion C evaluates (Priority 1)
  Add $2 surcharge to $0
  Cost now: $2

Final cost: $2
```

**ป้ายกำกับหยุดโปรโมชันต่อไป**:

หาก Promotion A มี `stop_further_promotions = True`:
```
Promotion A (Priority 100, stop_further_promotions=True): Free shipping if cart > $50
Promotion B (Priority 50): 10% discount
Promotion C (Priority 1): $2 surcharge

Cart: $60
Base: $15

Step 1: Promotion A applies, sets cost to $0
        stop_further_promotions = True → STOP

Final cost: $0 (Rules B and C never execute)
```

## การสร้างโปรโมชันการจัดส่ง

**ขั้นตอนการทำงาน**:

1. **ไปที่กฎ**
   - Settings > Shipping > Shipping Promotions
   - คลิก "Add Shipping Promotion"

2. **การตั้งค่าพื้นฐาน**
   - **ชื่อ**: ตัวระบุภายใน (เช่น "Free Shipping Over $50")
   - **คำอธิบาย**: หมายเหตุเพิ่มเติม (ไม่แสดงให้ลูกค้าเห็น)
   - **เปิดใช้งาน**: ปรับใช้เพื่อเปิด/ปิดใช้งาน
   - **ลำดับความสำคัญ**: ตั้งค่าลำดับการดำเนินการ (100 สำหรับลำดับความสำคัญสูง, 1 สำหรับลำดับความสำคัญต่ำ)

3. **เลือกประเภทโปรโมชัน**
   - เลือกประเภทการปรับ (ส่วนลดเปอร์เซ็นต์, ส่วนลดคงที่, ตั้งค่าค่าใช้จ่าย, ฟรี, ค่าธรรมเนียมเปอร์เซ็นต์, ค่าธรรมเนียมคงที่)
   - ใส่จำนวนหรือเปอร์เซ็นต์

4. **ตั้งค่าธงหยุด** (ไม่จำเป็น)
   - เลือก "หยุดการส่งเสริมการขายต่อไป" หากกฎนี้ควรป้องกันไม่ให้การส่งเสริมการขายที่มีลำดับความสำคัญต่ำกว่าทำงาน
   - ใช้สำหรับกฎสุดท้าย/สัมบูรณ์ (เช่น การจัดส่งฟรีไม่ควรเพิ่มค่าธรรมเนียมหลังจากนั้น)

5. **กำหนดเงื่อนไข** (ไม่จำเป็น - ปล่อยว่างหากต้องการ "ใช้เสมอ")
   - ช่วงเวลาที่ใช้ได้: วันเริ่มต้น/วันสิ้นสุด
   - ค่ามูลค่าตะกร้า: ค่าต่ำสุด/สูงสุด
   - น้ำหนักตะกร้า: ค่าต่ำสุด/สูงสุด
   - จำนวนสินค้า: ค่าต่ำสุด/สูงสุด
   - พื้นที่: เลือกพื้นที่ที่ใช้ได้
   - วิธี: เลือกวิธีที่ใช้ได้
   - สินค้า: จำเป็นหรือไม่รวม
   - ลูกค้า: กลุ่มหรือเฉพาะลูกค้าใหม่

6. **บันทึกรูปแบบการส่งเสริมการขาย**
   - คลิก Save
   - กฎจะเป็นผลทันที (หากปิด/เปิดสวิตช์เป็น Yes)

## สถานการณ์การส่งเสริมการขายการจัดส่งที่พบบ่อย

### สถานการณ์ 1: การจัดส่งฟรีเมื่อสั่งซื้อสูงกว่า $50

**เป้าหมาย**: ให้การจัดส่งฟรีเมื่อมูลค่าตะกร้ารวม ≥ $50

**การตั้งค่า**:
```
ชื่อ: Free Shipping Over $50
ประเภท: Free Shipping
ลำดับความสำคัญ: 100
เงื่อนไข:
  ค่าตะกร้าขั้นต่ำ: $50
หยุดการส่งเสริมการขายต่อไป: Yes
```

---

### สถานการณ์ 2: ค่าธรรมเนียมพิเศษสำหรับพื้นที่ห่างไกล

**เป้าหมาย**: เพิ่มค่าธรรมเนียม $10 สำหรับการจัดส่งไปยังพื้นที่ห่างไกล

**การตั้งค่า**:
```
ชื่อ: Remote Area Surcharge
ประเภท: Surcharge (Fixed)
จำนวน: $10
ลำดับความสำคัญ: 50

## กลยุทธ์การรวมโปรโมชัน

### กลยุทธ์ที่ 1: การทบยอดส่วนลด

**อนุญาตให้ส่วนลดหลายรายการทบยอดกัน**:
```

โปรโมชัน B (ลำดับความสำคัญ 50): ส่วนลด 15% สำหรับคำสั่งซื้อ >$100 → stop_further_promotions=No

ลูกค้า VIP ที่มีคำสั่งซื้อ $120:
ฐาน: $15
หลังโปรโมชัน A: $13.50 (ลด 10%)
หลังโปรโมชัน B: $11.48 (ลด 15% จาก $13.50)
```

### กลยุทธ์ที่ 2: กฎที่ไม่ซ้ำกัน

**เพียงกฎเดียวที่ใช้ได้** (ลำดับความสำคัญสูงสุด):
```
โปรโมชัน A (ลำดับความสำคัญ 100): การจัดส่งฟรี >$50 → stop_further_promotions=Yes
โปรโมชัน B (ลำดับความสำคัญ 50): ส่วนลด 20% สำหรับการจัดส่งทั้งหมด → stop_further_promotions=Yes
```

ตะกร้า > $50:
โปรโมชัน A ใช้ได้ → จัดส่งฟรี → STOP
โปรโมชัน B ไม่เคยทำงาน
```

### กลยุทธ์ 3: ค่าธรรมเนียมเพิ่มเติมแบบมีเงื่อนไข

**ลดราคาเป็นลำดับแรก ค่าธรรมเนียมเพิ่มเป็นลำดับสุดท้าย**:
```
โปรโมชัน A (ลำดับความสำคัญ 100): จัดส่งฟรี >$75
โปรโมชัน B (ลำดับความสำคัญ 75): ส่วนลด 15% สำหรับลูกค้า VIP
โปรโมชัน C (ลำดับความสำคัญ 50): ส่วนลดทั่วไป 10%
โปรโมชัน D (ลำดับความสำคัญ 25): ค่าธรรมเนียมพื้นที่ห่างไกล $5
โปรโมชัน E (ลำดับความสำคัญ 1): ค่าธรรมเนียมน้ำมัน 10%

คำสั่งซื้อ: $80, พื้นที่ห่างไกล, ลูกค้า VIP
ฐาน: $20
A: $80 > $75 → ฟรี ($0)
B: VIP → ลด 15% จาก $0 = $0

D: พื้นที่ห่างไกล +$5 = $5
E: ค่าธรรมเนียมน้ำมัน +10% ของ $5 = $5.50

```
โปรโมชัน A (ลำดับความสำคัญ 100, stop=Yes): จัดส่งฟรี >$75

คำสั่งซื้อเดียวกัน:
