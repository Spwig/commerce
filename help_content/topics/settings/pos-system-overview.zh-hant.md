Spwig POS 系統將您的商店轉變為完整的零售解決方案，採用現代化的銷售點終端機。它包含在每個版本中 — 社群版、專業版和企業版 — 不論是無限數量的終端機還是無限數量的地理位置，都不需要額外費用。每個終端機都是進步式網頁應用程式（PWA），可在離線狀態下運作、自動同步，並與您的庫存、客戶資料和付款處理系統無縫整合。從管理儀表板管理所有內容 — 終端機設定、班次對帳、收據自訂和硬體整合。

當您在實體零售商店、臨時快閃店、展覽會或任何需要顧客親自購買而非在網路上購買的環境中時，請使用 POS 系統。

## 什麼是 Spwig POS？

Spwig POS 是一個完全整合的銷售點系統，專為同時在線上和實體位置銷售的商家設計。與需要複雜整合的第三方 POS 系統不同，Spwig POS 直接建置在您的平台上，確保所有銷售渠道之間的數據完全同步。

**主要特徵**:
- **無限終端機** - 在不產生額外費用的情況下，部署所需的終端機數量
- **離線優先架構** - 即使在失去互聯網連接的情況下，也能繼續處理銷售
- **進步式網頁應用程式** - 無需應用程式商店安裝；可在任何設備（平板、電腦、專用終端機）上的瀏覽器中存取
- **實時庫存同步** - 庫存預訂（15 分鐘 TTL）防止跨渠道超賣
- **分拆付款支援** - 每筆交易可接受多種付款方式（現金 + 銀行卡 + 礼品卡）
- **硬體整合** - ESC/POS 熱敏印表機、條碼掃描器、現金抽屜、客戶顯示器
- **班次管理** - 透過開班/結班數量和差異追蹤進行現金對帳
- **多位置準備就緒** - 儲存群組，支援設定繼承，適用於特許經營和區域管理

## 版本

POS 已包含在所有 Spwig 版本中 —— 社区版、专业版和企业版 —— 自 Spwig 1.5.8 起。

没有单独的 POS 授权许可，无需激活步骤，也无每终端费用。

**每个版本包含的内容**：
- 無限的終端機註冊
- 無限的員工分配
- 所有 POS 功能（班次、現金管理、收據自定義、客戶顯示）
- 支付提供商整合（Stripe Terminal 和其他支援的提供商）
- 硬體整合支援

運行 Spwig 主機商店或支付專業版/企業版許可的商家將獲得更高限制的可選 Spwig 主機服務（GeoIP、地理編碼、推送通知）和優先支援，但 POS 功能本身在所有版本中是相同的。

## 系統架構

**前端** - React 18 進步式網頁應用程式：
- 首先離線，使用 Service Worker 缓存（無需互聯網）
- 使用 Vite 構建系統以實現快速加載
- CSS Modules + 設計令牌（與您的商店主題一致）
- 使用 IndexedDB 進行本地數據持久化
- 支援 10 種語言（英語、簡體/繁體中文、法語、德語、西班牙語、葡萄牙語、日語、俄語、阿拉伯語）

**後端** - 後端整合：
- 13 個 POS 模型（POSTerminal、POSShift、CashMovement、ReceiptTemplate、PromoSlide 等）
- 43 個以上的 REST API 端點用於終端機操作
- 帶 TTL 管理的庫存預訂系統
- 用於背景同步的 Celery 任務
- 支付提供商的加密憑證存儲

**安全性**：
- 終端機配對透過 8 個字符的代碼（伺服器端生成，使用後過期）
- 員工分配控制哪些用戶可以訪問哪些終端機
- 管理員緊急情況下的遠程鎖定/解鎖功能
- 加密的支付提供商憑證
- 基於會話的驗證，支援生物特徵解鎖（依瀏覽器而定）

## 開始使用流程

按照以下 4 個步驟部署您的第一個 POS 終端機。

如需查看包含員工設置、支付提供商和完成首筆銷售的完整逐步檢查清單，請參閱[POS入門](getting-started-with-pos)。

**步驟 1：建立倉庫**
- 點擊 **目錄 > 倉庫**
- 建立代表您零售位置的倉庫
- 設置地址和聯繫資訊
- 這個倉庫將追蹤 POS 賣出的實體庫存

**步驟 2：註冊終端機**
- 點擊 **POS > 終端機**
- 點擊 **+ 添加終端機**
- 設定終端機名稱（例如："主收銀機"、"結帳 1"）
- 從步驟 2 中指派倉庫
- 設置硬體設定（印表機、掃描器、現金抽屜）
- 儲存以生成 8 個字元的配對碼

**步驟 3：指派員工**
- 在終端機設定中，滾動到 **已指派用戶**
- 選擇被授權使用此終端機的員工
- 只有已指派的用戶才能登入終端機
- 用戶必須在其員工角色中擁有適當的 POS 權限

**步驟 4：配對設備**
- 在您的終端機設備（平板電腦/電腦）上，導航到 `/pos/` URL
- 輸入來自步驟 3 的 8 個字元配對碼
- 終端機下載設定並同步初始資料
- 使用已指派的員工憑證登入
- 終端機已準備好進行銷售

配對後，終端機會自動每 5 分鐘同步一次（可配置）。離線模式允許在沒有互聯網連接時繼續操作——當連接恢復時，銷售會自動同步。

## 核心 POS 功能

**銷售處理**：
- 透過名稱、SKU 或條碼搜尋產品
- 分散付款（每筆訂單使用多種付款方式）
- 暫存購物車（儲存未完成的交易）
- 退款和取消並追蹤原因
- 應用折扣（優惠券、禮品卡、促銷）
- 客戶查詢和忠誠度積分兌換

- 以起始現金數量開始班次

- 班次結束時進行預期與實際對賬

- 現金流動（浮動現金增加、零用現金提取並附原因）

- 基於現金銷售自動計算預期現金

- 差異追蹤與報告

- ESC/POS熱敏收據印表機（網路或串列）

- USB條碼掃描器

- 透過印表機脈衝觸發現金抽屜

- 顧客面對的顯示器（閒置時的促銷輪播）

- Stripe Terminal卡讀卡機 (S700, WisePOS E, P400)

- Service Worker緩存所有終端設備資源

- IndexedDB儲存最近的訂單（可配置：7-30天，200-1000筆訂單）

- 倉庫預訂（15分鐘TTL）防止超賣

- 當連線恢復時將銷售排隊以進行同步

- 自動重新連線檢測

使用這些管理員頁面來管理您POS部署的所有方面：

**收據模板** (`/admin/pos_app/receipttemplate/`)
- 自定義打印收據（紙張寬度、商標、標題/頁腳）
- 設置合規字段（稅號、商業註冊）
- 添加促銷的二維碼
- 將模板範圍限定於特定商店或群組
- [了解更多：收據模板自定義](receipt-template-customization)

**促銷幻燈片** (`/admin/pos_app/promoslide/`)
- 創建客戶顯示輪播內容
- 將幻燈片針對特定商店或群組
- 計劃季節性促銷
- [了解更多：客戶顯示促銷幻燈片](customer-display-promo-slides)

**支付提供商** (`/admin/pos_app/posterminalprovider/`)
- 設置 Stripe 終端集成
- 管理支付提供商憑證
- 監控連接狀態
- [了解更多：支付終端提供商](payment-terminal-providers)

**卡片讀卡器** (`/admin/pos_app/posterminalreader/`)
- 註冊物理卡片讀卡器
- 將讀卡器分配給終端
- 自定義 splash 屏幕（面對客戶的顯示品牌）
- 監控讀卡器狀態（在線/離線/忙碌）
- [了解更多：卡片讀卡器管理](card-reader-management)

## 多地部署

對於有多個零售地點的商家，Spwig POS 支持層級設置繼承：

**設置層級**（從最高優先級到最低）：
1. 終端特定設置（覆蓋所有）
2. 商店特定設置（覆蓋群組和網站）
3. 群組設置（覆蓋網站默認值）
4. 網站默認值（所有情況的備用）

在群組層級配置共享設置（例如區域貨幣、語言），並根據需要覆蓋特定商店或終端。有關詳細配置指南，請參閱 [POS 商店群組](pos-store-groups)。

## 小提示

保留所有 markdown 格式、圖片路徑、代碼塊和技術術語。

- **從一個終端開始** - 在全面部署之前，先用單個終端測試 POS 設置和工作流程
- **配對前指派倉庫** - 無法處理銷售的終端必須先指派倉庫
- **提前配置收據模板** - 合規欄位（稅號）因地區而異；上線前請先設置
- **測試離線模式** - 斷開網絡連接並驗證銷售是否能繼續；重新連接時確認同步
- **使用商店群組管理多個位置** - 簡化連鎖經營或區域部署的配置管理
- **監控心跳狀態** - 終端每 5 分鐘向服務器發送一次心跳；離線終端會出現在管理員儀表板中
- **為性能配置同步限制** - 網絡連接較慢的終端可從降低 sync_days/sync_limit 設置中受益
- **備份硬體配置** - 記錄打印機 IP、掃描器設置、錢箱配置，以備災難恢復
