title: 배송 규칙
---

배송 규칙은 장바구니 내용, 고객 속성, 배송 지역에 따라 배송 방법에 조건부 비용 조정을 적용합니다. $50 이상 주문 시 무료 배송을 자동으로 제공하거나, 원거리 지역에 요금을 추가하거나, VIP 고객을 위한 배송 할인을 제공할 수 있습니다. 규칙은 우선순위 기반 실행(높은 우선순위부터)을 사용하며, 추가 처리를 방지하기 위한 선택적 중지 플래그를 가질 수 있습니다. 각 규칙은 장바구니 가치, 무게, 지역, 제품, 고객 그룹과 같은 여러 조건을 평가하고, 모든 조건이 일치할 경우 6가지 조정 유형 중 하나를 실행합니다.

배송 비용이 주문 맥락에 따라 변경되는 동적 배송 비용이 필요한 경우에만 배송 규칙을 사용하십시오.

## 배송 규칙 유형

배송 규칙은 6가지 유형의 비용 조정을 적용합니다.

### 백분율 할인

**작동 방식**: 배송 비용을 백분율로 줄입니다 (예: 25% 할인).

**공식**: `new_cost = base_cost × (1 - percent/100)`

**예시**:
```
기본 비용: $20
할인: 25%
결과: $15
```

**사용 사례**:
- VIP 고객 할인 (모든 배송에 20% 할인)
- 계절 프로모션 (12월에 배송 15% 할인)
- 대량 주문 할인 (5개 이상 제품에 10% 할인)

---

### 고정 할인

**작동 방식**: 배송 비용에서 고정 금액을 뺍니다.

**공식**: `new_cost = base_cost - amount` (최소 $0)

**예시**:
```
기본 비용: $15
할인: $5
결과: $10
```

**사용 사례**:
- 첫 방문 고객 보너스 (첫 주문 배송 $5 할인)
- 뉴스레터 구독 보상 (배송 $3 할인)
- 충성 프로그램 혜택 (월간 배송 $10 할인)

---

### 설정 비용

**작동 방식**: 배송 비용을 특정 금액으로 대체합니다.

**공식**: `new_cost = fixed_amount`

**예시**:
```
기본 비용: $25
설정: $9.99
결과: $9.99
```

**사용 사례**:
- 플래시 세일 (오늘 모든 주문에 $5 고정 배송)
- 카테고리별 배송 (책은 항상 $3.99 배송)
- 시간 기반 프로모션 (이번 주 배송 최대 $9.99)

---

### 무료 배송

**작동 방식**: 배송 비용을 $0으로 설정합니다.

**공식**: `new_cost = $0`

**예시**:
```
기본 비용: $18
규칙 적용됨
결과: $0
```

**사용 사례**:
- $50 이상 무료 배송
- 특정 제품에 대한 무료 배송 (프로모션 상품)
- VIP 고객에게 대한 무료 배송
- 3개 이상의 상품이 포함된 주문에 대한 무료 배송


### 수수료 (고정 금액)

**작동 방식**: 배송 비용에 고정 금액을 추가합니다.

**공식**: `new_cost = base_cost + amount`

**예시**:
```
기본 비용: $12
수수료: $5
결과: $17
```

**사용 사례**:
- 원격 지역 배송 수수료
- 과중한 물품 처리
- 토요일 배송 수수료
- 취약한 물품 포장 수수료


### 수수료 (백분율)

**작동 방식**: 백분율로 배송 비용을 증가시킵니다.

**공식**: `new_cost = base_cost × (1 + percent/100)`

**예시**:
```
기본 비용: $20
수수료: 15%
결과: $23
```

**사용 사례**:
- 피크 시즌 수수료 (휴일 기간 동안 20%)
- 빠른 배송 프리미엄 (50% 수수료)
- 연료 수수료 (현재 요금에 따라 변동)


## 규칙 조건

규칙은 **모든 조건이 충족되어야만** 적용됩니다:

### 시간 유효성

- **시작 날짜**: 이 날짜 이후에만 규칙이 활성화됩니다
- **마감 날짜**: 이 날짜 이전에만 규칙이 활성화됩니다
- **사용 사례**: 계절별 프로모션, 한시적 오퍼

**예시**: 할로윈 주말에만 무료 배송
```
시작: 2026-11-27 00:00
마감: 2026-11-30 23:59
```


### 장바구니 금액 범위

- **최소 장바구니 금액**: 장바구니 합계는 ≥ 금액이어야 합니다
- **최대 장바구니 금액**: 장바구니 합계는 ≤ 금액이어야 합니다
- **사용 사례**: 무료 배송 기준, 계층별 할인

**예시**: $50-$200 사이 주문에 대한 무료 배송
```
최소: $50
최대: $200
```


### 장바구니 무게 범위

- **최소 무게**: 장바구니 총 무게는 ≥ 금액이어야 합니다
- **최대 무게**: 장바구니 총 무게는 ≤ 금액이어야 합니다
- **사용 사례**: 가벼운 화물 할인, 무거운 물품 수수료

**예시**: 20kg 이상 주문에 $5 수수료
```
최소 무게: 20kg
최대 무게: null (제한 없음)
```


### 항목 수 범위

- **최소 항목 수**: 장바구니에 ≥ 수량의 항목이 있어야 함
- **최대 항목 수**: 장바구니에 ≤ 수량의 항목이 있어야 함
- **사용 사례**: 대량 주문 할인, 단일 항목 수수료

**예시**: 5개 이상 항목에 대해 무료 배송
```
최소 항목 수: 5
최대 항목 수: null
```

### 배송 지역

- **지역**: 고객 주소가 선택한 지역 중 하나와 일치할 때만 규칙이 적용됨
- **비선택**: 규칙이 모든 지역에 적용됨
- **사용 사례**: 지역별 추가 요금 또는 할인

**예시**: 국내 지역만 해당되는 무료 배송
```
지역: ["국내 USA"]
```

### 배송 방법

- **배송 방법**: 특정 배송 방법에만 규칙이 적용됨
- **비선택**: 규칙이 모든 방법에 적용됨
- **사용 사례**: 방법별 프로모션

**예시**: 빠른 배송에 25% 할인
```
배송 방법: ["빠른 배송"]
```

### 제품 요구사항

**필요 제품**: 장바구니에 이 제품 중 하나 이상이 있어야 함

**필요 카테고리**: 장바구니에 이 카테고리의 제품 중 하나 이상이 있어야 함

**사용 사례**: 제품별 무료 배송, 프로모션 패키지

**예시**: "프로모션 아이템 A"가 장바구니에 있을 때 무료 배송
```
필요 제품: [제품 ID 123]
```

### 제품 제외

**제외 제품**: 장바구니에 이 제품 중 하나라도 있으면 규칙이 적용되지 않음

**제외 카테고리**: 장바구니에 이 카테고리의 제품 중 하나라도 있으면 규칙이 적용되지 않음

**사용 사례**: 무료 배송에서 중량/대형 품목 제외

**예시**: 가구 카테고리 제외 무료 배송
```
제외 카테고리: [가구]
```

### 고객 그룹

- **고객 그룹**: 선택한 그룹(VIP, 도매 등)에 속한 고객에게만 규칙이 적용됨
- **비선택**: 규칙이 모든 고객 그룹에 적용됨
- **사용 사례**: VIP 혜택, 도매 할인

**예시**: VIP 회원에게 15% 배송 할인
```
고객 그룹: ["VIP"]
```

### 첫 구매 고객

- **First Time Customer**: Toggle to restrict rule to customers with no previous orders
- **Use Case**: New customer welcome offers

**Example**: $5 off shipping for first order
```
First Time Customer: Yes
```


## Rule Priority & Execution

Rules execute in **priority order** (higher number = earlier execution):

### Priority Mechanics

**Example Execution**:
```
Rule A (Priority 100): Free shipping if cart > $50
Rule B (Priority 50): 10% discount on all shipping
Rule C (Priority 1): $2 surcharge for remote zones

Cart: $60, Remote zone
Base shipping cost: $15

Step 1: Rule A evaluates (Priority 100)
  Cart > $50? YES
  Apply: Set cost to $0
  Cost now: $0

Step 2: Rule B evaluates (Priority 50)
  Apply 10% discount to $0
  Cost now: $0 (still free)

Step 3: Rule C evaluates (Priority 1)
  Add $2 surcharge to $0
  Cost now: $2

Final cost: $2
```

**Stop Further Rules Flag**:

If Rule A has `stop_further_rules = True`:
```
Rule A (Priority 100, stop_further_rules=True): Free shipping if cart > $50
Rule B (Priority 50): 10% discount
Rule C (Priority 1): $2 surcharge

Cart: $60
Base: $15

Step 1: Rule A applies, sets cost to $0
        stop_further_rules = True → STOP

Final cost: $0 (Rules B and C never execute)
```


## Creating Shipping Rules

**Step-by-Step Workflow**:

1. **Navigate to Rules**
   - Settings > Shipping > Shipping Rules
   - Click "Add Shipping Rule"

2. **Basic Configuration**
   - **Name**: Internal identifier (e.g., "Free Shipping Over $50")
   - **Description**: Optional notes (not shown to customers)
   - **Active**: Toggle to enable/disable
   - **Priority**: Set execution order (100 for high priority, 1 for low)

3. **Choose Rule Type**
   - Select adjustment type (discount %, discount fixed, set cost, free, surcharge %, surcharge fixed)
   - Enter amount or percentage

4. **정지 플래그 설정** (선택적)
  - 이 규칙이 하위 우선순위 규칙의 실행을 방지해야 하는 경우 "더 이상 규칙 실행 중지" 체크박스를 선택하세요
  - 예: 무료 배송은 이후에 추가 요금이 부과되지 않도록 해야 합니다.

5. **조건 정의** (선택적 - 항상 적용되도록 비워 두세요)
  - 시간 유효성: 시작/종료 날짜
  - 장바구니 가치: 최소/최대
  - 장바구니 무게: 최소/최대
  - 항목 수: 최소/최대
  - 지역: 적용 가능한 지역 선택
  - 방법: 적용 가능한 방법 선택
  - 제품: 필수 또는 제외
  - 고객: 그룹 또는 첫 방문 고객만

6. **규칙 저장**
  - 저장을 클릭하세요
  - 규칙은 활성화 토글이 "예"인 경우 즉시 적용됩니다.

## 규칙 조합 전략

### 전략 1: 할인 중첩

**여러 할인을 중첩 적용할 수 있습니다**:
```
규칙 A (우선순위 100): VIP 고객에게 10% 할인 → stop_further_rules=No
규칙 B (우선순위 50): $100 이상 주문에 15% 할인 → stop_further_rules=No

VIP 고객이 $120 주문:
기본: $15
규칙 A 적용 후: $13.50 (10% 할인)
규칙 B 적용 후: $11.48 (13.50 달러에 15% 할인)
```

### 전략 2: 예외 규칙

**단 하나의 규칙만 적용됩니다** (가장 높은 우선순위):
```
규칙 A (우선순위 100): $50 이상 주문 시 무료 배송 → stop_further_rules=Yes
규칙 B (우선순위 50): 모든 배송에 20% 할인 → stop_further_rules=Yes

$50 이상 장바구니:
규칙 A가 적용됩니다 → 무료 배송 → 중지
규칙 B는 실행되지 않습니다
```

### 전략 3: 조건부 수수료

마크다운 형식, 이미지 경로, 코드 블록, 기술 용어를 보존합니다.

**할인은 먼저, 부과금은 나중에**:
```
규칙 A (우선순위 100): $75 이상 주문 시 무료 배송
규칙 B (우선순위 75): 15% VIP 할인
규칙 C (우선순위 50): 10% 일반 할인
규칙 D (우선순위 25): $5 원거리 지역 추가 요금
규칙 E (우선순위 1): 10% 연료 추가 요금

주문: $80, 원거리 지역, VIP 고객
기본: $20
A: $80 > $75 → 무료 ($0)
B: VIP → $0의 15% 할인 = $0
C: $0의 10% 할인 = $0
D: 원거리 지역 +$5 = $5
E: 연료 +$5의 10% = $5.50

최종: $5.50 (추가 요금으로 인해 무료가 아님)
```

**이를 방지하려면 stop_further_rules=Yes를 사용하십시오**:
```
규칙 A (우선순위 100, stop=Yes): $75 이상 주문 시 무료 배송

같은 주문:
A: $80 > $75 → 무료 ($0) → 중지
최종: $0 (진짜 무료)
```

## 문제 해결

**문제 1: 규칙이 적용되지 않음**

**원인**:
- 규칙이 비활성화됨
- 하나 이상의 조건이 충족되지 않음
- 더 높은 우선순위의 규칙이 stop_further_rules=Yes로 설정됨
- 유효 기간이 현재 날짜와 일치하지 않음

**해결**: 모든 조건을 검토하고, 우선순위를 확인하고, 활성 상태를 확인하십시오.

---

**문제 2: 예상치 않은 할인 금액**

**원인**:
- 여러 규칙이 중첩됨
- 이미 할인된 금액에 백분율 적용됨
- 규칙 우선순위가 잘못됨

**해결**: 우선순위 순서를 확인하고, stop_further_rules 플래그을 검토하고, 실행 흐름을 수동으로 추적하십시오.

---

**문제 3: 무료 배송이 작동하지 않음**

**원인**:
- 더 낮은 우선순위의 추가 요금 규칙이 무료 배송 규칙 이후에 비용을 추가함
- 장바구니가 최소 금액 기준을 충족하지 않음
- 장바구니에 제외된 제품이 있음

**해결책**: 무료 배송 규칙에 대해 stop_further_rules=Yes를 사용하고, 조건을 확인하고, 예외를 확인하십시오.

- **설명적인 이름 사용** - "VIP 20% 할인 (우선순위 75)"은 "규칙 3"보다 나쁩니다
- **복잡한 로직 문서화** - 설명 필드에 주석을 추가하십시오
- **간단한 규칙부터 시작하십시오** - 복잡성을 점진적으로 추가하십시오
- **규칙 성능 모니터링** - 규칙이 사용되는지 또는 혼동을 일으키는지 확인하십시오

- **지리적 영역 사용** - 국가별로 동일한 규칙을 여러 개 사용하는 것보다 나은 방법입니다

- **명확한 시간 창 설정** - 항상 프로모션의 종료 날짜를 포함하십시오
- **경계 사례 테스트** - 정확히 $50, 정확히 5개의 항목 등입니다
