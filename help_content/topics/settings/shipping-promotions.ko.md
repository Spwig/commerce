---
title: 배송 프로모션
---

배송 규칙은 장바구니 내용, 고객 속성 및 배송 지역에 따라 배송 방법에 조건부 비용 조정을 적용합니다. $50 이상 주문 시 무료 배송 제공, 원격 지역에 추가 요금 부과, VIP 고객에게 배송 할인 제공 등이 포함됩니다. 규칙은 우선순위 기반으로 실행되며(높은 우선순위부터), 추가 처리를 방지하기 위한 선택적 중단 플래그를 사용할 수 있습니다. 각 규칙은 여러 조건(장바구니 금액, 무게, 지역, 제품, 고객 그룹)을 평가하고 모든 조건이 일치할 때 6가지 조정 유형 중 하나를 실행합니다.

주문 맥락에 따라 동적으로 배송 비용을 변경해야 할 때 배송 프로모션을 사용합니다. 단순히 배송 방법에서 정적 비용만 제공하는 것이 아니라,

## 배송 프로모션 유형

배송 규칙은 6가지 유형의 비용 조정을 적용합니다:

### 비율 할인

**기능**: 배송 비용을 비율로 감소시킵니다(예: 25% 할인).

**공식**: `new_cost = base_cost × (1 - percent/100)`

**예시**:
```
기본 비용: $20
할인: 25%
결과: $15
```

**사용 사례**:
- VIP 고객 할인(모든 배송에 20% 할인)
- 계절 프로모션(12월 배송에 15% 할인)
- 대량 주문 할인(5개 이상 주문 시 배송 10% 할인)

---

### 고정 할인

**기능**: 배송 비용에서 고정 금액을 뺍니다.

**공식**: `new_cost = base_cost - amount` (최소 $0)

**예시**:
```
기본 비용: $15
할인: $5
결과: $10
```

**사용 사례**:
- 첫 구매 고객 보너스(첫 주문 배송에 $5 할인)
- 뉴스레터 등록 보상(배송에 $3 할인)
- 충성도 프로그램 혜택(월별 배송에 $10 할인)

---

### 비용 대체

**기능**: 배송 비용을 특정 금액으로 대체합니다.

**공식**: `new_cost = fixed_amount`

**예시**:
```
기본 비용: $25
설정 금액: $9.99
결과: $9.99
```

**사용 사례**:
- 플래시 세일(오늘 모든 주문에 $5 배송)
- 카테고리별 배송(도서는 항상 $3.99 배송)
- 시간 기반 프로모션(이번 주 배송은 $9.99로 제한)

---

### 무료 배송

**기능**: 배송 비용을 $0으로 설정합니다.

**공식**: `new_cost = $0`


**예시**:
```
기본 비용: $18
규칙 적용
결과: $0
```

**사용 사례**:
- $50 이상 무료 배송
- 특정 제품에 대한 무료 배송 (프로모션 상품)
- VIP 고객에게 무료 배송
- 3개 이상의 상품이 있는 주문에 무료 배송

---

### 추가 요금 (고정)

**기능**: 배송 비용에 고정 금액을 추가합니다.

**공식**: `new_cost = base_cost + amount`

**예시**:
```
기본 비용: $12
추가 요금: $5
결과: $17
```

**사용 사례**:
- 원격 지역 배송 요금
- 과대형 상품 처리 비용
- 토요일 배송 추가 요금
- 취약한 상품 포장 비용

---

### 추가 요금 (백분율)

**기능**: 배송 비용을 백분율로 증가시킵니다.

**공식**: `new_cost = base_cost × (1 + percent/100)`

**예시**:
```
기본 비용: $20
추가 요금: 15%
결과: $23
```

**사용 사례**:
- 피크 시즌 추가 요금 (휴일 기간 동안 20%)
- 익스프레스 배송 프리미엄 (50% 추가 요금)
- 연료 추가 요금 (현재 요금 기준으로 변동)

## 프로모션 조건

프로모션은 **모든 조건이 충족되어야** 규칙이 적용됩니다:

### 시간 유효성

- **시작 날짜**: 이 날짜 이후에만 규칙이 활성화됩니다
- **종료 날짜**: 이 날짜 이전에만 규칙이 활성화됩니다
- **사용 사례**: 계절별 프로모션, 한정 시간 제안

**예시**: 블랙 프라이데이 주말에만 무료 배송
```
시작: 2026-11-27 00:00
종료: 2026-11-30 23:59
```

---

### 장바구니 금액 범위

- **최소 장바구니 금액**: 장바구니 소계가 amount 이상이어야 합니다
- **최대 장바구니 금액**: 장바구니 소계가 amount 이하이어야 합니다
- **사용 사례**: 무료 배송 임계값, 계층별 할인

**예시**: $50-$200 주문에 무료 배송
```
최소: $50
최대: $200
```

---

### 장바구니 무게 범위

- **최소 무게**: 총 장바구니 무게가 amount 이상이어야 합니다
- **최대 무게**: 총 장바구니 무게가 amount 이하이어야 합니다
- **사용 사례**: 가벼운 배송 할인, 무거운 상품 추가 요금

**예시**: 20kg 이상 주문에 $5 추가 요금
```
최소 무게: 20kg
최대 무게: null (무제한)
```

---

### 상품 수 범위


- **최소 항목 수**: 장바구니에 항목 수량이 ≥ 이어야 함
- **최대 항목 수**: 장바구니에 항목 수량이 ≤ 이어야 함
- **사용 사례**: 대량 주문 할인, 단일 항목 수수료

**예시**: 5개 이상 주문 시 무료 배송
```
Min Items: 5
Max Items: null
```

---

### 배송 지역

- **지역**: 고객 주소가 선택한 지역 중 하나와 일치할 때만 규칙이 적용됨
- **빈 선택**: 모든 지역에 규칙이 적용됨
- **사용 사례**: 지역별 추가 요금 또는 할인

**예시**: 국내 지역만 무료 배송
```
Zones: ["Domestic USA"]
```

---

### 배송 방식

- **방식**: 특정 배송 방식에만 규칙이 적용됨
- **빈 선택**: 모든 방식에 규칙이 적용됨
- **사용 사례**: 방식별 프로모션

**예시**: 익스프레스 배송 25% 할인
```
Methods: ["Express Delivery"]
```

---

### 제품 요구 사항

**필요한 제품**: 장바구니에 이 제품 중 하나 이상이 포함되어야 함

**필요한 카테고리**: 장바구니에 이 카테고리 중 하나 이상의 제품이 포함되어야 함

**사용 사례**: 특정 제품의 무료 배송, 프로모션 번들

**예시**: 장바구니에 "프로모션 항목 A"가 포함되면 무료 배송
```
Requires Products: [Product ID 123]
```

---

### 제품 제외

**제외 제품**: 장바구니에 이 제품 중 하나 이상이 포함되면 규칙이 적용되지 않음

**제외 카테고리**: 장바구니에 이 카테고리 중 하나 이상의 제품이 포함되면 규칙이 적용되지 않음

**사용 사례**: 무거운/초과 크기 제품을 무료 배송에서 제외

**예시**: 가구 카테고리 제외한 무료 배송
```
Excludes Categories: [Furniture]
```

---

### 고객 그룹

- **고객 그룹**: 선택한 그룹(VIP, 도매 등)에 속한 고객에게만 규칙이 적용됨
- **빈 선택**: 모든 고객 그룹에 규칙이 적용됨
- **사용 사례**: VIP 혜택, 도매 할인

**예시**: VIP 멤버에게 15% 배송 할인
```
Customer Groups: ["VIP"]
```

---

### 첫 방문 고객


- **처음 방문 고객**: 규칙을 이전 주문이 없는 고객에게 제한하도록 전환
- **사용 사례**: 신규 고객 환영 혜택

**예시**: 첫 주문 시 $5 배송비 할인
```
First Time Customer: Yes
```

## 프로모션 우선순위 및 실행

프로모션은 **우선순위 순서**에 따라 실행됩니다 (숫자가 높을수록 먼저 실행):

### 우선순위 메커니즘

**실행 예시**:
```
프로모션 A (우선순위 100): 장바구니 금액이 $50 이상일 경우 무료 배송
프로모션 B (우선순위 50): 모든 배송비에 10% 할인
프로모션 C (우선순위 1): 원격 지역에 $2 추가 요금

장바구니: $60, 원격 지역
기본 배송비: $15

단계 1: 프로모션 A 평가 (우선순위 100)
  장바구니 금액이 $50 이상인가? 네
  적용: 비용을 $0으로 설정
  현재 비용: $0

단계 2: 프로모션 B 평가 (우선순위 50)
  $0에 10% 할인 적용
  현재 비용: $0 (계속 무료)

단계 3: 프로모션 C 평가 (우선순위 1)
  $0에 $2 추가 요금 적용
  현재 비용: $2

최종 비용: $2
```

**추가 프로모션 중단 플래그**:

프로모션 A가 `stop_further_promotions = True`인 경우:
```
프로모션 A (우선순위 100, stop_further_promotions=True): 장바구니 금액이 $50 이상일 경우 무료 배송
프로모션 B (우선순위 50): 10% 할인
프로모션 C (우선순위 1): $2 추가 요금

장바구니: $60
기본: $15

단계 1: 프로모션 A 적용, 비용을 $0으로 설정
        stop_further_promotions = True → 중단

최종 비용: $0 (규칙 B 및 C는 실행되지 않음)
```

## 배송 프로모션 생성

**단계별 워크플로**:

1. **규칙으로 이동**
   - 설정 > 배송 > 배송 프로모션
   - "배송 프로모션 추가" 클릭

2. **기본 구성**
   - **이름**: 내부 식별자 (예: "$50 이상 무료 배송")
   - **설명**: 선택적 메모 (고객에게 표시되지 않음)
   - **활성**: 활성화/비활성화 전환
   - **우선순위**: 실행 순서 설정 (100은 높은 우선순위, 1은 낮은 우선순위)

3. **프로모션 유형 선택**
   - 조정 유형 선택 (할인 %, 할인 고정, 비용 설정, 무료, 추가 요금 %, 추가 요금 고정)
   - 금액 또는 비율 입력

4. **중지 플래그 설정** (선택 사항)
   - 이 규칙이 하위 우선순위 프로모션의 실행을 방지해야 한다면 "추가 프로모션 중지"를 선택하세요
   - 최종/절대 규칙에 사용 (예: 무료 배송에는 이후 추가 요금이 붙어서는 안 됩니다)

5. **조건 정의** (선택 사항 - 비워두면 "항상 적용")
   - 시간 유효성: 시작/종료 날짜
   - 장바구니 금액: 최소/최대
   - 장바구니 무게: 최소/최대
   - 항목 수: 최소/최대
   - 지역: 적용 가능한 지역 선택
   - 방법: 적용 가능한 방법 선택
   - 상품: 필수 또는 제외
   - 고객: 그룹 또는 첫 방문자만

6. **규칙 저장**
   - 저장 버튼 클릭
   - 규칙이 즉시 활성화 됩니다 (활성화 전환 스위치가 Yes인 경우)

## 일반적인 배송 프로모션 시나리오

### 시나리오 1: $50 이상 무료 배송

**목표**: 장바구니 총액이 $50 이상일 때 무료 배송 제공.

**설정**:
```
이름: $50 이상 무료 배송
유형: 무료 배송
우선순위: 100
조건:
  최소 장바구니 금액: $50
추가 프로모션 중지: Yes
```

---

### 시나리오 2: 원격 지역 추가 요금

**목표**: 원격 지역 배송에 $10 추가 요금 부과.

**설정**:
```
이름: 원격 지역 추가 요금
유형: 고정 요금
금액: $10
우선순위: 50
조건:
  지역: ["원격 지역"]
추가 프로모션 중지: No
```

---

### 시나리오 3: VIP 고객 20% 할인

**목표**: VIP 고객에게 모든 배송에 대해 20% 할인 제공.

**설정**:
```
이름: VIP 배송 할인
유형: 비율 할인
비율: 20
우선순위: 75
조건:
  고객 그룹: ["VIP"]
추가 프로모션 중지: No
```

---

### 시나리오 4: 연말 고정 요금

**목표**: 12월 동안 모든 배송 요금을 $9.99로 제한.

**설정**:
```
이름: 12월 고정 요금 프로모션
유형: 요금 대체
금액: $9.99
우선순위: 100
조건:
  시작 날짜: 2026-12-01
  종료 날짜: 2026-12-31
추가 프로모션 중지: Yes
```

---

### 시나리오 5: 무거운 항목 추가 요금

**목표**: 25kg 이상 주문에 $15 요금 추가.


**설정**:
```
이름: 중량 많은 주문 추가 요금
유형: 추가 요금 (고정)
금액: $15
우선순위: 50
조건:
  최소 무게: 25kg
추가 프로모션 중단: 아니오
```

---

### 시나리오 6: 첫 주문 무료 배송

**목표**: 신규 고객은 첫 주문 시 무료 배송을 받습니다.

**설정**:
```
이름: 첫 주문 무료 배송
유형: 무료 배송
우선순위: 100
조건:
  첫 방문 고객: 예
추가 프로모션 중단: 예
```

---

### 시나리오 7: 카테고리별 무료 배송

**목표**: 프로모션 카테고리 상품을 포함한 주문에 대해 무료 배송을 제공합니다.

**설정**:
```
이름: 프로모션 카테고리 무료 배송
유형: 무료 배송
우선순위: 90
조건:
  필요한 카테고리: ["프로모션"]
추가 프로모션 중단: 예
```

### 시나리오 8: 가구 배송 제외

**목표**: $50 이상 주문 시 무료 배송, 하지만 장바구니에 가구가 포함된 경우 예외입니다.

**해결책**: 두 가지 규칙

**프로모션 1**:
```
이름: 일반 무료 배송
유형: 무료 배송
우선순위: 50
조건:
  최소 장바구니 금액: $50
  제외 카테고리: ["가구"]
추가 프로모션 중단: 아니오
```

**프로모션 2**:
```
이름: 가구 주문 $5 할인
유형: 할인 (고정)
금액: $5
우선순위: 40
조건:
  필요한 카테고리: ["가구"]
  최소 장바구니 금액: $50
추가 프로모션 중단: 아니오
```

---

## 프로모션 조합 전략

### 전략 1: 할인 누적

**여러 할인이 누적 가능**:
```
프로모션 A (우선순위 100): VIP 고객 10% 할인 → stop_further_promotions=No
프로모션 B (우선순위 50): $100 이상 주문 15% 할인 → stop_further_promotions=No

VIP 고객의 $120 주문:
기본 금액: $15
프로모션 A 적용 후: $13.50 (10% 할인)
프로모션 B 적용 후: $11.48 (15% 할인 $13.50)
```

### 전략 2: 독점 규칙

**한 가지 규칙만 적용** (가장 높은 우선순위):
```
프로모션 A (우선순위 100): $50 이상 무료 배송 → stop_further_promotions=Yes
프로모션 B (우선순위 50): 모든 배송 20% 할인 → stop_further_promotions=Yes
```

장바구니 > $50:
프로모션 A 적용 → 무료 배송 → STOP
프로모션 B는 실행되지 않음
```

### 전략 3: 조건부 추가 요금

**할인 먼저, 추가 요금 마지막**:
```
프로모션 A (우선순위 100): $75 이상 무료 배송
프로모션 B (우선순위 75): 15% VIP 할인
프로모션 C (우선순위 50): 10% 일반 할인
프로모션 D (우선순위 25): 원격 지역 $5 추가 요금
프로모션 E (우선순위 1): 연료 추가 요금 10%

주문: $80, 원격 지역, VIP 고객
기본: $20
A: $80 > $75 → 무료 ($0)
B: VIP → $0의 15% 할인 = $0
C: $0의 10% 할인 = $0
D: 원격 지역 +$5 = $5
E: 연료 +$5의 10% = $5.50

최종: $5.50 (추가 요금으로 인해 무료가 아님)
```

**이를 방지하려면 stop_further_promotions=Yes 사용**:
```
프로모션 A (우선순위 100, stop=Yes): $75 이상 무료 배송

동일한 주문:
A: $80 > $75 → 무료 ($0) → STOP
최종: $0 (진짜 무료)
```

## 배송 프로모션 테스트

**라이브 전에**:

1. **테스트 장바구니 생성**
   - 장바구니 A: $25 (기준 미달)
   - 장바구니 B: $55 (기준 초과)
   - 장바구니 C: $200 + 원격 지역
   - 장바구니 D: VIP 고객

2. **각 규칙 테스트**
   - 결제 창으로 이동
   - 올바른 배송 비용 표시 확인
   - 규칙 실행 순서 확인

3. **우선순위 해결 테스트**
   - 여러 규칙이 일치하는 경우
   - 우선순위가 높은 규칙이 먼저 실행되는지 확인
   - stop_further_promotions 행동 확인

4. **경계 사례 테스트**
   - 정확히 기준에 해당하는 장바구니 금액
   - 여러 조건이 일치하는 경우
   - 충돌하는 규칙

## 문제 해결

**문제 1: 프로모션 적용되지 않음**

**원인**:
- 규칙이 비활성화됨
- 하나 이상의 조건이 충족되지 않음
- 더 높은 우선순위 규칙이 stop_further_promotions=Yes 설정됨
- 유효 기간이 현재 날짜 외부에 있음

**해결책**: 모든 조건 검토, 우선순위 확인, 활성 상태 확인.

---

**문제 2: 예상치 못한 할인 금액**

**원인**:
- 여러 프로모션이 중첩됨
- 비율이 이미 할인된 비용에 적용됨
- 규칙 우선순위가 잘못됨

**해결책**: 우선순위 순서 확인, stop_further_promotions 플래그 검토, 실행 흐름 수동 추적.

**문제 3: 무료 배송이 작동하지 않음**

**원인**:
- 무료 배송 프로모션 이후에 우선순위가 낮은 추가 비용 규칙이 적용됨
- 장바구니의 최소 금액 기준을 충족하지 못함
- 장바구니에 제외된 상품이 포함됨

**해결책**: 무료 배송 프로모션에 stop_further_promotions=Yes를 사용하고, 조건을 확인하며, 제외 사항을 확인하세요.

- **무료 배송에 높은 우선순위 사용** - 우선순위 100은 다른 조정 사항보다 먼저 실행됩니다
- **절대 규칙에 대해 stop_further_promotions 설정** - 무료 배송은 추가 처리를 중단해야 합니다
- **규칙 조합 테스트** - 여러 프로모션은 예상치 못한 방식으로 상호작용할 수 있습니다
- **설명적인 이름 사용** - "VIP 20% 할인 (우선순위 75)"은 "프로모션 3"보다 좋습니다
- **복잡한 논리 문서화** - 설명 필드에 주석을 추가하세요
- **간단한 프로모션부터 시작** - 복잡성을 점진적으로 추가하세요
- **규칙 성능 모니터링** - 규칙이 사용되고 있는지 또는 혼란을 일으키는지 확인하세요
- **과도한 프로모션 피하기** - 너무 많은 프로모션은 결제 과정을 느리게 합니다, 최대 5~10개 사용하세요
- **지리적 영역을 위한 존 사용** - 국가별로 유사한 규칙을 여러 개 사용하는 것보다 좋습니다
- **방법과 함께 사용** - 규칙 + 방법은 복잡한 가격 설정에 함께 작동합니다
- **명확한 시간 범위 설정** - 프로모션에 종료 날짜를 항상 포함하세요
- **경계 사례 테스트** - 정확히 $50, 정확히 5개 항목 등
