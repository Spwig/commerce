---
title: 在庫通知
---

在庫通知は、在庫切れの製品が再び入手可能になると電子メールで通知されるように顧客が登録できる機能です。在庫表示設定は製品ページで顧客が見る内容を制御し、在庫状態ラベルや在庫切れの警告、製品が在庫切れになると何が起こるかなどを制御します。

## 在庫表示設定

在庫表示設定は、カテゴリーや製品レベルで上書きされるまで、すべての製品に適用される店舗全体のデフォルトです。

これらのオプションを構成するには、**カタログ > 在庫表示設定**に移動してください。あなたのストア用に1件の設定レコードがあります。編集するにはそれをクリックしてください。

### 在庫状態の表示

| セットアップ | 説明 |
|---------|-------------|
| **在庫状態を表示** | 製品ページに「在庫あり」または「在庫切れ」ラベルを表示します |
| **在庫切れの警告を表示** | 在庫が少なくなっているときに「X個しかありません」と表示されます |
| **ロウストックしきい値** | 在庫切れの警告が表示される数量（デフォルト: 5） |
| **正確な在庫数を表示** | 一般的な警告ではなく、正確な残数量（例: 「3個しかありません！」）を表示します |

### 在庫切れ時の動作

**在庫切れ時のアクション**設定は、製品に在庫がなければ顧客が見る内容を決定します:

| アクション | 顧客が見る内容 |
|--------|-------------------|
| **一覧から非表示** | 製品がカテゴリーページや検索結果から削除されます |
| **非表示として表示** | 製品は表示されますが、カートに追加することはできません |
| **「在庫復帰通知」ボタンを表示** | 顧客は在庫が戻るのを通知するために電子メールを登録できます |
| **バックオーダーを許可** | 在庫がゼロでも製品を購入できます |

製品が入手不可のときに表示されるテキストをカスタマイズするには、**在庫切れメッセージ**を設定してください（デフォルト: `在庫切れ`）。

バックオーダー可能な製品のときに表示されるテキストをカスタマイズするには、**バックオーダーメッセージ**を設定してください（デフォルト: `バックオーダー可能`）。

### 送料と配送の表示

Markdownフォーマット、画像パス、コードブロック、技術用語をすべて保持してください。

| Setting | Description |
|---------|-------------|
| **"Ships From" の場所を表示** | 製品ページに在庫場所名を表示します |
| **推定配達日を表示** | 在庫場所から計算された推定配達日を表示します |

### バックオーダーを許可する (サイト全体) 

デフォルトで、在庫切れの製品をカスタマーアクセス可能にするには、**バックオーダーを許可する** をチェックしてください。個々の製品やカテゴリは、この設定を上書きできます。

## 在庫切れ通知

在庫切れのアクションを **"Notify Me" ボタンを表示** に設定すると、カスタマーは製品ページで電子メールアドレスを入力して、製品が再入荷したときに電子メールを受信できます。

### 通知リクエストの表示

すべてのカスタマーリクエストを確認するには、**カタログ > 在庫通知** に移動してください。各レコードには、次の情報が表示されます:
- カスタマーの電子メールアドレス
- 製品とバージョン (該当する場合)
- 顧客が地域的な選好を指定した場合の希望する在庫場所
- リクエストが作成された日時
- 通知が送信された日時 (まだ送信されていない場合は空)

### 通知が送信されるタイミング

在庫がゼロより多くなると、Spwigは在庫復活メールを自動的に送信します。**通知日時** フィールドには、メールが送信された日時が記録されます。

カスタマーは1回だけ通知メールを受け取ります。通知を受けた後、製品が再び在庫切れになると、再度サインアップする必要があります。

### 通知リクエストのフィルタリング

管理画面のフィルターを使用して、次のようなリクエストを検索できます:
- 特定の製品に関するリクエスト
- すでに通知されたリクエスト (誰が連絡済みか確認するため)
- まだ保留中のリクエスト (在庫復活を待っている顧客)

## 製品レベルのオーバーライド

サイト全体の在庫表示設定は、製品やカテゴリごとに上書きできます。製品編集フォームでは、グローバルデフォルトとは異なる製品固有の **在庫切れアクション** を設定できる **在庫** セクションが表示されます。

在庫切れの商品を許容する多くの製品に対して、一部の製品のみ「お知らせを受ける」に設定するなど、特定の製品を在庫切れ時に非表示にするなどの目的で役立ちます。

## トipp

- 通常使用する再注文ポイントに**在庫切れのしきい値**を設定し、在庫切れになる前に在庫が限られていることを顧客に通知してください。
- 在庫切れの製品を非表示にする代わりに**「お知らせを受ける」ボタンの表示**オプションを使用してください。登録した顧客は実際に需要があり、再入荷注文を正当化するためのものです。
- **正確な在庫数の表示**は控えめに使ってください。多くの場合、「あと3点のみ」と表示する方が正確な数値を表示するよりも、在庫の全体像を明らかにすることなく焦りを生むために効果的です。
- 新しい注文を出す前に在庫通知リストを確認してください。保留中の通知リクエストの数から、その製品に対する需要の大きさがわかります。
- バックオーダーを使用している場合は、**バックオーダーメッセージ**を更新して、正確な期待値を設定してください（例: 「2〜3週間で発送します。今すぐ注文して予約してください」）。
- 在庫切れの通知とメールマーケティングを組み合わせて使用してください。人気のある製品が再入荷した際には、自動通知メールだけでなく、登録者全員にキャンペーンを送信してください。
