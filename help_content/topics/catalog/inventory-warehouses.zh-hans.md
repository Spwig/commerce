---
title: 库存与仓库
---

仓库系统允许您管理多个地点的库存，设置履行优先级，并实时跟踪库存水平。在管理后台侧边栏中导航至 **Products > Warehouses** 以管理您的仓库位置。

![仓库列表](/static/core/admin/img/help/inventory-warehouses/warehouse-list.webp)

## 仓库

### 仓库列表

仓库页面以卡片形式显示您所有的库存位置，包括：

- **名称和代码** — 仓库标识符（例如，"主仓库"，代码 "MAIN-WH"）
- **销售区域** — 地理区域分配
- **状态徽章** — 激活/非激活，零售地点
- **统计数据** — 库存商品，履行优先级，库存缓冲百分比
- **位置** — 城市和国家
- **最后更新** — 库存水平最后修改时间

### 创建仓库

1.

点击 **+ 添加仓库**
2.

填写 **基本信息**：
   - **名称** — 描述性标签（例如，"美国东岸仓库"）
   - **代码** — 短暂的唯一标识符（例如，"US-EAST"） — 必须在所有仓库中唯一
   - **销售区域** — 分配到地理区域以进行履行路由
   - **激活** — 启用以包含在履行中
3.

在 **地址** 部分填写完整的仓库地址
4.

配置 **履行设置**：
   - **履行优先级** — 数字越大 = 订单履行的优先级越高
   - **库存缓冲百分比** — 保留库存的百分比作为安全缓冲（0–100）
   - **发货地点** — 如果此仓库支持客户自提，可选择链接到一个取货地点
5.

配置 **客户显示**（可选）：
   - **显示名称** — 客户端标签（例如，"从澳大利亚发货"）。

   留空以使用仓库名称。
   - **在前端显示** — 在产品页面上向客户显示此仓库的来源
6.

保留所有markdown格式，图片路径，代码块和术语。

配置 **POS / 零售门店**（可选）：
  - **零售地点** — 勾选此仓库是否也作为拥有POS终端的实体店
  - **POS显示名称** — 在POS界面中显示的简称
  - **门店组** — 分配到一个POS门店组以继承设置
7.

如果需要，请添加 **联系信息**（姓名、电子邮件、电话）
8.

点击 **保存**

### 配货优先级

当有订单进来时，系统会根据以下因素选择最佳仓库：

1. **优先级值** — 优先级较高的仓库会被优先选择
2. **库存可用性** — 必须有足够的库存
3. **地区匹配** — 客户所在地区的仓库优先

例如，如果你有一个美国仓库（优先级100）和一个欧洲仓库（优先级60），美国订单将首先从美国仓库配货。

### 库存缓冲

库存缓冲会保留一定百分比的库存，不会在线销售。这在以下情况下很有用：
- 需要展示库存的实体店
- 安全库存以防止超售
- 保留库存用于批发订单

100个单位的10%缓冲意味着只有90个单位可用于在线订单。

## 库存条目

库存条目代表特定产品在特定仓库的实际库存。

### 查看库存水平

1. 点击任何仓库卡片上的 **库存图标** 以查看其库存条目
2. 或导航到产品的 **库存** 选项卡以查看所有仓库的库存

每个库存条目显示：
- **产品名称** 和变体（如果适用）
- **当前库存** — 总体实物库存
- **已分配** — 为待处理订单保留的数量
- **可用** — 当前库存减去已分配（可用于销售的数量）

### 添加库存

1.

导航到 **产品 > 库存条目** 并点击 **+ 添加库存条目**，或者
2.

打开产品的编辑表单并在底部的 **库存条目** 内联部分进行操作
3.

选择 **产品** 和 **仓库**（对于变体产品，可选地选择 **变体**）
4.

输入 **当前库存** 数量
5.

保留所有markdown格式、图片路径、代码块和术语。

设置 **库存低阈值** —— 此单品阈值会触发库存不足警报
6。

保存

### 库存变动

每次库存变动都会被记录为 **库存变动** ：

| 变动类型 | 描述 |
|----------|------|
| **入库** | 从供应商处收到的新库存 |
| **销售** | 用于完成订单的库存扣除 |
| **退货** | 顾客退回的库存 |
| **调整** | 手动更正（盘点差异） |
| **调拨** | 在仓库之间转移 |
| **预留** | 暂时保留用于活跃购物车 |
| **损耗** | 记录为损坏或丢失 |
| **重新盘点** | 根据实际库存数量进行更正 |

库存变动提供了库存变化的完整审计追踪。除了 **调整库存级别** 操作之外，Spwig 还在库存列表中提供了批量操作，可以一次性转移、冲销和重新盘点多个项目的库存 —— 详见 [批量库存操作](/help/stock-bulk-actions)。

## 产品上的库存跟踪

### 启用库存跟踪

在产品的 **库存** 部分：

1. 将 **跟踪库存** 切换为开启，以启用此产品的库存管理
2. 设置 **库存低阈值** —— 当任何仓库的库存低于此级别时，会触发仪表板警报
3. 如果希望接受缺货时的订单，请配置 **允许缺货** 
4. 可选地设置 **缺货操作** 以覆盖此特定产品的站点范围或分类行为

启用跟踪后，使用产品表单底部的 **库存项** 内联部分来管理实际库存数量，或通过 **产品 > 库存项** 进行管理。

### 多仓库库存

当启用库存跟踪时，库存选项卡会显示所有仓库的库存水平汇总表：

- 所有地点的总库存
- 每个仓库的细分
- 预订和分配后的可用库存数量

## 库存低警报

系统会自动监控库存水平并在以下情况提醒您：
- 产品库存低于 **最低库存阈值**
- 产品库存达到 **零库存**

低库存警报显示在：
- **店铺仪表板** 的“需要处理的事项”部分
- 产品列表中带有视觉指示器

## 提示

- 从一个仓库开始，随着业务增长再添加更多仓库。
- 根据每个地区的运输速度和成本设置履行优先级。
- 为零售门店设置库存缓冲，以确保货架上有货。
- 定期审查库存变动，以识别库存差异或差异。
- 根据您的重新订购提前期设置最低库存阈值 —— 如果补货需要 2 周时间，请将阈值设置为覆盖 2 周的销售。
- 在上线前启用库存跟踪，以避免超售。

保留所有 markdown 格式、图片路径、代码块和术语。
