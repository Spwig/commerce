---
title: 銷售區域
---

銷售區域讓您定義商店的地理市場，並控制每個區域中可用的產品。當您跨多個國家或地區銷售時，這對您很有用，您需要針對每個地點的不同產品目錄、地區貨幣或庫存可用性。

## 什麼是銷售區域？

銷售區域是包含一個或多個國家的命名地理區域。每個區域都有預設貨幣、優先級，可以鏈接到一個或多個倉庫。當客戶瀏覽您的商店時，Spwig 會根據他們的地理位置確定其區域，並套用適當的貨幣和產品可見性規則。

常見使用案例：
- 顯示每個國家的客戶僅可購買當地可用的產品
- 分配地區特定的預設貨幣（例如，紐西蘭客戶的 NZD）
- 控制每個區域的訂單由哪些倉庫履行
- 隱藏某些市場中尚未上市的產品

## 創建銷售區域

1. 導航至 **庫存 > 銷售區域**。如果您看不到它，請在 **設定 > 商店設定 > 電商** 下啟用 **啟用多倉庫** 以顯示選單項目 —— 您不需要實際使用多個倉庫，它只會解鎖連結。您也可以直接轉到 `/admin/catalog/salesregion/`。
2. 點擊 **+ 新增銷售區域**
3. 填寫區域細節：

| 欄位 | 描述 | 範例 |
|-------|-------------|---------|
| **區域名稱** | 此區域的顯示名稱 | `亞太` |
| **區域代碼** | 短暫的唯一識別碼 | `APAC` |
| **國家** | 此區域包含的 ISO 國家代碼 | `["NZ", "AU", "SG", "FJ"]` |
| **預設貨幣** | 此區域的 ISO 貨幣代碼 | `NZD` |
| **優先級** | 較高優先級的區域會首先匹配 | `10` |
| **啟用** | 此區域當前是否在使用 | 勾選 |

4. 點擊 **儲存**

### 國家代碼

以兩位元 ISO 碼的 JSON 清單輸入國家。

保留所有 markdown 格式、圖片路徑、程式碼區塊和技術術語。

例如：
- 新西兰和澳大利亚: `["NZ", "AU"]`
- 仅新加坡: `["SG"]`
- 欧洲所有国家: `["DE", "FR", "IT", "ES", "NL", "BE", "AT", "CH", "SE", "NO", "DK", "FI", "PL"]`

### 优先级

如果客户的国家匹配多个地区，则使用优先级编号最高的地区。为更具体的地区设置更高的优先级（例如，给 NZ 设置优先级 20，APAC 设置优先级 10，这样新西兰客户会首先匹配到 NZ 地区）。

## 按地区控制产品可见性

默认情况下，每个产品在所有地区都可见。要限制某个产品，请在 **Products > All Products** 下打开它，并在其 **Region availability** 字段（在 Status 部分）中设置，仅在特定地区允许显示，或在所有地区除外特定地区显示，然后在该字段下方的表格中选择地区。

这也会决定产品不可用地区的顾客看到的内容——产品是完全从列表中隐藏，还是显示带有“不运送到 [地区]”提示。请参阅 **Region Availability** 指南以获取完整操作步骤，包括显示设置和商店端的 Ship-To 选择器。

## 区域货币

每个地区都有默认货币。如果你的商店明确支持多种货币（**Settings > Multi-Currency**），当客户的地区发生变化时（无论是从自动地区提示还是 Ship-To 选择器），其显示的货币会切换到其地区默认货币。仅有一种货币的商店，或未特意启用多货币的商店，无论地区如何，始终显示该单一货币。

要在多种货币中设置价格，请在 **Settings > Exchange Rates** 下配置汇率。价格可以按货币自动转换或手动设置。

## 将仓库链接到地区

当你在 **Catalog > Warehouses** 下创建或编辑仓库时，仓库将链接到地区。

每個倉庫都屬於一個地區，這會控制用於履行訂單的地區庫存。

如需有關倉庫的更多細節，請參閱 **庫存與倉庫** 的幫助主題。

## 小技巧

- 保持地區代碼簡短且具有描述性（`NZ`、`APAC`、`EU`、`US`）— 它們會在內部和日誌中使用。
- 為較小、更具體的地區使用較高的優先級編號，以便它們優先於較大的通用地區。
- 如果你只銷售到一個國家，則完全不需要配置地區— Spwig 可以正常運作，僅需一個全球目錄。
- 僅在實際需要限制產品時，才設置產品的 **地區可用性** 遠離 **所有地區均可用** — 默認情況下，產品會在全球範圍內可用，且無需維護。
- 每次新增銷售地區時，請審查每個產品的地區規則，以確保限制仍然符合你的意圖。
- 將「Ship-To Selector」新增到你的導航欄（參閱 **地區可用性** 指南），以便你可以切換地區並檢查受限制的產品是否按預期運作。
