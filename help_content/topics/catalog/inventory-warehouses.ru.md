---
title: Запасы и склады
---

Система складов позволяет управлять запасами в нескольких местах, устанавливать приоритеты выполнения заказов и отслеживать уровни запасов в реальном времени. Перейдите по ссылке **Продукты > Склады** в боковой панели администратора, чтобы управлять своими складскими помещениями.

![Список складов](/static/core/admin/img/help/inventory-warehouses/warehouse-list.webp)

## Склады

### Список складов

Страница склада отображает все ваши складские помещения в виде карточек с:

- **Названием и кодом** — идентификатор склада (например, "Основной склад", код "ОСН-СКЛ")
- **Регионом продаж** — географическое назначение региона
- **Значками статуса** — активный/неактивный, розничная точка
- **Статистикой** — количество товаров на складе, приоритет выполнения, процент резервного запаса
- **Расположением** — город и страна
- **Последнее обновление** — когда уровни запасов последний раз изменялись

### Создание склада

1. Нажмите **+ Добавить склад**
2. Заполните раздел **Основная информация**:
   - **Название** — описательная метка (например, "Склад на востоке США")
   - **Код** — короткий уникальный идентификатор (например, "ВОСТОК-США") — должен быть уникальным во всех складах
   - **Регион продаж** — назначьте географический регион для маршрутизации выполнения заказов
   - **Активный** — включите, чтобы включить в выполнение заказов
3. Заполните раздел **Адрес** полным адресом склада
4. Настройте **Параметры выполнения**:
   - **Приоритет выполнения** — большие числа = более высокий приоритет для выполнения заказов
   - **Процент резервного запаса** — процент запасов, который нужно зарезервировать как резервный запас (0–100)
   - **Место отправки** — по желанию свяжитесь с местом самовывоза, если этот склад поддерживает самовывоз клиентами
5. Настройте **Отображение для клиентов** (по желанию):
   - **Название для отображения** — метка, видимая клиентам (например, "Отправка из Австралии"). Оставьте пустым, чтобы использовать название склада.
   - **Показывать на сайте** — отображать происхождение этого склада клиентам на страницах товаров
6. Настройте **POS / Розничный магазин** (по желанию):
   - **Розничная точка** — отметьте, если этот склад также служит физическим магазином с терминалами POS
   - **Название для отображения POS** — короткое имя, отображаемое в интерфейсе POS
   - **Группа магазинов** — назначьте группе магазинов POS для наследования настроек
7. Добавьте **Контактную информацию**, если это необходимо (имя, электронная почта, телефон)
8. Нажмите **Сохранить**

### Приоритет выполнения

Когда поступает заказ, система выбирает лучший склад на основе:

1. **Значение приоритета** — склады с более высоким приоритетом предпочтительнее
2. **Доступность запасов** — должен быть достаточный запас
3. **Соответствие региону** — склады в регионе клиента предпочтительнее

Например, если у вас есть склад в США (приоритет 100) и склад в Европе (приоритет 60), заказы из США будут выполняться со склада в США в первую очередь.

### Резервный запас

Резервный запас резервирует процент запасов, который не будет продаваться в интернете. Это полезно для:

- физических розничных магазинов, которым нужен товар на прилавке
- резервного запаса для предотвращения перепродажи
- зарезервированных запасов для оптовых заказов

10% резервного запаса на 100 единиц означает, что доступно только 90 единиц для онлайн-заказов.

## Статьи запасов

Статьи запасов представляют собой фактические запасы конкретного товара на конкретном складе.

### Просмотр уровней запасов

1. Нажмите на **иконку запасов** на любой карточке склада, чтобы увидеть статьи запасов
2. Или перейдите на вкладку **Запасы** товара, чтобы увидеть запасы на всех складах

Каждая статья запасов показывает:

- **Название товара** и вариант (если применимо)
- **Есть в наличии** — общий физический запас
- **Зарезервировано** — количество, зарезервированное для неоконченных заказов
- **Доступно** — есть в наличии минус зарезервировано (что можно продать)

### Добавление запасов

1. Перейдите по ссылке **Продукты > Статьи запасов** и нажмите **+ Добавить статью запасов**, или
2. Откройте форму редактирования товара и воспользуйтесь разделом **Статьи запасов** внизу
3. Выберите **товар** и **склад** (и по желанию **вариант** для переменных товаров)
4. Введите количество **на складе**
5. Установите **порог низкого запаса** — этот порог на уровне товара вызывает предупреждение о низком запасе
6. Сохранить

### Движения запасов

Каждое изменение запасов отслеживается как **движение запасов**:

| Тип движения | Описание |
|--------------|-------------|
| **Приход** | Новый товар, полученный от поставщика |
| **Продажа** | Списаниее товара для выполненного заказа |
| **Возврат** | Товар, возвращенный клиентом |
| **Коррекция** | Ручное исправление (расхождение в количестве) |
| **Перевод** | Перемещение между складами |
| **Резервирование** | Временно удерживаемый для активной корзины |
| **Повреждение** | Списано как поврежденный или утерянный |
| **Пересчет** | Исправлено в соответствии с физическим количеством товара |

Движения товара предоставляют полный аудиторский след изменений запасов. Помимо действия **Изменить уровни запасов**, Spwig также предлагает массовые действия на списке товаров для перевода, списания и пересчета запасов для многих товаров одновременно — см. [Массовые действия с запасами](/help/stock-bulk-actions).

## Отслеживание запасов на товарах

### Включение отслеживания запасов

На разделе **Запасы** товара:

1. Переключите **Отслеживать запасы**, чтобы включить управление запасами для этого товара
2. Установите **Порог низкого запаса** — срабатывает предупреждение на панели приложений, когда запасы в любом складе падают ниже этого уровня
3. Настройте **Разрешить предзаказы**, если хотите принимать заказы, когда товара нет в наличии
4. Опционально установите **Действие при отсутствии товара**, чтобы изменить поведение по умолчанию сайта или категории для этого конкретного товара

После включения отслеживания, управляйте фактическими количествами запасов с помощью встроенной секции **Товары-запасы** внизу формы товара или через **Продукты > Товары-запасы**.

### Многоскладской запас

Когда отслеживание запасов включено, вкладка **Запасы** отображает уровни запасов по всем складам в сводной таблице:

- Общее количество на руках по всем местоположениям
- Разбивка по складам
- Доступные количества после резервирования и распределения

## Предупреждения о низком запасе

Система автоматически отслеживает уровни запасов и предупреждает вас, когда:
- Товар падает ниже **порога низкого запаса**
- Товар достигает **нулевого количества доступных запасов**

Предупреждения о низком запасе появляются на:
- **Панели приложений** в разделе Действия, требующие внимания
- Списке товаров с визуальным индикатором

## Советы

- Начните с одного склада и добавьте больше по мере роста бизнеса.
- Установите приоритеты выполнения заказов на основе скорости и стоимости доставки в каждый регион.
- Используйте буферные запасы для розничных точек, чтобы обеспечить наличие товара на прилавке.
- Регулярно проверяйте движения запасов, чтобы выявить хищения или расхождения.
- Установите порог низкого запаса на основе времени восстановления запасов — если на восстановление уходит 2 недели, установите порог, покрывающий 2 недели продаж.
- Включите отслеживание запасов до запуска, чтобы избежать перепродажи.
