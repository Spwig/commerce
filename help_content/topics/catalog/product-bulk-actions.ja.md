---
title: 製品一括操作
---

製品一覧では、個別に開く代わりに、一度に多くの製品に対して操作を実行できます。製品一覧の上にあるツールバーの**一括操作**ドロップダウンから、製品を公開または非表示にしたり、特徴付けたり、CSVにデータをエクスポートしたり、国際配送準備が整っている製品を確認したり、削除したりできます。これは1つのステップで行えます。

**製品 > すべての製品** に移動してこれらの操作を使用してください。

![3つの製品カードが選択され、**一括操作**ドロップダウンにすべてのオプションが表示されている製品一覧のツールバー](/static/core/admin/img/help/product-bulk-actions/bulk-actions-dropdown.webp)

## 一括操作の実行

1. 必要があれば、フィルターパネルまたは**検索**ボックスを使用して、操作したい製品を絞り込みます
2. 含める製品のカードの左上にあるチェックボックスにチェックを入れます。**一括操作**バーに選択された製品数が表示されます
3. **一括操作**ドロップダウンから操作を選択します
4. **適用**をクリックします

データを変更またはエクスポートする操作はすぐに実行されます。**選択した製品の削除**は、リストから簡単に元に戻せないため、最初に確認を求められます。

## 利用可能な操作

| 操作 | 内容 |
|--------|---------------|
| **公開済みとしてマーク** | 選択した商品のステータスを「公開済み」に設定し、ストアフロントで表示できるようにします。 |
| **下書きとしてマーク** | 選択した商品のステータスを「下書き」に設定し、編集を継続しながらストアフロントから非表示にします。 |
| **特集としてマーク** | 選択した商品で **Is Featured** を有効にします。 |
| **特集を解除** | 選択した商品で **Is Featured** を無効にします。 |
| **CSV にエクスポート** | 選択した商品の ID、名前、SKU、ステータス、特集フラグ、価格の CSV をダウンロードします。 |
| **通関データのエクスポート (CSV)** | 選択した商品の通関情報の CSV をダウンロードします。詳細は下記を参照してください。 |
| **国際配送の準備状況を確認** | 選択した商品の中で、国際配送に必要な通関データが揃っているかを示すサマリーを表示します。詳細は下記を参照してください。 |
| **選択した商品を削除** | 確認プロンプトの後、選択した商品をゴミ箱に移動します。 |

## 通関データのエクスポート (CSV)

この機能は、フォワーダー、宅配業者、または通関業者に通関申告書を手渡す必要がある場合に使用します。例えば、大規模な国際配送の前に、または HS コードと原産国データを事前に要求する新しい運送業者を設定する際に使用します。

商品を選択し、ドロップダウンメニューから **Export Customs Data (CSV)** を選択して、**Apply** をクリックしてください。Spwig は `product_customs_data.csv` という名前のファイルをダウンロードします。このファイルには、商品ごとに1行ずつ、以下の列が含まれます：

| 列 | 出典 |
|--------|--------|
| **SKU** | 商品の SKU |
| **Name** | 商品名 |
| **HS Code** | ハーモナイゼーションシステム分類コード |
| **Country of Origin** | 商品の製造国 |
| **Customs Unit Price** | 通関用の1単位あたりの申告価格 |
| **Export License** | 商品に輸出許可証が必要な場合の輸出許可証番号 |
| **License Expiry** | 設定されている場合の輸出許可証の有効期限 |
| **International Ready** | `Yes` または `No` — 国際配送に必要な最低限のデータが商品に揃っているかどうか（下記を参照） |

これらのフィールドは、製品フォームの**国際配送 / 通関**セクションから取得されます。

製品にこれらの情報が欠けている場合、エクスポートファイルの該当する列は空白のままになります。実際の配送でこのファイルに依存する前に、製品に欠落データを補完してください。

## 国際配送の準備状況を確認する

個別に各製品を開いたり、完全なCSVエクスポートを待ったりすることなく、国際配送を開始する前に製品バッチの監査を行うためにこれを使用します。

製品を選択し、**国際配送の準備状況を確認する**を選択して、**適用**をクリックします。Spwigは選択された各製品について、3つの必須フィールドである**HSコード**、**原産国**、および**通関単価**をチェックし、結果を要約した通知を表示します：

- 選択されたすべての製品に3つのフィールドがすべて入力されている場合、すべてが準備完了であるという確認メッセージが表示されます。
- 一部の製品にデータが欠けている場合、通知は準備が整っている製品の数と整っていない製品の数を報告し、準備が整っていない各製品とその欠落しているフィールドをリストします（例：「Blue Ceramic Mug (missing: hs_code, country_of_origin)」）。10を超える製品にデータが欠けている場合、通知は最初の10件をリストし、さらに何件あるかを伝えます。

このアクションはデータを読み取るだけで、製品に変更を加えることはありません。そのため、カタログ全体で通関情報を記入している間、何度実行しても安全です。

**輸出許可番号**と**輸出許可の有効期限**は、準備状況チェックの対象ではありません。これらは管理対象または制限対象の物品にのみ適用されるため、これらがなくても国際配送に対して「準備完了」とみなされる場合があります。

## ヒント

- 1回の国際注文の前に、在庫一覧全体（または1つのカテゴリ単位）で「国際配送準備のチェック」を実行してください。輸送がすでに国境を越えているときにHSコードが見つからないことに気付かされるよりもはるかに速いです。
- 輸出通関データ（CSV）を保管して、ブローカーや輸送会社に渡すようにしてください。また、「国際配送準備のチェック」を社内で使用するチェックリストとしてお使いください。CSVは記録であり、「準備のチェック」はタスクリストです。
- 新しい製品を追加する際、製品フォーム（「国際配送 / 通関」の下）でHSコード、原産国、通関単価を入力してください。これにより、後で一括処理を行うことなく、後回しにすることが出来ます。
- 一覧表示のスクロールに応じて製品が自動的に読み込まれ、チェックボックスの選択は新しい製品が読み込まれるたびに保持されます。これにより、アクションを適用する前に大量の製品を選択しておけるようになります。

フィルターを変更したり、ページを再読み込みしたりすると、選択内容はすべてリセットされます。したがって、フィルターを調整する前にアクションを適用してください。
- 「下書きに設定」は、在庫の再集計の前に、店舗から複数の製品を一括して非表示にするための素早い方法です。それ以外の変更は一切行いません。
