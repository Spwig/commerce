---
title: 製品一括操作
---

製品一覧では、個別に開く代わりに一度に多くの製品に対して操作を実行できます。製品一覧の上にあるツールバーの「一括操作」ドロップダウンから、製品を公開または非表示にしたり、特徴付けるまたは外したり、CSVにデータをエクスポートしたり、国際配送準備が整っている製品を確認したり、削除したりできます。これは1つのステップで行えます。

これらの操作を使用するには、**製品 > すべての製品** に移動してください。

![3つの製品カードが選択され、「一括操作」ドロップダウンにすべてのオプションが表示されている製品一覧のツールバー](/static/core/admin/img/help/product-bulk-actions/bulk-actions-dropdown.webp)

## 一括操作の実行

1. 必要があれば、フィルターパネルまたは**検索**ボックスを使用して、操作したい製品を絞り込みます
2. 1つずつ操作したい製品カードの左上にあるチェックボックスにチェックを入れます。**一括操作**バーに選択された製品数が表示されます
3. **一括操作**ドロップダウンから操作を選択します
4. **適用**をクリックします

データを変更またはエクスポートする操作はすぐに実行されます。**選択した製品の削除**は、リストから簡単に元に戻せないため、最初に確認を求められます。

## 利用可能な操作

| Action | What it does |
|--------|---------------|
| **Published に設定** | 選択した製品のステータスを Published に設定し、店舗で表示されるようにします。 |
| **下書き に設定** | 選択した製品のステータスを下書きに設定し、編集を続ける間、店舗から非表示にします。 |
| **特記事項 に設定** | 選択した製品の **Is Featured** を有効にします。 |
| **特記事項 を解除** | 選択した製品の **Is Featured** を無効にします。 |
| **CSV にエクスポート** | 選択した製品の ID、名前、SKU、ステータス、特記事項のフラグ、価格の CSV をダウンロードします。 |
| **カスタムデータ (CSV) をエクスポート** | 選択した製品のカスタム情報の CSV をダウンロードします。下記を参照してください。 |
| **国際配送準備の確認** | 選択した製品が国際配送に必要なカスタムデータを持っているかの要約を表示します。下記を参照してください。 |
| **選択した製品を削除** | 確認プロンプトの後に、選択した製品を回収箱に移動します。 |

## カスタムデータ (CSV) をエクスポート

これは、小切出業者、配送業者、または通関業者に渡す必要がある通関申証明書が必要な場合に使用します。たとえば、大規模な国際配送の前や、HSコードと原産地データを事前に要求する新しい輸送業者を設定する際などです。

製品を選択し、ドロップダウンから **カスタムデータ (CSV) をエクスポート** を選択し、**適用** をクリックしてください。Spwig は `product_customs_data.csv` という名前のファイルをダウンロードし、1製品あたり1行ずつ、次の列を持つデータを提供します。

| カラム | ソース |
|--------|--------|
| **SKU** | 製品のSKU |
| **名前** | 製品名 |
| **HS コード** | ハーモナイズドシステムの分類コード |
| **原産国** | 製品が製造された場所 |
| **通関単価** | 通関用に明記された単価 |
| **輸出許可証** | 製品に必要な場合の輸出許可証番号 |
| **許可の有効期限** | 輸出許可証の有効期限、設定されている場合 |
| **国際配送準備完了** | 国際配送に必要な最低限のデータを持っているかを示す `Yes` または `No` (下記参照) |

すべてのマーケドフォーマット、画像パス、コードブロック、技術用語を保持してください。

これらのフィールドは、製品フォームの「国際配送 / 輸送関連」セクションから来ています。

製品に1つでもフィールドが欠落している場合、エクスポートではそのカラムは空のままになります。実際に輸送に使用する前に、製品のデータを入力してください。

## 国際配送の準備状況の確認

個別に製品を開かずに、フルなCSVエクスポートを待たずに、一括で製品の準備状況を確認できます。

製品を選択し、**国際配送の準備状況の確認**を選択して**適用**をクリックしてください。Spwigは、3つの必須フィールドである**HSコード**、**原産国**、および**通関単価**に対して、選択した製品をチェックし、結果を要約した通知を表示します:

- すべての製品が3つのフィールドを満たしている場合、すべての製品が準備できていることが確認できます。
- 一部の製品でデータが欠落している場合、通知ではどれだけの製品が準備できているか、そしてどれだけ準備できていないかが報告され、準備ができていない製品がそれぞれリストアップされ、どのフィールドが欠落しているかが示されます（例: 「ブルークレイミ cup (欠落: hs_code, country_of_origin)」）。10個を超える製品でデータが欠落している場合、最初の10個がリストアップされ、それ以降の数が表示されます。

この操作はデータを読み込むだけで、製品のデータを変更することはないため、カタログ全体の通関情報の入力中に何度でも実行できます。

**輸出許可番号**と**輸出許可の有効期限**は、準備状況のチェックには含まれていません。これらは制限品や制限品に適用されるため、これらがなくても国際配送に「準備完了」とみなせます。

## トipp

すべてのマーケドンフォーマット、画像パス、コードブロック、技術用語を保存してください。

- トランスポートの国際配送準備チェックを、最初の国際注文を行う前に、カタログ全体（または1つのカテゴリ単位）で実行してください。これは、出荷がすでに国境に近づいているときにHSコードが見つからないことに気付くよりもはるかに速いです。
- 輸出通関データ（CSV）を、ブローカーや輸送会社に渡すために保持し、通関準備のチェックリストとして**国際配送準備のチェック**を自身の内部チェックリストとして使用してください。CSVは記録であり、準備チェックはタスクリストです。
- 新しい製品を追加する際、**HSコード**、**原産国**、および**通関単価**を製品フォーム（**国際配送 / 通関**の下）に入力してください。これにより、後で一括処理で行う必要がなくなります。
- 一覧表示されている製品はスクロールするにつれて自動的に読み込まれ、新しい製品が読み込まれるたびにチェックボックスの選択は保持されます。これにより、アクションを適用する前に大量の製品を選択しておけるようになります。

フィルターを変更したり、ページを再読み込みしたりすると、選択内容はすべてクリアされます。したがって、フィルターを調整する前にアクションを適用してください。
- **下書きとして保存**は、在庫の再集計の前に、店舗から複数の製品を一括して非表示にするための素早い方法です。他の変更は一切行いません。
