---
title: 在庫と倉庫
---

在庫管理システムでは、複数の場所にまたがる在庫を管理し、出荷優先順位を設定し、リアルタイムで在庫レベルを追跡できます。管理サイドバーの**製品 > 倉庫**に移動して、あなたの倉庫の場所を管理してください。

![在庫一覧](/static/core/admin/img/help/inventory-warehouses/warehouse-list.webp)

## 倉庫

### 倉庫一覧

在庫ページには、以下の情報を持つカード形式ですべての在庫場所が表示されます：

- **名前とコード** — 倉庫の識別子（例：「メイン倉庫」、コード「MAIN-WH」）
- **販売地域** — 地理的領域の割り当て
- **ステータスバッジ** — 有効/無効、小売店舗
- **統計情報** — 在庫商品数、出荷優先順位、在庫バッファの割合
- **場所** — 市と国
- **最終更新日** — 在庫レベルが最後に変更された日時

### 倉庫の作成

1.

**+ 倉庫を追加**をクリックしてください
2.

**基本情報**を入力してください：
   - **名前** — 説明的なラベル（例：「US East Warehouse」）
   - **コード** — 短いユニークな識別子（例：「US-EAST」） — すべての倉庫でユニークである必要があります
   - **販売地域** — 出荷ルーティング用に地理的領域に割り当てます
   - **有効** — 出荷に含めるには有効にしてください
3.

**住所**セクションに、フルな倉庫の住所を入力してください
4.

**出荷設定**を構成してください：
   - **出荷優先順位** — 数値が高いほど注文処理の優先順位が高くなります
   - **在庫バッファの割合** — セーフティバッファとして予約する在庫の割合（0〜100）
   - **出荷場所** — この倉庫がカスタマーピックアップをサポートしている場合、オプションでピックアップ場所にリンクできます
5.

**カスタマーディスプレイ**（オプション）を構成してください：
   - **表示名** — 顧客向けラベル（例：「オーストラリアから出荷」）。
   - 入力しない場合、倉庫名が使用されます。
   - **フロントエンドに表示** — 顧客が製品ページでこの倉庫の出発地を表示するようにします
6.

すべてのマークダウンフォーマット、画像パス、コードブロック、技術用語を保持してください。

POS / レイヤー ストアの設定 (オプション):
  - **小売場所** — この倉庫がPOS端末を備えた物理的な店舗としても機能しているかを確認してください
  - **POS表示名** — POSインターフェースに表示される短い名前
  - **ストアグループ** — 設定の継承用にPOSストアグループに割り当ててください
7.

必要に応じて **連絡先情報** を追加してください (名前、電子メール、電話番号)
8.

**保存** をクリックしてください

### 出荷優先度

注文が入ると、システムは次の基準に基づいて最適な倉庫を選択します:

1. **優先度値** — 高い優先度を持つ倉庫が優先されます
2. **在庫の入手可能状況** — 十分な在庫を持っている必要があります
3. **地域の一致** — 顧客の地域にある倉庫が優先されます

たとえば、米国に100の優先度を持つ倉庫と欧州に60の優先度を持つ倉庫がある場合、米国の注文は最初に米国の倉庫から出荷されます。

### 在庫バッファ

在庫バッファは、オンラインで販売されない在庫のパーセンテージを予約しています。これは次の用途に役立ちます:
- フロア在庫が必要な物理的な小売店
- オーバークロックを防ぐためのセーフティストック
- 卸売注文用に予約された在庫

100個の在庫に対して10%のバッファがあると、オンライン注文用に90個しか利用できません。

## 在庫アイテム

在庫アイテムは、特定の製品と特定の倉庫における実際の在庫を表しています。

### 在庫レベルの表示

1. 任意の倉庫カード上の **在庫アイコン** をクリックして、その在庫アイテムを確認してください
2. または、製品の **在庫** タブに移動して、すべての倉庫にわたる在庫を確認してください

各在庫アイテムには、次が表示されます:
- **製品名** とバージョン (該当する場合)
- **在庫数** — 実際の在庫総数
- **割り当て済み** — 保留中の注文に予約された数量
- **利用可能** — 在庫数から割り当て済みを差し引いたもの (販売可能とみなされる数量)

### 在庫の追加

1. **製品 > 在庫アイテム** に移動し、**+ 在庫アイテムを追加** をクリックしてください。または
2. 製品の編集フォームを開き、下部の **在庫アイテム** セクションを使用してください
3. **製品** と **倉庫** を選択してください (変数製品の場合、**バージョン** をオプションで選択してください)
4. **在庫数** を入力してください
5. すべてのマークダウンフォーマット、画像パス、コードブロック、技術用語を保持してください

在庫のロウストックしきい値を設定してください - この個別製品のしきい値は、在庫が低いとアラートをトリガーします
6。

保存

### 在庫の移動

在庫の変更すべては、**在庫の移動**として記録されます:

| モーションタイプ | 説明 |
|--------------|-------------|
| **受取** | 仕入先から受け取った新規在庫 |
| **販売** | 注文が満たされたため在庫が差し引かれます |
| **返品** | デリバリーから顧客に返却された在庫 |
| **調整** | マニュアル修正（在庫の不一致） |
| **移動** | 貯蔵間での移動 |
| **予約** | 有効なカートのために一時的に保持される |
| **破損** | 損傷または紛失として帳簿に記録される |
| **再集計** | 実在する在庫数に一致させるために修正される |

在庫の移動は、在庫変更の完全な監査証跡を提供します。**在庫レベルの調整**アクションに加えて、Spwigでは、在庫アイテム一覧で一括操作を実行して、多くのアイテムに対して在庫を一括して移動、減損、再集計できます。[一括在庫操作](/help/stock-bulk-actions)を参照してください。

## 製品での在庫トラッキング

### 在庫トラッキングの有効化

製品の**在庫**セクションで:

1. **在庫を追跡する**をトグルして、この製品の在庫管理を有効にします
2. **在庫ロウストックしきい値**を設定してください - このレベルは、どの倉庫の在庫もこのレベルを下回るとダッシュボードアラートをトリガーします
3. 在庫切れ時に注文を受けたい場合は、**バックオーダーを許可する**を構成します
4. この特定の製品のためにサイト全体またはカテゴリの動作をオーバーライドする**在庫切れ時の行動**をオプションで設定します

トラッキングを有効にした後、製品フォームの下にある**在庫アイテム**のインラインセクションを使用して、実際の在庫数量を管理するか、**製品 > 在庫アイテム**から管理してください。

### 複数倉庫在庫

在庫トラッキングが有効になると、在庫タブにはすべての倉庫での在庫レベルが要約されたテーブルが表示されます:

- すべての場所にわたる合計在庫
- 各倉庫別の内訳
- 予約および割り当て後の利用可能数量

## ローストックアラート

すべてのマーカーフォーマット、画像パス、コードブロック、技術用語を保持してください。

システムは在庫レベルを自動的にモニタリングし、以下の状況になると通知します:
- 商品が**在庫ローアラート**を下回ったとき
- 商品の**在庫なし**に達したとき

在庫ローアラートは、以下の場所に表示されます:
- **ショップダッシュボード**の[実行が必要なアクション]セクション
- 視覚的なインジケーター付きの製品一覧

## トipp

- 1つの倉庫から始め、ビジネスが成長するにつれて他の倉庫を追加してください。
- 各地域への配送速度とコストに基づいて、受注処理の優先順位を設定してください。
- 小売店舗の在庫バッファを使用して、店頭在庫の可用性を確保してください。
- 在庫の移動を定期的に確認して、減耗や不一致を特定してください。
- 在庫ローアラートを、再注文リードタイムに基づいて設定してください - 在庫補充に2週間かかる場合は、2週間分の販売をカバーするように設定してください。
- オーバーインベントリを防ぐために、ローンチする前に在庫追跡を有効にしてください。
