---
title: 대량 재고 작업
---

단일 조정 외에도 Spwig은 **재고 항목** 목록에서 여러 제품에 걸쳐 발생하는 재고 작업을 위해 세 가지 대량 작업을 제공합니다: 창고 간 재고 이동, 손상되거나 분실된 단위의 적자 처리, 물리적 카운트 후 재고 정리. 이 세 가지 작업은 모두 동일한 **작업** 드롭다운에서 실행되며, 선택한 모든 재고 항목에 동일한 수량을 적용하고, 재고 이동 감사 추적에 완전히 기록됩니다.

사용하려면 **제품 > 재고 항목**으로 이동하십시오.

## 대량 재고 작업 실행

1. **재고 항목** 목록에서 필터나 검색을 사용하여 업데이트하고 싶은 항목을 찾으십시오
2. 각 재고 항목 옆에 있는 체크박스를 선택하거나(또는 헤더 체크박스를 사용하여 현재 페이지의 모든 항목을 선택)하십시오
3. **Actions** 드롭다운에서 세 가지 작업 중 하나를 선택하십시오:
   - **창고로 재고 이전**
   - **손상/분실 재고 기록**
   - **재재고 (물리적 카운트)**
4. **Go**를 클릭하십시오
5. 확인 페이지를 검토하십시오 — 선택한 모든 재고 항목과 현재 **보유**, **할당**, **사용 가능한** 수량을 나열하여 올바른 항목을 선택했는지 확인할 수 있습니다
6. 작업의 필드를 입력하고(아래 참조) 제출 버튼을 클릭하여 적용하십시오

![재고 항목 목록에 표시되는 대량 작업 드롭다운, 창고로 재고 이전, 손상/분실 재고 기록 및 재재고 (물리적 카운트) 옆에 다른 작업이 표시됨](/static/core/admin/img/help/stock-bulk-actions/stock-items-actions-dropdown.webp)

입력한 동일한 수량이 **모든** 선택된 항목에 적용됩니다 — 이는 여러 SKU에서 동일한 수량의 단위를 이동하거나, 적자 처리하거나, 재재고하는 데 설계되었습니다(예: 여러 제품의 10단위를 새로운 매장 위치로 이전하는 것). 단일 항목에 다른 수량이 필요한 경우, 이 작업을 다시 실행하고 단일 항목만 선택하거나, 대신 **재고 수준 조정**을 사용하십시오.

## 창고로 재고 이전

선택한 항목의 창고에서 다른 창고로 사용 가능한 재고를 이동하는 데 사용하세요. 예를 들어, 메인 창고에서 새로운 소매점에 재고를 재충전하거나, 지역 출하 센터 간에 재고를 재균형 잡는 것이 있습니다.

확인 페이지에서 다음을 입력하십시오:

| 필드 | 설명 |
|-------|-------------|
| **목적지 창고** | 재고가 이동할 장소입니다. 이 목록에는 활성 창고만 표시됩니다. |
| **항목당 수량** | 선택한 항목의 현재 창고에서 이동할 단위 수입니다. |
| **이유** | 선택적 메모입니다. 예: "새로운 오클랜드 매장 재충전". |

**재고 이전**을 클릭하여 적용하십시오.

![재고 이전 확인 페이지: 현재 재고/지정된/이용 가능한 수량이 표시된 선택한 재고 항목 카드, 목적지 창고, 수량, 이유가 입력된 이전 세부 정보 폼이 있는 이미지](/static/core/admin/img/help/stock-bulk-actions/transfer-stock-confirmation.webp)

**이전할 수 있는 것은 예약되지 않은 재고만입니다.** Spwig는 *사용 가능한* 재고(주문이 열려 있는 경우에 할당된 단위를 뺀 현재 재고)에서 이전을 수행합니다. 고객의 주문에 이미 약속된 단위는 해당 주문이 여전히 충족될 수 있도록 원본 창고에 남아 있습니다. 선택한 항목이 입력한 수량을 커버할 수 있는 사용 가능한 재고가 충분하지 않은 경우, 해당 항목은 건너뛰고 이유를 설명하는 오류 메시지가 표시되며, 선택한 다른 항목은 여전히 이전됩니다.

선택한 항목이 선택한 목적지 창고에 이미 재고가 있는 경우, 자동으로 건너뛰며(자기 자신에게 이전할 것이 없기 때문입니다), 이로 인해 건너뛴 항목이 몇 개인지에 대한 메시지가 표시됩니다.

각 이전 작업은 감사 기록에 쌍을 이룬 이동 기록을 작성합니다. 원본 창고에 음의 **창고 이전** 항목이 있고, 목적지 창고에 양의 항목이 있어야 합니다. 이로 인해 전체 감사 기록은 재고가 어디서 왔는지, 어디로 갔는지를 정확히 보여줍니다.

## 손상/분실된 재고 기록

모든 마크다운 포맷, 이미지 경로, 코드 블록, 기술 용어를 보존하십시오.

파손, 손상, 누락된 단위를 기록하기 위해 사용하세요 — 예를 들어, 배송 중 파손된 상품을 찾거나, 차이를 조사할 때 사용합니다.

확인 페이지에 다음을 입력하십시오:

| 필드 | 설명 |
|-------|-------------|
| **기록할 수량 (단위당)** | 선택한 각 항목에 대해 재고에서 제거할 단위 수입니다. |
| **이유** | 선택적 메모, 예: "창고에서의 물리적 손상". |

**기록을 완료**를 클릭하여 적용하십시오.

**예약된 재고는 기록할 수 없습니다.** 재고 수량은 열린 주문에 할당된 수량보다 낮아질 수 없습니다 — Spwig은 입력한 수량이 할당된 재고를 먹어버리는 경우 기록을 차단하므로, 결제된 주문이 재고 없이 남는 것을 방지할 수 있습니다. 이 상황이 발생하면 항목 이름과 실제로 기록할 수 있는 비예약 단위 수가 표시된 오류 메시지가 나타납니다.

각 기록은 해당 재고 항목에 대해 **파손/분실** 이동으로 기록되며, 음의 수량을 가집니다.

## 재고 재확인 (물리적 카운트)

창고 감사나 사이클 카운트 후 많은 항목을 신속하게 정리하기 위해 물리적 재고 수를 사용하여 실제 카운트한 수량과 맞추는 데 사용하십시오.

확인 페이지에 다음을 입력하십시오:

| 필드 | 설명 |
|-------|-------------|
| **물리적으로 확인한 재고 수량 (단위당)** | 물리적으로 확인한 수량입니다. 선택한 모든 항목에 대해 이 정확한 수량으로 재고가 설정됩니다 — 더하거나 빼지 않습니다. |
| **이유** | 선택적 메모, 예: "3/4분기 창고 재고 수량". |

**재확인 적용**을 클릭하여 적용하십시오.

![재확인 재고 확인 페이지: 선택한 재고 항목 카드와 입력된 물리적으로 확인한 재고 수량 및 이유를 가진 재확인 세부 정보 폼](/static/core/admin/img/help/stock-bulk-actions/recount-stock-confirmation.webp)

다른 두 가지 작업과 달리, 재확인은 재고를 상승 또는 하강으로 이동시킬 수 있습니다 — 시스템이 예상한 수량보다 더 많이 카운트한 경우 상승, 적게 카운트한 경우 하강.

모든 마크다운 포맷, 이미지 경로, 코드 블록, 기술 용어를 보존하십시오.

입력한 수량이 열린 주문에 할당된 수량보다 낮으면, Spwig는 여전히 적용합니다 (수량은 논쟁할 것이 아닌 사실입니다), 하지만 해당 항목의 **재고 가능** 값은 재고 목록에서 `0`으로 표시되며, 재고 상태 아이콘은 **품절**로 전환됩니다 — 이는 해당 주문이 여전히 충족 가능한지 확인하라는 신호로 간주해야 합니다.

각 재검산은 **물리적 재검산** 이동으로 기록되며, 수량은 기존 재고와 새 재고 사이의 수정(양수 또는 음수)을 보여줍니다.

## 변경 사항 검토

모든 이전 이동, 손실 및 재검산은 다른 재고 변경과 동일한 방식으로 기록됩니다:

- 재고 항목을 열고 **재고 이동** 섹션으로 스크롤하여 전체 이력 보기
- 또는 **제품 > 재고 이동**으로 이동하여 모든 항목을 통해 이동을 브라우징하고, 유형별로 필터링 가능

각 항목은 이동 유형, 수량 변경, 이전 및 새 재고 수량, 변경을 한 사람, 그리고 입력한 이유(있을 경우)를 기록합니다. 따라서 대량의 이전 이동이나 손실은 단일 수동 조정과 마찬가지로 추적할 수 있습니다.

## 팁

- 물리적 재고 계산 직후 **재고 재검산**을 실행하세요. 입력한 수량이 아직 생기 있는 동안에는 이동 기록에서 나중에 헤쳐내는 것보다 확인 페이지에서 오타를 찾는 것이 더 쉽습니다.
- 손실 및 재검산에 대해 **원인**을 입력하세요.

6개월 후, "창고에서의 물 손상"은 공백 필드보다 감사 추적에서 훨씬 유용할 것입니다.
- 재고를 이전하기 전에 확인 페이지의 **재고 가능** 열을 확인하세요. 이미 할당된 단위를 고려하고 있으므로, 선택한 항목 중 하나에 대해 수량이 너무 높은지 즉시 알 수 있습니다.
- 이 작업은 선택한 모든 항목에 동일한 수량을 적용합니다.


선택한 항목을 실제로 동일한 수량을 이동, 적자, 재검토해야 하는 항목들로 그룹화하고, 예외 사항은 하나씩 처리하십시오.
- 소매점에서 POS를 사용하는 경우, 창고 재고 버퍼는 온라인 주문에 대한 "사용 가능" 항목이 아니라는 점을 기억하십시오. 하지만 대량 이전 및 적자 처리는 여전히 창고의 실제 재고 총량에 대해 이루어져야 합니다.
