---
title: 多幣種禮品卡
---

如果您向多個國家的客戶銷售商品，可以發行特定幣種的禮品卡。例如，新西蘭客戶可以購買價值 50 新西蘭元（NZD）的禮品卡，收件人可以用新西蘭元兌換——無論匯率如何波動，禮品卡的面值都保持不變。

此功能需要啟用多幣種功能，並至少配置一個匯率提供商。

> **禮品卡銷售暫時中止**，在我們完成自動發送流程之前——請參閱 **禮品卡** 帮助主題以獲取詳細信息。您現在仍然可以為產品設置 **禮品卡幣種**，這樣當銷售重新開放時即可立即銷售，而且您今天仍然可以手動發行特定幣種的禮品卡，就像發行其他禮品卡一樣（在您希望卡所使用的幣種中設置 **初始價值**）。

## 如何操作

當您為禮品卡產品設置 **禮品卡幣種** 時，系統會在購買時根據當前匯率將產品價格轉換為目標幣種。生成的禮品卡以該幣種標示，且只能由使用相同幣種購物的客戶兌換。

| 步驟 | 發生什麼情況 |
|------|-------------|
| **產品設置** | 您以基本幣種設置禮品卡產品價格，並選擇目標幣種（例如 NZD） |
| **購買** | 顧客購買禮品卡。基本價格根據當前匯率轉換為 NZD |
| **禮品卡創建** | 輸出的禮品卡價值以 NZD 表示（例如 NZ$78.50） |
| **兌換** | 收件人在使用 NZD 購物時，在結帳時輸入代碼。NZD 餘額將被扣除 |

## 前提條件

在設置多幣種禮品卡之前，請確保您已：

1. **啟用多幣種** — 轉到 **設定 > 商店設定** 並啟用多幣種支援
2. **已設定支援的幣種** — 加入您想要提供的幣種（例如：NZD、SGD、EUR）
3. **已連接匯率提供商** — 轉到 **設定 > 匯率** 並設定一個提供商，以便能夠使用即時匯率

## 設定多幣種禮品卡產品

### 第 1 步：建立或編輯禮品卡產品

1. 轉到 **產品 > 所有產品**
2. 點擊 **+ 新增產品** 或開啟現有的禮品卡產品
3. 將 **產品類型** 設為 **禮品卡**

### 第 2 步：設定禮品卡幣種

1. 點擊 **禮品卡** 標籤
2. 如常設定您的面額選項（固定金額、自訂金額或兩者皆有）
3. 在禮品卡標籤底部，找到 **禮品卡幣種** 下拉選單
4. 選擇目標幣種（例如：**NZD - 新西蘭元**）
5. 儲存產品

下拉選單會顯示您商店設定中啟用的所有幣種。選擇 **商店基準幣種（預設）** 表示禮品卡將以您的基準幣種發行 — 這是標準行為。

### 第 3 步：設定價格

如常設定產品價格，以您的基準幣種為單位。當客戶購買此禮品卡時，價格會根據當前匯率自動轉換為目標幣種。

**範例：** 您的基準幣種是 USD。您建立一個價值 $50 USD 的禮品卡產品，並設定禮品卡幣種為 NZD。如果匯率為 1 USD = 1.57 NZD，則產生的禮品卡價值將為 NZ$78.50。

## 幣種匹配與兌換

多幣種禮品卡使用 **相同幣種兌換** — 客戶的當前購物幣種必須與禮品卡的幣種相符。

### 客戶的體驗

- 以 **NZD** 為貨幣的客戶可以在結帳時使用 NZD 礼品卡
- 以 **USD** 為貨幣的客戶無法使用 NZD 礼品卡 — 他們會看到一條說明貨幣不匹配的訊息
- 客戶可以在應用禮品卡之前，透過您商店前端的貨幣選擇器切換購物貨幣

### 礼品卡餘額的運作方式

禮品卡餘額始終以原生貨幣進行追蹤：

- 一張 NZ$78.50 的禮品卡最初餘額為 NZ$78.50
- 如果客戶進行 NZ$30 的購買，剩餘餘額為 NZ$48.50
- 餘額不會隨著匯率波動 — 面值是固定的

當禮品卡在結帳時被應用，系統會在內部將折扣轉換為您的基準貨幣以進行訂單計算，但禮品卡餘額始終以原生貨幣扣除。

## 管理多幣種禮品卡

導覽至 **Products > Gift Cards** 來查看所有已發行的禮品卡。多幣種禮品卡會以原生貨幣顯示：

- **Balance** 會以禮品卡的貨幣顯示（例如 NZ$48.50）
- **Transactions** 會以禮品卡的貨幣記錄金額
- **Initial value** 會顯示購買時的轉換金額

### 查看匯率細節

每個禮品卡交易都會記錄交易當時使用的匯率。這為會計目的提供了完整的審計追蹤。

## 範例

### 範例 1：針對紐西蘭的區域禮品卡

**情境：** 您的營業地點在美國，但有紐西蘭的客戶。您希望販售以 NZD 為單位的禮品卡。

| Setting | Value |
|---------|-------|
| Product name | NZ Gift Card |
| Product type | Gift Card |
| Price | $50.00 (USD — 您的基準貨幣) |
| Denomination type | Fixed Denominations |
| Fixed denominations | 25, 50, 100, 200 |
| Gift Card Currency | NZD - New Zealand Dollar |
| Expiration | 365 days |

當客戶選擇 $50 面額時：
- 系統會根據當前匯率將 $50 美元轉換為紐西蘭元
- 會創建一張以紐西蘭元為單位的禮品卡（例如：NZ$78.50）
- 收件人可以在購物時以紐西蘭元兌換

### 範例 2：多種貨幣的禮品卡

**情境：** 你向新加坡、澳洲和英國的客戶銷售。建立三種禮品卡產品：

1. **新加坡禮品卡** — 礼品卡貨幣：SGD
2. **澳洲禮品卡** — 礼品卡貨幣：AUD
3. **英國禮品卡** — 礼品卡貨幣：GBP

每個產品在購買時會將你的基本價格轉換為目標貨幣。每個地區的客戶都可以用當地貨幣兌換禮品卡。

### 範例 3：混合禮品卡方案

**情境：** 你想要提供基本貨幣和區域貨幣兩種禮品卡。

- **商店禮品卡** — 礼品卡貨幣：*商店基本貨幣（預設）* — 可在你的基本貨幣兌換
- **紐西蘭禮品卡** — 礼品卡貨幣：NZD — 僅能在 NZD 兌換

這兩種產品可以在你的目錄中共存。當客戶查看餘額時，會看到禮品卡所使用的貨幣。

## 小技巧

- 從一種區域貨幣開始，先測試完整的流程（購買、配送、兌換），再添加更多貨幣。
- 購買時的匯率決定了禮品卡的價值。

如果匯率發生重大變化，禮品卡價值仍保持固定 — 這保護了你和你的客戶。
- 在產品名稱中明確標示貨幣（例如："NZ 礼品卡" 或 "Gift Card (NZD)"），讓客戶清楚他們購買的是什麼。
- 沒有設定貨幣的禮品卡仍會以你的基本貨幣運作 — 現有的產品不會受到影響。
- 監控你的匯率提供商，確保匯率是最新的。

過時的匯率可能會導致禮品卡價值過高或過低。
- 請仔細考慮你的面額設定。

$25 美元的面額會轉換為約 NZ$39 — 在目標貨幣中使用四捨五入的面額看起來會更好。

您可以為目標貨幣創建金額為整數的獨立產品。
