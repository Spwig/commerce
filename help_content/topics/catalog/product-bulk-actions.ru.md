---
title: Массовые действия с товарами
---

Список **Товаров** позволяет выполнять действия с несколькими товарами одновременно, а не открывать каждый отдельно. Из раскрывающегося списка **Массовые действия** в панели инструментов над сеткой товаров вы можете публиковать или снимать с публикации товары, выделять или снимать выделение, экспортировать данные в CSV, проверять, готовы ли товары к международной доставке, или удалять их — все это в один шаг.

Перейдите по ссылке **Товары > Все товары**, чтобы воспользоваться этими действиями.

![Панель инструментов списка товаров с тремя выбранными товарами и раскрывающимся списком Массовые действия, отображающим все варианты, включая Экспорт данных о таможне (CSV) и Проверка готовности к международной доставке](/static/core/admin/img/help/product-bulk-actions/bulk-actions-dropdown.webp)

## Выполнение массового действия

1. Используйте панель фильтров или поле **Поиск**, чтобы сузить круг товаров, которые вы хотите, если это необходимо
2. Отметьте галочкой поле в левом верхнем углу каждой карточки товара, которую хотите включить — панель **Массовые действия** отображает текущее количество выбранных товаров
3. Выберите действие из раскрывающегося списка **Массовые действия**
4. Нажмите **Применить**

Действия, изменяющие или экспортирующие данные, выполняются немедленно; **Удалить выбранные** запрашивает подтверждение, так как это единственное действие, которое нельзя легко отменить с помощью списка.

## Доступные действия

| Действие | Что это делает |
|--------|---------------|
| **Пометить как опубликованный** | Устанавливает статус выбранных товаров как Опубликовано, чтобы они были видны на витрине. |
| **Пометить как черновик** | Устанавливает статус выбранных товаров как Чертеж, скрывая их от витрины, пока вы продолжаете редактирование. |
| **Пометить как рекомендуемый** | Включает **Рекомендуемый** для выбранных товаров. |
| **Убрать рекомендуемый** | Отключает **Рекомендуемый** для выбранных товаров. |
| **Экспортировать в CSV** | Скачивает CSV выбранных товаров с ID, названием, SKU, статусом, флагом рекомендуемого и ценой. |
| **Экспорт данных о таможне (CSV)** | Скачивает CSV информации о таможне для выбранных товаров. См. ниже. |
| **Проверить готовность к международной доставке** | Показывает сводку о том, какие выбранные товары имеют данные, необходимые для международной доставки. См. ниже. |
| **Удалить выбранные** | Перемещает выбранные товары в корзину, после запроса подтверждения. |

## Экспорт данных о таможне (CSV)

Используйте это, когда вам нужна форма декларации о таможне, которую нужно передать грузоперевозчику, курьерской компании или таможенному брокеру — например, перед крупной международной поставкой или при настройке нового перевозчика, который просит HS-коды и данные о происхождении заранее.

Выберите товары, выберите **Экспорт данных о таможне (CSV)** из раскрывающегося списка и нажмите **Применить**. Spwig скачивает файл с именем `product_customs_data.csv` с одной строкой на товар и следующими столбцами:

| Столбец | Источник |
|--------|--------|
| **SKU** | SKU товара |
| **Название** | Название товара |
| **HS-код** | Код классификации Гармонизированной системы |
| **Страна происхождения** | Где изготовлен товар |
| **Стоимость товара для таможни** | Объявленная стоимость за единицу для таможни |
| **Лицензия на экспорт** | Номер лицензии на экспорт, если товар требует лицензии |
| **Срок действия лицензии** | Дата окончания срока действия лицензии на экспорт, если установлена |
| **Готовность к международной доставке** | `Да` или `Нет` — указывает, имеет ли товар минимальные данные, необходимые для международной доставки (см. ниже) |

Эти поля берутся из раздела **Международная доставка / Таможня** формы товара. Если у товара отсутствует один из них, столбец остается пустым в экспорте — заполните недостающие данные по товару, прежде чем полагаться на этот файл для реальной поставки.

## Проверка готовности к международной доставке

Используйте это, чтобы провести аудит партии товаров перед началом их международной доставки, не открывая каждый товар отдельно или не ожидая полного экспорта CSV.

Выберите товары, выберите **Проверить готовность к международной доставке** и нажмите **Применить**. Spwig проверяет каждый выбранный товар по трем обязательным полям — **HS-код**, **Страна происхождения** и **Стоимость товара для таможни** — и отображает уведомление, резюмирующее результат:

- Если у каждого выбранного продукта заполнены все три поля, вы увидите подтверждение того, что все они готовы.
- Если у некоторых не хватает данных, уведомление сообщает, сколько из них готово, а сколько нет, и перечисляет каждый продукт, который не готов, а также какие поля у него отсутствуют (например, «Синая керамическая кружка (отсутствуют: hs_code, страна_производства»).

Если более 10 продуктов не имеют данных, уведомление перечисляет первые 10 и сообщает, сколько еще их.

Это действие читает данные — оно не изменяет ничего на продуктах, поэтому его можно запускать столько, сколько угодно, пока вы заполняете информацию о таможне в вашем каталоге.

**Номер лицензии на экспорт** и **Срок действия лицензии на экспорт** не являются частью проверки готовности. Они применяются только к контролируемым или ограниченным товарам, поэтому продукт может быть «готовым» для международной доставки без них.

## Советы

- Запустите **Проверка готовности международной доставки** по всему каталогу (или по категориям по отдельности) до первого международного заказа — это намного быстрее, чем обнаружение пропущенного кода HS, когда поставка уже на границе.
- Храните **Экспорт данных о таможне (CSV)** для передачи брокерам и перевозчикам, а также **Проверка готовности международной доставки** для собственного внутреннего списка — CSV — это запись, а проверка готовности — список дел.
- Заполняйте **Код HS**, **Страна производства** и **Стоимость товара для таможни** на форме продукта (в разделе **Международная доставка / Таможня**), добавляя новые продукты, чтобы в будущем не пришлось делать это в массовом порядке.
- Сетка продуктов автоматически загружает больше продуктов при прокрутке (бесконечная прокрутка), и ваши выборки продуктов сохраняются при загрузке новых продуктов — поэтому вы можете прокрутить, чтобы собрать большой выбор перед применением действия. Однако изменение фильтра или перезагрузка страницы очищает ваш выбор, поэтому применяйте действие до того, как вы измените фильтры.
- **Поместить в черновики** — это быстрый способ одновременно убрать несколько продуктов с прилавка — например, перед пересчетом запасов — не изменяя ничего еще в них.
