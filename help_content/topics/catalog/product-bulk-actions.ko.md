title: 제품 일괄 작업

**제품** 목록을 사용하면 개별 제품을 하나씩 열지 않고 여러 제품을 동시에 처리할 수 있습니다. 제품 그리드 상단의 도구 모음에 있는 **일괄 작업** 드롭다운에서 제품을 게시하거나 게시 해제하고, 추천 또는 추천 해제하고, 데이터를 CSV로 내보내고, 국제 배송이 가능한 제품을 확인하거나, 삭제할 수 있습니다 — 모두 한 번의 단계로 가능합니다.

이 작업을 사용하려면 **제품 > 모든 제품**으로 이동하세요.

![세 개의 제품 카드가 선택되어 있고, 수출 통관 데이터(CSV) 및 국제 배송 준비 상태 확인을 포함한 모든 옵션이 표시된 일괄 작업 드롭다운이 있는 제품 목록 도구 모음](/static/core/admin/img/help/product-bulk-actions/bulk-actions-dropdown.webp)

## 일괄 작업 실행

1. 필요할 경우 필터 패널 또는 **검색** 상자를 사용하여 원하는 제품으로 범위를 좁힙니다
2. 포함할 각 제품 카드의 왼쪽 상단 상자를 선택합니다 — **일괄 작업** 바에 선택된 제품 수가 실시간으로 표시됩니다
3. **일괄 작업** 드롭다운에서 작업을 선택합니다
4. **적용**을 클릭합니다

데이터를 변경하거나 내보내는 작업은 즉시 실행됩니다. **선택 항목 삭제**는 목록 자체에서 쉽게 되돌릴 수 없는 유일한 작업이므로 먼저 확인을 요청합니다.

## 사용 가능한 작업

| 작업 | 수행 내용 |
|--------|---------------|
| **게시로 표시** | 선택한 제품의 상태를 게시로 설정하여 스토어프론트에서 표시되도록 합니다. |
| **초안으로 표시** | 선택한 제품의 상태를 초안으로 설정하여 편집을 계속하는 동안 스토어프론트에서 숨깁니다. |
| **추천으로 표시** | 선택한 제품의 **추천** 옵션을 활성화합니다. |
| **추천 해제** | 선택한 제품의 **추천** 옵션을 비활성화합니다. |
| **CSV로 내보내기** | 선택한 제품의 ID, 이름, SKU, 상태, 추천 플래그 및 가격을 CSV로 다운로드합니다. |
| **관세 데이터 내보내기 (CSV)** | 선택한 제품의 관세 정보를 CSV로 다운로드합니다. 아래를 참조하세요. |
| **국제 배송 준비 상태 확인** | 국제 배송에 필요한 관세 데이터가 있는 선택한 제품의 요약을 표시합니다. 아래를 참조하세요. |
| **선택 항목 삭제** | 확인 프롬프트 후 선택한 제품을 휴지통으로 이동합니다. |

## 관세 데이터 내보내기 (CSV)

화물 운송업체, 택배사 또는 관세사에게 통관 신고서를 전달해야 하는 경우, 예를 들어 대규모 국제 배송 전이나 HS 코드와 원산지 데이터를 사전에 요구하는 새로운 운송업체를 설정할 때 이 기능을 사용하세요.

제품을 선택하고 드롭다운에서 **관세 데이터 내보내기 (CSV)**를 선택한 후 **적용**을 클릭하세요. Spwig는 제품당 한 줄씩 다음 열을 포함한 `product_customs_data.csv`라는 이름의 파일을 다운로드합니다:

| 열 | 출처 |
|--------|--------|
| **SKU** | 제품의 SKU |
| **이름** | 제품 이름 |
| **HS 코드** | 조화시스템 분류 코드 |
| **원산지** | 제품이 제조된 국가 |
| **관세 단가** | 관세를 위한 단위당 신고 가치 |
| **수출 허가증** | 제품이 필요로 하는 경우 수출 허가증 번호 |
| **허가증 만료일** | 설정된 경우 수출 허가증의 만료일 |
| **국제 배송 준비 완료** | `예` 또는 `아니오` — 국제 배송에 필요한 최소 데이터가 제품에게 있는지 여부 (아래 참조) |

이 필드는 제품 폼의 **국제 배송 / 관세** 섹션에서 옵니다.

제품이 하나라도 누락된 경우, 내보내기 파일에서 해당 열은 비어 있게 됩니다. 실제 선적에 이 파일을 신뢰하기 전에 제품에서 누락된 데이터를 채워 주세요.

## 국제 배송 준비 상태 확인

이 기능은 각 제품을 개별로 열지 않고, 전체 CSV 내보내기를 기다리지 않고 국제적으로 배송하기 전에 대량의 제품을 감사하는 데 사용할 수 있습니다.

제품을 선택하고 **국제 배송 준비 상태 확인**을 선택한 후 **적용**을 클릭하십시오. Spwig는 각 선택된 제품을 세 가지 필수 필드인 **HS 코드**, **원산지 국가**, 및 **관세 단위 가격**과 비교하고 결과를 요약한 알림을 표시합니다:

- 선택된 모든 제품이 세 가지 필드를 모두 채운 경우, 모두 준비되어 있음을 확인하는 알림을 보게 됩니다.
- 일부 제품이 데이터를 누락한 경우, 알림은 준비된 제품과 준비되지 않은 제품의 수를 보고하며, 준비되지 않은 제품 각각과 해당 필드가 누락되었는지를 나열합니다 (예: "파란 도자기 머그잔 (누락: hs_code, country_of_origin)"). 10개 이상의 제품이 데이터를 누락한 경우, 알림은 처음 10개를 나열하고 추가로 몇 개가 더 있는지 알려줍니다.

이 작업은 데이터를 읽기만 할 뿐 제품의 내용을 변경하지 않으므로, 제품 카탈로그에서 관세 정보를 입력하는 동안 원하는 만큼 실행하는 것이 안전합니다.

**수출 라이선스 번호** 및 **수출 라이선스 만료일**은 준비 상태 검사의 일부가 아닙니다. 이는 제한된 또는 제어된 항목에만 적용되므로, 제품은 이들 없이도 국제 배송에 "준비" 상태일 수 있습니다.

## 팁

모든 마크다운 포맷, 이미지 경로, 코드 블록, 기술 용어를 보존하십시오.

- 첫 번째 국제 주문이 들어오기 전에 전체 카탈로그(또는 카테고리별로)에 대해 **국제 배송 준비 상태 확인**을 실행하세요 — 이미 국경에 도착한 화물에서 누락된 HS 코드를 발견하는 것보다 훨씬 빠릅니다.
- 브로커 및 운송업체에 전달할 목적으로 **수출 관세 데이터 (CSV)**를 유지하고, 내부 체크리스트용으로는 **국제 배송 준비 상태 확인**을 사용하세요 — CSV는 기록이고, 준비 상태 확인은 할 일 목록입니다.
- 새 제품을 추가할 때 제품 양식(**국제 배송 / 관세** 아래)에 **HS 코드**, **원산지**, **관세 단가**를 입력해 두면 나중에 일괄 처리할 필요가 없습니다.
- 제품 그리드는 스크롤할 때 자동으로 더 많은 제품을 로드합니다(무한 스크롤)하며, 새 제품이 로드될 때 체크박스 선택이 유지됩니다 — 따라서 작업을 적용하기 전에 스크롤하여 대량의 선택을 구성할 수 있습니다.

다만, 필터를 변경하거나 페이지를 다시 로드하면 선택이 초기화되므로, 필터를 조정하기 전에 작업을 적용하세요.
- **초안으로 표시**는 예를 들어 재고 재계산 전과 같이 다른 설정을 변경하지 않고 여러 제품을 한 번에 스토어프론트에서 제거하는 빠른 방법입니다.
