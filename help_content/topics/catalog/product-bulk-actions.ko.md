title: 제품 대량 작업
---

제품 목록은 각각의 제품을 개별적으로 열지 않고 여러 제품을 동시에 실행할 수 있도록 합니다. 제품 그리드 상단의 도구 모음에 있는 **대량 작업** 드롭다운에서 제품을 게시하거나 비게시하고, 특징을 지정하거나 해제하며, 데이터를 CSV로 내보내거나, 국제 배송 준비가 완료된 제품을 확인하거나, 또는 단일 단계에서 삭제할 수 있습니다.

이 작업을 사용하려면 **제품 > 모든 제품**으로 이동하십시오.

![세 개의 제품 카드가 선택되고, 대량 작업 드롭다운에 모든 옵션이 표시된 제품 목록 도구 모음, CSV로 내보내기 및 국제 배송 준비 확인 포함](/static/core/admin/img/help/product-bulk-actions/bulk-actions-dropdown.webp)

## 대량 작업 실행

1. 필요하다면 필터 패널 또는 **검색** 상자를 사용하여 작업할 제품을 좁히십시오
2. 포함할 제품 카드의 왼쪽 상단에 있는 체크박스를 선택하십시오 — **대량 작업** 바에 선택된 제품 수가 표시됩니다
3. **대량 작업** 드롭다운에서 작업을 선택하십시오
4. **적용**을 클릭하십시오

데이터를 변경하거나 내보내는 작업은 즉시 실행됩니다; **선택된 항목 삭제**는 목록에서 쉽게 되돌릴 수 없기 때문에 먼저 확인을 요청합니다.

## 사용 가능한 작업

| Action | What it does |
|--------|---------------|
| **게시로 표시** | 선택한 제품의 상태를 게시되어 있는 것으로 설정하여 상점에서 보이도록 합니다. |
| **드래프트로 표시** | 선택한 제품의 상태를 드래프트로 설정하여 편집을 계속하면서 상점에서 숨깁니다. |
| **특징으로 표시** | 선택한 제품에 **특징 있음**을 활성화합니다. |
| **특징 제거** | 선택한 제품에서 **특징 있음**을 비활성화합니다. |
| **CSV로 내보내기** | 선택한 제품의 ID, 이름, SKU, 상태, 특징 플래그, 가격을 포함한 CSV를 다운로드합니다. |
| **통관 데이터(CSV) 내보내기** | 선택한 제품에 대한 통관 정보를 포함한 CSV를 다운로드합니다. 아래를 참조하십시오. |
| **국제 운송 준비 상태 확인** | 선택한 제품 중 국제 운송을 위한 통관 데이터가 필요한 제품의 요약을 보여줍니다. 아래를 참조하십시오. |
| **선택한 항목 삭제** | 확인 프롬프트 후 선택한 제품을 재활용 쓰레기통으로 이동시킵니다. |

## 통관 데이터(CSV) 내보내기

대형 국제 운송 전이나, HS 코드 및 원산지 데이터를 미리 요청하는 새로운 운송사 설정 시와 같이 화물 운송사, 택배사 또는 세관 중개사에게 통관 서류를 제공해야 할 때 사용하십시오.

제품을 선택하고 드롭다운에서 **통관 데이터(CSV) 내보내기**를 선택한 후 **적용**을 클릭하십시오. Spwig는 제품당 한 줄씩, 다음 열을 포함한 `product_customs_data.csv`라는 파일을 다운로드합니다:

| 열 | 소스 |
|--------|--------|
| **SKU** | 제품의 SKU |
| **이름** | 제품 이름 |
| **HS 코드** | 조화된 시스템 분류 코드 |
| **원산지 국가** | 제품이 제조된 국가 |
| **통관 단위 가격** | 세관을 위한 단위당 신고 가격 |
| **수출 허가** | 제품에 필요한 경우 수출 허가 번호 |
| **허가 만료일** | 설정된 경우 수출 허가의 만료일 |
| **국제 준비 완료** | 제품이 국제 운송을 위한 최소 데이터를 보유하고 있는지 여부 (아래 참조) |

모든 마크다운 포맷, 이미지 경로, 코드 블록, 기술 용어를 보존하십시오.

이 필드는 제품 폼의 **국제 배송 / 관세** 섹션에서 옵니다.

제품이 하나라도 누락된 경우, 내보내기 파일에서 해당 열은 비어 있게 됩니다. 실제 선적에 이 파일을 신뢰하기 전에 제품에서 누락된 데이터를 채워 주세요.

## 국제 배송 준비 상태 확인

이 기능은 각 제품을 개별적으로 열지 않고, 전체 CSV 내보내기를 기다리지 않고 국제적으로 배송하기 전에 대량의 제품을 감사하는 데 사용할 수 있습니다.

제품을 선택하고 **국제 배송 준비 상태 확인**을 선택한 후 **적용**을 클릭하십시오. Spwig는 각 선택된 제품을 세 가지 필수 필드인 **HS 코드**, **원산지**, 및 **관세 단위 가격**과 비교하여 결과를 요약한 알림을 표시합니다:

- 선택된 모든 제품이 세 가지 필드를 모두 채운 경우, 모두 준비되어 있음을 확인할 수 있습니다.
- 일부 제품이 데이터를 누락한 경우, 알림은 준비된 제품과 준비되지 않은 제품의 수를 보고하며, 준비되지 않은 제품 각각과 해당 필드가 누락되었는지를 나열합니다 (예: "파란 도자기 머그잔 (누락: hs_code, country_of_origin)"). 10개 이상의 제품이 데이터를 누락한 경우, 알림은 처음 10개를 나열하고 추가로 몇 개가 더 있는지 알려줍니다.

이 작업은 데이터를 읽기만 할 뿐 제품의 내용을 변경하지 않으므로, 제품 카탈로그에서 관세 정보를 입력하는 동안 원하는 만큼 실행하는 것이 안전합니다.

**수출 라이선스 번호** 및 **수출 라이선스 만료일**은 준비 상태 검사의 일부가 아닙니다. 이는 제한된 또는 제어되는 항목에만 적용되므로, 제품은 이들 없이도 국제 배송에 "준비" 상태일 수 있습니다.

## 팁

모든 마크다운 포맷, 이미지 경로, 코드 블록, 기술 용어를 보존하십시오.

- 전체 카탈로그(또는 하나의 카테고리씩)에서 **국제 배송 준비 상태 확인**을 실행하십시오. 첫 번째 국제 주문을 하기 전이어야 하며, 배송이 이미 국경에 도달한 후에 누락된 HS 코드를 발견하는 것보다 훨씬 빠릅니다.
- **수출 세관 데이터 (CSV)**를 수출자 및 운송사에게 전달하기 위해 보관하고, **국제 배송 준비 상태 확인**을 자체 내부 체크리스트로 사용하십시오. CSV는 기록이며, 준비 상태 확인은 할 일 목록입니다.
- 새 제품을 추가할 때 **HS 코드**, **원산지**, **세관 단가**를 제품 양식 (즉, **국제 배송 / 세관**)에 입력하십시오. 나중에 대량으로 처리하지 않도록 하십시오.
- 제품 그리드는 스크롤할 때마다 더 많은 제품을 자동으로 로드하며, 체크박스 선택은 새 제품이 로드될 때까지 유지됩니다. 따라서 액션을 적용하기 전에 대규모 선택을 할 수 있습니다.

필터를 변경하거나 페이지를 새로 고치면 선택이 지워지므로, 필터를 조정하기 전에 액션을 적용하십시오.
- **작성 중으로 설정**은 여러 제품을 동시에 상점에서 제거하는 빠른 방법입니다. 예를 들어, 재고 재확인 전에 제품을 변경하지 않고도 이동할 수 있습니다.
