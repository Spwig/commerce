이 가이드는 스토어에 새 제품을 추가하는 방법을 안내합니다. 제품 폼은 기본 정보, 미디어, 가격, 재고, SEO 등과 같은 섹션으로 구성되어 있으므로,
모든 정보를 한 번에 입력하거나 나중에 섹션을 완료할 수 있습니다.

## 시작하기

사이드바에서 **제품 > 모든 제품**으로 이동하여 제품 카탈로그를 확인합니다. 상단 오른쪽의 **+ 제품 추가** 버튼을 클릭하여 제품 생성 폼을 엽니다.

![제품 목록 페이지](/static/core/admin/img/help/add-product/product-list-page.webp)

## 기본 정보

**기본 정보** 섹션에서는 제품의 핵심 정체성을 정의합니다.

![제품 추가 폼](/static/core/admin/img/help/add-product/add-product-form.webp)

### 필수 필드

모든 마크다운 포맷, 이미지 경로, 코드 블록, 기술 용어를 보존하십시오.

- **이름** — 고객에게 보이는 제품 이름입니다.

글로벌 아이콘을 클릭하여 다른 언어로의 번역을 추가하십시오.
- **슬러그** — URL 친화적인 이름 (자동 생성됨).

필요한 경우 수정하십시오.
- **SKU** — 내부 재고 관리 코드입니다.
- **제품 유형** — 다음 중 선택: 단순, 변수, 디지털, 패키지, 선불 카드, 사용자 정의, 구성 가능, 또는 예약.
- **카테고리** — 조직 및 스토어플로어 탐색을 위해 제품을 카테고리에 할당하십시오.

### 상태 및 가시성

양식 하단의 **상태** 섹션에 있습니다:

- **상태** — 작업 중인 경우 **초안**으로 설정하고, 판매 준비가 완료되면 **게시**하거나, 더 이상 제공하지 않는 제품의 경우 **중단됨**으로 설정하십시오.
- **특징 제품** — 이 제품을 스토어플로어에 강조 표시하려면 체크합니다.
- **디지털 제품** — 이 제품에 디지털 다운로드(파일, 라이선스)가 포함되어 있는 경우 체크합니다. 어떤 제품 유형과도 결합할 수 있습니다.
- **스토어플로어에서 숨기기** — 제품을 카탈로그 목록에서 숨기지만, 구성 요소나 패키지 구성 요소로는 사용할 수 있도록 유지합니다.

### 선택 필드

- **브랜드** — 해당하는 경우 브랜드와 연관시킵니다.
- **태그** — 이 탭 하단의 **태그** 카드에 하나 이상의 태그를 할당합니다. 태그는 컬렉션과는 다릅니다. 제품을 조직하고 필터링하는 데 사용되는 빠른, 자유형 라벨이며, 상품 판매 그룹은 아닙니다. 기존 태그를 검색하려면 입력을 시작하십시오. 또는 즉시 새 이름을 입력하여 생성하십시오. **제품 태그** 도움말 주제를 참조하십시오. 직접 태그를 생성, 이름 변경, 대량 삭제하는 방법을 알아보십시오.

### 제품 설명

- **짧은 설명** — 제품 목록 및 카드에 표시됩니다. 간결하고 매력적으로 유지하십시오.
- **완전한 설명** — 제품 세부 정보 페이지에서 표시되는 제품 설명입니다. 포맷팅, 이미지, 비디오, 표를 추가하기 위해 풍부한 텍스트 편집기를 사용하십시오.

두 설명 필드 모두 번역 기능을 지원합니다. 다른 언어로 콘텐츠를 제공하려면 글로벌 아이콘을 클릭하십시오.

### 특징 및 사양

모든 마크다운 포맷, 이미지 경로, 코드 블록, 기술 용어를 보존하십시오.

제품 세부 정보 섹션에는 두 가지 구조화된 데이터 필드가 있습니다:

- **특징** — 제품 강조 사항에 대한 키-값 쌍 (예: "배터리 수명: 20시간").
- **사양** — 제품 페이지의 사양 탭에 대한 기술적 세부 정보 (예: "프로세서: 인텔 i7").

## 미디어

**미디어** 섹션에서는 통합 미디어 라이브러리를 사용하여 제품 이미지를 관리할 수 있습니다.

![미디어 탭](/static/core/admin/img/help/add-product/media-tab.webp)

1. **+ 미디어 라이브러리에서 이미지 추가**를 클릭하여 미디어 선택기를 엽니다.
2. 기존 이미지를 선택하거나 직접 업로드할 수 있습니다.
3. 이미지를 드래그하여 순서를 재정렬합니다. - **첫 번째 이미지**는 목록 및 카드에 표시되는 주요 제품 이미지가 됩니다.

**갤러리 유형** 필드는 이미지가 상점에서 어떻게 표시되는지를 제어합니다: 표준 갤러리, 카ousel, 그리드 레이아웃, 줌 갤러리, 또는 360도 보기.

## 가격

제품의 가격을 설정하고, 세일을 구성하십시오.

![가격 탭](/static/core/admin/img/help/add-product/pricing-tab.webp)

### 정가

- **정가** — 고객이 보게 될 표준 소매가입니다. 통화는 가격 금액과 함께 설정됩니다.
- **비용** — 제품 비용으로, 이는 수익 계산에 사용됩니다. 이는 고객에게 보이지 않습니다.

### 세일 설정

시간 제한 할인을 구성하십시오:

- **세일 유형** — 선택 가능한 옵션: "세일 없음", "고정 세일 가격", "고정 금액 할인", "백분율 할인" 중 하나를 선택하십시오.
- **세일 값** — 할인 금액 또는 백분율입니다.
- **세일 시작일 / 세일 종료일** — 세일이 활성화되고 만료되는 시기를 설정하십시오. 즉시 시작하거나 종료일이 없도록 비워 두려면 비워 두세요.

### 다국가 통화 가격

가게에 다국가 통화가 활성화되어 있는 경우, **가격 전략** 필드가 나타납니다:

- **동적 가격** — 다른 통화의 가격은 구성된 환율을 사용하여 자동으로 계산됩니다.
- **고정 가격** — **다국가 통화 가격** 섹션이 아래에 나타나며, 각 통화에 대해 독립적으로 특정 가격을 설정할 수 있습니다.

## 재고

모든 마크다운 포맷, 이미지 경로, 코드 블록, 기술 용어를 보존하십시오.

재고 수준, 배송 행동 및 물리적 제품 속성을 관리하십시오.

![재고 탭](/static/core/admin/img/help/add-product/inventory-tab.webp)

### 재고 관리

- **재고 추적** — 기본적으로 활성화되어 있는 재고 수량을 추적하도록 설정합니다.
- **저재고 기준** — 이 숫자보다 재고가 낮아지면 알림을 받습니다 (기본값: 5).
- **재주문 허용** — 재고가 없을 때 주문을 받도록 설정합니다.
- **재고 소진 시 행동** — 이 제품이 재고가 소진되었을 때 사이트 전체 또는 카테고리의 행동을 재정의합니다. 숨기기, 사용 불가로 표시하기, "알림 받기" 버튼 표시, 또는 재주문 허용을 선택할 수 있습니다.

재고 수량은 창고별로 관리됩니다. 제품을 저장한 후, 양식 하단의 **재고 항목** 섹션(또는 **제품 > 재고 항목**으로 이동)을 사용하여 각 창고 위치의 수량을 설정하십시오.

### 물리적 속성

배송 계산을 위해 제품의 무게(kg)와 치수(길이, 너비, 높이, cm 단위)를 입력하십시오.

### 배송

- **배송 필요** — 이 제품이 고객에게 배송되어야 하는지 여부입니다. 물리적 제품에 대해 기본적으로 활성화되어 있습니다. 스토어플랫폼과 체크아웃은 이 설정을 기반으로 주소를 수집하고 주문에 대한 배송비를 산정합니다. Spwig은 디지털, 예약, 선물 카드 제품에 대해서는 이 기능을 자동으로 비활성화합니다. 이 제품 유형에 대해서는 다시 활성화할 수 없습니다. 예를 들어, 상자에 포장되어 배송되는 인쇄된 선물 카드와 같이 디지털과 유사한 모양을 가진 물리적 제품에 대해서는 이 옵션을 체크해 두십시오.
- **선호하는 배송 패키지** — 구성된 배송 패키지 중 하나를 선택할 수 있습니다. 설정이 되면, 이 제품의 무게와 치수 대신 패키지의 치수가 배송 요금 계산에 사용됩니다. 제품이 항상 동일한 표준 상자나 봉투에 포장되어 배송되는 경우 유용합니다. 제품의 물리적 속성을 사용하려면 비워 두세요. 사용 가능한 패키지는 **배송 > 패키지**에서 관리하십시오.

### 사전 주문

모든 마크다운 포맷, 이미지 경로, 코드 블록, 기술 용어를 보존하십시오.

사전 주문 카드를 사용하여 재고가 없는 제품을 판매하십시오. 출시 전에 주문을 시작하고자 하는 새로운 출시 제품에 유용합니다:

- **사전 주문** — 이 제품을 재고가 없을 때도 고객이 구매할 수 있도록 하려면 활성화하십시오.
- **사전 주문 출시 날짜** — 고객에게 표시되는 예상 가용성 날짜입니다.
- **사전 주문 메시지** — 고객에게 표시되는 짧은 사용자 정의 메시지로, 200자까지 가능합니다 (예: "2026년 3월 출고").

### 제품 식별자

마켓플레이스 목록 및 재고 시스템용 표준 제품 코드:

- **GTIN** — 글로벌 트레이드 아이템 번호
- **EAN** — 유럽 제품 번호
- **UPC** — 유니버설 제품 코드 (미국)
- **ISBN** — 책용
- **ASIN** — 아마존 식별자
- **MPN** — 제조사 부품 번호

### 국제 배송 / 관세

국제 배송에 필요합니다 (**) 국제 배송 / 관세 ** 섹션을 확장하십시오):

- **HS 코드** — 통합 시스템 분류 코드
- **원산지 국가** — 제품이 제조된 국가
- **관세 단위 가격** — 관세를 위한 단위당 선언 가격
- **수출 라이선스 번호** — 통제되거나 제한된 품목에만 필요한 번호
- **수출 라이선스 만료일** — 수출 라이선스의 만료 날짜

## SEO

제품의 검색 엔진 노출를 최적화하십시오.

![SEO 탭](/static/core/admin/img/help/add-product/seo-tab.webp)

- **메타 제목** — 검색 엔진 결과에서 표시되는 제목입니다. 번역하려면 세계 지도 아이콘을 클릭하십시오.
- **메타 설명** — 검색 결과용 짧은 설명 (최대 160자). 번역하려면 세계 지도 아이콘을 클릭하십시오.
- **자동 생성 SEO** — 제품을 저장할 때 SEO 콘텐츠를 자동으로 생성하려면 체크하십시오.

실시간 **검색 결과 미리보기**는 제품이 구글 검색 결과에서 어떻게 표시되는지 정확히 보여줍니다.

## 제품 페이지 설정

**고급** 탭의 **제품 페이지 설정** 카드는 이 제품의 스토어 페이지가 어떻게 보이는지 제어할 수 있게 해줍니다.

- **페이지 템플릿** — 이 제품에 대해 사이트 기본 제품 페이지 레이아웃을 재정의합니다. 클래식, 전체 너비, 갤러리 포커스, 또는 디지털을 선택하십시오.

기본값을 **사이트 기본값 사용**으로 설정하면 디자인 설정에서 지정한 레이아웃을 상속받습니다. 대부분의 제품은 기본값을 유지해야 하며, 이 경우 템플릿 변경 사항이 자동으로 적용됩니다.
- **관련 제품 표시** — 페이지 하단에 관련 제품을 표시합니다.
- **리뷰 표시** — 고객 리뷰를 표시합니다.
- **사양 표시** — 사양 탭을 표시합니다.

**갤러리 유형** 필드는 제품 이미지 표시 방식(표준 갤러리, 카ousel, 그리드 레이아웃, 줌 갤러리, 또는 360도 뷰)을 제어하는 것으로, **미디어** 탭에서 별도로 설정됩니다.

## 판매 채널

**판매 채널** 필드는 제품을 판매할 수 있는 위치를 제어합니다(상태 섹션에 있음):

- **모든 채널** — 온라인 및 오프라인(POS)에서 제공됩니다.
- **온라인만** — POS 단말기를 통해 제공되지 않습니다.
- **오프라인 매장만** — 온라인에 등록되지 않으며, 물리적인 매장에서만 제공됩니다.

POS 바코드 스캔용 **바코드** 필드도 제공됩니다.

## 제품 저장하기

준비가 되면 상단 오른쪽 모서리의 저장 버튼을 사용하십시오. 제품 상태가 **게시됨**으로 설정되면 제품이 스토어에서 보이게 됩니다.

## 팁

모든 마크다운 포맷, 이미지 경로, 코드 블록, 기술 용어를 보존하십시오.

- **초안** 상태로 시작하여, 고객이 보는 것보다 먼저 제품을 완벽하게 만드세요.
- 여러 이미지를 업로드하세요 - 여러 사진이 있는 제품은 더 잘 팔립니다.
- 검색 엔진에서 탐색이 가능하도록 **SEO** 필드를 채우세요.
- 고객이 카탈로그를 탐색하는 데 도움이 되도록 **카테고리**, **브랜드**, **태그**를 사용하세요.
- 변형 제품(예: 다양한 크기나 색상)의 경우, **변형 제품** 유형을 선택하고 저장한 후 변형을 추가하세요.
- 제품 페이지의 전용 탭에 표시되는 구조화된 제품 데이터를 추가하기 위해 **특징**과 **사양**을 사용하세요.
- **배송 필요**가 체크된 상태로 남아 있지 않는 경우, **제품 유형**을 확인하세요 - 디지털, 예약, 선불 카드 제품은 물리적으로 배송되지 않기 때문에 Spwig은 이 제품 유형에 대해 자동으로 배송을 끕니다.
- 항상 동일한 상자로 배송되는 제품에 대해 **선호하는 배송 패키지**를 설정하세요 - 이로 인해 제품의 무게와 치수를 실제로 사용하는 상자와 동기화할 필요가 없게 됩니다.
