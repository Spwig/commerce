## どの製品タイプをサブスクリプションとして販売できますか

サブスクリプションは、次の製品タイプでのみ利用可能です:

| 対象となる | 対象外 | 
|----------|---------------| 
| シンプル製品 | 製品バンドル | 
| バリアブル製品 | ギフトカード | 
| デジタル製品 | カスタマイズ可能な製品 | 
| | 設定可能な製品 | 
| | ブッキング製品 | 

理由は、納品、価格ではなく、サブスクリプションはサイクルごとにカスタマに再請求し、各サイクルごとに新しい注文を通じて製品を再配信するからです。

Spwigは、シンプルまたは変動商品を再配送し、デジタル製品のダウンロードまたはライセンスを再付与できることがわかりますが、再発行することはできません。これは、ギフトカードの発行、マルチコンポーネントバンドル、カスタマーサービスのカスタマイズ、カスタマイズビルダー、予約スロットを繰り返しスケジュールすることを意味します。

これらの種類をサブスクリプションとして販売すると、2回目のサイクルで顧客のお金を引き出すリスクがあり、何の提供も行えなくなる可能性があります。

**サブスクリプションを有効にする**チェックボックスは、不適格な種類に対して非表示またはグレーアウトされていません。これは、どの製品でもチェックできます。ギフトカード、バンドル、カスタマイズ可能、構成可能、予約の製品をサブスクリプションを有効にして保存しようとすると、Spwigは検証エラーで、この製品タイプはサブスクリプションとして販売できませんと説明するエラーを送出します。まず**製品タイプ**を変更してください（基本情報タブ）、またはその製品に対してサブスクリプションをオフにしてください。

## 製品にサブスクリプションを有効にする

1. **製品 > すべての製品**に移動し、サブスクリプションとして販売したい製品を開きます（または新しい製品を作成します）。
2. **製品タイプ**が基本情報タブで**シンプル**、**変動**、または**デジタル**であることを確認してください。
3. **サブスクリプション**タブをクリックします。
4. **サブスクリプションを有効にする**にチェックを付けます。
5. **サブスクリプションプラン**フィールドで、この製品が提供するプランを選択します。すでに存在するプランのみを選択できます。まだ作成していない場合は、まず[サブスクリプションプラン](/help/subscription-plans)を参照してください。
6. 2つの購入モードのチェックボックスを構成します（下にあります）。
7. **保存**をクリックします。

## サブスクリプションプランを添付する

**サブスクリプションプラン**は、支払いスケジュールオプション、トライアル、設定料、キャンセルルールなど、一度構築してから、どのエレガブル製品にも添付できるテンプレートです。製品のサブスクリプションタブにある**サブスクリプションプラン**フィールドは、製品をそのプランに接続する場所です。

同じ製品に1つ以上のプランを添付できます。

すべてのマーケドフォーマット、画像パス、コードブロック、技術用語を保持してください。

これは、たとえば、同じ製品に対して「スタンダード」と「プレミアム」の繰り返し価格モデルを提供したい場合に役立ちます。これにより、各プランで独自の価格階層、トライアル、解約ポリシーを設定できます。

製品に複数のプランが関連付けられている場合、カスタマーアreaは、支払い頻度を選択する前に製品ページでプラン選択器を見ることになります。

## 1回払いと購読購入の制御

サブスクリプションタブに2つのチェックボックスがあり、カスタマーアreaが製品を購入する方法を制御します。

- **1回払いを許可する** — 既定では有効です。チェックを入れると、カスタマーアreaは通常の1回払いと購読のどちらかを選べます。チェックを外すと、製品は購読専用になります。すべての購入が繰り返し注文となり、1回払いのオプションは一切表示されなくなります。
- **購読にデフォルトする** — 製品ページが読み込まれるときに、カスタマーアreaが積極的に選ばなくても、購読オプション（およびそのデフォルトプラン/階層）がデフォルトで選択されるようになります。これは**1回払いを許可する**がチェックされている場合にのみ効果があります。1回払いがオフになっている場合、この設定に関係なく製品は購読専用になります。

**購読にデフォルトする**は、繰り返し配達が自然な期待である製品（コーヒー、サプリメント、消耗品など）に使用してください。これは1クリックを削除し、カスタマーアreaを繰り返し購入するオプションに向かせるようにしつつ、一度だけ購入する能力を制限しないようにします。

## カスタマーアreaが見る画面

### 製品ページで

製品にサブスクリプションが有効になっており、少なくとも1つのアクティブで公開されているプランが関連付けられている場合、製品ページに購入モードセレクターが表示されます。

- 1回限りの購入が許可されている場合、カスタマーは**「1回限りの購入」**と**「購読して節約」**の選択肢を見ることになり、どちらかのモードがデフォルトで構成されます。
- 商品に1つ以上のプランが関連付けられている場合、ユーザーが「購読して節約」を選択すると、プラン選択者が表示されます。
- 選択されたプランに対して、カスタマーはそのプランの価格構造（例: 月次、四半期、年次）から構成された**配達頻度**の一覧を見ることになり、その価格構造に割引が適用されている場合は**「X%節約」**のバッジが表示されます。
- トライアル期間、設定料、およびプランの解約ポリシー（例: 「いつでも解約可能」）は、価格構造一覧とともに表示され、支払い方法はチェックアウト時に追加されることに注意してください。

### カートとチェックアウトで

カート内のサブスクリプションのラインアイテムには**サブスクリプション**のバッジが表示され、支払いのサイクル（例: 「毎月」）と、該当する場合のトライアルノートが表示されるため、カスタマーがどのラインが繰り返しのものであるかが明確になります。チェックアウトでは、通常通り決済プロバイダーを選択します。これは、今後の更新時に請求される支払い方法になります。

> **既知の制限:** 一部の決済プロバイダーでは、チェックアウト時にカスタマーのカードを自動的に保存して、今後のサブスクリプションの更新に使用する機能がまだ接続されていません。特定のプロバイダーがこの機能をサポートするまで、そのプロバイダーを通じて購入されたサブスクリプションは、チェックアウト時に自動的に請求されない場合があるため、更新の前にカスタマーに新しい支払い情報を依頼するなどの追加フォローアップが必要になる可能性があります。この点について心配な点が見られる場合は、支払いプロバイダーの設定について確認してください。

## トピック

- サブスクリプションプランを作成し、テストしてから製品に接続してください（価格構造、トライアル、解約ポリシー）。一度プランを正しく設定してから製品に接続した方が、後で複数の製品にわたって修正するよりも楽です。
- ほとんどの製品で**1回限りの購入を許可**するチェックを外さないでください。

購入オプションの製品は、1回限りの購入が本当にビジネスにとって意味のない場合にのみ予約してください。
- 既存の売れ筋製品をサブスクリプションオプションに変換している場合、最初は**デフォルトをサブスクリプションに**オフのままにして、一度だけ購入する習慣がある顧客に影響を与えないでください。サブスクIBァーの反応を見てから後で**デフォルトをサブスクリプションに**をオンにしてください。
- デジタル製品はサブスクリプションに最適です（ソフトウェアライセンス、コンテンツ会員制）は、リニューアルで自動的にアクセス権が再付与されるため、配達が不要だからです。
- 一時的な製品タイプ（バンドルやカスタマイズ可能な製品など）が繰り返し購入されるようにしたい場合は、サブスクリプションを代用することができる単純なシングルまたはデジタル版を検討してください。
