ระบบคลังสินค้าช่วยให้คุณจัดการสต็อกสินค้าในหลายสถานที่ กำหนดลำดับความสำคัญในการจัดส่ง และติดตามระดับสต็อกแบบเรียลไทม์ ไปที่ **สินค้า > คลังสินค้า** ในแถบด้านข้างของผู้ดูแลเพื่อจัดการสถานที่คลังสินค้าของคุณ

![รายการคลังสินค้า](/static/core/admin/img/help/inventory-warehouses/warehouse-list.webp)

## คลังสินค้า

### รายการคลังสินค้า

หน้าคลังสินค้าแสดงสถานที่จัดเก็บสินค้าทั้งหมดในรูปของบัตรที่มี:

- **ชื่อและรหัส** — รหัสตัวระบุคลังสินค้า (เช่น "คลังสินค้าหลัก" รหัส "MAIN-WH")
- **เขตการขาย** — การจัดประเภทภูมิภาคทางภูมิศาสตร์
- **สัญลักษณ์สถานะ** — สถานะเปิด/ปิด สถานที่ค้าปลีก
- **สถิติ** — สินค้าที่มีอยู่ ลำดับความสำคัญในการจัดส่ง ร้อยละของสต็อกสำรอง
- **ตำแหน่ง** — เมืองและประเทศ
- **อัปเดตล่าสุด** — เวลาที่ระดับสต็อกถูกแก้ไขลast

### การสร้างคลังสินค้า

1.

คลิก **+ เพิ่มคลังสินค้า**
2.

กรอกข้อมูลพื้นฐาน:
   - **ชื่อ** — ชื่อที่อธิบายได้ (เช่น "คลังสินค้าตะวันออกสหรัฐ")
   - **รหัส** — รหัสย่อที่ไม่ซ้ำ (เช่น "US-EAST") — ต้องไม่ซ้ำกับคลังสินค้าทั้งหมด
   - **เขตการขาย** — กำหนดให้กับภูมิภาคทางภูมิศาสตร์สำหรับการจัดส่ง
   - **เปิดใช้งาน** — เปิดเพื่อรวมเข้ากับการจัดส่ง
3.

กรอกส่วน **ที่อยู่** ด้วยที่อยู่เต็มของคลังสินค้า
4.

ตั้งค่า **การตั้งค่าการจัดส่ง**:
   - **ลำดับความสำคัญในการจัดส่ง** — ค่าที่มากขึ้น = ลำดับความสำคัญสูงขึ้นสำหรับการจัดส่ง
   - **ร้อยละของสต็อกสำรอง** — ร้อยละของสต็อกที่ต้องสงวนเป็นสต็อกสำรอง (0–100)
   - **ตำแหน่งจัดส่ง** — ระบุตำแหน่งรับสินค้าได้ในกรณีที่คลังสินค้านี้รองรับการรับสินค้าของลูกค้า
5.

ตั้งค่า **การแสดงผลให้ลูกค้า** (ตัวเลือก):
   - **ชื่อที่แสดง** — ชื่อที่ลูกค้าเห็น (เช่น "จัดส่งจากออสเตรเลีย")

   ปล่อยว่างเพื่อใช้ชื่อคลังสินค้า
   - **แสดงบนหน้าแรก** — แสดงต้นกำเนิดของคลังสินค้านี้ให้ลูกค้าบนหน้าสินค้า
6.

รักษารูปแบบ Markdown ทั้งหมด รูปแบบไฟล์รูปภาพ บล็อกโค้ด และคำศัพท์ทางเทคนิค

ตั้งค่า **POS / ร้านค้าปลีก** (ตัวเลือก):
   - **สถานที่ขายปลีก** — ตรวจสอบว่าคลังสินค้านี้ยังเป็นร้านค้าปลีกที่มีเครื่องมือ POS หรือไม่
   - **ชื่อแสดงใน POS** — ชื่อย่อที่แสดงในหน้าต่าง POS
   - **กลุ่มร้านค้า** — กำหนดให้อยู่ในกลุ่มร้านค้า POS เพื่อการส héritage ของค่าตั้งค่า
7.

เพิ่ม **ข้อมูลติดต่อ** หากจำเป็น (ชื่อ, อีเมล, เบอร์โทรศัพท์)
8.

คลิก **บันทึก**

### ลำดับความสำคัญในการจัดส่ง

เมื่อมีคำสั่งซื้อเข้ามา ระบบจะเลือกคลังสินค้าที่ดีที่สุดโดยอิงจาก:

1. **ค่าลำดับความสำคัญ** — คลังสินค้าที่มีลำดับความสำคัญสูงกว่าจะได้รับการเลือกมากกว่า
2. **การมีอยู่ของสินค้า** — ต้องมีสินค้าเพียงพอ
3. **การตรงกันของภูมิภาค** — คลังสินค้าในภูมิภาคของลูกค้าจะได้รับการเลือกมากกว่า

ตัวอย่างเช่น หากคุณมีคลังสินค้าในสหรัฐอเมริกา (ลำดับความสำคัญ 100) และคลังสินค้าในยุโรป (ลำดับความสำคัญ 60) คำสั่งซื้อจากสหรัฐอเมริกาจะได้รับการจัดส่งจากคลังสินค้าในสหรัฐอเมริกาก่อน

### จำนวนสินค้าสำรอง

จำนวนสินค้าสำรองนี้จะสำรองเปอร์เซ็นต์ของสินค้าที่ไม่ได้ขายทางออนไลน์ ซึ่งมีประโยชน์สำหรับ:
- ร้านค้าปลีกที่ต้องการสินค้าบนพื้นที่
- สินค้าสำรองเพื่อป้องกันการขายเกิน
- สินค้าสำรองสำหรับคำสั่งซื้อขายส่ง

การสำรอง 10% ของ 100 หน่วยหมายความว่ามีเพียง 90 หน่วยที่พร้อมขายทางออนไลน์เท่านั้น

## รายการสินค้า

รายการสินค้าแสดงถึงสินค้าจริงของผลิตภัณฑ์เฉพาะในคลังสินค้าเฉพาะ

### การดูระดับสินค้า

1. คลิก **สัญลักษณ์สินค้า** บนบัตรคลังสินค้าทุกอันเพื่อดูรายการสินค้า
2. หรือนำทางไปยังแท็บ **Inventory** ของผลิตภัณฑ์เพื่อดูสินค้าในคลังสินค้าทั้งหมด

แต่ละรายการสินค้าแสดง:
- **ชื่อผลิตภัณฑ์** และรูปแบบ (ถ้ามี)
- **จำนวนที่มี** — จำนวนสินค้าจริง
- **จำนวนที่จัดสรร** — จำนวนที่สำรองไว้สำหรับคำสั่งซื้อที่ยังไม่เสร็จ
- **จำนวนที่พร้อมขาย** — จำนวนที่มี ลบ จำนวนที่จัดสรร (จำนวนที่สามารถขายได้)

### การเพิ่มสินค้า

1.

ไปที่ **Products > Stock Items** และคลิก **+ Add Stock Item**, หรือ
2.

เปิดฟอร์มแก้ไขของผลิตภัณฑ์และใช้ส่วน **Stock Items** ที่อยู่ด้านล่าง
3.

เลือก **ผลิตภัณฑ์** และ **คลังสินค้า** (และตัวเลือก **รูปแบบ** สำหรับผลิตภัณฑ์ที่มีหลายรูปแบบ)
4.

ป้อนจำนวน **จำนวนที่มี**
5.

รักษารูปแบบมาโครทั้งหมด ชื่อไฟล์รูปภาพ บล็อกโค้ด และคำศัพท์ทางเทคนิค

ตั้งค่า **ระดับสินค้าคงเหลือต่ำ** — ค่าที่กำหนดสำหรับแต่ละสินค้าจะกระตุ้นการแจ้งเตือนสินค้าคงเหลือต่ำ
6。

บันทึก

### การเคลื่อนไหวของสินค้าคงเหลือ

ทุกการเปลี่ยนแปลงของสินค้าคงเหลือจะถูกบันทึกเป็น **การเคลื่อนไหวของสินค้าคงเหลือ**:

| ประเภทการเคลื่อนไหว | คำอธิบาย |
|--------------|-------------|
| **การรับสินค้า** | สินค้าใหม่ที่ได้รับจากผู้ขาย |
| **การขาย** | สินค้าถูกหักออกเนื่องจากคำสั่งซื้อที่ได้รับการจัดส่ง |
| **การคืนสินค้า** | สินค้าที่คืนกลับมาจากรายการลูกค้า |
| **การปรับปรุง** | การแก้ไขด้วยมือ (ความคลาดเคลื่อนของจำนวนสินค้า) |
| **การโอนย้าย** | ถูกย้ายระหว่างคลังสินค้า |
| **การจัดสรรชั่วคราว** | ถูกจัดสรรไว้ชั่วคราวสำหรับตะกร้าสินค้าที่ยังไม่ได้รับการยืนยัน |
| **ความเสียหาย** | ถูกตัดออกเนื่องจากสินค้าเสียหายหรือสูญหาย |
| **การนับสินค้าซ้ำ** | ปรับให้ตรงกับจำนวนสินค้าจริง |

การเคลื่อนไหวของสินค้าคงเหลือให้ข้อมูลการตรวจสอบการเปลี่ยนแปลงของสินค้าคงเหลือ นอกเหนือจากการ **ปรับระดับสินค้าคงเหลือ** แล้ว Spwig ยังมีการดำเนินการแบบหลายรายการบนรายการสินค้าคงเหลือเพื่อโอนย้าย เขียนลดค่า และนับสินค้าซ้ำสำหรับสินค้าหลายรายการพร้อมกัน — ดู [การดำเนินการแบบ Bulk ของสินค้าคงเหลือ](/help/stock-bulk-actions)。

## การติดตามสินค้าคงเหลือบนสินค้า

### การเปิดใช้งานการติดตามสินค้าคงเหลือ

ในส่วน **สินค้าคงเหลือ** ของสินค้า:

1. เปิดใช้งาน **การติดตามสินค้าคงเหลือ** เพื่อเปิดการจัดการสินค้าคงเหลือสำหรับสินค้าตัวนี้
2. ตั้งค่า **ระดับสินค้าคงเหลือต่ำ** — จะกระตุ้นการแจ้งเตือนบนแดชบอร์ดเมื่อสินค้าคงเหลือที่แต่ละคลังลดลงต่ำกว่าค่านี้
3. ตั้งค่า **อนุญาตให้สั่งซื้อเมื่อไม่มีสินค้า** หากคุณต้องการรับคำสั่งซื้อเมื่อไม่มีสินค้าคงเหลือ
4. ตั้งค่า **การดำเนินการเมื่อไม่มีสินค้า** เป็นทางเลือกเพื่อแทนที่พฤติกรรมของเว็บไซต์หรือหมวดหมู่สำหรับสินค้าเฉพาะตัวนี้

หลังจากเปิดใช้งานการติดตามแล้ว จัดการจำนวนสินค้าคงเหลือจริงโดยใช้ส่วน **สินค้าคงเหลือ** ที่อยู่ในรูปแบบของสินค้า ที่ด้านล่างของฟอร์มสินค้า หรือผ่าน **สินค้า > สินค้าคงเหลือ**

### สินค้าคงเหลือหลายคลัง

เมื่อการติดตามสินค้าคงเหลือถูกเปิดใช้งาน แท็บสินค้าคงเหลือจะแสดงระดับสินค้าคงเหลือในคลังทั้งหมดในตารางสรุป:

- จำนวนสินค้าคงเหลือรวมทั้งหมด
- การแบ่งส่วนแต่ละคลัง
- จำนวนสินค้าคงเหลือหลังจากการจัดสรรและการจัดสรรชั่วคราว

## การแจ้งเตือนสินค้าคงเหลือต่ำ

รักษารูปแบบมาร์กดาวน์เดิม ชื่อเส้นทางรูปภาพ บล็อกโค้ด และคำศัพท์ทางเทคนิคทั้งหมด

ระบบจะตรวจสอบระดับสินค้าคงคลังโดยอัตโนมัติและแจ้งเตือนคุณเมื่อ:
- สินค้าลดลงต่ำกว่า **ระดับสต็อกต่ำ**
- สินค้าเหลือ **จำนวนสินค้าที่มีอยู่ศูนย์**

การแจ้งเตือนเกี่ยวกับสต็อกต่ำจะปรากฏใน:
- **หน้าจอร้านค้า** ในส่วน Actions Required
- รายการสินค้าด้วยสัญลักษณ์แสดงผลทางภาพ

## เคล็ดลับ

- เริ่มต้นด้วยคลังสินค้าเพียงแห่งเดียว และเพิ่มอีกเมื่อธุรกิจเติบโตขึ้น
- กำหนดลำดับความสำคัญในการจัดส่งตามความเร็วและค่าใช้จ่ายในการจัดส่งแต่ละพื้นที่
- ใช้สต็อกสำรองสำหรับสาขาค้าปลีกเพื่อให้มั่นใจว่ามีสินค้าสำหรับขายบนพื้นที่
- ตรวจสอบการเคลื่อนไหวของสินค้าเป็นประจำเพื่อระบุการสูญเสียหรือความคลาดเคลื่อน
- ตั้งค่าระดับสต็อกต่ำตามเวลาในการสั่งซื้อของคุณ — หากการสั่งซื้อใช้เวลา 2 สัปดาห์ ให้ตั้งค่าระดับสต็อกให้ครอบคลุมการขาย 2 สัปดาห์
- เปิดใช้งานการติดตามสต็อกก่อนที่จะเปิดตัวเพื่อหลีกเลี่ยงการขายเกินสต็อก
