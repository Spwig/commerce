---
title: 재고 알림
---

재고 알림은 제품이 다시 재고가 있을 때 이메일로 알림을 받을 수 있도록 고객을 등록하게 해줍니다. 재고 표시 설정은 제품 페이지에서 고객이 보는 내용을 제어한다. 예를 들어 재고 상태 라벨, 저재고 경고, 제품이 품절되었을 때 어떤 일이 발생하는지를 포함합니다.

## 재고 표시 설정

재고 표시 설정은 카테고리나 제품 수준에서 재정의되지 않는 한 모든 제품에 적용되는 가맹점 전체 기본 설정입니다.

이 옵션을 구성하려면 **카탈로그 > 재고 표시 설정**으로 이동하세요. 가맹점용 설정 레코드가 하나 있습니다. 수정하려면 클릭하세요.

### 재고 상태 표시

| 설정 | 설명 |
|---------|-------------|
| **재고 상태 표시** | 제품 페이지에 "재고 있음" 또는 "품절" 라벨 표시 |
| **저재고 경고 표시** | 재고가 줄어들면 "X개만 남음" 메시지 표시 |
| **저재고 기준** | 저재고 경고가 표시되는 수량 (기본값: 5) |
| **정확한 수량 표시** | "3개만 남음!"과 같은 정확한 수량 표시 (일반적인 경고 대신) |

### 품절 시 행동

"품절 시 행동" 설정은 제품에 재고가 없을 때 고객이 보는 내용을 결정합니다:

| 행동 | 고객이 보는 내용 |
|--------|-------------------|
| **목록에서 숨기기** | 제품이 카테고리 페이지 및 검색 결과에서 제거됨 |
| **사용 불가로 표시** | 제품은 보이지만 장바구니에 추가할 수 없음 |
| "내게 알림 보내기" 버튼 표시 | 고객은 재고가 돌아올 때 알림을 받을 수 있도록 이메일을 등록할 수 있음 |
| **백오더 허용** | 재고가 0일 때에도 제품을 구매할 수 있음 |

"품절 메시지"를 설정하여 제품이 사용할 수 없을 때 표시되는 텍스트를 사용자 정의합니다 (기본값: `품절`).

"백오더 메시지"를 설정하여 백오더 가능한 제품에 표시되는 텍스트를 사용자 정의합니다 (기본값: `백오더 가능`).

### 배송 및 배송 표시

모든 마크다운 포맷, 이미지 경로, 코드 블록, 기술 용어를 유지하십시오.

| 설정 | 설명 |
|---------|-------------|
| **"배송지" 위치 표시** | 상품 페이지에 창고 이름 표시 |
| **예상 배송일 표시** | 창고 위치 기반으로 계산된 예상 배송일 표시 |

### 재고 소진 상품 주문 허용 (사이트 전체)

기본적으로 재고가 없는 제품을 고객이 구매할 수 있도록 하려면 **재고 소진 상품 주문 허용**을 체크하세요. 개별 제품과 카테고리는 이 설정을 재정의할 수 있습니다.

## 재고 재입고 알림

재고 소진 시 action을 **"알림 받기" 버튼 표시**로 설정하면, 고객은 상품 페이지에서 이메일 주소를 입력하여 상품이 재입고될 때 이메일을 받을 수 있습니다.

### 알림 요청 보기

모든 고객 알림 요청을 보려면 **카탈로그 > 재고 알림**으로 이동하세요. 각 기록에는 다음 정보가 표시됩니다.
- 고객 이메일 주소
- 상품 및 변형 (해당하는 경우)
- 고객이 지역 선호도를 선택한 경우 선호 창고
- 요청이 생성된 시점
- 알림이 전송된 시점 (아직 전송되지 않은 경우 공란)

### 알림이 전송될 때

상품의 재고 수준이 0보다 높아지면 Spwig는 자동으로 재고 재입고 이메일을 보냅니다. **알림 시간** 필드는 이메일이 전송된 시점을 기록합니다.

고객은 하나의 알림 이메일만 받습니다. 알림을 받은 후에 상품이 다시 재고 소진 상태가 되면 다시 등록해야 합니다.

### 알림 요청 필터링

관리자 필터를 사용하여 다음을 찾을 수 있습니다.
- 특정 상품에 대한 요청
- 이미 알림이 전송된 요청 (연락을 받은 사람 확인용)
- 여전히 보류 중인 요청 (재고 재입고를 기다리는 고객)

## 상품 수준의 재정의

사이트 전체 재고 표시 설정은 개별 상품이나 카테고리별로 재정의할 수 있습니다. 상품 편집 폼에서 **재고** 섹션을 찾아 글로벌 기본값과 다른 제품별 **재고 소진 시 행동**을 설정할 수 있습니다.

이것은 대부분의 제품을 백오더를 허용하지만 일부 제품만 "알림 신청"으로 설정하고 싶을 때 유용합니다. 또는 재고가 소진되었을 때 특정 제품을 숨기고 싶을 때도 사용합니다.

## 팁

- 일반적으로 사용하는 재주문 지점인 **저품고 기준**을 설정하여 재고가 완전히 소진되기 전에 고객이 제한된 재고를 알 수 있도록 경고합니다.
- 재고가 소진된 제품을 숨기는 대신 **"알림 신청" 버튼 표시** 옵션을 사용하세요. 고객이 신청한 것은 실제 수요를 나타내며, 재입고 주문을 정당화할 수 있습니다.
- **정확한 수량 표시**를 제한적으로 사용하세요. 대부분의 상점에서는 "3개만 남았습니다!"와 같은 메시지가 정확한 수량을 표시하는 것보다 더 긴급함을 유도하므로, 전체 재고 상황을 드러내지 않고도 효과적입니다.
- 새로운 주문을 할 때 재고 알림 목록을 확인하세요. 이는 해당 제품에 대해 얼마나 많은 수요가 있는지를 보여주는 예약 알림 요청 수를 알려줍니다.
- 백오더를 사용하는 경우, **백오더 메시지**를 업데이트하여 정확한 기대를 설정하세요 (예: "2~3주 내 배송 — 지금 주문하여 자리 확보!").
- 재고 소진 알림을 이메일 마케팅과 결합하세요. 인기 있는 제품이 재입고되면, 자동 알림 이메일이 아닌 신청한 모든 사람에게 캠페인을 보냅니다.
