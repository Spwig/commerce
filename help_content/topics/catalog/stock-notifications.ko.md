---
title: 재고 알림
---

재고 알림은 재고가 없는 제품이 다시 재고로 들어오면 고객에게 이메일을 받을 수 있도록 가입할 수 있는 기능입니다. 재고 표시 설정은 제품 페이지에서 고객이 보는 내용을 제어합니다. 예를 들어, 재고 상태 라벨, 재고 부족 경고, 제품이 매진되었을 때의 동작 등이 포함됩니다.

## 재고 표시 설정

재고 표시 설정은 카테고리 또는 제품 수준에서 재정의되지 않는 한 모든 제품에 적용되는 스토어 전체 기본값입니다.

**카탈로그 > 재고 표시 설정**으로 이동하여 이 옵션을 구성하십시오. 스토어에는 하나의 설정 레코드가 있습니다 — 편집하려면 클릭하십시오.

### 재고 상태 표시

| 설정 | 설명 |
|---------|-------------|
| **재고 상태 표시** | 제품 페이지에 "재고 있음" 또는 "재고 없음" 라벨 표시 |
| **재고 부족 경고 표시** | 재고가 부족할 때 "남은 수량 X개" 메시지 표시 |
| **재고 부족 임계값** | 재고 부족 경고가 표시되는 수량 이하의 값 (기본값: 5) |
| **정확한 수량 표시** | 일반적인 경고 대신 정확한 남은 수량 표시 (예: "남은 수량 3개!") |

### 재고 없음 동작

**재고 없음 동작** 설정은 제품이 재고 없이 사용할 수 없을 때 고객이 보는 내용을 결정합니다:

| 동작 | 고객이 보는 내용 |
|--------|-------------------|
| **목록에서 숨김** | 제품이 카테고리 페이지 및 검색 결과에서 제거됨 |
| **사용 불가로 표시** | 제품은 표시되지만 장바구니에 추가할 수 없음 |
| **"알림 받기" 버튼 표시** | 고객이 재고가 돌아오면 알림을 받을 수 있도록 이메일을 등록할 수 있음 |
| **예약 주문 허용** | 재고가 0이어도 고객이 제품을 구매할 수 있음 |

**재고 없음 메시지**를 설정하여 제품이 사용 불가능할 때 표시되는 텍스트를 사용자 지정하십시오 (기본값: `재고 없음`).

**예약 주문 메시지**를 설정하여 예약 주문이 가능한 제품에 대해 표시되는 텍스트를 사용자 지정하십시오 (기본값: `예약 주문 가능`).

### 배송 및 배달 표시

| Setting | Description |
|---------|-------------|
| **"Ships From" 위치 표시** | 상품 페이지에 창고 이름 표시 |
| **추정 배송일 표시** | 창고 위치 기반으로 계산된 추정 배송일 표시 |

### 재고 소진 상품 주문 허용 (사이트 전체)

기본적으로 재고가 없는 제품을 구매할 수 있도록 하려면 **재고 소진 상품 주문 허용**을 선택하십시오. 개별 제품 및 카테고리는 이 설정을 재정의할 수 있습니다.

## 재고 재입고 알림

재고 소진 시 action을 **"알림 요청" 버튼 표시**로 설정하면, 고객은 상품 페이지에서 이메일 주소를 입력하여 상품이 재입고될 때 이메일을 받을 수 있습니다.

### 알림 요청 보기

모든 고객의 알림 요청을 보려면 **카탈로그 > 재고 알림**으로 이동하십시오. 각 기록에는 다음 정보가 표시됩니다.
- 고객 이메일 주소
- 상품 및 변형 (해당하는 경우)
- 고객이 지역 선호도를 선택한 경우 선호 창고
- 요청이 생성된 시점
- 알림이 전송된 시점 (아직 전송되지 않은 경우 공란)

### 알림 전송 시점

상품의 재고 수준이 0보다 높아지면 Spwig는 자동으로 재고 재입고 이메일을 보냅니다. **알림 시간** 필드는 이메일이 전송된 시점을 기록합니다.

고객은 한 번의 알림 이메일만 받습니다. 한 번 알림을 받은 후에 상품이 다시 재고 소진 상태가 되면 다시 등록해야 합니다.

단일 텍스트 알림 대신, 예를 들어 **

관리자 필터를 사용하여 다음을 검색하세요:
- 특정 제품의 요청
- 이미 알림이 전송된 요청(연락받은 사람을 확인하기 위해)
- 아직 대기 중인 요청(재입고를 기다리는 고객)

## 제품별 오버라이드

사이트 전체 재고 표시 설정은 제품 또는 카테고리별로 오버라이드할 수 있습니다. 제품 편집 양식에서 **재고** 섹션을 찾아, 전역 기본값과 다른 제품별 **품절 시 동작**을 설정할 수 있습니다.

대부분의 제품은 예약 주문을 허용하되 일부 제품만 "알림 받기"로 설정하거나, 특정 제품이 품절 시 숨겨져야 하는 경우에 유용합니다.

## 팁

- **저재고 임계값**을 일반적으로 사용하는 재주문 지점으로 설정하여, 재고가 완전히 소진되기 전에 고객에게 제한된 재고를 경고하세요.
- 품절된 제품을 숨기는 대신 **"알림 받기" 버튼 표시** 옵션을 사용하세요. 가입한 고객은 재입고 주문을 정당화할 수 있는 실제 수요를 나타냅니다.
- **정확한 수량 표시**를 절제하여 사용하세요. 대부분의 스토어에서는 정확한 숫자를 표시하는 것보다 "남은 수량 3개!"와 같이 표시하는 것이 전체 재고 현황을 노출하지 않으면서도 긴박감을 조성하므로 더 효과적입니다.
- 새로운 주문을 하기 전에 재고 알림 목록을 확인하세요. 대기 중인 알림 요청 수는 해당 제품에 대한 수요가 얼마나 있는지 알려줍니다.
- 예약 주문을 사용하는 경우, **예약 주문 메시지**를 업데이트하여 정확한 기대치를 설정하세요(예: "2~3주 내 발송 — 지금 주문하여 자리를 예약하세요").
- 품절 알림을 이메일 마케팅과 결합하세요: 인기 제품을 재입고할 때, 자동 알림 이메일뿐만 아니라 가입한 모든 사람에게 캠페인을 보내세요.
