---
title: 庫存與倉庫
---

倉庫系統讓您可以跨多個地點管理庫存，設定履行優先順序，並即時追蹤庫存水準。導覽至管理員側邊欄中的 **Products > Warehouses** 來管理您的倉庫地點。

![倉庫清單](/static/core/admin/img/help/inventory-warehouses/warehouse-list.webp)

## 倉庫

### 倉庫清單

倉庫頁面以卡片形式顯示您所有的庫存地點，包含：

- **名稱和代碼** — 倉庫識別碼（例如："主倉庫"，代碼 "MAIN-WH"）
- **銷售區域** — 地理區域分配
- **狀態徽章** — 活性/非活性，零售地點
- **統計** — 存貨商品數量，履行優先順序，庫存緩衝百分比
- **地點** — 城市與國家
- **最後更新** — 當庫存水準最後被修改

### 創建一個倉庫

1.

點擊 **+ 新增倉庫**
2.

填寫 **基本資訊**：
   - **名稱** — 描述性標籤（例如："美國東部倉庫"）
   - **代碼** — 短暫唯一識別碼（例如："US-EAST"） — 必須在所有倉庫中唯一
   - **銷售區域** — 分配至地理區域以進行履行路由
   - **啟用** — 啟用以包含在履行中
3.

在 **地址** 部分填寫完整的倉庫地址
4.

設定 **履行設定**：
   - **履行優先順序** — 數字越高 = 越高的履行優先順序
   - **庫存緩衝百分比** — 保留作為安全緩衝的庫存百分比（0–100）
   - **運輸地點** — 如果此倉庫支援客戶自取，可選擇連結至自取地點
5.

設定 **客戶顯示**（可選）：
   - **顯示名稱** — 客戶面對的標籤（例如："從澳洲發貨"）。

   留空以使用倉庫名稱。
   - **在前端顯示** — 在商品頁面上向客戶顯示此倉庫的來源
6.

保留所有markdown格式、圖片路徑、程式碼區塊和技術術語。

設定 **POS / 零售店**（可選）：
   - **零售地點** — 選擇此倉庫是否也作為實體店鋪，具備POS終端機
   - **POS顯示名稱** — 在POS介面中顯示的短名稱
   - **商店群組** — 分配至POS商店群組以繼承設定
7.

若需要，請新增 **聯繫資訊**（姓名、電子郵件、電話）
8.

按一下 **儲存**

### 配送優先順序

當訂單到來時，系統會根據以下條件選擇最佳倉庫：

1. **優先順序值** — 優先順序較高的倉庫會被優先選擇
2. **庫存可用性** — 必須有足夠的庫存
3. **地區匹配** — 客戶所屬地區的倉庫會被優先選擇

例如，如果您有一個美國倉庫（優先順序100）和一個歐洲倉庫（優先順序60），美國訂單將首先從美國倉庫配送。

### 庫存緩衝

庫存緩衝會保留一部分庫存，不會在網路上銷售。這對以下情況很有用：
- 需要展示庫存的實體零售店
- 防止過度銷售的安全庫存
- 為批發訂單保留庫存

10%的緩衝率，100個單位的庫存表示只有90個單位可用於在線訂單。

## 庫存項目

庫存項目代表特定倉庫中特定產品的實際庫存。

### 查看庫存水準

1. 點擊任何倉庫卡片上的 **庫存圖示** 以查看其庫存項目
2. 或導航至產品的 **庫存** 標籤以查看所有倉庫的庫存

每個庫存項目顯示：
- **產品名稱** 和變體（如果適用）
- **現有庫存** — 總體物理庫存
- **已分配** — 保留用於待處理訂單的數量
- **可用** — 現有庫存減去已分配（可銷售的數量）

### 新增庫存

1.

導航至 **產品 > 庫存項目** 並點擊 **+ 新增庫存項目**，或者
2.

開啟產品的編輯表單並使用底部的 **庫存項目** 內嵌部分
3.

選擇 **產品** 和 **倉庫**（對於變體產品，可選擇性地選擇 **變體**）
4.

輸入 **現有庫存** 數量
5.

保留所有markdown格式、圖片路徑、程式碼區塊和技術術語。

設定 **庫存低於門檻值** — 當每個商品的庫存低於此門檻值時會觸發庫存不足警告
6。

儲存

### 庫存變動

每次庫存變動都會被追蹤為 **庫存變動** ：

| 變動類型 | 描述 |
|--------------|-------------|
| **入貨** | 從供應商處收到的新庫存 |
| **銷售** | 訂單完成後扣除的庫存 |
| **退貨** | 客戶退回的庫存 |
| **調整** | 手動修正（盤點差異） |
| **轉移** | 在倉庫之間移動 |
| **預留** | 暫時保留給活躍的購物車 |
| **損耗** | 視為損壞或遺失而核銷 |
| **重新盤點** | 修正以符合實際庫存數量 |

庫存變動提供了完整的庫存變動審計追蹤。除了 **調整庫存等級** 功能外，Spwig 還在 **庫存項目** 列表中提供批量操作，可一次轉移、核銷和重新盤點多個項目庫存 — 請參閱 [批量庫存操作](/help/stock-bulk-actions)。

## 產品上的庫存追蹤

### 啟用庫存追蹤

在產品的 **庫存** 畫面：

1. 切換 **追蹤庫存** 以啟用此產品的庫存管理
2. 設定 **庫存低於門檻值** — 當任何倉庫的庫存低於此門檻值時會觸發儀錶板警告
3. 如果您希望接受庫存不足時的訂單，請設定 **允許預購** 
4. 可選地設定 **庫存不足時的動作** 以覆蓋此特定產品的網站範圍或分類行為

啟用追蹤後，請使用產品表單底部的 **庫存項目** 內嵌部分管理實際庫存數量，或透過 **產品 > 庫存項目** 進行管理。

### 多倉庫庫存

當啟用庫存追蹤時，庫存標籤會顯示所有倉庫的庫存水準摘要表格：

- 所有地點的總庫存
- 每個倉庫的明細
- 預留和分配後的可用數量

## 庫存低於門檻值警告

保留所有 markdown 格式、圖片路徑、程式碼區塊和技術術語。

系統會自動監控庫存水準並在以下情況通知您：
- 產品庫存低於 **最低庫存門檻**
- 產品庫存達到 **零庫存**

低庫存警告會出現在：
- **商店首頁** 的「需要處理的動作」部分
- 產品清單中以視覺指示器顯示

## 小技巧

- 從單一倉庫開始，隨著業務擴張再增加更多倉庫。
- 根據運送到各個地區的運送速度和成本設置履行優先級。
- 為實體店鋪設置庫存緩衝，以確保庫存充足。
- 定期審查庫存流動，以識別庫存損耗或差異。
- 根據您的重新訂購提前期設置低庫存門檻 —— 如果補貨需要 2 週間，請將門檼設置為涵蓋 2 週的銷售。
- 在上線前啟用庫存追蹤，以避免過度銷售。
