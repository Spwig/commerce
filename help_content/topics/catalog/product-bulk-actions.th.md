รายการ **สินค้า** ช่วยให้คุณดำเนินการกับสินค้าหลายรายการพร้อมกันได้ โดยไม่ต้องเปิดทีละตัว คุณสามารถเผยแพร่หรือยกเลิกการเผยแพร่สินค้า ทำให้สินค้าเป็นที่เด่น หรือไม่เด่น คุณสามารถส่งออกข้อมูลไปยัง CSV ตรวจสอบว่าสินค้าใดพร้อมสำหรับการส่งออกสินค้าไปต่างประเทศ หรือลบสินค้าได้ทั้งหมดในขั้นตอนเดียว จาก **ตัวเลือกการดำเนินการแบบหลายรายการ** ในแถบเครื่องมือเหนือตารางสินค้า

ไปที่ **สินค้า > สินค้าทั้งหมด** เพื่อใช้การดำเนินการเหล่านี้

![แถบเครื่องมือของรายการสินค้าพร้อมการเลือกสินค้า 3 รายการและตัวเลือกการดำเนินการแบบหลายรายการแสดงทุกอย่าง รวมถึง Export Customs Data (CSV) และ Check International Shipping Readiness](/static/core/admin/img/help/product-bulk-actions/bulk-actions-dropdown.webp)

## การดำเนินการแบบหลายรายการ

1. ใช้แผงตัวกรองหรือช่อง **ค้นหา** เพื่อลดจำนวนสินค้าที่คุณต้องการ ถ้าจำเป็น
2. ตรวจสอบช่องในมุมบนซ้ายของแต่ละบัตรสินค้าที่คุณต้องการเพิ่ม แถบ **การดำเนินการแบบหลายรายการ** จะแสดงจำนวนสินค้าที่เลือกอย่างต่อเนื่อง
3. เลือกการดำเนินการจาก **ตัวเลือกการดำเนินการแบบหลายรายการ**
4. คลิก **ใช้**

การดำเนินการที่เปลี่ยนแปลงหรือส่งออกข้อมูลจะดำเนินการทันที; **ลบสิ่งที่เลือก** จะแสดงการยืนยันก่อน เพราะนี่คือการดำเนินการเพียงอย่างเดียวที่ไม่สามารถย้อนกลับได้จากตารางเอง

## การดำเนินการที่มีอยู่

รักษารูปแบบมาโครเดิม ชื่อไฟล์รูปภาพ บล็อกโค้ด และคำศัพท์ทางเทคนิคทั้งหมด

| การกระทำ | สิ่งที่มันทำ |
|--------|---------------|
| **ตั้งเป็นเผยแพร่** | กำหนดสถานะของสินค้าที่เลือกให้เป็น "เผยแพร่" เพื่อให้เห็นได้บนหน้าร้านค้า |
| **ตั้งเป็นร่าง** | กำหนดสถานะของสินค้าที่เลือกให้เป็น "ร่าง" ซึ่งจะทำให้สินค้าถูกซ่อนไว้จากหน้าร้านค้าขณะที่คุณยังคงแก้ไข |
| **ตั้งเป็นสินค้าเด่น** | เปิดใช้งาน **เป็นสินค้าเด่น** บนสินค้าที่เลือก |
| **ลบการเป็นสินค้าเด่น** | ปิดการใช้งาน **เป็นสินค้าเด่น** บนสินค้าที่เลือก |
| **ส่งออกเป็น CSV** | ดาวน์โหลดไฟล์ CSV ของ ID, ชื่อ, SKU, สถานะ, คุณสมบัติสินค้าเด่น และราคาของสินค้าที่เลือก |
| **ส่งออกข้อมูลศุลกากร (CSV)** | ดาวน์โหลดไฟล์ CSV ของข้อมูลศุลกากรสำหรับสินค้าที่เลือก ดูรายละเอียดเพิ่มเติมด้านล่าง |
| **ตรวจสอบความพร้อมสำหรับการจัดส่งระหว่างประเทศ** | แสดงภาพรวมของสินค้าที่เลือกซึ่งมีข้อมูลที่จำเป็นสำหรับการจัดส่งระหว่างประเทศ ดูรายละเอียดเพิ่มเติมด้านล่าง |
| **ลบสินค้าที่เลือก** | ย้ายสินค้าที่เลือกไปยังถังขยะ หลังจากได้รับการยืนยัน |

## ส่งออกข้อมูลศุลกากร (CSV)

ใช้เมื่อคุณต้องการแผ่นคำชี้แจงศุลกากรเพื่อส่งให้ผู้ให้บริการขนส่ง ผู้ให้บริการไปรษณีย์ หรือตัวแทนศุลกากร เช่น ก่อนที่จะจัดส่งสินค้าระหว่างประเทศจำนวนมาก หรือเมื่อตั้งค่าผู้ให้บริการใหม่ที่ต้องการข้อมูล HS code และข้อมูลแหล่งกำเนิดสินค้าล่วงหน้า

เลือกสินค้า แล้วเลือก **ส่งออกข้อมูลศุลกากร (CSV)** จากเมนูแบบเลื่อนลง แล้วคลิก **ดำเนินการ** Spwig จะดาวน์โหลดไฟล์ชื่อ `product_customs_data.csv` ซึ่งมีหนึ่งแถวต่อสินค้า และมีคอลัมน์ดังนี้:

| คอลัมน์ | แหล่งที่มา |
|--------|--------|
| **SKU** | SKU ของสินค้า |
| **ชื่อ** | ชื่อสินค้า |
| **HS Code** | รหัสการจัดประเภทระบบ HS |
| **ประเทศที่ผลิต** | ที่มาของสินค้า |
| **ราคาหน่วยสำหรับศุลกากร** | ค่าที่ระบุต่อหน่วยสำหรับศุลกากร |
| **ใบอนุญาตส่งออก** | หมายเลขใบอนุญาตส่งออก หากสินค้าต้องการ |
| **วันหมดอายุของใบอนุญาต** | วันหมดอายุของใบอนุญาตส่งออก หากมี |
| **ความพร้อมสำหรับการจัดส่งระหว่างประเทศ** | "Yes" หรือ "No" — แสดงว่าสินค้ามีข้อมูลขั้นพื้นฐานที่จำเป็นสำหรับการจัดส่งระหว่างประเทศ (ดูรายละเอียดเพิ่มเติมด้านล่าง) |

ฟิลด์เหล่านี้มาจากส่วน **การจัดส่งระหว่างประเทศ / ศุลกากร** ของฟอร์มสินค้า

หากสินค้าใดขาดข้อมูล ฟิลด์นั้นจะว่างเปล่าในการส่งออก — กรุณาเติมข้อมูลที่ขาดหายไปในสินค้านั้นก่อนที่คุณจะนำไฟล์นี้ไปใช้สำหรับการจัดส่งจริง

## ตรวจสอบความพร้อมสำหรับการจัดส่งระหว่างประเทศ

ใช้ฟีเจอร์นี้เพื่อตรวจสอบสินค้าเป็นชุดก่อนที่คุณจะเริ่มจัดส่งระหว่างประเทศ โดยไม่ต้องเปิดดูสินค้าแต่ละรายการหรือรอการส่งออก CSV ทั้งหมด

เลือกสินค้า เลือก **ตรวจสอบความพร้อมสำหรับการจัดส่งระหว่างประเทศ** แล้วคลิก **ใช้**. Spwig จะตรวจสอบสินค้าแต่ละรายการที่เลือกกับฟิลด์บังคับสามรายการ — **รหัส HS**, **ประเทศต้นกำเนิด**, และ **ราคาหน่วยศุลกากร** — และแสดงการแจ้งเตือนสรุปผลลัพธ์:

- หากสินค้าที่เลือกทั้งหมดมีฟิลด์ทั้งสามรายการครบถ้วน คุณจะเห็นการยืนยันว่าสินค้าทั้งหมดพร้อมแล้ว
- หากมีสินค้าบางรายการขาดข้อมูล การแจ้งเตือนจะรายงานว่ามีกี่รายการที่พร้อมและกี่รายการที่ไม่พร้อม พร้อมระบุชื่อสินค้าแต่ละรายการที่ไม่พร้อมและฟิลด์ที่ขาด (เช่น "แก้วเซรามิกสีน้ำเงิน (ขาด: hs_code, country_of_origin)"). หากมีสินค้ามากกว่า 10 รายการที่ขาดข้อมูล การแจ้งเตือนจะแสดงรายการ 10 รายการแรกและบอกคุณว่ามีอีกกี่รายการ

การดำเนินการนี้เป็นการอ่านข้อมูลเท่านั้น — ไม่มีการเปลี่ยนแปลงใดๆ ในสินค้า ดังนั้นจึงปลอดภัยที่จะดำเนินการบ่อยครั้งเท่าที่คุณต้องการขณะกำลังเติมข้อมูลศุลกากรในแคตตาล็อกของคุณ

**หมายเลขใบอนุญาตส่งออก** และ **วันหมดอายุใบอนุญาตส่งออก** ไม่เป็นส่วนหนึ่งของการตรวจสอบความพร้อม ฟิลด์เหล่านี้ใช้เฉพาะกับสินค้าควบคุมหรือสินค้าจำกัด ดังนั้นสินค้าสามารถ "พร้อม" สำหรับการส่งออกระหว่างประเทศได้โดยไม่ต้องมีฟิลด์เหล่านี้

## เคล็ดลับ

- ทำงาน **ตรวจสอบความพร้อมในการส่งสินค้าระหว่างประเทศ** สำหรับรายการสินค้าทั้งหมด (หรือแต่ละประเภททีละประเภท) ก่อนที่จะมีคำสั่งซื้อระหว่างประเทศครั้งแรก — มันจะรวดเร็วกว่าการที่คุณจะพบว่ามีรหัส HS ที่ขาดหายไปเมื่อสินค้าอยู่ที่ชายแดนแล้ว
- จัดเก็บ **ข้อมูลศุลกากรสำหรับการส่งออก (CSV)** เพื่อส่งให้ตัวแทนจัดส่งและผู้ให้บริการขนส่ง และ **ตรวจสอบความพร้อมในการส่งสินค้าระหว่างประเทศ** สำหรับรายการตรวจสอบภายในของคุณเอง — CSV คือบันทึก และการตรวจสอบความพร้อมคือรายการงานที่ต้องทำ
- ป้อน **รหัส HS**, **ประเทศที่ผลิต**, และ **ราคาหน่วยศุลกากร** บนฟอร์มสินค้า (ภายใต้ **การส่งสินค้าระหว่างประเทศ / ศุลกากร**) เมื่อคุณเพิ่มสินค้าใหม่ ดังนั้นคุณจึงไม่ต้องทำทีละอันในภายหลัง
- ตารางสินค้าจะโหลดสินค้าเพิ่มเติมโดยอัตโนมัติเมื่อคุณเลื่อนลง (การเลื่อนแบบไม่สิ้นสุด) และการเลือกช่องทำเครื่องหมายของคุณจะถูกเก็บไว้เมื่อสินค้าเพิ่มเติมโหลดเข้ามา — ดังนั้นคุณจึงสามารถเลื่อนเพื่อสร้างการเลือกจำนวนมากก่อนที่จะดำเนินการ
- การเปลี่ยนตัวกรองหรือโหลดซ้ำหน้าจะทำให้การเลือกของคุณถูกลบออก ดังนั้นให้ดำเนินการก่อนที่คุณจะปรับตัวกรอง
- **ตั้งเป็นร่าง** เป็นวิธีที่รวดเร็วในการนำสินค้าหลายตัวออกจากร้านค้าในคราวเดียว — เช่น ก่อนที่จะนับสต็อกใหม่ — โดยไม่ต้องเปลี่ยนสิ่งอื่นใดเกี่ยวกับสินค้า
