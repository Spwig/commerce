รายการ **สินค้า** ช่วยให้คุณดำเนินการกับสินค้าหลายรายการพร้อมกันได้ โดยไม่ต้องเปิดทีละตัว คุณสามารถเผยแพร่หรือยกเลิกการเผยแพร่สินค้า ทำให้สินค้าเป็นที่เด่น หรือไม่เด่น คุณสามารถส่งออกข้อมูลไปยัง CSV ตรวจสอบว่าสินค้าใดพร้อมสำหรับการส่งออกสินค้าไปต่างประเทศ หรือลบสินค้า — ทั้งหมดนี้ในขั้นตอนเดียว ได้จาก **ช่องเลือกการดำเนินการแบบหลายรายการ** ในแถบเครื่องมือเหนือตารางสินค้า

ไปที่ **สินค้า > สินค้าทั้งหมด** เพื่อใช้การดำเนินการเหล่านี้

![แถบเครื่องมือรายการสินค้าพร้อมการ์ดสินค้า 3 ชิ้นที่ถูกเลือก และช่องเลือกการดำเนินการแบบหลายรายการแสดงทุกตัวเลือก รวมถึง Export Customs Data (CSV) และ Check International Shipping Readiness](/static/core/admin/img/help/product-bulk-actions/bulk-actions-dropdown.webp)

## การดำเนินการแบบหลายรายการ

1. ใช้แผงตัวกรองหรือช่อง **ค้นหา** เพื่อลดจำนวนสินค้าที่คุณต้องการ ถ้าจำเป็น
2. ตรวจสอบช่องในมุมบนซ้ายของแต่ละการ์ดสินค้าที่คุณต้องการเพิ่ม — **แถบการดำเนินการแบบหลายรายการ** จะแสดงจำนวนสินค้าที่เลือกอย่างต่อเนื่อง
3. เลือกการดำเนินการจาก **ช่องเลือกการดำเนินการแบบหลายรายการ**
4. คลิก **ใช้**

การดำเนินการที่เปลี่ยนแปลงหรือส่งออกข้อมูลจะดำเนินการทันที; **Delete Selected** จะแสดงการยืนยันก่อน เพราะนี่คือการดำเนินการเพียงอย่างเดียวที่ไม่สามารถย้อนกลับได้จากรายการโดยตรง

## การดำเนินการที่มีอยู่

รักษารูปแบบมาโครเดิม ตำแหน่งรูปภาพ บล็อกโค้ด และคำศัพท์ทางเทคนิคทั้งหมด

| การกระทำ | สิ่งที่มันทำ |
|--------|---------------|
| **ตั้งเป็นเผยแพร่** | กำหนดสถานะของสินค้าที่เลือกให้เป็น "เผยแพร่" เพื่อให้เห็นได้บนหน้าร้านค้า |
| **ตั้งเป็นร่าง** | กำหนดสถานะของสินค้าที่เลือกให้เป็น "ร่าง" ซึ่งจะทำให้สินค้าถูกซ่อนไว้จากหน้าร้านค้าขณะที่คุณยังคงแก้ไข |
| **ตั้งเป็นสินค้าเด่น** | เปิดใช้งาน **เป็นสินค้าเด่น** บนสินค้าที่เลือก |
| **ยกเลิกการเป็นสินค้าเด่น** | ปิดการใช้งาน **เป็นสินค้าเด่น** บนสินค้าที่เลือก |
| **ส่งออกเป็น CSV** | ดาวน์โหลดไฟล์ CSV ของ ID, ชื่อ, SKU, สถานะ, ค่าฟีเจอร์, และราคาของสินค้าที่เลือก |
| **ส่งออกข้อมูลศุลกากร (CSV)** | ดาวน์โหลดไฟล์ CSV ของข้อมูลศุลกากรสำหรับสินค้าที่เลือก ดูรายละเอียดด้านล่าง |
| **ตรวจสอบความพร้อมสำหรับการจัดส่งระหว่างประเทศ** | แสดงภาพรวมของสินค้าที่เลือกที่มีข้อมูลศุลกากรที่จำเป็นสำหรับการจัดส่งระหว่างประเทศ ดูรายละเอียดด้านล่าง |
| **ลบสินค้าที่เลือก** | ย้ายสินค้าที่เลือกไปยังถังขยะ หลังจากยืนยันแล้ว |

## ส่งออกข้อมูลศุลกากร (CSV)

ใช้เมื่อคุณต้องการแผ่นคำชี้แจงศุลกากรเพื่อส่งให้ผู้ให้บริการขนส่ง ผู้ให้บริการไปรษณีย์ หรือตัวแทนศุลกากร เช่น ก่อนที่จะจัดส่งสินค้าระหว่างประเทศจำนวนมาก หรือเมื่อตั้งค่าผู้ให้บริการใหม่ที่ต้องการข้อมูล HS code และข้อมูลแหล่งกำเนิดสินค้าล่วงหน้า

เลือกสินค้า แล้วเลือก **ส่งออกข้อมูลศุลกากร (CSV)** จากเมนูแบบเลื่อนลง แล้วคลิก **ดำเนินการ** Spwig ดาวน์โหลดไฟล์ชื่อ `product_customs_data.csv` ซึ่งมีหนึ่งแถวต่อสินค้า และมีคอลัมน์ดังนี้:

| คอลัมน์ | แหล่งที่มา |
|--------|--------|
| **SKU** | ค่า SKU ของสินค้า |
| **ชื่อ** | ชื่อสินค้า |
| **HS Code** | รหัสการจัดประเภทระบบ HS |
| **ประเทศแหล่งกำเนิด** | ที่ซึ่งสินค้านั้นผลิตขึ้น |
| **ราคาหน่วยสำหรับศุลกากร** | ค่าที่ระบุต่อหน่วยสำหรับศุลกากร |
| **ใบอนุญาตส่งออก** | หมายเลขใบอนุญาตส่งออก หากสินค้านั้นต้องการ |
| **วันหมดอายุใบอนุญาต** | วันหมดอายุของใบอนุญาตส่งออก หากมี |
| **ความพร้อมสำหรับการจัดส่งระหว่างประเทศ** | "Yes" หรือ "No" — ว่าสินค้ามีข้อมูลขั้นพื้นฐานที่จำเป็นสำหรับการจัดส่งระหว่างประเทศหรือไม่ (ดูรายละเอียดด้านล่าง) |

ช่องส่วนนี้มาจากส่วน **การจัดส่งระหว่างประเทศ / ข้อมูลศุลกากร** ของฟอร์มสินค้า

หากสินค้าใดขาดช่องใดช่องหนึ่ง ช่องนั้นจะว่างในไฟล์ที่ส่งออก ให้เติมข้อมูลที่ขาดหายไปในสินค้าก่อนที่จะพึ่งพาไฟล์นี้สำหรับการจัดส่งจริง

## ตรวจสอบความพร้อมสำหรับการจัดส่งระหว่างประเทศ

ใช้สิ่งนี้เพื่อตรวจสอบสินค้าเป็นจำนวนมากก่อนที่จะเริ่มจัดส่งไปต่างประเทศ โดยไม่ต้องเปิดสินค้าแต่ละตัวหรือรอการส่งออก CSV ทั้งหมด

เลือกสินค้า แล้วเลือก **ตรวจสอบความพร้อมสำหรับการจัดส่งระหว่างประเทศ** และคลิก **ดำเนินการ** Spwig จะตรวจสอบแต่ละสินค้าที่เลือกตามช่องที่จำเป็น 3 ช่อง ได้แก่ **รหัส HS**, **ประเทศที่ผลิต**, และ **ราคาหน่วยศุลกากร** และแสดงการแจ้งเตือนที่สรุปผลลัพธ์:

- หากสินค้าทั้งหมดที่เลือกมีข้อมูลทั้งสามช่องครบ คุณจะได้รับการยืนยันว่าทั้งหมดพร้อม
- หากบางตัวขาดข้อมูล การแจ้งเตือนจะรายงานจำนวนที่พร้อมและจำนวนที่ไม่พร้อม และแสดงรายการสินค้าที่ไม่พร้อมแต่ละตัวพร้อมกับช่องที่ขาดหายไป (เช่น "ถ้วยเซรามิกสีฟ้า (ขาด: hs_code, country_of_origin)")
ถ้ามีสินค้ามากกว่า 10 ตัวที่ขาดข้อมูล การแจ้งเตือนจะแสดงรายการ 10 ตัวแรกและแจ้งให้ทราบว่ามีอีกเท่าไร

การดำเนินการนี้จะอ่านข้อมูลเท่านั้น — ไม่ได้เปลี่ยนแปลงข้อมูลในสินค้า ดังนั้นจึงปลอดภัยที่จะดำเนินการซ้ำๆ ได้บ่อยเท่าใดก็ได้ขณะที่คุณกำลังเติมข้อมูลศุลกากรในไลบรารีของคุณ

**หมายเลขใบอนุญาตส่งออก** และ **วันหมดอายุของใบอนุญาตส่งออก** ไม่ได้เป็นส่วนหนึ่งของการตรวจสอบความพร้อม พวกเขาใช้ได้กับสินค้าที่ถูกควบคุมหรือจำกัดเท่านั้น ดังนั้นสินค้าสามารถ "พร้อม" สำหรับการจัดส่งระหว่างประเทศโดยไม่มีพวกเขาได้

## เคล็ดลับ

รักษารูปแบบ Markdown ทั้งหมด ทั้งเส้นทางรูปภาพ บล็อกโค้ด และคำศัพท์ทางเทคนิค

- ทำงาน **ตรวจสอบความพร้อมในการจัดส่งสินค้าระหว่างประเทศ** สำหรับรายการสินค้าทั้งหมด (หรือแต่ละหมวดหมู่ทีละครั้ง) ก่อนที่จะมีคำสั่งซื้อระหว่างประเทศครั้งแรก — มันจะรวดเร็วกว่าการที่คุณพบว่ามีรหัส HS ที่ขาดหายไปเมื่อสินค้าอยู่ที่ชายแดนแล้ว
- จัดเก็บ **ข้อมูลศุลกากรสำหรับการส่งออก (CSV)** เพื่อส่งให้ตัวแทนจัดส่งและผู้ให้บริการขนส่ง และ **ตรวจสอบความพร้อมในการจัดส่งสินค้าระหว่างประเทศ** สำหรับรายการตรวจสอบภายในของคุณเอง — CSV นั้นคือบันทึก และการตรวจสอบความพร้อมนั้นคือรายการงานที่ต้องทำ
- ป้อน **รหัส HS**, **ประเทศที่มาของสินค้า**, และ **ราคาหน่วยศุลกากร** บนฟอร์มสินค้า (ภายใต้ **การจัดส่งระหว่างประเทศ / ข้อมูลศุลกากร**) เมื่อคุณเพิ่มสินค้าใหม่ ดังนั้นคุณจึงไม่ต้องทำในภายหลังเป็นจำนวนมาก
- ตารางสินค้าจะโหลดสินค้าเพิ่มเติมโดยอัตโนมัติเมื่อคุณเลื่อนลง (การเลื่อนแบบไม่สิ้นสุด) และการเลือกช่องทำเครื่องหมายของคุณจะถูกเก็บไว้เมื่อสินค้าเพิ่มเติมโหลดเข้ามา — ดังนั้นคุณจึงสามารถเลื่อนเพื่อสร้างการเลือกที่หลากหลายก่อนที่จะดำเนินการใด ๆ

การเปลี่ยนตัวกรองหรือโหลดซ้ำหน้าจะทำให้การเลือกของคุณถูกลบออก ดังนั้นจงดำเนินการก่อนที่จะปรับตัวกรอง
- **ตั้งเป็นร่าง** เป็นวิธีที่รวดเร็วในการนำสินค้าหลายตัวออกจากร้านค้าออนไลน์ในคราวเดียว — เช่น ก่อนที่จะนับสต็อกใหม่ — โดยไม่ต้องเปลี่ยนสิ่งอื่นใดเกี่ยวกับสินค้า
