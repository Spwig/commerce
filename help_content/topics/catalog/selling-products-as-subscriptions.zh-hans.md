## 哪些产品类型可以作为订阅销售

订阅仅适用于以下产品类型：

| 符合条件 | 不符合条件 |
|----------|---------------|
| 简单产品 | 产品组合 |
| 变体产品 | 礼品卡 |
| 数字产品 | 可定制产品 |
| | 可配置产品 |
| | 预订产品 |

原因是履行，而不是定价：订阅会在每个周期重新向客户收费，并通过每次的新订单重新交付产品。

Spwig知道如何在每次续订时重新发货一个简单或变体产品，并重新授予数字产品的下载或许可证——但它无法安全地重新运行礼品卡发行、多组件捆绑包、客户的已保存自定义设置、配置器构建或定期计划的预订时段。

让这些类型作为订阅销售可能会在第2个周期中骗取客户的资金而无法提供任何东西。

**启用订阅**复选框本身对于不适用的类型不会被隐藏或变灰——您可以在任何产品上技术上勾选它。如果您尝试保存一个带有订阅功能的礼品卡、捆绑包、可自定义产品、可配置产品或预订产品，Spwig将拒绝保存，并显示验证错误，说明此产品类型无法作为订阅销售。首先更改**产品类型**（基本信息选项卡），或者为该产品关闭订阅功能。

## 在产品上启用订阅

1. 导航到 **Products > All Products** 并打开您想作为订阅销售的产品（或创建一个新产品）。
2. 确认 **产品类型** 在基本信息选项卡上是 Simple、Variable 或 Digital。
3. 点击 **Subscriptions** 选项卡。
4. 勾选 **Enable Subscription**。
5. 在 **Subscription Plans** 字段中，选择此产品应提供的一个或多个计划。您只能选择已存在的计划——如果尚未创建任何计划，请先参阅[Subscription Plans](/help/subscription-plans)。
6. 配置两个购买模式复选框（在下方）。
7. 点击 **Save**。

## 将订阅计划附加到产品

一个 **Subscription Plan** 是一个可重复使用的模板——计费频率选项、试用期、设置费用、取消规则——您只需构建一次，就可以将它附加到任何数量的合格产品上。产品 **Subscriptions** 选项卡上的 **Subscription Plans** 字段是您将产品与应销售的计划连接起来的地方。

您可以将多个计划附加到同一个产品上。

这在你想要为同一商品提供“标准”和“高级”订阅层级时非常有用——每个计划可以有自己的定价层级、试用期和取消政策。

当一个商品有多个关联的计划时，客户在选择计费频率之前会在商品页面看到一个计划选择器。

## 控制一次性购买与订阅购买

在订阅选项卡中有两个复选框，用于控制客户如何购买该商品：

- **允许一次性购买** —— 默认为选中。当被选中时，客户可以在常规的一次性购买和订阅之间进行选择。取消选中以使该商品仅限订阅——每次购买都会成为定期订单，且完全不显示一次性购买选项。
- **默认选择订阅** —— 在商品页面加载时预选订阅选项（以及其默认计划/层级），而不是让客户主动选择。仅当**允许一次性购买**也被选中时才会生效——如果关闭一次性购买，该商品将仅限订阅，无论此设置如何。

对于订阅交付是自然预期的商品（如咖啡、膳食补充剂、消耗品），请使用**默认选择订阅**功能——这可以减少一次点击，促使客户选择能让他们持续购买的选项，同时不会影响他们一次性购买的能力。

## 客户看到的内容

### 在商品页面

当商品启用了订阅功能并且至少有一个活动的、公开的计划关联时，商品页面会出现一个购买模式选择器：

- 如果允许一次性购买，客户会看到 **“一次性购买”** 与 **“订阅并节省”** 的选择，默认情况下会根据您配置的模式进行选择。
- 如果产品有多个计划关联，当选择“订阅并节省”时，会显示一个计划选择器。
- 对于所选计划，客户会看到一个由该计划的定价层级（例如：每月、每季度、每年）构建的 **配送频率** 列表，每个层级显示其价格，并在该层级有折扣时显示 **“节省 X%”** 标签。
- 试用期长度、设置费用以及该计划的取消政策（例如：“随时取消”）会与层级列表一起显示，同时还会有提示说明在结账时会添加支付方式。

### 在购物车和结账时

购物车中的订阅商品会带有 **订阅** 标签、计费周期（例如：“每月一次”）以及试用期说明（如果适用），以便客户清楚了解哪些商品是定期订阅的。在结账时，客户会像平常一样选择支付提供商——这是未来续订时将被扣费的支付方式。

> **已知限制：** 对于某些支付提供商，自动保存客户的卡以供订阅续订仍处于连接中。在特定提供商支持此功能之前，通过该提供商下单的订阅可能需要额外的跟进（例如，在续订前联系客户获取更新的支付信息），而不是从第一天起就完全无需操作。如果注意到某个订阅的续订未自动扣费，请与您的支付提供商设置进行确认。

## 提示

- 首先创建并测试订阅计划（定价层级、试用期、取消政策），然后再将其附加到产品上——在一开始就正确设置计划会比之后在多个产品上修复计划更容易。
- 对于大多数产品，请保持 **允许一次性购买** 选项被勾选。

保留所有 markdown 格式、图片路径、代码块和术语。

将仅订阅的产品保留用于那些一次性购买对您的业务确实没有意义的情况。
- 如果您正在将现有畅销品转换为订阅选项，请先关闭 **默认为订阅** 以避免打扰那些习惯一次性购买的客户 —— 在您观察到订阅者的反应后，再稍后开启此功能。
- 数字产品非常适合订阅（如软件许可证、内容会员资格），因为续订会自动重新授予访问权限，且无需物流。
- 如果您需要一种不符合条件的产品类型（例如捆绑产品或可自定义商品）也能按定期收费销售，可以考虑是否可以使用简化版的简易或数字产品来替代订阅。
