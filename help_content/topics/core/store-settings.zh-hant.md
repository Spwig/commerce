---
title: 配置商店設置
---

商店設置是用來配置您的商店的身分、本地化、品牌和操作首選項的中心地。導覽至 **設定 > 商店設置** 開始。

![商店設置常規選項卡](/static/core/admin/img/help/store-settings/store-settings-general.webp)

## 常規選項卡

**常規** 選項卡包含您商店的核心身分設置。

### 商店身分

- **商店名稱** — 在頁面標題、電子郵件和管理員標頭中顯示的名稱。
- **副標題** — 您商店的簡短描述，用於 SEO 和社交分享。
- **網站網址** — 您商店的公開網際網路位址。這用於電子郵件、地圖產生和連結建立。

### 聯繫資訊

- **聯絡電郵** — 接收訂單通知，並在客戶溝通中顯示。
- **電話號碼** — 選擇性支援電話號碼，顯示在頁尾和電子郵件中。

### 營業地址

輸入您的完整地址（街道、城市、州、郵遞區號、國家）。這用於：
- 運費起點計算
- 稅務計算
- 法律要求和發票

## 品牌

### 商標

上傳您的商店商標（建議 PNG 或 SVG，約 200x50px，透明背景）。商標出現在：
- 商店前端標頭
- 電子郵件模板
- 管理員介面

### 網站圖示

上傳一個方形網站圖示（ICO 或 PNG，32x32px）。它出現在：
- 瀏覽器標籤圖示
- 書籤圖示
- 移動主螢幕圖示

## 本地化

| 語言 | 碼 |
|----------|------|
| 英語 | en |
| 西班牙語 | es |
| 法語 | fr |
| 德語 | de |
| 葡萄牙語 | pt |
| 日語 | ja |
| 簡體中文 | zh-hans |
| 繁體中文 | zh-hant |
| 俄語 | ru |

預設語言控制管理介面語言和 storefront 內容的預設值。

### 時區

選擇您商店的時區以確保訂單時間戳、計畫促銷和報告的準確性。

### 幣別

保留所有 markdown 格式、圖片路徑、程式碼區塊和技術術語。

- **預設貨幣** — 用於定價和會計的主要貨幣。
- **多貨幣** — 啟用後，客戶可以透過即時匯率自動轉換，以其偏好的貨幣查看價格。

在 **設定 > 商店設定 > 貨幣** 中設定其他貨幣。

## 電子商務設定

### 訪客結帳

允許在未建立帳戶的情況下進行購買：
- 更快的結帳流程
- 降低首次購買者的門檻
- 收集較少的客戶資料

### 帳戶建立時機

控制何時提示客戶建立帳戶：

| 選項 | 描述 |
|--------|-------------|
| **購買後（建議）** | 在訂單成功後提示建立帳戶 — 利用購買後的良好體驗以獲得最佳轉換率 |
| **結帳期間** | 在處理付款前建立帳戶 |
| **結帳前** | 在購物前要求帳戶（不建議 — 會降低轉換率） |

您也可以設定自訂的 **帳戶建立訊息** 來說明註冊的好處。

### 庫存預設值

- **追蹤庫存** — 全域啟用庫存追蹤
- **低庫存門檻** — 發送低庫存警報至管理員電子郵件的庫存水平（預設：10 單位）

### 庫存智慧

![顯示預設補貨提前期、安全庫存倍數、銷售速度計算窗口、預設允許補貨和低庫存警報頻率欄位的庫存智慧卡片](/static/core/admin/img/help/store-settings/ecommerce-inventory-intelligence.webp)

這些設定用於調整自動補貨、安全庫存和銷售速度的計算，並控制缺貨和低庫存情況的處理方式。

- **預設補貨提前期（天）** — 下單後從供應商收到補貨通常需要多少天（預設：14）。

預測功能使用此設定來標記需要*立即*補貨的產品，以避免在新貨到貨前出現缺貨。
- **安全庫存倍數** — 在預期需求之上套用的緩衝值，用以吸收銷售激增或供應商延遲。

例如，倍數為 `1.5` 會在計算出的安全庫存之上建立 50% 的緩衝；`2.0` 則將其加倍。

對於缺貨代價高昂的產品（如暢銷品、季節性商品），請調高此值；對於不想過度訂購的慢速流動庫存，請調低此值。
- **銷售速度計算窗口（天數）** — Spwig 用於計算每個產品銷售速度的回溯窗口，這將進一步驅動補貨建議和供應天數的數值（預設值：30）。

較短的窗口能更快反應近期的需求變化；較長的窗口則能平滑季節性高峰，避免單一忙碌週期扭曲預測。
- **預設允許預購** — 套用於新建立產品的初始預購設定（預設為關閉）。

每個產品仍可在其專屬產品頁面中個別覆蓋此設定，且現有產品將保留其原有的設定 — 更改此設定僅改變新產品開始時的預設值，不會追溯更新您的目錄。
- **低庫存警報頻率** — 您的 Spwig 行動應用程式收到低庫存通知的頻率：**即時** 會在產品跨越低庫存門檻的瞬間發送推送通知；**每日摘要** 和 **每週總結** 則會依該排程發送單一推送，彙總所有目前處於低庫存狀態的產品。

此設定僅在啟用 **低庫存警報**（下方的電子郵件設定）時生效 — 若警報關閉，則不會在任何頻率下發送通知。

### 文件與發票

![顯示文件與發票卡片，包含已填入範例值的稅務編號 / VAT 編號、發票頁尾文字、裝運單頁尾文字和文件 Logo 寬度欄位](/static/core/admin/img/help/store-settings/ecommerce-documents-invoicing.webp)


這些欄位會填入 Spwig 為訂單產生的發票和出貨單 — 例如當商家下載或透過電子郵件發送 PDF 發票，或為出貨列印出貨單時。

- **稅務編號 / 營業稅號** — 您的企業稅務識別號碼。列印在產生的發票上，以符合當地稅務文件要求。
- **發票頁尾文字** — 顯示在每張產生發票底部的自由文字。常見用途：付款條件（「30 天內付款」）、感謝訊息或銀行轉帳資訊。
- **出貨單頁尾文字** — 顯示在每張產生出貨單底部的自由文字。常見用途：退貨說明或給倉庫/履約團隊的備註。
- **文件 Logo 寬度 (px)** — 您的商店 Logo 在產生的 PDF 發票和出貨單上顯示的寬度（預設：200px）。高度會自動縮放以匹配，因此您的 Logo 比例會保持不變。Logo 圖片本身來自您的 **Logo**（品牌設定，上方）— SVG Logo 不會繪製在 PDF 文件上，因此如果您在商店前端使用向量圖形，請上傳 PNG 或 JPG 版本的 Logo。

## 電子郵件設定

在 **設定 > 電子郵件帳戶** 和 **設定 > 電子郵件範本** 中設定電子郵件傳遞設定。請參閱 [電子郵件設定](/help/email-configuration) 以取得完整詳細資訊。

商店設定中可用的主要電子郵件設定：

- **訂單確認電子郵件** — 開啟或關閉自動確認電子郵件
- **出貨通知電子郵件** — 開啟或關閉出貨更新通知
- **低庫存警告** — 當庫存低於門檻值時，向管理員電子郵件發送警告
- **電子郵件傳遞模式** — 即時（正常傳遞）、暫停（保留所有電子郵件）或僅記錄（記錄但永不發送）
- **測試重定向電子郵件** — 將所有外發電子郵件重定向到單一地址以進行測試

## 安全性設定

### 雙重驗證 (2FA)

控制是否要求員工使用雙重驗證：

| 設定 | 描述 |
|---------|-------------|
| **可選** | 員工可以選擇啟用兩步驗證，但不是必填 |
| **推薦** | 員工會看到提示鼓勵他們設置兩步驗證 |
| **必填** | 員工在啟用兩步驗證之前無法訪問管理後台 |

- **寬限期（天數）** — 員工在啟用執行後設置兩步驗證的天數
- **允許可信裝置** — 允許員工在指定天數內跳過可信裝置的兩步驗證

## Cookie 同意

配置顯示給商店訪客的 cookie 同意橫幅:

- **Cookie 同意已啟用** — 顯示或隱藏 cookie 橫幅
- **橫幅位置** — 橫幅在螢幕上的顯示位置（底部欄、角落彈窗等）
- **同意模式** — 簡單通知、選擇加入或選擇退出
- **橫幅標題和文字** — 可自定的標題和描述顯示給訪客
- **分類描述** — 分別為分析、營銷和功能 cookie 的描述

所有橫幅文字欄位都支援多語言商店的翻譯。

## 通訊

**通訊**選項卡控制您的商店如何獲取、確認並讓客戶管理營銷電子郵件和簡訊的同意。這些設置會影響您的法律合規立場（電子郵件的GDPR，簡訊的TCPA），因此在上線前請與您自己的法律顧問審查它——Spwig提供控制，而不是建議。

![通訊選項卡顯示電子郵件營銷同意、偏好與退訂和簡訊同意卡片](/static/core/admin/img/help/store-settings/communications-tab.webp)

### 電子郵件營銷同意

- **為營銷電子郵件啟用雙重選擇** — 當啟用時，選擇加入營銷電子郵件的客戶會收到確認電子郵件，並必須點擊其中的連結，Spwig才會發送任何營銷訊息。

當關閉時，勾選營銷選擇加入方塊就足夠了。

保留所有markdown格式、圖片路徑、代碼塊和技術術語。

預設啟用，符合GDPR最佳實務。
- **預設營銷同意狀態** — 新建立的客戶帳戶預設套用的營銷同意狀態。

預設關閉（GDPR選擇不參與），因此新客戶預設未訂閱營銷電子郵件，直到他們主動同意參與。

當雙重確認啟用時，同意參與會觸發一封確認電子郵件，內含驗證連結。在客戶點選之前，他們會被記錄為已同意但未驗證，營銷電子郵件將跳過他們——交易電子郵件（訂單確認、運送更新、密碼重設）永遠不會受到此設定的影響。

### 偏好設定與退訂

- **啟用客戶偏好中心** — 當啟用時，客戶可以從他們帳戶儀表板連結的自我服務頁面管理電子郵件和簡訊偏好設定。當關閉時，該頁面及其支援API會回傳不可用，儀表板連結也會隱藏。電子郵件中的單擊退訂連結無論如何都能正常運作——這是一種合規性逃生通道，不受此切換的影響。
- **收集退訂原因** — 當啟用時，單擊退訂頁面會要求客戶提供簡短的原因後再確認：*我收到太多電子郵件*, *內容與我不相關*, *我未註冊此服務*, *我不再感興趣*, 或 *其他*。客戶選擇的原因會記錄到共識審計追蹤中，讓您可以隨時審查退訂模式。

### 簡訊同意

- **需要簡訊驗證** — 當啟用時（預設），客戶必須使用一次性代碼驗證電話號碼，Spwig才會傳送任何簡訊給他們，包括營銷簡訊。當關閉時，勾選簡訊同意方塊就足夠啟動傳送。此預設已變更為 **啟用** 以符合TCPA安全標準——只有在註冊流程中有其他驗證步驟時才關閉。

## 維護模式

保留所有markdown格式、圖片路徑、程式碼區塊和技術術語。

啟用維護模式以暫時將您的商店下線：
- 向訪客顯示自定義的維護訊息
- 您可以連結在頁面編輯器中建立的 **維護頁面**，以提供完整的品牌體驗
- 僅限管理員訪問
- 在重大更新或遷移期間非常實用

## 社交媒體

連結您的商店的社交媒體個人資料。這些會出現在頁尾和電子郵件模板中：

- **Facebook網址**
- **Twitter網址**
- **Instagram網址**
- **LinkedIn網址**

## SEO預設值

設置頁面沒有自己的SEO設置時使用的預設meta標籤：

- **Meta標題** — 預設頁面標題（最多60個字元）
- **Meta描述** — 預設描述，顯示在搜尋結果中（最多160個字元）
- **Meta關鍵字** — 預設逗號分隔的關鍵字

## 稅務設置

在 **Settings > Tax Settings** 設定稅務收集：

1. **計算方式** — 依據運費地址、賬單地址或商店所在地
2. **稅率** — 依據地區和產品稅務等級定義稅率
3. **稅務顯示** — 顯示含稅價格、不含稅價格或兩者皆顯示

## 提示

保留所有markdown格式、圖片路徑、程式碼區塊和技術術語。

- 在處理任何訂單之前，請正確設定您的時區——這會影響所有時間戳記和報告。
- 啟用訪客結帳以提高轉換率。
- 填寫您的商業地址，以進行準確的運送和稅務計算。
- 上傳標誌和 favicon，以提供專業且具品牌特色的體驗。
- 使用**購買後**的帳戶建立時機，以獲得最佳註冊率。
- 為員工啟用雙重驗證強制執行，以保護您的商店管理員。
- 在正式上線之前，使用**測試重定向電子郵件**設定來測試電子郵件流程。
- 將**預設重新訂購提前期**設定為與您最慢的常規供應商相匹配——重新訂購預測會將此單一值應用於您的整個目錄，因此請以提前期最長的产品為準。
- 如果您頻繁進行促銷或補貨，並希望預測能快速反應最近幾天的銷售情況，請縮短**速度計算窗口**；為了獲得更穩定、較少尖峰的需求視圖，請延長它。
- 如果您開啟**預設允許超賣**，請記住它僅為在變更*之後*建立的产品設定起點——如果您也希望在目前的目錄中啟用超賣，請個別重新檢視現有产品。
- 將**低庫存警報頻率**與您管理庫存的活躍程度相匹配：對於快速流動的目錄，其中每個缺貨風險都需要立即關注，請使用**即時**；對於較大的目錄，請使用**每日摘要**或**每週總結**以避免警報疲勞。
- 在您的第一張真實發票發送給客戶之前，請填寫您的**稅務編號 / VAT 號碼**和頁尾文字——這兩個欄位預設為空白。
- 如果您的**標誌**是 SVG，請也上傳 PNG 或 JPG 版本——**文件標誌寬度**對 PDF 沒有影響，因為 Spwig 無法在生成的發票和裝運單上繪製 SVG 圖形。
- 除非您有特定原因要關閉**啟用行銷電子郵件雙重確認**，否則請保持開啟——這是 GDPR 的更安全預設值，它透過將未驗證的地址排除在您的行銷發送之外來保護您的發件人聲譽。
- 保持**預設行銷訂閱狀態**為關閉。

對新帳戶預先勾選行銷同意，即使客戶在技術上可以取消勾選，也會削弱 GDPR 的選入（opt-in）要求。
- 不要為了簡化帳戶儀表板而停用 **啟用客戶偏好中心** — 沒有它，客戶仍然可以退訂單一訊息類型，但會失去微調偏好的能力（例如保留運送更新但取消電子報）。
- 除非您的註冊流程已透過其他方式確認電話號碼（例如基於 SMS 的登入），否則請保持 **要求 SMS 驗證** 開啟 — 此設定專門用於確保您符合 TCPA 規則。

## 疑難排解

**變更未顯示在商店前端：**
- 清除您的瀏覽器快取
- 從管理面板執行快取清除
- 檢查是否意外啟用了維護模式

**電子郵件未發送：**
- 在電子郵件設定中驗證您的電子郵件供應商設定
- 檢查 **電子郵件傳遞模式** 是否設定為 **即時**
- 如果您希望電子郵件發送給實際收件者，請確保 **測試重定向電子郵件** 為空白

**貨幣轉換不起作用：**
- 驗證您的匯率供應商是否已連接
- 檢查匯率設定中的 API 憑證
- 嘗試手動更新匯率

**行銷電子郵件未到達已選入的客戶：**
- 檢查 **啟用行銷電子郵件雙重選入** 是否開啟 — 如果是，客戶必須點擊驗證電子郵件中的確認連結，行銷發送才會恢復
- 請客戶檢查垃圾郵件/垃圾郵件資料夾中的確認電子郵件
- 確認客戶偏好中的行銷選入仍然開啟 — 點擊退訂會將其關閉

**客戶表示找不到偏好中心：**
