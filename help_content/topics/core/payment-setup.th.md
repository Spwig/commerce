ผู้ให้บริการชำระเงินเชื่อมต่อร้านค้าของคุณกับช่องทางการชำระเงิน เพื่อให้คุณสามารถรับชำระเงินผ่านบัตรเครดิต กระเป๋าเงินดิจิทัล และวิธีการชำระเงินอื่น ๆ ได้ที่หน้าชำระเงิน Spwig รองรับผู้ให้บริการหลายรายพร้อมกัน ทำให้ลูกค้าของคุณมีตัวเลือกในการชำระเงินที่ยืดหยุ่นมากขึ้น

![ผู้ให้บริการชำระเงิน](/static/core/admin/img/help/payment-setup/payment-dashboard.webp)

## ผู้ให้บริการที่มีอยู่

| ผู้ให้บริการ | คำอธิบาย |
|----------|-------------|
| **Stripe** | บัตรเครดิต Apple Pay Google Pay และ 135+ สกุลเงิน |
| **PayPal** | ยอดเงิน PayPal บัตรเครดิต/เดบิต และตัวเลือกชำระเงินภายหลัง |
| **Airwallex** | การชำระเงินหลายสกุลเงินที่ออกแบบมาสำหรับการค้าข้ามพรมแดน |
| **Square** | การชำระเงินแบบตัวต่อตัวและออนไลน์พร้อมการสนับสนุน POS ที่ผสานรวม |
| **Revolut** | การโอนเงินในยุโรปที่รวดเร็วพร้อมอัตราแลกเปลี่ยนที่มีการแข่งขัน |

## การเชื่อมต่อกับผู้ให้บริการ

ไปที่ **การตั้งค่า > ผู้ให้บริการชำระเงิน** และคลิก **เชื่อมต่อผู้ให้บริการ** เพื่อเปิดตัวเครื่องมือตั้งค่า

### ขั้นตอนที่ 1: เลือกผู้ให้บริการ

เลือกผู้ให้บริการชำระเงินที่มีอยู่ แต่ละบัตรแสดงถึงคุณสมบัติและภูมิภาคที่ผู้ให้บริการรองรับ

### ขั้นตอนที่ 2: คำแนะนำการตั้งค่า

ตรวจสอบคู่มือการตั้งค่าเฉพาะผู้ให้บริการ ซึ่งรวมถึง:
- วิธีสร้างบัญชีกับผู้ให้บริการ (หากคุณยังไม่มี)
- ตำแหน่งที่คุณสามารถหาได้ API credentials ในแดชบอร์ดของผู้ให้บริการ
- ข้อกำหนดเบื้องต้น (เช่น การตรวจสอบธุรกิจ)

### ขั้นตอนที่ 3: ป้อนข้อมูลการรับรอง

ป้อนข้อมูล API ของคุณ:
- **API Key / Secret Key** — ข้อมูลการรับรองการเข้าถึงของคุณจากแดชบอร์ดผู้ให้บริการ
- **โหมดการชำระเงิน** — เลือกวิธีที่ลูกค้าจะมีปฏิสัมพันธ์กับฟอร์มชำระเงิน:

| โหมด | คำอธิบาย |
|------|-------------|
| **Hosted** | ลูกค้าจะถูกเปลี่ยนเส้นทางไปยังหน้าชำระเงินของผู้ให้บริการ (เช่น Stripe Checkout) ตั้งค่าที่ง่ายที่สุด โดยผู้ให้บริการจะจัดการความเป็นไปตามมาตรฐาน PCI |
| **Integrated** | ฟอร์มชำระเงินจะถูกฝังไว้ในหน้าชำระเงินของคุณโดยตรง ประสบการณ์ที่ราบรื่น แต่ต้องการ SDK JavaScript ของผู้ให้บริการ |

- **โหมดทดลอง / โหมดจริง** — เริ่มต้นในโหมดทดลองเพื่อทดสอบ จากนั้นเปลี่ยนไปโหมดจริงเมื่อพร้อม

### ขั้นตอนที่ 4: ทดสอบการเชื่อมต่อ

คลิก **Test Connection** เพื่อตรวจสอบว่าข้อมูลการเข้าสู่ระบบของคุณถูกต้อง วิザาร์ดจะตรวจสอบ:
- การตรวจสอบความถูกต้องของ API key
- สิทธิ์บัญชี
- ความสามารถในการเข้าถึงปลายทาง Webhook

### ขั้นตอนที่ 5: ตั้งค่าและบันทึก

กำหนดค่าตัวเลือกของผู้ให้บริการ:
- **Active** — เปิดหรือปิดการใช้งานผู้ให้บริการ
- **Default Provider** — ตั้งเป็นวิธีการชำระเงินหลักที่เคาน์เตอร์ชำระเงิน
- **Display Name** — ชื่อที่แสดงให้ลูกค้าเห็นขณะชำระเงิน
- **Sort Order** — ควบคุมลำดับที่ผู้ให้บริการปรากฏที่เคาน์เตอร์ชำระเงิน (ตัวเลขที่ต่ำกว่าจะปรากฏก่อน)

## แดชบอร์ดการชำระเงิน

ไปที่ **Settings > Payment Dashboard** เพื่อดูภาพรวมกิจกรรมการชำระเงินของคุณ:

### การดำเนินการที่จำเป็น

การ์ดแจ้งเตือนด้านบนจะเน้นปัญหาที่ต้องได้รับการแก้ไข:
- **Failed Transactions** — การชำระเงินที่ไม่สามารถดำเนินการได้
- **Pending Captures** — การชำระเงินที่ได้รับการอนุมัติแต่ยังรอการจับเงิน
- **Connection Errors** — ผู้ให้บริการที่มีปัญหาการเชื่อมต่อ

### การวิเคราะห์รายได้

- **Revenue Chart** — การแสดงผลภาพรวมของปริมาณการชำระเงินตามเวลา แบ่งตามวัน สัปดาห์ หรือเดือน
- **Performance Metrics** — รายได้ทั้งหมด อัตราความสำเร็จ มูลค่าการซื้อเฉลี่ย และอัตราคืนเงิน
- **Provider Comparison** — บัตรเปรียบเทียบประสิทธิภาพของผู้ให้บริการที่เชื่อมต่อแต่ละราย

### การวิเคราะห์การชำระเงิน

- **Status Distribution** — จำนวนการชำระเงินที่สำเร็จ รอการดำเนินการ ล้มเหลว และคืนเงิน
- **Payment Method Mix** — วิธีการชำระเงินที่ลูกค้าใช้บ่อยที่สุด (บัตรเครดิต PayPal กระเป๋าเงินดิจิทัล)

## การจัดการวิธีการชำระเงิน

ผู้ให้บริการแต่ละรายสนับสนุนวิธีการชำระเงินที่แตกต่างกัน คุณสามารถเปิดหรือปิดวิธีการเฉพาะตามประเทศ:

1. ไปที่หน้าตั้งค่าของผู้ให้บริการ
2. ค้นหาส่วน **Payment Methods**
3. เปิดหรือปิดวิธีการแต่ละวิธี
4. ใช้การควบคุมระดับประเทศเพื่อจำกัดวิธีการเฉพาะในตลาดที่กำหนด

สิ่งนี้มีประโยชน์เมื่อวิธีการชำระเงินได้รับความนิยมในภูมิภาคหนึ่งแต่ไม่ใช่ในอีกภูมิภาค (เช่น iDEAL ในเนเธอร์แลนด์ Bancontact ในเบลเยียม)

## Webhooks

เว็บฮุคช่วยให้ร้านค้าของคุณสอดคล้องกับผู้ให้บริการชำระเงินแบบเรียลไทม์

พวกเขาจัดการเหตุการณ์ เช่น:
- การชำระเงินสำเร็จหรือล้มเหลว
- การคืนเงินที่ดำเนินการแล้ว
- การเปิดข้อพิพาทและคืนเงินโดยไม่ได้รับอนุญาต
- การต่ออายุสมาชิก

### การตั้งค่าอัตโนมัติ

เมื่อคุณเชื่อมต่อกับผู้ให้บริการ Spwig จะลงทะเบียนจุดปลายเว็บฮุคกับผู้ให้บริการอัตโนมัติ คุณสามารถดู URL ของเว็บฮุคได้บนหน้าการตั้งค่าของผู้ให้บริการเพื่อใช้อ้างอิง

### การตรวจสอบเว็บฮุค

เว็บฮุคที่เข้ามาทุกตัวจะถูกบันทึกพร้อมกับ:
- **ประเภทเหตุการณ์** (เช่น payment_intent.succeeded)
- **เวลาที่บันทึก** และสถานะการประมวลผล
- **ข้อมูลที่ส่งมา** สำหรับการตรวจสอบข้อผิดพลาด

หากเว็บฮุคไม่สามารถประมวลผลได้ จะถูกบันทึกเป็นข้อผิดพลาดเพื่อให้คุณสามารถตรวจสอบได้

## การใช้ผู้ให้บริการหลายราย

คุณสามารถเชื่อมต่อกับผู้ให้บริการชำระเงินหลายรายพร้อมกัน:

- **ผู้ให้บริการเริ่มต้น** — ผู้ให้บริการที่ถูกเลือกเป็นค่าเริ่มต้นที่หน้าชำระเงิน ให้เลือกผู้ให้บริการหนึ่งเป็นผู้ให้บริการเริ่มต้นในการตั้งค่าของมัน
- **ลำดับการจัดเรียง** — ควบคุมลำดับการแสดงผลที่หน้าชำระเงิน ลูกค้าจะเห็นผู้ให้บริการทั้งหมดที่เปิดใช้งานและสามารถเลือกผู้ให้บริการที่ต้องการได้
- **การสำรอง** — หากผู้ให้บริการมีปัญหาด้านการดำเนินงาน ลูกค้ายังสามารถชำระเงินผ่านผู้ให้บริการอื่นได้

## เคล็ดลับ

- เริ่มต้นด้วย **Stripe** หรือ **PayPal** — พวกเขาครอบคลุมวิธีการชำระเงินและภูมิภาคที่กว้างที่สุด
- ใช้โหมด **ทดลอง/ทดสอบ** เพื่อประมวลผลธุรกรรมทดสอบก่อนเปิดใช้งานจริง แต่ละผู้ให้บริการมีหมายเลขบัตรทดสอบในเอกสารประกอบของพวกเขา
- เปิดใช้งาน **ผู้ให้บริการหลายราย** เพื่อให้ลูกค้ามีทางเลือกในการชำระเงินหากผู้ให้บริการหนึ่งมีปัญหา
- ตั้งค่า **ลำดับการจัดเรียงต่ำ** สำหรับผู้ให้บริการที่คุณชอบ เพื่อให้แสดงขึ้นแรกที่หน้าชำระเงิน
- ตรวจสอบแดชบอร์ดการชำระเงินรายสัปดาห์เพื่อจับธุรกรรมที่ล้มเหลวและปัญหาการเชื่อมต่อตั้งแต่เนิ่นๆ
- รักษา **ข้อมูล API ของคุณให้ปลอดภัย** — แม้ว่าจะถูกเข้ารหัสในฐานข้อมูล แต่ไม่ควรแบ่งปันกับผู้อื่นเลย
