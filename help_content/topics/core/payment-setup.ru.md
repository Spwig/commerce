title: Настройка оплаты
---

Провайдеры оплаты подключают ваш магазин к платежным шлюзам, чтобы вы могли принимать кредитные карты, цифровые кошельки и другие методы оплаты на этапе оформления заказа. Spwig поддерживает несколько провайдеров одновременно, предоставляя вашим клиентам гибкие варианты оплаты.

![Провайдеры оплаты](/static/core/admin/img/help/payment-setup/payment-dashboard.webp)

## Доступные провайдеры

| Провайдер | Описание |
|----------|-------------|
| **Stripe** | Кредитные карты, Apple Pay, Google Pay и 135+ валют |
| **PayPal** | Баланс PayPal, кредитные/дебетовые карты и опции оплаты позже |
| **Airwallex** | Многонациональные платежи, оптимизированные для международной торговли |
| **Square** | Оплата в магазине и онлайн с поддержкой интегрированного POS |
| **Revolut** | Быстрые европейские платежи с конкурентоспособными курсами обмена |

## Подключение провайдера

Перейдите в **Настройки > Провайдеры оплаты** и нажмите **Подключить провайдера**, чтобы запустить мастер настройки.

### Шаг 1: Выберите провайдера

Выберите из доступных провайдеров оплаты. Каждая карточка показывает поддерживаемые функции и регионы провайдера.

### Шаг 2: Инструкции по настройке

Просмотрите инструкцию по настройке, специфичную для провайдера. Это включает:
- Как создать учетную запись у провайдера (если у вас еще нет такой)
- Где найти ваши учетные данные API в панели управления провайдера
- Любые предварительные условия (например, проверка бизнеса)

### Шаг 3: Введите учетные данные

Введите свои учетные данные API:
- **API-ключ / Секретный ключ** — ваши учетные данные аутентификации из панели управления провайдера
- **Режим оплаты** — выберите, как клиенты взаимодействуют с формой оплаты:

| Режим | Описание |
|------|-------------|
| **Хостированный** | Клиенты перенаправляются на страницу оплаты провайдера (например, Stripe Checkout). Самый простой способ настройки, соответствие требованиям PCI обеспечивается провайдером. |
| **Интегрированный** | Форма оплаты встраивается напрямую в вашу страницу оформления заказа. Плавный опыт, но требуется JavaScript SDK провайдера. |

- **Режим песочницы / Режим продаж** — начните с режима песочницы для тестирования, затем переключитесь на режим продаж, когда будет готово

### Шаг 4: Тестирование подключения

Нажмите **Проверить подключение**, чтобы убедиться, что ваши учетные данные действительны. Мастер проверяет:
- Аутентификацию API-ключа
- Разрешения учетной записи
- Доступность конечной точки веб-_hooks

### Шаг 5: Настройка и сохранение

Завершите настройки провайдера:
- **Активный** — включить или отключить провайдера
- **Основной провайдер** — установить как основной метод оплаты при оформлении заказа
- **Отображаемое имя** — имя, отображаемое клиентам при оформлении заказа
- **Порядок сортировки** — управляет порядком, в котором провайдеры отображаются при оформлении заказа (меньшие числа отображаются первыми)

## Панель оплаты

Перейдите в **Настройки > Панель оплаты**, чтобы получить обзор вашей активности по оплатам:

### Действия, требующие внимания

Карты предупреждений в верхней части выделяют проблемы, требующие внимания:
- **Неудачные транзакции** — платежи, которые не удалось обработать
- **Ожидающие захвата** — авторизованные платежи, ожидающие захвата
- **Ошибка подключения** — провайдеры с проблемами подключения

### Анализ доходов

- **Диаграмма доходов** — визуальное разделение объема платежей со временем, сгруппированное по дням, неделям или месяцам
- **Показатели производительности** — общий доход, уровень успешности, среднее значение транзакции и уровень возвратов
- **Сравнение провайдеров** — карточки производительности для каждого подключенного провайдера, расположенные рядом

### Разбивка транзакций

- **Распределение статусов** — количество завершенных, ожидаемых, неудачных и возвращенных транзакций
- **Смесь методов оплаты** — какие методы оплаты чаще всего используют клиенты (кредитные карты, PayPal, цифровые кошельки)

## Управление методами оплаты

Каждый провайдер поддерживает разные методы оплаты. Вы можете включить или отключить конкретные методы по стране:

1. Перейдите на страницу настройки провайдера
2. Прокрутите до раздела **Методы оплаты**
3. Включите или отключите отдельные методы
4. Используйте настройки на уровне страны, чтобы ограничить методы определенными рынками

Это полезно, когда метод оплаты популярен в одной области, но не в другой (например, iDEAL в Нидерландах, Bancontact в Бельгии).

## Веб-хуки

Вебхуки синхронизируют ваш магазин с платежным провайдером в реальном времени.

Они обрабатывают события, такие как:
- Завершение или сбой платежа
- Обработка возвратов
- Открытие споров и возвратов средств
- Обновления подписок

### Автоматическая настройка

Когда вы подключаетесь к провайдеру, Spwig автоматически регистрирует конечную точку вебхука у провайдера. URL-адрес вебхука отображается на странице конфигурации провайдера для справки.

### Мониторинг вебхуков

Каждый входящий вебхук записывается с:
- **Типом события** (например, payment_intent.succeeded)
- **Временем** и статусом обработки
- **Полезной нагрузкой** для отладки

Если вебхук не удается обработать, он записывается как ошибка, чтобы вы могли провести расследование.

## Использование нескольких провайдеров

Вы можете одновременно подключить несколько платежных провайдеров:

- **Основной провайдер** — провайдер, выбранный по умолчанию на этапе оформления заказа. Отметьте один провайдер как основной в его настройках.
- **Порядок сортировки** — управляет порядком отображения на этапе оформления заказа. Покупатели видят все активные провайдеры и могут выбрать предпочтительный.
- **Резервное копирование** — если у провайдера возникает сбой, покупатели все равно могут оплатить с помощью альтернативного провайдера.

## Советы

- Начните с **Stripe** или **PayPal** — они охватывают наибольшее количество методов оплаты и регионов.
- Используйте **режим песочницы/теста**, чтобы обрабатывать тестовые транзакции перед запуском. У каждого провайдера в их документации есть тестовые номера карт.
- Включите **несколько провайдеров**, чтобы у покупателей был резервный вариант оплаты, если у одного провайдера возникнут проблемы.
- Установите **низкий порядок сортировки** для вашего предпочтительного провайдера, чтобы он отображался первым при оформлении заказа.
- Регулярно проверяйте панель оплаты еженедельно, чтобы вовремя выявлять сбойные транзакции и проблемы с подключением.
- Сохраняйте свои учетные данные API в безопасности — они хранятся в зашифрованном виде в базе данных, но никогда не должны делиться.
