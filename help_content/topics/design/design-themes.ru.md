title: Дизайн и темы
---

Система Дизайна и Тем позволяет управлять внешним видом вашего магазина — от цветов и шрифтов до заголовков, подвалов и макетов страниц. Перейдите по ссылке **Настройки > Дизайн и Темы**, чтобы открыть панель управления Дизайном.

![Панель управления Дизайном](/static/core/admin/img/help/design-themes/theme-dashboard.webp)

## Панель управления Дизайном

Панель управления дает обзор состояния дизайна вашего магазина:

- **Активная Тема** — Показывает, какая тема сейчас применяется, с превью и быстрыми кнопками
- **Статистика Дизайна** — Количество установленных тем, пользовательских заголовков, пользовательских подвалов и меню
- **Карты разделов** — Перейти к Темам, Конструктору Заголовков, Конструктору Подвалов, Меню или Объявлениям

## Темы

### Просмотр Тем

Нажмите на раздел **Темы**, чтобы увидеть все установленные темы. Каждая карточка темы содержит:
- Название темы и изображение превью
- Автор и версия
- Статус активной/неактивной темы

### Активация Темы

1. Нажмите **Активировать** на теме, которую вы хотите использовать
2. Тема применяется немедленно к вашему магазину
3. Одновременно может быть активной только одна тема

### Настройка Темы

Каждая тема поддерживает набор **дизайнерских токенов** — настраиваемые значения, которые управляют визуальным внешним видом без редактирования кода.

Нажмите **Настроить** на вашей активной теме, чтобы получить доступ к редактору токенов. Доступные категории токенов включают:

| Категория | Что контролирует |
|----------|-----------------|
| **Цвета** | Основные, второстепенные, акцентные цвета, фон, цвет текста |
| **Шрифты** | Семьи шрифтов, размеры, веса, межстрочное расстояние |
| **Промежутки** | Отступы, поля, промежутки между элементами |
| **Границы** | Толщина границ, радиусы, цвета |
| **Тени** | Тени для карточек, кнопок, модальных окон |
| **Кнопки** | Стили кнопок, размеры, эффекты при наведении |
| **Макет** | Ширины контейнеров, промежутки сетки, точки прерывания |

Изменения предварительно просматриваются в реальном времени перед сохранением.

## Конструктор Заголовков

Конструктор Заголовков позволяет создавать заголовок вашего магазина с помощью интерфейса перетаскивания.

### Создание Заголовка

1. Перейдите по ссылке **Дизайн > Конструктор Заголовков**
2. Нажмите **Создать Заголовок** или отредактируйте существующий
3. У Builder есть три строки: **Верхняя Полоса**, **Основной Заголовок** и **Нижняя Полоса**
4. Перетащите виджеты из корзины в любую строку

### Доступные Виджеты Заголовка

- **Логотип** — Логотип вашего магазина с настраиваемым размером и ссылкой
- **Меню Навигации** — Раскрывающееся меню из ваших определенных меню
- **Поле Поиска** — Поиск товаров с мгновенными результатами
- **Значок Корзины** — Мини-корзина с бейджом количества товаров
- **Значок Аккаунта** — Раскрывающееся меню входа/аккаунта
- **Выбор Языка** — Переключатель языков для многоязычных магазинов
- **Выбор Валюты** — Переключатель валют для многовалютных магазинов
- **Выбор Местоположения** — Позволяет покупателям выбрать страну своего местоположения доставки, переключая их регион продаж (и валюту, для многовалютных магазинов). Ознакомьтесь с руководством **Доступность Регионов** для получения дополнительной информации
- **Пользовательский HTML** — Добавьте любой пользовательский контент
- **Социальные Значки** — Ссылки на ваши профили в социальных сетях
- **Полоса Объявлений** — Рекламные сообщения и предложения

### Настройки Заголовка

У каждого шаблона заголовка есть глобальные настройки:
- **Липкий Заголовок** — Заголовок остается видимым при прокрутке
- **Прозрачный Режим** — Накладка на героические изображения
- **Точка Переключения на Мобильную Версию** — Когда переключаться на мобильный макет

## Конструктор Подвалов

Конструктор Подвалов работает аналогично Конструктору Заголовков.

### Создание Подвала

1. Перейдите по ссылке **Дизайн > Конструктор Подвалов**
2. Нажмите **Создать Подвал** или отредактируйте существующий
3. Конструктор поддерживает несколько столбцов и строк
4. Перетащите виджеты в нужное место

### Доступные Виджеты Подвала

- **Меню Навигации** — Ссылки навигации в подвале
- **Подписка на Новостную рассылку** — Форма подписки на электронную почту
- **Социальные Значки** — Ссылки на социальные сети
- **Пользовательский HTML** — Пользовательский контент, значки, сертификаты
- **Значки Оплаты** — Отображение принятых способов оплаты
- **Авторские Права** — Динамический текст авторских прав с годом
- **Логотип** — Вариант логотипа в подвале

## Меню Навигации

Меню определяет ссылки навигации в вашем заголовке и подвале.

### Создание Меню

1. 

Перейдите по ссылке **Дизайн > Меню**
2.

Нажмите **Добавить меню**
3.

Дайте меню имя (например, "Основное меню")
4.

Добавьте элементы меню:
   - **Ссылка на страницу** — Ссылка на страницу, созданную в конструкторе страниц
   - **Ссылка на категорию** — Ссылка на категорию товаров
   - **Пользовательский URL** — Любой внешний или внутренний URL
   - **Выпадающее меню** — Вложенные подпункты
5.

Перетащите элементы, чтобы изменить их порядок
6.

Сохраните и назначьте меню виджету заголовка или футера

## Объявления

Создавайте рекламные баннеры, которые появляются в верхней части вашего магазина.

### Создание объявления

1. Перейдите по ссылке **Дизайн > Объявления** (или воспользуйтесь картой панели приборов)
2. Нажмите **Добавить объявление**
3. Настройте:
   - **Сообщение** — Текст объявления (поддерживает переводы)
   - **Ссылка** — Необязательный URL при нажатии
   - **Стиль** — Цвет фона, цвет текста, иконка
   - **Расписание** — Даты начала и окончания
   - **Убираемое** — Могут ли клиенты закрыть его
4. Сохраните и активируйте

Множество объявлений могут быть активными одновременно — они автоматически вращаются.

## Советы

- Начните с кастомайзера активной темы, чтобы подобрать цвета бренда, прежде чем строить заголовки и футеры.
- Используйте функцию **предварительного просмотра** в конструкторах заголовков и футеров, чтобы увидеть изменения до публикации.
- Создайте отдельные заголовки для десктопа и мобильных устройств, если вам нужны очень разные макеты.
- Держите навигацию простой — 5-7 пунктов верхнего уровня идеальны для удобства использования.
- Используйте объявления для временных акций, а не для постоянных сообщений.
- Редактор токенов темы поддерживает предварительный просмотр в реальном времени — экспериментируйте свободно и сохраняйте, когда будете довольны.
