# 보기 규칙

보기 규칙은 방문자의 신분과 위치에 따라 스토어프론트의 일부를 보이거나 숨길 수 있습니다. 고객의 시장 또는 지역, 언어 또는 통화, 하루 중 시간, 또는 로그인 여부와 같은 개인별 신호에 따라 **페이지 요소**, **메뉴 항목**, **헤더/푸터 위젯**을 동일한 조건으로 제한할 수 있습니다.

모든 것이 **규칙 그룹**에서 구성됩니다: 하나 이상의 조건이 포함된 이름이 지정된 재사용 가능한 패키지입니다. 예를 들어 "뉴질랜드 시장" 또는 "로그인한 회원"과 같은 규칙 그룹을 한 번 생성한 다음, 해당 그룹이 제어하고자 하는 어떤 요소, 메뉴 항목, 또는 위젯에든 연결할 수 있습니다. 규칙 그룹이 연결되지 않은 항목은 항상 보입니다.

## 보기 결정 방법

항목에 두 개 이상의 규칙 그룹이 연결된 경우, **어떤 하나**의 연결된 그룹이 일치하면 항목이 표시됩니다 (OR로 결합됩니다). 단일 그룹 내에서는 **모든** 또는 **어떤 하나**의 조건이 일치해야 하는지 선택합니다.

규칙은 두 가지 유형으로 나뉘며, Spwig은 이들을 다르게 처리하여 스토어가 빠르고 검색 엔진 친화적이게 유지하도록 합니다:

- **시장 규칙** — 지역/시장, 언어, 통화, 시간 기반 조건. 이들은 각 시장 URL에서 서버에서 결정되므로, 해당 주소에 있는 모든 방문자(및 모든 검색 엔진)에게 동일한 페이지가 제공됩니다. 이는 페이지를 캐시 가능하게 하고 SEO에 안전하게 유지합니다.
- **개별 방문자 규칙** — 로그인 상태, 장바구니 내용, 기기, 정확한 위치. 이들은 개별 방문자의 경우에 따라 달라지므로, 페이지가 로드된 후 Spwig이 개인적으로 해결합니다. 이들은 공유된 캐시된 페이지에 포함되지 않습니다.

규칙 그룹을 비활성화하면 적용이 중지되며, 연결된 항목이 다시 표시됩니다. 그룹을 비활성화하는 것은 무엇을 숨기는 방법이 아닙니다.

## 규칙 생성 및 연결

규칙 그룹을 작업하는 두 가지 방법이 있습니다.

### 디자인 중에 연결하세요

내용을 제한할 수 있는 모든 위치에서 **보기 제어**(눈 아이콘)를 볼 수 있습니다:

이미지 경로, 코드 블록, 기술 용어를 유지하십시오.

- **Page Builder** — 요소를 선택하고, 속성을 열고, 시각화 제어를 사용하십시오.
- **Menu Builder** — 메뉴 항목을 선택하고 **보기 규칙** 탭을 여십시오.

이 기능은 **모든** 항목에 적용되며, 다른 항목 아래에 중첩된 하위 메뉴(드롭다운) 항목도 포함됩니다.
자식 항목에 규칙이 적용되면 해당 자식 항목만 숨기고, 다른 메뉴는 그대로 유지됩니다.
- **Header & Footer Builder** — 위젯을 선택하고, 설정의 **보기 규칙 그룹** 섹션을 여십시오.

방문자의 개인적 정보에 따라 결정되는 규칙 — 로그인 여부, 장바구니에 있는 항목, 기기 — 은 스토어를 느리게 하거나 검색 엔진에 영향을 주지 않고 각 고객마다 해결됩니다.
고객은 자신의 목적에 맞는 탐색만 볼 수 있도록 하여, 스토어는 빠르고 캐시 가능하게 유지됩니다.

시각화 편집기에서 다음 작업을 수행할 수 있습니다:

- **연결** — 기존 규칙 그룹을 체크하여 연결합니다.
- **빠른 규칙** — 즉시 사용할 수 있는 간단한 규칙 그룹을 만드십시오 (예: "회원만", 단일 시장, 통화, 기기, 최소 장바구니 가치 등) 및 단계에서 연결합니다.
- **규칙 그룹 관리** — 고급 규칙을 위한 전체 빌더로 이동하십시오.

**적용**을 클릭하면 항목이 즉시 제한됩니다.

### 고급 규칙 만들기

여러 조건을 결합하거나, 그룹을 중첩하거나, 세부적인 연산자를 사용하는 것과 같은 더 복잡한 작업을 위해서는 **디자인 → 시각화 규칙** (규칙 그룹)으로 이동하십시오. 이곳에서 AND/OR 논리로 규칙을 구성하고, 전체 스토어에서 규칙을 재사용할 수 있습니다.

## 일반 조건

| Condition | Use it to… |
|-----------|------------|
| **Region / market** | 특정 시장(예: 뉴질랜드)에 있는 방문자에게만 블록 표시 |
| **선택된 통화** | 특정 통화가 활성화된 경우에만 가격 노트나 제안 표시 |
| **선택된 언어** | 특정 언어에서만 콘텐츠 표시 |
| **날짜/시간/요일/영업 시간** | 세일 창 또는 영업 시간 동안 배너 실행 |
| **로그인 상태** | "회원 전용" 콘텐츠 표시 또는 게스트에게 가입 안내 표시 |
| **기기 유형** | 모바일, 태블릿, 데스크탑에서 무엇을 표시하거나 숨길지 결정 |
| **장바구니 가치/품목** | 장바구니가 한도를 초과할 때 무료 배송 안내 표시 |

## 미리 보기

Page Builder 미리보기에서 **시장으로 미리 보기** 및 **방문자로 미리 보기**(샘플 장바구니와 함께 로그인 상태 또는 게스트)를 선택하여 각 대상이 보는 내용을 정확히 확인할 수 있습니다. - 일반적으로 개인적으로 해결되는 방문자별 규칙 포함.

## 팁

- "뉴질랜드 시장", "회원", "모바일 전용"과 같은 잘 정의된 규칙 그룹을 만들고 모든 곳에서 재사용하세요. - 한 번 사용 규칙보다 관리하기가 더 쉽습니다.
- 시장 규칙은 특정 시장 URL에서 모든 사람이 동일한 결과를 얻기 때문에 검색 엔진에 인덱싱되기를 원하는 모든 항목에 대해 안전한 선택입니다.
- 항목이 예기치 않게 사라졌을 경우 연결된 규칙 그룹을 확인하세요. - 항목은 활성 그룹이 있고 현재 방문자와 일치하는 그룹이 하나도 없는 경우에만 숨겨집니다.
