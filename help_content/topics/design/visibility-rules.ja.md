# 表示ルール

表示ルールを使用すると、訪問者が誰か、どこにいるかによって、ストアフロントの一部を表示または非表示にできます。顧客の市場や地域、表示している言語や通貨、1日中の時間、またはログインしているかどうかなどの個々のビジターのシグナルに基づいて、**ページの要素**、**メニューアイテム**、**ヘッダー/フッターのウィジェット**を制限できます。

すべてのものは**ルールグループ**から構築されます: 1つ以上の条件の名前付きで再利用可能なバンドルです。たとえば「ニュージーランド市場」や「ログイン中のメンバー」など、ルールグループを一度作成し、それを制御したい任意の要素、メニューアイテム、ウィジェットに接続します。ルールグループが接続されていない項目は常に表示されます。

## 表示がどのように決定されるか

1つの項目に複数のルールグループが接続されている場合、**どのグループ**が一致しても項目は表示されます (ORで結合されます)。1つのグループ内で、**すべて**または**いずれか**の条件が一致する必要があるかを選択できます。

ルールは2つのファミリーに分かれ、Spwigはそれらを異なる方法で処理して、ストアが高速で検索エンジンに最適な状態を保つようにします:

- **市場ルール** — 地域/市場、言語、通貨、時間に基づく条件。これは、各市場URLでサーバーで決定されるため、そのアドレスにアクセスするすべてのビジター (および検索エンジン) に同じページが一貫して提供されます。これにより、ページがキャッシュ可能でSEOに適した状態になります。
- **個々のビジタールール** — ログイン状態、カートの内容、デバイス、正確な場所。これは個々のビジターに依存するため、Spwigはページが読み込まれた後、それぞれの人にプライベートに解決します。これらは共有キャッシュページに組み込まれることはありません。

ルールグループを無効にすると、適用が停止するだけです — その項目は表示されるようになります。グループを無効にすることは、何かを隠す手段ではありません。

## ルールの作成と接続

ルールグループを操作するには2つの方法があります。

### デザイン時に接続する

どこでコンテンツを制限できるか、**表示制御** (目アイコン) を確認できます:


- **Page Builder** — 要素を選択し、そのプロパティを開けて、表示制限のコントロールを使用してください。
- **Menu Builder** — メニュー項目を選択し、**表示制限**タブを開けてください。

これは、サブメニュー（ドロップダウン）項目など、他の項目の下にネストされている項目を含む、**あらゆる**アイテムで動作します。
子メニュー項目にルールを設定すると、その子メニュー項目のみが非表示になり、他のメニューはそのままでした。
- **Header & Footer Builder** — ウィジェットを選択し、設定の**表示制限ルールグループ**セクションを開けてください。

訪問者の個々の状況に応じたルール（ログインしているかどうか、カートの中身、デバイスなど）は、あなたのストアを遅くすることなく、検索エンジンに影響を与ことなく、それぞれのショッパーに対して解決されます。
あなたの storefront は高速でキャッシュ可能なままとなり、各訪問者が自分用に用意されたナビゲーションのみを表示することになります。

表示制限エディタでは、以下のことができます：

- 既存のルールグループをチェックして**関連付ける**ことができます。
- **クイックルール** — すぐに作成可能な単純なルールグループ（例: メンバーのみ、1つの市場、通貨、デバイス、またはカートの最小価値など）を1ステップで関連付けることができます。
- **ルールグループの管理** — さらなるルール用のフルビルダーにジャンプできます。

**適用**をクリックすると、その項目はすぐに制限されます。

### 一部のルールを構築する

いくつかの条件を組み合わせたり、グループをネストさせたり、細かい演算子を使用するなど、より複雑な作業には、**Design → Visibility Rules**（ルールグループ）に移動してください。ここで、AND/ORロジックでルールを構成し、ストア全体でルールを再利用できます。

## 一般的な条件

| 条件 | これを使用する理由 | 
|-----------|------------| 
| **地域 / マーケット** | 特定のマーケット（例: ニュージーランド）にアクセスした訪問者に対してのみブロックを表示します | 
| **選択された通貨** | 選択された通貨がアクティブなときにのみ価格ノートやオファーを表示します | 
| **選択された言語** | 特定の言語でのみコンテンツを表示します | 
| **日付 / 時刻 / 曜日 / 営業時間** | セールウィンドウや営業時間中のみバナーを表示します | 
| **ログイン状態** | 会員限定のコンテンツを表示する、またはゲストに登録プロンプトを表示する | 
| **デバイスタイプ** | モバイル、タブレット、デスクトップで何かを表示または非表示にする | 
| **カートの価値 / 商品** | カートがしきい値を超えると無料配送のアドバイスを表示します | 

## プレビュー | 

Page Builderのプレビューでは、**マーケットとしてのプレビュー**と**訪問者としてのプレビュー**（サンプルカート付きのサインインまたはゲスト）を**表示できます**。これにより、それぞれのオーディエンスが見る内容を正確に確認できます。これは、通常はプライベートに解決する、訪問者ごとのルールも含めます。 | 

## トゥイク | 

- 小さな数のよく名前がつけられたルールグループ（"ニュージーランド市場", "会員", "モバイルのみ"）を作成し、あらゆる場所で再利用してください。一度きりのルールよりも管理が簡単です。 | 
- サーチエンジンによってインデックスされるものをすべてのための安全な選択肢として、特定のマーケットURLで誰もが同じ結果を得られるようにするため、マーケットルールを使用してください。 | 
- 予期せずにアイテムが表示されなくなった場合は、関連するルールグループを確認してください。アイテムが非表示になるのは、アクティブなグループがあり、そのグループが現在の訪問者に一致しない場合のみです。
