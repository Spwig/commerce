title: 设计与主题

设计与主题系统允许您控制整个商店的外观和感觉 —— 从颜色和字体排版到页眉、页脚和页面布局。导航至 **设置 > 设计与主题** 以打开设计仪表板。

![设计仪表板](/static/core/admin/img/help/design-themes/theme-dashboard.webp)

## 设计仪表板

仪表板为您提供商店设计状态的概览:

- **当前主题** — 显示当前应用的主题，带有预览和快速访问按钮
- **设计统计** — 已安装主题的数量、自定义页眉、自定义页脚和菜单的数量
- **部分卡片** — 跳转至主题、页眉构建器、页脚构建器、菜单或公告

## 主题

### 浏览主题

点击 **主题** 部分卡片以查看所有已安装的主题。每个主题卡片显示:
- 主题名称和预览图片
- 作者和版本
- 激活/非激活状态

### 激活主题

1. 点击您要使用的主题的 **激活**
2. 主题会立即应用到您的商店
3. 同一时间只能有一个主题处于激活状态

### 主题自定义

每个主题都支持一组 **设计标记** —— 可配置的值，用于控制视觉外观而无需编辑代码。

点击您当前主题的 **自定义** 以访问标记编辑器。可用的标记类别包括:

| 类别 | 控制内容 |
|------|-----------|
| **颜色** | 主要颜色、次要颜色、强调颜色、背景色、文字颜色 |
| **排版** | 字体族、大小、粗细、行高 |
| **间距** | 边距、内边距、元素之间的间隙 |
| **边框** | 边框宽度、圆角、颜色 |
| **阴影** | 卡片、按钮、模态框的盒子阴影 |
| **按钮** | 按钮样式、大小、悬停效果 |
| **布局** | 容器宽度、网格间隙、断点 |

在保存之前，更改将实时预览。

## 页眉构建器

页眉构建器允许您使用拖放界面设计商店的页眉。

### 创建页眉

1.

导航至 **设计 > 头部构建器**
2.

点击 **创建头部** 或编辑现有头部
3.

构建器有三个行：**顶部栏**、**主标题** 和 **底部栏**
4.

将小部件从工具箱拖放到任何行

### 可用的头部小部件

- **Logo** — 您的商店标志，可配置大小和链接
- **导航菜单** — 从您定义的菜单中下拉菜单
- **搜索栏** — 产品搜索，即时结果
- **购物车图标** — 小型购物车，带有项目计数徽章
- **账户图标** — 登录/账户下拉菜单
- **语言选择器** — 用于多语言商店的语言切换器
- **货币选择器** — 用于多货币商店的货币切换器
- **运送至选择器** — 允许购物者选择他们的送货目的地国家，切换他们的销售区域（对于多货币商店，货币也会切换）。详见 **地区可用性** 指南以获取详细信息
- **自定义HTML** — 添加任何自定义内容
- **社交图标** — 链接到您的社交媒体资料
- **公告栏** — 促销信息和优惠

### 头部设置

每个头部模板都有全局设置：
- **固定头部** — 当滚动时保持可见
- **透明模式** — 叠加在横幅图片上
- **移动断点** — 何时切换到移动布局

## 页脚构建器

页脚构建器的工作方式与头部构建器类似。

### 创建页脚

1. 导航至 **设计 > 页脚构建器**
2. 点击 **创建页脚** 或编辑现有页脚
3. 构建器支持多列和多行
4. 将小部件拖动到合适的位置

### 可用的页脚小部件

- **导航菜单** — 页脚导航链接
- **新闻简报注册** — 电子邮件订阅表单
- **社交图标** — 社交媒体链接
- **自定义HTML** — 自定义内容、徽章、认证
- **支付图标** — 展示接受的支付方式
- **版权** — 动态版权文本，包含年份
- **Logo** — 页脚logo变体

## 导航菜单

菜单定义了您头部和页脚中的导航链接。

### 创建菜单

1.

导航至 **设计 > 菜单**
2.

点击 **添加菜单**
3.

给菜单命名（例如，"主导航"）
4.

添加菜单项：
   - **页面链接** — 链接到页面构建器页面
   - **分类链接** — 链接到产品分类
   - **自定义URL** — 任何外部或内部URL
   - **下拉菜单** — 嵌套的子菜单项
5.

拖动项目以重新排序
6.

保存并将菜单分配到标题或页脚小部件

## 公告

创建在您的商店前端顶部显示的促销横幅。

### 创建公告

1. 导航至 **设计 > 公告**（或使用仪表板卡片）
2. 点击 **添加公告**
3. 配置：
   - **消息** — 公告文本（支持翻译）
   - **链接** — 点击时的可选URL
   - **样式** — 背景色、文字颜色、图标
   - **计划** — 开始和结束日期
   - **可关闭** — 客户端是否可以关闭
4. 保存并激活

可以同时激活多个公告 — 它们会自动轮换。

## 提示

- 在构建标题和页脚之前，先使用活动主题的自定义器来匹配您的品牌颜色。
- 在发布前使用 **预览** 功能查看标题和页脚构建器中的更改。
- 如果需要非常不同的布局，请为桌面和移动设备创建单独的标题。
- 保持导航简单 — 5-7个顶级菜单项是可用性的理想选择。
- 使用公告进行限时促销，而不是永久性信息。
- 主题标记编辑器支持实时预览 — 自由地进行实验，并在满意时保存。

保留所有markdown格式、图像路径、代码块和术语。
