# กฎการเข้าถึง

กฎการเข้าถึงช่วยให้คุณสามารถแสดงหรือซ่อนส่วนต่าง ๆ ของร้านค้าของคุณได้ตามผู้เยี่ยมชมและที่ตั้งของพวกเขา คุณสามารถกำหนด **องค์ประกอบหน้า**, **รายการเมนู**, และ **ส่วนเสริมหัวข้อ/ท้ายหน้า** ด้วยเงื่อนไขเดียวกัน - ตลาดหรือภูมิภาคของลูกค้า ภาษาหรือส moneta ที่พวกเขาใช้ ช่วงเวลาของวัน หรือสัญญาณเฉพาะผู้เยี่ยมชม เช่น ว่าพวกเขาเข้าสู่ระบบหรือไม่

ทุกสิ่งถูกสร้างขึ้นจาก **กลุ่มกฎ**: ชุดที่มีชื่อ ใช้ซ้ำได้ ของเงื่อนไขหนึ่งตัวขึ้นไป คุณสร้างกลุ่มกฎหนึ่งครั้ง (เช่น "ตลาดนิวซีแลนด์" หรือ "สมาชิกที่เข้าสู่ระบบ") จากนั้นจึงแนบมันกับองค์ประกอบ รายการเมนู หรือส่วนเสริมใด ๆ ที่คุณต้องการให้มันควบคุม รายการที่ไม่มีกลุ่มกฎใด ๆ ถูกต่อไว้ จะแสดงอยู่เสมอ

## วิธีการตัดสินการเข้าถึง

เมื่อมีกลุ่มกฎมากกว่าหนึ่งตัวถูกต่อไว้กับรายการเดียวกัน รายการนั้นจะถูกแสดงหาก **กลุ่มใดกลุ่มหนึ่ง** ที่ต่อไว้ตรงกับเงื่อนไข (พวกเขาใช้ OR) ภายในกลุ่มเดียว คุณเลือกได้ว่า **ทุก** หรือ **บาง** ของเงื่อนไขในกลุ่มต้องตรงกัน

กฎมีอยู่ 2 ประเภท และ Spwig จัดการกับมันต่างกันเพื่อให้ร้านค้าของคุณมีประสิทธิภาพและเป็นมิตรกับเครื่องมือค้นหา:

- **กฎตลาด** — เงื่อนไขเกี่ยวกับภูมิภาค/ตลาด ภาษา ส moneta และเวลา กฎเหล่านี้ถูกตัดสินบนเซิร์ฟเวอร์สำหรับแต่ละ URL ตลาด ดังนั้นหน้าเดียวกันจะถูกส่งไปอย่างเหมือนกันกับผู้เยี่ยมชมทุกคน (และเครื่องมือค้นหาทุกตัว) ที่ที่อยู่นั้น นี่คือการรักษาให้หน้าเว็บสามารถจัดเก็บข้อมูลได้และปลอดภัยต่อ SEO
- **กฎเฉพาะผู้เยี่ยมชม** — สถานะการเข้าสู่ระบบ รายการในตะกร้า อุปกรณ์ และที่ตั้งที่แน่นอน กฎเหล่านี้ขึ้นอยู่กับผู้เยี่ยมชมแต่ละคน ดังนั้น Spwig จึงจัดการกับมันแบบส่วนตัวสำหรับแต่ละคนหลังจากที่หน้าโหลดแล้ว พวกเขาไม่เคยถูกใส่ลงไปในหน้าที่จัดเก็บไว้ร่วมกัน

หากคุณปิดใช้งานกลุ่มกฎ มันก็จะไม่ทำงานแล้ว - รายการที่มันถูกต่อไว้จะกลับมาแสดงอย่างเดิม การปิดใช้งานกลุ่มไม่ได้เป็นวิธีในการซ่อนสิ่งใดสิ่งหนึ่ง

## การสร้างและติดตั้งกฎ

มีสองวิธีในการทำงานกับกลุ่มกฎ

### ติดตั้งที่คุณออกแบบ

ทุกที่ที่คุณสามารถควบคุมเนื้อหา คุณจะเห็น **การควบคุมการเข้าถึง** (รูปสัญลักษณ์สายตา):

รักษารูปแบบ Markdown ทั้งหมด ชื่อไฟล์รูปภาพ บล็อกโค้ด และคำศัพท์ทางเทคนิค

- **ตัวสร้างหน้า (Page Builder)** — เลือกองค์ประกอบหนึ่งตัว แล้วเปิดคุณสมบัติของมัน และใช้การควบคุมการมองเห็น
- **ตัวสร้างเมนู (Menu Builder)** — เลือกไอteam เมนู และเปิด **แท็บการมองเห็น**

นี่ทำงานกับ **ทุกไอteam** รวมถึงไอteam เมนูย่อย (เมนูย่อย) ที่อยู่ภายใต้ไอteamอื่น
- **ตัวสร้างหัวและท้ายหน้า (Header & Footer Builder)** — เลือกส่วนประกอบ และเปิดส่วน **กลุ่มกฎการมองเห็น** ของค่าตั้งค่าของมัน

กฎที่ขึ้นอยู่กับผู้ใช้แต่ละคน เช่น ว่าพวกเขาเข้าสู่ระบบแล้วหรือยัง ของในตะกร้าของพวกเขา หรืออุปกรณ์ของพวกเขา จะถูกประมวลผลสำหรับผู้ใช้แต่ละคนโดยไม่ทำให้ร้านค้าของคุณช้าลงหรือส่งผลต่อเครื่องมือค้นหา ร้านค้าของคุณยังคงเร็วและสามารถจัดเก็บข้อมูลชั่วคราวได้ และผู้ใช้แต่ละคนยังเห็นการนำทางที่เหมาะสมกับพวกเขาเท่านั้น

ในตัวแก้ไขการมองเห็น คุณสามารถ:

- **ติดตั้ง** กลุ่มกฎที่มีอยู่ของคุณโดยการเลือก
- **กฎแบบเร็ว** — สร้างกลุ่มกฎแบบง่ายทันที (เช่น "เฉพาะสมาชิก" ตลาดเดียว เงินสกุล หนึ่งอุปกรณ์ หรือค่าตะกร้าขั้นต่ำ) และติดตั้งในขั้นตอนเดียว
- **จัดการกลุ่มกฎ** — ไปยังตัวสร้างทั้งหมดสำหรับกฎขั้นสูง

คลิก **ใช้** และไอteamจะถูกปิดกั้นทันที

### สร้างกฎขั้นสูง

สำหรับสิ่งที่ซับซ้อนมากขึ้น — การรวมเงื่อนไขหลายอย่าง การซ้อนกลุ่ม หรือตัวดำเนินการที่ละเอียดอ่อน — ไปที่ **ออกแบบ → กฎการมองเห็น** (กลุ่มกฎ) ที่นี่คุณสามารถจัดเรียงกฎด้วยตรรกะ AND/OR และนำกฎเหล่านั้นมาใช้ซ้ำได้ทั่วทั้งร้านค้าของคุณ

## สภาพทั่วไปที่พบบ่อย

ให้รักษารูปแบบมาร์กดาวน์ ชื่อเส้นทางรูปภาพ บล็อกโค้ด และคำศัพท์ทางเทคนิคไว้เดิม

| ข้อกำหนด | ใช้เพื่อ… |
|-----------|------------|
| **ภูมิภาค / ตลาด** | แสดงบล็อกเฉพาะให้กับผู้เยี่ยมชมในตลาดเฉพาะ (เช่น นิวซีแลนด์) |
| **สกุลเงินที่เลือก** | แสดงข้อความเกี่ยวกับราคาหรือข้อเสนอเฉพาะเมื่อสกุลเงินหนึ่งเป็นสกุลที่ใช้งาน |
| **ภาษาที่เลือก** | แสดงเนื้อหาเฉพาะในภาษาที่กำหนด |
| **วันที่ / เวลา / วัน / ช่วงเวลาทำการ** | เปิดตัวแบนเนอร์ในช่วงเวลาการขายหรือเฉพาะในช่วงเวลาทำการเท่านั้น |
| **สถานะการเข้าสู่ระบบ** | แสดงเนื้อหาแบบเฉพาะสมาชิก หรือข้อความแนะนำให้สมัครสมาชิกสำหรับผู้เยี่ยมชม |
| **ประเภทอุปกรณ์** | แสดงหรือซ่อนบางสิ่งบนมือถือ แท็บเล็ต หรือคอมพิวเตอร์ |
| **มูลค่าของตะกร้า / จำนวนสินค้า** | แสดงข้อความแนะนำการจัดส่งฟรีเมื่อมูลค่าของตะกร้าเกินเกณฑ์ |

## การดูตัวอย่าง

ในหน้าการสร้างหน้า (Page Builder) คุณสามารถ **ดูตัวอย่างในตลาด** และ **ดูตัวอย่างผู้เยี่ยมชม** (ที่เข้าสู่ระบบหรือไม่ได้เข้าสู่ระบบ โดยมีตะกร้าตัวอย่าง) เพื่อดูว่าแต่ละกลุ่มเป้าหมายจะเห็นอะไร — รวมถึงกฎที่เกี่ยวข้องกับผู้เยี่ยมชมแต่ละคนที่มักจะถูกแก้ไขโดยไม่เปิดเผย |

## เคล็ดลับ

- สร้างกลุ่มกฎที่มีชื่อชัดเจน ("ตลาดนิวซีแลนด์", "สมาชิก", "เฉพาะมือถือ") และใช้ซ้ำทุกที่ — ง่ายต่อการจัดการมากกว่ากฎที่ใช้เพียงครั้งเดียว |
- กฎเกี่ยวกับตลาดเป็นทางเลือกที่ปลอดภัยสำหรับสิ่งที่คุณต้องการให้ถูกจัดทำดัชนีโดยเครื่องมือค้นหา เนื่องจากผลลัพธ์จะเหมือนกันสำหรับทุกคนที่เข้าถึง URL ของตลาดนั้น |
- หากสิ่งของหายไปโดยไม่ได้ตั้งใจ ให้ตรวจสอบกลุ่มกฎที่เกี่ยวข้อง — สิ่งของจะถูกซ่อนเฉพาะเมื่อมีกลุ่มที่ใช้งานอยู่ และไม่มีกลุ่มใดที่ตรงกับผู้เยี่ยมชมปัจจุบัน
