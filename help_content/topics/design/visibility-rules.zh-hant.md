# 可見規則

可見規則讓您可以根據訪客身分和地點來顯示或隱藏商店的某些部分。您可以根據相同的條件來限制「頁面元素」、「選單項目」和「頁首/頁尾小工具」— 例如顧客的市場或地區、他們正在查看的語言或貨幣、一天中的時間，或與每位訪客相關的信號，例如他們是否已登錄。

所有內容都是基於「規則群組」：一個命名的、可重複使用的條件集合。您只需建立一個規則群組（例如「紐西蘭市場」或「已登錄成員」），然後將它附加到任何您想要控制的元素、選單項目或小工具。沒有附加任何規則群組的項目始終可見。

## 如何判斷可見性

當多個規則群組附加到一個項目時，如果「任何」附加群組符合條件（它們以 OR 組合），就會顯示該項目。在單一群組中，您可以選擇其條件中「所有」或「任何」必須符合。

規則分為兩種類型，Spwig 會以不同方式處理它們，以確保您的商店運行快速且對搜尋引擎友好：

- **市場規則** — 針對地區/市場、語言、貨幣和基於時間的條件。這些在伺服器端根據每個市場網址進行判斷，因此同一頁面會以相同方式傳送給該網址的每位訪客（以及每個搜尋引擎）。這可以保持頁面可快取且 SEO 安全。
- **每位訪客的規則** — 已登錄狀態、購物車內容、裝置和精確地點。這些取決於個別訪客，因此 Spwig 在頁面載入後為每位個人私密解決。它們永遠不會被嵌入到共享的快取頁面中。

如果您停用一個規則群組，它就會停止套用 — 附加到該群組的項目會恢復可見。停用一個群組並不是隱藏某物的方法。

## 創建和附加規則

有兩種方式可以處理規則群組。

### 在您設計的區域中附加它們

只要您可以在該處限制內容，您會看到「可見性控制」（眼睛圖示）：

- **頁面編輯器** — 選擇一個元件，開啟其屬性，並使用可見性控制。
- **選單編輯器** — 選擇一個選單項目並開啟 **可見性** 標籤。

此功能適用於 **任何** 項目，包括巢狀在另一個選單下的子選單（下拉式）項目 —— 子選單的規則只會隱藏該子選單，而不會影響其他選單內容。
- **頁首與頁尾編輯器** — 選擇一個小工具並開啟其設定中的 **可見性規則群組** 組態。

根據個別訪客的條件所設定的規則 —— 例如是否已登入、購物車內容或裝置類型 —— 會針對每位顧客進行解析，不會影響您的商店效能或搜尋引擎優化。您的商店介面保持快速且可快取，每位訪客只會看到適合他們的導覽選單。

在可見性編輯器中，您可以：

- **附加** 任何您已建立的規則群組，勾選即可。
- **快速規則** — 在現場建立一個簡單的規則群組（例如「僅限會員」、單一市場、貨幣、裝置或最低購物金額），並在一步之內附加。
- **管理規則群組** — 跳轉至完整編輯器以建立進階規則。

按一下 **套用**，項目就會立即受到限制。

### 建立進階規則

針對更複雜的需求 —— 組合多個條件、巢狀群組或細微的運算子 —— 請前往 **設計 → 可見性規則**（規則群組）。在那裡，您可以使用 AND/OR 邏輯組裝規則，並在整個商店中重複使用。

## 常見條件

| 條件 | 使用方式 |
|-----------|------------|
| **地區 / 市場** | 僅顯示給特定市場的訪客（例如紐西蘭） |
| **選擇的貨幣** | 當某種貨幣啟用時，顯示定價說明或優惠 |
| **選擇的語言** | 僅顯示特定語言的內容 |
| **日期 / 時間 / 星期 / 營業時間** | 在促銷視窗期間顯示橫幅，或僅在營業時間內顯示 |
| **已登入狀態** | 顯示「會員專屬」內容，或向訪客顯示註冊提示 |
| **裝置類型** | 在行動裝置、平板或桌面裝置上顯示或隱藏某樣東西 |
| **購物車金額 / 物品** | 當購物車金額超過門檻值時顯示免運費提示 |

## 預覽

在 Page Builder 的預覽中，您可以 **以市場身分預覽** 和 **以訪客身分預覽**（已登入或訪客，含範例購物車）以查看每個受眾會看到的內容 —— 包括通常會私密解決的每位訪客規則。

## 小技巧

- 建立一組數量少且命名明確的規則群組（「紐西蘭市場」、「會員」、「僅行動裝置」）並重複使用於所有地方 —— 比起一次性規則更容易管理。
- 市場規則是搜尋引擎索引內容的可靠選擇，因為在特定市場網址下，所有人都會看到相同的結果。
- 如果某個項目意外消失，請檢查其附加的規則群組 —— 僅有活躍群組且其群組中沒有符合當前訪客的群組時，項目才會隱藏。
