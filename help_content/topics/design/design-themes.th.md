ระบบการออกแบบ & รูปแบบช่วยให้คุณควบคุมรูปลักษณ์และสไตล์ของร้านค้าทั้งหมดของคุณ - จากสีและรูปแบบตัวอักษรไปจนถึงหัวข้อ ท้ายหน้า และรูปแบบหน้า ไปที่ **การตั้งค่า > การออกแบบ & รูปแบบ** เพื่อเปิด Dashboard การออกแบบ

![Dashboard การออกแบบ](/static/core/admin/img/help/design-themes/theme-dashboard.webp)

## Dashboard การออกแบบ

 Dashboard นี้แสดงภาพรวมสถานะการออกแบบร้านค้าของคุณ:

- **รูปแบบที่ใช้งานอยู่** — แสดงรูปแบบที่ถูกใช้งานอยู่ในปัจจุบัน พร้อมภาพตัวอย่างและปุ่มเข้าถึงเร็ว
- **สถิติการออกแบบ** — จำนวนรูปแบบที่ติดตั้งแล้ว หัวข้อที่ปรับแต่งเอง ท้ายหน้าที่ปรับแต่งเอง และเมนู
- **บัตรส่วน** — ไปที่รูปแบบ ตัวสร้างหัวข้อ ตัวสร้างท้ายหน้า เมนู หรือประกาศ

## รูปแบบ

### การเลือกรูปแบบ

คลิกที่บัตร **รูปแบบ** เพื่อดูรูปแบบที่ติดตั้งแล้ว แต่ละบัตรรูปแบบแสดง:
- ชื่อรูปแบบและรูปภาพตัวอย่าง
- ผู้แต่งและเวอร์ชัน
- สถานะใช้งาน/ไม่ใช้งาน

### การเปิดใช้งานรูปแบบ

1. คลิก **เปิดใช้งาน** บนรูปแบบที่คุณต้องการใช้
2. รูปแบบจะถูกใช้งานทันทีกับร้านค้าของคุณ
3. สามารถใช้งานรูปแบบได้เพียงรูปแบบเดียวในเวลาเดียวกัน

### การปรับแต่งรูปแบบ

แต่ละรูปแบบรองรับชุดของ **ค่าตัวแปรการออกแบบ** — ค่าที่สามารถตั้งค่าได้ซึ่งควบคุมรูปลักษณ์ทางภาพโดยไม่ต้องแก้ไขโค้ด

คลิก **ปรับแต่ง** บนรูปแบบที่ใช้งานอยู่เพื่อเข้าถึงตัวแก้ไขค่าตัวแปร หมวดหมู่ค่าตัวแปรที่มีอยู่รวมถึง:

| หมวดหมู่ | สิ่งที่ควบคุม |
|----------|-----------------|
| **สี** | สีหลัก สีรอง สีเน้น โทนสีพื้นหลัง สีตัวอักษร |
| **รูปแบบตัวอักษร** | ประเภทฟont ขนาด น้ำหนัก ความสูงของบรรทัด |
| **ระยะห่าง** | ระยะขอบ ระยะห่าง ช่องว่างระหว่างองค์ประกอบ |
| **เส้นขอบ** | ความหนาของเส้นขอบ รัศมี สี |
| **เงา** | เงาของบัตร ปุ่ม หน้าต่างที่ปรากฏขึ้น |
| **ปุ่ม** | รูปแบบ ขนาด ผลการคลิกของปุ่ม |
| **รูปแบบการจัดวาง** | ความกว้างของตัวจัดวาง ช่องว่างของกริด จุดเปลี่ยน |

การเปลี่ยนแปลงจะแสดงผลแบบเรียลไทม์ก่อนที่คุณจะบันทึก

## ตัวสร้างหัวข้อ

ตัวสร้างหัวข้อช่วยให้คุณออกแบบหัวข้อของร้านค้าของคุณโดยใช้อินเตอร์เฟซลากและวาง

### การสร้างหัวข้อ

1.

ไปที่ **การออกแบบ > ตัวสร้างหัวหน้า**
2.

คลิก **สร้างหัวหน้า** หรือแก้ไขหัวหน้าที่มีอยู่แล้ว
3.

ตัวสร้างมี 3 แถว: **แถบบน**, **หัวหน้าหลัก**, และ **แถบล่าง**
4.

ลากวิดเจ็ตจากกล่องเครื่องมือเข้าไปในแถวใดก็ได้

### วิดเจ็ตหัวหน้าที่มีอยู่

- **โลโก้** — โลโก้ร้านค้าของคุณที่สามารถปรับขนาดและลิงก์ได้
- **เมนูนำทาง** — เมนูย่อยจากเมนูที่คุณกำหนดไว้
- **แถบค้นหา** — การค้นหาสินค้าพร้อมผลลัพธ์แบบทันที
- **ไอคอนตะกร้า** — ตะกร้าสินค้าแบบย่อมีป้ายจำนวนสินค้า
- **ไอคอนบัญชี** — เมนูย่อยสำหรับเข้าสู่ระบบ/บัญชี
- **ตัวเลือกภาษา** — ตัวเลือกเปลี่ยนภาษาสำหรับร้านค้าหลายภาษา
- **ตัวเลือกสกุลเงิน** — ตัวเลือกเปลี่ยนสกุลเงินสำหรับร้านค้าหลายสกุลเงิน
- **ตัวเลือกประเทศจัดส่ง** — ให้ผู้ซื้อเลือกประเทศที่ต้องการจัดส่ง ซึ่งจะเปลี่ยนพื้นที่ขายของพวกเขา (และสกุลเงิน สำหรับร้านค้าหลายสกุลเงิน) ดูคู่มือ **การเข้าถึงพื้นที่** สำหรับรายละเอียดเพิ่มเติม
- **HTML ที่กำหนดเอง** — เพิ่มเนื้อหาที่กำหนดเองทั้งหมด
- **ไอconโซเชียลมีเดีย** — ลิงก์ไปยังโปรไฟล์โซเชียลมีเดียของคุณ
- **แถบประกาศ** — ข้อความโปรโมชั่นและข้อเสนอ

### การตั้งค่าหัวหน้า

แต่ละรูปแบบหัวหน้ามีการตั้งค่าทั่วไป:
- **หัวหน้าที่ยึดติด** — หัวหน้าจะยังคงอยู่เมื่อเลื่อนลง
- **โหมดโปร่งใส** — ครอบคลุมรูปภาพฮีโร่
- **จุดเปลี่ยนโหมดมือถือ** — เมื่อใดที่จะเปลี่ยนไปใช้รูปแบบมือถือ

## ตัวสร้าง Footer

ตัวสร้าง Footer มีการทำงานที่คล้ายกับตัวสร้างหัวหน้า

### การสร้าง Footer

1. ไปที่ **การออกแบบ > ตัวสร้าง Footer**
2. คลิก **สร้าง Footer** หรือแก้ไข Footer ที่มีอยู่แล้ว
3. ตัวสร้างนี้รองรับหลายคอลัมน์และแถว
4. ลากวิดเจ็ตเข้าที่ตั้ง

### วิดเจ็ต Footer ที่มีอยู่

- **เมนูนำทาง** — ลิงก์นำทางใน Footer
- **การสมัครสมาชิกข่าวสาร** — ฟอร์มสมัครรับข่าวสารทางอีเมล
- **ไอคอนโซเชียลมีเดีย** — ลิงก์ไปยังโซเชียลมีเดียของคุณ
- **HTML ที่กำหนดเอง** — เนื้อหาที่กำหนดเอง ป้ายกำกับ ใบรับรอง
- **ไอคอนการชำระเงิน** — แสดงวิธีการชำระเงินที่ได้รับการยอมรับ
- **ลิขสิทธิ์** — ข้อความลิขสิทธิ์แบบไดนามิกพร้อมปี
- **โลโก้** — รูปแบบโลโก้ใน Footer

## เมนูนำทาง

เมนูกำหนดลิงก์นำทางในหัวหน้าและ Footer ของคุณ

### การสร้างเมนู

1.

ไปที่ **การออกแบบ > เมนู**
2.

คลิก **เพิ่มเมนู**
3.

ตั้งชื่อเมนู (เช่น "การนำทางหลัก")
4.

เพิ่มรายการเมนู:
   - **ลิงก์หน้า** — ลิงก์ไปยังหน้าที่สร้างด้วย Page Builder
   - **ลิงก์ประเภท** — ลิงก์ไปยังประเภทสินค้า
   - **URL ทั่วไป** — URL ภายนอกหรือภายในที่คุณต้องการ
   - **เมนูย่อย** — รายการย่อยที่ซ้อนกัน
5.

ลากจัดเรียงรายการ
6.

บันทึกและกำหนดเมนูให้กับส่วนหัวหรือส่วนท้าย

## การประกาศข่าวสาร

สร้างแบนเนอร์โปรโมชั่นที่แสดงอยู่ด้านบนของร้านค้าของคุณ

### การสร้างการประกาศข่าวสาร

1. ไปที่ **การออกแบบ > การประกาศข่าวสาร** (หรือใช้การ์ดแดชบอร์ด)
2. คลิก **เพิ่มการประกาศข่าวสาร**
3. ตั้งค่า:
   - **ข้อความ** — ข้อความของการประกาศ (รองรับการแปล)
   - **ลิงก์** — URL ที่สามารถคลิกได้ (ไม่จำเป็น)
   - **สไตล์** — สีพื้นหลัง สีตัวอักษร รูปสัญลักษณ์
   - **กำหนดเวลา** — วันเริ่มต้นและวันสิ้นสุด
   - **สามารถปิดได้** — ลูกค้าสามารถปิดได้หรือไม่
4. บันทึกและเปิดใช้งาน

การประกาศข่าวสารหลายรายการสามารถใช้งานได้พร้อมกัน - จะหมุนโดยอัตโนมัติ

## เคล็ดลับ

- เริ่มต้นด้วยตัวปรับแต่งธีมปัจจุบันเพื่อให้ตรงกับสีแบรนด์ของคุณก่อนที่จะสร้างส่วนหัวและส่วนท้าย
- ใช้ฟีเจอร์ **การดูตัวอย่าง** ในตัวสร้างส่วนหัวและส่วนท้ายเพื่อดูการเปลี่ยนแปลงก่อนที่จะเผยแพร่
- สร้างส่วนหัวแยกสำหรับคอมพิวเตอร์และมือถือหากคุณต้องการรูปแบบที่แตกต่างกันมาก
- รักษาการนำทางให้ง่าย - จำนวนรายการระดับแรก 5-7 รายการเป็นตัวเลือกที่ดีสำหรับการใช้งาน
- ใช้การประกาศข่าวสารสำหรับโปรโมชั่นที่มีข้อจำกัดด้านเวลาแทนข้อความที่ไม่มีวันสิ้นสุด
- ตัวแก้ไขโทเคนธีมรองรับการดูตัวอย่างแบบเรียลไทม์ - ทดลองได้อย่างอิสระและบันทึกเมื่อคุณพอใจ
