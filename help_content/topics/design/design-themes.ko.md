---
title: 디자인 및 테마
---

디자인 및 테마 시스템은 전체 스토어의 스타일을 제어할 수 있는 도구입니다. 색상, 타이포그래피, 헤더, 푸터, 페이지 레이아웃에 이르기까지 모든 요소를 관리할 수 있습니다. 디자인 대시보드를 여려면 **설정 > 디자인 및 테마**로 이동하십시오.

![디자인 대시보드](/static/core/admin/img/help/design-themes/theme-dashboard.webp)

## 디자인 대시보드

대시보드는 스토어 디자인 상태에 대한 개요를 제공합니다:

- **활성 테마** — 현재 적용된 테마를 보여주며 미리보기 및 빠른 접근 버튼 제공
- **디자인 통계** — 설치된 테마 수, 사용자 정의 헤더, 사용자 정의 푸터, 메뉴 수
- **섹션 카드** — 테마, 헤더 빌더, 푸터 빌더, 메뉴, 공지사항으로 이동

## 테마

### 테마 탐색

**테마** 섹션 카드를 클릭하여 설치된 모든 테마를 확인하십시오. 각 테마 카드에는 다음이 표시됩니다:
- 테마 이름 및 미리보기 이미지
- 저자 및 버전
- 활성/비활성 상태

### 테마 활성화

1. 사용하려는 테마의 **활성화**를 클릭하십시오
2. 테마가 즉시 스토어에 적용됩니다
3. 동시에 하나의 테마만 활성화될 수 있습니다

### 테마 맞춤 설정

각 테마는 코드를 수정하지 않고 시각적 표시를 제어하는 설정 가능한 값인 **디자인 토큰** 세트를 지원합니다.

활성 테마의 **맞춤 설정**을 클릭하여 토큰 편집기를 열 수 있습니다. 사용 가능한 토큰 범주는 다음과 같습니다:

| 범주 | 제어하는 내용 |
|----------|-----------------|
| **색상** | 주요 색상, 보조 색상, 강조 색상, 배경색, 텍스트 색상 |
| **타이포그래피** | 폰트 가족, 크기, 굵기, 줄 간격 |
| **공간** | 요소 간 마진, 패딩, 간격 |
| **테두리** | 테두리 두께, 반경, 색상 |
| **그림자** | 카드, 버튼, 모달에 대한 상자 그림자 |
| **버튼** | 버튼 스타일, 크기, 호버 효과 |
| **레이아웃** | 컨테이너 너비, 그리드 간격, 브레이크포인트 |

변경 사항은 저장하기 전에 실시간으로 미리 확인할 수 있습니다.

## 헤더 빌더

헤더 빌더는 드래그 앤 드롭 인터페이스를 사용하여 스토어 헤더를 디자인할 수 있는 도구입니다.

### 헤더 생성

1.

Design > Header Builder로 이동하세요

2.

**헤더 생성**을 클릭하거나 기존 헤더를 편집하세요

3.

빌더에는 세 가지 행이 있습니다: **상단 바**, **메인 헤더**, 및 **하단 바**

4.

도구 상자에서 위젯을 어떤 행이든으로 끌어다 놓으세요

### 사용 가능한 헤더 위젯

- **로고** — 사용자가 정의할 수 있는 크기와 링크가 있는 스토어 로고
- **탐색 메뉴** — 사용자가 정의한 메뉴에서 드롭다운 메뉴
- **검색 막대** — 실시간 결과가 있는 상품 검색
- **장바구니 아이콘** — 항목 수 카운트가 있는 미니 장바구니
- **계정 아이콘** — 로그인/계정 드롭다운
- **언어 선택기** — 다국가 상점을 위한 언어 전환기
- **화폐 선택기** — 다화폐 상점을 위한 화폐 전환기
- **배송지 선택기** — 고객이 배송 목적지 국가를 선택하도록 하여 판매 지역(다화폐 상점의 경우 화폐 포함)을 전환합니다. 자세한 내용은 **지역 가용성** 가이드를 참조하십시오
- **사용자 정의 HTML** — 어떤 사용자 정의 콘텐츠든 추가할 수 있습니다
- **소셜 아이콘** — 소셜 미디어 프로필로의 링크
- **공지사항 바** — 프로모션 메시지 및 제안

### 헤더 설정

각 헤더 템플릿에는 글로벌 설정이 있습니다:
- **스티키 헤더** — 스크롤 시 헤더가 보이도록 유지합니다
- **투명한 모드** — 헤드 이미지 위에 오버레이합니다
- **모바일 브레이크포인트** — 모바일 레이아웃으로 전환할 시점

## 푸터 빌더

푸터 빌더는 헤더 빌더와 유사하게 작동합니다.

### 푸터 만들기

1. **디자인 > 푸터 빌더**로 이동하세요
2. **푸터 생성**을 클릭하거나 기존 푸터를 편집하세요
3. 빌더는 여러 열과 행을 지원합니다
4. 위젯을 위치에 끌어다 놓으세요

### 사용 가능한 푸터 위젯

- **탐색 메뉴** — 푸터 탐색 링크
- **뉴스레터 가입** — 이메일 구독 양식
- **소셜 아이콘** — 소셜 미디어 링크
- **사용자 정의 HTML** — 사용자 정의 콘텐츠, 뱃지, 인증서
- **결제 아이콘** — 인증된 결제 수단 표시
- **저작권** — 동적 저작권 텍스트(년도 포함)
- **로고** — 푸터 로고 버전

## 탐색 메뉴

메뉴는 헤더 및 푸터의 탐색 링크를 정의합니다.

### 메뉴 만들기

1.

Design > 메뉴로 이동하세요
2.
**메뉴 추가**를 클릭하세요
3.
메뉴에 이름을 지정하세요 (예: "메인 탐색")
4.
메뉴 항목을 추가하세요:
   - **페이지 링크** — 페이지 빌더 페이지로 연결
   - **카테고리 링크** — 상품 카테고리로 연결
   - **사용자 정의 URL** — 외부 또는 내부 URL
   - **드롭다운** — 중첩된 하위 메뉴 항목
5.
아이템을 끌어 이동하여 순서를 정하세요
6.
메뉴를 헤더 또는 푸터 위젯에 할당하고 저장하세요

## 공지사항

스토어의 상단에 표시되는 프로모션 배너를 만드세요.

### 공지사항 생성하기

1. **디자인 > 공지사항**으로 이동하세요 (대시보드 카드를 사용할 수도 있음)
2. **공지사항 추가**를 클릭하세요
3. 구성:
   - **메시지** — 공지사항 텍스트 (번역을 지원함)
   - **링크** — 클릭 시 선택적 URL
   - **스타일** — 배경 색상, 텍스트 색상, 아이콘
   - **일정** — 시작 및 종료 날짜
   - **닫기 가능** — 고객이 닫을 수 있는지 여부
4. 저장 및 활성화

동시에 여러 개의 공지사항을 활성화할 수 있습니다. 자동으로 회전합니다.

## 팁

- 헤더 및 푸터를 만들기 전에 활성 테마의 커스터마이저에서 브랜드 색상을 맞추세요.
- 헤더 및 푸터 빌더에서 **미리보기** 기능을 사용하여 게시하기 전에 변경 사항을 확인하세요.
- 매우 다른 레이아웃이 필요한 경우 데스크탑 및 모바일용 별도 헤더를 만드세요.
- 탐색을 간단하게 유지하세요. 사용성에 이상적인 상위 수준 메뉴 항목은 5~7개입니다.
- 영구 메시지보다는 시간 제한 프로모션을 위한 공지사항을 사용하세요.
- 테마 토큰 편집기는 실시간 미리보기 기능을 지원합니다. 자유롭게 실험하고 만족할 때까지 저장하세요.
