# 可见性规则

可见性规则允许您根据访问者身份和位置来显示或隐藏商店的某些部分。您可以根据相同条件来限制**页面元素**、**菜单项**和**页眉/页脚小部件**— 例如客户的市场或地区、他们正在查看的语言或货币、一天中的时间，或基于访问者的信号，如是否已登录。

所有内容都基于**规则组**构建：一个命名的、可重用的一组条件。您只需创建一个规则组（例如，"新西兰市场" 或 "已登录成员"），然后将其附加到任何您希望它控制的元素、菜单项或小部件上。未附加任何规则组的项目始终可见。

## 如何决定可见性

当一个项目附加了多个规则组时，如果**任何**附加组匹配，就会显示该项目（它们使用 OR 组合）。在一个组内部，您可以选择其条件必须匹配**所有**或**任何**。

规则分为两个家族，Spwig 会以不同方式处理它们，以确保您的商店保持快速且对搜索引擎友好：

- **市场规则** — 区域/市场、语言、货币和基于时间的条件。这些在每个市场 URL 上由服务器决定，因此该地址的每个访问者（包括每个搜索引擎）都会收到完全相同的页面。这保持了页面的可缓存性和 SEO 安全性。
- **基于访问者的规则** — 已登录状态、购物车内容、设备和精确位置。这些依赖于个别访问者，因此 Spwig 在页面加载后为每个人私密地解析它们。它们永远不会被烘焙到共享的缓存页面中。

如果您禁用一个规则组，它就会停止应用 — 附加到它的项目会恢复可见。禁用一个组并不是隐藏某物的方法。

## 创建和附加规则

有两种方法可以处理规则组。

### 在您设计的地方附加它们

无论您可以在哪里限制内容，您都会看到一个 **可见性控制**（眼睛图标）：

- **Page Builder** — 选择一个元素，打开其属性，并使用可见性控制。
- **Menu Builder** — 选择一个菜单项并打开 **Visibility** 选项卡。

此功能适用于 **任何** 项目，包括嵌套在另一个菜单项下的子菜单（下拉菜单）项 —— 子项的规则仅隐藏该子项，而不会影响菜单的其余部分。
- **Header & Footer Builder** — 选择一个小工具并打开其设置中的 **Visibility Rule Groups** 部分。

基于个别访客的规则 —— 是否已登录、购物车内容或设备类型 —— 会为每位顾客单独解析，而不会减慢您的商店或影响搜索引擎。您的店铺保持快速且可缓存，每位访客仍然只能看到适合他们的导航。

在可见性编辑器中，您可以：

- **附加** 任何现有的规则组，通过勾选它们。
- **快速规则** —— 现场创建一个简单的规则组（例如“仅限会员”，一个市场，一种货币，一个设备，或最低购物车价值）并一步附加。
- **管理规则组** —— 跳转到完整构建器以创建高级规则。

点击 **Apply**，该项目将立即受到限制。

### 构建高级规则

对于更复杂的操作 —— 组合多个条件、嵌套组或细粒度操作符 —— 请转到 **Design → Visibility Rules**（规则组）。在那里，您可以使用 AND/OR 逻辑组装规则，并在整个商店中重复使用它们。

## 常见条件

| 条件 | 使用它来... |
|-----------|------------|
| **地区 / 市场** | 仅向特定市场的访客显示一个区块（例如，新西兰） |
| **选定的货币** | 当特定货币处于活动状态时显示价格说明或优惠 |
| **选定的语言** | 仅以特定语言显示内容 |
| **日期 / 时间 / 星期 / 营业时间** | 在销售窗口期间或仅在营业时间运行横幅 |
| **登录状态** | 显示"仅限会员"内容，或向访客显示注册提示 |
| **设备类型** | 在移动设备、平板或桌面设备上显示或隐藏某些内容 |
| **购物车价值 / 商品** | 当购物车超过一定金额时显示免费配送提示 |

## 预览

在 Page Builder 预览中，您可以 **以市场身份预览** 和 **以访客身份预览**（登录或访客，带有示例购物车）以查看每个受众会看到什么内容 —— 包括通常在私密状态下解析的访客规则。

## 提示

- 构建一组命名良好的规则组（"新西兰市场"、"会员"、"仅移动设备"）并到处复用它们 —— 比起一次性规则更容易管理。
- 市场规则是搜索引擎索引的首选，因为对于给定市场 URL 的每个人来说结果都是一样的。
- 如果某个项目意外消失，请检查其关联的规则组 —— 仅当它有一个活动组且其任何组都不匹配当前访客时，该项目才会被隐藏。
