---
title: デザインとテーマ
---

デザインとテーマシステムを使用すると、色やフォント、ヘッダー、フッター、ページレイアウトに至るまで、ストア全体の見た目と感触を制御できます。デザインダッシュボードを開くには、**設定 > デザインとテーマ**に移動してください。

![デザインダッシュボード](/static/core/admin/img/help/design-themes/theme-dashboard.webp)

## デザインダッシュボード

ダッシュボードでは、ストアのデザイン状態の概要が確認できます。

- **アクティブなテーマ** — 今現在適用されているテーマを表示し、プレビューと素早くアクセスできるボタンを提供します
- **デザイン統計** — インストールされたテーマの数、カスタムヘッダー、カスタムフッター、メニューやアノンスメントの数
- **セクションカード** — テーマ、ヘッダーのビルド、フッターのビルド、メニューやアノンスメントにジャンプできます

## テーマ

### テーマのブラウズ

**テーマ**セクションカードをクリックして、すべてのインストール済みテーマを確認してください。各テーマカードには、以下が表示されます:
- テーマ名とプレビュー画像
- 作成者とバージョン
- 有効/非表示ステータス

### テーマの有効化

1. 使用したいテーマの**有効**をクリックしてください
2. テーマは即座にストアフロントに適用されます
3. 一度に1つのテーマしか有効にできません

### テーマのカスタマイズ

各テーマは、コードを編集することなく視覚的な外観を制御するための**デザイントークン**のセットをサポートしています。

アクティブなテーマの**カスタマイズ**をクリックして、トークンエディタにアクセスしてください。利用可能なトークンカテゴリには、以下が含まれます:

| カテゴリ | 制御内容 |
|----------|----------|
| **カラーパレット** | メイン、セカンダリ、アクセントカラー、背景、テキストカラー |
| **フォント** | フォントファミリー、サイズ、太さ、行間 |
| **スペース** | マージン、パディング、要素間のギャップ |
| **ボーダー** | ボーダーの太さ、ラウンド、色 |
| **シャドウ** | カード、ボタン、モーダルのボックスシャドウ |
| **ボタン** | ボタンスタイル、サイズ、ホバー効果 |
| **レイアウト** | コンテナの幅、グリッドギャップ、ブレイクポイント |

変更内容は保存する前にリアルタイムでプレビューされます。

## ヘッダーのビルド

ヘッダーのビルド機能を使用すると、ドラッグ＆ドロップインターフェースを使ってストアのヘッダーをデザインできます。

### ヘッダーの作成

1.

デザイン > ヘッダー ビルダー に移動してください
2.

**ヘッダーを作成** または既存のヘッダーを編集してください
3.

ビルダーには3つの行があります: **トップ バー**, **メイン ヘッダー**, および **ボトム バー**
4.

ツールボックスからウィジェットをドラッグして、任意の行に配置してください

### 利用可能なヘッダー ウィジェット

- **ロゴ** — 画像サイズやリンクをカスタマイズ可能なストアのロゴ
- **ナビゲーション メニュー** — 定義されたメニューからのドロップダウン メニュー
- **検索バー** — 一時的な結果付きの製品検索
- **カート イコン** — アイテム数のバッジ付きのミニカート
- **アカウント イコン** — ログイン/アカウントドロップダウン
- **言語セレクター** — 複数言語対応のストア用の言語スイッチャー
- **通貨セレクター** — 複数通貨対応のストア用の通貨スイッチャー
- **配送先セレクター** — 買い物客が配送先の国を選択できるようにし、販売地域 (複数通貨対応ストアの場合は通貨) を切り替えることができます。詳細は **地域の利用可能状況** ガイドを参照してください
- **カスタム HTML** — 任意のカスタム コンテンツを追加
- **ソーシャル イコン** — フォロワー用のソーシャル メディア プロファイルへのリンク
- **アンナンスメント バー** — プロモーションメッセージやオファー

### ヘッダー設定

各ヘッダー テンプレートにはグローバル設定があります:
- **スタックヘッダー** — スクロール時にヘッダーが表示されます
- **トランスペアレント モード** — ヘッダー画像にオーバーレイ
- **モバイル ブレイクポイント** — モバイルレイアウトに切り替えるタイミング

## フッター ビルダー

フッター ビルダーはヘッダー ビルダーと同様の動作をします。

### フッターの作成

1. **デザイン > フッター ビルダー** に移動してください
2. **フッターの作成** または既存のフッターを編集してください
3. ビルダーは複数列と行をサポートしています
4. ウィジェットを位置にドラッグしてください

### 利用可能なフッター ウィジェット

- **ナビゲーション メニュー** — フッターのナビゲーション リンク
- **ニュースレター登録** — メール購読フォーム
- **ソーシャル イコン** — ソーシャル メディア リンク
- **カスタム HTML** — カスタム コンテンツ、バッジ、認証
- **決済アイコン** — 取り入れた決済方法を表示
- **著作権** — 年付きの動的著作権テキスト
- **ロゴ** — フッター用ロゴのバージョン

## ナビゲーション メニュー

メニューはヘッダーとフッターのナビゲーション リンクを定義します。

### メニューの作成

1.

Design > メニュー に移動してください
2.
**メニューの追加** をクリックします
3.
メニューに名前を付けます（例: "メインナビゲーション"）
4.
メニュー項目を追加します:
   - **ページリンク** — ページビルダーのページへのリンク
   - **カテゴリーリンク** — 製品カテゴリへのリンク
   - **カスタムURL** — 任意の外部または内部URL
   - **ドロップダウン** — ネストされたサブメニュー項目
5.
項目をドラッグして順序を変更します
6.
ヘッダーまたはフッターのウィジェットにメニューを保存して割り当てます

## お知らせ

ストアフロントの上部に表示されるプロモーションバナーを作成します。

### お知らせの作成

1. **Design > Announcements** に移動します（ダッシュボードカードを使用することもできます）
2. **お知らせの追加** をクリックします
3. 設定:
   - **メッセージ** — お知らせのテキスト（翻訳をサポート）
   - **リンク** — クリック時にオプションのURL
   - **スタイル** — 背景色、テキスト色、アイコン
   - **スケジュール** — 開始日と終了日
   - **閉じる** — 顧客が閉じることができるかどうか
4. 保存して有効にします

複数のお知らせを同時に有効にすることができます — 自動的に回転します。

## トゥイット

- ヘッダーとフッターを構築する前に、アクティブなテーマのカスタマイザーからブランドカラーに合わせてください。
- ヘッダーおよびフッターのビルダーで**プレビュー**機能を使用して、公開する前に変更を確認してください。
- 要件によっては、デスクトップ用とモバイル用に別のヘッダーを作成してください。
- ナビゲーションをシンプルに保つ — ユーザビリティには5〜7つのトップレベルのメニューアイテムが理想的です。
- 永続的なメッセージではなく、期間限定のプロモーション用にお知らせを使用してください。
- テーマトークンエディタはリアルタイムプレビューをサポートしています — 実験的に freely に実行し、満足がいくまで保存してください。
