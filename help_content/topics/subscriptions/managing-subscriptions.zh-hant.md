---
title: 管理客戶訂閱
---

客戶訂閱部分讓您全面了解商店中所有活躍、暫停和取消的定期訂閱。從這裡您可以監控帳單健康狀況，查看單個訂閱明細，並在出現問題時採取行動。

## 查看客戶訂閱

導覽至 **Subscriptions > Customer Subscriptions** 以查看所有客戶的訂閱清單。

![客戶訂閱清單](/static/core/admin/img/help/managing-subscriptions/subscription-list.webp)

清單顯示每個訂閱的客戶、方案名稱、當前狀態、下次結帳日期以及已完成的結帳週期數。

### 篩選和搜尋

使用右側的篩選面板來根據以下條件縮小訂閱範圍：

- **狀態** — 依活躍、試用、逾期、暫停、取消或過期篩選
- **方案** — 查看特定方案的訂閱
- **提供者模式** — 內建（Stripe/PayPal管理）或備用（內部結帳）

使用搜尋欄透過客戶電子郵件地址尋找訂閱。

## 訂閱狀態

了解每個狀態有助於識別需要關注的訂閱：

| 狀態 | 代表含義 |
|--------|---------------|
| **試用** | 客戶處於免費或減價試用期 |
| **活躍** | 訂閱狀態健康 — 結帳及時且存取權限活躍 |
| **逾期** | 付款嘗試失敗 — 系統正在重試。在寬限期內客戶仍可存取 |
| **暫停** | 訂閱暫時中止 — 無結帳，無存取 |
| **取消** | 取消請求已提交。客戶可能仍可存取至週期結束日期 |
| **過期** | 訂閱已完全結束 — 試用期過期、達到最大結帳週期或取消週期已過 |

需要最多關注的訂閱是 **逾期** 狀態的訂閱 — 如果付款持續失敗且寬限期結束，訂閱將會被暫停。

## 查看訂閱的明細

保留所有 markdown 格式、圖片路徑、程式碼區塊和技術術語。

點擊任何訂閱以打開詳細檢視。

這顯示了：

### 当前計費週期

- **當前週期開始 / 結束** — 活動計費視窗的日期
- **下次計費日期** — 下一次收費嘗試的日期
- **上次計費日期** 和 **上次計費狀態** — 最近一次計費嘗試的結果
- **計費週期數** — 已完成的成功的計費週期數量

### 訂閱資訊

- **方案** 和 **定價等級** — 客戶所使用的方案和計費頻率
- **產品 / 變體** — 與此訂閱關聯的目錄產品（如果適用）
- **數量** — 座位或單位數量（用於數量基礎的方案）
- **付款金鑰** — 用於重複計費的存儲付款方式

### 試用詳情

如果訂閱處於試用期，**試用結束日期** 顯示客戶的試用期何時到期，並開始正式計費。

### 取消詳情

對於已取消的訂閱，您可以查看：

- **取消類型** — 取消是立即生效、在週期結尾生效，還是已排程
- **取消時間** — 取消請求的時間
- **取消原因** — 關於客戶取消原因的備註（如果已記錄）
- **重新啟用截止日期** — 客戶可以在不從頭開始重新訂閱的情況下重新啟用的最後日期

### 容限期和承諾

- **容限期結束日期** — 如果一筆付款失敗，這顯示在訪問被暫停前的截止日期
- **最低承諾期結束日期** — 對於有最低承諾期的方案，最早可取消的日期

## 暫停訂閱

暫停的訂閱會暫時停止計費，同時也暫停訪問。這對想要暫時放棄但不完全取消的客戶很有用。

要查看暫停的訂閱，請過濢 **狀態: 暫停**。詳細檢視顯示：

- **暫停時間** — 暫停開始的時間
- **暫停原因** — 暫停的備註
- **自動恢復日期** — 如果設置，則為訂閱自動恢復收費和訪問的日期

訂閱會在自動恢復日期恢復，或者在客戶手動重新激活後恢復。

## 計費週期記錄

每次計費嘗試（無論成功或失敗）都會記錄在計費週期記錄中。導航至 **訂閱 > 計費週期記錄** 以查看此歷史記錄。

![計費週期記錄清單](/static/core/admin/img/help/managing-subscriptions/billing-cycle-log.webp)

### 讀取計費週期記錄條目

每個記錄條目會記錄以下內容:

- **訂閱** — 這筆計費嘗試所屬的客戶訂閱
- **週期編號** — 連續計費週期（週期 1 = 試用期後的第一次收費）
- **計費日期** — 該筆費用嘗試的日期
- **狀態** — 等待中、處理中、成功、失敗或重試中
- **金額細節**:
  - **基本金額** — 在任何調整之前的計畫價格
  - **數量金額** — 對於座位/單位數量的額外費用
  - **附加費用金額** — 活動附加費用的總成本
  - **折扣金額** — 所有套用的折扣總額
  - **總金額** — 最終收費金額（或嘗試收費的金額）
- **付款方式** — 使用的卡或付款方式
- **供應商交易ID** — 付款供應商的參考編號（有利於退款查詢）
- **失敗原因** — 如果計費失敗，為何失敗（例如，卡被拒絕、資金不足）

### 計費失敗的診斷

如果客戶聯繫您關於計費問題，請找到他們的訂閱並檢查計費週期記錄。**失敗原因** 字段會說明出了什麼問題。常見的失敗原因包括：

- **信用卡被拒** — 客戶的信用卡被銀行拒絕
- **餘額不足** — 結帳時帳戶餘額不夠
- **信用卡過期** — 儲存的付款方式已過期
- **網路錯誤** — 支付提供者暫時連線問題 — 通常重試後會解決

如持續失敗，請引導客戶在帳戶設定中更新付款方式。

## 繳費如何處理

每次成功的續費扣款會為該帳單週期產生一個全新的已付款訂單 — 不只是付款紀錄。該訂單會透過您正常的履行流程，與結帳時下單的訂單完全一樣：

- **實體商品** — 繳費訂單會進入您常規的履行併發排程進行揀選、包裝和運送。在信用卡扣款的瞬間，庫存不會自動分配，因此庫存短編不會阻擋已成功的扣款 — 您仍會看到訂單並可根據庫存情況進行履行。
- **數位商品** — 一旦產生續費訂單，就會自動重新授予存取權（下載連結、授權金鑰），與首次購買時的方式相同。

續費訂單會複製啟動訂閱的訂單的運費和賬單細節，因此您不需要重新輸入任何內容。在您的 **訂單** 清單中不會顯示特殊標籤，但您可以隨時追蹤特定週期回溯到其訂單：開啟 **訂閱 > 計費週期日誌**，點擊該週期的日誌條目，**訂單** 欄位會直接連結到該訂單。

## 自動訂閱電子郵件

Spwig 會自動發送訂閱生命週期電子郵件 — 您不需要手動觸發這些。商家最常詢問的電子郵件：

| 電子郵便 | 何時送信されるか |
|-------|----------------|
| **更新のリマインダー** | 予定されている更新料の前 |
| **トライアル終了** | 無料または割引料金のトライアルが本格的な請求に変換される前に |
| **支払い失敗** | 更新料の支払いに失敗した後、すぐに送信され、猶予期間が終了する直前に最終的な注意喚起として再送信されます（デューディレーション） |
| **キャンセル確認** | サブスクリプションがキャンセルされたとき |

Spwig は、サブスクリプションのライフサイクルにおける関連するポイントで、ウェルカム、支払い成功、一時停止/再開、有効期限切れ、再活性化、プラン変更、支払い方法の有効期限切れのメールも送信します。これらすべては通常の電子メールテンプレートです。[メールテンプレート](/help/email-templates)を参照して、中身を確認またはカスタマイズし、有効であることを確認してください。

## カスタマーセルフサービス

カスタマーは通常のサブスクリプションの変更についてあなたに連絡する必要がありません。彼らは自分のアカウントからサブスクリプションを管理できます。詳細や支払い履歴の表示、一時停止、再開、キャンセル、およびファイル上の支払い方法の更新が可能です。これは、あなたへのサポートの問い合わせにあたる多くの問題をカバーしており、カスタマーがサブスクリプションについて問い合わせた場合は、あなたが管理画面で変更を行う前に、彼らがすでにアカウントページを試したか確認することをお勧めします。

## トipp

- 毎週 **未払い** フィルターをチェックして、離脱リスクのあるサブスクリプションを確認してください。

クイックな電子メールで、通常は猶予期間が切れる前に支払いの問題が解決します。
- 請求サイクルのログは読み取り専用です。自動的に作成され、編集することはできません。

これは信頼性のある監査記録を保証します。
- カスタマーのサブスクリプションが **未払い** と表示されているが、すでに支払い方法を更新した場合、次の自動リトライで新しいカードが認識されます。

リトライは、プランで構成された猶予期間スケジュールに従います。
- **有効期限切れ** のサブスクリプションは削除されず、レポート用に表示されたままになります。

使用日期過濾器來專注於當前活躍的訂閱。
- 對於 **試用** 狀態的訂閱，請檢查 **試用結束日期** 以預期即將到來的第一筆費用，並主動解決任何付款方式的問題。
- 如果客戶說實體續訂「還沒寄出」，請檢查您的常規履行佇列，而不是訂閱記錄 — 繼續訂單的履行方式與其他訂單相同，不會跳過佇列。
