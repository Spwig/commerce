---
title: Планы подписки
---

Планы подписки позволяют предлагать повторяющиеся платежи за ваши товары — идеально подходит для расходных материалов, услуг, подборок, или любого товара, который покупают повторно. Эта инструкция объясняет, как создавать и настраивать планы, устанавливать тарифные планы, добавлять периоды пробного использования и присоединять дополнительные опции.

## Начало работы

Перейдите по ссылке **Подписки > Планы подписки** в боковом меню администратора. Список планов отображает все ваши планы с их моделью ценообразования, количеством активных подписчиков и статусом видимости.

Чтобы создать новый план, нажмите кнопку **+ Добавить план подписки** — это открывает мастер создания плана, который шаг за шагом проведет вас через настройку.

![Список планов подписки](/static/core/admin/img/help/subscription-plans/plan-list.webp)

План сам по себе не подлежит покупке — это шаблон. После того как вы его создадите, прикрепите его к одному или нескольким товарам из вкладки **Подписки** товара (только для простых, переменных и цифровых товаров), чтобы клиенты могли действительно подписаться. Для этого шага см. [Продажа товаров как подписки](/help/selling-products-as-subscriptions).

## Информация о плане

Первый раздел содержит основную информацию о вашем плане.

- **Название плана** — название, которое видят клиенты при подписке. Нажмите на иконку глобуса, чтобы добавить переводы для других языков магазина.
- **Слаг** — идентификатор, совместимый с URL, автоматически генерируемый из названия (например, `premium-plan`). Используется внутренне и в интеграциях.
- **Описание** — необязательный текст, описывающий, что включает план. Поддерживает переводы.

## Модель ценообразования

Выберите, как структурировать цены для этого плана:

| Модель ценообразования | Подходит для |
|---------------|----------|
| **Тарифное ценообразование** | Предоставление вариантов ежемесячной, квартальной и годовой оплаты с дисконтами за более длительные сроки |
| **Ценообразование в зависимости от количества** | Цену за место или пользователя, где общая сумма зависит от количества (например, лицензии для команды) |
| **Фиксированная ставка** | Единственная фиксированная цена без вариаций |

Для планов **Ценообразования в зависимости от количества**, установите **Минимальное количество** (минимальное количество мест, необходимое), и при необходимости установите **Максимальное количество**, чтобы ограничить, сколько мест может приобрести подписчик.

## Тарифные планы

Тарифные планы определяют частоту начисления и варианты скидок, доступные клиентам на этом плане. Добавьте их в разделе **Тарифные планы** ниже основной формы.

Каждый тарифный план имеет следующие поля:

- **Название тарифного плана** — метка, отображаемая клиентам (например, `Ежемесячно`, `Годовой — Экономия 20%`). Поддерживает переводы.
- **Цикл начисления** — как часто клиент оплачивает: ежедневно, еженедельно, ежемесячно, ежеквартально, полугодово или ежегодно.
- **Интервал начисления** — множитель для цикла начисления. Установите `2`, чтобы начислять каждые 2 месяца с ежемесячным циклом.
- **Процент скидки** — скидка, применяемая к цене товара для этого тарифного плана. Установите `0` для полной цены, или `20`, чтобы дать скидку 20%. Эта скидка накладывается на любую распродажную цену товара.
- **Тарифный план по умолчанию** — отметьте один тарифный план как тарифный план по умолчанию, чтобы заранее выбрать его для клиентов, когда они просматривают варианты подписки.

Скидка применяется с самого первого цикла начисления клиента, а не просто на обновления — тарифный план с 20% скидки взимает 20% скидки с первого дня (или с первого платежа после пробного периода, если у плана его есть).

### Пример: тарифный план с тремя вариантами

Для плана подписки «Кофейный клуб»:

| Название тарифного плана | Цикл начисления | Скидка |
|-----------|---------------|----------|
| Ежемесячно | Ежемесячно | 0% |
| Квартально — Экономия 10% | Квартально | 10% |
| Годовой — Экономия 20% | Годовой | 20% |

## Период пробного использования

Период пробного использования позволяет клиентам протестировать вашу подписку перед первым полным платежом. Настройте это в разделе **Период пробного использования**:

- **Период пробного использования (дни)** — количество бесплатных дней пробного периода. Установите `0`, чтобы отключить пробные периоды. Максимум 365 дней.
- **Цена пробного периода** — опциональная сниженная цена в течение пробного периода (например, $1 за первый месяц). Оставьте пустым для полной бесплатной пробной версии.

## Правила отмены

Управляйте тем, как клиенты могут отменить свою подписку в разделе **Правила отмены**:

| Policy | Description |
|--------|-------------|
| **Отменить в любое время** | Клиенты могут отменить в любое время |
| **Отменить по окончании периода** | Отмена применяется по окончании оплаченного периода — клиенты получают доступ до истечения срока |
| **Необходимо минимальное обязательство** | Клиенты должны завершить минимальное количество циклов начисления перед отменой |

Дополнительные настройки:

- **Минимальное обязательство (циклы)** — При использовании политики обязательства установите необходимое количество циклов начисления (например, `3` для минимального срока в 3 месяца).
- **Срок прощения (дни)** — Дни продолжительного доступа после неудачной оплаты, прежде чем подписка будет приостановлена. Установите `0` для немедленной приостановки.
- **Срок переактивации (дни)** — Дни после отмены, в течение которых клиент может повторно активировать свою подписку без необходимости заново подписываться.

## Поведение изменения плана

Когда клиенты обновляют или понижают планы, вы можете контролировать, когда изменение вступает в силу:

- **Поведение обновления** — Установите **Немедленно** (списать пропорциональную сумму сейчас) или **В момент продления** (сменить в следующую дату списания).
- **Поведение понижения** — Установите **Немедленно** (применить кредит к следующему счету) или **В момент продления** (сменить в следующую дату списания).

## Ограничения и правила

- **Максимальное количество циклов начисления** — Общее количество циклов начисления, после которого подписка автоматически завершится. Оставьте пустым для неограниченных периодических платежей. Полезно для планов оплаты в рассрочку или временных подписок.
- **Плата за подключение** — Одноразовая плата, взимаемая при первом создании подписки (например, плата за наboarding или активацию). Установите `0.00`, чтобы не взимать плату за подключение.

## Дополнительные элементы плана

Дополнительные элементы — это дополнительные опции, которые подписчики могут присоединить к своему плану. Добавьте их в разделе **Дополнительные элементы плана**:

- **Название дополнительного элемента** — Название, отображаемое клиентам. Поддерживает переводы.
- **Описание** — Что предоставляет дополнительный элемент.
- **Цена** — Стоимость дополнительного элемента.
- **Частота начисления** — Насколько часто начисляется дополнительный элемент: **По циклу начисления** (повторяющееся) или **Одноразово** при создании подписки.
- **Разрешить количество** — Включите, чтобы позволить клиентам покупать несколько единиц дополнительного элемента.
- **Необходимо** — Отметьте, чтобы автоматически включить дополнительный элемент во все новые подписки. Необходимые дополнительные элементы нельзя удалить клиентом.

## Видимость и статус

- **Активный** — Снимите отметку, чтобы деактивировать план, чтобы новые подписки не могли быть созданы. Существующие подписки не затрагиваются.
- **Публичный** — Снимите отметку, чтобы скрыть план от страниц, предназначенных для клиентов (полезно для внутренних или устаревших планов, на которые остаются подписчики).
- **Порядок сортировки** — Контролирует порядок отображения на страницах выбора подписки. Меньшие числа отображаются первыми.

## Советы

- Используйте **период испытания**, чтобы снизить колебания — даже короткий 7-дневный бесплатный период может значительно повысить коэффициент конверсии для продуктов с подпиской.
- Настройте **три ценовых уровня** (ежемесячно, ежеквартально, ежегодно) с увеличивающимися скидками, чтобы поощрять ежегодные обязательства и улучшать ваш поток наличности.
- Для подписок на услуги установите **Политику отмены** на **Отменить по окончании периода**, чтобы клиенты получали доступ в течение своего оплаченного периода — это кажется справедливым и снижает количество возвратов.
- Удерживайте **Срок прощения** на уровне 3–7 дней для сбоев оплаты. Это дает клиентам время обновить способ оплаты, прежде чем потерять доступ.
- Используйте флажок **Необходимо** на дополнительных элементах осторожно — используйте его только для тех вещей, которые действительно являются обязательными (например, соглашение о предоставлении услуг), а не как способ увеличения цен.
- Деактивируйте планы без подписчиков, а не удаляйте их — это сохраняет исторические данные для любых клиентов, которые ранее подписывались.
