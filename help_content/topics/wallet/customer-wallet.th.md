---
title: กระเป๋าเงินลูกค้า
---

กระเป๋าเงินลูกค้าคือสมุดบัญชีเครดิตร้านค้าที่ติดตามยอดคงเหลือที่กำลังดำเนินอยู่สำหรับลูกค้าแต่ละราย เครดิตร้านค้าสามารถเพิ่มได้จากผลของการคืนเงิน รางวัลการแนะนำ แคมเปญโปรโมชัน หรือการปรับเปลี่ยนแบบมีการจัดการโดยทีมของคุณ

> **ยอดคงเหลือในกระเป๋าเงินสามารถใช้ได้ที่ขั้นตอนการชำระเงิน** ลูกค้าที่เข้าสู่ระบบซึ่งมีเครดิตร้านค้าจะเห็นมันในขั้นตอนการชำระเงินและสามารถใช้ได้ด้วยการคลิกเพียงครั้งเดียว เงินเครดิตจะถูกหักออกจากยอดค่าใช้จ่ายสุดท้ายหลังจากหักภาษีและค่าส่ง และส่วนที่เหลือจะถูกเรียกเก็บเงินตามปกติไปยังบัตรของลูกค้า หากเครดิตครอบคลุมคำสั่งซื้อทั้งหมด ก็ไม่จำเป็นต้องใช้บัตรเลย เงินเครดิตจะถูกสำรองไว้เมื่อใช้แล้ว และจะถูกหักจริงๆ เมื่อการชำระเงินได้รับการยืนยัน ดังนั้น การทิ้งขั้นตอนการชำระเงินจะไม่เกิดค่าใช้จ่ายใดๆ ให้กับลูกค้าเลย

ไปที่ **ลูกค้า > กระเป๋าเงินลูกค้า** เพื่อดูและจัดการกระเป๋าเงิน

## การเข้าใจยอดคงเหลือกระเป๋าเงิน

กระเป๋าเงินของลูกค้าแต่ละรายแสดงยอดคงเหลือ 4 รายการดังนี้:

| ยอดคงเหลือ | คำอธิบาย |
|---|---|
| **ยอดคงเหลือที่ใช้ได้** | เงินเครดิตปัจจุบันที่สามารถใช้ได้ของลูกค้า — นี่คือยอดที่สามารถใช้ได้ที่ขั้นตอนการชำระเงินเมื่อฟีเจอร์นี้เปิดใช้งาน |
| **ยอดคงเหลือที่รอการยืนยัน** | เงินเครดิตที่ยังไม่ถูกเพิ่มเข้าสู่ยอดคงเหลือที่ใช้ได้ — เช่น การคืนเงินที่ยังอยู่ในช่วงเวลาการยืนยัน |
| **ยอดเครดิตตลอดชีวิต** | จำนวนเงินทั้งหมดที่เคยถูกเครดิตเข้ากระเป๋าเงินนี้ รวมถึงเครดิตทั้งหมดในอดีต |
| **ยอดใช้ตลอดชีวิต** | จำนวนเงินทั้งหมดที่เคยถูกหักออกจากกระเป๋าเงินนี้ |

ยอดคงเหลือที่ใช้ได้คือตัวเลขที่สำคัญเมื่อการใช้จ่ายที่ขั้นตอนการชำระเงินเปิดใช้งานแล้ว ยอดเครดิตที่รอการยืนยันจะถูกเพิ่มเข้าไปในยอดคงเหลือที่ใช้ได้เมื่อช่วงเวลาการรอสิ้นสุดลง

## การดูกระเป๋าเงินของลูกค้า

1. ไปที่ **ลูกค้า > กระเป๋าเงินลูกค้า**
2. ใช้ช่องค้นหาเพื่อค้นหาลูกค้าตามชื่อหรืออีเมล
3. คลิกที่รายการกระเป๋าเงินเพื่อเปิดดูรายละเอียด

หน้ารายละเอียดแสดงยอดคงเหลือปัจจุบันที่ด้านบนและประวัติการทำธุรกรรมทั้งหมดด้านล่าง ตัวระบุเวลา **Last Credited At** และ **Last Used At** จะบอกคุณว่ากระเป๋าเงินถูกใช้งานครั้งสุดท้ายเมื่อใด

### การกรองรายการกระเป๋าเงิน

ใช้ตัวกรอง **Active** เพื่อแยกกระเป๋าเงินที่ใช้งานอยู่ออกจากกระเป๋าเงินที่ถูกแช่แข็ง

กระเป๋าเงินที่ถูกทำเครื่องหมายว่าไม่ใช้งานจะถูกแช่แข็ง — ไม่สามารถบันทึกเครดิตหรือการหักเงินได้ แม้ว่าจะยังคงมียอดคงเหลืออยู่

## การดูประวัติการทำธุรกรรม

ทุกการเปลี่ยนแปลงในยอดเงินของกระเป๋าเงินจะถูกบันทึกเป็นธุรกรรมแต่ละรายการ ประวัติการทำธุรกรรมเป็นบัญชีที่สมบูรณ์และถาวร — ธุรกรรมจะไม่มีการแก้ไขหรือลบ หากต้องการแก้ไขข้อผิดพลาด จะเพิ่มธุรกรรมชดเชยใหม่แทน

แต่ละธุรกรรมแสดงรายการดังนี้:

| Field | Description |
|---|---|
| **Type** | เครดิต, ค่าใช้จ่าย, การคืนเงิน, การปรับปรุง, หรือการยกเลิก |
| **Amount** | ค่าของธุรกรรมนี้ (จะแสดงเป็นตัวเลขบวกเสมอ) |
| **Balance After** | ยอดเงินในกระเป๋าเงินทันทีหลังจากธุรกรรมนี้ถูกประมวลผล |
| **Source** | ที่มาของเครดิตหรือค่าใช้จ่าย |
| **Status** | สำเร็จ, รอการดำเนินการ, หรือถูกยกเลิก |
| **Description** | คำอธิบายสั้น ๆ เกี่ยวกับธุรกรรม |
| **Reference ID** | ลิงก์ไปยังบันทึกต้นทาง (เช่น หมายเลขคำสั่งซื้อหรือรหัสรางวัล) |
| **Created At** | เมื่อธุรกรรมถูกบันทึก |

### การอธิบายประเภทของธุรกรรม

- **Credit** — เงินที่ถูกเพิ่มเข้าไปในกระเป๋าเงิน (จากคืนเงิน, การส่งเสริมการขาย, หรือการปรับปรุงด้วยมือ)
- **Debit** — เงินที่ถูกหักออกจากกระเป๋าเงิน เมื่อการใช้จ่ายที่เคาน์เตอร์สิ้นสุดลงจะหมายถึง "ใช้จ่ายสำหรับคำสั่งซื้อ" — สำหรับตอนนี้วิธีเดียวที่จะเกิดการหักเงินคือการปรับปรุงด้วยมือ
- **Refund** — เงินที่ถูกเพิ่มเข้ามาเฉพาะจากการคืนหรือยกเลิกคำสั่งซื้อ
- **Adjustment** — การแก้ไขด้วยมือที่ทีมของคุณทำ
- **Reversal** — ธุรกรรมที่ยกเลิกการบันทึกก่อนหน้า

### การอธิบายแหล่งที่มาของธุรกรรม

- **Order Refund** — เงินที่ได้รับเมื่อคำสั่งซื้อถูกคืนเงินเข้ากระเป๋าเงิน
- **Referral Reward** — เงินที่ได้รับผ่านโปรแกรมแนะนำ
- **Promotion** — เงินที่ได้รับเป็นส่วนหนึ่งของแคมเปญการตลาด
- **Manual Adjustment** — เงินที่ถูกเพิ่มหรือหักโดยตรงโดยพนักงาน
- **Order Payment** — เงินที่ใช้ในการชำระเงินที่เคาน์เตอร์เพื่อซื้อสินค้า ยังไม่ได้ใช้งาน — สำรองไว้เมื่อการใช้จ่ายกระเป๋าเงินที่เคาน์เตอร์ส่งมอบแล้ว

## การปรับยอดเงินกระเป๋าอย่างมืออาชีพ

คุณไม่สามารถเพิ่มหรือลดยอดเงินผ่านแดชบอร์ดผู้ดูแลระบบ — การทำธุรกรรมกระเป๋าเงินจะถูกสร้างขึ้นโดยกระบวนการที่เป็นเจ้าของเท่านั้น: การคืนเงินจากการสั่งซื้อ, รางวัลสะสม, และรางวัลจากการแนะนำ นี่เป็นการตั้งใจไว้ ทุกการเคลื่อนไหวมีการอ้างอิงกลับไปยังสิ่งที่ทำให้เกิดขึ้น และการตรวจสอบในแต่ละคืนจะตรวจสอบยอดเงินในกระเป๋าแต่ละใบกับประวัติของมันเอง; แถวที่ป้อนด้วยมือคือสิ่งที่ทำลายลูกโซ่นั้น

สำหรับเครดิตดีๆ — เช่น การร้องเรียนบริการ หรือการให้ของขวัญหลังจากเกิดปัญหา — ให้ออก **บัตรของขวัญ** ด้วยมือแทน (ดูหัวข้อช่วยเหลือ **บัตรของขวัญ**) บัตรของขวัญถูกออกแบบมาเพื่อใช้ในกรณีนี้โดยเฉพาะ: คุณควบคุมค่าของบัตร, ลูกค้าจะได้รับรหัสผ่านทางอีเมล และสามารถใช้ได้ในขั้นตอนชำระเงินเช่นเดียวกับเครดิตในร้านค้า

## การแช่แข็งกระเป๋าเงิน

หากคุณต้องการป้องกันไม่ให้ลูกค้าใช้ยอดเงินในกระเป๋าของพวกเขา — เช่น ในระหว่างการสืบสวนการฉ้อโกง — คุณสามารถปิดใช้งานได้โดยไม่ต้องลบหรือลบยอดเงิน

1. เปิดหน้ารายละเอียดกระเป๋าเงินของลูกค้า
2. คลิกปุ่ม **Active** เพื่อไม่เลือก
3. คลิก **บันทึก**

ยอดเงินจะถูกเก็บไว้ และกระเป๋าสามารถเปิดใช้งานได้ทุกเมื่อ ขณะที่ไม่ได้ใช้งาน ไม่มีการเพิ่มหรือลดยอดเงิน — ทั้งแบบมืออาชีพหรืออื่น ๆ — สามารถบันทึกไว้กับกระเป๋าได้

## การดูธุรกรรมทั้งหมด

สำหรับมุมมองแบบองค์กรเกี่ยวกับกิจกรรมกระเป๋าเงิน ให้ไปที่ **ลูกค้า > ธุรกรรมกระเป๋าเงิน** รายการนี้แสดงธุรกรรมทั้งหมดในกระเป๋าเงินของลูกค้าทุกคน โดยมีตัวกรองดังนี้:

- **ประเภทธุรกรรม** — กรองตามเครดิต, ค่าใช้จ่าย, การปรับปรุง, ฯลฯ
- **แหล่งที่มา** — กรองตามที่ธุรกรรมเริ่มต้น
- **สถานะ** — กรองตามที่เสร็จสิ้น, รอ, หรือถูกยกเลิก
- **วันที่** — ใช้ลำดับชั้นของวันที่ด้านบนเพื่อดูข้อมูลเฉพาะวัน, เดือน, หรือปี

รายการธุรกรรมเป็นแบบอ่านเฉพาะ — ไม่สามารถแก้ไขหรือลบธุรกรรมจากมุมมองนี้ได้

## เคล็ดลับ

รักษาการจัดรูปแบบมาร์กดาวน์, ค่าเส้นทางรูปภาพ, บล็อกโค้ด และคำศัพท์ทางเทคนิคไว้ทั้งหมด

- ตรวจสอบ **Lifetime Credited** ต่อ **Lifetime Used** เพื่อทำความเข้าใจว่าลูกค้าใช้เครดิตร้านค้าของตนอย่างกระตือรือร้นเพียงใด — ยอดคงเหลือที่ไม่ได้ใช้จำนวนมากอาจบ่งบอกว่าลูกค้าลืมว่ามีอยู่
- หากลูกค้ารายงานว่ายอดคงเหลือดูผิดปกติ ให้ตรวจสอบประวัติการทำธุรกรรมทั้งหมดเพื่อติดตามว่ายอดคงเหลือเปลี่ยนแปลงอย่างไรตามเวลาที่ผ่านมา คอลัมน์ **Balance After** ที่ปรากฏในแต่ละรายการทำให้สิ่งนี้เป็นเรื่องง่าย
- ยอดคงเหลือที่ไม่ได้ใช้จำนวนมากมีคุณค่าที่ควรส่งข้อความกระตุ้น — ลูกค้าจะเห็นเครดิตร้านค้าของตนบนแดชบอร์ดบัญชีและขั้นตอนการชำระเงินที่เคาน์เตอร์ แต่การส่งอีเมลสั้นๆ ที่ชี้ให้เห็นมักจะเปลี่ยนยอดคงเหลือนั้นให้กลายเป็นคำสั่งซื้อได้
- กระเป๋าเงินที่ถูกแช่แข็งจะรักษายอดคงเหลือไว้ตลอดไป ไม่มีการหมดอายุ — หากคุณปิดใช้งานกระเป๋าเงินชั่วคราว จำไว้ว่าต้องเปิดใช้งานใหม่เมื่อปัญหาได้รับการแก้ไขแล้ว
- **Reference ID** ที่ปรากฏในแต่ละการทำธุรกรรมจะเชื่อมโยงกลับไปยังบันทึกต้นทาง ทำให้สามารถตรวจสอบได้อย่างตรงไปตรงมาว่าเหตุใดเครดิตหรือการหักเงินจึงถูกนำไปใช้โดยไม่จำเป็นต้องค้นหาที่อื่น
