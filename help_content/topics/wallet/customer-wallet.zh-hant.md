---
title: 客戶錢包
---

客戶錢包是用來追蹤每位客戶餘額的商店信用賬戶。商店信用可以透過退款、推薦獎勵、促銷活動或您的團隊手動調整來增加。

> **錢包餘額可在結帳時使用。** 已登入的客戶在結帳時會看到他們的商店信用，並可以點擊一次來應用。信用會從最終賬單中扣除——扣除稅款和運費後，剩餘部分會如常從他們的信用卡中扣除。如果信用足以支付整筆訂單，則完全不需要信用卡。當應用信用時會預先保留信用，只有在付款確認後才實際扣除，因此放棄結帳不會讓客戶產生任何費用。

導航至 **客戶 > 客戶錢包** 來查看和管理錢包。

## 理解錢包餘額

每個客戶錢包會顯示四個餘額數字：

| 餘額 | 說明 |
|---|---|
| **可用餘額** | 客戶目前可用的信用——這將是在結帳功能上線後可用的餘額 |
| **待處理餘額** | 尚未列入可用餘額的信用——例如，仍在確認窗口內的退款 |
| **累計信用總額** | 此錢包歷史上所有信用總額，包括所有過去的信用 |
| **累計使用總額** | 此錢包歷史上所有扣除總額 |

可用餘額是結帳功能上線後會影響的數字。待處理的信用在待處理期過後會轉入可用餘額。

## 查看客戶的錢包

1. 導航至 **客戶 > 客戶錢包**
2. 使用搜尋欄透過姓名或電子郵件查找客戶
3. 點擊錢包條目以打開詳細視圖

詳細視圖會在頂部顯示當前餘額，並在下方顯示完整的交易歷史。**最近一次信用時間** 和 **最近一次使用時間** 的時間戳告訴您錢包上次活躍的時間。

### 過濾錢包列表

使用 **活躍** 過濾器來區分活躍的錢包和凍結的錢包。

被標記為非活躍的錢包會被凍結 — 無法記錄任何信貸或借記，儘管它仍保留餘額。

## 查看交易記錄

每個錢包餘額的更改都會作為一筆獨立交易進行記錄。交易記錄是一份完整且永久的賬本 — 交易從來不會被編輯或刪除。如果需要糾正錯誤，會新增一筆補償交易來處理。

每筆交易顯示：

| 欄位 | 說明 |
|---|---|
| **類型** | 信貸、借記、退款、調整或逆轉 |
| **金額** | 這筆交易的價值（始終顯示為正數） |
| **交易後餘額** | 這筆交易應用後的錢包餘額 |
| **來源** | 信貸或借記的來源 |
| **狀態** | 已完成、待處理或已逆轉 |
| **說明** | 交易的簡短說明 |
| **參考 ID** | 連結到原始記錄（例如訂單號碼或獎勵 ID） |
| **建立時間** | 交易被記錄的時間 |

### 交易類型說明

- **信貸** — 加入錢包的資金（來自退款、促銷或手動調整）
- **借記** — 從錢包中扣除資金。一旦結帳消費上線，這將意味著「用於訂單」— 目前借記發生的唯一方式是手動調整
- **退款** — 因退貨或取消訂單而特別加入的信貸
- **調整** — 您團隊進行的手動修正
- **逆轉** — 取消先前條目的交易

### 交易來源說明

- **訂單退款** — 訂單退款至錢包時發放的信貸
- **推薦獎勵** — 透過推薦計劃賺取的信貸
- **促銷** — 作為市場營銷活動的一部分授予的信貸
- **手動調整** — 員工直接加入或扣除的信貸
- **訂單付款** — 在結帳時用來支付訂單的資金。尚未使用 — 預留給錢包結帳消費上線時使用

## 手動調整錢包

你無法從管理面板中增加或減少資金 — 錢包交易只能由擁有它的流程創建：訂單退款、忠誠度獎勵和推薦獎勵。這是刻意設計的。每一次資金的流動都會有回溯的參考來源，而且每晚會有一項檢查，將每個錢包的餘額與其歷史記錄進行核對；手動輸入的行會破壞這個鏈條。

如果是善意賠償 — 例如服務投訴，或是在出現問題後的禮物 — 請手動發放一張 **禮品卡**（請參閱 **禮品卡** 帮助主題）。禮品卡正是為此而設計的：你可以控制價值，客戶會透過電子郵件收到一個代碼，並在結帳時以與商店信用相同的方式使用。

## 冻結錢包

如果你需要防止客戶使用其錢包餘額 — 例如在進行詐騙調查期間 — 你可以停用它，而不需要刪除或移除餘額。

1. 打開客戶的錢包詳細視圖
2. 取消勾選 **啟用** 開關
3. 點擊 **保存**

餘額會被保留，而且錢包隨時可以重新啟用。在停用期間，無法對錢包記錄任何新的信貸或借記 — 手動或其他方式皆不可。

## 查看所有交易

如需查看整個商店的錢包活動，請導航至 **客戶 > 錢包交易**。此列表顯示所有客戶錢包的每筆交易，並可過濾以下項目：

- **交易類型** — 過濾信貸、借記、調整等
- **來源** — 過濾交易的來源
- **狀態** — 過濾已完成、待處理或已逆轉
- **日期** — 使用頂部的日期層級深入查看特定日期、月份或年份

交易列表僅為只讀 — 無法從此視圖編輯或刪除交易。

## 小提示

保留所有 markdown 格式、圖片路徑、程式碼塊和技術術語。

- 檢查 **Lifetime Credited** 與 **Lifetime Used**，以了解客戶如何積極使用其商店信用額度 — 一個大額未使用的餘額可能表示客戶已經忘記它的存在
- 如果客戶報告其餘額看起來不正確，請查看完整的交易記錄，以追溯餘額隨時間變化的具體情況；每個條目中的 **Balance After** 欄位使這一點變得輕鬆
- 一個大額未使用的餘額值得提醒一下 — 客戶在帳戶儀表板和結帳付款步驟中都能看到他們的商店信用，但一封簡短的電子郵件提醒他們，通常會將其轉化為訂單
- 冻結的錢包會永久保留其餘額；沒有過期日期 — 如果您臨時停用錢包，請記得在問題解決後重新啟用它
- 每筆交易上的 **Reference ID** 可追溯到原始記錄，使驗證信用或借記的應用原因變得簡單，無需在其他地方搜索
