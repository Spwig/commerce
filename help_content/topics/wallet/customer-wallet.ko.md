---
title: 고객 지갑
---

고객 지갑은 각 고객의 잔액을 추적하는 가맹점 신용 장부입니다. 가맹점 신용은 환불, 추천 보상, 프로모션 캠페인 또는 귀하의 팀이 수동으로 수행한 조정으로 인해 추가될 수 있습니다.

> **지갑 잔액은 결제 시 사용할 수 있습니다.** 가맹점 신용이 있는 로그인한 고객은 결제 단계에서 이를 보고 한 번 클릭으로 적용할 수 있습니다. 신용은 세금과 배송비를 제외한 최종 청구서에서 차감되며, 남은 금액은 일반적으로 그들의 카드에 청구됩니다. 신용이 전체 주문을 커버하는 경우 결제에 필요한 카드가 전혀 필요하지 않습니다. 신용이 적용되면 예약되며 결제가 확인된 후에만 실제로 차감되므로 포기한 결제는 고객에게 아무런 비용도 발생하지 않습니다.

**고객 > 고객 지갑**으로 이동하여 지갑을 확인하고 관리할 수 있습니다.

## 지갑 잔액 이해

각 고객 지갑은 네 가지 잔액 수치를 보여줍니다:

| 잔액 | 설명 |
|---|---|
| **사용 가능한 잔액** | 고객의 현재, 사용 가능한 신용 — 이 기능이 출시되면 체크아웃 시 사용 가능한 금액이 됩니다 |
| **대기 잔액** | 사용 가능한 잔액이 아닌 신용 — 예를 들어, 확인 기간이 아직 남은 환불 |
| **생애 신용 금액** | 이 지갑에 지금까지 누적된 총 신용 금액, 과거 모든 신용 포함 |
| **생애 사용 금액** | 이 지갑에서 지금까지 차감된 총 금액 |

사용 가능한 잔액은 체크아웃 결제가 출시되면 중요한 수치가 됩니다. 대기 신용은 대기 기간이 끝나면 사용 가능한 잔액으로 이동합니다.

## 고객의 지갑 보기

1. **고객 > 고객 지갑**으로 이동합니다
2. 이름 또는 이메일로 고객을 검색하려면 검색 필드를 사용합니다
3. 지갑 항목을 클릭하여 세부 정보 보기로 이동합니다

세부 정보 보기에서는 상단에 현재 잔액이 표시되고, 아래에는 전체 거래 내역이 표시됩니다. **마지막으로 신용된 시점** 및 **마지막으로 사용된 시점** 타임스탬프는 지갑이 마지막으로 활성화된 시점을 알려줍니다.

### 지갑 목록 필터링

**활성** 필터를 사용하여 활성 지갑과 동결된 지갑을 구분합니다.

비활성 상태로 표시된 지갑은 동결됩니다 — 이 지갑에 대한 신용 또는 차감 기록이 전혀 이루어지지 않으며, 현재 잔액은 유지됩니다.

## 거래 내역 확인

지갑 잔액의 모든 변경 사항은 개별 거래로 기록됩니다. 거래 내역은 완전하고 영구적인 장부이며, 거래는 수정되거나 삭제되지 않습니다. 오류를 수정해야 하는 경우, 대신 새로운 보상 거래가 추가됩니다.

각 거래는 다음과 같은 정보를 표시합니다:

| 필드 | 설명 |
|---|---|
| **타입** | 신용, 차감, 환불, 조정, 또는 취소 |
| **금액** | 이 거래의 금액 (항상 양수로 표시됨) |
| **거래 후 잔액** | 이 거래가 적용된 후 지갑 잔액 |
| **출처** | 신용 또는 차감의 원천 |
| **상태** | 완료, 대기, 또는 취소 |
| **설명** | 거래에 대한 간단한 설명 |
| **참조 ID** | 원본 기록으로 이어지는 링크 (예: 주문 번호 또는 보상 ID) |
| **생성 시간** | 거래가 기록된 시간 |

### 거래 유형 설명

- **신용** — 지갑에 추가된 자금 (환불, 프로모션 또는 수동 조정으로 인해)
- **차감** — 지갑에서 자금이 차감됨. 체크아웃 결제가 출시되면 이는 "주문에 사용됨"을 의미할 것이며, 현재는 차감이 발생하는 유일한 방법은 수동 조정입니다.
- **환불** — 반품 또는 주문 취소로 인해 지갑에 추가된 신용
- **조정** — 귀하의 팀이 수행한 수동 수정
- **취소** — 이전 항목을 무효화하는 거래

### 거래 출처 설명

- **주문 환불** — 주문이 지갑으로 환불될 때 제공되는 신용
- **추천 보상** — 추천 프로그램을 통해 얻은 신용
- **프로모션** — 마케팅 캠페인의 일부로 제공된 신용
- **수동 조정** — 직원이 직접 추가하거나 차감한 신용
- **주문 결제** — 체크아웃에서 주문을 결제하기 위해 사용된 자금. 아직 사용되지 않음 — 지갑 체크아웃 결제가 출시될 때 예약됨

## 수동 지갑 조정

관리자 패널에서 자금을 추가하거나 제거할 수 없습니다 — 지갑 거래는 해당 거래를 소유하는 프로세스(예: 환불, 충성도 보상, 추천 보상)에 의해만 생성됩니다. 이는 의도된 것입니다. 모든 이동에는 원인을 가리키는 참조가 있으며, 밤새 진행되는 검사에서 각 지갑의 잔액이 자체 기록과 일치하는지 확인합니다. 수동으로 입력된 행이 이 체인을 깨뜨립니다.

좋은 의도로 인한 신용 — 서비스 불만, 문제 후의 선물 —은 대신 수동으로 **선물 카드**를 발행하세요( **선물 카드** 도움말 주제를 참조하십시오). 선물 카드는 바로 이 상황을 위해 설계되었습니다: 당신이 가치를 제어하고, 고객은 이메일로 코드를 받으며, 체크아웃 시 스토어 크레딧과 동일한 방식으로 사용할 수 있습니다.

## 지갑 잠금

고객이 지갑 잔액을 사용하는 것을 방지해야 하는 경우 — 예를 들어 사기 조사 중 — 지갑을 삭제하거나 잔액을 제거하지 않고 비활성화할 수 있습니다.

1. 고객의 지갑 상세 보기로 이동합니다
2. **활성화** 토글을 해제합니다
3. **저장**을 클릭합니다

잔액은 보존되고 언제든지 지갑을 다시 활성화할 수 있습니다. 비활성화된 동안 새로운 신용 또는 차감 — 수동 또는 기타 —은 지갑에 기록될 수 없습니다.

## 모든 거래 보기

지갑 활동에 대한 전체적인 가시성을 원하는 경우, **고객 > 지갑 거래**로 이동하세요. 이 목록은 모든 고객 지갑의 모든 거래를 보여주며, 다음 필터를 사용할 수 있습니다:

- **거래 유형** — 신용, 차감, 조정 등으로 필터
- **출처** — 거래가 발생한 위치로 필터
- **상태** — 완료, 대기, 취소 등으로 필터
- **날짜** — 상단의 날짜 계층 구조를 사용하여 특정 날짜, 월, 또는 연도로 세부 정보를 확인

거래 목록은 읽기 전용입니다 — 이 뷰에서 거래를 편집하거나 삭제할 수 없습니다.

## 팁

모든 마크다운 포맷, 이미지 경로, 코드 블록 및 기술 용어를 보존하세요.

- **생애 주기 적립액**과 **생애 주기 사용액**을 확인하여 고객이 얼마나 적극적으로 스토어 크레딧을 사용하는지 파악할 수 있습니다. 사용되지 않은 금액이 많다면 고객이 이를 잊어버렸을 가능성이 있습니다.
- 고객이 잔액이 잘못 표시된다고 보고할 경우, 전체 거래 내역을 확인하여 시간에 따라 잔액이 어떻게 변경되었는지 정확히 추적하세요. 각 항목의 **거래 후 잔액** 열은 이 작업을 쉽게 만들어 줍니다.
- 사용되지 않은 큰 금액은 고객에게 알리는 것이 좋습니다. 고객은 계정 대시보드와 결제 단계에서 스토어 크레딧을 볼 수 있지만, 짧은 이메일로 이를 지적하면 자주 주문으로 이어집니다.
- 동결된 지갑은 잔액을 영구적으로 유지합니다. 만료 기간이 없습니다. 잠시 지갑을 비활성화한 경우, 문제가 해결되면 다시 활성화하는 것을 기억하세요.
- 각 거래의 **참조 ID**는 원본 기록으로 돌아가며, 이는 다른 곳을 검색할 필요 없이 크레딧 또는 차감이 왜 적용되었는지 쉽게 확인할 수 있도록 해줍니다.
