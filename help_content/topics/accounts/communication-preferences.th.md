---
title: การตั้งค่าการติดต่อสื่อสาร
---

การตั้งค่าการติดต่อสื่อสารช่วยให้ลูกค้าสามารถควบคุมอีเมลและข้อความ SMS ที่พวกเขาต้องการรับจากร้านค้าของคุณ ระบบนี้ช่วยให้ปฏิบัติตามข้อกำหนด GDPR และช่วยให้คุณเคารพการตั้งค่าการติดต่อสื่อสารของลูกค้าผ่านทุกช่องทาง

ไปที่ **Customers > Communication Preferences** ในแถบด้านข้างของแอดมินเพื่อจัดการการตั้งค่าการติดต่อสื่อสารของลูกค้า

## การทำความเข้าใจการตั้งค่าการติดต่อสื่อสาร

ระบบการตั้งค่าการติดต่อสื่อสารให้ลูกค้าสามารถควบคุมข้อความที่พวกเขาได้รับอย่างละเอียด ซึ่งรวมถึง:

- **อีเมลธุรกรรม** — อีเมลยืนยันคำสั่งซื้อ การอัปเดตการจัดส่ง และอีเมลความปลอดภัยของบัญชี (เปิดใช้งานเสมอ)
- **อีเมลการตลาด** — นิตยสารข่าว โปรโมชัน และคำแนะนำผลิตภัณฑ์ (ต้องมีการสมัครรับ)
- **การแจ้งเตือนเฉพาะแอป** — โพสต์บล็อก คะแนนความภักดี รางวัลการแนะนำ และค่าคอมมิชชันพันธมิตร
- **การแจ้งเตือน SMS** — การแจ้งเตือนผ่านข้อความ (ต้องมีการสมัครรับอย่างชัดเจนตาม TCPA)

การสื่อสารทางการตลาดทั้งหมดต้องได้รับความยินยอมจากลูกค้าและการยืนยันอีเมลเพื่อให้ปฏิบัติตามข้อกำหนด GDPR

## ประเภทของการตั้งค่าที่อธิบาย

### การสื่อสารธุรกรรม (เปิดใช้งานเสมอ)

ข้อความธุรกรรมมีความจำเป็นสำหรับบัญชีและคำสั่งซื้อของลูกค้า ลูกค้า **ไม่สามารถปิดใช้งาน** ข้อความเหล่านี้ได้:

| ประเภท | คำอธิบาย | ตัวอย่าง |
|------|-------------|----------|
| **การยืนยันคำสั่งซื้อ** | การยืนยันเมื่อมีการสั่งซื้อ | รับคำสั่งซื้อ #12345 แล้ว |
| **การอัปเดตการจัดส่ง** | การแจ้งเตือนเมื่อสถานะคำสั่งซื้อเปลี่ยนแปลง | คำสั่งซื้อของคุณถูกจัดส่งแล้ว |
| **การยืนยันการชำระเงิน** | รับการชำระเงิน หรือดำเนินการคืนเงิน | ยืนยันการชำระเงิน $49.99 |
| **ความปลอดภัยของบัญชี** | รีเซ็ตรหัสผ่าน ยืนยันอีเมล | รีเซ็ตรหัสผ่านของคุณ |

| ประเภท | คำอธิบาย | ค่าเริ่มต้น |
|------|-------------|---------|
| **จดหมายข่าว** | จดหมายข่าวทั่วไปและการอัปเดต | Opt-out |
| **ข้อเสนอส่งเสริมการขาย** | การลดราคา ส่วนลด ข้อเสนอพิเศษ | Opt-out |
| **คำแนะนำผลิตภัณฑ์** | คำแนะนำผลิตภัณฑ์เฉพาะบุคคล | Opt-out |
| **สินค้าพร้อมจำหน่าย** | การแจ้งเตือนเมื่อสินค้าพร้อมจำหน่ายอีกครั้ง | Opt-out |

ลูกค้าต้อง **ยืนยันที่อยู่อีเมล** ก่อนรับอีเมลการตลาดใดๆ (ข้อกำหนด GDPR double opt-in)

### การตั้งค่าเฉพาะแอป

ลูกค้าสามารถควบคุมการแจ้งเตือนจากฟีเจอร์เฉพาะได้:

**การแจ้งเตือนบล็อก**
- โพสต์บล็อกใหม่เผยแพร่ (ทันที, สรุปข่าวรายสัปดาห์, หรือสรุปข่าวรายเดือน)
- การสมัครรับข้อมูลตามหมวดหมู่
- การตั้งค่าความถี่

**โปรแกรมความภักดี**
- การแจ้งเตือนคะแนนที่ได้รับ
- การเลื่อนระดับ
- รางวัลที่ปลดล็อกแล้ว
- คะแนนที่กำลังจะหมดอายุ
- โบนัสวันเกิด
- ข้อเสนอแคมเปญ

**โปรแกรมแนะนำ**
- รางวัลที่ออกแล้ว (ทั้งผู้แนะนำและผู้ถูกแนะนำ)
- การสมัครสมาชิกผ่านการแนะนำที่สำเร็จ
- รางวัลที่กำลังจะหมดอายุ
- คำเชิญแนะนำ

**โปรแกรมพันธมิตร** 
- ค่าคอมมิชชันที่ได้รับ
- ค่าคอมมิชชันที่ได้รับการอนุมัติหรือถูกปฏิเสธ
- การจ่ายเงินที่ดำเนินการเสร็จสิ้น, สำเร็จ, หรือล้มเหลว
- รายงานประสิทธิภาพรายเดือน

### การแจ้งเตือน SMS (ต้องมีการ Opt-In อย่างชัดเจน)

การแจ้งเตือน SMS ทั้งหมดต้องมีการ **opt-in อย่างชัดเจน** ตามกฎระเบียบ TCPA ลูกค้าต้องทำเครื่องหมายในกล่อง opt-in SMS อย่างกระตือรือร้น:

- **SMS ธุรกรรม** — สินค้าจัดส่งแล้ว, ส่งมอบแล้ว (ต้อง opt-in)
- **SMS การตลาด** — การส่งเสริมการขาย, ข้อเสนอพิเศษ (ต้อง opt-in แยกต่างหาก)

แม้กระทั่ง SMS ธุรกรรมก็ต้องการ opt-in เนื่องจากข้อความที่ไม่ได้รับเชิญถูกควบคุมอย่างเข้มงวดกว่าอีเมล

## การจัดการการตั้งค่าของลูกค้าใน Admin

### การดูการตั้งค่าทั้งหมด

ไปที่ **Customers > Communication Preferences** เพื่อดูการตั้งค่าของลูกค้าทั้งหมด:


| คอลัมน์ | คำอธิบาย |
|--------|-------------|
| **อีเมลผู้ใช้** | ที่อยู่อีเมลของลูกค้า (ลิงก์ไปยังหน้าจัดการผู้ใช้) |
| **สถานะอีเมล** | สีเขียว ✓ หากเปิดใช้งานอีเมล, สีเทา ○ หากปิดใช้งาน |
| **สถานะ SMS** | สีเขียว ✓ หากเปิดใช้งาน SMS, สีเทา ○ หากปิดใช้งาน |
| **สถานะการตลาด** | ป้าย "Opted In" หรือ "Opted Out" |
| **สถานะการยืนยัน** | 📧✓ หากยืนยันอีเมลแล้ว, 📱✓ หากยืนยัน SMS แล้ว |
| **แหล่งที่มาของคำยินยอม** | ที่ที่ลูกค้าให้คำยินยอม (การลงทะเบียน, การชำระเงิน, ศูนย์ตั้งค่า) |
| **อัปเดตเมื่อ** | เวลาสุดท้ายที่การตั้งค่าถูกเปลี่ยนแปลง |

### การกรองการตั้งค่า

ใช้แถบด้านข้างตัวกรองเพื่อค้นหาลูกค้า:

- **เปิดใช้งานอีเมล** — ใช่/ไม่ใช่
- **เปิดใช้งาน SMS** — ใช่/ไม่ใช่
- **การตลาดทางอีเมล** — ใช่/ไม่ใช่ (สมัครรับการตลาดทางอีเมล)
- **การตลาดทาง SMS** — ใช่/ไม่ใช่ (สมัครรับการตลาดทาง SMS)
- **ยืนยันอีเมลแล้ว** — ใช่/ไม่ใช่ (ยืนยันที่อยู่อีเมลแล้ว)
- **ยืนยัน SMS แล้ว** — ใช่/ไม่ใช่ (ยืนยันหมายเลขโทรศัพท์แล้ว)
- **แหล่งที่มาของคำยินยอม** — การลงทะเบียน, การชำระเงิน, ศูนย์ตั้งค่า, API, การย้ายข้อมูล
- **รหัสภาษา** — ภาษาที่ต้องการสำหรับการสื่อสาร

### การค้นหากำหนดการตั้งค่า

ค้นหาลูกค้าโดย:
- อีเมลผู้ใช้
- ชื่อผู้ใช้
- ชื่อ
- นามสกุล
- โทเคนยกเลิกการสมัครรับ

### การดำเนินการแบบกลุ่ม

เลือกลูกค้าหลายคนและดำเนินการแบบกลุ่ม:

**✓ ระบุว่าอีเมลได้รับการยืนยัน**
- ยืนยันที่อยู่อีเมลของลูกค้าด้วยตนเอง
- มีประโยชน์เมื่อนำเข้าลูกค้าจากระบบอื่น
- ทำให้แคชการตั้งค่าหมดอายุเพื่อใช้การเปลี่ยนแปลงทันที

**🚫 ยกเลิกการสมัครรับการตลาดทั้งหมด**
- ปิดการสื่อสารทางการตลาดทั้งหมด (อีเมล, SMS, แอปทั้งหมด)
- ยังคงเปิดใช้งานอีเมลธุรกรรม
- ใช้สำหรับลูกค้าที่ขอเลิกการสมัครรับทั้งหมด
- เคารพสิทธิ์ GDPR ในการถอนคำยินยอม

**📥 ส่งออกการตั้งค่าเป็น CSV**
- ส่งออกการตั้งค่าของลูกค้าไปยังสเปรดชีต
- รวมถึงฟิลด์การตั้งค่าทั้งหมดและการตั้งค่าเฉพาะแอป
- มีประโยชน์สำหรับการตรวจสอบการปฏิบัติตามกฎระเบียบและการวิเคราะห์
- รูปแบบ: CSV พร้อมหัวคอลัมน์

## ศูนย์ตั้งค่าบริการตนเองสำหรับลูกค้า

ลูกค้าสามารถจัดการการตั้งค่าของตนเองได้ที่ `/accounts/preferences/` เมื่อเข้าสู่ระบบแล้ว

### คุณสมบัติของศูนย์ความเป็นเจ้าของความยินยอม

**การกระทำเร็ว**
- **สมัครรับข้อความการตลาดทั้งหมด** — เปิดการสื่อสารทางการตลาดทั้งหมดในครั้งเดียว
- **ยกเลิกการรับข้อความทั้งหมด** — ปิดการสื่อสารทางการตลาดทั้งหมด (ข้อความการดำเนินการยังคงเปิดอยู่)

**บัตรความเป็นเจ้าของความยินยอม**
- **อีเมลการดำเนินการ** — อ่านเท่านั้น (เปิดอยู่เสมอ ระบุว่า "จำเป็น")
- **การสื่อสารทางการตลาด** — เปิด/ปิดด้วยการยืนยันรูปแบบ
- **การตั้งค่าบล็อก** — เปิด/ปิด ระบุความถี่ (ทันที รายสัปดาห์ รายเดือน)
- **โปรแกรมความภักดี** — เปิด/ปิด ประเภทการแจ้งเตือนเฉพาะ
- **โปรแกรมแนะนำเพื่อน** — เปิด/ปิด การแจ้งเตือนรางวัล
- **โปรแกรมพартเนอร์** — เปิด/ปิด การแจ้งเตือนค่าคอมมิชชิ่นและผลประโยชน์
- **การแจ้งเตือนผ่าน SMS** — สมัครรับ/ยกเลิก SMS (แสดงสถานะการยืนยัน)

**การอัปเดตแบบเรียลไทม์**
- การเปลี่ยนแปลงจะถูกบันทึกทันทีผ่าน AJAX
- ไม่จำเป็นต้องโหลดหน้าซ้ำ
- การตอบสนองทางภาพเมื่อบันทึกแล้ว

### กระบวนการยืนยันอีเมล

เมื่อลูกค้าเปิดใช้งานอีเมลการตลาด:

1. ลูกค้าสลับ "อีเมลการตลาด" เป็น ON
2. ระบบส่งอีเมลยืนยันพร้อมลิงก์เฉพาะ
3. ลูกค้าคลิกลิงก์ยืนยัน
4. อีเมลถูกยืนยันแล้ว (สัญลักษณ์ 📧✓ จะปรากฏขึ้น)
5. อีเมลการตลาดจะถูกส่งแล้ว

**ลูกค้าที่ยังไม่ยืนยันจะไม่ได้รับอีเมลการตลาด** แม้ว่าจะตั้งค่าเป็น ON ก็ตาม ซึ่งช่วยให้ระบบปฏิบัติตามข้อกำหนดของ GDPR ในการยืนยันสองชั้น

## การยกเลิกการรับข้อความแบบคลิกเดียว

อีเมลการตลาดทั้งหมดมีลิงก์ยกเลิกการรับข้อความในส่วนท้าย คลิกลิงก์นี้:

1. นำลูกค้าไปยัง `/accounts/unsubscribe/<token>/` (ไม่จำเป็นต้องเข้าสู่ระบบ)
2. แสดงว่าลูกค้ากำลังยกเลิกการรับข้อความอะไร
3. อนุญาตให้ให้ความคิดเห็นแบบเลือกได้ (เหตุผลในการยกเลิกการรับข้อความ)
4. ปิดการสื่อสารทางการตลาด
5. ยังคงเปิดอีเมลการดำเนินการไว้อยู่
6. ให้ลิงก์ไปยังศูนย์ความเป็นเจ้าของความยินยอมทั้งหมด

ลูกค้าสามารถสมัครรับข้อความใหม่ได้ตลอดเวลาผ่านศูนย์ความเป็นเจ้าของความยินยอม

## ข้อกำหนดด้านกฎหมายและกฎหมาย

### การปฏิบัติตามข้อกำหนดของ GDPR มาตรา 7

ระบบจัดการให้ปฏิบัติตามข้อกำหนดของ GDPR มาตรา 7 อย่างสมบูรณ์:

รักษารูปแบบ Markdown เดิม ชื่อไฟล์รูปภาพ บล็อกโค้ด และคำศัพท์ทางเทคนิค

**✅ หลักฐานการยินยอม**
- เวลาที่ลูกค้ายินยอม
- แหล่งที่มาของข้อมูลการยินยอม (การลงทะเบียน, การชำระเงิน, ศูนย์ความเป็นเจ้าของ)
- ที่อยู่ IP ของลูกค้า
- ข้อมูลเบราว์เซอร์ (User agent)

**✅ การยินยอมแยกต่างหาก**
- การจัดส่งอีเมลเชิงการตลาดและอีเมลเชิงธุรกรรมเป็นตัวเลือกแยกต่างหาก
- แต่ละแอป (เช่น บล็อก, คะแนนความภักดี) ต้องการการยินยอมเป็นของตัวเอง

**✅ การถอนการยินยอมได้ง่าย**
- ลิงก์ยกเลิกการสมัครในอีเมลการตลาดทุกฉบับ
- ศูนย์ความเป็นเจ้าของมีให้ลูกค้าที่ล็อกอินแล้วทั้งหมด
- การยกเลิกการสมัครเกิดขึ้นทันที

**✅ การยินยอมที่ได้รับโดยสมัครใจ**
- ค่าเริ่มต้นคือการไม่สมัคร (opt-out) สำหรับการตลาด (แนวทางปฏิบัติที่ดีตาม GDPR)
- ไม่มีช่องทำเครื่องหมายไว้ล่วงหน้า (ลูกค้าต้องเลือกสมัครด้วยตนเอง)

**✅ การยินยอมที่ชัดเจนและมีข้อมูล**
- คำอธิบายที่ชัดเจนเกี่ยวกับสิ่งที่แต่ละตัวเลือกควบคุม
- ตัวเลือกระดับแอปที่ละเอียด (ไม่ใช่ทั้งหมดหรือไม่มีเลย)

**✅ การยืนยันการยินยอมได้**
- การยืนยันสองชั้นสำหรับอีเมลการตลาด
- บันทึกการตรวจสอบผ่านสถานะของ EmailOutbox

### การปฏิบัติตามกฎหมาย TCPA (กฎระเบียบ SMS ของสหรัฐอเมริกา)

การแจ้งเตือนทั้งหมดผ่าน SMS ต้องมี **การยินยอมแบบชัดเจน**:

- ลูกค้าต้องคลิกช่องยินยอม SMS ด้วยตนเอง
- ไม่มีช่องทำเครื่องหมายไว้ล่วงหน้า
- มีคำอธิบายชัดเจนว่าพวกเขาต้องการยินยอมในสิ่งใด
- ลูกค้าสามารถยกเลิกการสมัครได้ง่ายผ่านศูนย์ความเป็นเจ้าของ
- การส่ง SMS ทั้งหมดถูกบันทึกไว้เพื่อการตรวจสอบตามกฎหมาย

### การปฏิบัติตามกฎหมาย CAN-SPAM (กฎระเบียบอีเมลของสหรัฐอเมริกา)

ระบบจัดการอีเมลของ Spwig รับรองว่าปฏิบัติตามกฎหมาย CAN-SPAM:

- มีลิงก์ยกเลิกการสมัครในอีเมลการตลาดทุกฉบับ
- การยกเลิกการสมัครจะดำเนินการทันที (กฎหมายกำหนดให้ดำเนินการภายใน 10 วันทำการ แต่ระบบของเราทำทันที)
- ชื่อผู้ส่ง (From) ชัดเจน (ชื่อร้านค้าของคุณ)
- ที่อยู่ที่ตั้งของร้านค้าในส่วนท้ายอีเมล
- ไม่มีหัวข้ออีเมลที่ทำให้ผิดพลาด

## การเข้าใจสถานะอีเมลใน EmailOutbox

เมื่อคุณเข้าไปที่ **ระบบอีเมล > กล่องออกอีเมล** คุณจะเห็นว่าความตั้งค่ามีผลต่อการส่งอีเมลอย่างไร:

| สถานะ | ความหมาย | เหตุผล |
|--------|---------|--------|
| **ค้าง** | อีเมลถูกจัดลำดับเพื่อส่ง | ความตั้งค่าอนุญาตให้ส่งอีเมลนี้ |
| **ถูกจัดลำดับ** | อยู่ในคิวการส่ง | ความตั้งค่าอนุญาตให้ส่งอีเมลนี้ |
| **ถูกข้าม** | อีเมลไม่ได้ถูกส่ง | ความตั้งค่าของลูกค้าถูกปิด |
| **ส่งแล้ว** | ส่งได้สำเร็จ | ส่งอีเมลตามปกติ |

เมื่ออีเมลถูก **ข้าม** (skipped) ฟิลด์ `skip_reason` จะแสดงเหตุผล:

- **user_preference_disabled** — ลูกค้าปิดการรับอีเมลประเภทนี้ในตั้งค่าการตั้งค่า
- **email_not_verified** — ลูกค้ายังไม่ได้ยืนยันที่อยู่อีเมล
- **email_disabled** — ลูกค้าปิดการรับอีเมลทั้งหมด (สวิตช์หลัก)

บันทึกการตรวจสอบนี้มีความสำคัญสำหรับการปฏิบัติตาม GDPR — คุณสามารถพิสูจน์ได้ว่าได้เคารพการตั้งค่าของลูกค้า

## การตั้งค่าไซต์สำหรับการตั้งค่า

ไปที่ **Settings > Site Settings** เพื่อกำหนดค่าค่าเริ่มต้นของการตั้งค่าทั่วโลก:

**Enable Double Opt-In for Marketing Emails** (ค่าเริ่มต้น: ใช่)
- ต้องมีการยืนยันอีเมลก่อนส่งอีเมลการตลาด
- เป็นแนวปฏิบัติที่ดีสำหรับ GDPR
- แนะนำ: ให้อยู่ในสถานะเปิด

**Default Marketing Opt-In State** (ค่าเริ่มต้น: ไม่ - Opt-Out)
- สถานะเริ่มต้นเมื่อลูกค้าใหม่ลงทะเบียน
- GDPR กำหนดให้ต้องเป็น opt-out โดยค่าเริ่มต้น
- แนะนำ: ให้อยู่ในสถานะ opt-out (False)

**Preference Center Enabled** (ค่าเริ่มต้น: ใช่)
- อนุญาตให้ลูกค้าจัดการการตั้งค่าของตนเอง
- จำเป็นสำหรับสิทธิ์ในการถอนความยินยอมตาม GDPR
- แนะนำ: ให้อยู่ในสถานะเปิด

**Require SMS Verification** (ค่าเริ่มต้น: ไม่)
- ต้องมีการยืนยันหมายเลขโทรศัพท์สำหรับการแจ้งเตือน SMS
- เป็นตัวเลือกแต่แนะนำสำหรับผู้ส่ง SMS ปริมาณมาก
- สามารถเปิดได้หากต้องการ double opt-in สำหรับ SMS

**Show Unsubscribe Reasons** (ค่าเริ่มต้น: ใช่)
- รวบรวมข้อมูลป้อนกลับแบบไม่บังคับเมื่อลูกค้ายกเลิกการรับ
- ช่วยทำความเข้าใจว่าทำไมลูกค้าจึงเลือก opt-out
- แนะนำ: ให้อยู่ในสถานะเปิดเพื่อข้อมูลเชิงลึก

## แนวปฏิบัติที่ดีที่สุด

### 1. ตั้งค่าเริ่มต้นเป็น Opt-Out สำหรับการตลาด

ให้สื่อสารการตลาดเป็น **opt-out** (ไม่ถูกติ๊ก) เสมอ:
- เป็นไปตาม GDPR
- สร้างความไว้วางใจกับลูกค้า
- ลดข้อร้องเรียนเรื่องสแปม
- ส่งเฉพาะลูกค้าที่สนใจ

### 2. ต้องมีการยืนยันอีเมล

ให้ **Double Opt-In** อยู่ในสถานะเปิด:
- รับประกันว่าที่อยู่อีเมลถูกต้อง
- ยืนยันว่าลูกค้าต้องการรับอีเมลการตลาดจริงๆ
- ลดอัตราการส่งกลับ (bounce rate)
- จำเป็นสำหรับการปฏิบัติตาม GDPR

### 3. เคารพการตั้งค่าทันที



เมื่อลูกค้าเปลี่ยนการตั้งค่า:
- การเปลี่ยนแปลงมีผลทันที
- แคชการตั้งค่าถูกยกเลิก
- การส่งอีเมลครั้งถัดไปจะตรวจสอบการตั้งค่าที่อัปเดตแล้ว
- ไม่มีการล่าช้าในการปฏิบัติตามคำขอเลิกสมัครรับ

### 4. ตรวจสอบอีเมลที่ถูกข้าม

ตรวจสอบ **กล่องจดหมายขาออก (Email Outbox)** เป็นประจำสำหรับอีเมลที่ถูกข้าม:
- อัตราการข้ามที่สูงบ่งชี้ว่าลูกค้ากำลังเลิกสมัครรับ
- อาจเป็นสัญญาณว่าเนื้อหาอีเมลต้องได้รับการปรับปรุง
- ช่วยระบุปัญหาเกี่ยวกับการตั้งค่า

### 5. การตรวจสอบความสอดคล้องเป็นระยะ

ส่งออกการตั้งค่าเป็นระยะเพื่อตรวจสอบความสอดคล้อง:
1. ไปที่ **การตั้งค่าการสื่อสาร (Communication Preferences)**
2. เลือกลูกค้าทั้งหมด
3. เลือก **ส่งออกการตั้งค่าเป็น CSV (Export Preferences to CSV)**
4. บันทึกเพื่อใช้เป็นหลักฐานการตรวจสอบ GDPR

จัดเก็บข้อมูลที่ส่งออกไว้ **อย่างน้อย 3 ปี** เพื่อปฏิบัติตามข้อกำหนดการเก็บข้อมูลของ GDPR

### 6. การสื่อสารที่ชัดเจน

เมื่อรวบรวมการยินยอม:
- ใช้ภาษาที่เข้าใจง่าย ไม่ใช่ศัพท์ทางกฎหมาย
- อธิบายว่าลูกค้าจะได้รับอะไร
- แสดงความถี่ (รายวัน, รายสัปดาห์, รายเดือน)
- ทำให้อาสาสมัคร (opt-in boxes) โดดเด่นแต่ไม่ถูกติ๊กไว้ล่วงหน้า

### 7. แบ่งกลุ่มตามการตั้งค่า

เมื่อส่งแคมเปญการตลาด:
- ส่งเฉพาะลูกค้าที่ตรวจสอบแล้วและสมัครรับ
- เคารพการตั้งค่าเฉพาะแอป (อย่าส่งอีเมลบล็อกไปยังลูกค้าที่ปิดการตั้งค่าบล็อก)
- ใช้การตั้งค่าความถี่ (อย่าส่งอีเมลทันทีไปยังผู้สมัครรับสรุปข่าวรายสัปดาห์)

## เคล็ดลับ

**💡 ตรวจสอบการตั้งค่าก่อนส่ง**

ระบบจะตรวจสอบการตั้งค่าโดยอัตโนมัติเมื่อคุณส่งอีเมลโดยใช้ `EmailSendingService.send_template_email()` ตรวจสอบให้แน่ใจว่าการส่งอีเมลทั้งหมดใช้บริการนี้ ไม่ใช่การเรียก SMTP โดยตรง

**💡 สถานะที่ถูกข้ามเป็นเรื่องปกติ**

อย่าตกใจกับอีเมลที่ถูกข้ามในกล่องจดหมายขาออก — หมายความว่าระบบทำงานได้อย่างถูกต้องและเคารพการตั้งค่าของลูกค้า การข้ามอีเมลที่ไม่ต้องการดีกว่าเสี่ยงถูกปรับตาม GDPR หรือได้รับข้อร้องเรียนเรื่องสแปม

**💡 แคชการตั้งค่ามีอายุ 5 นาที**

การตรวจสอบการตั้งค่าจะถูกแคชไว้ 5 นาทีเพื่อประสิทธิภาพ เมื่อลูกค้าเปลี่ยนการตั้งค่าผ่านศูนย์การตั้งค่าหรือการดำเนินการของแอดมิน แคชจะถูกยกเลิกทันทีเพื่อให้การเปลี่ยนแปลงมีผลทันที

**💡 ลูกค้าผู้เยี่ยมชม (Guest) ข้ามการตรวจสอบ**

ลูกค้าที่ใช้การชำระเงินแบบแขกรับเชิญ (ไม่มีบัญชี) จะได้รับอีเมลทั้งหมดตามปกติ เนื่องจากไม่มีบันทึกการตั้งค่าความชอบ

นี่เป็นสิ่งที่ตั้งใจไว้ — พวกเขาได้ให้ความยินยอมโดยให้ข้อมูลอีเมลในขั้นตอนการชำระเงิน

**💡 อีเมลธุรกรรมจะส่งเสมอ**

การยืนยันคำสั่งซื้อ การอัปเดตการจัดส่ง และอีเมลความปลอดภัยของบัญชี **จะส่งเสมอ** ไม่ว่าการตั้งค่าความชอบจะเป็นอย่างไร สิ่งนี้ช่วยให้ลูกค้าได้รับข้อมูลสำคัญเกี่ยวกับคำสั่งซื้อและบัญชีของพวกเขา

**💡 ใช้การดำเนินการแบบกลุ่มอย่างระมัดระวัง**

การดำเนินการแบบกลุ่ม "ยกเลิกการรับอีเมลการตลาดทั้งหมด" จะส่งผลต่อ **แอปทั้งหมด** (บล็อก, ความภักดี, การแนะนำ, พันธมิตร) ใช้สิ่งนี้เฉพาะสำหรับลูกค้าที่ร้องขออย่างชัดเจนให้ยกเลิกการรับอีเมลทั้งหมดเท่านั้น สำหรับความชอบเฉพาะ ให้แก้ไขบันทึกของลูกค้าแต่ละราย

**💡 ร่องรอยการตรวจสอบเพื่อปฏิบัติตามกฎระเบียบ**

ระบบติดตาม:
- เวลาและแหล่งที่มาของการให้ความยินยอม
- ที่อยู่ IP และ user agent
- เวลาการยืนยันอีเมล
- การเปลี่ยนแปลงความชอบทุกครั้งผ่านสถานะ EmailOutbox ที่ถูกข้าม

ร่องรอยการตรวจสอบนี้พิสูจน์การปฏิบัติตาม GDPR หากหน่วยงานรัฐร้องขอหลักฐานการให้ความยินยอม
