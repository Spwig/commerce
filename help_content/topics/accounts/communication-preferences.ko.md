---
title: 커뮤니케이션 설정
---

커뮤니케이션 설정을 통해 고객이 스토어에서 받는 이메일 및 SMS 메시지를 제어할 수 있습니다. 이 시스템은 GDPR 준수를 보장하고 모든 채널에서 고객의 커뮤니케이션 설정을 존중하는 데 도움이 됩니다.

관리자 사이드바에서 **고객 > 커뮤니케이션 설정**으로 이동하여 고객 커뮤니케이션 설정을 관리하세요.

## 커뮤니케이션 설정 이해하기

커뮤니케이션 설정 시스템은 고객이 받는 메시지에 대해 세밀한 제어를 제공합니다. 여기에는 다음이 포함됩니다:

- **거래 이메일** — 필수 주문 확인, 배송 업데이트, 계정 보안 이메일 (항상 켜짐)
- **마케팅 이메일** — 뉴스레터, 프로모션, 제품 추천 (옵트인 필요)
- **앱별 알림** — 블로그 게시물, 로열티 포인트, 추천 보상, 제휴 수수료
- **SMS 알림** — 문자 메시지 알림 (TCPA에 따라 명시적 옵트인 필요)

모든 마케팅 커뮤니케이션은 GDPR 준수를 위해 고객 동의 및 이메일 인증이 필요합니다.

## 설정 유형 설명

### 거래 커뮤니케이션 (항상 활성화됨)

거래 메시지는 고객의 계정 및 주문에 필수적입니다. 고객은 이를 **비활성화할 수 없습니다**:

| 유형 | 설명 | 예시 |
|------|-------------|----------|
| **주문 확인** | 주문이 접수되었을 때 확인 | 주문 #12345가 접수되었습니다 |
| **배송 업데이트** | 주문 상태가 변경될 때 알림 | 주문이 발송되었습니다 |
| **결제 확인** | 결제 완료, 환불 처리 | $49.99 결제가 확인되었습니다 |
| **계정 보안** | 비밀번호 재설정, 이메일 인증 | 비밀번호를 재설정하세요 |

### 마케팅 커뮤니케이션 (옵트인 필요)

마케팅 메시지는 고객 동의 및 이메일 인증이 필요합니다:

| 유형 | 설명 | 기본값 |
|------|-------------|---------|
| **뉴스레터** | 일반 뉴스레터 및 업데이트 | 옵트아웃 |
| **프로모션 제공** | 세일, 할인, 특별 제공 | 옵트아웃 |
| **제품 추천** | 개인화된 제품 제안 | 옵트아웃 |
| **재입고** | 제품이 재입고될 때 알림 | 옵트아웃 |

고객은 마케팅 이메일을 수신하기 전에 **이메일 주소를 확인**해야 합니다(GDPR 이중 옵트인 요구 사항).

### 앱별 설정

고객은 특정 기능의 알림을 제어할 수 있습니다:

**블로그 알림**
- 새 블로그 게시글 발행(즉시, 주간 다이제스트, 또는 월간 다이제스트)
- 카테고리별 구독
- 빈도 설정

**로열티 프로그램**
- 포인트 획득 알림
- 등급 승격
- 리워드 해제
- 곧 만료되는 포인트
- 생일 보너스
- 캠페인 제공

**추천 프로그램**
- 리워드 지급(추천인 및 추천 대상자)
- 성공적인 추천 가입
- 곧 만료되는 리워드
- 추천 초대

**제휴 프로그램**
- 수수료 획득
- 수수료 승인 또는 거부
- 지급 처리, 완료 또는 실패
- 월간 성과 보고서

### SMS 알림(명시적 옵트인 필요)

모든 SMS 알림은 TCPA 규정에 따라 **명시적 옵트인**이 필요합니다. 고객은 SMS 옵트인 상자를 능동적으로 선택해야 합니다:

- **거래 SMS** — 주문 발송, 배송 완료(옵트인 필요)
- **마케팅 SMS** — 프로모션, 특별 제공(별도 옵트인 필요)

거래 SMS도 수신하지 않은 텍스트 메시지 전송이 이메일보다 엄격하게 규제되므로 옵트인이 필요합니다.

## 관리자에서 고객 설정 관리

### 모든 설정 보기

**고객 > 커뮤니케이션 설정**으로 이동하여 모든 고객 설정을 확인합니다:


| 열 | 설명 |
|--------|-------------|
| **사용자 이메일** | 고객의 이메일 주소 (사용자 관리자로 링크) |
| **이메일 상태** | 이메일이 활성화된 경우 초록색 ✓, 비활성화된 경우 회색 ○ |
| **SMS 상태** | SMS가 활성화된 경우 초록색 ✓, 비활성화된 경우 회색 ○ |
| **마케팅 상태** | "동의함" 또는 "동의하지 않음" 뱃지 |
| **인증 상태** | 이메일이 인증된 경우 📧✓, SMS가 인증된 경우 📱✓ |
| **동의 원본** | 고객이 동의한 위치 (등록, 체크아웃, 선호도 센터) |
| **업데이트 시간** | 마지막으로 선호도가 변경된 시간 |

### 선호도 필터링

필터 사이드바를 사용하여 고객을 찾으세요:

- **이메일 활성화** — 예/아니요
- **SMS 활성화** — 예/아니요
- **이메일 마케팅** — 예/아니요 (마케팅에 동의함)
- **SMS 마케팅** — 예/아니요 (SMS 마케팅에 동의함)
- **이메일 인증** — 예/아니요 (이메일 주소 인증함)
- **SMS 인증** — 예/아니요 (전화번호 인증함)
- **동의 원본** — 등록, 체크아웃, 선호도 센터, API, 마이그레이션
- **언어 코드** — 커뮤니케이션을 위한 선호 언어

### 선호도 검색

다음으로 고객을 검색하세요:
- 사용자 이메일
- 사용자 이름
- 이름
- 성
- 구독 해제 토큰

### 대량 작업

여러 고객을 선택하고 대량 작업을 적용하세요:

**✓ 이메일을 인증됨으로 표시**
- 고객 이메일 주소를 수동으로 인증합니다
- 다른 시스템에서 고객을 가져올 때 유용합니다
- 선호도 캐시를 무효화하여 변경 사항을 즉시 적용합니다

**🚫 모든 마케팅에 대한 구독 해제**
- 모든 마케팅 통신 (이메일, SMS, 모든 앱)을 비활성화합니다
- 거래 이메일은 활성화된 상태로 유지합니다
- 고객이 완전히 구독 해제를 요청한 경우에 사용하세요
- GDPR의 동의 철회 권리에 따라 동의를 존중합니다

**📥 CSV로 선호도 내보내기**
- 고객 선호도를 스프레드시트로 내보냅니다
- 모든 선호도 필드 및 앱별 설정을 포함합니다
- 준수 감사 및 분석에 유용합니다
- 형식: 헤더가 있는 CSV

## 고객 자체 서비스 선호도 센터

로그인한 상태에서 고객은 `/accounts/preferences/`에서 자신의 선호도를 관리할 수 있습니다.

모든 마크다운 포맷, 이미지 경로, 코드 블록, 기술 용어를 보존하세요.

### 선호도 센터 기능

**빠른 작업**
- **모든 마케팅 구독** — 단일 클릭으로 모든 마케팅 커뮤니케이션 활성화
- **모든 구독 해지** — 모든 마케팅 커뮤니케이션 비활성화 (트랜잭션 이메일은 여전히 활성화됨)

**선호도 카드**
- **트랜잭션 이메일** — 읽기 전용 (항상 활성화됨, '필수'로 표시됨)
- **마케팅 커뮤니케이션** — 확인 버튼을 통해 켜기/끄기
- **블로그 선호도** — 주파수 선택 (즉시, 주간, 월간)으로 켜기/끄기
- **충성 프로그램** — 개별 알림 유형 켜기/끄기
- **추천 프로그램** — 보상 알림 켜기/끄기
- **제휴 프로그램** — 수수료 및 지급 알림 켜기/끄기
- **SMS 알림** — SMS 등록/해제 (확인 상태 표시됨)

**실시간 업데이트**
- AJAX를 통해 즉시 저장됨
- 페이지 새로 고침 필요 없음
- 저장 시 시각적 피드백 제공

### 이메일 인증 프로세스

고객이 마케팅 이메일을 활성화할 경우:

1. 고객이 '마케팅 이메일'을 ON으로 설정함
2. 시스템이 고유한 링크가 포함된 인증 이메일을 보냄
3. 고객이 인증 링크를 클릭함
4. 이메일이 인증됨 (📧✓ 표시됨)
5. 마케팅 이메일이 전송됨

**인증되지 않은 고객은** 마케팅 이메일을 수신하지 않음. 이는 GDPR 이중 동의 준수를 보장하기 위함임.

## 한 번의 클릭으로 구독 해지

모든 마케팅 이메일에는 푸터에 구독 해지 링크가 포함됨. 이 링크를 클릭하면:

1. 고객이 `/accounts/unsubscribe/<token>/`로 이동함 (로그인 필요 없음)
2. 구독 해지하는 항목 표시됨
3. 선택적 피드백 제공 (구독 해지 이유)
4. 마케팅 커뮤니케이션 비활성화됨
5. 트랜잭션 이메일은 활성화됨
6. 전체 선호도 센터로 이동하는 링크 제공됨

고객은 언제든지 선호도 센터를 통해 다시 구독할 수 있음.

## 준수 및 법적 요구사항

### GDPR 제7조 준수

시스템은 GDPR 제7조 준수를 보장함:



**✅ 동의 증명**
- 동의가 제공된 시간戳
- 동의 출처 (가입, 결제, 설정 센터)
- 동의 시 IP 주소
- 사용자 에이전트 (브라우저 정보)

**✅ 개별 동의**
- 마케팅 및 거래 이메일은 개별 토글로 관리됩니다
- 각 앱(블로그, 로열티 등)은 개별 동의를 요구합니다

**✅ 쉬운 철회**
- 모든 마케팅 이메일에 원클릭 구독 취소 제공
- 로그인한 모든 고객에게 설정 센터 제공
- 구독 취소는 즉시 적용됩니다

**✅ 자발적 동의**
- 마케팅의 기본값은 옵트아웃입니다 (GDPR 모범 사례)
- 미리 체크된 상자가 없습니다 (고객이 능동적으로 옵트인해야 함)

**✅ 구체적이고 정보에 기반한 동의**
- 각 설정이 무엇을 제어하는지에 대한 명확한 설명
- 세분화된 앱 수준 설정 (전체 또는 무조건 방식 아님)

**✅ 검증 가능한 동의**
- 마케팅 이메일에 이중 옵트인 적용
- EmailOutbox 상태 추적을 통한 감사 추적

### TCPA 준수 (미국 SMS 규정)

모든 SMS 알림은 **명시적 옵트인**을 요구합니다:

- 고객이 SMS 옵트인 상자를 능동적으로 체크해야 합니다
- 미리 체크된 상자는 허용되지 않습니다
- 무엇을 옵트인하는지에 대한 명확한 설명
- 설정 센터를 통한 쉬운 옵트아웃
- 규정 준수를 위해 모든 SMS 전송이 기록됩니다

### CAN-SPAM 준수 (미국 이메일 규정)

시스템은 CAN-SPAM 준수를 보장합니다:

- 모든 마케팅 이메일에 구독 취소 링크 포함
- 구독 취소 즉시 처리 (10영업일 이내 처리 요구, 우리는 즉시 처리)
- 명확한 "From" 이름 (귀하의 상점 이름)
- 이메일 하단에 실제 주소 포함
- 기만적인 제목 사용 금지

## EmailOutbox에서 이메일 상태 이해하기

**이메일 시스템 > 이메일 발신함**을 볼 때, 설정이 이메일 전달에 어떻게 영향을 미치는지 확인할 수 있습니다:

| 상태 | 의미 | 이유 |
|--------|---------|--------|
| **대기 중** | 전송을 위해 대기 중인 이메일 | 설정이 이 이메일을 허용함 |
| **큐에 있음** | 전송 큐에 있음 | 설정이 이 이메일을 허용함 |
| **건너뜀** | 이메일이 전송되지 않음 | 고객 설정이 비활성화됨 |
| **전송됨** | 성공적으로 전달됨 | 이메일이 정상적으로 전송됨 |

이메일이 **건너뛰기(skipped)**된 경우, `skip_reason` 필드에 그 이유가 표시됩니다:

- **user_preference_disabled** — 고객이 설정에서 해당 이메일 유형을 비활성화했습니다
- **email_not_verified** — 고객이 이메일 주소를 인증하지 않았습니다
- **email_disabled** — 고객이 모든 이메일을 비활성화했습니다(마스터 토글)

이 감사 추적은 GDPR 준수에 중요합니다 — 고객 설정을 존중했음을 입증할 수 있습니다.

## 설정 > 사이트 설정

**설정 > 사이트 설정**으로 이동하여 전역 기본 설정을 구성합니다:

**마케팅 이메일 이중 옵트인 활성화** (기본값: 예)
- 마케팅 이메일 전송 전 이메일 인증 필요
- GDPR 모범 사례
- 권장: 활성화 상태로 유지

**기본 마케팅 옵트인 상태** (기본값: 아니오 - 옵트아웃)
- 신규 고객 등록 시 기본 상태
- GDPR은 기본적으로 옵트아웃을 요구합니다
- 권장: 옵트아웃(False)으로 유지

**설정 센터 활성화** (기본값: 예)
- 고객이 자신의 설정을 관리할 수 있도록 허용
- GDPR의 동의 철회 권리를 위해 필수
- 권장: 활성화 상태로 유지

**SMS 인증 요구** (기본값: 아니오)
- SMS 알림을 위해 전화번호 인증 요구
- 대량 SMS 발송자에게는 선택 사항이지만 권장됨
- SMS에 이중 옵트인을 원할 경우 활성화 가능

**구독 해제 사유 표시** (기본값: 예)
- 고객이 구독을 해제할 때 선택적 피드백 수집
- 고객이 옵트아웃하는 이유를 이해하는 데 도움
- 권장: 인사이트를 위해 활성화 상태로 유지

## 모범 사례

### 1. 마케팅은 기본적으로 옵트아웃으로 설정

마케팅 커뮤니케이션은 항상 **옵트아웃**(미선택)으로 기본 설정하세요:
- GDPR 준수
- 고객 신뢰 구축
- 스팸 신고 감소
- 참여도가 높은 고객에게만 전송

### 2. 이메일 인증 요구

**이중 옵트인**을 활성화 상태로 유지하세요:
- 이메일 주소가 유효함을 보장
- 고객이 실제로 마케팅 이메일을 원함을 확인
- 바운스율 감소
- GDPR 준수를 위해 필수

### 3. 설정을 즉시 존중

고객이 설정을 변경할 때:
- 변경 사항은 즉시 적용됩니다
- 설정 캐시가 무효화됩니다
- 다음 이메일 전송 시 업데이트된 설정이 확인됩니다
- 구독 해지 요청 처리에 지연이 없습니다

### 4. 건너뛴 이메일 모니터링

**이메일 발신함**에서 건너뛴 이메일을 정기적으로 확인하세요:
- 높은 건너뛰기율은 고객이 구독을 해지하고 있음을 나타냅니다
- 이메일 콘텐츠 개선이 필요하다는 신호일 수 있습니다
- 설정 문제를 식별하는 데 도움이 됩니다

### 5. 정기적인 규정 준수 감사

규정 준수를 위해 설정을 주기적으로 내보내세요:
1. **통신 설정**으로 이동
2. 모든 고객 선택
3. **설정을 CSV로 내보내기** 선택
4. GDPR 감사 기록을 위해 저장

GDPR 데이터 보존 요구 사항을 준수하기 위해 내보낸 파일을 **최소 3년** 동안 보관하세요.

### 6. 명확한 소통

동의 사항을 수집할 때:
- 법률 용어가 아닌 평이한 언어를 사용하세요
- 고객이 무엇을 받을지 설명하세요
- 빈도(일일, 주간, 월간)를 표시하세요
- 구독 확인란을 눈에 띄게 하되 미리 체크하지 마세요

### 7. 설정별 세분화

마케팅 캠페인을 전송할 때:
- 인증된 구독 고객에게만 전송하세요
- 앱별 설정을 존중하세요(블로그를 비활성화한 고객에게 블로그 이메일을 보내지 마세요)
- 빈도 설정을 사용하세요(주간 다이제스트 구독자에게 즉시 이메일을 보내지 마세요)

## 팁

**💡 전송 전 설정 확인**

`EmailSendingService.send_template_email()`을 사용하여 이메일을 전송할 때 시스템이 자동으로 설정을 확인합니다. 모든 이메일 전송이 이 서비스를 사용하도록 하세요. 직접 SMTP 호출을 사용하지 마세요.

**💡 건너뛴 상태는 정상입니다**

발신함에서 건너뛴 이메일을 보고 놀라지 마세요 — 이는 시스템이 올바르게 작동하고 고객 설정을 존중하고 있음을 의미합니다. 원치 않는 이메일을 건너뛰는 것이 GDPR 벌금이나 스팸 신고 위험을 감수하는 것보다 낫습니다.

**💡 설정 캐시는 5분입니다**

성능을 위해 설정 확인은 5분 동안 캐시됩니다. 고객이 설정 센터 또는 관리자 작업을 통해 설정을 변경하면 캐시가 즉시 무효화되어 변경 사항이 바로 적용됩니다.

**💡 게스트 고객은 확인을 우회합니다**

게스트 체크아웃 고객(계좌 없음)은 선호도 기록이 없으므로 모든 이메일을 정상적으로 수신합니다.

이것은 의도된 동작입니다 — 체크아웃 시 이메일을 제공함으로써 동의한 것입니다.

**💡 거래 관련 이메일은 항상 전송됩니다**

주문 확인, 배송 업데이트 및 계정 보안 이메일은 선호도와 관계없이 **항상 전송**됩니다. 이를 통해 고객이 주문 및 계정에 대한 중요한 정보를 수신할 수 있습니다.

**💡 일괄 작업을 신중하게 사용하세요**

"모든 마케팅에서 구독 해제" 일괄 작업은 **모든 앱**(블로그, 로열티, 추천, 제휴)에 영향을 미칩니다. 이 작업은 완전히 구독 해제를 명시적으로 요청한 고객에게만 사용하세요. 특정 선호도를 설정하려면 개별 고객 기록을 편집하세요.

**💡 규정 준수용 감사 추적**

시스템은 다음을 추적합니다:
- 동의 타임스탬프 및 출처
- IP 주소 및 사용자 에이전트
- 이메일 인증 타임스탬프
- EmailOutbox 건너뜀 상태를 통한 모든 선호도 변경

이 감사 추적은 당국이 동의 증거를 요청할 경우 GDPR 규정 준수를 입증합니다.
