หากร้านค้าของคุณกำลังใช้งาน WooCommerce อยู่ในปัจจุบัน โปรแกรมช่วยย้ายข้อมูลของ Spwig สามารถนำเข้าสินค้า ลูกค้า คำสั่งซื้อ และเนื้อหาโดยตรงผ่าน REST API ของ WooCommerce คู่มือนี้ครอบคลุมการขอข้อมูล API การดำเนินการนำเข้า และคุณสมบัติเฉพาะของ WooCommerce สองอย่างที่ควรรู้ก่อน: ปลั๊กอิน Migration Bridge ที่เป็นตัวเลือกสำหรับข้อมูลพันธมิตร และการสนับสนุนในตัวสำหรับปลั๊กอิน WooCommerce ยอดนิยมหลายตัว

## ก่อนเริ่มต้น

WooCommerce มีการสนับสนุนที่กว้างที่สุดเมื่อเทียบกับแพลตฟอร์มแหล่งข้อมูลอื่น ๆ ในโปรแกรมช่วยย้ายข้อมูล ข้อมูลต่อไปนี้สามารถนำเข้าได้อย่างถูกต้อง: หมวดหมู่ (พร้อมลำดับชั้น), สินค้า, รูปภาพและตัวเลือก, ลูกค้าและที่อยู่, คำสั่งซื้อ, รีวิว, คูปอง, และบล็อกพร้อมหมวดหมู่, แท็ก และรูปภาพ

โปรไฟล์พันธมิตร, บันทึกค่าคอมมิชชัน และประวัติการจ่ายเงินสามารถนำเข้าได้เช่นกัน แต่เฉพาะเมื่อคุณติดตั้งปลั๊กอิน Spwig Migration Bridge ก่อน — ดูข้อมูลด้านล่าง ถ้าไม่ติดตั้ง ข้อมูลเหล่านั้นจะถูกข้ามไปโดยอัตโนมัติ

โปรดทราบเพิ่มเติมดังนี้:

- สินค้าจากปลั๊กอิน WooCommerce บางตัว (การสมัครสมาชิก, ชุดสินค้า, การจอง, บัตรของขวัญ) จะถูกนำเข้าไปยังคุณสมบัติที่ตรงกันใน Spwig แต่ไม่ใช่ทุกรายละเอียดจะถูกนำเข้ามา — ดู **การสนับสนุนปลั๊กอิน WooCommerce** ด้านล่าง
- ฟิลด์เฉพาะในสินค้า ลูกค้า และคำสั่งซื้อของคุณจะถูกตรวจจับโดยอัตโนมัติ และจำเป็นต้องกำหนดการจับคู่ในขั้นตอนถัดไป ดู [การจับคู่ฟิลด์การย้ายข้อมูล](migration-field-mapping)
- ตัวเลือก **นำเข้าการตั้งค่าภาษี** และ **นำเข้าโซนและวิธีการจัดส่ง** ของโปรแกรมช่วยย้ายข้อมูลจะไม่ถูกนำไปใช้กับข้อมูลที่นำเข้ามา ตั้งค่าอัตราภาษีและวิธีการจัดส่งใน Spwig ด้วยตนเองหลังจากนั้น — ดู [หลังการย้ายข้อมูลของคุณ](after-migration-review)
- ตัวเลือก **การปรับราคา** ในขั้นตอนเดียวกัน *จะ* ถูกนำไปใช้กับการนำเข้าจาก WooCommerce ซึ่งจะเปลี่ยนราคาพื้นฐานของสินค้าขณะสร้าง ตั้งค่าเป็น **ไม่มี** เว้นแต่คุณต้องการปรับราคาทุกตัวโดยเจตนา

เตรียมบัญชีผู้ดูแล WordPress ของคุณไว้ และทราบจำนวนสินค้า ลูกค้า และคำสั่งซื้อที่คุณกำลังนำเข้าโดยประมาณ เพื่อที่คุณจะสามารถตรวจสอบความถูกต้องของจำนวนที่โปรแกรมช่วยย้ายข้อมูลแสดงให้คุณได้

## การขอข้อมูล REST API

Spwig เชื่อมต่อกับ WooCommerce โดยใช้ REST API key ที่สร้างขึ้นจาก WordPress admin ของคุณ

คีย์นี้ต้องการสิทธิ์ **Read** เท่านั้น — Spwig จะอ่านข้อมูลจากร้านค้าของคุณเพียงอย่างเดียวในระหว่างการย้ายข้อมูล และจะไม่เขียนอะไรกลับไปเลย

1. ใน WordPress ให้ไปที่ **WooCommerce > Settings > Advanced > REST API**
2. คลิก **Add key**
3. ให้คำอธิบาย (เช่น `Spwig Migration`) และตั้งค่า **Permissions** เป็น **Read**
4. คลิก **Generate API key**
5. คัดลอก **Consumer Key** (`ck_...`) และ **Consumer Secret** (`cs_...`) ไปยังสถานที่ปลอดภัย

> **สำคัญ:** WooCommerce จะแสดง Consumer Secret ได้เพียงครั้งเดียว ขณะที่คุณกำลังสร้างมัน หากคุณออกจากหน้าก่อนที่จะคัดลอกมัน คุณจะต้องสร้างคีย์ใหม่

## การเชื่อมต่อร้านค้าของคุณ

ไปที่ **Data Import & Export > Start New Migration** ใน Spwig admin และเลือก **WooCommerce** ที่ขั้นตอนที่ 1 ที่ขั้นตอนที่ 2 ให้กรอก:

- **Store URL** — ที่อยู่เว็บไซต์เต็มของร้านค้าของคุณ เช่น `https://mystore.com`
- **Consumer Key** และ **Consumer Secret** — ค่าที่คุณเพิ่งคัดลอก

ให้ตรวจสอบ **Test connection before proceeding** (เปิดใช้งานโดยค่าเริ่มต้น) เพื่อให้ Spwig ยืนยันว่าสามารถเข้าถึงร้านค้าและตรวจสอบสิทธิ์ของคุณได้ก่อนที่คุณจะดำเนินการต่อ — นี่จะช่วยตรวจจับข้อผิดพลาดในการพิมพ์และปัญหาเกี่ยวกับสิทธิ์ได้ทันที แทนที่จะเกิดขึ้นระหว่างการนำเข้า คลิก **Next** เมื่อการเชื่อมต่อสำเร็จ

## การตรวจสอบและเลือกข้อมูล

ขั้นตอนที่ 3 จะดึงข้อมูลจำนวนจริงจากร้านค้าของคุณ — หมวดหมู่ ผลิตภัณฑ์ ลูกค้า คำสั่งซื้อ รีวิว และคูปอง — รวมถึงตัวอย่างผลิตภัณฑ์ 5 รายการแรก เพื่อให้คุณตรวจสอบว่ามันอ่านข้อมูลจากเว็บไซต์ที่ถูกต้อง ช่องถูกติ๊กสำหรับแต่ละประเภทข้อมูลจะถูกติ๊กอัตโนมัติเมื่อจำนวนข้อมูลนั้นมากกว่าศูนย์ และจะถูกปิดใช้งานเมื่อจำนวนข้อมูลนั้นเป็นศูนย์

**ตัวเลือกการนำเข้า**:

- **ข้ามรายการที่มีอยู่แล้ว** (เปิดใช้งาน) — เปรียบเทียบรายการที่เข้ามา กับรายการที่มีอยู่ใน Spwig (SKU สำหรับผลิตภัณฑ์ อีเมลสำหรับลูกค้า) และข้ามรายการที่ซ้ำกัน

ปล่อยไว้ตามค่าเริ่มต้นเว้นแต่คุณจะเริ่มจากร้านค้าว่าง
- **นำเข้ารูปภาพสินค้า** (เปิด) — ช้ากว่า แต่คุ้มค่า
- **รักษา ID เดิมเมื่อเป็นไปได้** (ปิด) — วิธีการนี้เองที่ระบุว่า "ไม่แนะนำ" ให้ปล่อยไว้เป็นปิด เว้นแต่คุณมีเหตุผลทางเทคนิคเฉพาะที่ต้องการรักษา ID ตัวเลขของ WooCommerce
- **ขนาดแบตช์** — 10, 25 (ค่าเริ่มต้น), 50 หรือ 100 รายการทีละครั้ง

แบตช์ขนาดเล็กเหมาะกับการเชื่อมต่อที่ไม่มั่นคง; แบตช์ขนาดใหญ่จะเสร็จเร็วขึ้นเมื่อเชื่อมต่อเสถียร

## ปลั๊กอิน Spwig Migration Bridge

WooCommerce ไม่มีแนวคิดในตัวเกี่ยวกับโปรแกรมพันธมิตร ดังนั้นหากคุณดำเนินการผ่านปลั๊กอินพันธมิตรของ WooCommerce ข้อมูลนั้นจะอยู่ในตารางที่ API แบบมาตรฐาน REST ไม่สามารถมองเห็นได้ ปลั๊กอิน **Spwig Migration Bridge** เป็นปลั๊กอินขนาดเล็กที่คุณติดตั้งบนเว็บไซต์ WordPress เพื่อเปิดเผยข้อมูลนั้น

ปลั๊กอิน Bridge ช่วยให้คุณสามารถ:

- **โปรไฟล์พันธมิตร** — รายละเอียดของพันธมิตรและรหัสแนะนำ
- **บันทึกค่าคอมมิชชัน** — ประวัติค่าคอมมิชชันที่เกี่ยวข้องกับแต่ละพันธมิตร
- **ประวัติการจ่ายเงิน** — การจ่ายเงินในอดีตที่ทำให้กับพันธมิตร

มันเป็นตัวเลือกที่ไม่จำเป็น — ข้ามมันไปหากคุณไม่ดำเนินการโปรแกรมพันธมิตร หรือไม่จำเป็นต้องมีประวัติใน Spwig

> **หมายเหตุ:** ข้อมูลพันธมิตรสามารถนำเข้าได้ก็ต่อเมื่อคุณนำเข้าคำสั่งซื้อและลูกค้าในครั้งย้ายข้อมูลเดียวกัน เนื่องจากค่าคอมมิชชันและการจ่ายเงินมีความเกี่ยวข้องกับคำสั่งซื้อและลูกค้าเฉพาะ

วิธีติดตั้ง:

1. ในขั้นตอนที่ 3 หากปลั๊กอินยังไม่ถูกตรวจพบในเว็บไซต์ของคุณ คุณจะเห็นปุ่ม **ดาวน์โหลดปลั๊กอิน Bridge** พร้อมคำแนะนำการติดตั้ง
2. ดาวน์โหลดไฟล์ ZIP ของปลั๊กอิน
3. ใน WordPress ให้ไปที่ **Plugins > Add New > Upload Plugin** เลือกไฟล์ ZIP คลิก **Install Now** แล้ว **Activate**
4. กลับไปที่เวิร์ดเพรสและรีเฟรชหน้า — กล่องถูกติ๊ก **Affiliates** และบล็อก **Affiliate Program Data** จะปรากฏขึ้น แสดงจำนวนที่พบ

คุณสามารถปิดใช้งานและลบปลั๊กอิน Bridge ออกจาก WordPress หลังจากที่การย้ายข้อมูลของคุณเสร็จสิ้น

## การสนับสนุนจากปลั๊กอิน WooCommerce


# การนำเข้าข้อมูล WooCommerce

หากร้านค้าของคุณใช้ส่วนขยายที่เป็นที่นิยมบางตัว ผลิตภัณฑ์ที่สร้างโดยส่วนขยายเหล่านั้นจะถูกจัดการในระหว่างการนำเข้าและจัดส่งไปยังฟีเจอร์ที่ตรงกันใน Spwig แทนที่จะนำเข้าเป็นผลิตภัณฑ์ทั่วไป:

| ส่วนขยาย WooCommerce | ถูกจัดส่งไปยัง |
|---|---|
| Subscriptions | แผนการสมัครสมาชิกของ Spwig |
| Product Add-Ons | ฟีเจอร์เพิ่มเติมของผลิตภัณฑ์ Spwig |
| Product Bundles | ชุดผลิตภัณฑ์ของ Spwig |
| Gift Cards (WooCommerce, YITH และ PW variants) | บัตรของขวัญของ Spwig |
| Composite Products | ผลิตภัณฑ์แบบผสมของ Spwig |
| Bookings and Accommodation Bookings | การจองของ Spwig |

> **หมายเหตุ:** การนำเข้าข้อมูลจากส่วนขยายจะไม่เคยขัดขวางการสร้างผลิตภัณฑ์พื้นฐาน ถ้าข้อมูลเฉพาะของส่วนขยายไม่สามารถอ่านได้ ผลิตภัณฑ์ยังคงถูกนำเข้า — เพียงแค่เป็นผลิตภัณฑ์ทั่วไป โดยไม่มีการตั้งค่าการสมัครสมาชิก ชุดผลิตภัณฑ์ การจอง หรือการตั้งค่าบัตรของขวัญ

ตรวจสอบผลิตภัณฑ์สมัครสมาชิก ชุดผลิตภัณฑ์ การจอง และบัตรของขวัญของคุณหลังจากการนำเข้าเพื่อยืนยันว่าการตั้งค่าเฉพาะของส่วนขยายถูกนำเข้ามาอย่างถูกต้อง แทนที่จะสมมติว่าการนำเข้าที่สำเร็จได้นำรายละเอียดทั้งหมดมาด้วย

## ฟิลด์แบบกำหนดเอง

หากคุณเพิ่มฟิลด์ข้อมูลแบบกำหนดเองในผลิตภัณฑ์ ลูกค้า หรือคำสั่งซื้อใน WooCommerce Spwig จะเก็บตัวอย่างข้อมูลประมาณสิบรายการของแต่ละประเภทเพื่อตรวจจับว่ามีฟิลด์ใดอยู่ คุณจะต้องจับคู่แต่ละฟิลด์กับช่องฟิลด์แบบกำหนดเองของ Spwig หรือฟิลด์ข้อมูล Meta Data ทั่วไปในขั้นตอนที่ 4 ดู [การจับคู่ฟิลด์การย้ายข้อมูล](migration-field-mapping) เพื่อดูขั้นตอนทั้งหมด รวมถึงวิธีการจับคู่ที่ถูกบันทึกไว้สำหรับการย้ายข้อมูลในอนาคต

## การเริ่มต้นการนำเข้า

เมื่อคุณได้ตรวจสอบขั้นตอนที่ 3 และยืนยันการจับคู่ในขั้นตอนที่ 4 ให้เริ่มต้นการนำเข้า การนำเข้าจะทำงานในพื้นหลัง — คุณสามารถปิดหน้าต่างเบราว์เซอร์และมันจะยังคงดำเนินต่อไป ขั้นตอนที่ 5 แสดงความคืบหน้าแบบเรียลไทม์พร้อมแถวสำหรับแต่ละประเภทข้อมูล (หมวดหมู่ ผลิตภัณฑ์ ลูกค้า คำสั่งซื้อ รีวิว ส่วนลด โพสต์บล็อก และผู้ร่วมมือ/ค่าคอมมิชชัน/การจ่ายเงิน หากใช้ปลั๊กอิน Bridge) รวมถึงบันทึกกิจกรรมที่สามารถขยายได้

ขั้นตอนที่ 6 แสดงผลลัพธ์ของคุณ: สิ่งที่ถูกนำเข้า, ข้ามหรือล้มเหลว รวมถึงเครื่องมือ **Link Rewriting** หากพบลิงก์ภายในไปยังโดเมน WooCommerce เดิมของคุณในเนื้อหาที่นำเข้ามา

ตรวจสอบสรุปอย่างละเอียด จากนั้นดำเนินการตามรายการตรวจสอบใน [After Your Migration](after-migration-review) — มันครอบคลุมการตรวจสอบข้อมูลของคุณ การตั้งค่าอัตราภาษีและการจัดส่ง (ซึ่งเวิร์กช็อปไม่ได้ตั้งค่าให้คุณ) และการเขียนลิงก์ภายในใหม่

## Revoke Your API Key

เมื่อคุณยืนยันว่าการย้ายถ่ายข้อมูลเสร็จสิ้นอย่างสำเร็จ ให้กลับไปที่ **WooCommerce > Settings > Advanced > REST API** ใน WordPress และยกเลิกหรือลบคีย์ที่คุณสร้างสำหรับ Spwig ไม่มีเหตุผลใดที่จะปล่อยให้คีย์ API ที่ใช้งานอยู่บนร้านค้าเดิมของคุณหลังจากที่คุณเสร็จสิ้นการใช้งาน

## Tips

- **สร้างคีย์ API ก่อนที่คุณจะต้องใช้มัน** — เนื่องจาก Consumer Secret จะแสดงเพียงครั้งเดียว จึงควรสร้างมันทันทีก่อนเริ่มขั้นตอนที่ 2 แทนที่จะสร้างล่วงหน้า
- **การอ่านเพียงอย่างเดียวจริงๆ ก็เพียงพอแล้ว** — อย่าเคยอนุญาตให้ใช้สิทธิ์เขียนหรืออ่าน/เขียน; Spwig จะอ่านจากร้านค้า WooCommerce ของคุณเพียงอย่างเดียว
- **ติดตั้งปลั๊กอิน Bridge ก่อนเริ่มการนำเข้า** — คุณจะต้องเพิ่มมันและรีเฟรชเวิร์กช็อปก่อนเริ่มนำเข้า ดังนั้นจึงควรตรวจสอบมันล่วงหน้าแทนที่จะตรวจสอบระหว่างทาง
- **ตรวจสอบผลิตภัณฑ์ที่ขับเคลื่อนโดยส่วนขยายอย่างรวดเร็ว** — ผลิตภัณฑ์เช่น การสมัครสมาชิก, ชุดสินค้า, การจอง และบัตรกำนัล เป็นผลิตภัณฑ์ที่มีแนวโน้มสูงสุดที่ต้องตรวจสอบด้วยตนเองหลังการนำเข้า
- **การนำเข้าบางส่วนจะไม่ถูกทำความสะอาดโดยอัตโนมัติ** — ดู [Migration Troubleshooting](migration-troubleshooting) ก่อนลองนำเข้าอีกครั้งหากการนำเข้าล้มเหลว
- **ยกเลิกคีย์ API เมื่อคุณเสร็จสิ้น** — อย่าปล่อยให้การเชื่อมต่อเก่าที่ใช้งานอยู่บนร้านค้าที่คุณย้ายออกแล้ว
