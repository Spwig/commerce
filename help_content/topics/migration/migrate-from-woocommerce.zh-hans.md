---
title: 从WooCommerce迁移
---

如果您的商店目前使用WooCommerce，Spwig的迁移向导可以通过WooCommerce的REST API直接导入您的产品、客户、订单和内容。本指南涵盖获取API凭证、运行导入，以及两个值得首先了解的WooCommerce特定功能：可选的迁移桥接插件用于导入联盟数据，以及对几种流行的WooCommerce扩展的内置支持。

## 开始之前

WooCommerce是迁移向导中支持最广泛的源平台。以下内容可以干净地导入：分类（带层次结构）、产品、图片和变体、客户和地址、订单、评论、优惠券，以及带有分类、标签和图片的博客文章。

如果先安装了Spwig迁移桥接插件，还可以导入联盟资料、佣金记录和付款历史——请参见下文。如果没有安装该插件，这些数据将被简单跳过。

还需要注意以下几点：

- 某些WooCommerce扩展（订阅、捆绑包、预订、礼品卡）的产品会落入Spwig中对应的功能，但并非所有细节都会转移——请参见下方的**WooCommerce扩展支持**。
- 您产品、客户和订单上的自定义字段会自动检测到，并需要在后续步骤中进行映射。请参见[Migration Field Mapping](migration-field-mapping)。
- 向导中的**Import tax settings**（导入税务设置）和**Import shipping zones and methods**（导入运输区域和方法）选项不会应用于导入的数据。请在Spwig中自行设置税率和运输方式——请参见[After Your Migration](after-migration-review)。
- **Price adjustment**（价格调整）选项在相同步骤中*确实*适用于WooCommerce导入，它会在创建每个产品时更改其基础价格。除非您有意让每个价格都发生偏移，请将其保留为**None**。

请准备好您的WordPress管理员登录信息，并大致了解您要导入的产品、客户和订单数量，以便对向导显示的数量进行合理性检查。

## 获取REST API凭证

Spwig 通过从你的 WordPress 管理后台生成的 REST API 密钥连接到 WooCommerce。

此密钥只需要 **读取** 权限 —— Spwig 在迁移过程中只会从你的商店读取数据，绝不会将任何内容写回。

1. 在 WordPress 中，前往 **WooCommerce > 设置 > 高级 > REST API**
2. 点击 **添加密钥**
3. 为其添加描述（例如，`Spwig 迁移`），并将 **权限** 设置为 **读取**
4. 点击 **生成 API 密钥**
5. 将 **消费者密钥** (`ck_...`) 和 **消费者密钥密码** (`cs_...`) 复制到一个安全的地方

> **重要提示：** WooCommerce 只会在你生成密钥的那一刻显示一次消费者密钥密码。如果你在复制之前离开了这个页面，就需要重新生成一个密钥。

## 连接你的商店

在 Spwig 管理后台进入 **数据导入与导出 > 开始新迁移**，在第 1 步中选择 **WooCommerce**。在第 2 步中，输入以下内容：

- **商店 URL** — 你商店的完整网址，例如 `https://mystore.com`
- **消费者密钥** 和 **消费者密钥密码** — 你刚刚复制的值

保持 **在继续之前测试连接** 勾选（默认已启用），这样 Spwig 会在你继续之前确认它能够连接到你的商店并进行身份验证 —— 这样可以立即发现拼写错误和权限问题，而不是在导入过程中部分出现。测试成功后，点击 **下一步**。

## 查看和选择数据

第 3 步会从你的商店获取实时数据统计 —— 分类、产品、客户、订单、评论和优惠券 —— 加上前五个产品的样本，以便你确认它正在读取正确的网站。每种数据类型的复选框会在其数量大于零时自动勾选，数量为零时则禁用。

**导入选项：**

- **跳过已有项目**（开启） — 将传入的记录与 Spwig 中已有的内容进行匹配（产品的 SKU，客户的电子邮件），并跳过重复项。

除非你从一个空商店开始，否则请保留此选项。
- **导入产品图片**（开启）——速度较慢，但值得。
- **尽可能保留原始ID**（关闭）——向导本身将此标记为“不推荐”。除非你有特定的技术原因需要保留WooCommerce的数字ID，否则请保持关闭。
- **批量大小** — 10、25（默认）、50 或 100 条记录一次。

较小的批次适用于不稳定的连接；较大的批次在连接稳定时完成得更快。

## Spwig 迁移桥接插件

WooCommerce 没有内置的联盟计划概念，因此如果你通过 WooCommerce 联盟扩展运行联盟计划，这些数据存储在标准 REST API 无法访问的表中。**Spwig 迁移桥接插件**是一个小型配套插件，你可以在 WordPress 网站上安装它以公开这些数据。

桥接插件解锁以下功能：

- **联盟资料** — 你的联盟成员的详细信息和推荐码
- **佣金记录** — 与每个联盟成员相关的佣金历史
- **付款历史** — 已支付给联盟成员的历史记录

这是可选的 —— 如果你没有运行联盟计划，或者在 Spwig 中不需要这些历史记录，可以跳过它。

> **注意：** 只有在迁移过程中同时导入订单和客户时，才能导入联盟数据，因为佣金和付款与特定的订单和客户相关联。

安装步骤如下：

1. 在第 3 步，如果插件尚未在你的网站上检测到，你将看到一个 **下载桥接插件** 按钮，并附带安装说明
2. 下载插件 ZIP 文件
3. 在 WordPress 中，进入 **插件 > 添加新插件 > 上传插件**，选择 ZIP 文件，点击 **立即安装**，然后 **激活**
4. 返回 Spwig 向导并刷新页面 —— 一个 **联盟成员** 复选框和一个 **联盟计划数据** 块将出现，显示找到的数量

在迁移完成后，你可以从 WordPress 中停用并删除桥接插件。

## WooCommerce 扩展支持

如果您的商店使用了某些流行的扩展程序，导入时会识别这些扩展程序创建的产品，并将其映射到相应的 Spwig 功能，而不是作为普通产品导入：

| WooCommerce 扩展 | 映射到 |
|---|---|
| Subscriptions | Spwig 订阅计划 |
| Product Add-Ons | Spwig 产品附加项 |
| Product Bundles | Spwig 产品捆绑包 |
| Gift Cards (WooCommerce, YITH 和 PW 变体) | Spwig 礼品卡 |
| Composite Products | Spwig 组合产品 |
| Bookings and Accommodation Bookings | Spwig 预订 |

> **注意：** 扩展数据导入不会阻止底层产品被创建。如果无法读取产品的扩展特定数据，产品仍然会导入——只是作为普通产品，不带其订阅、捆绑包、预订或礼品卡配置。

导入后，请检查您的订阅、捆绑包、预订和礼品卡产品，确认其扩展特定的设置已正确传输，而不是假设成功的导入包含了所有细节。

## 自定义字段

如果您在 WooCommerce 产品、客户或订单中添加了自定义元字段，Spwig 会采样每种类型约十条记录以检测哪些字段存在。您将在第 4 步将每个字段映射到 Spwig 的自定义字段插槽或通用的元数据字段。有关完整操作指南，请参阅 [迁移字段映射](migration-field-mapping)，包括映射如何保存以供未来迁移使用。

## 运行导入

在您审查完第 3 步并确认第 4 步的映射后，开始导入。它在后台运行——您可以关闭浏览器窗口，导入仍会继续。第 5 步会显示实时进度，每种数据类型（分类、产品、客户、订单、评论、优惠券、博客文章，以及如果使用了 Bridge 插件则包括联盟/佣金/付款）各占一行，还有一个可展开的活动日志。

第 6 步会显示你的结果：已导入的内容、跳过的部分以及失败的部分，如果在导入的内容中发现了指向你旧 WooCommerce 域名的内部链接，还会提供一个 **链接重写** 工具。

仔细查看摘要，然后按照 [迁移后](after-migration-review) 中的检查清单进行操作 —— 它涵盖了验证数据、设置税率和运费（向导不会为你配置这些内容），以及重写内部链接。

## 撤销你的 API 密钥

确认迁移成功完成后，返回 WordPress 中的 **WooCommerce > 设置 > 高级 > REST API**，撤销或删除你为 Spwig 创建的密钥。一旦你完成操作，就没有理由在旧商店上保留一个活动的 API 密钥。

## 小贴士

- **在需要时再生成 API 密钥** —— 由于消费者密钥只显示一次，因此请在开始第 2 步之前立即创建它，而不是提前创建。
- **只读权限就足够了** —— 永远不要授予写入或读写权限；Spwig 只会从你的 WooCommerce 商店中读取数据。
- **在开始导入前安装 Bridge 插件** —— 在导入前你需要添加它并刷新向导，因此请提前检查是否存在该插件，而不是在导入过程中才检查。
- **抽查依赖扩展的产品** —— 订阅、捆绑包、预订和礼品卡是最有可能在导入后需要手动检查的产品。
- **部分导入不会自动清理** —— 在重新尝试失败的导入之前，请先查看 [迁移故障排除](migration-troubleshooting)。
- **完成操作后撤销 API 密钥** —— 不要在你已迁移离开的商店上保留旧的集成活动状态。
