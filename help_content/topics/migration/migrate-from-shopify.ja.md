---
title: Shopifyからの移行
---

現在、ストアがShopify上で稼働している場合、Spwigの移行ウィザードは、Shopify Partnersダッシュボードで作成した小さなカスタムアプリに接続することで、製品、顧客、注文、コンテンツをインポートできます。Shopifyのプラットフォームは他のプラットフォームよりも制限が多く、そのためこのガイドの大部分はそのアプリを正しく作成する方法について説明しています。アプリが存在すれば、接続自体は5分で完了します。

## 移行開始前の準備

ここでは、後でテーブルに記載されているだけでなく、特に注意が必要な2つのShopify固有の制限について説明します。

> **重要:** ShopifyにはレビューAPIが存在しないため、**顧客のレビューは一切移行されません**。どのアプリスコープを許可しても、レビューは移行されません。レビューが必要な場合は、使用しているレビュー用アプリ（Judge.me、Yotpo、Looxなど）から個別にエクスポートし、Spwigにインポートしてください。

> **重要:** デフォルトでは、Spwigは**過去60日以内の注文**のみを読み取ることができます。すべての注文履歴を移行するには、アプリを作成する際に`read_all_orders`スコープを追加する必要があります。これは、アプリがこのスコープなしでも接続し、インポートに成功するため、見落としやすい点です。ただ、注文履歴がどのくらい遡れるかは静かに制限されます。

他のすべては問題なく移行されます: カテゴリ（コレクションとして — 下記を参照）、製品、画像、バリアント、顧客と住所、割引、ブログコンテンツ。カスタムフィールドは他の主要なギャップです — このガイドの終わり近くにある**Shopifyメタフィールド**を参照してください。

また、以下の点にも注意してください:

- ウィザードの **Import tax settings** および **Import shipping zones and methods** オプションは、インポートされたデータには適用されません。

  移行後、Spwigで税金の設定および配送方法を自分で設定してください — [移行後の確認](after-migration-review)を参照してください。
- 同じステップの **Price adjustment** オプションは、Shopifyのインポートでは**有効になります**。各製品の基本価格が作成される際に変更されます。

  すべての価格を変更したい場合以外は、**None** に設定してください。
- アプリを作成するには、Shopify Partnersアカウントへのアクセスが必要です。


すでに持っている場合は除き、Shopifyはpartners.shopify.comで無料で1つを作成できます。

## Shopifyアプリの作成

Spwigは、独自のアプリを作成して自分のストアにインストールすることでShopifyに接続します。これは、製品内にある**Shopify API Setup Guide**モーダル（ウィザードのステップ2で**Open Setup Guide**をクリックして開く）と同様なので、以下の手順はそこに表示されているものと完全に一致しています — どちらかを従ってもかまいません。

### ステップ1: アプリの作成

1. [Shopify Partners dev dashboard](https://dev.shopify.com/dashboard)にアクセスし、**Apps**を開きます。
2. **Create app**をクリックします。
3. **Start from Dev Dashboard**を選択します。
4. アプリ名を入力: `Spwig Migration`
5. **Create**をクリックします。

![Shopify dev dashboardでSpwig Migrationアプリを作成しています](/static/core/admin/img/help/migrate-from-shopify/shopify-create-app.webp)

### ステップ2: アプリURLとスコープの設定

新しいアプリの設定ページで、**Versions**の下で以下を設定します:

- **App URL**: `https://shopify.dev/apps/default-app-home`
- **Scopes**: `read_customers,read_discounts,read_files,read_orders,read_products,read_content`

![アプリURLと必要なスコープを設定しています](/static/core/admin/img/help/migrate-from-shopify/shopify-app-url-scopes.webp)

| スコープ | Spwigにアクセス権を提供します |
|---|---|
| `read_products` | 商品、バリエーション、画像、コレクション |
| `read_customers` | 顧客名、メールアドレス、住所 |
| `read_orders` | 過去60日の注文 |
| `read_content` | ブログ投稿とページ |
| `read_discounts` | クーポンコードとルール |
| `read_files` | アップロードされたメディアファイル |

> **注意:** 過去60日ではなく、すべての注文履歴が必要ですか？上記のスコープリストに`read_all_orders`を追加してください。

### ステップ3: Client IDとSecretをコピーする

**Settings > Credentials**に移動し、そこに表示されている**Client ID**と**Secret**をコピーしてください — すぐにSpwigウィザードに貼り付けることになります。

![アプリのSettingsページからClient IDとSecretをコピーしています](/static/core/admin/img/help/migrate-from-shopify/shopify-credentials.webp)

### ステップ4: カスタム配布リンクを生成する

1. **配布**にアクセスし、**カスタム配布**を選択します
2. あなたのストアドメインを入力してください（例: `yourstore.myshopify.com`）
3. **リンクを生成**をクリックし、生成されたインストールリンクを**コピー**します

![生成されたカスタム配布インストールリンクのコピー](/static/core/admin/img/help/migrate-from-shopify/shopify-install-link.webp)

### ステップ5: ストアにアプリをインストールする

先ほどコピーしたインストールリンクを開き、ブラウザで開いてください（Shopifyストア管理者としてログインしていることを確認してください）。要求される権限を確認し、**インストール**をクリックしてください。

![Shopifyストアへのアプリのインストール](/static/core/admin/img/help/migrate-from-shopify/shopify-install-app.webp)

> **重要:** この最終ステップは簡単に見過ごされがちです。インストールリンクの生成はアプリのインストールを実行しません。リンクを開いて**インストール**をクリックしないと、Spwigは接続できません。次のセクションで接続テストが失敗した場合は、まずこれを確認してください。

## Spwigに資格情報をコピーする

Spwig管理者画面にアクセスし、**データのインポートとエクスポート > 新しいマイグレーションを開始**を選択し、ステップ1で**Shopify**を選択し、ステップ2で以下を入力してください:

- **ストアドメイン** — `yourstore.myshopify.com`
- **クライアントID** — 設定 > 資格情報から取得
- **クライアントシークレット** — 設定 > 資格情報から取得

このガイドの代わりに、製品内でのウォークスルーを使用したい場合は、このステップで**セットアップガイドを開く**をクリックしてください — これは上記の5つのステップと同様の手順で、同じスクリーンショットが含まれており、全体で約10分かかります。

**接続をテストしてから進む**をチェックしたままにしてください。あなたのアプリのスコープに`read_products`、`read_customers`、または`read_orders`が欠けている場合、Spwigは継続する前に警告します。Shopifyダッシュボードのアプリのバージョンページに戻り、不足しているスコープを追加し、新しいバージョンを保存してから再度試してください。

## データの確認と選択

ステップ3では、ストアからライブカウントを取得し、最初の5つの製品のサンプルを表示します。他のプラットフォームといくつかの点が異なります:

- **コレクション、カテゴリではなく** — Shopifyは製品をコレクションではなくカテゴリに分類しており、コレクションはネストをサポートしないため、階層構造はフラットにインポートされます。

Shopifyストアがコレクションを使ってカテゴリツリーを表していた場合、インポート後、Spwigのカテゴリマネージャーでその構造を再構築する必要があります。
- **割引、クーポンではなく** — Shopifyの割引コードとルールはSpwigの割引としてインポートされます。
- **レビュー行なし** — ShopifyにはレビューAPIが存在しないため、このデータタイプはステップに一切表示されません。WooCommerceやCSVインポートとは異なります。

**インポートオプション**は他のプラットフォームと同じように動作します：**既存のアイテムをスキップ**（オン）はSKUとメールアドレスで一致して重複を防ぎます；**製品画像をインポート**（オン）は少し遅くなりますが推奨されます；**可能な限り元のIDを保持**（オフ）は変更する特定の理由がない限りオフのままにしておくべきです；**バッチサイズ**はデフォルトで25です。

## Shopifyメタフィールド

Shopifyメタフィールドを使って製品、顧客、注文に追加データを保存している場合、Spwigはそれらを検出したり読み取ったりしません。WooCommerceとは異なり、Shopifyインポートにはカスタムフィールドのマッピングステップはありません。メタフィールドに保存したデータは、移行後、Spwigで[カスタムフィールド](migration-field-mapping)を使って手動で再入力する必要があります。そのため、移行を開始する前にShopifyからメタフィールドとその値のリストをエクスポートしておくと良いでしょう。

## インポートの実行

ステップ3を確認した後、インポートを開始してください。これはバックグラウンドで実行されます — ブラウザウィンドウを閉じても実行が続きます。ステップ5では、データタイプごとに1行ずつ表示され、拡張可能なアクティビティログがライブで進捗を示します。

ステップ6では結果が表示されます：インポートされたもの、スキップされたもの、失敗したものの他、インポートされたコンテンツに古い`myshopify.com`ドメインへの内部リンクが見つかった場合、**リンクの書き換え**ツールが表示されます。

移動後の確認リスト [After Your Migration](after-migration-review) を確認し、データの確認、コレクション階層の再構築、税率と配送の設定（ウィザードでは設定されません）、メタフィールドに保存されていたものを再入力するなど、チェックリストを順番に実施してください。
