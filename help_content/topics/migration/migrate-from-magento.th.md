title: การย้ายข้อมูลจาก Magento

Spwig สามารถนำเข้าแคตตาล็อก ลูกค้า คำสั่งซื้อ คูปอง และหน้า CMS จาก Magento 2 หรือ Adobe Commerce ที่กำลังทำงานได้โดยตรงโดยใช้ REST API ของ Magento คู่มือนี้จะอธิบายขั้นตอนการสร้างข้อมูลการผสานที่ Magento ต้องการ การใช้เวิร์กช็อปย้ายข้อมูล และช่องว่างที่สำคัญที่ผู้ค้าที่ย้ายมาจากระบบ Magento ต้องวางแผน: การรีวิวสินค้า

เฉพาะ **Magento 2 และ Adobe Commerce** เท่านั้นที่ได้รับการสนับสนุน Magento 1 ได้สิ้นสุดการสนับสนุนไปแล้วเมื่อหลายปีก่อน และไม่ได้เปิดเผย REST API ที่การย้ายข้อมูลนี้พึ่งพา — หากคุณยังใช้งาน Magento 1 อยู่ ให้ใช้ [การนำเข้าจากไฟล์ CSV](csv-import) แทน

## ก่อนเริ่มต้น

ตรวจสอบ [ภาพรวมการย้ายข้อมูล](migration-overview) เพื่อได้รับคำแนะนำในการวางแผนทั่วไป สำหรับ Magento โดยเฉพาะ:

- **หมวดหมู่** — นำเข้าพร้อมกับลำดับชั้นที่สมบูรณ์
- **สินค้า** — นำเข้า รวมถึงภาพประกอบ
- **ลูกค้าและที่อยู่** — นำเข้า
- **คำสั่งซื้อ** — นำเข้า
- **คูปอง** — นำเข้าเป็นคูปองของ Spwig โดยมาจากกฎการขายของ Magento
- **หน้า CMS** — นำเข้าเป็นหน้าของ Spwig
- **รีวิว** — โดยทั่วไป **ไม่** นำเข้า โปรดดูส่วนถัดไปก่อนที่จะพึ่งพาการนำเข้านี้
- รูปแบบย่อยได้รับการสนับสนุนสำหรับสินค้าที่กำหนดได้

> **หมายเหตุ:** การย้ายข้อมูลจาก Magento ไม่ได้ถ่ายโอนโปรแกรมพันธมิตร ค่าคอมมิชชั่น หรือการจ่ายเงิน — การผสานกับสะพานพันธมิตรของ Spwig สามารถใช้งานได้เฉพาะสำหรับร้านค้า WooCommerce เท่านั้น

### ข้อจำกัดเกี่ยวกับรีวิว

Magento Community Edition ไม่ได้เปิดเผยจุดปลายทาง REST สำหรับรีวิวสินค้า — เส้นทาง `/reviews` ไม่มีอยู่ในติดตั้ง Community Edition แบบมาตรฐาน Spwig จะตรวจสอบเส้นทางนี้ก่อนการนำเข้า และหากไม่มีอยู่ จะบันทึกข้อความและดำเนินการย้ายข้อมูลส่วนที่เหลือต่อไปแทนที่จะล้มเหลวทั้งงาน หมวดหมู่ สินค้า ลูกค้า คำสั่งซื้อ คูปอง และหน้าของคุณยังคงถูกนำเข้ามาได้; เพียงรีวิวเท่านั้นที่ถูกข้าม

รีวิว **จะ** ถูกนำเข้าหากร้านค้าของคุณใช้ **Adobe Commerce** (ซึ่งเปิดเผยจุดปลายทางนี้) หรือหากการติดตั้ง Magento ของคุณมีโมดูลที่กำหนดเองเพิ่มเส้นทางรีวิวที่เข้ากันได้

หากคุณใช้งาน Magento Community และต้องการนำรีวิวของคุณมาใช้กับ Spwig ให้ส่งออกไฟล์รีวิวแยกก่อน (ส่วนใหญ่ตัวขยายรีวิวมีตัวเลือกส่งออกเป็น CSV) และนำเข้าภายหลังโดยใช้ไฟล์รีวิวใน [การนำเข้าจากไฟล์ CSV](csv-import) โดยใช้ `product_id` เพื่อเชื่อมโยงกับสินค้าของคุณ

## ขั้นตอนที่ 1: เลือก Magento

จากแดชบอร์ดการย้ายข้อมูลที่ **Data Import & Export** ให้คลิก **Start New Migration** และเลือก **Magento** เป็นแพลตฟอร์มของคุณ

## ขั้นตอนที่ 2: เชื่อมต่อกับร้านของคุณ

คุณจะต้องใช้ URL ของร้าน Magento และโทเค็นการเข้าถึงอินเทอร์เฟซการรวมตัว (integration access token) ระบบ Admin ของ Magento ไม่ได้แจกโทเค็น API แบบง่ายๆ ตามที่แพลตฟอร์มบางแห่งทำ — คุณต้องสร้าง **Integration** ซึ่งเป็นการเข้าถึงที่มีขอบเขต ซึ่ง Magento จัดการเหมือนแอปที่เชื่อมต่อ

### การสร้างโทเค็นการเข้าถึง Integration

1. ในระบบ Admin ของ Magento ให้ไปที่ **System > Integrations**
2. คลิก **Add New Integration**
3. ตั้งชื่อเป็น `Spwig Migration` เพื่อให้ระบุได้ง่ายในภายหลัง
4. เปิดแท็บ **API** และตั้งค่า **Resource Access** เป็น **All**
5. คลิก **Save** แล้วคลิก **Activate**
6. ยืนยันโดยคลิก **Allow** ที่หน้าต่างป๊อปอัปที่แสดงรายการสิทธิ์ที่กำลังอนุญาต
7. คัดลอกโทเค็นการเข้าถึงที่แสดงหลังจากเปิดใช้งาน — Magento จะแสดงมันเพียงครั้งเดียวเท่านั้น

> **หมายเหตุ:** ตั้งค่า Resource Access เป็น **All** เพราะต้นไม้ทรัพยากรของ Magento มีความละเอียดสูงมาก — มีสิทธิ์กว่าร้อยรายการครอบคลุมแคตตาล็อก การขาย ลูกค้า และ CMS — โดยไม่มีสวิตช์ "อ่านทุกอย่าง" ที่ไม่ต้องเลือกทั้งหมด กระบวนการย้ายข้อมูลจะอ่านข้อมูลจากร้านของคุณเท่านั้น มันจะไม่เขียนกลับไป และคุณสามารถยกเลิกการรวมตัวนี้ได้เมื่อการย้ายข้อมูลของคุณได้รับการตรวจสอบแล้ว (จะกล่าวถึงที่สุดท้ายของคู่มือนี้)

เมื่อกลับมาที่เวิร์ดซินของ Spwig ให้ใส่ **Store URL** และ **Access Token** ที่คุณคัดลอกไว้ ให้เปิดใช้งาน **Test connection before proceeding** (เปิดใช้งานโดยค่าเริ่มต้น) เพื่อให้ Spwig ตรวจสอบว่าสามารถเชื่อมต่อกับร้านของคุณและยืนยันตัวตนได้ก่อนที่คุณจะดำเนินการต่อ หากการทดสอบล้มเหลว ให้ตรวจสอบ URL อีกครั้ง และตรวจสอบว่าการรวมตัวยังอยู่ในสถานะ Active ใน Magento คลิก **Next**

เมื่อเสร็จสิ้น คุณจะถูกนำไปยังหน้าสรุปผล ให้ตรวจสอบ [หลังการย้ายข้อมูลของคุณ](after-migration-review) เพื่อยืนยันว่าข้อมูลที่ถ่ายโอนมาถูกต้อง จัดการการเปลี่ยนลิงก์สำหรับเนื้อหาที่อ้างอิง URL ของ Magento เดิม และจัดการการตั้งค่าภาษีและการจัดส่งที่เวิร์กโฟลว์รวบรวมไว้แต่ไม่ได้ใช้งานอัตโนมัติ

## กำหนดเวลาการยกเลิกการย้ายข้อมูล

Magento เป็นแพลตฟอร์มเดียวที่การยกเลิกมีกำหนดเวลา เมื่อการย้ายข้อมูลของคุณเสร็จสิ้น ปุ่ม **Rollback** จะปรากฏบนหน้าสรุปงาน — แต่สำหรับ Magento โดยเฉพาะ ปุ่มนี้อาจหยุดให้บริการหลังจากช่วงเวลาหนึ่งหลังการย้ายข้อมูลเสร็จสิ้น ประเภทการย้ายข้อมูลอื่นๆ (WooCommerce, Shopify, CSV) ไม่มีกำหนดเวลาดังกล่าว แต่ Magento มี ดังนั้นอย่าเลื่อนการตรวจสอบไปจนถึงภายหลัง

> **คำเตือน:** การยกเลิกจะลบข้อมูลมากกว่าที่การย้ายข้อมูลสร้างขึ้น — รวมถึงคำสั่งซื้อที่ลูกค้าที่ย้ายมาทำหลังการย้ายข้อมูล และรายการสินค้าที่อ้างอิงสินค้าที่ย้ายมา แม้ในคำสั่งซื้อจากลูกค้าที่คุณไม่ได้ย้ายมา ควรใช้ได้เฉพาะทันทีหลังการย้ายข้อมูลเท่านั้น ภายในก่อนที่จะมีการซื้อขายจริงเกิดขึ้นบนร้านค้า ดู [การแก้ไขปัญหาการย้ายข้อมูล](migration-troubleshooting) เพื่อดูภาพรวมทั้งหมดว่าการยกเลิกสามารถยกเลิกอะไรได้และไม่สามารถยกเลิกอะไรได้

ตรวจสอบข้อมูลที่นำเข้าของคุณทันทีขณะที่ยังสามารถใช้ฟังก์ชัน Rollback ได้ ในกรณีที่คุณอาจต้องใช้มัน

## ยกเลิกการผสานรวม


เมื่อคุณตรวจสอบข้อมูลใน Spwig แล้ว — สินค้า ราคา รูปภาพ ลูกค้า คำสั่งซื้อ ส่วนลด และหน้าเว็บไซต์ดูถูกต้อง — ให้กลับไปที่ **System > Integrations** ใน Magento ค้นหา `Spwig Migration` และปิดใช้งานหรือลบมันออก

โทเค็นจะไม่จำเป็นอีกต่อไปเว้นแต่คุณวางแผนที่จะรันการย้ายข้อมูลอีกครั้ง และการลบมันจะปิดการเข้าถึงข้อมูลแบบอ่านที่คุณไม่จำเป็นต้องเปิดไว้ anymore

## Tips

- **รีวิวเป็นความประหลาดใจที่ใหญ่ที่สุดสำหรับผู้ขาย Magento** — วางแผนสำหรับการส่งออก/นำเข้าแยกหากคุณใช้ Community Edition และรีวิวมีความสำคัญต่อร้านของคุณ
- **คัดลอกโทเค็นเข้าถึงทันที** — Magento แสดงมันเพียงครั้งเดียวเมื่อคุณเปิดใช้งานการผสาน; หากคุณสูญเสียมัน คุณจะต้องปิดใช้งานและสร้างการผสานใหม่
- **อย่าเลื่อนการตรวจสอบ** — ปุ่ม Rollback มีความพร้อมใช้งานจำกัดเวลาเฉพาะสำหรับ Magento เท่านั้น ไม่เหมือนกับแพลตฟอร์มอื่นๆ
- **ใช้ตัวอย่างการดูตัวอย่างในขั้นตอนที่ 3** เพื่อจับปัญหาการจับคู่ที่เห็นได้ชัด (ราคาผิด รูปภาพหาย) ก่อนที่จะรันการนำเข้าทั้งหมด
- **ส่วนลดมาจากกฎการขาย** — หากส่วนลด Magento ขึ้นอยู่กับเงื่อนไขที่ซับซ้อน ตรวจสอบมันใน Spwig หลังจากนั้นเนื่องจากไม่ใช่ทุกประเภทกฎที่มีการเทียบตรง
- **ตั้งค่าอัตราภาษีและโซนการจัดส่งใน Spwig หลังการนำเข้า** — ตัวเลือกภาษีและจัดส่งของวิซาร์ดถูกบันทึกไว้แต่ไม่ได้ถูกนำไปใช้กับร้านของคุณอัตโนมัติ
