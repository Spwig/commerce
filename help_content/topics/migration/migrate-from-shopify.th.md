---
title: การย้ายข้อมูลจาก Shopify
---

หากร้านค้าของคุณกำลังใช้งาน Shopify อยู่ในปัจจุบัน โปรแกรมช่วยย้ายข้อมูลของ Spwig สามารถนำเข้าสินค้า ลูกค้า คำสั่งซื้อ และเนื้อหาของคุณได้โดยการเชื่อมต่อกับแอปที่คุณสร้างขึ้นเองในแดชบอร์ด Shopify Partners แพลตฟอร์มของ Shopify มีข้อจำกัดมากกว่าแพลตฟอร์มอื่น ๆ มาก ดังนั้นส่วนใหญ่ของคู่มือนี้จะเน้นการสร้างแอปนั้นอย่างถูกต้อง — การเชื่อมต่อมีเพียงขั้นตอนที่ใช้เวลาประมาณ 5 นาทีหลังจากที่แอปถูกสร้างขึ้นแล้ว

## ก่อนเริ่มต้น

ข้อจำกัดเฉพาะของ Shopify สองข้อต่อไปนี้มีความสำคัญพอที่จะต้องระบุไว้ที่นี่ ไม่ใช่แค่ในตารางด้านล่าง:

> **สำคัญ:** Shopify ไม่มี API สำหรับรีวิว ดังนั้น **รีวิวของลูกค้าจะไม่ถูกย้ายข้อมูลเลย** ไม่ว่าคุณจะอนุญาตสิทธิ์ (app scopes) ใด ๆ ให้กับแอปของคุณ หากคุณต้องการรีวิวของคุณ ให้ส่งออกข้อมูลรีวิวแยกจากแอปรีวิวที่คุณใช้งานอยู่ (เช่น Judge.me, Yotpo, Loox ฯลฯ) และนำเข้าข้อมูลรีวิวนั้นเข้าสู่ Spwig ด้วยตนเอง

> **สำคัญ:** โดยค่าเริ่มต้น Spwig จะสามารถอ่าน **คำสั่งซื้อในช่วง 60 วันที่ผ่านมาเท่านั้น** หากคุณต้องการนำข้อมูลประวัติคำสั่งซื้อทั้งหมดมาด้วย คุณจะต้องเพิ่มสิทธิ์ (scope) `read_all_orders` ขณะที่คุณสร้างแอป — ดูรายการสิทธิ์ (scope) ด้านล่าง นี่เป็นสิ่งที่ง่ายต่อการมองข้าม เพราะแอปยังสามารถเชื่อมต่อและนำเข้าข้อมูลได้สำเร็จโดยไม่มีสิทธิ์นี้ แต่จะจำกัดให้ประวัติคำสั่งซื้อของคุณย้อนกลับได้แค่เพียงระยะหนึ่งเท่านั้น

ทุกสิ่งอื่น ๆ สามารถย้ายข้อมูลได้ดี: หมวดหมู่ (ในรูปแบบ Collections — ดูข้อมูลด้านล่าง), สินค้า, รูปภาพ, ตัวเลือกสินค้า, ลูกค้าและที่อยู่, ส่วนลด, และเนื้อหาบล็อก ฟิลด์ที่กำหนดเองเป็นอีกจุดที่ขาดหายไป — ดู **Shopify metafields** ใกล้ท้ายของคู่มือนี้

โปรดจำไว้ว่า:

- ตัวเลือก **Import tax settings** และ **Import shipping zones and methods** ของโปรแกรมช่วยย้ายข้อมูลจะ **ไม่ถูกนำไปใช้กับข้อมูลที่นำเข้า**

ตั้งค่าอัตราภาษีและค่าจัดส่งใน Spwig ด้วยตนเองหลังจากนั้น — ดู [หลังการย้ายข้อมูล](after-migration-review)
- ตัวเลือก **Price adjustment** ในขั้นตอนเดียวกัน *จะมีผล* สำหรับการนำเข้าจาก Shopify โดยเปลี่ยนราคาพื้นฐานของสินค้าขณะที่สร้างขึ้น

ตั้งค่าเป็น **None** เว้นแต่คุณต้องการปรับราคาทุกตัวอย่างโดยเจตนา
- คุณจะต้องมีการเข้าถึงบัญชี Shopify Partners เพื่อสร้างแอป

หากคุณยังไม่มีแอป Shopify คุณสามารถสร้างได้ฟรีที่ partners.shopify.com

## การสร้างแอป Shopify

Spwig เชื่อมต่อกับ Shopify ผ่านแอปที่คุณสร้างและติดตั้งบนร้านค้าของคุณเอง นี่คือการสะท้อนของหน้าต่าง **Shopify API Setup Guide** ที่ใช้งานภายในผลิตภัณฑ์ (เปิดผ่าน **Open Setup Guide** ที่ขั้นตอนที่ 2 ของวิザาร์ด) ดังนั้นขั้นตอนด้านล่างจึงตรงกับสิ่งที่คุณจะเห็นที่นั่นอย่างแน่นอน — คุณสามารถทำตามขั้นตอนใดขั้นตอนหนึ่งก็ได้

### ขั้นตอนที่ 1: สร้างแอป

1. ไปที่ [Shopify Partners dev dashboard](https://dev.shopify.com/dashboard) และเปิด **Apps**
2. คลิก **Create app**
3. เลือก **Start from Dev Dashboard**
4. ใส่ชื่อแอป: `Spwig Migration`
5. คลิก **Create**

![Creating the Spwig Migration app in the Shopify dev dashboard](/static/core/admin/img/help/migrate-from-shopify/shopify-create-app.webp)

### ขั้นตอนที่ 2: ตั้งค่า App URL และ Scopes

บนหน้าตั้งค่าของแอปใหม่ ภายใต้ **Versions** ให้ตั้งค่า:

- **App URL**: `https://shopify.dev/apps/default-app-home`
- **Scopes**: `read_customers,read_discounts,read_files,read_orders,read_products,read_content`

![Setting the App URL and required scopes](/static/core/admin/img/help/migrate-from-shopify/shopify-app-url-scopes.webp)

| Scope | Gives Spwig access to |
|---|---|
| `read_products` | Products, variants, images, collections |
| `read_customers` | Customer names, emails, addresses |
| `read_orders` | Orders from the last 60 days |
| `read_content` | Blog posts and pages |
| `read_discounts` | Discount codes and rules |
| `read_files` | Uploaded media files |

> **หมายเหตุ:** หากคุณต้องการประวัติการสั่งซื้อทั้งหมด ไม่ใช่แค่ 60 วันที่ผ่านมา ให้เพิ่ม `read_all_orders` ลงในรายการ scope ด้านบน

### ขั้นตอนที่ 3: คัดลอก Client ID และ Secret ของคุณ

ไปที่ **Settings > Credentials** และคัดลอก **Client ID** และ **Secret** ที่แสดงอยู่ที่นั่น — คุณจะวางข้อมูลเหล่านี้ลงในวิザาร์ดของ Spwig ในอีกไม่ช้า

![Copying the Client ID and Secret from the app's Settings page](/static/core/admin/img/help/migrate-from-shopify/shopify-credentials.webp)

### ขั้นตอนที่ 4: สร้างลิงก์การแจกจ่ายแบบกำหนดเอง

1. ไปที่ **Distribution** และเลือก **Custom distribution**
2. ใส่โดเมนของร้านคุณ (เช่น `yourstore.myshopify.com`)
3. คลิก **Generate link** จากนั้น **Copy** ลิงก์ติดตั้งที่สร้างขึ้น

![Copying the generated custom-distribution install link](/static/core/admin/img/help/migrate-from-shopify/shopify-install-link.webp)

### ขั้นตอนที่ 5: ติดตั้งแอปในร้านคุณ

เปิดลิงก์ติดตั้งที่คุณเพิ่งคัดลอกในเบราว์เซอร์ของคุณ (โปรดตรวจสอบว่าคุณได้เข้าสู่ระบบในแดชบอร์ด Shopify ของคุณแล้ว) ตรวจสอบสิทธิ์ที่แอปขอ และคลิก **Install**

![Installing the app on the Shopify store](/static/core/admin/img/help/migrate-from-shopify/shopify-install-app.webp)

> **สำคัญ:** ขั้นตอนสุดท้ายนี้มักถูกละเลย การสร้างลิงก์ติดตั้งไม่ได้ติดตั้งแอป — คุณต้องเปิดลิงก์และคลิก Install จริง ๆ หรือ Spwig จะไม่สามารถเชื่อมต่อได้ หากการทดสอบการเชื่อมต่อล้มเหลวในส่วนถัดไป นี่คือสิ่งแรกที่ควรตรวจสอบ

## การคัดลอกข้อมูลการรับรองเข้าไปใน Spwig

ในแดชบอร์ดของ Spwig ให้ไปที่ **Data Import & Export > Start New Migration** เลือก **Shopify** ในขั้นตอนที่ 1 และในขั้นตอนที่ 2 ให้กรอก:

- **Store Domain** — `yourstore.myshopify.com`
- **Client ID** — จาก Settings > Credentials
- **Client Secret** — จาก Settings > Credentials

หากคุณต้องการใช้คำแนะนำภายในผลิตภัณฑ์แทนคู่มือนี้ ให้คลิก **Open Setup Guide** ในขั้นตอนนี้ — มันครอบคลุมขั้นตอน 5 ขั้นตอนเดียวกันข้างต้นพร้อมภาพหน้าจอเดียวกัน และใช้เวลาประมาณ 10 นาทีในการทำทั้งหมด

ให้ตรวจสอบ **Test connection before proceeding** ไว้ หาก `read_products`, `read_customers` หรือ `read_orders` หายไปจากขอบเขตของแอปของคุณ Spwig จะเตือนคุณก่อนที่คุณจะดำเนินการต่อ — ให้กลับไปที่หน้า Versions ในแดชบอร์ด Shopify ของแอป เพิ่มขอบเขตที่ขาดหายไป บันทึกเวอร์ชันใหม่ และลองอีกครั้ง

## การตรวจสอบและเลือกข้อมูล

ขั้นตอนที่ 3 จะดึงข้อมูลนับแบบเรียลไทม์จากร้านคุณ และแสดงตัวอย่างของสินค้า 5 ชิ้นแรก บางสิ่งมีลักษณะต่างออกไปจากแพลตฟอร์มอื่น:

- **การจัดกลุ่ม ไม่ใช่หมวดหมู่** — Shopify จัดกลุ่มสินค้าเป็น Collections แทนที่จะเป็นหมวดหมู่ และ Collections ไม่รองรับการฝังซ้อนกัน ดังนั้นลำดับชั้นจะถูกนำเข้าแบบแบน

หากร้าน Shopify ของคุณใช้ Collections เพื่อแสดงโครงสร้างของหมวดหมู่ คุณควรวางแผนสร้างโครงสร้างนั้นใหม่ในตัวจัดการหมวดหมู่ของ Spwig หลังการนำเข้า
- **ส่วนลด ไม่ใช่คูปอง** — ส่วนลดและกฎของ Shopify จะถูกนำเข้าเป็นส่วนลดของ Spwig
- **ไม่มีแถวรีวิว** — เนื่องจาก Shopify ไม่มี API สำหรับรีวิว ข้อมูลประเภทนี้จะไม่ปรากฏในขั้นตอนนี้เลย ต่างจาก WooCommerce หรือการนำเข้า CSV

**ตัวเลือกการนำเข้า** ทำงานเหมือนกับแพลตฟอร์มอื่น ๆ: **ข้ามรายการที่มีอยู่แล้ว** (เปิดใช้งาน) จะตรงกับ SKU และอีเมลเพื่อหลีกเลี่ยงการซ้ำกัน; **นำเข้ารูปภาพสินค้า** (เปิดใช้งาน) จะช้าลงแต่แนะนำให้ใช้; **รักษา ID ต้นฉบับไว้มากที่สุดเท่าที่จะทำได้** (ปิดใช้งาน) ควรจะอยู่ในสถานะปิดใช้งาน เว้นแต่คุณมีเหตุผลเฉพาะที่ต้องการเปลี่ยนมัน; **ขนาดแบตช์** ค่าเริ่มต้นคือ 25

## Shopify Metafields

หากคุณใช้ Shopify Metafields เพื่อเก็บข้อมูลเพิ่มเติมในสินค้า ลูกค้า หรือคำสั่งซื้อ โปรดทราบว่า Spwig ไม่สามารถตรวจจับหรืออ่านข้อมูลเหล่านี้ได้ — ต่างจาก WooCommerce ไม่มีขั้นตอนการจับคู่ฟิลด์เฉพาะสำหรับการนำเข้า Shopify ข้อมูลใด ๆ ที่คุณเก็บไว้ใน Metafields จะต้องถูกป้อนใหม่ด้วยตนเองใน Spwig โดยใช้ [ฟิลด์เฉพาะ](migration-field-mapping) หลังการย้าย ดังนั้นจึงควรส่งออกรายการ Metafields และค่าของคุณจาก Shopify ก่อนเริ่มต้น

## การเริ่มต้นการนำเข้า

เมื่อคุณตรวจสอบขั้นตอนที่ 3 แล้ว ให้เริ่มต้นการนำเข้า การนำเข้าจะทำงานในพื้นหลัง — คุณสามารถปิดหน้าต่างเบราว์เซอร์และมันจะยังคงดำเนินต่อไป ขั้นตอนที่ 5 จะแสดงความคืบหน้าแบบเรียลไทม์ โดยมีแถวต่อประเภทข้อมูล และบันทึกกิจกรรมที่สามารถขยายได้

ขั้นตอนที่ 6 จะแสดงผลลัพธ์ของคุณ: สิ่งที่ถูกนำเข้า ข้าม หรือล้มเหลว รวมถึงเครื่องมือ **การเปลี่ยนลิงก์** หากพบลิงก์ภายในไปยังโดเมนเก่าของคุณ `myshopify.com` ในเนื้อหาที่นำเข้ามา

ตรวจสอบสรุปอย่างละเอียด จากนั้นดำเนินการตามรายการตรวจสอบใน [หลังการย้ายข้อมูล](after-migration-review) — มันครอบคลุมการตรวจสอบข้อมูลของคุณ การสร้างลำดับชั้นการรวบรวมใหม่ การตั้งค่าอัตราภาษีและค่าจัดส่ง (ซึ่งเวิลด์ไวด์ไม่ได้ตั้งค่าให้คุณ) และการป้อนข้อมูลที่เก็บไว้ใน metafields อีกครั้ง

## ลบแอปจาก Shopify

เมื่อคุณยืนยันว่าการย้ายข้อมูลเสร็จสิ้นอย่างสำเร็จ ให้กลับไปที่หน้า **Apps** ใน Shopify admin หรือแดชบอร์ดของพาร์ทเนอร์ และลบแอป Spwig Migration (หรืออย่างน้อยก็ถอนการติดตั้งออกจากร้านของคุณ) ไม่มีเหตุผลที่จะปล่อยให้การเข้าถึงข้อมูลร้านของคุณอยู่ในสถานะที่เปิดอยู่หลังจากที่การย้ายข้อมูลเสร็จสิ้นแล้ว

## เคล็ดลับ

- **ประวัติการสั่งซื้อถูกจำกัดโดยค่าเริ่มต้น** — หากคุณต้องการมากกว่า 60 วันของการสั่งซื้อ ให้เพิ่ม `read_all_orders` ลงในรายการ scope ก่อนสร้างลิงก์การติดตั้งของคุณ ไม่ใช่หลังจากนั้น
- **รีวิวต้องการการส่งออกแยกต่างหาก** — วางแผนสำหรับสิ่งนี้ก่อนที่คุณจะย้าย เพราะไม่มีวิธีใดที่จะนำรีวิวผ่านเวิลด์ไวด์ได้เลย
- **การสร้างลิงก์ไม่เหมือนกับการติดตั้งแอป** — ให้ทำขั้นตอนที่ 5 และคลิกติดตั้งเสมอ หรือการทดสอบการเชื่อมต่อใน Spwig จะล้มเหลว
- **การรวบรวมจะมาในรูปแบบแบน** — หากโครงสร้างหมวดหมู่ของคุณมีความสำคัญสำหรับการนำทางหรือ SEO ให้จัดสรรเวลาเพื่อสร้างลำดับชั้นใหม่ใน Spwig หลังการนำเข้า
- **ส่งออก metafields ก่อน** — Spwig ไม่สามารถอ่านมันได้ ดังนั้นให้จับข้อมูลนั้นจาก Shopify ก่อนเริ่มต้นหากคุณต้องการมันในภายหลัง
- **ลบแอปเมื่อคุณยืนยันแล้ว** — อย่าปล่อยให้การเชื่อมต่อที่ใช้งานอยู่ชี้ไปยังร้านเก่าของคุณหลังจากที่คุณย้ายไปแล้ว
