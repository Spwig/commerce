title: WooCommerce에서 마이그레이션하기
---

현재 가게가 WooCommerce에서 실행 중이라면, Spwig의 마이그레이션 마법사가 WooCommerce의 REST API를 통해 직접 제품, 고객, 주문 및 콘텐츠를 가져올 수 있습니다. 이 가이드는 API 자격 증명을 얻는 방법, 가져오기 실행 방법, 그리고 먼저 알아야 할 두 가지 WooCommerce 전용 기능에 대해 다룹니다: 선택적 마이그레이션 브리지 플러그인(아フィ리에이트 데이터를 위해) 및 여러 인기 있는 WooCommerce 확장 프로그램에 대한 내장 지원입니다.

## 시작하기 전에

마이그레이션 마법사에서 가장 넓은 지원을 제공하는 소스 플랫폼은 WooCommerce입니다. 다음 항목은 깔끔하게 가져옵니다: 카테고리(계층 구조 포함), 제품, 이미지 및 변형, 고객 및 주소, 주문, 리뷰, 쿠폰, 그리고 블로그 게시물과 그 카테고리, 태그 및 이미지.

아피리에이트 프로필, 수수료 기록 및 지급 내역도 가져올 수 있지만, 먼저 Spwig 마이그레이션 브리지 플러그인을 설치해야 합니다 — 아래를 참조하십시오. 이를 설치하지 않으면 해당 데이터는 건너뜁니다.

또한 다음 사항을 염두에 두십시오:

- 특정 WooCommerce 확장 프로그램(구독, 묶음, 예약, 선물 카드)에서 가져온 제품은 Spwig의 대응 기능에 들어갑니다. 하지만 모든 세부 사항이 이전과 동일하게 유지되지는 않습니다 — 아래의 **WooCommerce 확장 프로그램 지원**을 참조하십시오.
- 제품, 고객 및 주문에 있는 사용자 정의 필드는 자동으로 감지되며, 나중 단계에서 매핑이 필요합니다. [마이그레이션 필드 매핑](migration-field-mapping)을 참조하십시오.
- 마법사의 **세금 설정 가져오기** 및 **배송 지역 및 방법 가져오기** 옵션은 가져온 데이터에 적용되지 않습니다. 마이그레이션 후 Spwig에서 직접 세금 비율 및 배송 설정을 구성하십시오 — [마이그레이션 후](after-migration-review)를 참조하십시오.
- 동일한 단계의 **가격 조정** 옵션은 WooCommerce 가져오기에 적용되며, 제품이 생성될 때마다 기본 가격을 변경합니다. 모든 가격을 조정하고 싶지 않다면 **None**으로 설정해 두세요.

WordPress 관리자 로그인을 준비해 두고, 가져올 제품, 고객 및 주문의 수를 대략적으로 파악하여 마법사가 보여주는 수치를 정상성 검사를 할 수 있도록 하세요.

## REST API 자격 증명 얻기

Spwig은 WordPress 관리자에서 생성한 REST API 키를 사용하여 WooCommerce에 연결합니다.

이 키는 **읽기** 권한만 필요합니다 — Spwig은 마이그레이션 중에만 상점에서 데이터를 읽고, 다시는 아무것도 쓰지 않습니다.

1. WordPress에서 **WooCommerce > 설정 > 고급 > REST API**로 이동합니다.
2. **키 추가**를 클릭합니다.
3. 설명을 입력하세요(예: `Spwig Migration`) 및 **권한**을 **읽기**로 설정합니다.
4. **API 키 생성**을 클릭합니다.
5. **소비자 키**(ck_...) 및 **소비자 비밀**(cs_...)을 안전한 곳에 복사합니다.

> **중요:** WooCommerce는 생성 시점에만 소비자 비밀을 표시합니다. 복사하기 전에 다른 페이지로 이동하면 새로운 키를 생성해야 합니다.

## 상점 연결

Spwig 관리에서 **데이터 임포트 및 내보내기 > 새 마이그레이션 시작**으로 이동하고, 단계 1에서 **WooCommerce**를 선택합니다. 단계 2에서 다음을 입력합니다:

- **상점 URL** — 상점의 전체 웹 주소, 예: `https://mystore.com`
- **소비자 키** 및 **소비자 비밀** — 방금 복사한 값

**진행하기 전에 연결 테스트**를 선택한 상태로 두세요(기본값은 활성화됨) — Spwig은 계속하기 전에 상점을 연결하고 인증할 수 있는지 확인합니다. 이는 임포트 중간에 오타나 권한 문제를 잡는 대신 즉시 확인할 수 있습니다. 성공하면 **다음**을 클릭합니다.

## 데이터 검토 및 선택

단계 3은 상점에서 실시간으로 카테고리, 제품, 고객, 주문, 리뷰 및 쿠폰의 수를 가져옵니다. 또한 첫 5개 제품의 샘플도 가져와서 올바른 사이트를 읽고 있는지 확인할 수 있습니다. 각 데이터 유형의 체크박스는 해당 수가 0보다 클 때 자동으로 선택되고, 0일 때는 비활성화됩니다.

**임포트 옵션:**

- **기존 항목 건너뛰기**(활성화됨) — 들어오는 레코드를 Spwig에 이미 있는 항목(제품의 SKU, 고객의 이메일)과 비교하여 중복 항목을 건너뜁니다.

```python
# 예시 코드 블록 (변경하지 않음)
import requests

response = requests.get("https://api.example.com/data")
print(response.json())
```

![Spwig WooCommerce 연결 이미지](/static/core/admin/img/woocommerce-connection.png)

> 참고: 이 이미지의 대체 텍스트는 "Spwig WooCommerce 연결"으로 번역되었습니다.

빈 상태에서 시작하지 않는 한 끄지 마세요.
- **제품 이미지 가져오기** (켜짐) — 느리지만 가치가 있습니다.
- **가능한 한 원본 ID 유지** (꺼짐) — 마법사 자체가 이 옵션을 "추천하지 않음"으로 표시합니다. WooCommerce의 숫자 ID를 유지해야 하는 특별한 기술적 이유가 없다면 꺼 두세요.
- **배치 크기** — 10, 25(기본값), 50 또는 100개의 레코드씩.

작은 배치는 불안정한 연결에 적합하며, 안정적인 연결에서는 더 큰 배치가 더 빠르게 완료됩니다.

## Spwig 마이그레이션 브리지 플러그인

WooCommerce에는 아フィ리에이트 프로그램에 대한 내장 개념이 없기 때문에, 만약 WooCommerce 아피리에이트 확장 기능을 통해 아피리에이트 프로그램을 운영하고 있다면, 해당 데이터는 표준 REST API가 접근할 수 없는 테이블에 저장됩니다. **Spwig 마이그레이션 브리지**(Spwig Migration Bridge)는 WordPress 사이트에 설치하는 작은 보조 플러그인으로, 이를 노출시켜 줍니다.

브리지 플러그인은 다음과 같은 기능을 제공합니다:

- **아피리에이트 프로필** — 아피리에이트의 세부 정보 및 추천 코드
- **커미션 기록** — 각 아피리에이트와 연결된 커미션 기록
- **지급 내역** — 아피리에이트에게 지급된 과거 내역

이것은 선택 사항입니다. Spwig에서 아피리에이트 프로그램을 운영하지 않거나 해당 내역이 필요하지 않다면 건너뛰세요.

> **참고:** 아피리에이트 데이터는 동일한 마이그레이션에서 주문과 고객도 함께 가져오는 경우에만 가져올 수 있습니다. 커미션과 지급 내역은 특정 주문과 고객과 연결되어 있기 때문입니다.

설치 방법:

1. 단계 3에서 플러그인이 이미 사이트에 감지되지 않은 경우, **브리지 플러그인 다운로드**(Download Bridge Plugin) 버튼과 설치 지침이 표시됩니다.
2. 플러그인 ZIP 파일을 다운로드합니다.
3. WordPress에서 **플러그인 > 새 플러그인 추가 > 플러그인 업로드**, ZIP 파일을 선택한 후 **지금 설치**(Install Now)를 클릭한 다음 **활성화**(Activate)를 클릭합니다.
4. Spwig 마법사로 돌아가서 페이지를 새로 고침하면 **아피리에이트**(Affiliates) 확인란과 **아피리에이트 프로그램 데이터**(Affiliate Program Data) 블록이 나타나며, 발견된 수량이 표시됩니다.

마이그레이션이 완료되면 WordPress에서 브리지 플러그인을 비활성화하고 제거할 수 있습니다.

## WooCommerce 확장 기능 지원

# 특정 인기 확장 기능 사용 시

가게가 특정 인기 확장 기능을 사용하는 경우, 이들이 생성한 제품은 임포트 시 일반 제품이 아닌 대응하는 Spwig 기능으로 인식되어 매핑됩니다:

| WooCommerce 확장 기능 | 매핑되는 위치 |
|---|---|
| Subscriptions | Spwig 구독 계획 |
| Product Add-Ons | Spwig 제품 추가 기능 |
| Product Bundles | Spwig 제품 묶음 |
| Gift Cards (WooCommerce, YITH 및 PW 버전) | Spwig 선물 카드 |
| Composite Products | Spwig 복합 제품 |
| Bookings and Accommodation Bookings | Spwig 예약 |

> **참고:** 확장 기능 데이터 임포트는 기존 제품이 생성되는 것을 방해하지 않습니다. 제품의 확장 기능 관련 데이터를 읽을 수 없는 경우에도 제품은 여전히 임포트되며, 단지 일반 제품으로 임포트되며 구독, 묶음, 예약 또는 선물 카드 설정은 포함되지 않습니다.

임포트 후 구독, 묶음, 예약 및 선물 카드 제품을 점검하여 확장 기능 관련 설정이 올바르게 전달되었는지 확인하세요. 성공적인 임포트가 모든 세부 사항을 포함했다고 가정하지 마세요.

## 사용자 정의 필드

WooCommerce 제품, 고객 또는 주문에 사용자 정의 메타 필드를 추가한 경우, Spwig은 각 유형의 약 10개 레코드를 샘플링하여 존재하는 필드를 감지합니다. 단계 4에서 각 필드를 Spwig 사용자 정의 필드 슬롯 또는 일반 메타 데이터 필드에 매핑해야 합니다. [이전 데이터 이전 필드 매핑](migration-field-mapping)을 참조하여 전체 가이드를 확인하세요. 포함된 매핑이 향후 데이터 이전에 어떻게 저장되는지 포함합니다.

## 임포트 실행

단계 3을 검토하고 단계 4에서 매핑을 확인한 후 임포트를 시작하세요. 이는 백그라운드에서 실행됩니다 — 브라우저 창을 닫아도 계속 진행됩니다. 단계 5는 데이터 유형(카테고리, 제품, 고객, 주문, 리뷰, 쿠폰, 블로그 게시물 및 Bridge 플러그인을 사용한 경우의 파트너/커미션/지급)별로 진행 상황을 실시간으로 표시하며, 확장 가능한 활동 로그도 포함합니다.

6단계는 결과를 보여줍니다: 가져온 항목, 건너뛴 항목 또는 실패한 항목, 그리고 가져온 콘텐츠에 이전 WooCommerce 도메인을 가리키는 내부 링크가 포함되어 있을 경우 **링크 재작성** 도구가 제공됩니다.

요약을 신중히 검토한 후 [이전 이전 후 점검](after-migration-review)에서 제공하는 확인 목록을 따라 진행하세요. 이 목록은 데이터 확인, 세금율 및 배송 설정(마법사가 설정하지 않음) 및 내부 링크 재작성을 포함합니다.

## API 키 취소

이전 이전이 성공적으로 완료되었음을 확인한 후 WordPress에서 **WooCommerce > 설정 > 고급 > REST API**로 이동하여 Spwig을 위해 생성한 키를 취소하거나 삭제하세요. 이전 이전이 완료된 후 이전 스토어에 활성화된 API 키를 남겨둘 이유는 없습니다.

## 팁

- **필요할 때 바로 API 키를 생성하세요** - Consumer Secret은 한 번만 표시되므로, 2단계를 시작하기 직전에 생성하세요. 미리 생성하지 마세요.
- **읽기 전용이 충분합니다** - 쓰기 또는 읽기/쓰기 권한을 결코 부여하지 마세요. Spwig은 WooCommerce 스토어에서 항상 읽기만 수행합니다.
- **이전에 가져오기 시작하기 전에 Bridge 플러그인을 설치하세요** - 가져오기 전에 추가하고 마법사를 새로 고쳐야 하므로, 가져오기 중간에 찾기보다는 미리 확인하세요.
- **확장 기반 제품을 점검하세요** - 구독, 번들, 예약 및 기프트 카드는 가져오기 후 수동 점검이 필요한 제품입니다.
- **부분 가져오는 경우 자동으로 정리되지 않습니다** - 가져오기 실패 후 다시 시도하기 전에 [이전 이전 문제 해결](migration-troubleshooting)을 참조하세요.
- **이전이 완료되면 API 키를 취소하세요** - 이전 이전한 스토어에 이전된 인тег레이션을 활성화 상태로 남겨두지 마세요.
