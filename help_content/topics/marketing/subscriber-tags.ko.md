---
title: 구독자 태그
---

태그는 캠페인 스튜디오의 대상을 조직하기 위한 자체 라벨입니다. `VIP`, `단량`, 또는 `이벤트-2026`과 같은 짧은 마커로, 당신이 정의하고 해당 구독자에게 적용할 수 있습니다. 한 번 생성된 태그는 언제든지 구독자 목록을 필터링하거나, 여러 사람에게 동시에 적용하거나 제거할 수 있으며, 가장 유용하게도 세그먼트를 만들 때 조건으로 사용하여 정확하게 태그를 지정한 사람에게 타겟팅할 수 있습니다.

## 태그란 무엇인가요?

태그는 단순히 선택한 이름일 뿐입니다. Spwig는 미리 정의된 태그를 제공하지 않으며, 자동으로 하나을 적용하지 않습니다. 당신이 이름을 정하고, 누구에게 적용할지 결정합니다. 이는 Spwig가 이미 추적하는 상태와 일치하지 않는, 당신의 비즈니스에 특별한 항목에 적합합니다. 충성 고객 레벨, 단량 계정, 전시회에서 가입한 모든 사람, 또는 `이벤트-2026`과 같은 단일 이벤트 목록과 같은 항목입니다.

각 태그에는 **Slug**도 있습니다. 이는 이름의 단순화된, URL 안전 버전으로, 생성 시 자동으로 생성됩니다. 세그먼트 및 필터는 내부적으로 슬러그를 사용하며, 상인으로서는 거의 사용하지 않을 것입니다.

## 태그 생성하기

태그는 자체 관리 섹션을 가지고 있습니다. **캠페인 스튜디오 > 구독자**로 이동한 후, 페이지 상단의 **캠페인 스튜디오**를 클릭하여 캠페인 스튜디오 섹션 전체 목록을 확인하고, **구독자 태그**를 선택하십시오.

1. **구독자 태그 추가**를 클릭하십시오.
2. **이름**을 입력하십시오. 짧고 구체적인 것이 가장 좋습니다. 예: `VIP`, `단량`, 또는 `이벤트 2026`.
3. Spwig가 입력하는 동안 일치하는 **Slug**를 채웁니다. 생성된 대로 두어도 됩니다.
4. 원하시면 **색상** 필드를 사용하여 헤시 코드(`#2563eb` 등)를 기록할 수 있습니다.
5. **저장**을 클릭하십시오.

이름을 지을 필요가 있는 것은 아닙니다. 구독자의 편집 페이지에서 **태그** 필드 옆에 초록색 **+**가 표시되면, 동일한 "태그 추가" 폼을 팝업으로 열 수 있습니다.

그리고 태그를 하나도 생성하지 않은 상태에서 구독자 일괄 태그를 시도하면, 태그 선택기에 **태그 생성** 단축키가 제공되어 해당 페이지로 바로 이동할 수 있습니다.

## 구독자 태그 지정

태그를 적용하는 가장 일반적인 방법은 구독자 목록에서 일괄 적용하는 것입니다:

1. **캠페인 스튜디오 > 구독자**를 엽니다.
2. 태그를 지정하려는 각 구독자의 체크박스를 선택합니다(또는 **이 페이지의 모든 항목 선택**을 클릭합니다).
3. **일괄 작업** 드롭다운에서 **선택 항목에 태그 추가…**를 선택합니다(또는 태그를 제거하려면 **선택 항목에서 태그 제거…**를 선택합니다).
4. **실행**을 클릭합니다.
5. 목록에서 태그를 선택하고 **태그 추가**(또는 **태그 제거**)를 클릭합니다.

!["선택 항목에 태그 추가…"를 4명의 구독자에게 선택한 후의 일괄 태그 선택기](/static/core/admin/img/help/subscriber-tags/bulk-tag-picker.webp)

적용된 후, 태그는 목록에서 구독자 카드에 상태 및 소스 배지와 함께 작은 칩으로 표시됩니다. 최소 하나의 태그가 있으면 구독자 목록의 필터 패널에 **태그** 필터도 나타나므로, 특정 태그를 가진 모든 사람을 대상으로 목록을 좁혀서 해당 캠페인을 만들기 전에 대상 집단에 누가 포함되어 있는지 확인할 수 있습니다.

![VIP 태그로 필터링된 구독자 목록, CSV 가져오기 버튼 및 태그 칩이 표시됨](/static/core/admin/img/help/subscriber-tags/subscriber-list-tag-chips.webp)

일괄 작업이 관리하는 동일한 **태그** 필드를 사용하여 개별 구독자의 태그를 해당 편집 페이지에서 직접 추가하거나 제거할 수도 있습니다.

## 세그먼트에서 태그 사용

세그먼트는 캠페인과 여정을 지시하는 저장된 규칙 기반 대상 집합입니다. 최소 하나의 태그를 생성하면 세그먼트 규칙 빌더에서 **태그 보유** 조건이 사용 가능해집니다. 태그가 정의되지 않은 신규 설치 환경에서는 해당 옵션이 표시되지 않으므로, 유용하기 전에 무용한 옵션을 보게 되는 일이 없습니다.

사용하려면 **캠페인 스튜디오 > 세그먼트**를 열고 동적 세그먼트를 추가(또는 편집)한 다음 **+ 조건 추가**를 클릭합니다:

1.

조건 필드를 **태그 보유**로 설정합니다.
2.

연산자 선택 — **is**는 단일 태그에 사용하고, **is any of**는 다른 방식으로 표현하고 싶을 때 사용합니다.
3.

드롭다운에서 태그를 선택하십시오.

![태그가 VIP로 설정된 'Has tag' 조건, 일치하는 구독자 수가 표시됨](/static/core/admin/img/help/subscriber-tags/segment-has-tag-rule.webp)

규칙을 만들면서 상단 오른쪽의 카운트가 업데이트됩니다. 이는 저장하기 전에 현재 해당 규칙에 부합하는 구독자가 몇 명인지 정확히 확인할 수 있도록 합니다. 현재 **Has tag** 조건은 하나의 태그만 일치시킵니다. 여러 태그 중에서 어떤 태그든 일치시키고 싶다면 (예: `VIP` 또는 `Wholesale`), 각 태그당 **Has tag** 조건을 하나씩 추가하고, **Match**를 **any**로 설정하십시오.

이러한 방식으로 태그가 조직화하는 것 이상으로 유용하게 사용됩니다. **Has tag**를 기반으로 한 세그먼트는 브로드캐스트나 반복 캠페인에서 **Segment**로 선택하거나, 여정의 **Only for segment** 설정으로 사용할 수 있습니다. 즉, 'VIP 태그가 있는 사람'은 별도의 환영 시리즈나 반복 뉴스레터를 가지거나, 단순히 다음 번 한 번만 보내는 공지사항을 선택할 때 누군가를 선택할 수 있습니다.

## 팁

모든 마크다운 포맷, 이미지 경로, 코드 블록, 기술 용어를 보존하십시오.

- 태그 이름은 짧고 구체적으로 유지하세요 — 구독자 카드에 컴팩트한 칩으로 표시되므로 `VIP`가 `Very Important Person - Tier 1`보다 훨씬 잘 읽힙니다.
- 세그먼트를 구성하거나 캠페인을 보내기 전에 실제로 태그가 적용된 대상이 누구인지 확인하려면 **태그** 필터를 사용하세요.
- 태그는 누적형입니다 — 구독자에서 태그를 제거해도 해당 구독자의 다른 태그에는 영향을 주지 않으며, 상태, 출처, 동의 정보에도 절대 영향을 미치지 않습니다.
- 태그를 다른 룰 빌더 조건(예: **마케팅 동의** 또는 **총 지출액**)과 동일한 세그먼트에서 함께 사용하여 태그 단독 사용보다 더 정확한 대상 집합을 구성하세요.
- 구독자는 원하는 만큼 많은 태그를 가질 수 있습니다 — 제한이 없으므로 여러 겹치는 용도(로열티 등급 *및* 이벤트 목록 *및* 출처 메모)에 함께 사용하는 것이 가능합니다.
- 더 이상 유용하지 않은 태그가 있다면, **구독자 태그**에서 삭제하면 해당 태그가 적용된 모든 구독자와 이를 참조한 모든 세그먼트 규칙에서 제거됩니다 — 해당 태그를 사용하던 세그먼트는 해당 조건에 대해 더 이상 매칭되지 않게 됩니다.
