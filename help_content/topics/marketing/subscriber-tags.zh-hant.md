---
title: 訂閱者標籤
---

標籤是您用來組織 Campaign Studio 受眾的自訂標籤——例如 `VIP`、`wholesale` 或 `event-2026` 等簡短標記，由您定義並套用至符合條件的訂閱者。一旦標籤建立完成，您就可以依此篩選訂閱者清單、一次為多人套用或移除標籤，以及——最實用的是——在建立分群（Segment）時將其作為條件，讓您的行銷活動與旅程能精準針對您已標記的對象。

## 標籤是什麼

標籤不過是您選擇的一個名稱。Spwig 不內建任何標籤，也從不會自動套用——由您決定標籤名稱以及誰擁有該標籤。這使它們非常適合用於任何特定於您自身業務、且無法對應到 Spwig 已追蹤狀態的項目：例如忠誠度等級、批發帳戶、在展覽上註冊的所有人，或像 `event-2026` 這樣的一次性活動清單。

每個標籤也會有一個 **Slug**——其名稱的簡化、URL 安全版本——在建立時自動生成。分群與篩選器內部使用 slug；作為商家，您幾乎不需要查看它。

## 建立標籤

標籤擁有自己的管理區段。開啟 **Campaign Studio > Subscribers**，然後點擊頁面頂部的 **Campaign Studio** 以查看完整的 Campaign Studio 區段清單，並選擇 **Subscriber tags**。

1. 點擊 **Add subscriber tag**。
2. 輸入 **Name**——簡短且具體的最佳，例如 `VIP`、`Wholesale` 或 `Event 2026`。
3. Spwig 會隨您輸入自動填入對應的 **Slug**。您可以保留自動生成的內容。
4. 如果您希望為標籤記錄一個十六進位顏色（例如 `#2563eb`）以供自己參考，也可以使用選填的 **Colour** 欄位。
5. 點擊 **Save**。

您也不必中斷目前的工作來建立標籤——在任何訂閱者的編輯頁面上，**Tags** 欄位旁邊的綠色 **+** 會在彈出視窗中開啟相同的「新增標籤」表單。

如果您在尚未建立任何標籤的情況下，嘗試為訂閱者批量貼上標籤，標籤選擇器會提供一個**建立標籤**的快捷方式，直接帶您前往該頁面。

## 為訂閱者貼上標籤

套用標籤最常見的方式是透過訂閱者清單進行批量操作：

1. 開啟**Campaign Studio > Subscribers**。
2. 勾選您想要貼上標籤的每位訂閱者的核取方塊（或**Select all on this page**）。
3. 從**Bulk actions**下拉選單中，選擇**Add tag to selected…**（或選擇**Remove tag from selected…**以移除標籤）。
4. 點擊**Go**。
5. 從清單中選擇標籤，然後點擊**Add tag**（或**Remove tag**）。

![選擇「Add tag to selected…」為四位訂閱者貼上標籤後的批量標籤選擇器](/static/core/admin/img/help/subscriber-tags/bulk-tag-picker.webp)

套用後，標籤會以小型徽章的形式顯示在清單中訂閱者卡片上，與其狀態和來源徽章並列。一旦您至少建立了一個標籤，訂閱者清單的篩選面板中也會出現**Tag**篩選器，讓您可以將清單縮小至所有帶有特定標籤的人員——這在建立相關活動前檢查受眾範圍時非常實用。

![篩選至 VIP 標籤的訂閱者清單，可見匯入 CSV 按鈕和標籤徽章](/static/core/admin/img/help/subscriber-tags/subscriber-list-tag-chips.webp)

您也可以直接從個別訂閱者的編輯頁面，使用與批量操作相同的**Tags**欄位，來新增或移除該訂閱者的標籤。

## 在分群中使用標籤

分群（Segments）是您儲存並指向活動和旅程的基於規則的受眾。一旦您建立了至少一個標籤，分群規則建立器中就會出現**Has tag**條件——在沒有定義任何標籤的全新安裝中，此條件不會出現，因此您不會在對您有用之前看到一個無效的選項。

要使用它，請開啟**Campaign Studio > Segments**，新增（或編輯）一個動態分群，並點擊**+ Add condition**：

1.

將條件的欄位設定為**Has tag**。
2.


選擇一個運算子 — **is** 用於單一標籤，或 **is any of** 用於以其他方式表達的情況。
3。

從下拉選單中選擇標籤。

![「Has tag」條件設為 VIP，顯示符合訂閱者的即時數量](/static/core/admin/img/help/subscriber-tags/segment-has-tag-rule.webp)

右上角的數量會隨著您建立規則而更新，讓您可以精確看到目前符合條件的訂閱者數量，再進行儲存。每個 **Has tag** 條件目前每次只會匹配一個標籤 — 如果您想要建立一個符合多個標籤中任何一個的受眾（例如 `VIP` 或 `Wholesale`），請為每個標籤新增一個 **Has tag** 條件，並設定 **Match** 為 **any**。

這就是標籤除了用於組織之外的優勢：基於 **Has tag** 建立的段落可以作為 **Segment** 選擇，用於廣播或定期活動，或者作為旅程的 **Only for segment** 設定 —— 所以「所有標籤為 VIP 的人」可以有自己的歡迎系列、自己的定期通訊，或者只是您下次發送單次公告時所選擇的對象。

## 小技巧

保留所有 markdown 格式、圖片路徑、程式碼區塊和技術術語。

- 標籤名稱請保持簡短且具體——它們會以精簡標籤的形式顯示在訂閱者卡片上，因此 `VIP` 比 `Very Important Person - Tier 1` 更易讀。
- 在建立分群或發送相關活動之前，請使用 **Tag** 篩選器來確認哪些訂閱者確實已被標記。
- 標記是累加的——從訂閱者身上移除某個標籤，絕不會影響他們擁有的其他標籤，也不會觸及他們的狀態、來源或同意設定。
- 將標籤與其他規則建構器條件（例如 **Opted into marketing** 或 **Total spent**）結合在同一個分群中，以獲得更精確的受眾，而非僅依賴單一標籤。
- 訂閱者可以擁有任意數量的標籤——沒有限制，因此您可以將它們用於多個重疊的用途（例如忠誠度層級 *以及* 活動清單 *以及* 來源備註）。
- 如果某個標籤不再有用，從 **Subscriber tags** 中刪除它，將從所有已套用該標籤的訂閱者以及任何引用該標籤的分群規則中移除它——使用該標籤的分群將簡單地停止匹配該條件。
