---
title: 受众
---

**细分** 是一个已保存的受众，您可以将其用于营销活动、客户旅程或 A/B 测试——Campaign Studio 自身的细分列表将其称为“目标受众”，本指南对同一事物使用这两个词。每个细分要么是**动态**的，由 Spwig 每次使用时重新评估的规则定义；要么是**静态**的，即您手动选择的订阅者明确列表。

本指南涵盖动态细分规则的设置——包括用于定位您商店自身客户价值层级、忠诚度计划和联盟合作伙伴的新字段——以及一键**添加初始受众**按钮，该按钮会根据您商店已有的数据构建一组现成的细分。

## 动态与静态细分

| 类型 | 工作原理 | 适用场景 |
|---|---|---|
| **动态（规则）** | 您定义条件——例如“总消费金额至少为 500 美元”。Spwig 每次使用细分时都会重新计算符合条件的用户，因此随着订阅者的变化，成员资格会自动更新。 | 需要始终保持最新的持续受众，例如“VIP 客户”或“90 天内未下单”。 |
| **静态（固定列表）** | 一个明确的订阅者列表，您手动添加或移除成员。除非您更改，否则成员资格永不改变。 | 一次性列表——来自特定活动的每个人，或为一次性发送而手动挑选的群体。 |

创建细分时，使用**类型**字段选择类型。本指南的其余部分关于动态细分——静态细分只是一个成员列表，没有需要配置规则。

## 构建动态细分

打开 **Campaign Studio > 细分**，然后点击 **+ 新建细分**（或打开现有的动态细分）以进入**受众规则**构建器。点击 **+ 添加条件** 以添加规则，选择要检查的内容及方式，并设置订阅者必须匹配**所有**还是**任意**条件。右上角的实时计数——例如“8 位符合条件的订阅者”——会在每次更改后片刻更新，因此您可以在保存前确切看到谁符合条件。

[The Audience rules builder with Customer segment, Loyalty tier, Lifetime value, and Affiliate conditions set, and a live matching-subscriber count](/static/core/admin/img/help/audiences/rule-builder-new-fields.webp)

一个具有固定 **is true** 样式的检查条件 —— **已下单**, **订阅营销**, **忠诚会员**, **联盟伙伴** —— 除了选择字段本身之外，不需要任何操作符或值；无需设置操作符或值。

## 您可以定位的内容

| 字段 | 检查内容 | 
|---|---| 
| **总消费** | 生命周期内的订单总额。 | 
| **订单数量** | 完成的订单数量。 | 
| **生命周期价值** | 客户的计算出的生命周期价值。 | 
| **平均订单价值** | 每个完成订单的平均金额。 | 
| **自上次订单以来的天数** | 自客户最近一次订单以来的天数 —— 目标为90天以上，用于重新获取客户群体。 | 
| **已下单** | 客户是否至少有一个完成的订单。 | 
| **订阅营销** | 订阅者是否同意接收营销邮件。 | 
| **语言** | 订阅者的存储语言。 | 
| **来源** | 订阅者加入的方式 —— 商店注册、导入、订单、手动添加或 API。 | 
| **加入日期之后** | 在选定日期或之后加入的订阅者。 | 
| **有标签** | 订阅者是否拥有您创建的[标签](/help/subscriber-tags)。 | 
| **客户分组** | 客户是否属于您商店的某个命名的[客户分组](/help/customer-segments) —— 未注册客户、新客户、常规客户、常客、高价值客户、VIP客户、低价追求者、高风险客户或不活跃客户。 | 
| **忠诚会员** | 客户是否是您忠诚计划的活跃成员。 | 
| **忠诚积分** | 会员当前的可用积分余额。 | 
| **忠诚等级** | 会员当前所处的忠诚等级。 | 
| **联盟伙伴** | 客户是否是您活跃的联盟合作伙伴之一。 |

**客户分组**, 两个 **忠诚度** 值字段, **忠诚度等级**, 和 **联盟伙伴** 是新增的选项, 仅在您的商店实际拥有此类数据时才会在条件选择器中显示: 忠诚度字段会在您的忠诚度计划有成员且至少有一个活跃等级时出现, **联盟伙伴** 会在您至少有一个联盟伙伴时出现, **客户分组** 会在您至少配置了一个活跃客户分组时出现。

您将不会在全新商店中看到任何不可能匹配任何人的选项。

一个目前需要了解的限制: 对于任何具有下拉选项的条件 - **语言**, **来源**, **有标签**, **客户分组**, **忠诚度等级** - **是其中之一** 运算符仍然只能一次选择一个值。如果您想要匹配多个(例如, 既在您的VIP或高价值分组中的客户), 请为每个值添加一个条件并将 **匹配** 设置为 **任意**。

## 添加初始分组

从零开始为每个明显的分组 - 您的VIP客户, 您的忠诚度成员, 所有已经静默的客户 - 创建一个规则非常繁琐, 当Spwig已经可以识别谁符合条件时。在分组列表中, 点击 **添加初始分组** , Spwig会根据您商店已有的客户, 忠诚度和联盟伙伴数据创建一组现成的可编辑动态分组。

![带有新增分组和添加初始分组按钮的分组列表](/static/core/admin/img/help/audiences/segments-changelist.webp)

| 入门 | 目标 | 需求 |
|---|---|---|
| **VIP 客户** | 您的 VIP 客户细分 | 一个活跃的 VIP 客户细分 |
| **高价值客户** | 您的 VIP 和高价值客户细分 | 一个活跃的 VIP 或高价值客户细分 |
| **回头客** | 您的常客和常规客户细分 | 一个活跃的常客或常规客户细分 |
| **新客户** | 您的新客户细分 | 一个活跃的新客户细分 |
| **流失客户** | 曾下过单但最近 90 天内未下单的客户 | 任何客户订单历史 |
| **忠诚度会员** | 您忠诚度计划中的所有活跃成员 | 一个拥有会员的活跃忠诚度计划 |
| **顶级忠诚度层级** | 您排名最高的忠诚度层级中的成员 | 至少一个活跃的忠诚度层级 |
| **联盟伙伴** | 您活跃的联盟合作伙伴 | 至少一个联盟伙伴 |

Spwig 仅创建其实际拥有数据的入门受众——尚未设置忠诚度计划的商店不会获得 **忠诚度会员** 入门受众，而不是一个永远无法匹配任何人的空受众。Spwig 会准确确认其添加的内容，例如：“已添加 7 个入门受众：高价值客户、回头客、新客户、流失客户、忠诚度会员、顶级忠诚度层级、联盟伙伴。”

![确认刚刚添加了哪些入门受众的成功消息](/static/core/admin/img/help/audiences/starter-audiences-added.webp)

多次点击 **添加入门受众** 是安全的。Spwig 永远不会创建已存在的入门受众的副本，因此在（例如）首次设置忠诚度计划后再次点击，只会添加新可用的内容——如果所有内容都已设置，它只会说明这一点。

![当所有入门受众都已存在时显示的信息消息](/static/core/admin/img/help/audiences/starter-audiences-already-set-up.webp)

如果您删除了某个不需要的初始受众，再次点击**添加初始受众**不会将其恢复——Spwig 会将其视为您有意删除的细分，而不是需要重新创建的细分。

一旦创建，初始受众就是一个普通的动态细分：您可以从列表中打开它，查看或调整其规则、重命名或删除它，操作方式与您自己创建的任何细分完全相同。

## 这些受众实际覆盖的人群

上述客户、忠诚度和合作伙伴条件仅匹配其电子邮件与顾客账户关联的订阅者——匿名新闻通讯注册不会匹配**忠诚度会员**或**VIP**条件，这是正确的，因为 Spwig 没有订单或忠诚度历史记录可供核对。如果您的许多客户拥有账户但尚未订阅，请负责管理您的 Spwig 安装的人员运行一次订阅者同步——它会一步为每个现有顾客账户创建订阅者记录，从而使这些受众有真实的人可供匹配。

无论细分包含多少订阅者，该数字描述的是*可能*接收营销活动的人群，而不是实际接收的人群。每次发送都会先检查每个订阅者自己的营销同意状态，因此细分绝不是绕过这一检查的方式。

## 提示

- 从初始受众开始并进行调整，而不是手动构建相同的规则——一旦创建，初始受众与您自己创建的任何细分没有区别。
- 像**忠诚度会员**、**合作伙伴**和**已下单**这样的布尔条件不需要运算符或值——只需添加条件即可。
- 将新字段与原始字段结合使用以实现更精准的定位，例如**忠诚度会员**加上**已同意营销**，而不是仅依赖单一条件。
- 如果细分的规则引用了已被删除的内容——例如已删除的顾客细分、已清空的标签等——Spwig 会将其视为不匹配任何人，而不是回退到您的整个订阅者列表。

错误的定向发送会意外地向所有人广播。
- 如果某个分组的成员数量看起来已过时，请打开它并再次保存，或者从分组列表中使用 **重新生成成员数量** 批量操作，立即重新计算。
- 在构建规则时，请注意实时的“匹配订阅者”数量 —— 这是最快的方式，可以在保存之前发现你所设置的条件是否比预期更窄（或更宽）。
