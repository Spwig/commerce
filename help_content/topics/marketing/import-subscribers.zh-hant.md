---
title: 從 CSV 匯入訂閱者
---

如果您在其他地方已經有一份通訊名單——例如舊的電子郵件工具、電子報訂閱的試算表，或一堆展會胸卡掃描資料——您不需要逐一將這些聯絡人新增到 Spwig。Campaign Studio 的訂閱者匯入功能可讀取 CSV 或 Excel 檔案，並一次性將所有有效聯絡人加入您的受眾，隨時可進行標籤、分群和發送電子郵件。

## 匯入前：同意

每次匯入都需要您勾選一個確認框：**「這些聯絡人已同意接收我的行銷電子郵件。」** 這並非形式主義——請僅匯入真正已選擇接收您行銷電子郵件的聯絡人。這很重要，原因有二：

- **在大多數地區這是法律要求。** 向從未同意接收行銷電子郵件的人發送郵件，會違反許多司法管轄區的同意法。
- **這有助於保護您的郵件送達率。** 向從未選擇加入的人發送電子郵件會產生垃圾郵件投訴和退信，郵件服務供應商會據此判斷您的*任何*電子郵件——包括發給已選擇加入的人的郵件——是否能進入收件匣。

如果一份名單並非明確來自已選擇加入的訂閱，請勿匯入。

## 準備您的檔案

匯入工具接受包含標題列的 `.csv` 或 `.xlsx` 檔案。只需一列為必填：

| 欄位 | 必填？ | 說明 |
|--------|-----------|-------|
| **Email** | 是 | 必須是有效的電子郵件地址。 |
| **First name** | 否 | 用於個人化電子郵件。 |
| **Last name** | 否 | 用於個人化電子郵件。 |
| **Language** | 否 | 訂閱者偏好的語言代碼（例如 `en`、`es`）。 |

欄位會根據標題名稱自動對應到這些欄位，因此您無需先重新命名——常見變體如 `E-mail`、`Email Address`、`First Name`、`Given Name`、`Surname` 或 `Locale` 均會被識別。

每次匯入上限為 **5 MB** 和 **5,000 列**。如果您的名單超過此限制，請將其拆分為較小的檔案，並逐一匯入。

## 匯入您的聯絡人

1.

開啟 **Campaign Studio > 當前訂閱者** 並點擊 **匯入 CSV**。
2.

選擇您的 `.csv` 或 `.xlsx` 檔案。
3.

選擇當 **聯絡人已經在您的清單中** 時該如何處理 — 請參閱下方的 [處理重複資料](#handling-duplicates)。
4.

選擇一個標籤，於 **匯入聯絡人時套用標籤** 下方，以標記此批次的所有聯絡人（例如 `Event 2026`） — 請參閱 [訂閱者標籤](/help/subscriber-tags) 以了解更多關於標籤的資訊。
5.

勾選 **這些聯絡人已同意接收我發送的行銷電子郵件**。
6.

點擊 **繼續**。

![已選擇檔案、選取標籤並確認同意的匯入上傳表單](/static/core/admin/img/help/import-subscribers/import-upload-form.webp)

Spwig 會在實際匯入前顯示預覽画面：

![顯示新增、已存在以及跳過無效數量及其原因的匯入預覽](/static/core/admin/img/help/import-subscribers/import-preview.webp)

- **新增聯絡人** — 會建立全新訂閱者的資料列。
- **已在您的清單中** — 這類資料列的電郵位址與現有訂閱者相符。
- **跳過（無效）** — 無法讀取的資料列，每個都會列出其資料列編號和原因（無效的電郵格式、電郵欄位為空白，或與同一檔案中先前資料列重複）。

檢查這些數字，然後點擊 **立即匯入** 來提交匯入，或點擊 **取消** 來放棄變更。

## 處理重複資料

當電郵位址與您已有的訂閱者相符時，這筆資料會被視為重複。您可以在上傳表單中選擇 Spwig 應如何處理這些資料：

| 選項 | 發生什麼 | 
|--------|--------------| 
| **保持不變** *(預設)* | 現有訂閱者的姓名和語言將保持不變。 | 
| **更新其姓名 / 語言** | 現有訂閱者的名、姓和語言將從檔案中更新（僅針對檔案實際提供的欄位）。 | 

保留所有 markdown 格式、圖片路徑、程式碼區塊和技術術語。

您為導入選擇的標籤會套用到 **檔案中的所有人** —— 新增和現有聯繫人皆是，無論您選擇哪種重複選項。

因此，使用 **VIP** 標籤導入您的「VIP 清單」會同時標記您已有的聯繫人。

重複選項僅控制是否覆蓋現有聯繫人的 *姓名和語言*。

## 導入後

每個由導入建立的聯繫人會以來源 **Import** 記錄，並在您執行導入的那一刻標記為已同意（而不是他們可能在其他地方選擇加入的任何較早日期）。如果檔案提供了他們的名稱，則會儲存於其訂閱者資料中，這表示您活動中的 `[[first_name]]` 和 `[[last_name]]` 合併欄位現在也會正確地為他們個人化，即使他們從未建立 Spwig 帳戶。

## 小技巧

- 在上傳前，將來源清單匯出為單一工作表的 CSV 或 `.xlsx` 檔案，並使用乾淨的標題列 —— 過多的工作表、合併的單元格或總結列可能會干擾欄位匹配。
- 使用 **將導入的聯繫人標記為** 來馬上建立您之後想要目標的精準受眾 —— 請參閱 [訂閱者標籤](/help/subscriber-tags) 以了解如何從中建立一個群組。
- 在假設導入失敗前，請始終閱讀 **跳過（無效）** 的原因 —— 對於大多數真實世界的清單來說，少量跳過的列並有明確原因是正常的。
- 重新執行相同的檔案是安全的：您已經導入的聯繫人第二次會被視為重複，而不是重新建立。
- 如果您正在合併幾個小清單，請為每個導入使用不同的標籤（例如 `Import: Jan Event`、`Import: Trade Show`），這樣即使它們全部混合到您的主要受眾中，您也能區分它們。
- 對於超過 5,000 列的清單，請根據明顯的邊界（按字母順序、來源或收集日期）進行分割，而不是任意切割，以便之後每個批次都能輕鬆識別。
