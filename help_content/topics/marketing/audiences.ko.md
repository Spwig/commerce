---
title: 대상자
---

특정 조건을 기반으로 생성된 **세그먼트**는 캠페인, 여정, 또는 A/B 테스트에 지정할 수 있습니다. Campaign Studio의 자체 세그먼트 목록에서는 '타겟팅된 대상자'라고 부르며, 이 가이드에서는 이 두 단어를 동일한 의미로 사용합니다. 모든 세그먼트는 **동적** 또는 **정적**입니다. 동적 세그먼트는 Spwig가 매번 사용할 때마다 재평가하는 규칙에 의해 정의되며, 정적 세그먼트는 직접 선택한 구독자 목록입니다.

이 가이드는 동적 세그먼트의 규칙을 만드는 방법을 다루며, 이는 스토어의 고객 가치 백켓, 충성 고객 프로그램, 및 대리점에 대한 타겟팅이 가능한 새로운 필드를 포함합니다. 또한, 스토어에 이미 존재하는 데이터를 기반으로 준비된 세그먼트 집합을 생성하는 **시작 대상자 추가** 버튼을 제공합니다.

## 동적 세그먼트 vs. 정적 세그먼트

| 유형 | 작동 방식 | 적합한 경우 |
|---|---|---|
| **동적 (규칙 기반)** | "총 지출이 최소 $500"과 같은 조건을 정의합니다. Spwig는 세그먼트가 사용될 때마다 누가 일치하는지 다시 계산하여, 구독자가 변경될 때 자동으로 멤버십이 변경됩니다. | 항상 최신 상태로 유지해야 하는 지속적인 대상자, 예: "VIP 고객" 또는 "90일 동안 주문하지 않은 고객" |
| **정적 (고정 목록)** | 직접 추가하거나 제거하는 구독자 목록입니다. 멤버십은 변경되지 않으며, 당신이 변경하지 않는 한 영구히 유지됩니다. | 특정 이벤트의 모든 사람이나 단일 전송을 위한 수동으로 선택된 그룹과 같은 단일 목록 |

세그먼트를 생성할 때 **유형** 필드에서 유형을 선택합니다. 이 가이드의 나머지는 동적 세그먼트에 대해 다루며, 정적 세그먼트는 구성할 규칙이 없는 멤버 목록일 뿐입니다.

## 동적 세그먼트 만들기

**Campaign Studio > 세그먼트**로 이동한 후 **+ 새 세그먼트**를 클릭하거나 기존 동적 세그먼트를 열어 **대상 규칙** 빌더에 도달합니다. **+ 조건 추가**를 클릭하여 규칙을 추가하고, 확인할 내용과 방법을 선택한 후, 구독자가 모든 조건을 충족해야 하는지 또는 어떤 조건을 충족해야 하는지 설정합니다. 각 변경 사항 후에 실시간으로 업데이트되는 상단 오른쪽에 있는 카운트 예: "8명의 일치하는 구독자"가 표시되어, 저장하기 전에 정확히 누구에게 적용되는지 확인할 수 있습니다.

[The Audience rules builder with Customer segment, Loyalty tier, Lifetime value, and Affiliate conditions set, and a live matching-subscriber count](/static/core/admin/img/help/audiences/rule-builder-new-fields.webp)

고정된 **is true** 스타일 체크를 가진 조건 - **주문이 있음**, **마케팅에 등록됨**, **충성 고객**, **제휴사** - 필드 자체를 선택하기만 하면 되며, 연산자나 값은 설정할 필요가 없습니다.

## 타겟팅 가능한 항목

| 필드 | 확인하는 내용 |
|---|---|
| **총 지출** | 라이프타임 주문 합계. |
| **주문 수** | 완료된 주문 수. |
| **라이프타임 가치** | 고객의 계산된 라이프타임 가치. |
| **평균 주문 가치** | 완료된 주문당 평균 금액. |
| **마지막 주문 이후 일** | 고객의 최신 주문 이후로 얼마나 많은 시간이 지났는지 - 재등록 고객을 타겟으로 삼기 위해 90일 이상을 표적으로 삼으세요. |
| **주문이 있음** | 고객이 최소한 하나 이상의 완료된 주문을 가지고 있는지 여부. |
| **마케팅에 등록됨** | 구독자가 마케팅 이메일에 동의했는지 여부. |
| **언어** | 구독자가 저장한 언어. |
| **소스** | 구독자가 가입한 방법 - 스토어플랫폼 등록, 수입, 주문, 수동으로 추가, 또는 API. |
| **이후 가입** | 선택한 날짜 이후에 가입한 구독자. |
| **태그가 있음** | 생성한 [태그](/help/subscriber-tags)를 보유하고 있는지 여부. |
| **고객 세그먼트** | 고객이 귀하의 가게의 자체 이름이 붙은 [고객 세그먼트](/help/customer-segments) 중 하나에 속하는지 여부 - 게스트 고객, 신규 고객, 정기 고객, 빈번한 구매자, 고가치 고객, VIP 고객, 할인 찾기, 위험에 처진 고객, 비활성 고객. |
| **충성 고객** | 고객이 귀하의 충성 프로그램에 활성 멤버인지 여부. |
| **충성 포인트** | 멤버의 현재 사용 가능한 포인트 잔액. |
| **충성 레벨** | 멤버가 현재 보유한 충성 레벨. |
| **제휴사** | 고객이 귀하의 활성 제휴 파트너인지 여부.

**고객 세그먼트**, 두 개의 **충성도** 값 필드, **충성도 레벨**, 및 **제휴사**는 최신 추가 기능으로, 이들 각각은 귀하의 스토어에 해당 유형의 데이터가 실제로 존재할 때만 조건 선택기에서 표시됩니다. 충성도 프로그램이 멤버를 가지고 있고 최소한 하나의 활성 레벨이 있을 때 **충성도** 필드가 표시되며, **제휴사**는 최소한 하나의 제휴사가 있을 때 표시되며, **고객 세그먼트**는 최소한 하나의 활성 고객 세그먼트가 구성되어 있을 때 표시됩니다.

새로운 스토어에서는 아무도 일치하지 않는 옵션이 표시되지 않습니다.

알아두면 좋은 현재의 제한 사항: **언어**, **소스**, **태그 있음**, **고객 세그먼트**, **충성도 레벨**과 같은 선택 목록이 있는 조건에 대해서는 **'어떤 것이든'** 연산자는 여전히 하나의 값을 선택할 수 있습니다. 여러 개의 값을 일치시키려면 (예: VIP 또는 높은 가치 고객 세그먼트에 속하는 고객), 각 값당 하나의 조건을 추가하고 **일치**를 **어떤 것이든**으로 설정해야 합니다.

## 시작 세그먼트 추가

Spwig가 이미 해당하는 고객을 확인할 수 있기 때문에, 명백한 세그먼트를 위한 규칙을 새로 만드는 것은 번거로울 수 있습니다. 예를 들어, 귀하의 VIP, 충성도 멤버, 또는 조용해진 모든 고객과 같은 세그먼트를 위한 규칙을 새로 만드는 것은 번거로울 수 있습니다. '세그먼트' 목록에서 **시작 세그먼트 추가**를 클릭하면 Spwig가 이미 존재하는 고객, 충성도, 및 제휴사 데이터를 기반으로 준비된 동적 세그먼트를 생성합니다.

![새로운 세그먼트 및 시작 세그먼트 추가 버튼이 있는 세그먼트 목록](/static/core/admin/img/help/audiences/segments-changelist.webp)

| 스타터 | 대상 | 필요한 조건 |
|---|---|---|
| **VIP 고객** | 귀하의 VIP 고객 세그먼트 | 활성 VIP 고객 세그먼트 |
| **고객 가치가 높은 고객** | 귀하의 VIP 및 높은 가치를 가진 고객 세그먼트 | 활성 VIP 또는 높은 가치를 가진 고객 세그먼트 |
| **반복 구매자** | 귀하의 자주 구매하는 고객 및 정기 고객 세그먼트 | 활성 자주 구매하는 고객 또는 정기 고객 세그먼트 |
| **신규 고객** | 귀하의 신규 고객 세그먼트 | 활성 신규 고객 세그먼트 |
| **이탈한 고객** | 이전에 주문을 했지만 최근 90일 이내에 주문이 없는 고객 | 어떤 고객이든 주문 기록 |
| **충성 고객** | 귀하의 충성 프로그램에 참여한 모든 사람 | 활성 충성 프로그램이 있는 회원 |
| **상위 충성 레벨** | 귀하의 최상위 레벨 충성 고객 | 최소 하나 이상의 활성 충성 레벨 |
| **제휴사** | 귀하의 활성 제휴 파트너 | 최소 하나의 제휴 |

Spwig은 실제로 데이터가 있는 스타터만 생성합니다. 예를 들어, 아직 충성 프로그램이 없는 가게는 "충성 고객" 스타터를 가지지 않으며, 아무것도 일치하지 않는 빈 스타터를 가지지 않습니다. Spwig은 추가한 항목을 정확히 확인할 수 있으며, 예를 들어 "7개의 스타터 대상이 추가되었습니다: 고가치 고객, 반복 구매자, 신규 고객, 이탈한 고객, 충성 고객, 상위 충성 레벨, 제휴사"라고 표시합니다.

![추가된 스타터 대상 확인을 위한 성공 메시지](/static/core/admin/img/help/audiences/starter-audiences-added.webp)

"스타터 대상 추가"를 여러 번 클릭하는 것은 안전합니다. Spwig은 이미 존재하는 스타터를 중복해서 생성하지 않으므로, 첫 번째로 충성 프로그램을 설정한 후 다시 클릭하면 새로 제공되는 항목만 추가됩니다. 모든 것이 이미 설정되어 있다면 그에 대해 알립니다.

![모든 스타터 대상이 이미 존재하는 경우 표시되는 정보 메시지](/static/core/admin/img/help/audiences/starter-audiences-already-set-up.webp)

시작 대상에서 제거한 항목을 삭제하면, 다시 **시작 대상 추가**를 클릭하더라도 다시 나타나지 않습니다. Spwig은 이 항목을 의도적으로 제거한 세그먼트로 간주하며, 다시 생성할 세그먼트는 아닙니다.

시작 대상이 생성되면 일반적인 동적 세그먼트가 됩니다. 이 세그먼트를 목록에서 열어 규칙을 검토하거나 수정하고, 이름을 바꾸거나, 삭제할 수 있습니다. 이는 자신이 만든 다른 세그먼트와 동일하게 수행할 수 있습니다.

## 실제로 이 대상이 누가 되는지

위의 고객, 충성 고객, 대리점 조건은 이메일이 고객 계정과 연결된 구독자만 일치합니다. 익명의 뉴스레터 가입은 **충성 고객** 또는 **VIP** 조건과 일치하지 않습니다. Spwig에는 주문 내역이나 충성 고객 데이터가 없기 때문에, 이에 대해 확인할 수 없습니다. 고객들이 계정을 가지고 있지만 아직 구독하지 않은 경우가 많다면, Spwig 설치를 관리하는 사람이 구독자 동기화를 실행하도록 요청해야 합니다. 이 작업은 한 번에 모든 기존 고객 계정에 대해 구독자 기록을 생성하여, 이 세그먼트가 실제 사람과 일치할 수 있도록 합니다.

세그먼트에 포함된 구독자 수가 몇 명이든, 이 숫자는 *전송될 수 있는* 사람을 나타내며, 실제로 전송되는 사람을 나타내는 것은 아닙니다. 여전히 모든 전송 시 구독자의 마케팅 동의 여부를 확인합니다. 따라서 세그먼트는 이에 대한 방법이 될 수 없습니다.

## 팁

- 손으로 같은 규칙을 만드는 대신 시작 대상에서 조정하세요. 생성된 시작 대상은 자신이 만든 다른 세그먼트와 차이가 없습니다.
- **충성 고객**, **대리점**, **주문이 있음**과 같은 부울 조건은 연산자나 값을 입력할 필요가 없습니다. 조건을 추가하면 끝입니다.
- 최신 필드를 원래 필드와 결합하여 더 정밀하게 타겟팅하세요. 예를 들어 **충성 고객**과 **마케팅에 동의함**을 결합하고, 단일 조건에만 의존하지 마세요.
- 세그먼트의 규칙이 이미 제거된 항목을 참조하고 있다면(예: 삭제된 고객 세그먼트, 비워진 태그 등), Spwig은 이를 아무도 일치하지 않는 것으로 간주하며, 전체 구독자 목록으로 돌아가지 않습니다.

잘못된 타겟팅으로 인해 전체가 실수로 전송되지 않도록 주의하세요.
- 세그먼트의 멤버 수가 오래된 것으로 보인다면, 다시 열고 저장하거나, 세그먼트 목록에서 **멤버 수 재구성**을 사용하여 즉시 재계산할 수 있습니다.
- 규칙을 만들면서 실시간으로 "일치하는 구독자" 수를 확인하세요 — 이는 저장하기 전에 의도한 것보다 좁거나 넓은 조건을 빠르게 확인할 수 있는 방법입니다.
