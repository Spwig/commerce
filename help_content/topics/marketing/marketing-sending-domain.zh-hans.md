# 营销发送域名

您的商店会发送两种非常不同的电子邮件：

- **交易类** —— 订单确认、发货更新、密码重置。这些邮件必须始终到达收件箱。
- **营销类** —— 新闻简报、促销活动、购物车恢复、库存补充通知。

默认情况下，两者都使用相同的发送身份，这意味着它们**共享一个发件人声誉**。如果营销活动引发垃圾邮件投诉或发送到无效地址，该声誉会下降——并且您的订单确认和密码重置也可能开始进入垃圾邮件。

**营销发送域名** 可以解决这个问题。您设置一个第二个发送身份——使用其自己的子域名，例如 `news.yourstore.com`——并将其标记为营销。然后 Spwig 会从该身份发送每个活动，并将交易邮件保留在您的主域名上。一个糟糕的活动不能再拖累您客户*需要*接收的邮件。

> 适用于自托管商店。在 Spwig 托管计划中，发送声誉会自动为您管理。

## Spwig 如何决定使用哪个身份

一旦存在营销发送账户，路由会自动进行——您无需进行任何标记：

- **营销邮件**（活动、旅程、新闻简报、购物车恢复、库存补充）→ 营销发送域名。
- **交易邮件**（订单、发货、密码重置、验证）→ 您的主域名。

如果您从未设置营销域名，一切保持不变：所有内容仍会从您的默认账户发送，与之前完全相同。

## 设置它

您可以从任一入口开始：

- Campaign Studio 仪表板横幅上的 **"设置营销域名"** 按钮，或者
- **电子邮件账户 → "营销发送域名"**。

![Campaign Studio 仪表板，带有 "保护您的交易邮件" 横幅及其设置营销域名按钮](/static/core/admin/img/help/marketing-sending-domain/marketing-domain-nudge.webp)

![电子邮件账户列表中的营销发送域按钮，位于“浏览提供商”旁边](/static/core/admin/img/help/marketing-sending-domain/marketing-domain-button.webp)

两者都会打开电子邮件设置向导，并预先标记为营销账户。然后：

1. **选择一个子域。** 使用类似 `news.yourstore.com` 或
   `mail.yourstore.com` 的名称。这是最重要的一步：营销身份必须是一个
   **不同的（子）域**，与您用于事务性电子邮件的域不同——这种隔离
   正是保护您事务性声誉的关键。从您的主域发送营销邮件无法提供隔离。
2. **输入该子域上的发件人地址**，例如 `news@news.yourstore.com`。
3. **添加 DNS 记录。** 向导会为子域生成 SPF、DKIM 和 DMARC 记录
   ——包括一个专属于此营销身份的 DKIM 密钥。在您的 DNS 提供商处添加它们
   （向导提供复制按钮和按提供商划分的选项卡），然后运行
   检查，直到所有记录通过。
4. **完成。** 账户已创建并标记为 **仅限营销**。从现在开始，您的
   营销活动将从该账户发送。

您可以在 **电子邮件账户** 列表中确认其是否正常工作：您会看到一个第二个账户，
其用途为 **仅限营销**，并且 Campaign Studio 横幅将消失。

## 须知

- **您不会意外破坏事务性电子邮件。** Spwig 不允许您将唯一的
  账户设置为“仅限营销”，也不允许您禁用/删除最后一个事务性账户——
  订单确认和密码重置始终有地方可去。
- **逐步预热。** 全新的发送域尚没有声誉。

在几周内逐步增加您的
  发送量，而不是在第一天就向整个列表发送大量邮件。
- **保持子域的 DNS 健康。** 营销子域上的 SPF、DKIM 和 DMARC
  需要保持有效，就像您的主域一样。

查看[邮件可 deliverability 运行手册](deliverability)以获取完整信息。
- **仍然需要同意。** 营销邮件仅发送给已订阅的用户，
  每个活动都包含退订链接 —— 分离域名不会改变这一切。
