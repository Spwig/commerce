## 產品目錄

- **預訂產品** — 商家銷售預約、租賃和活動，具備可用性規則、動態定價、定金、候補清單、重新排程、取消功能，以及 iCal 日曆輸出。
- **自定義設計定價與結帳** — 配置的設計根據表面、上傳、剪貼畫和文字進行定價，作為時間限制的購物車草稿保存，驗證在購物車中，結帳時凍結到訂單中。
- **自定義欄位驗證** — 輸入的值會根據每個欄位的類型、是否必填、範圍、選項和格式進行檢查，並提供每個欄位的錯誤報告。
- **自定義欄位** — 您可以將自定義的類型欄位新增到產品、分類、訂單和客戶，並進行分組和排序。
- **設計模板** — 工作人員可以建立和管理產品的預設畫布模板，並鎖定個別元素以引導客戶編輯。
- **欄位資料輸入與 storefront 顯示** — 工作人員在記錄上輸入自定義欄位值，並在 storefront 上顯示分組值，套用選擇的標籤和預設值。
- **欄位回存籃與還原** — 刪除的欄位和分組會移至回存籃，其中儲存的資料會保留以供還原，或可永久刪除。
- **禮品卡** — 商家發行資金禮品卡，並在結帳時接受作為付款，追蹤餘額、暫扣、扣款和退款。
- **授權金鑰管理** — 商家自動產生授權金鑰，強制裝置啟動限制，本地或透過外部供應商驗證授權，並通知整合的生命周期事件。
- **多表面產品設定** — 工作人員定義每個產品的設計表面，包括尺寸、區域、列印/DPI 設定、樣板，以及每個表面允許的文字、上傳和剪貼畫。
- **多倉庫庫存** — 商家追蹤跨倉庫的庫存，包括分配、 shipment 配送、可用性檢查、調整，以及不可變更的移動審計追蹤。
- **列印準備完成檔案** — 結帳後，根據目標 DPI 將訂單設計組合到列印準備圖像檔案中以供生產。
- **產品設計編輯器** — 客戶可以在即時畫布上自定義產品，使用文字、上傳圖片、剪貼畫和自定義字型，但需符合每個表面的限制。
- **產品購買需求** — 商家根據客戶已擁有或購物車中的必要前置產品來門檻購買，強制兼容性和升級路徑。
- **客戶保存的設計** — 已登入的客戶可以保存、重新載入和刪除他們自己的命名產品設計，跨會話。
- **庫存保留** — 暫時的購物車級別庫存保留可防止從加入購物車到結帳時過度銷售，然後轉換為訂單分配或 POS 配送。

## 3D 產品組裝器

- **3D 產品模型設定** — 將 3D 模型附加到可組裝產品，並儲存其解析的場景結構以供組裝。
- **互動式 3D 與 AR 查看器** — 向 shoppers 展示互動式 3D/AR 產品查看器，具備可配置的相機、照明和已儲存場景縮略圖。
- **材質與材質資料庫** — 上傳和管理可套用到模型的材質圖片資源。
- **可視配置選項** — 將產品配置選項連結到3D模型上的可視變更：材質顏色、零件可見性和可交換幾何形狀。

## 購物車與結帳

- **預訂結帳** — 在結帳時，預訂購物車項目會轉換為帶有排程、資源和人員細節的已確認預訂記錄。
- **結帳與下單** — 顧客設置地址，選擇合資格的付款方式，並在即時重新計算總金額後下達已驗證的訂單，轉換為倉儲分配的訂單。
- **空購物車推薦** — 空購物車會顯示從最近瀏覽過的、相關的、促銷中的、熱門的和特色產品中精選的庫存商品建議。
- **禮品卡與錢包支付** — 買家可以通過授權保留來使用禮品卡餘額或商店錢包信用額，可以釋放的授權保留，由提單完全覆蓋的提單在結帳時不會產生網關費用。
- **訪客結帳** — 匿名購物者可以在不註冊帳戶的情況下完成購買，包括跳過運費的數位商品購物車。
- **訪客結帳** — 購物者可以在不註冊帳戶的情況下購買，或在結帳時創建帳戶，每個匿名瀏覽器只能打開自己的訂單確認。
- **引導式結帳** — 買家通過基於會話的結帳流程，捕獲聯繫資訊和地址，保持總金額即時，並在下單前驗證準備狀態。
- **付款方式選擇** — 買家只會看到其國家、貨幣和金額的活躍且合資格的付款提供者，所選的提供者會套用到結帳。
- **會話與用戶購物車** — 購物者在匿名和登錄會話中保持一個持久的購物車，匿名購物車在登錄時會合併到其帳戶中。
- **運費計算** — 可用的運送方式會根據區域和購物車資格過濾，透過運送規則和促銷來定價，並在結帳時可選擇。
- **運送選擇** — 買家會看到其目的地的合資格運送方式，包含規則調整的費用和自取選項，所選方式的費用和運送預估會套用。
- **庫存保留** — 新增項目會保留其庫存直到結帳，並在移除或清除時釋放，防止過度銷售。
- **訂閱結帳** — 訂閱購物車項目會在訂單建立時使用儲存的付款令牌轉換為其計畫和定價等級的重複訂閱。
- **稅金計算** — 稅金根據地理地址的具體性和產品資格計算，並有可重用的名稱稅收預設。
- **優惠券套用** — 顧客可以在結帳時套用和移除折扣代碼，並強制執行currency、最低訂單、每客戶、組合規則。
- **優惠券兌換** — 套用的折扣代碼會被鎖定，並在訂單時間重新驗證上限和有效性，使用次數會原子性計數，如果超過限制會回滾訂單。
- **願望清單** — 顧客可以將項目保存到願望清單中並添加備註、優先級和缺貨/促銷通知，並透過公開URL分享願望清單。

## 付款

- **3DS / 強客戶認證** — 將信用卡付款路由到提供者的3DS/SCA第二次認證步驟，並在客戶完成認證後完成結算。
- **結帳付款處理** — 針對結帳訂單建立付款，確認付款，成功時標記為已支付或失敗以供重試，並在放棄時取消並釋放庫存。
- **客戶錢包歷史** — 客戶可以從其帳戶頁面和API查看其錢包餘額和完整的最新交易明細，可過濾類型、來源和狀態。
- **不可變錢包明細與對賬** — 每一個錢包交易都會記錄在防篡改明細中，貨幣不匹配的交易會被拒絕，並根據明細對賬以檢測偏差。
- **結帳時使用錢包支付** — 客戶可以在結帳會話中使用其錢包餘額，保留會在付款時捕獲，取消時釋放，若放棄則過期。
- **支付分析** — 查看聚合支付和供应商性能、随时间的收入、交易状态、方法分布、覆盖范围、网络钩子统计信息和退款指标。
- **支付提供者與連接** — 從加密憑證安裝支付提供者，驗證連接，將其結帳 SDK 掛載到商店前端，並在前端 SDK 載入失敗時發送電子郵件通知。
- **按國家支付方式** — 同步提供者在每個國家提供的支付方式，按國家或全球啟用或停用，並在結帳時僅顯示合資格的提供者。
- **商店信用錢包** — 每位顧客在商店的預設貨幣中有一個錢包，可以增加和減少餘額，顯示可使用的餘額。
- **交易生命週期與退款** — 追蹤每個支付從結算到部分或全額退款，具有冪等性檢查，訂單取消，以及在捕獲前聲明無效授權步驟。
- **錢包管理** — 管理員可以搜尋和檢查顧客錢包和交易，凍結錢包以阻止所有信用、借記和保留活動。
- **錢包退款與逆轉** — 商家可以將錢包支付的全部或部分金額退還給顧客餘額，並逆轉合資格信用，並執行每筆捕獲的限制。
- **網絡鉤子驗證與狀態同步** — 使用簽名驗證和去重處理提供者網絡鉤子，重放存儲的未處理事件，並輪詢提供者以在狀態分歧時同步本地支付狀態。

## 訂單與退貨

- **多幣別訂單** — 每個訂單使用購買時鎖定的匯率存儲顧客幣別和基礎幣別金額。
- **一鍵重新下單** — 顧客從過去的訂單重建購物車，重新檢查當前的可用性和庫存，跳過不再銷售的商品。
- **訂單生命週期與追蹤** — 商家將訂單移動到已驗證的狀態，取消合資格訂單，並提供客戶即時追蹤與履行里程碑。
- **訂單統計與熱門商品** — 顧客可以查看其訂單歷史和支出摘要，而付費訂單會提供準確的每個商品銷售次數。
- **退款流程** — 商家可以發起全額或部分退款，根據支付方式優先級退回所有捕獲金額，並完整追蹤狀態。
- **退貨與RMA** — 顧客在交付訂單後請求退貨，商家批准、標籤、追蹤、檢查並端到端關閉退貨。
- **版本化地址** — 顧客管理可重複使用的運費和賬單地址；編輯會產生新版本，使過去訂單保留原始地址。

## 運輸與履行

- **運送商整合** — 連接運送商帳戶以取得即時運費報價、購買標籤和測試連接。
- **店內取貨** — 提供店內取貨服務，檢查營業時間和準備時間，並預訂30分鐘時段。
- **本地配送範圍** — 檢查目的地是否在您自己的配送車隊的配送範圍內。
- **多倉庫履行** — 根據目的地國家解析運輸來源倉庫，使用優先級故障切換鏈。
- **費率表** — 根據購物車重量、價格或商品數量，按區域範圍查詢分層表中的運費。
- **退貨標籤（RMA）** — 生成包含RMA編號和退貨地址的PDF退貨標籤。
- **運輸追蹤** — 接收運送商網絡鉤子並輪詢提供者以更新運輸狀態和追蹤事件。
- **運輸文件** — 生成紙箱清單、商業發票和CN22/CN23海關文件的PDF。
- **運費規則與促銷** — 計算購物車運費並透過條件式免運費、折扣或附加費促銷來修改它。
- **運費區域** — 根據國家、州/省或郵遞區號模式定義地理區域，以控制運費適用範圍。

## 銷售點

- **信用卡讀取器整合** — 發現、指派並監控每個終端機的信用卡讀取器，並向裝置推送品牌 splash 畫面。
- **購物車建立與顧客查詢** — 瀏覽目錄，透過條碼/SKU加入商品，套用促銷兌換券，並附加或建立來店顧客。
- **結帳與分批付款** — 跨現金、信用卡、終端機信用卡、禮品卡及分批付款完成銷售，並記錄付款。
- **顧客顯示介面** — 使用旋轉配對碼將第二台顧客顯示裝置與終端機配對。
- **顧客顯示介面** — 配對第二台螢幕，顯示即時購物車與付款狀態，加上店內範圍的促銷投影片。
- **數位收據** — 透過電子郵件、簡訊或 WhatsApp 發送訂單收據給顧客。
- **整合式信用卡讀取器付款** — 透過整合式信用卡讀取器建立、捕獲及取消付款意圖來進行信用卡付款。
- **庫存控制** — 查看各個地點的庫存與變動，並調整倉庫庫存以處理入貨、損壞、重新盤點與退貨。
- **櫃檯忠誠度** — 在銷售前預覽忠誠度點數與獎勵，並在完成訂單後授予已獲得的點數。
- **離線模式與同步** — 在離線狀態下排程銷售與庫存調整，並重放它們以確保一致性，同時取得資料變更以保持終端機同步。
- **暫存購物車** — 保存中途交易的購物車，列出暫存購物車，稍後還原一個來服務多個顧客。
- **暫存購物車** — 保存中途交易的購物車，稍後還原它，並在過期後自動清除暫存購物車。
- **收據與數位交付** — 套用店內範圍的收據模板，並透過電子郵件、簡訊、WhatsApp 或公開收據連結發送收據。
- **退款與作廢** — 全額或部分退款 POS 訂單，並在同一班次內作廢訂單，自動反轉班次總額。
- **銷售報表** — 查看每日 POS 銷售總額與熱門商品指標。
- **班次與現金管理** — 以開班浮動金額、現金存入/提領變動與運行總額來開啟與關閉班次。
- **班次管理** — 以現金存入/提領變動與預期金額與實際金額對帳來開啟與關閉櫃員班次。
- **員工折扣控制** — 在員工限額內手動套用每筆或整張購物車折扣，並允許經理使用 PIN 碼覆蓋超過限額的金額。
- **員工折扣控制** — 強制執行每員工折扣限額，並要求經理使用 PIN 碼批准超過限額的折扣。
- **員工登入與生物特徵終端機解鎖** — 透過 WebAuthn 生物特徵、PIN 碼或員工卡進行員工登入與終端機解鎖，並有鎖定審計。
- **終端機鎖定與解鎖** — 透過櫃員/經理 PIN 碼、員工卡、生物特徵或遠端管理來鎖定與解鎖終端機，並有完整的審計日誌與鎖定規則。
- **終端機管理** — 註冊與配對 POS 終端機，回傳其設定，並記錄心跳信號。
- **終端機設置與裝置配對** — 註冊POS終端機，發放配對代碼，並在上線前驗證支付服務器連接。

## 訂閱與重複

- **取消與重新啟用** — 立即或在週期結尾取消訂閱，記錄原因，按計畫過期，並在設定的視窗內重新啟用符合資格的取消訂閱。
- **失敗付款還原（催繳）** — 自動重試失敗的費用，於寬限期內重新嘗試付款，僅在還原嘗試耗盡後取消。
- **免費試用** — 提供試用期，試用結束時自動轉為付費訂閱。
- **生命週期提醒電子郵件** — 發送自動電子郵件提醒試用即將結束、即將到來的續訂，以及與訂閱活動相關的付款事件。
- **暫停與恢復** — 訂閱者可以手動或在設定的自動恢復日期暫停活躍的訂閱，並在後續恢復。
- **重複計費引擎** — 在每個計費週期向訂閱者計費，並處理服務器webhook和備用事件，以保持訂閱狀態和週期同步。
- **儲存付款方式** — 安全地將客戶付款方式轉換為令牌，更新訂閱中的卡，並在沒有活躍訂閱依賴時刪除令牌。
- **訂閱方案與定價** — 發佈訂閱方案和等級，具有由產品衍生的重複定價、等級折扣和數量定價，客戶可以瀏覽並訂閱。
- **升級、降級與計畫變更** — 讓訂閱者切換方案或等級，按比例計費或退款，可立即或安排在下次續訂時變更，並有取消待處理變更的選項。

## 客戶分析

- **放棄購物車還原** — 檢測放棄的購物車，發送階段還原電子郵件，並標記購物車為已還原。
- **群組分析** — 按取得時間分組客戶，並追蹤每個群組的保留率、累積收入和平均LTV隨時間的變化。
- **通訊偏好與同意** — 客戶可以控制收到的電子郵件和簡訊，具備驗證的雙重選擇加入和一鍵退訂，而交易訊息仍受保護。
- **客戶帳戶與來賓結帳** — 購物者可以以來賓身分購買，之後升級為完整帳戶，重複的電子郵件記錄會自動合併。
- **客戶分析** — 聚合跨客戶分析，包括按群組的收入、流失風險分佈和群組保留率。
- **客戶備註** — 讓工作人員輸入客戶備註，並設定後續要求，標記為已完成。
- **客戶節省追蹤** — 總結客戶的已實現折扣、銷售和忠誠度節省，並估算未來可能的節省。
- **客戶分群** — 根據消費金額、訂單數量和購買時間，將每個客戶分配到最高優先級的匹配群組。
- **終身價值（LTV）** — 使用RFM、群組歷史和機率（BG/NBD）方法估算每位客戶的終身價值，並有價值等級和流失風險。
- **忠誠度狀態** — 根據消費金額推導出客戶的忠誠度等級、點數、進度到下一個等級，以及等級好處。
- **同意洞察與預設建議** — 商家可以看到同意採用趨勢，並獲得基於規則的參與分數，建議每位客戶的適當訊息頻率。
- **隱私與資料權利（GDPR）** — 商家可以匯出或不可逆地刪除客戶的資料，並保留每筆偏好變更的不可變 audit trail，並有保留限制。
- **產品推薦** — 排序客戶最喜愛的產品、類別和品牌，並產生庫存中的個人化推薦。
- **RFM 評分** — 根據已送貨訂單歷史，對每位客戶進行回購頻率、最近購買時間和金額價值的評分。
- **社會登入** — 在商店的 OAuth 應用程式設定完成後，客戶可以使用 Google、Apple 等提供者進行登入。

## 營銷與成長

- **成就徽章** — 成員在達成訂單數量、消費金額、連續訂單、時間或推薦條件時會自動獲得徽章。
- **合作夥伴通知與報表** — 合作夥伴會收到語言對應的電子郵件，通知帳戶、會員、佣金與付款事件，並附上每月績效摘要。
- **合作夥伴付款** — 透過 PayPal 或 Airwallex 發送單筆或批量合作夥伴佣金付款，包含費用/到帳預估與進行中的取消功能。
- **合作夥伴計畫** — 建立並運行多個合作夥伴計畫，設定百分比或固定佣金、Cookie 有效期限、最低付款門檻，並啟用、暫停或歸檔計畫。
- **合作夥伴招募與審核** — 註冊合作夥伴，讓他們申請計畫，並審核、暫停、拒絕或自動批准其帳戶與會員資格。
- **自動與批量 SEO 填充** — 儲存時自動填入遺漏的 SEO 元資料，或一次批次產生多個專案的 SEO 元資料。
- **自動feeds同步** — feeds 會根據小時、日或週排程重新產生並上傳至提供者，包含同步日誌與過期 feeds 清理。
- **批量禮券產生與匯入/匯出** — 一次產生最多 1,000 個唯一代碼，並以 CSV/XLSX 格式匯入或匯出禮券批次。
- **佣金與付款** — 批准、拒絕或反向合作夥伴佣金，並透過基於門檻或合作夥伴請求的付款方式透過 PayPal 或 Airwallex 支付合作夥伴，並追蹤完整狀態。
- **Feed 渠道連線** — 使用加密憑證連線與管理市場平台提供者帳戶、連線測試、啟用/停用，以及指定主要帳戶。
- **Feed 提供者元件** — 從元件註冊表安裝與更新市場平台 feed 提供者元件。
- **禮品卡與儲值** — 發行以禮券為背書的禮品卡，查詢餘額，並用於訂單兌換，直到餘額用完。
- **連結追蹤與歸因** — 合作夥伴產生獨特追蹤連結，點擊會被記錄並透過最後點擊 Cookie 歸因至訂單，並自動清理過期點擊資料。
- **忠誠度活動** — 商家執行觸發式與排程的多步驟活動，獎勵點數、傳送電子郵件、發放獎勵、頒發徽章，或將成員移動至不同群組。
- **忠誠點數** — 客戶在訂單、行動或手動獎勵中獲得點數，根據不可變的會計分錄，保持準確且可對帳的餘額。
- **忠誠等級** — 成員根據終身點數、消費金額與訂單數量在等級間晉升或降級，降級前有冷卻期。
- **市場平台產品 feeds** — 以 RSS/XML、CSV/TSV 或 JSON 格式產生 Google Shopping、Meta 等市場平台的產品 feeds，包含預覽與可下載匯出。
- **成員群組** — 成員被分組至手動或基於規則的群組（依點數、消費、訂單、回購頻率等）以進行活動目標設定。
- **付款提供者帳戶** — 連線、測試、啟用/停用、刪除，並為每個付款提供者（PayPal、Airwallex）設定預設帳戶。
- **付款提供者元件** — 從更新伺服器安裝與更新付款提供者元件套件，支援版本切換。
- **付款狀態與 Webhooks** — 接收與驗證提供者 webhooks 的簽章，日誌記錄以供稽核，並追蹤每筆付款至完成、失敗或取消狀態。
- **提供者憑證保護** — 提供者憑證會在靜態時加密，並在日誌中遮蔽。
- **推薦歸屬與審核** — 推薦客戶的首次送達訂單會歸屬於推薦人，每次歸屬可被審核通過、駁回或在審核期後自動過期。
- **推薦詐欺檢測** — 透過合資格規則和0-100分的詐欺風險分數來篩選推薦，高風險的歸屬會重新篩選並自動駁回以阻止濫用。
- **推薦漏斗分析** — 商家可看到推薦漏斗總數、轉化率、獎勵金額、頂級推薦人及每位推薦人的統計資料，並根據保留週期刪除舊的低價值事件。
- **推薦連結與邀請** — 每位客戶可獲得獨有的推薦連結與QR碼，可分享，並可直接透過電郵發送邀請給朋友。
- **推薦獎勵** — 推薦人及雙向計畫中的被推薦人可獲得錢包信用額、優惠券或好處，這些獎勵會在其生命週期內自動發放、兌換、過期或撤回。
- **獎勵與兌換** — 會員可兌換點數以獲得獎勵或折扣，包含庫存檢查、安全代碼、履行追蹤，以及取消或過期時的點數退款。
- **SEO內容產生器** — 為產品、分類、品牌、頁面和部落格文章產生meta標題、描述和關鍵字。
- **SEO覆蓋率與缺口** — 查看每種類型和整體的SEO完整性，並列出哪些項目缺失或長度有問題。
- **SEO供應商整合** — 連接、安裝和更新SEO供應商，每個網站強制使用一個主要供應商帳戶。
- **分享事件追蹤** — 每位已登入客戶或訪客的每次分享都會被驗證並記錄，包含平台、裝置和會話細節。
- **分享獎勵與歷史** — 已登入客戶可透過分享獲得忠誠度徽章，並可查看自己按平台分類的分享歷史和總數。
- **分享分析儀錶板** — 員工可審閱分享總數、趨勢、平台分佈、頂級內容和頂級分享者，並可搜尋和過濾個別分享事件。
- **社交證明分享次數** — storefront 頁面可顯示每個產品或內容項目的即時平台分佈和總分享次數。
- **storefront 分享按鈕** — 客戶可透過可設定的分享按鈕分享產品、分類、部落格文章和頁面，商家可根據內容類型切換每個類型的分享按鈕。
- **優惠券套用** — 客戶可在結帳時套用和移除折扣代碼，並強制執行合資格規則、堆疊規則和最低金額規則。
- **優惠券使用報表** — 可查看每張優惠券的使用次數、獨家客戶數、總折扣和平均折扣，以及最近的兌換紀錄。
- **優惠券與折扣碼** — 建立百分比、固定金額或禮品卡折扣碼，並設定使用規則和限制。

## 電郵與通訊

- **AI模板翻譯** — 模板會自動翻譯成多種語言，並有手動驗證/駁回步驟以進行品質控制。
- **DNS與投遞設定** — 所有者驗證SPF/DKIM/DMARC跨解析器，取得建議的DNS記錄，DKIM簽署出站郵件，並追蹤驗證歷史。
- **電郵佇列與投遞** — 電郵會根據客戶偏好排入佇列，透過帳戶提供者傳送，排程後送，並在被擱置時重新嘗試或釋放。
- **電郵模板資料庫** — 店家可啟用、複製和渲染品牌交易電郵模板，始終有系統預設模板。
- **通訊與新聞通訊** — 所有者可傳送由員工管理的新letter模板至已解決的收件人清單，作為個別佇列電郵。
- **開啟與點選追蹤** — 所有者可查看電郵何時被開啟以及哪些連結被點選，並處理安全重導向，並有空間處理供應商的退件/投訴事件。
- **發送帳戶設定** — 所有者可透過加密憑證連接郵件供應商，測試連接，並在上線前產生DKIM金鑰。
- **SMS 同意與安全傳送** — 跳過已透過訊息類型放棄的客戶訊息，並在沙盒模式下阻止傳送至未白名單的號碼。
- **SMS 通訊** — 透過設定好的 SMS 供應商傳送純文字或基於範本的簡訊給客戶，並追蹤每則訊息的傳送/送達狀態。
- **SMS 供應商組件** — 從組件市場安裝和更新 SMS 供應商整合，啟用所選版本。
- **SMS 供應商設定** — 以驗證過的加密憑證新增和設定 SMS/WhatsApp 供應商帳戶，進行連線測試，並為每個通路設定預設帳戶。
- **範本版本控制** — 每次編輯範本都會建立快照，讓管理員可以檢視歷程並還原至任何先前版本。
- **WhatsApp 通訊** — 傳送已核准的參數化 WhatsApp 範本訊息，並追蹤寄件箱中的結果。

## 部落格與內容

- **公告匯入與匯出** — 以顯示設定、到期日、圖片、翻譯和連結目標來匯出公告，並匯入至其他商店，根據標題更新或刪除。
- **公告浮層** — 開啟公告的浮層，顯示完整內文、橫幅或背景圖片與浮疊，解決的行動呼籲連結，並透過按鈕、浮疊或 Escape 鍵關閉。
- **部落格文章與內容模式** — 以豐富文字或頁面編輯器建立、編輯、發佈和取消發佈部落格文章。
- **分類與標籤** — 以層級分類和平坦標籤組織文章，讓讀者可以瀏覽。
- **電子郵件訂閱者** — 讀者以雙重選擇加入，根據偏好接收新文章、每週或每月摘要電子郵件。
- **多語言公告** — 使用儲存的語言特定翻譯，以 shopper 的語言顯示公告標題、內文和連結文字。
- **讀者參與度** — 顯示預估閱讀時間和相關文章，並追蹤每篇文章的瀏覽次數。
- **RSS 資料提要** — 發佈可設定的最近文章 RSS 資料提要，包含摘要或完整內容和特色圖片附件。
- **排程發佈** — 設定文章的未來日期和時間，並自動發佈。
- **社交自動分享** — 連接社交帳戶並在發佈時自動分享文章，支援權杖更新和失敗分享的重試。
- **商店公告** — 以排程方式顯示優先順序的公告給 shopper，自動隱藏到期後，每個公告連結至產品、分類、部落格文章、頁面或自訂 URL。

## 設計與商店外觀

- **4 級別的權杖階層** — 設計權杖以固定優先順序（品牌、主題、元件、系統）解析，以確保覆蓋層保持預測。
- **自動表單動作** — 每個提交可以觸發自動回覆電子郵件、通知電子郵件給你的團隊，以及簽入的 webhook 送到外部系統。
- **品牌自訂** — 在不寫程式碼的情況下變更顏色、字型、間距和元件權杖，並在發佈前預覽結果。
- **條件邏輯** — 規則根據訪客輸入的內容顯示、隱藏、要求或預設欄位和步驟。
- **自訂 CSS** — 注入已命名的 CSS 片段，在它到達商店外觀前移除危險規則。
- **深色模式** — 主題產生深色模式 CSS，包含響應式變體，以回應訪客的系統偏好。
- **表單建立工具** — 工作人員可使用可重新排序的欄位和一鍵複製功能，在視覺化建立工具中建立和編輯多步驟表單。

- **頁首與頁尾建立工具** — 使用主題預設值和小工具組裝頁首和頁尾區域，並預覽每個小工具在頁面中的顯示效果。
- **頁面安全層** — 頁面層級控制哪些元件和令牌自定義可在敏感頁面中使用。
- **回應匯出** — 以 CSV 格式下載已完成的回應，包含提交的元資料和每個欄位的值。
- **垃圾訊息防護** — 蜜罐欄位可在瀏覽器中阻止機器人提交；reCAPTCHA 設定可調整，但尚未在伺服器端強制執行。
- **提交與檔案上傳** — 訪客可提交包含驗證過的必要欄位和檔案附件的表單，並可儲存部分草稿以稍後完成。
- **主題開發工具** — 在隔離的開發會話中建立主題，使用主題 SDK 階段檔案，並即時編譯和驗證 CSS。
- **主題系統** — 從市場中安裝、啟用和更新主題套件，自動套用內建的預設值和令牌。
- **受信任元件** — 市場元件在渲染前會經過驗證、簽名和完整性檢查，以檢測是否被篡改。

## 頁面建立工具

- **自訂元件建立工具** — 工作人員可以從管理員建立工具中建立、命名、列出、搜尋、編輯和刪除重複使用的自訂元件。
- **草稿、發佈與版本歷史** — 頁面會儲存為編號的草稿，發佈時追蹤歷史，並可還原到任何先前的快照。
- **動態資料繫結** — 將元件內容欄位繫結到即時模型資料，使元件在 storefront 中顯示真實的產品和記錄值。
- **元件可見性規則** — 根據地理、使用者、裝置、時間、行為和商務條件組合的巢狀 AND/OR 规則群組，顯示或隱藏頁面元件。
- **多語言頁面** — 根據語言翻譯頁面和元件內容，透過 AI 或手動輸入，並保留原始文字作為預設。
- **頁面設定與 SEO** — 設定每頁的元資料、認證需求、頁首/頁尾和設計設定。
- **頁面範本與複製** — 從重複使用的範本建立新草稿頁面，或複製現有頁面及其巢狀元件。
- **視覺化元件編輯器** — 透過新增、移動、編輯和刪除巢狀元件，使用多欄布局預設值和即時畫布預覽來建立元件的結構。
- **視覺化頁面建立工具** — 工作人員可從巢狀、可重新排序的元件建立商店頁面，並自動產生預覽縮圖。

- **多媒體資料庫組織** — 將資源分類到資料夾和標籤中，搜尋和編輯它們，一次動作批量更新，並查看每個資源的使用情況。
- **回復桶與還原** — 軟刪除的資源會移至回復桶，工作人員可以還原或永久刪除。
- **安全上傳** — 上傳圖片、影片和 3D 檔案，會自動進行安全性檢查，並檢測其尺寸、格式和元資料。
- **視訊與3D媒體傳遞** — 上傳的視訊會轉碼為網頁格式，並帶有略圖畫面，支援尋找功能串流。

## 搜尋與發現

- **拼寫修正** — 拼寫錯誤的查詢會從目錄詞彙和常見過去看搜尋中獲得建議修正。
- **文件與數位資產搜尋** — PDF、DOCX、XLSX 和純文字檔中的文字會被索引並可搜尋，並顯示匹配片段。
- **預測自動完成** — 當購物者輸入時，會看到快速分組建議，根據內容類型並立即重導向已知詞彙。
- **搜尋分析** — 商家可追蹤查詢量、無結果率、點選率、熱門詞彙和回應時間，並可匯出 CSV。
- **搜尋重導向** — 商家可以使用精確、包含、前綴或正則表達式規則，將特定查詢直接導向至所選頁面。
- **storefront 產品與內容搜尋** — 購物者可以透過語言感知、過濾、排序、分頁結果找到產品、分類、品牌和部落文章。
- **同義詞管理** — 商家可定義每種語言的雙向同義詞，並從無結果查詢中獲得建議的新增詞彙。

## 國際化

- **AI 內容翻譯** — 商家使用 AI 將產品、頁面和其他內容翻譯成活躍語言，並可鎖定欄位，控制作業重試/取消。
- **自動貨幣與語言** — 根據訪客所屬國家自動建議並儲存適當貨幣與語言，並可設定國家預設。
- **自動匯率更新** — 排程提供者支援的匯率取得，可選擇來源優先權，並清理過時快取匯率。
- **貨幣轉換** — 使用已解決的匯率在貨幣之間轉換金額，可選擇標記並對目標貨幣四捨五入。
- **兌換率提供者** — 連接、安裝、更新和管理外部貨幣率提供者，其中一個被指定為網站的主要來源。
- **外部翻譯提供者** — 商家使用加密憑證連接和測試第三方翻譯提供者帳戶。
- **地理商業規則** — 根據訪客國家、地區、行動裝置和 VPN 狀態觸發動作，例如設定貨幣、顯示橫幅或重導向。
- **GeoIP 提供者管理** — 讓工作人員從管理後台配置、測試、切換並檢查地理定位提供者的可用性。
- **GeoIP 訪客定位檢測** — 從 IP 解析每位訪客的國家、地區和城市，支援瀏覽器提示還原，機器人/裝置分類和手動修正。
- **鎖定訂單兌換率** — 每個訂單會記錄精確的解決率及其來源，因此歷史訂單會保留其原始轉換。
- **手動兌換率** — 設定、編輯、啟用、鎖定並批量管理自己的貨幣對率，優先於提供者率。
- **商店語言** — 商家可啟用、停用、排序並設定商店的預設語言。
- **商店介面文字自訂** — 商家可覆寫、自動翻譯、鎖定並匯入/匯出任何商店介面字串，依語言。
- **翻譯覆蓋率與進度** — 商家可查看每種語言翻譯內容的覆蓋率，並追蹤批量翻譯作業的進度，作業前後及進行中。
- **訪客與流量分析** — 追蹤頁面瀏覽和會話，然後報告儀表板 KPI、每日趨勢、會話旅程、活動歸因和國家/裝置分佈。
- **訪客資料保留** — 在可配置的保留窗口內自動清除舊的原始頁面瀏覽和過期的訪客記錄，同時保留聚合統計數據。

## 智能商務

- **代理身分驗證** — 每個代理請求在被信任前會根據取得的金鑰目錄進行密碼學簽名驗證。
- **代理信任與安全控制** — 商家可設定誰可以讀取或購買，封鎖或解除封鎖單獨代理，評估準備狀態，並立即終止所有代理存取權限。
- **智能結帳** — AI代理可以建立購物車，新增地址和運費，並代表買家完成付款結帳。
- **AI購物代理發現** — AI購物代理可以通過UCP、ACP和MCP端點發現、搜尋並讀取您的即時目錄。
- **簽署訂單命令** — 每個付費代理訂單都會獲得商家簽署的AP2命令，證明金額和明細項目，代理可隨時取得。
- **防篡改代理審計追蹤** — 每個代理事件會附加到HMAC連結的雜湊鏈，可重新驗證以證明未被修改。

## 企業與安全

- **管理員存取控制** — 根據角色設定每位工作人員可開啟的管理區域，包含只讀帳戶和管理員覆蓋權限。
- **自動使用者建立** — 首次SSO登入會建立對應的工作人員帳戶，並在每次登入時從提供者聲明中同步名稱。
- **身分提供者設定** — 儲存一個OpenID Connect提供者的端點、憑證和聲明對應，並加密客戶端密碼以確保靜態安全。
- **行動應用程式單一登入** — 工作人員透過相同的身分提供者登入管理員行動應用程式，並為每個裝置發放權杖。
- **POS工作人員權限** — 控制哪些工作人員可以使用POS以及其可執行的動作和限制，根據使用者的所有角色合併套用。
- **角色與存取控制** — 身分提供者群組設定工作人員和管理員權限，限制登入至工作人員，並為SSO使用者滿足MFA要求。
- **單一登入（網頁）** — 工作人員透過您現有的OpenID Connect身分提供者登入管理員網頁，而非獨立密碼。
- **工作人員指派** — 新增或移除角色中的工作人員，並立即更新其存取權限。
- **工作人員角色與權限** — 建立、編輯、複製、刪除工作人員角色，設定每類別的檢視或完整存取等級，並提供八種預設角色。

- **錯誤與錯誤報告** — 後端和前端錯誤被捕獲，根據特徵碼去重，商家錯誤報告會傳送到更新伺服器以供支援。
- **事件驅動交付** — 將商店事件打包並傳送至每個訂閱端點，同步或非同步進行。

- **商店內幫助中心與搜尋** — 商家和工作人員透過關鍵字和語意搜尋找到解答，包含上文提示、檢視追蹤和幫助性反饋。
- **入站簽名驗證** — 使用時間戳、常數時間 HMAC 簽名檢查驗證入站 webhooks，無效或過期的將被拒絕。
- **授權管理** — 從更新伺服器取得並驗證新簽署的授權和密鑰，並持久化更新的授權資料。

- **平台升級** — 檢查並運行完整的平台版本升級，包括預檢查、套件驗證和排定的主機升級視窗。
